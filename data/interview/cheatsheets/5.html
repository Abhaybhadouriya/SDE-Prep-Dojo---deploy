The 45-minute round

  1. Requirements (about 5 min). Core features, users, scale, latency, consistency. Write them down.
  2. Estimates (about 3 min). Only the numbers that change the design.
  3. API and data model (about 7 min). Endpoints, entities, keys, SQL or NoSQL with a reason.
  4. High-level design (about 10-15 min). One request path at a time, narrating what changes.
  5. Deep dives (about 10 min). The one or two hardest parts: hot keys, consistency, failure.
  6. Wrap-up (about 3-5 min). Bottlenecks, failure of each box, monitoring, what changes at 10x.

See the 45-minute framework for the full version with examples.
