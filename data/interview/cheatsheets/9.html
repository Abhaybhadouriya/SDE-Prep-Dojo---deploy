Remember this

  • Debug in order: status, describe (events), previous logs, endpoints, cluster events.
  • 137 = SIGKILL (often OOM), 143 = SIGTERM. Memory over limit kills; CPU over limit throttles.
  • Kafka production recipe: RF 3, min.insync.replicas 2, acks=all, unclean election off.
  • A new consumer group starts at latest by default; offsets reset only when the group is stopped.
  • 1M requests/day is about 12 per second; storage = writes x size x days x replicas.
  • Every choice gets the sentence: X because A, cost B, switch to Y if C.
  • Defaults change between versions: check the docs before quoting one at work.
