How to use these sheets

  1. Print. Use your browser's print (Ctrl+P). Each sheet starts on a new page; navigation, videos and buttons are hidden in print.
  2. Cover and recall. Hide the right column of a table and try to say the command or value before you look.
  3. Type, do not copy. In a lab, type commands by hand. Your fingers remember better than your eyes.
  4. Trust the docs over this page. Defaults here were read from the official docs for the versions this site targets (Docker Engine 29, Kubernetes 1.37, Kafka 4.4, as of late 2026). Versions change; check before quoting a number at work.

Tip: commands below use capital placeholders such as POD, NAME and GROUP. Replace them with real names.
