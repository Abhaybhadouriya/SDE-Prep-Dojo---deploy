  • Kubernetes Failure Stories blog - a collection of public Kubernetes post-mortems; source for many scenario ideas (repo: hjacobs/kubernetes-failure-stories).
  • danluu/post-mortems repo - a long list of public post-mortems across many companies and technologies.
  • The Pragmatic Engineer on the Reddit Pi-Day outage blog - readable summary of the 1.24 upgrade failure in drill K8.
  • Datadog: deep dive into the 2023-03-08 incident blog - the OS update that removed CNI routing rules (drill K9).
  • OpenAI: Scaling Kubernetes to 7,500 nodes blog - control-plane bottlenecks and what they changed.
  • Slack: Scaling Slack's Job Queue blog - Kafka placed in front of Redis as a durable buffer after an outage.
  • ByteByteGo: Walmart's trillion-message Kafka setup blog - rebalancing pain and the messaging proxy idea (drills F2, F6).
  • CNCF case study: Flipkart chaos engineering blog - preparing Kubernetes services for Big Billion Days.
  • Kubernetes docs: Debug Pods doc - the official version of the pod decision tree.
  • Kubernetes docs: Debug Running Pods doc - kubectl debug, ephemeral containers and node debugging.
  • Kubernetes docs: Resource Management doc - requests, limits, OOM and throttling.
  • Kubernetes docs: PodDisruptionBudgets doc - background for drill K7.
  • Apache Kafka 4.4 docs: Operations doc - consumer group tools, monitoring metrics, topic configs.
  • Debezium PostgreSQL connector doc - replication slots and WAL (drill F10).
  • Docker docs: json-file logging driver doc - log rotation options for drill D3.
  • Yelp: dumb-init blog - why PID 1 in a container is special (drill D2).
  • Snyk: Leaky Vessels blog - container breakout CVEs; good for "patch the runtime, not just images".
