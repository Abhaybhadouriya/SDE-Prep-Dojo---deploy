Quick quiz

At Amazon, which interviewer is from another team and can veto a hire?

  1. The hiring manager
  2. The recruiter
  3. The Bar Raiser
  4. The phone screener
The Bar Raiser comes from outside the hiring team, focuses on the long-term hiring bar (often Leadership Principles) and has veto power.

In a STAR answer, which part should take most of your time?

  1. Situation
  2. Action
  3. Task
  4. Result
The Action is what the interviewer scores: what you personally did, step by step, and why.

Which round is commonly reported as the first and often eliminating round at Flipkart?

  1. Machine coding
  2. Behavioural
  3. System design
  4. Hiring manager
Candidates repeatedly report a 60-90 minute machine-coding round first, where runnable, extensible code is expected.

What most clearly separates an SDE-2 design answer from an SDE-1 answer?

  1. Drawing more boxes
  2. Naming more technologies
  3. Writing code on the whiteboard
  4. Driving the round and raising trade-offs and failure modes unprompted
More boxes or buzzwords do not help. SDE-2 candidates lead the discussion, use numbers to justify choices and talk about failure and monitoring without being asked.

An interviewer asks about a tool you have never used. Best response?

  1. Guess confidently so you do not look weak
  2. Say so briefly, reason from first principles, state assumptions, say how you would verify
  3. Change the topic to something you know
  4. Stay silent and think for five minutes
Honest plus reasoning out loud scores well. Bluffing is the worst option; a wrong confident answer damages trust for the rest of the round.

Which translation of a networking story into SDE language is accurate?

  1. VLAN tagging is the same as Kafka consumer groups
  2. A routing table is a Docker image
  3. ECMP flow hashing is like Kafka key partitioning: same key, same path, order kept
  4. BGP is the same as Kubernetes RBAC
ECMP hashes a flow's 5-tuple to one next hop so packets of a flow stay in order; Kafka hashes the message key to one partition so messages for that key stay in order.
