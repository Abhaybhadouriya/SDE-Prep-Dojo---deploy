Kubernetes

Goal: name every component and what it writes, walk kubectl apply to a serving pod, and explain Services as NAT. On this site: Kubernetes track.

Start (Level 1-2)

  • Kubernetes basics tutorial doc if you open only one - the official six-module tutorial: deploy, expose, scale, update.
  • Kubernetes components doc - one page with every control-plane and node component. Learn it until you can draw it.
  • Killercoda course - free browser terminals with real clusters (and Linux and Kafka scenarios).
  • kubectl quick reference doc - the official cheat sheet. Keep it open in a tab.

Build (Level 3)

  • kind course - run a multi-node cluster in Docker on your laptop. The lab tool this site's pipeline uses.
  • Services doc - ClusterIP, NodePort, LoadBalancer, headless; then read the virtual IPs page it links to.
  • learnk8s: Tracing the path of network traffic blog - follows a packet through iptables, veth and the node. Network-engineer friendly.
  • what-happens-when-k8s repo - every step from kubectl run to a running container, naming each component. The best answer to "walk me through it".
  • CKAD exercises repo - short hands-on drills by topic (pods, config, probes, services).
  • Online Boutique demo repo - an 11-service shop to deploy on kind and break.

Go deep (Level 4-5)

  • Kubernetes the Hard Way repo - build a cluster by hand: certificates, etcd, API server, kubelet. Slow, but nothing is magic afterwards.
  • OpenAI: Scaling Kubernetes to 7,500 nodes blog - etcd and API server limits, why they left an overlay network, and what broke at scale.
  • Datadog: the March 2023 outage blog - an OS update flushed Cilium's routing rules. A kernel-routing story you will understand better than most candidates.
  • Kubernetes failure stories blog - a collection of public post-mortems (DNS, CPU limits, OOM, etcd). Mine it for scenario answers.
  • CNCF case study: Flipkart chaos engineering blog - how Flipkart tests resilience before Big Billion Days. Good for Flipkart interviews.
  • learnk8s: Troubleshooting deployments blog - the famous visual flowchart from "pod not running" to the cause.
