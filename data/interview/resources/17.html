Gotchas: outdated and misleading resources

The cloud-native world moves fast. Many popular posts are now wrong in ways that interviewers notice. Before trusting a resource, check its date and these known changes.

If a resource says...The current truth
"Kafka needs ZooKeeper"ZooKeeper was removed in Kafka 4.0 (March 2025). Kafka 4.x runs only in KRaft mode.
"The default linger.ms is 0"It changed to 5 ms in Kafka 4.0 (KIP-1030).
"The producer default is acks=1"Since Kafka 3.0 the default is acks=all with idempotence enabled.
"Kubernetes runs on Docker (dockershim)"dockershim was removed in Kubernetes 1.24. Nodes use containerd or CRI-O; Docker-built images still run fine.
"Install ingress-nginx for Ingress"The community ingress-nginx controller was retired in 2026. The Ingress API remains; Gateway API is the recommended path.
"Use PodSecurityPolicy"Removed in Kubernetes 1.25; use Pod Security Admission.
"Use kube-proxy IPVS mode for speed"IPVS mode is deprecated (since 1.35) with removal planned; nftables mode is the recommended replacement.
"Kafka beats X by N times" (vendor benchmark)Benchmarks by a vendor are run on that vendor's chosen workload. Quote them as "a vendor benchmark showed..." or not at all.

Common mistakes when studying. (1) Tutorial hell: watching course after course without typing a command. (2) Collecting links instead of finishing one resource. (3) Learning internals first and never practising the 45-minute design round. (4) Trusting forum answers or AI summaries without checking the official docs. (5) Quoting numbers in interviews without knowing where they came from - say "rule of thumb" when it is one.
