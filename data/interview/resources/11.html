Books

Books are slow, so choose few. Read the chapters that match the page you are on, not cover to cover.

BookLevelRead forNotes
Designing Data-Intensive Applications - Martin Kleppmann3-5Replication (ch. 5), partitioning (ch. 6), transactions (ch. 7), consistency and consensus (ch. 9), streams (ch. 11)The book for HLD and Kafka thinking. Chapter numbers refer to the first edition.
System Design Interview, Vol. 1 and 2 - Alex Xu, Sahn Lam3-5One chapter per classic designFast to read, interview-shaped. Pair each chapter with the same design on this site.
Kafka: The Definitive Guide, 2nd ed. - Shapira, Palino, Sivaram, Petty2-4Producers, consumers, internals, reliabilityFree from Confluent. Written before Kafka 4 (ZooKeeper era), so check defaults in the current docs.
Kubernetes: Up and Running, 3rd ed. - Burns, Beda, Hightower, Evenson2-3Core objects and how to use themWritten by Kubernetes co-creators. The publisher's page may block scripts but opens in a browser.
Site Reliability Engineering - Google4SLOs, error budgets, monitoring, incident responseFree to read online. Great for "how do you monitor and roll out?" questions.
Understanding Distributed Systems - Roberto Vitillo3-4A gentler, shorter path through distributed systemsGood if DDIA feels heavy at first.
Database Internals - Alex Petrov4-5B-trees, LSM trees, replication and consensus inside databasesFor when you want the storage-engine depth behind HLD answers.
