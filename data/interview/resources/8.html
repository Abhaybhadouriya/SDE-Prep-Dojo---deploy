End-to-end pipelines and stream processing

Goal: draw app to outbox or CDC to Kafka to stream processor to sink, fix the dual-write problem, and explain event time and windows. On this site: Pipeline project.

Start (Level 2)

  • microservices.io: transactional outbox blog if you open only one - the pattern on one page, from Chris Richardson.
  • Event streaming patterns doc - a catalogue of named patterns (dead-letter, outbox, event sourcing, claim check) with diagrams.

Build (Level 3)

  • Debezium documentation doc - CDC connectors and the outbox event router.
  • debezium-examples repo - runnable docker-compose CDC demos, including an outbox example.
  • Error handling patterns in Kafka blog - stop, skip, dead-letter, retry topics: when to use which.

Go deep (Level 4-5)

  • Shopify: capturing every change from a sharded monolith blog - Debezium and Kafka Connect across many MySQL shards in production.
  • Slack: scaling the job queue blog - after an outage, Slack put Kafka in front of Redis as a durable buffer. A clean backpressure story.
  • Walmart: real-time replenishment on Kafka blog - an inventory pipeline on Kafka. Good for Walmart and e-commerce interviews.
  • Apache Flink documentation doc - read the concepts pages on time, watermarks and state when you reach windowing.
  • Strimzi quickstart doc - run Kafka on kind or minikube with the operator, the base of this site's Kubernetes pipeline page.
