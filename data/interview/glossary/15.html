L4 vs L7 load balancing
HLD must know		One guard looks only at the envelope; the other opens the letter to see what it is about.An L4 load balancer works on TCP/UDP connections (IPs and ports) and is fast and protocol-agnostic. An L7 load balancer understands HTTP: it can route by path or header, terminate TLS, retry and add headers, but costs more CPU. From your world: L4 = 5-tuple NAT/hash; L7 = a proxy that reads HTTP.Networking for HLD: DNS, Proxies, LBs & API Gateways
Labels and selectors
Kubernetes		Name stickers on every toy, and a rule like "all red toys" to pick a group.Labels are key-value tags on objects (app=orders). Selectors pick objects by label. Services, ReplicaSets, NetworkPolicies and Deployments all find their pods this way, not by name. From your world: Like matching a class-map in QoS.Deployments, ReplicaSets & Rollouts
AWS Lambda
Cloud must know		A helper who wakes up only when the doorbell rings, does one small job, and goes back to sleep.Event-driven functions: AWS runs your code per event (an S3 upload, a queue message, a log batch) and bills per request and per GB-second. One invocation runs for at most 15 minutes. Failure handling depends on the trigger type (async, stream or queue).Lambda Glue
Last-known-good config
HLD		If the new instructions look broken, keep following yesterday's instructions.A client-side fallback: each service caches the last configuration that loaded and validated successfully, and keeps using it when the config service is unreachable or a new version fails validation. It makes the config service a soft dependency.Distributed Configuration Service
Latency
HLD		How long you wait between asking and getting an answer.The time one operation takes, measured end to end. Report percentiles (p50, p95, p99), not averages. Latency adds up along every hop and retry. From your world: Exactly the RTT and per-hop delay you know.Back-of-Envelope Estimation
Launch template
Cloud		The recipe card for making one more identical worker.A versioned EC2 configuration: AMI, instance type(s), security groups, IAM instance profile, user data, IMDSv2 setting and disks. An ASG launches every instance from a template version; instance refresh rolls the fleet to a new version.Launch templates
Law of Demeter
LLD		Ask your friend, not your friend's friend's friend.A method should call only its own fields, parameters and objects it creates, not chains like a.getB().getC().doIt(). Reduces coupling to far-away structure. From your world: Not reaching through three struct pointers of another subsystem.DRY, KISS, YAGNI & Law of Demeter
Leader and follower (partition)
Kafka must know		One child holds the real diary; the others copy from them.Every partition has one leader replica that handles all writes (and by default reads) and followers that copy it. If the leader's broker fails, the controller picks a new leader, normally from the ISR. From your world: VRRP master and backups, per partition.Replication & ISR
Leader epoch
Kafka		A "captain number" that goes up every time a new captain is picked.A number that increases with every new leader of a partition. Replicas use it to truncate any records the old leader wrote that were never committed, so logs never diverge. From your world: Like a Raft term.Replication & ISR
Lease
HLD		Borrowing a library book for a fixed time; if you do not renew it, someone else can take it.A lock or leadership right that expires unless renewed. Used for leader election (Kubernetes Lease objects, etcd leases) and to bound how long a dead holder blocks others. From your world: Like a DHCP lease or hold timer.Replication, Consensus & Coordination
LEO (log end offset)
Kafka		The number of the next empty line in the diary.The offset the next record will get in a partition: one more than the last record written. Lag = LEO minus the group's committed offset. From your world: The writer index of a ring.Replication & ISR
linger.ms
Kafka		How long the postman waits for more letters before leaving.A producer setting: how long to wait for more records before sending a batch that is not full yet. Default 5 ms since Kafka 4.0 (was 0). Higher means bigger batches and throughput, a bit more latency. From your world: Interrupt coalescing timer.Producers
Linux capabilities
Docker		Giving a helper only the keys they need, instead of the whole key ring.The kernel splits root's power into about 40 separate privileges (such as CAP_NET_ADMIN, CAP_SYS_ADMIN). Docker drops most of them by default and you can drop more with --cap-drop ALL and add back only what is needed. From your world: capabilities(7), the same API you use for a daemon that needs raw sockets but not full root.Internals: Namespaces, cgroups, OverlayFS
Little's Law
HLD		If 5 children get on the slide every minute and each stays 2 minutes, about 10 are on it at any moment.L = λ × W: the average number of items inside a system equals the arrival rate times the average time each item spends inside. Use it to size in-flight work, e.g. 500 orders/s × a 10-minute saga = 300,000 sagas in flight. From your world: The bandwidth-delay product: rate × time = bytes in flight.Pattern: Multi-step Processes (Sagas & Workflows)
Liveness and readiness probes
Kubernetes must know		Liveness: "Are you awake?" (if not, restart). Readiness: "Are you ready for customers?" (if not, do not send any).Checks the kubelet runs on containers. A failing liveness probe restarts the container. A failing readiness probe removes the pod from Service endpoints without restarting it. A startup probe holds the other two off while a slow app boots. From your world: Readiness = pulling a member out of an ECMP group; liveness = a hardware watchdog reboot.Pods
LL-HLS (low-latency HLS)
HLD		Sending the video in tiny slices so you see the goal a few seconds after it happens.An extension of HTTP Live Streaming that publishes partial segments (a few hundred ms each) and lets players request upcoming parts in advance, cutting live delay from 20-30 s to a few seconds while still using normal CDNs.Live Streaming
LLD (low-level design) / OOD
Interview must know		After you draw the whole city (HLD), you now draw one house: its rooms, doors and who uses which door.Designing the inside of one component: classes, interfaces, their relationships, state and the design patterns used (strategy, observer, factory). Also called object-oriented design (OOD). Interviews ask for a class diagram plus key methods for a parking lot, Splitwise or an LRU cache, and judge clean boundaries, extensibility and SOLID. HLD is boxes and arrows between services; LLD is the code shape inside one box.HLD vs LLD: Handling Combined Design Rounds
LLM (large language model)
HLD		A very well-read robot that guesses the next word again and again to write answers.A neural network trained on large text corpora that generates text token by token. Serving one at scale is a GPU scheduling, batching and caching problem.AI/LLM System Building Blocks
Load balancer
HLD must know		A helper who sends each new customer to the shortest queue.A component that spreads requests across healthy backends using an algorithm (round robin, least connections, hashing) and health checks. Works at L4 or L7; can be hardware, software (NGINX, Envoy, HAProxy) or a cloud service. From your world: An L4 VIP with health-checked real servers, or an L7 proxy.Networking for HLD: DNS, Proxies, LBs & API Gateways
LoadBalancer Service
Kubernetes		Asking the city to give your building a public front door.A Service type that asks the cloud (or MetalLB on bare metal) for an external load balancer with a public IP that forwards to the Service's NodePorts or directly to pods.Services & Cluster Networking
Log aggregation
HLD		Collecting every class's diary into one big library so you can search them all.Shipping logs from every container and host (with agents such as Fluent Bit) into a central store (Elasticsearch/OpenSearch, Loki) where they can be searched and alerted on, often through Kafka as a buffer. From your world: Centralised syslog at a much larger scale.Log Aggregation (ELK at scale)
Log compaction
Kafka		A notebook where, for each friend, you only keep their newest phone number.A topic cleanup policy (cleanup.policy=compact) where Kafka keeps at least the latest record for every key and removes older ones in the background. A record with a null value (a tombstone) deletes the key. Used for state, such as __consumer_offsets. From your world: Like an ARP or MAC table: only the latest entry per key matters.Storage Internals & Performance Secrets
Log segment
Kafka		A diary is made of many small notebooks; when one is full, a new one starts.A partition on disk is a directory of segment files (.log plus .index and .timeindex), each named by its first offset and up to 1 GiB by default. Only the newest (active) segment is written; retention deletes whole old segments.Storage Internals & Performance Secrets
Long polling
HLD		Asking "anything new?" and the shopkeeper waits to answer until there is news.The client sends a request that the server holds open until data changes or a timeout passes, then the client immediately asks again. Simpler than WebSockets and works through proxies; used by config services and chat fallbacks.Distributed Configuration Service
LP (Amazon Leadership Principles)
Interview		The class rules everyone is graded on, like "be kind" and "finish what you start".Amazon's list of principles (Customer Obsession, Ownership, Dive Deep, and others). Every Amazon interview round includes questions on one or two of them, answered as STAR stories; weak LP answers can sink a strong technical loop.Amazon Guide
LRU eviction
HLD		When the toy shelf is full, the toy nobody touched for longest goes back to the attic.Least recently used: when a cache is full, remove the entry that was used longest ago. Redis offers LRU and LFU approximations as maxmemory-policy choices. From your world: Same LRU as page replacement or a CPU cache.Fundamentals: Scale, Cache, DB, CAP
LSM tree
HLD		Writing new notes quickly on loose pages, then tidying them into sorted books later.Log-structured merge tree: writes go to a memory table and a log, are flushed as sorted immutable files (SSTables) and merged by compaction. Fast writes; reads may check several files (Bloom filters help). Used by Cassandra, RocksDB, LevelDB.Data Modeling, Indexing & Storage Engines
LSO (last stable offset)
Kafka		The last line in the diary where every unfinished story has been finished.In a partition with transactions, the offset before the first still-open transaction. A read_committed consumer reads only up to the LSO, so one long-open transaction holds readers back.Delivery Semantics & Exactly-Once
LSP (Liskov Substitution Principle)
LLD must know		A toy duck that needs batteries is not a drop-in for a real duck at the pond.The L in SOLID: a subtype must work anywhere its base type is expected, without surprising callers (no stronger preconditions, no weaker guarantees, no new exceptions). From your world: A new driver must honour the same ops contract, return codes included.Liskov Substitution Principle
