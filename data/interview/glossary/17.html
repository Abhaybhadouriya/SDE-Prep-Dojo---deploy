Network ACL (NACL)
Cloud		A guard at the street entrance with a numbered checklist who remembers nobody.A stateless, numbered allow/deny rule list attached to a subnet and evaluated lowest number first. Because it is stateless, replies need their own rule (usually ephemeral ports 1024-65535). Use it for coarse subnet-wide blocks; do day-to-day filtering with security groups.Security groups vs NACLs
Namespace (Kubernetes)
Kubernetes must know		A named folder for a team's toys inside the same toy room.A logical group of Kubernetes objects (for example shop, kube-system). Names must be unique inside a namespace; RBAC, ResourceQuotas and NetworkPolicies are applied per namespace. It gives no kernel isolation at all. From your world: Like a VRF name for config grouping, but with no forwarding separation by itself.Security & RBAC
Namespace (Linux)
Docker must know		Blinkers on a pony: the process can only see its own little world.A kernel feature that gives a process its own view of one resource: pid, net, mnt, uts, ipc, user, cgroup and time namespaces. A container is a process in its own set of namespaces. From your world: clone(2) flags such as CLONE_NEWNET; a net namespace is like a VRF for one process tree.Internals: Namespaces, cgroups, OverlayFS
Namespace (which one?)
Kubernetes		Two different things share one word: a fence the kernel puts around a process, and a folder for Kubernetes objects.A Linux namespace is a kernel isolation feature that makes a container possible. A Kubernetes namespace is just a named group of API objects for organisation, quotas and access control. They are unrelated.Pods
NAT gateway
Cloud must know		A one-way door: people inside can go out to the shops, but nobody outside can walk in.A managed, outbound-only address translator (PAT) for private subnets. It lives in one AZ, so production runs one per AZ. It supports up to 55,000 simultaneous connections to each unique destination per IP address and is billed per hour plus per GB processed. From your world: iptables MASQUERADE with conntrack.NAT gateway
NetworkPolicy
Kubernetes		Rules for which classrooms may pass notes to which.A Kubernetes object that allows ingress and egress traffic to selected pods by labels, namespaces, IP blocks and ports. Once a pod is selected, all other traffic is denied. Needs a CNI that enforces it (Calico, Cilium). From your world: ACLs applied per pod, written with labels instead of addresses.Security & RBAC
Node
Kubernetes		One classroom where lunch boxes are opened.A worker machine (VM or bare metal) in a Kubernetes cluster. It runs the kubelet, a container runtime and kube-proxy (or an eBPF replacement), and hosts pods. From your world: A line card.Architecture: Control Plane & Nodes
NodePort
Kubernetes		Opening the same numbered side door on every house in the street.A Service type that opens one port (default range 30000-32767) on every node and forwards it to the Service's pods. Simple, but clients must know node IPs; usually sits behind a LoadBalancer. From your world: A static NAT on every box.Services & Cluster Networking
Noisy neighbour
Docker		One loud child in a shared room makes it hard for everyone else to work.One workload hurting others on the same host by using shared resources that cgroups do not fully isolate: CPU caches, memory bandwidth, disk I/O, network queues, kernel locks. From your world: Head-of-line blocking from one port on a shared buffer.Internals: Namespaces, cgroups, OverlayFS
Normalization
HLD		Writing each friend's address once in an address book, not on every party invite.Organising relational tables so each fact is stored once and referenced by keys, avoiding update anomalies. Reads may need joins; denormalization trades that back for speed.Data Modeling, Indexing & Storage Engines
NoSQL
HLD must know		Toy boxes shaped for one kind of toy, not one big shelf with fixed slots.Databases that are not traditional relational SQL stores: key-value (Redis, DynamoDB), document (MongoDB), wide-column (Cassandra, Bigtable), graph (Neo4j). They usually scale out by partitioning and offer flexible schemas, with weaker joins and transactions.Choosing Storage: DB Types & Key Technologies
NRML (carry-forward position)
HLD		Keeping your toy overnight instead of giving it back at home time.In Indian broker apps, NRML is the product type for futures and options positions you can hold overnight until expiry, as opposed to MIS (intraday, squared off the same day) and CNC (delivery of shares).Stock Broker App
Null Object (pattern)
LLD		A 'nobody' player who always passes, so the game never has to ask 'is anyone there?'.An object that implements the interface with do-nothing behaviour, replacing null checks (a NoOpLogger, a NoDiscount). From your world: A dummy ops table with stub functions instead of NULL checks everywhere.Null Object
