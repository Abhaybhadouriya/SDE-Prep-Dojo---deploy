OA (online assessment)
Interview		A take-home test the school sends before you are invited to the real classroom.A timed online coding test (often 60-120 minutes, 2-4 problems) on a platform such as HackerRank or CodeSignal, used to filter candidates before any live interview. Some include debugging or multiple-choice parts. Treat it like a DSA round with no interviewer to give hints.Interview Hub
OAuth 2.0 / OpenID Connect
HLD		Letting a friend borrow your library card for one book, without giving them your house key.OAuth 2.0 is a framework for granting an app limited access tokens to act on a user's behalf. OpenID Connect adds a standard identity layer (ID tokens) on top for login and SSO.Security & Identity in System Design
Observability (metrics, logs, traces)
Kubernetes		Windows, diaries and footprints that let you see what the system is doing inside.Being able to understand a system's internal state from its outputs: metrics (numbers over time), logs (events) and traces (one request's path across services). OpenTelemetry is the common standard for producing them. From your world: SNMP / streaming telemetry, syslog, and a packet trace across hops.Observability & Troubleshooting
Observer (pattern)
LLD must know		A newsletter: everyone who signed up gets the news when it comes out.A behavioural pattern: a subject keeps a list of observers and notifies them on change. Watch for leaks (unsubscribe), ordering and slow observers. From your world: Linux notifier chains (register_netdevice_notifier).Observer
OCI (Open Container Initiative)
Docker		The shared rule book so every company's lunch boxes fit every company's shelves.A Linux Foundation project with three specs: the image spec (manifests, layers), the runtime spec (config.json plus a root filesystem, run by runc) and the distribution spec (the registry HTTP API).Internals: Namespaces, cgroups, OverlayFS
OCP (Open/Closed Principle)
LLD must know		Add a new LEGO piece without melting the old ones.The O in SOLID: open for extension, closed for modification. Add new behaviour by adding a class behind an interface, not by editing a switch statement. From your world: Adding a new protocol by registering ops, without editing the core.Open/Closed Principle
Offset
Kafka must know		The line number in the diary.A 64-bit number giving a record's position inside one partition, starting at 0 and only increasing. Consumers commit the offset they have finished so they can resume after a restart. From your world: The ring-buffer read index; each consumer group has its own.Core Concepts: Topics, Partitions, Offsets
OHLC candle
HLD		For each minute, write down the first, highest, lowest and last price - that is one candle.Open, high, low and close price for a time bucket (1 minute, 1 day), the data behind candlestick charts. Built by stream aggregation over ticks; recent candles are served from cache and older ones from a time-series or SQL store.Stock Broker App
On-call
SRE must know		Taking turns holding the "wake me if the house is on fire" phone.A rotation in which one engineer (plus a secondary) is reachable to respond to production pages within an agreed time for a fixed shift. Healthy on-call caps pages per shift and turns every page into follow-up work.On-Call & Postmortems
OI (open interest)
HLD		How many swap promises between children are still not finished.The number of futures or options contracts that are still open (not closed or expired). Broker apps show it next to price and volume on F&O instruments.Stock Broker App
OLAP store
HLD		A big notebook arranged so that adding up whole columns is very fast.Online analytical processing: a database built for fast group-by, sum and count queries over huge tables, usually column-oriented. Examples: Apache Druid, Apache Pinot, ClickHouse. The opposite of OLTP, which serves many small row reads and updates. From your world: Like a flow collector built for reports, not the forwarding table.Pattern: Counting, Ranking & Windowed Aggregation
OIDC (OpenID Connect)
HLD		A signed name badge that says who you are, so you do not need to carry a secret password.A standard for signed identity tokens (JWTs) built on OAuth 2.0. A CI system gives each job a short-lived OIDC token whose claims say which repo, branch and workflow it is; a cloud provider or a signing service (Sigstore) trusts the issuer's signature and exchanges it for a short-lived credential, so no long-lived keys are stored. From your world: Like a certificate signed by a CA you trust, issued per session instead of a shared password.CI/CD Platform
OOMKilled
Kubernetes must know		The program ate more than its lunch-money limit, so it was sent home at once.A container status meaning the kernel OOM killer stopped it with SIGKILL because its cgroup memory limit was reached (exit code 137). Fix the leak, or raise the limit to fit the real working set. From your world: The kernel OOM killer, scoped to a memory cgroup.Scheduling & Autoscaling
OpenTofu
IaC		The same recipe book, copied by the community before the publisher changed the rules.The Linux Foundation fork of Terraform, created after HashiCorp moved Terraform from MPL 2.0 to the Business Source License in August 2023 (Terraform 1.6). HCL and state are largely compatible; OpenTofu adds features such as client-side state encryption.Terraform Basics
Operator
Kubernetes		A robot nanny that knows exactly how to look after one tricky toy, like Kafka.A custom controller plus CRDs that encode the operational knowledge for one application (install, upgrade, scale, back up, fail over). Strimzi is the operator for Kafka on Kubernetes.StatefulSets, CRDs & Operators
Optimistic locking
HLD		You fix a page only if nobody changed it since you looked; otherwise you look again.Concurrency control without holding locks: read a version number, then write only if the version is unchanged (compare-and-set); on conflict, retry. Good when conflicts are rare. From your world: Like a compare-and-swap instruction.Pattern: Dealing with Contention
Outbox pattern
Pipeline must know		Writing your letter into the same notebook as your diary entry, and a postman later posts every new letter.Writing the business change and an "event to publish" row in the same database transaction; a separate relay (often CDC with Debezium) publishes the outbox rows to Kafka. Fixes the dual-write problem; consumers must still de-duplicate.Distributed Transactions & Event-Driven Data
Overlay network (VXLAN)
Kubernetes		A secret tunnel between houses, so pods think they are on the same street.A virtual network built by encapsulating pod packets inside packets between nodes (VXLAN, Geneve), so pod IPs work across a network that does not know them. Costs a little MTU and CPU; the alternative is native routing such as BGP. From your world: VXLAN tunnels and VTEPs on every node.Services & Cluster Networking
OverlayFS
Docker		Stacking clear sheets: you see through to the pictures below, and new drawing goes on the top sheet.A union filesystem that merges read-only lower directories (image layers) with one writable upper directory into one view. Docker's overlay2 driver uses it; changing a lower file copies it up first. From your world: overlayfs lowerdir / upperdir / workdir / merged.Internals: Namespaces, cgroups, OverlayFS
