veth pair

Visitor (pattern)
LLD		A doctor visiting each animal in the zoo and doing the right check for each kind.A behavioural pattern that adds operations to a fixed class hierarchy without changing it, using double dispatch (accept(visitor) calls visitor.visit(this)). VPA (Vertical Pod Autoscaler)

VPC (Virtual Private Cloud)

You split it into subnets, one or more per Availability Zone, and steer traffic with route tables. From your world: a VRF with its own routing table.AWS Networking: VPC & Subnets
vtable
LLD		A list of phone numbers inside each toy: 'for speak, call this one'.The per-class table of function pointers a compiler uses for virtual (overridable) methods; each object carries a pointer to its class's table. Dynamic dispatch costs one extra indirect call. From your world: Exactly a const ops table pointed to from each object.Polymorphism & vtables
VXLAN
