JA3 / JA4 fingerprint
HLD		Recognising someone by the way they knock, whatever name they give.A hash of a client's TLS ClientHello (cipher suites, extensions, ALPN). Each TLS library produces its own, so a "Chrome" User-Agent with a Python-requests fingerprint is a strong bot signal. JA4 sorts the fields, so the extension-order shuffling that broke JA3 does not break it.Edge Defense & Bots
Jenkins
CI/CD		An old, reliable butler who will do any job you write down, if you keep him fed.A self-hosted open-source automation server. Pipelines are written as a Jenkinsfile (declarative or scripted Groovy) and run on agents; plugins add almost everything. Flexible, but you own the controller, the plugins and their upgrades.Builds and Pipelines

JVM (Java Virtual Machine)
Kafka		The machine that runs Java programs.The runtime that executes Java bytecode. Kafka brokers and many clients run on it; heap size and garbage collection settings affect latency.Operations, Tuning & Kafka on K8s
JWT (JSON Web Token)
HLD		A signed hall pass that any teacher can check without calling the office.A compact token with a header, JSON claims (user, expiry, scopes) and a signature. Services verify the signature locally instead of calling an auth server. Hard to revoke before expiry, so lifetimes are kept short.Security & Identity in System Design
