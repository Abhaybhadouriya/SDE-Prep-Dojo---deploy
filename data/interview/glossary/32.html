Quick quiz

Which operation is idempotent?

  1. Add 10 to the balance
  2. Set the order status to PAID for order 7
  3. Append a new row to a log
Setting a value to a fixed result gives the same end state however many times you do it. Adding or appending changes the state each time.

The log end offset of a partition is 14 and the group committed 8. What is the lag?

  1. 14
  2. 8
  3. 6
Lag = log end offset minus committed offset = 14 - 8 = 6 records not yet read.

Which watermark decides how far a Kafka consumer may read?

  1. The high watermark
  2. The event-time watermark
  3. Neither
The high watermark is the replication one: consumers read only records every in-sync replica has. The event-time watermark lives inside a stream processor.

A Kubernetes namespace gives pods...

  1. Their own kernel and network stack
  2. A shared name scope for objects, RBAC and quotas, but no kernel isolation
  3. A separate physical node
Kubernetes namespaces are an API grouping. The kernel-level fences are Linux namespaces, which every pod gets anyway.

A container exits with code 137. What is the most likely cause?

  1. A syntax error in the app
  2. A normal SIGTERM stop
  3. SIGKILL, often the OOM killer after hitting the memory limit
137 = 128 + 9, and signal 9 is SIGKILL. In Kubernetes it usually shows as OOMKilled. 143 would be SIGTERM.

What is a ClusterIP, physically?

  1. A virtual IP that exists only as NAT rules programmed on every node
  2. An IP on the control-plane node's interface
  3. The pod's own IP
No interface owns it. kube-proxy (or an eBPF data plane) programs each node to DNAT the ClusterIP to a ready pod IP.

What is a PVC?

  1. A kind of container image
  2. A pod's request for storage that Kubernetes binds to a PersistentVolume
  3. A network policy
A PersistentVolumeClaim asks for storage of a size, access mode and class; Kubernetes binds it to a PersistentVolume, often created on demand.

Which pair is the closest "from your world" match for a rate limiter's token bucket?

  1. ECMP hashing
  2. VXLAN
  3. A QoS policer
It is the same algorithm as a token bucket policer or shaper: tokens refill at a rate, bursts up to the bucket size are allowed.
