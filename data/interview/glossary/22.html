S2 / H3 cells
HLD		Covering the whole globe with numbered tiles so you can say "everything in tile 42".Hierarchical ways to divide the Earth into cells with 64-bit ids. Google S2 projects the globe onto a cube and orders squares with a Hilbert curve; Uber H3 uses hexagons, whose neighbours are all the same distance away. A query covers a circle with a few cells and scans them. From your world: Like hierarchical IP prefixes, but for places.Pattern: Geo & Proximity Queries
Saga
HLD must know		A chain of small promises; if one fails, you undo the earlier ones politely.A way to do a multi-service business transaction as a sequence of local transactions, each with a compensating action if a later step fails. Coordinated by an orchestrator or by events (choreography).Distributed Transactions & Event-Driven Data
Sandboxed runtime (gVisor, Kata, Firecracker)
Kubernetes		Putting a risky toy inside its own glass box, so even if it breaks it cannot touch the other toys.A container runtime that adds a stronger wall than plain namespaces, for untrusted code. gVisor (runsc) runs a user-space kernel that intercepts the container's system calls; Kata Containers and Firecracker run each pod or task in a tiny virtual machine with its own kernel. In Kubernetes you choose one per pod with a RuntimeClass. Trade-off: better isolation for some start-up time and system-call overhead. From your world: Moving from a process jail to a separate VM or hypervisor partition.Security & RBAC
Savings Plan
SRE		Paying for a year of bus rides up front to get a cheaper fare.An AWS commitment to spend a fixed amount per hour on compute for 1 or 3 years in return for a discount. Compute Savings Plans apply across EC2, Fargate and Lambda; EC2 Instance Savings Plans give a bigger discount but lock the instance family and region.Cloud Cost / FinOps
SBOM (software bill of materials)

ScaNN
HLD		Finding the closest toys quickly by first sorting them into labelled bins.Google's approximate nearest-neighbour library: partition the vectors, score candidates with anisotropic vector quantisation, then re-rank the best few exactly. Also offered as a managed index in AlloyDB and in Vertex AI Vector Search.Recommendation Algorithms
Scatter-gather
HLD		Asking every classroom the same question at once, then putting all the answers together.Sending one request in parallel to many shards or services and merging their replies. Latency is set by the slowest reply: if each shard is slow 1% of the time, a request to 100 shards hits at least one slow shard about 63% of the time (1 - 0.99100). From your world: Like a broadcast query where you must wait for every reply.Pattern: Fan-out (Push vs Pull)
Schema Registry

From your world: BPF syscall filtering, the same one you can attach with prctl.Internals: Namespaces, cgroups, OverlayFS
Secret

Security group

A rule can name another security group as the source instead of an IP range.EC2, ASG & Security Groups
Semantic lock
HLD		Putting a "being used" note on a toy so other children leave it alone until you are done.A status field such as PENDING that a saga sets on a record it is still working on; other sagas see the flag and wait, refuse or handle the record specially. Semaphore
LLD		A parking lot sign that counts free spaces.A counter of permits: acquire takes one (waits if zero), release returns one. Limits concurrency (connection pools); a binary semaphore is not quite a mutex because it has no owner. From your world: The kernel's struct semaphore, down() and up().Locks, Conditions & Semaphores
Sequence diagram

HLD must know		Splitting a giant phone book into A-H, I-P and Q-Z books held by different people.Splitting one dataset across several databases (shards) by a shard key, using hash, range or a lookup directory. Share group (Queues for Kafka)
Kafka		Many readers may take letters from the same pile, one letter each.A KIP-932 consumer type, production ready in Kafka 4.2, where several consumers can read the same partition and each record is acknowledged individually, giving queue-like work sharing without the "one consumer per partition" limit. Single-flight (request coalescing)
HLD		When ten children ask the same question, only one walks to the teacher and tells the others the answer.Letting only one request per key do the expensive fetch while concurrent requests for the same key wait for its result. Stops a cache stampede. A slow or failed leader must not turn into a false "not found" for the waiters. From your world: Like ARP resolution: one request on the wire, many packets queued behind it.Pattern: Scaling Reads (and Caching Pitfalls)

SLA, SLO, SLI
HLD must know		SLI: what you measure. SLO: the goal. SLA: the promise with a penalty.A Service Level Indicator is a measured number (for example the share of requests under 300 ms). HLD		A number made from the time, the machine's number and a counter, so no two are ever the same.A 64-bit, roughly time-ordered unique id: 41 bits of milliseconds, 10 bits of machine id and 12 bits of sequence, as in Twitter's original design. SOLID principles
Interview		Five tidy-room rules so that adding a new toy never means rebuilding the whole shelf.Five object-oriented design rules: Single responsibility (one reason to change per class), Open/closed (add behaviour by adding code, not editing old code), Liskov substitution (a subclass must work wherever its parent does), Interface segregation (small, focused interfaces), Dependency inversion (depend on interfaces, not concrete classes). LLD and machine-coding rounds judge your classes against these.HLD vs LLD: Handling Combined Design Rounds

SSTable (sorted string table)

Static membership (group.instance.id)
Kafka		A kid who says "I am just going to the bathroom, keep my seat" so the teacher does not reshuffle the whole class.Give each consumer a fixed group.instance.id (KIP-345). If it restarts and comes back within session.timeout.ms, it gets the same partitions back with no rebalance, which makes rolling restarts on Kubernetes much calmer. Trade-off: if it really died, its partitions wait for the session timeout before moving. From your world: A stable identity like a fixed MAC or router ID, so a reboot does not trigger reconvergence.Consumers & Consumer Groups
