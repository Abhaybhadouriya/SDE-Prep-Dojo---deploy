Gateway API

GC pause
Kafka		The whole class stops while the cleaner sweeps the floor.A pause while the Java garbage collector frees memory. A long pause can make a broker or consumer miss heartbeats, which looks like a failure and causes ISR shrinks or rebalances. From your world: Like a CPU stall long enough to miss hello timers.Operations, Tuning & Kafka on K8s
GDS (global distribution system)
HLD		A big shared notebook where airlines write which seats are free, read by many travel shops.A shared booking network (Amadeus, Sabre, Travelport) that travel sites query for flight availability and fares and use to hold and ticket seats. Calls are slow and rate-limited, so search results are cached and a seat is only truly yours after the supplier confirms.Flight Search & Booking
Geohash
HLD		Cutting a map into squares and giving each square a short name; neighbours have similar names.An encoding of latitude and longitude into a short string where a shared prefix usually means nearby. Lets an ordinary index answer "what is near me?" Quadtrees, S2 and Uber's H3 hexagons are alternatives. From your world: Like longest-prefix match on an address: shared prefix, same area.Geospatial, Text & Prefix Indexes
GitHub Actions
CI/CD		A robot that wakes up every time you push and runs your checklist.GitHub's built-in CI/CD. A workflow (YAML in .github/workflows/) runs jobs on hosted or self-hosted runners when an event fires (push, pull request, schedule). Jobs are made of steps that run shell commands or reusable actions; secrets, caches, artifacts and OIDC tokens for cloud logins are built in.Builds and Pipelines

God object

Golden signals (latency, traffic, errors, saturation)
HLD		Four questions a doctor asks first: how fast, how busy, how many mistakes, how full.The four metrics Google's SRE book says to watch first on any user-facing service: latency (how long requests take, split into successful and failed), traffic (requests per second), errors (rate of failed requests) and saturation (how full the busiest resource is: CPU, memory, queue depth, consumer lag). Saying these four is the fastest strong start to any "how would you monitor it" question. From your world: Interface counters: rate, drops, errors, buffer utilisation.Reliability at Scale: SLOs, Multi-Region & DR
Gossip protocol
HLD		Each child tells two friends the news, and soon the whole school knows.Nodes periodically exchange state with a few random peers, so information (membership, failures) spreads to all nodes in O(log n) rounds without a central server. Used by Cassandra, Consul and Redis Cluster. From your world: Like flooding of link-state adverts, but random and lazy.Replication, Consensus & Coordination
Graceful shutdown (SIGTERM)
Kubernetes		"Please finish your sentence and then leave" instead of being pulled out of the room.When a pod is deleted, the kubelet sends SIGTERM, waits terminationGracePeriodSeconds (30 s default), then SIGKILL. The app should stop accepting work, finish in-flight requests and commit offsets. Endpoints are removed in parallel, so a short preStop sleep helps.Pods
