IAM role (and STS)
Cloud must know		A visitor badge that works for one hour and only opens the doors written on it.An AWS identity with permission policies but no password or long-lived keys. A trusted principal (an EC2 instance, an ECS task, a Lambda function, a pod, a person) assumes it through STS and gets temporary credentials that expire. A trust policy says who may assume it. Evaluation: an explicit deny beats any allow, and anything not allowed is denied.IAM in 10 minutes
Idempotency key
HLD must know		A ticket number on your order, so if you ask twice the shop knows it is the same order.A unique id the client sends with a request (often an Idempotency-Key header). The server stores the key with the result and returns the stored result for any retry, so a timeout-and-retry never charges twice. From your world: Sequence numbers that let a receiver drop retransmitted duplicates.Payment System
Idempotent
HLD must know		Pressing the lift button five times still brings one lift.An operation is idempotent if doing it many times has the same effect as doing it once. "Set status to PAID" is; "add 10 to balance" is not. The foundation of safe retries in at-least-once systems.Distributed Building Blocks
Idempotent producer
Kafka		The postman numbers each letter so the post office throws away accidental copies.A Kafka producer mode (default since 3.0) where the broker gives the producer an id and epoch, and each batch carries a per-partition sequence number. The broker drops duplicate retries and keeps order. From your world: Sequence-number de-duplication on a reliable link.Producers
Image (container image)
Docker must know		A frozen, ready-to-go lunch box you can copy as many times as you like.A read-only, content-addressed bundle: an ordered list of filesystem layers (tarballs) plus a JSON config (command, env, user), described by a manifest. Running it creates a container with a thin writable layer on top. From your world: An ELF binary vs the running process: one image, many containers.Images & Layers
Image digest
Docker		A fingerprint for a picture; if one dot changes, the fingerprint changes.A content address such as sha256:3f2b... computed from an image manifest or layer. Unlike a tag, a digest can never point to different content, so image@sha256:... pins an exact build. From your world: A firmware image checked by its SHA-256, not by its file name.Images & Layers
Incident commander (IC)
SRE		The one person holding the clipboard during a fire drill, telling everyone what to do.The role that coordinates an incident: sets severity, assigns operations, communications and scribe roles, decides on mitigations and keeps the timeline. The IC does not debug; they keep everyone else effective.On-Call & Postmortems
Inheritance
LLD		A puppy gets its parent's spots and can learn new tricks.An is-a relationship: a subclass reuses and extends a base class. Use it for true subtype relationships (LSP holds); prefer composition for code reuse. From your world: Embedding a base struct as the first member and casting with container_of.Inheritance
Interface (OOP)
LLD must know		A plug shape: anything with this shape fits the socket.A contract of method signatures with no state. Classes implement it; callers depend on it. The main tool for loose coupling, testing and the Strategy pattern. From your world: A struct of function pointers such as file_operations.Abstract Classes vs Interfaces
Internet Gateway (IGW)
Cloud		The main gate of the plot that opens onto the public road.A horizontally scaled VPC attachment that routes traffic to and from the internet and does 1:1 NAT between an instance's public IPv4 and its private IP. A subnet is public when its route table sends 0.0.0.0/0 to the IGW.Route tables and the IGW
IRSA / EKS Pod Identity
Cloud		Giving each lunch box its own visitor badge instead of sharing the building's badge.Two ways to give a Kubernetes pod on EKS its own IAM role. IRSA: the pod's projected service-account token is exchanged with STS AssumeRoleWithWebIdentity through the cluster's OIDC provider. Pod Identity: an association maps a service account to a role, and a node agent hands the pod its credentials.Pod IAM: IRSA vs Pod Identity
Image layer
Docker must know		One clear sheet in a stack of pictures; together they make the whole picture.A tarball of filesystem changes made by one Dockerfile instruction, identified by its digest. Layers are shared between images and stacked with OverlayFS; files deleted in a later layer are only hidden (whiteouts), so secrets in early layers stay inside the image. From your world: overlayfs lowerdirs.Images & Layers
Image tag
Docker		A sticker name on the lunch box, like "version 2"; someone can move the sticker to another box.A human-friendly, movable name for an image, such as myapp:1.4.2. latest is just a default tag, not "the newest". Pin by digest for reproducible deploys.Images & Layers
Ingress
Kubernetes must know		The receptionist at the building's front door who sends visitors to the right office by the address they say.A Kubernetes object with HTTP routing rules (host and path to Service), carried out by an Ingress controller (a reverse proxy). The API is frozen and still supported; the community ingress-nginx controller was retired in 2026, and Gateway API is the recommended successor. From your world: An L7 reverse proxy policy table.Ingress & Gateway API
Init container
Kubernetes		A helper who sets up the table before the party starts.A container in a pod that runs to completion before the main containers start, for example to wait for a database, run migrations or fetch config. Init containers run one at a time, in order.Pods
Inverted index
HLD		A list of every word, and for each word the pages where it appears.A map from each term to the list of documents (and positions) containing it. The core of full-text search engines like Lucene, Elasticsearch and OpenSearch.Geospatial, Text & Prefix Indexes
iptables / nftables
Kubernetes		The traffic rules on every road in your town.Linux packet filtering and NAT frameworks. Docker uses them for port publishing and masquerade; kube-proxy uses them (iptables mode by default, nftables mode GA since 1.33) to DNAT Service IPs to pod IPs on every node. From your world: The netfilter tables you already know; iptables -t nat -L shows the magic.Services & Cluster Networking
IPVS mode (kube-proxy)
Kubernetes		An older faster road sign system that the town is now taking down.A kube-proxy mode using the kernel's IP Virtual Server load balancer. Deprecated since Kubernetes 1.35 with removal planned; nftables mode is the recommended replacement. From your world: LVS, the kernel L4 load balancer.Services & Cluster Networking
ISP (Interface Segregation Principle)
LLD		Don't make a fish sign up for flying lessons.The I in SOLID: clients should not depend on methods they do not use. Split fat interfaces into small, role-based ones. From your world: Drivers fill only the ops they support; small ops tables beat one huge one.Interface Segregation Principle
ISR (in-sync replicas)
Kafka must know		The helpers whose diaries are fully caught up with the leader's.The set of replicas (leader included) that are caught up with the leader within replica.lag.time.max.ms. acks=all waits for all of them; only ISR members are normally elected leader. From your world: A redundancy group with sync state: an out-of-sync member is a standby not ready to take over.Replication & ISR
