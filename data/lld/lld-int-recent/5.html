1. AI-assisted LLD rounds arrived (and some companies ban AI)

4 reports in our set describe a round where AI tools were allowed or required. The pattern in those posts: the interviewer watches how you use the tool - how you frame the prompt, what you accept, what you reject - more than the code it writes. At the same time, the 2026 Flipkart machine-coding guidelines in a posted problem statement say AI tools are not allowed. Always ask which rule applies.

2. Concurrency is now part of the problem, not a bonus

Several 2026 prompts list thread safety as a core requirement: the Flipkart quick-commerce problem (post 7588244, 2026-02-18), Adobe's thread-safe message queue in C++ (post 8452812, 2026-08-10) and Walmart's thread pool executor (post 7620235, 2026-03-02). Rubrik goes further and gives a whole multithreading round ("sync two large hash maps", post 8524180, 2026-09-16), which is not an LLD round but tests the same locking skills. Prepare the concurrency interview set.

4. Domain apps replace toy problems at Indian product companies

Flipkart, PhonePe and Meesho now set business-shaped problems (BNPL: Buy Now Pay Later, quick commerce, hackathon platform, app version rollout, customer issue resolution) rather than textbook ones. The skill is the same; the nouns are new every time. Practise turning an unseen problem statement into entities in 10 minutes.
