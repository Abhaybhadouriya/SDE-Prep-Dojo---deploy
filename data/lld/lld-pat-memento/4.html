How it works: undo with Command and Memento, step by step

The most common real use combines two patterns: each Command takes a memento before it runs, so undoing it is simply "restore what it saved".

  1. The user types. History (the caretaker) runs a command object for that edit.
  2. Before changing anything, the command asks the editor for a snapshot. Only the editor knows what goes into it; the command just holds the envelope.
  3. Now the command performs the edit on the editor.
  4. History pushes the command on the undo stack. Any redo history is cleared, because a new edit starts a new branch of time.
  5. The user presses Ctrl+Z. History pops the last command and calls its undo().
  6. The command hands the saved snapshot back to the editor, which restores its own state. The command moves to the redo stack.
