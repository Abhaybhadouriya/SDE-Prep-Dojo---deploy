Remember this

  • Memento = save an object's state in an opaque snapshot and restore it later, without exposing fields.
  • Originator creates and reads mementos; Caretaker stores them and never looks inside.
  • Keep mementos immutable and deep: shallow copies share mutable parts and silently change.
  • Cost = state size x snapshots kept. Cap history; use deltas or Command undo for large state.
  • Undo/redo = two stacks; a new action clears redo; commands often hold a memento.
  • Checkpoint before a risky batch, restore on failure: all-or-nothing updates.
  • Kernel bridge: pt_regs on entry, context switch, setjmp/longjmp, CRIU.
