Related and confused-with patterns

PatternRelation to MementoOne-liner
CommandUndo by reversing an operation instead of restoring a state; often combined (the command stores a memento)"Memento stores state; Command stores the action."
PrototypeBoth copy an object. Prototype makes a new working object; a memento is a frozen copy only used to restore"Prototype clones to use; Memento copies to go back."
IteratorAn iterator's position can be saved as a memento to resume a walk later"A bookmark is a memento of a cursor."
StateState changes behaviour by swapping state objects; Memento saves data to restore. Different problems, similar name"State is behaviour; Memento is a backup."
Event sourcingStore every event and rebuild state by replay; snapshots (mementos) speed up replay"Log of changes plus periodic snapshots."
