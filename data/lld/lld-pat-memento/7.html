Real-world uses

WhereMementoNotes
Editors and IDEsUndo / redo historyUsually Command-based with snapshots for complex steps, as in our demo.
JDK (Swing)javax.swing.undo.StateEdit with StateEditableThe object stores its state into a table (storeState) and restores it (restoreState); the undo manager just keeps the edit objects.
Pythoncopy.deepcopy, pickleBuilding blocks for snapshots; implement __getstate__/__setstate__ to control exactly what is captured.
C librarysetjmp / longjmp and jmp_bufAn opaque saved execution context.
Linux kernelstruct pt_regs on interrupt or syscall entry; per-task CPU state on context switchSave registers, run something else, restore and resume.
Checkpoint / restoreCRIU (user space), VM and container snapshotsFreeze a process or machine to an image and bring it back, possibly elsewhere.
DatabasesSAVEPOINT / ROLLBACK TO SAVEPOINTA named point inside a transaction to roll back to.
Network devicesConfiguration checkpoints and rollbackMany router operating systems keep previous committed configurations so an operator can roll back a bad change, the same idea as our C++ demo.
