Intent

Memento (GoF behavioral pattern, also called Token or Snapshot): let an object pack its private state into a sealed snapshot that others can keep but not open, and later hand the snapshot back so the object can roll itself back to that point.

The key idea is that the snapshot is sealed: privacy is kept. Copying state is easy; the pattern is about who is allowed to do it. The originator itself creates the snapshot and is the only one who can read it. Everyone else gets an opaque token they can store, pass around and hand back.
