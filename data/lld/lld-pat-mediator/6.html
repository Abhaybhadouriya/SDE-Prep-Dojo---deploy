Real-world uses

WhereMediatorColleagues
Linux kernelDriver core + struct bus_type (match, probe)Devices and drivers; neither looks the other up.
Swing (JDK)javax.swing.ButtonGroupRadio buttons: selecting one deselects the others, and the buttons do not know each other.
GUI frameworksA dialog or form controllerWidgets: "OK is enabled only when the email field is valid and the terms box is ticked".
.NETThe MediatR libraryRequest senders and handlers; senders send a request object to the mediator, which routes it to one handler.
KubernetesThe API serverControllers, the scheduler and kubelets never call each other; they read and write objects through the API server (control plane).
MicroservicesA saga orchestratorOrder, payment and inventory services; the orchestrator tells each what to do next (sagas and workflows).
Chat and gamesA chat server, a game room or match serverPlayers and clients; see the chat app HLD.

The last three are architecture-level cousins rather than the class-level GoF pattern, but the trade-off is identical: fewer links and one place for rules, in exchange for a central component that must stay healthy and must not grow without limit.
