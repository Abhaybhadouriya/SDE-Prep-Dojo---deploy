The problem: everyone knows everyone

A first attempt at an online auction lets bidders tell each other directly:

class Bidder {
    List<Bidder> others;          // every bidder holds every other bidder
    Bidder leader; long price;    // and a private copy of the auction state!

    void bid(long amount) {
        if (amount < price + 100) return;          // rule copied into each bidder
        Bidder old = leader;
        for (Bidder b : others) {
            b.leader = this; b.price = amount;     // poke other objects' fields
            if (b == old) b.notifyOutbid(this);
            else b.notifyPrice(amount);
        }
    }
}
  • Tight coupling. Each bidder depends on every other bidder. You cannot reuse Bidder in a different auction type without dragging the others along.
  • Rules spread out. The minimum increment, "who is leading" and "is the auction open" live in every bidder. Change the increment rule and you edit every copy.
  • State goes out of sync. Each bidder keeps its own price and leader. One missed update and two bidders disagree on who is winning.
  • Hard to test. To test one bid you must build a whole web of bidders.
