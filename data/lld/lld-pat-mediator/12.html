What problem does Mediator mainly solve?

  1. Creating objects without naming their classes
  2. Adding behaviour to an object at runtime
  3. Many-to-many direct references between cooperating objects
  4. Traversing a collection
It replaces the mesh of references with a star around one coordinator.

In a well-designed auction, a Bidder holds a reference to:

  1. Only the auction mediator
  2. Every other bidder
  3. The current leader
  4. Nothing at all
Colleagues know only the mediator; the mediator knows the colleagues.

Which statement best separates Mediator from Observer?

  1. Observer is creational, Mediator is structural
  2. Mediator cannot use callbacks
  3. Observer needs an interface, Mediator does not
  4. Observer broadcasts without coordinating; a Mediator owns the rules of how colleagues interact
Both are behavioral and both may use callbacks; the intent differs.

The most common way a Mediator goes wrong is:

  1. Too many interfaces
  2. It turns into a god object holding everyone's logic
  3. Colleagues become immutable
  4. It uses inheritance
Keep colleague behaviour in colleagues and split mediators by concern.

In the Linux driver model, what plays the mediator?

  1. The device
  2. The driver's probe() function
  3. The bus and driver core, using the bus's match()
  4. sysfs
Devices and drivers register with the bus; the core pairs them via match() and then calls probe().

Saga orchestration maps most closely to which pattern?

  1. Mediator
  2. Observer
  3. Iterator
  4. Memento
A central orchestrator coordinates services. Choreography (services reacting to events) is closer to Observer.
