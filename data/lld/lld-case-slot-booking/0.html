The story: the sign-up sheet on the clinic door

Explain like I'm 5

A doctor pins a sheet on her door. Each line is a 30-minute visit, and each line has room for one name. If your line is already taken, you can write your name on a small "waiting" list under it. If the person on the line crosses their name out, the first waiting name moves up, and someone runs to tell that person "you are in now". A yoga class works the same way, except each line has room for 20 names instead of one.

Two more rules: you cannot be on two lines at the same time (you cannot be in two rooms at once), and only one person may hold the pen at a time, so two people never both see an empty line and both write on it.

From your world

A slot is a counting semaphore with an exclusive wait queue. Capacity is the semaphore count; the waitlist is a wait_queue_head_t where waiters were added with the exclusive flag, so a release wakes exactly one of them instead of the whole herd. The difference from the kernel: our waiters are not sleeping threads, they are records, and "wake up" means "change status to CONFIRMED and send a message". The bounded waitlist is like a listen backlog: once it is full, new arrivals are refused at the door.

Interfaces in C terms: every interface on this page is, in C, a struct of function pointers; each implementation fills one in, like file_operations. Java and C++ build that table (the vtable) for you, and every object carries a pointer to it. More in OOP from C structs and polymorphism and vtables.
