Quiz

Why does Way 2 use two Conditions instead of one?

  1. Java requires two
  2. It makes the lock fair
  3. Producers and consumers wait on separate queues, so signal() always wakes the right kind of thread
  4. It avoids the need for a while loop
Separate wait queues mean a consumer's signal goes only to producers, so waking one is enough. The while loop is still required.

You have 3 consumer threads. How many poison pills do you put, and when?

  1. 3, after all producers have finished
  2. 1, immediately
  3. 3, before starting producers
  4. None, the JVM stops them at exit
Each consumer exits after eating one pill, and putting them before producers finish can strand later items.

What does offer(e, 50, MILLISECONDS) do on a full queue?

  1. Throws IllegalStateException at once
  2. Blocks forever
  3. Drops the oldest item
  4. Waits up to 50 ms for space, then returns false
The timed offer is the "time out and reject" backpressure policy.

What is the risk of new LinkedBlockingQueue<>() in a producer-consumer design?

  1. It is not thread-safe
  2. Its default capacity is Integer.MAX_VALUE, so overload grows memory instead of pushing back
  3. It cannot block
  4. It loses ordering
Without a capacity it is effectively unbounded. Always pass a bound.

When is a lock-free ring with just two atomic indexes correct?

  1. Any number of producers and consumers
  2. Only on x86
  3. Exactly one producer and one consumer, with release/acquire ordering on the indexes
  4. Only when the queue is unbounded
SPSC works because each index has a single writer. More writers need CAS or a lock.

Using wait/notify on one monitor with producers and consumers, what can notify() (instead of notifyAll()) cause?

  1. All threads asleep although progress was possible, because a consumer woke another consumer
  2. A compile error
  3. Data corruption in the array
  4. Nothing, it is always safe
With one shared wait set, notify may wake the wrong kind of thread. That waiter goes back to sleep, and nobody wakes the thread that could proceed.

A NIC with a full RX ring drops the packet and increments a counter. Which backpressure policy is that?

  1. Block the producer
  2. Drop newest
  3. Drop oldest
  4. Time out and retry
Hardware cannot wait, so it drops the arriving packet and counts it.
