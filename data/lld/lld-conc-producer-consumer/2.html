The design: one interface, three implementations

In an interview, start with the contract. A bounded buffer has a capacity, put blocks while it is full, and take blocks while it is empty. Everything else is an implementation detail behind that interface.

The storage inside both hand-written versions is a circular array (ring buffer): a fixed array plus three numbers. tail is where the next put writes, head is where the next take reads, and count is how many items are inside. Both indexes wrap around with modulo, so the array is reused forever with no allocation per item.
