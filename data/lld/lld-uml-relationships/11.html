Quiz

A Report class has a method render(Formatter f) and no field of type Formatter. Which relationship is it?

  1. Association
  2. Aggregation
  3. Dependency
  4. Realization
Formatter appears only as a parameter. Nothing is kept, so it is a dependency (dashed line, open arrow).

Where does the filled diamond go in "Invoice composes InvoiceLine"?

  1. At the InvoiceLine end
  2. At the Invoice end
  3. In the middle of the line
  4. Either end; it does not matter
Diamonds always sit at the whole (the container), here Invoice.

Which code shape best matches aggregation?

  1. lines.add(new Line()) inside the whole
  2. class Team extends Player
  3. A method parameter used once
  4. team.add(existingPlayer) where the player was created elsewhere
In aggregation the part is created elsewhere and passed in; the whole does not control its lifetime.

A dashed line with a hollow triangle pointing at Comparable means:

  1. The class implements the Comparable interface
  2. The class extends Comparable
  3. The class uses Comparable as a parameter
  4. The class owns a Comparable
Dashed + hollow triangle is realization: implementing an interface.

In C, which shape is closest to composition?

  1. A pointer field to a refcounted object
  2. A function taking a pointer argument
  3. A struct embedded by value inside another struct
  4. A static const ops table
An embedded struct lives in the outer struct's memory, so it cannot outlive it: composition. Pointer + refcount is aggregation; the ops table is realization.

A Student-Course link needs a grade per student per course. Best model?

  1. Put the grade field in Student
  2. Add an Enrollment class between them
  3. Make Course inherit from Student
  4. Put a list of grades in Course
The grade belongs to the pair, so promote the association to a class (an association class, like a join table).

"Customer 1 — 0..* Order". Which statement is true?

  1. Each order has zero or more customers
  2. Each customer has exactly one order
  3. It is a composition
  4. Each order has exactly one customer, and a customer can have none
Multiplicity is written next to the class being counted: 1 customer per order, 0..* orders per customer. A plain line is an association, not a composition.
