Resources

  • uml-diagrams.org: Association doc - multiplicity, navigability, ends; the most precise free reference.
  • uml-diagrams.org: Aggregation and Composition doc - the shared vs composite distinction with notation details.
  • uml-diagrams.org: Dependency, Generalization, Realization doc - the other three lines and their keywords («use», «create»).
  • OMG UML 2.5.1 specification paper - the official standard, for settling arguments.
  • SourceMaking: Class diagram blog - a gentle second explanation with examples.
  • Wikipedia: Class diagram doc - quick overview of all relationship notations.
  • Mermaid class diagram syntax and PlantUML class diagram doc - draw these as text in docs and PRs.
  • Linux kernel: kref doc - the refcount behind "aggregation" in C.
  • Martin Fowler: UML Distilled book - the classic short book on using just enough UML (book page only).
