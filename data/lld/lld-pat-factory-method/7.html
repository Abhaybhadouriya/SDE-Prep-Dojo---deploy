Real-world uses

WhereCreator / factory methodProduct
Java collectionsIterable.iterator(), overridden by ArrayList, HashSet, TreeMap.keySet()...an Iterator that knows that collection's internals; the for-each loop is the "workflow" that uses it
Java networkingURLStreamHandler.openConnection(URL), overridden per protocol handlera protocol-specific URLConnection
Java concurrencyThreadFactory.newThread(Runnable) injected into executorsa Thread with your name, priority or daemon flag (the function-object variant)
Python__iter__() on any iterablean iterator object; for loops call it for you
Python stdlibsocketserver servers create one handler per request from their RequestHandlerClassa request handler instance (you subclass the handler and pass the class)
SpringFactoryBean<T>.getObject()a bean whose creation logic the container should not hard-code
Django class-based viewsget_form_class() / get_queryset() overridden in a view subclassthe form or queryset the generic view's workflow then uses
Linux sockets (related, not pure)net_proto_family->create (inet_create, unix_create, ...)a family-specific socket; chosen by a registry keyed on the address family, so closer to a parameterised factory
Linux file systemssuper_operations->alloc_inode on each file systemthat file system's inode, which embeds the generic struct inode

The alloc_inode row is a good one to say aloud in a kernel-flavoured interview: the VFS runs a generic "create an inode" path and asks the file system to allocate its own bigger struct (for example ext4's inode info) that contains the generic one, found again with container_of.
