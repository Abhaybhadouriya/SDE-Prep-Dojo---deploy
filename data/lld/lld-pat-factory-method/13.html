  • Factory Method: the base class's workflow calls an overridable create...(); subclasses decide the concrete product.
  • Two parallel hierarchies: creators and products. The base creator talks only to the product interface.
  • It is a Template Method whose varying step creates an object.
  • Key words: key = Simple Factory, subclass = Factory Method, family = Abstract Factory.
  • Wins: Open/Closed and Dependency Inversion. Cost: more classes; use an injected supplier when only creation differs.
  • Never call a virtual factory method from a base constructor.
  • Kernel twin: super_operations->alloc_inode (fixed by the file system type). net_proto_family->create is a keyed registry, a cousin.
