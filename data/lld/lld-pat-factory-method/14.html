Quiz

In Factory Method, who decides which concrete product is created?

  1. The client, by passing a string key
  2. The creator subclass, by overriding the factory method
  3. A separate factory object that makes a family of products
Subclasses override the creation hook. A key is Simple Factory; a family object is Abstract Factory.

What does the base creator usually do with the product?

  1. Uses it in its own workflow through the product interface
  2. Returns it to the client immediately and does nothing else
  3. Casts it to the concrete class to call special methods
The creator has real work (send, audit) and needs a product to do it. Casting would bring back the dependency.

Which pattern is Factory Method a special case of, structurally?

  1. Observer
  2. Decorator
  3. Template Method
A fixed algorithm in the base with an overridable step; here the step creates an object.

Creators differ only in which channel they create. The cleanest way to cut the number of classes?

  1. Merge all channels into one class with a switch
  2. Inject a Supplier<Channel> (or lambda) into one Notifier
  3. Make every creator a Singleton
Composition over inheritance: pass the creation function; keep subclasses only when they override other steps too.

In C++, a base constructor calls the pure virtual createChannel(). What happens?

  1. Undefined behaviour; usually a "pure virtual call" abort
  2. It calls the subclass override as normal
  3. The compiler silently picks the first subclass
During base construction the dynamic type is the base, so the override is not reachable.

Which is a Factory Method in the Linux kernel?

  1. kmalloc(size, GFP_KERNEL)
  2. list_for_each_entry()
  3. super_operations->alloc_inode called by the VFS
The VFS runs the workflow and asks the file system, fixed by its type, to create its own inode. (net_proto_family->create is looked up by a key at call time, which makes it a registry.)

Which JDK method is a Factory Method (not a static factory)?

  1. Calendar.getInstance()
  2. Iterable.iterator()
  3. List.of(...)
Each collection overrides iterator() to return its own iterator. The other two are static creation methods.
