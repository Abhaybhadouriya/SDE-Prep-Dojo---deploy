Fragments: if, else, loops and early exits

Real flows branch. UML puts branches and loops in combined fragments: a rectangle around some messages with an operator in a little tab in the top-left corner and a guard in square brackets. Here are the five you need, shown on a cash-machine withdrawal:

OperatorMeaningCode equivalent
altChoose exactly one section whose guard is trueif / else if / else, switch
optRun the section only if the guard is trueif with no else
loopRepeat while the guard holds (can show bounds, e.g. loop(1,3))for, while, retry loop
breakRun this section and then leave the enclosing fragmentreturn / throw on an error path
parSections run in paralleltwo futures, then allOf(...).join()

Do not turn the diagram into a flowchart. If you need three nested alts, the diagram is trying to show an algorithm. Draw the happy path plus one or two important failure branches. Put the rest in code or in an activity diagram.
