From your world

Every ladder diagram in an RFC is a sequence diagram with two lifelines. The TCP three-way handshake (SYN, SYN-ACK, ACK), a DHCP DORA exchange, a TLS handshake, a BGP OPEN/KEEPALIVE exchange: hosts across the top, time flowing down, slanted arrows because the network takes time. Wireshark's "Flow Graph" draws exactly this from a capture.

On the code side, ftrace's function_graph tracer prints nested call trees with entry and exit: each nesting level is an activation bar, each } is a return arrow. A synchronous message is a direct call; an asynchronous one is queue_work(), schedule_work() or raising a softirq: you hand off and return at once, and the work runs later on another context.
