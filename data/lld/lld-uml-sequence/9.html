Quiz

Which arrow means "send and do not wait"?

  1. Solid line, filled head
  2. Solid line, open head
  3. Dashed line, open head
  4. A loop back onto the same lifeline
Open head on a solid line is an asynchronous message. Dashed is a reply; filled head is a synchronous call.

Which fragment matches an if with no else?

  1. alt
  2. loop
  3. opt
  4. par
opt runs its section only when its guard holds. alt picks one of several sections.

On a payment-failure path you release the seats and return an error, skipping the rest. Best fragment?

  1. break
  2. loop
  3. par
  4. opt followed by the rest
break runs its section and then leaves the enclosing interaction, like an early return or throw.

What does a long activation bar on :OrderService spanning a slow external call indicate?

  1. The service is idle
  2. The call is asynchronous
  3. The service was destroyed
  4. The service is busy (its thread is held) until the call returns
The bar covers the time the object is executing or waiting inside a call it made, which on a thread pool means a thread is tied up.

The TCP handshake in RFC ladder diagrams uses slanted arrows because:

  1. The messages are asynchronous replies
  2. Messages take time to cross the network
  3. They are self-calls
  4. They form a loop fragment
A slant shows the message arrives later than it was sent: network delay. In-process calls are drawn horizontal.

Your sequence diagram has :Checkout sending reserve() to :Inventory. What must your class design have?

  1. Inventory extends Checkout
  2. Nothing: diagrams are independent
  3. A reserve method on Inventory and a reference from Checkout to an Inventory (field or parameter)
  4. A composition from Inventory to Checkout
Each message needs a receiver method and a way for the sender to reach the receiver. That cross-check is why the two diagrams are drawn together.
