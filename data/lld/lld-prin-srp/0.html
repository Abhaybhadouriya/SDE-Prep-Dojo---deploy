The story: the one-person canteen

Explain like I'm 5

A small school canteen has one helper, Raju. Raju cooks the food, writes the bills, keeps the money box and tells parents when lunch fees are due. One day the principal says "bills must now show the tax". Raju stops cooking to fix the bill book, and lunch is late. Next week the menu changes, and Raju, rushing, writes the wrong prices on the bills. Everything Raju does is tangled together, so a change in one job spoils another job.

Then the canteen hires three people: a cook, a cashier and a messenger. Now a new tax rule only goes to the cashier. A new recipe only goes to the cook. Nobody else is disturbed. Each person has one boss to listen to. That is the whole idea of the Single Responsibility Principle.

In code, Raju is a class that does everything. Programmers call it a god class: a class that knows too much and does too much. The fix is not "make every class tiny". The fix is "make sure each class listens to only one boss".
