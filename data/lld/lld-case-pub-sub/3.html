Identify entities: nouns become classes, verbs become methods

Underline the nouns and verbs of the requirement list. Then merge, drop and rename. Click through.

  1. Start from the clarified statement, not from a memorised Kafka diagram.
  2. Nouns are candidate classes. Do not create all of them; this is a long list on purpose.
  3. Verbs are candidate methods. Each verb must end up on the class that owns the data it touches (Information Expert).
  4. Drop what has no behaviour of its own. A "Producer" class would only forward to the broker; an offset is a number; a DLQ is a topic with a naming rule.
  5. The final model: five core types and three small interfaces. Retry and partitioning are interfaces because the interviewer will ask to change them.
