APIs and interfaces

// Facade used by application code
Topic         createTopic(String name, int partitions);      // idempotent
Message       publish(String topic, String key, String value); // returns partition + offset
ConsumerGroup group(String topic, String groupId, RetryPolicy retry);

// Consumer group lifecycle
void join(String memberName, Subscriber s);   // before start()
void start();                                  // assign partitions, start workers
void seek(int partition, long offset);         // replay / skip
long lag();                                    // published - committed, all partitions
void stop();

// Extension points
interface Subscriber  { void onMessage(Message m) throws Exception; }   // Observer
interface Partitioner { int partitionFor(String key, int numPartitions); } // Strategy
interface RetryPolicy { int maxAttempts(); long backoffMs(int failedAttempt); } // Strategy

Design notes worth saying aloud: publish returns the stored Message, so the caller can log "u4 went to p1@2", which is what real Kafka's RecordMetadata gives you. onMessage may throw: an exception is the subscriber's way of saying "not processed", which is cleaner than a boolean everybody forgets to check.
