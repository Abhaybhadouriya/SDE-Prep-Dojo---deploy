Level 4: threads, testing and cost

  • Threads. An adapter is only as thread-safe as the adaptee behind it. If the legacy SDK is not thread-safe, the adapter must serialise calls or keep one client per thread.
  • Testing. Write one contract test suite for the target interface and run it against every adapter, so OldBank and Acme are proven to behave alike, including error mapping.
  • Cost. One translation per call (field mapping, maybe a copy). Usually noise next to a network call; it matters only for bulk data conversion.
