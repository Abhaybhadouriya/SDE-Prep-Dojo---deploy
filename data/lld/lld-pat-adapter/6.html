Real-world uses

WhereAdapterFrom to
JDKInputStreamReaderA byte stream (InputStream) seen as a character stream (Reader), decoding with a charset.
JDKArrays.asList(array)A plain array seen as a fixed-size List (writes go through to the array).
JDKCollections.enumeration()A live adapter: wraps a modern Collection and forwards to its iterator through the old Enumeration interface. (Collections.list(Enumeration) goes the other way but copies into a new ArrayList: a one-shot conversion, not an adapter. That difference is a nice interview point.)
Python stdlibio.TextIOWrapperA binary buffered stream seen as a text stream, as in our demo.
Linux kernelcompat_sys_* syscalls32-bit user ABI structs to native 64-bit kernel structs.
LoggingSLF4J bridge modules (for example jul-to-slf4j)Calls made to one logging API rerouted into another.
AndroidRecyclerView.AdapterYour data list to the views the list widget asks for.
PaymentsOne adapter per gatewayEvery multi-gateway checkout (cards, UPI, wallets) normalises each provider's SDK behind one internal interface. The provider names and fields differ; the adapter hides them.

A wider name for the same idea is an anti-corruption layer (from Domain-Driven Design): a boundary of adapters that keeps a foreign model (a partner's API, a legacy system) from leaking into your own domain model.
