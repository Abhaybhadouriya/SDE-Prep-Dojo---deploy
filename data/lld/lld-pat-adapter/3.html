Structure: four participants

  • Target (PaymentGateway): the interface the client is written against. You own it.
  • Client (Checkout): only ever calls Target methods.
  • Adaptee (OldBankSdk): the existing class with a useful but incompatible interface. You do not own it, or you cannot change it.
  • Adapter (OldBankAdapter): implements Target and translates each call into Adaptee calls. One adapter per adaptee.
