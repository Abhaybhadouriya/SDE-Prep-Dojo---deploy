Remember this

  • Adapter = convert an existing interface into the one the client expects. Neither side changes.
  • Participants: Target, Client, Adaptee, Adapter. One adapter per adaptee.
  • Prefer the object adapter (composition). Class adapter only to override adaptee hooks.
  • Translate names, data and results only; no business logic, no swallowed errors.
  • Write the Target in your own domain language, not the first vendor's.
  • Adapter changes the interface; Decorator and Proxy keep it; Facade simplifies many; Bridge is designed up front.
  • Kernel bridge: compat_sys_* wrappers adapt 32-bit ABI structs to native ones.
