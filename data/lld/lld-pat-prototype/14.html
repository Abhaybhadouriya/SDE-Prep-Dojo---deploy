Quiz

A layout is cloned with new SeatLayout(name, new ArrayList<>(seats)). Booking a seat in the clone...

  1. affects only the clone
  2. also marks the seat booked in the original, because the Seat objects are shared
  3. throws an exception
  4. is impossible
A new list with the same elements is a shallow copy. The Seat objects are shared, so their booked flag is shared.

Which field is safe to share (not copy) between a prototype and its clone?

  1. A List<Seat>
  2. A HashMap of prices that the show can change
  3. An open socket
  4. An immutable String screen name
Immutable objects can be shared freely. Mutable collections must be copied; resources must not be copied blindly.

What is the main benefit of a polymorphic clone() over a copy constructor?

  1. The caller can copy an object through a base-class reference without knowing its concrete class
  2. It is always faster
  3. It always makes a deep copy
  4. It avoids memory allocation
A copy constructor needs the concrete type at compile time; a virtual clone() dispatches to the right class at run time.

How does Python's copy.deepcopy handle an object that refers back to itself?

  1. It recurses forever
  2. It raises an error
  3. It keeps a memo dict from original to copy and reuses copies it has already made
  4. It makes a shallow copy instead
The memo dictionary maps the id of each original object to its copy, so cycles and shared references are preserved.

In clone(2), passing CLONE_VM means the child...

  1. gets a private deep copy of the parent's memory
  2. shares the parent's address space (like a thread): a shallow clone for memory
  3. gets no memory
  4. runs in a virtual machine
CLONE_VM shares the memory descriptor. Without it (as with fork()), memory is copied, lazily via copy-on-write.

Which pattern is the opposite idea: share one immutable instance instead of copying?

  1. Builder
  2. Memento
  3. Flyweight
  4. Abstract Factory
Flyweight shares intrinsic, immutable state among many users; Prototype duplicates so copies can change independently.
