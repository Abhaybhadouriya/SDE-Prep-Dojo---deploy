In interviews: where it shows up

Prototype is a tier 3 pattern in our research: rarely asked by name, but "shallow vs deep copy" is a common follow-up, and cloning is the clean answer in a few case studies.

Case studyWhere cloning helps
BookMyShowA screen's seat layout cloned for each show, exactly the example on this page.
IRCTC / Slot bookingCoach layout or daily slot template cloned per date.
ChessCopy the board to test a move for "does this leave my king in check?" without touching the real game.
Text editorDuplicate a styled block; copy-paste keeps formatting; snapshots for undo (with Memento).
File systemcp -r of a directory = deep clone of a composite tree.
Task tracker / Meeting schedulerRecurring tasks or meetings created from a template.

When you say "I'll copy the layout", immediately add "a deep copy of the seats, because seat status is per show". That single sentence shows you know the trap.
