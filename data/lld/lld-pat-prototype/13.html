Remember this

  • Prototype = make new objects by asking a configured object to copy itself, then tweak the copy.
  • Two wins: skip expensive setup, and copy without knowing the concrete class (virtual copy constructor).
  • A registry maps keys to prototypes and hands out clones.
  • Shallow copy shares inner objects; deep copy duplicates them. Share immutables, copy mutables, never blindly copy resources.
  • Cycles need an identity map (Python's deepcopy memo, LeetCode "Clone Graph").
  • In Java prefer copy constructors or copy factories over Cloneable; in Python use copy and dataclasses.replace.
  • From your world: fork() with copy-on-write, clone(2) flags, skb_clone vs skb_copy.
