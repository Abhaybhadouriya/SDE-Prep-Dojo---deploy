Creational patterns: how objects get made

Rows tagged (non-GoF) are common patterns that are not among the 23 in the Gang of Four book (5 creational, 7 structural, 11 behavioural). Name them as patterns, but do not call them GoF in an interview.

PatternIntent (one line)Signal in a problemCode shapeDo not use whenKernel look-alike
SingletonExactly one instance, reachable from anywhere"one config / registry / logger for the app"private ctor + holder class (a nested static class created on first use; the JVM class-init lock makes it thread-safe) or enumyou need test doubles or per-tenant copies; pass the object in insteadone global object made at boot, e.g. init_net
Simple Factory (non-GoF)One place turns a type name into an object"create vehicle by type from input"switch (type) or map of constructorsthere are only one or two types that never growa lookup table of create() functions by id
Factory MethodSubclass decides which class to create"each kind of X makes its own Y"abstract createY() overridden per subclassno subclass hierarchy exists; a map of constructors is simplereach address family's create hook builds its own socket type (inet_create(), unix_create())
Abstract FactoryCreate a family of objects that must match"themes", "per-platform widgets", "per-region rules"interface with createA(), createB()products do not have to match each othernet_proto_family.create wires matching proto_ops and proto into a socket
BuilderBuild a complex object step by step, validate once"many optional fields", "immutable once built"fluent setters + build() that validatestwo or three required fields; a constructor is clearerbuilding an sk_buff: alloc_skb, skb_reserve, skb_put, skb_push
PrototypeNew object by copying a configured one"clone this template", "copy is cheaper than build"copy() / copy constructorobjects are cheap to build or hold references that must not be sharedfork() duplicating the task; skb_clone()
Object Pool (non-GoF)Reuse expensive objects instead of creating new ones"connections", "workers", "buffers"acquire()/release() over a BlockingQueueobjects are cheap; pooling adds reset bugs and leaksslab caches, mempool_t
Dependency Injection (non-GoF)Give objects their collaborators from outside"swap storage", "test with fakes"constructor parameters typed as interfaces; wiring in maina tiny script with one implementation of everythingdrivers handing their ops tables to the core at register time
