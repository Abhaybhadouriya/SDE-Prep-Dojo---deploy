Quiz

"Users can pay by UPI, card or net banking, and more modes will come." Which pattern does this signal?

  1. State
  2. Composite
  3. Strategy
  4. Memento
An algorithm (how to pay) that varies by type and is chosen at run time: Strategy.

Stacked network devices (a VLAN device on a bond on a physical NIC) are closest to which pattern?

  1. Decorator
  2. Singleton
  3. Visitor
  4. Abstract Factory
Each layer has the same device interface, wraps the one below and adds behaviour.

On a UML class diagram, a dashed line with a hollow triangle means:

  1. Composition
  2. Dependency
  3. Inheritance
  4. Realisation (implements an interface)
Solid with a triangle is inheritance; dashed with a triangle is implementing an interface.

Which smell most directly points to an Open/Closed violation?

  1. A class with private fields
  2. The same switch on a type copied into several services
  3. A method with two parameters
  4. An immutable value object
Every new type forces edits in every copy of the switch. Polymorphism or Strategy closes them.

Many readers, rare writers, and the data is a small config map. Which tool is the simplest good fit?

  1. A Semaphore
  2. A global synchronized method around every read
  3. An immutable map in an AtomicReference, replaced on each write
  4. A CountDownLatch
Readers take the current snapshot with no lock; a writer builds a new map and swaps it. The kernel's RCU uses the same idea.

An object refuses "cancel" once an order is picked up, and the order moves itself to the next status. Which pattern fits?

  1. State
  2. Strategy
  3. Bridge
  4. Flyweight
Allowed actions depend on the current status and the states decide the next one.
