Structural patterns: how objects fit together

PatternIntent (one line)Signal in a problemCode shapeDo not use whenKernel look-alike
AdapterMake an existing interface fit the one you need"third-party SDK", "legacy API", "vendor returns paise"class implements your interface, calls theirsyou own both sides; change the interface insteadcompat_ioctl translating 32-bit calls
BridgeSplit two dimensions so each varies alone"N kinds x M channels" class explosionabstraction holds an implementation interfaceonly one dimension really variesfilesystems over block drivers via the block layer
CompositeTreat one item and a group the same way"folders and files", "nested menus", "expression tree"Node interface; group holds List<Node>there is no nesting; a flat list is enoughdevice model tree (struct device parents and children)
DecoratorAdd behaviour by wrapping, stackable"add-ons in any combination", "toppings", "compress then encrypt"wrapper implements X and holds an Xthe order of layers must be fixed or the add-ons interact; a pipeline or flags is clearerstacked net devices (VLAN over bond over NIC); dm-crypt over a disk
FacadeOne simple entry over a complex subsystem"placeOrder does inventory, payment, shipping"thin class calling several servicescallers need fine control of each subsystem stepsystem calls over many subsystems
FlyweightShare the heavy, unchanging part of many objects"millions of similar small objects"factory cache of shared immutable parts + extrinsic state (per-use data such as position, passed in on each call, never stored in the shared object)there are only a few objects, or the shared part is mutableKSM merging identical pages
ProxySame interface, controls access to the real object"lazy load", "cache", "check permission", "remote"wrapper that may not call the real objectthere is nothing to control; it is just an extra hopNFS client: local inode ops that talk to a remote server
Repository (non-GoF)Collection-like access that hides storage"in memory now, database later"save, findById on an interfacea one-off script with no storage swap in sightidr/xarray: look up an object by id
