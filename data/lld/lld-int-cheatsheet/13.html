Resources

  • refactoring.guru: design patterns catalogue doc - illustrated free reference for the GoF patterns; read it there, we only link to it.
  • SourceMaking: design patterns doc - the GoF patterns plus Object Pool, Null Object and Private Class Data.
  • Java Design Patterns (iluwatar) repo - open-source examples of over a hundred patterns, including concurrency ones.
  • Head First Design Patterns, 2nd ed. (official page) book - the friendliest book on the topic.
  • uml-diagrams.org: class diagrams doc - precise notation reference for every arrow and adornment.
  • java.util.concurrent package summary (Java 21) doc - official overview of executors, queues, synchronizers and concurrent collections.
  • On this site: patterns overview, patterns in the Linux kernel, LLD question bank, and the HLD cheat sheets.
