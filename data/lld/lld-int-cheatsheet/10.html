Thirty-second recipes

When askedSay (in this order)
"Which pattern?"What varies (quote the problem) → the pattern → why not the look-alike.
"Make it thread-safe"The invariant → the race → the lock and its scope → what stays lock-free.
"Add feature X"Which class is new → which one changes → which ones do not.
"Add a database"New repository implementation → one wiring line → transactions and locking move to the DB.
"Is this over-designed?"Agree where true → keep the seams the requirements justify → remove one now.
"Explain principle P"One line → a smell that breaks it → the refactor.
