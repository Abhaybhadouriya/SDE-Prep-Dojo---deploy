The story: the pocket card

Explain like I'm 5

A pilot knows how to fly, but before take-off they still read a small card: fuel, flaps, lights. The card does not teach flying. It just makes sure nothing is forgotten when it matters.

This page is that card for design interviews. You learnt each pattern and principle on its own page. Here they sit side by side, so in the last hour before an interview you can check that every name still brings up a picture, an example and a "when not to".

From your world

Most patterns already live in the kernel tree. The last column of each pattern table names a kernel structure that does the same job. If an interviewer asks "where have you seen this?", that column is your answer; the patterns in the kernel page tells each story in full.

How to use it: cover the "intent" column and say it from the pattern name, then cover the name and guess it from the "signal" column. Five minutes per table.
