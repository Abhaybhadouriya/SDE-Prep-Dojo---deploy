APIs and interfaces

enum IssueType   { PAYMENT, MUTUAL_FUND, GOLD, INSURANCE }
enum IssueStatus { OPEN, WAITING, IN_PROGRESS, RESOLVED;  boolean canMoveTo(IssueStatus next); }

interface AssignmentStrategy {
    Optional<Agent> pick(Issue issue, List<Agent> experts);   // experts already filtered by type
}

final class IssueService {
    IssueService(AssignmentStrategy strategy);
    Issue  createIssue(String txnId, IssueType type, String subject, String desc, String email);
    Agent  addAgent(String email, String name, List<IssueType> expertise);
    Optional<String> assignIssue(String issueId);              // empty = no expert, stays OPEN
    List<Issue> getIssues(Predicate<Issue> filter);           // IssueFilters.byEmail(..).and(..)
    void   updateIssue(String issueId, IssueStatus status, String resolution);
    void   resolveIssue(String issueId, String resolution);
    Map<String, List<String>> viewAgentsWorkHistory();        // agent id -> resolved issue ids
}

The statement's getIssues({"email": "..."}) takes a map. If you want to match it literally, add a two-line adapter that turns {"email": x, "type": y} into byEmail(x).and(byType(y)). Keep the predicate version as the real API: it is type-checked and composes. Errors are one unchecked IssueException with a clear message; the driver prints and continues.
