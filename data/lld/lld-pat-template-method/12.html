Remember this

  • Template Method = a final skeleton method in a base class that calls steps subclasses fill in.
  • Abstract steps must be implemented; hooks have defaults and are optional.
  • Make the skeleton final (C++: non-virtual, the NVI idiom) so the order cannot be broken.
  • Hollywood principle: the base class calls the subclass, not the other way round.
  • Real uses: AbstractList, InputStream, HttpServlet, AQS, unittest.TestCase, Mapping.
  • vs Strategy: inheritance and fixed at creation vs composition and swappable at runtime.
  • Kernel: generic function + ops table at fixed points (page-cache reads, driver probe).
