Resources

  • LeetCode Discuss: LLD topics and design patterns roadmap (2024-07-06) blog - a community list of practice problems next to the patterns worth knowing.
  • refactoring.guru pattern catalogue doc - clear free reference for the GoF patterns with diagrams. Read it there; we only link to it.
  • ashishps1/awesome-low-level-design repo - a large open list of LLD problems, concepts and resources.
  • iluwatar/java-design-patterns repo - over a hundred patterns in Java, including concurrency patterns like thread pool and producer-consumer.
  • ByteByteGo: Object-Oriented Design Interview (official course page) course - the public table of contents is a good checklist of case studies; the content is paid and not used here.
  • HelloInterview: Low-Level Design course - free hub covering the round format, evaluation and concurrency basics.
  • The Little Book of Semaphores (free PDF from its publisher) book - classic synchronisation puzzles, the best practice for concurrency cards.
  • Java Language Specification, chapter 17: Threads and Locks doc - the official memory model behind the volatile and happens-before answers.
  • On this site: patterns and principles cheat sheet, recent LLD interview reports, mock LLD interviews, machine-coding code layout, look-alike patterns, and the HLD system design question bank.
