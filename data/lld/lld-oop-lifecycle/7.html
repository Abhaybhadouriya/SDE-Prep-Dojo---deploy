Remember this

  • A constructor's job is to make the object valid or throw. One full constructor holds the checks; others delegate with this(...).
  • Private constructor + static factory gives names, validation and caching; it is the seed of Factory, Builder and Singleton.
  • Java order: zeroed memory, super() chain, field initializers, body. Do not call overridable methods in constructors.
  • C++ destructors run at scope exit in reverse order: RAII. Java has no destructors: use AutoCloseable + try-with-resources; finalize() is deprecated for removal.
  • Shallow copy shares inner objects, deep copy duplicates mutable ones. In Java prefer copy constructors over clone().
  • C++: rule of three/five if you own a raw resource; rule of zero for everything else.
