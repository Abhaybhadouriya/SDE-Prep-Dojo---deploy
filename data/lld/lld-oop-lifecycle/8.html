Quiz

In Java, new Port(1) where Port extends Base. What prints first?

  1. Port's field initializer
  2. Port's constructor body
  3. Base's constructor body
super() runs first in the constructor that does not delegate with this(...); field initializers run only after it returns.

Inside try (A a = ...; B b = ...) the body throws. Which close order does Java use?

  1. A then B
  2. B then A
  3. Unspecified
Resources are closed in reverse order of opening, like C++ destructors in a scope.

A C++ class has a raw owning pointer and a custom destructor only. What happens on PacketBuf b = a; and scope exit?

  1. Double free: both destructors delete the same block
  2. A deep copy is made automatically
  3. Compile error
The generated copy constructor copies the pointer value. Rule of three: you need a copy constructor and copy assignment too.

Best way to give a class correct copy, move and destroy behaviour in modern C++?

  1. Always write all five special members
  2. Write only the destructor
  3. Hold resources in vector / unique_ptr members and write none (rule of zero)
Members that manage themselves make the generated special members correct.

copy.copy(t) in Python, then t.routes.append(x). What does the copy see?

  1. The old list without x
  2. The list with x
  3. An error
copy.copy is shallow: both objects reference the same list.

Why is finalize() not a replacement for close()?

  1. It may run late or never, in no particular order
  2. It runs too early, before the object is used
  3. It cannot access fields
GC timing is not deterministic; finalization is deprecated for removal by JEP 421.

Why mark a C++ move constructor noexcept?

  1. It makes the move faster at run time
  2. So containers like std::vector use it when they grow instead of copying
  3. The compiler requires it
vector moves elements on reallocation only if the move cannot throw, to keep its strong exception guarantee.
