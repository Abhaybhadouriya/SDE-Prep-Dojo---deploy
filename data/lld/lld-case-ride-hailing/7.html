APIs and interfaces

interface DriverMatchingStrategy { List<Driver> rank(List<Driver> candidates, Location pickup); }
interface FareStrategy           { long fare(CabType cab, double km, long minutes); }   // paise
interface TripListener           { void onChange(Trip t, TripStatus from, TripStatus to); }

// RideService (facade)
void addRider(String id, String name);
void addDriver(String id, String name, CabType cab, Location at, double rating);
void updateLocation(String driverId, Location at);
boolean goOffline(String driverId);            // only if AVAILABLE
Trip requestRide(String riderId, Location pickup, Location drop, CabType cab);   // throws NoDriverAvailableException
void startTrip(String tripId);
long endTrip(String tripId, long minutes);      // returns fare in paise
void cancelTrip(String tripId);                 // only before IN_PROGRESS
void setMatcher(DriverMatchingStrategy m);  void setFareRule(FareStrategy f);

Note what the strategy returns: a ranked list, not one driver. The service needs a fallback when the first choice is taken by another thread a moment earlier. A strategy that returns a single driver forces either a global lock or a retry loop around the strategy.
