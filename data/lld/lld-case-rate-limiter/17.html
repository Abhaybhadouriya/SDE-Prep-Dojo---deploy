  • Five algorithms, one interface: tryAcquire(now). Token bucket for bursts, leaky for smoothness, fixed window for cheap quotas, sliding log for strict small limits, sliding counter for large limits.
  • Strategy (algorithms) + Factory (rule to object) + Composite (combined limits) + Facade (allow).
  • Inject the clock; pass now in; test with a manual clock and no sleeps.
  • Thread safety = atomic key creation (computeIfAbsent) + per-limiter lock. No global lock, no nested locks.
  • Composite rolls back earlier permits; worst case is under-admission, never over-admission.
  • Follow-ups: per-API rules, combined rules, tiers, Retry-After, eviction of idle keys, Redis for many servers.
