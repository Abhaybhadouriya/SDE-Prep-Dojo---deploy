Quiz

A fixed window limiter allows 100 requests per minute. What is the most a client can send in any 2-second span?

  1. 100
  2. 200
  3. 101
100 at the end of one window and 100 at the start of the next: 200 within a couple of seconds. This is the edge-burst problem.

Which algorithm needs memory that grows with the limit itself?

  1. Token bucket
  2. Sliding window counter
  3. Sliding window log
The log keeps one timestamp per accepted request in the window, so up to limit entries per key.

Why does the service use computeIfAbsent instead of get followed by put?

  1. So two threads racing on a new key cannot create two limiters
  2. Because it is faster for existing keys
  3. Because HashMap does not have put
Check-then-act is a race. computeIfAbsent on a ConcurrentHashMap runs the factory at most once per key, atomically.

A request passes the per-API limiter and then fails the group limiter. What must the composite do?

  1. Nothing; the request is rejected anyway
  2. Roll back the permit the per-API limiter took
  3. Retry the group limiter until it passes
Otherwise a rejected request still uses quota on the per-API limit.

Sliding counter, limit 10 per second. Previous window had 8 requests; we are 25% into the current window, which has 3. Allowed?

  1. No, because 8 + 3 = 11
  2. No, because 3 + 8 x 0.25 + 1 = 6
  3. Yes, because 8 x 0.75 + 3 + 1 = 10 <= 10
The previous window still covers 75% of the sliding window: 6 + 3 = 9, plus this request = 10, which is within the limit.

Which pattern lets you add a GCRA algorithm without editing the service?

  1. Strategy (behind the Limiter interface), created by the factory
  2. Singleton
  3. Observer
The service depends only on the Limiter interface; GCRA is a new implementation plus one factory case.

Which kernel facility is a fixed-window limiter?

  1. tc tbf
  2. printk_ratelimited() / struct ratelimit_state
  3. The iptables hashlimit match
ratelimit_state allows burst messages per interval and then resets: a fixed window. tbf and hashlimit are token buckets.
