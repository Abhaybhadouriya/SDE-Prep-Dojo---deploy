Quiz

8 threads each run chm.put(k, chm.get(k) + 1) 1,000 times on a ConcurrentHashMap. The final value is:

  1. Always 8,000
  2. Always less than 8,000
  3. 8,000 or less: updates can be lost
  4. An exception
Each call is atomic, but the get-add-put sequence is not. Use merge(k, 1, Integer::sum).

What does a failed compareAndSet(5, 6) tell you?

  1. The value was no longer 5, and nothing was written
  2. The value is now 6
  3. Another thread holds a lock
  4. The CPU does not support CAS
CAS writes only if the current value equals the expected one. On failure, re-read and retry.

Which is the wrong use of LongAdder?

  1. Counting HTTP requests
  2. Counting cache hits
  3. Bytes sent, scraped every 15 s
  4. Generating unique order numbers
LongAdder cannot return a unique value per increment, and sum() is not a snapshot. Use AtomicLong.incrementAndGet().

Why does ConcurrentHashMap reject null values?

  1. To save memory
  2. So that get() returning null always means "absent"
  3. Nulls break hashing
  4. For Hashtable compatibility only
In a concurrent map you cannot safely follow get() with containsKey() to resolve the ambiguity.

The ABA problem is mainly a risk when:

  1. Using synchronized blocks
  2. Reading a volatile field
  3. A CAS target can change and return to an old value, such as reused nodes
  4. Using LongAdder
CAS compares values, not history. Reused memory or recycled states make "same value" lie.

An event bus has 20 listeners, changed once a day, notified 10,000 times a second. Best list?

  1. CopyOnWriteArrayList
  2. Collections.synchronizedList(new ArrayList())
  3. ConcurrentLinkedQueue
  4. LinkedList
Read-mostly and iterated constantly: COW gives lock-free snapshot iteration. Writes are rare, so copying is cheap overall.

Inside map.compute(a, ...) you call map.put(b, ...) on the same ConcurrentHashMap. What can happen?

  1. Nothing special
  2. Deadlock, or IllegalStateException "Recursive update"
  3. The put is ignored
  4. Both keys update atomically together
The function runs while holding a's bin. Touching other keys of the same map is forbidden by the contract.
