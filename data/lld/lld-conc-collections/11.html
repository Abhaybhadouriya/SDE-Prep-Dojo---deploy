Remember this

  • Thread-safe calls do not make a thread-safe sequence of calls. get then put loses updates even on a ConcurrentHashMap.
  • Use merge, compute, computeIfAbsent for atomic per-key updates. Keep the function short, and never touch other keys inside it.
  • CAS = read, compute, publish if unchanged, else retry. Lock-free, but it contends on one cache line.
  • LongAdder = per-CPU counter: fast writes, approximate sum(). Use AtomicLong for IDs and decisions.
  • ABA: CAS cannot see A → B → A. Fix with a version stamp or safe reclamation. GC hides most of it in Java.
  • CHM: lock-free reads, CAS into empty bins, a per-bin lock on collision, tree bins at 8, no nulls, weakly consistent iterators.
  • CopyOnWrite for read-mostly lists (listeners), SkipListMap for sorted concurrent data, BlockingQueue when threads should wait.
  • Several fields that change together: one immutable object behind an AtomicReference, or a lock.
