Real-world uses

WhereExampleWhat is single
JDKRuntime.getRuntime()One Runtime per JVM: memory figures, availableProcessors(), shutdown hooks.
PythonNone, True, False, EllipsisExactly one object each, which is why x is None works.
Pythonlogging.getLogger("pay")One logger per name. That variant is called a multiton: a registry with one instance per key.
Linux kernelinit_net, init_taskThe initial network namespace and the first task: named global objects everyone links against.
Linux kernel"singleton ops" tablesLWN's article on kernel OO patterns describes ops tables whose methods drop the object pointer because only one instance can exist.
SpringDefault bean scope "singleton"One bean per container, created by the framework and injected. Same "only one", no global access point, so it stays testable.

The Spring row is the modern lesson: most production code keeps the "only one" part and drops the "global getInstance()" part. The container (or your main) creates one object and passes it to whoever needs it. See Dependency Injection.
