Compared withSame ideaThe difference
Static class (all static methods)Global access, no newA singleton is a real object: it can implement an interface, be passed as a parameter, be lazily built, and hold state with a lifetime. A static utility class cannot be swapped or mocked at all.
Global variableOne shared valueA singleton controls creation (private constructor, lazy, thread-safe). A global just exists. Both share the hidden-coupling problem.
Multiton / registryControlled instancesOne instance per key (logging.getLogger(name), one pool per database).
Monostate / BorgEveryone shares stateMany objects, but all fields are static or shared, so they behave as one. Python's "Borg" shares __dict__.
Abstract Factory, Builder, FacadeOften only one neededThese are frequently implemented as singletons. Singleton is a lifetime choice layered on top of them.
Dependency InjectionOne shared instanceDI keeps "one" but makes the dependency explicit and replaceable. The modern replacement for most singletons.
