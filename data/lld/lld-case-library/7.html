APIs and interfaces

// facade
void         addBook(Book b);
void         addCopy(String barcode, String isbn, String rack);
void         addMember(Member m);
List<String> search(String query);                 // title, author or subject; shows free/total
Loan         borrow(String memberId, String isbn);  // throws LibraryException(reason)
long         returnCopy(String barcode);            // returns the fine in paise
int          reserve(String memberId, String isbn); // returns queue position
void         renew(String barcode);
int          expireHolds();                         // daily job
void         payDues(String memberId, long paise);
void         subscribe(AvailabilityListener l);

// extension points
interface FineStrategy         { long fine(long daysLate); }
interface AvailabilityListener { void onHold(Member m, Book b, LocalDate holdUntil); }

Borrow takes an isbn, not a barcode, because members ask for a book; the service chooses the copy. Return takes a barcode, because the librarian scans the physical copy. Getting that asymmetry right is a small detail that interviewers notice.
