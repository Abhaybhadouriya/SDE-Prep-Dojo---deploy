Quiz

Which pattern lets you add a "write to Kafka" option without editing the formatter classes?

  1. Singleton
  2. Strategy (a new LogSink implementation)
  3. Template Method
The sink is a strategy behind an interface. A new sink class plugs in; formatters and handlers are untouched.

Why is AsyncSink a Decorator?

  1. It creates sinks
  2. It decides which sink handles a message
  3. It has the same interface as the sink it wraps and adds behaviour (background writing)
Same interface, wraps one object, always forwards: that is Decorator.

The async queue is full and the sink is DEBUG output. Best default?

  1. Drop the line and count it
  2. Block the caller until there is room
  3. Throw an exception to the caller
Debug logs must never slow or break business code. Drop, count, and report the count.

How does the logger read the current config without a lock?

  1. It copies the config on every call
  2. The config is immutable and published through a volatile reference
  3. It uses synchronized on the logger
An immutable object behind a volatile field is safely published; readers just read the reference.

What guarantees that lines queued before shutdown are written?

  1. Daemon threads
  2. Calling interrupt() on the writer
  3. A poison pill queued after them, then joining the writer thread
The queue is FIFO, so the pill is taken only after every earlier line has been written.

The kernel has one global console_loglevel. Which part of our design does that comparison match most closely?

  1. A level check applied to every console at once, like a single root threshold; our per-handler thresholds are finer-grained (each sink can have its own)
  2. The formatter
  3. The async queue
Classic printk compares each message with one global console_loglevel and applies the answer to all registered consoles, so it is one threshold for all sinks. Our design gives every handler its own threshold, which is finer-grained: the alert sink can take only ERROR while the file takes INFO. The ring buffer still keeps everything, whatever the level.
