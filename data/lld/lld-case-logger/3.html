Identify entities: nouns, verbs, and what varies

Take the requirement sentence and mine it. Nouns become classes, verbs become methods, and the things that "can be one of many" become interfaces.

  1. Underline the nouns. Each one that holds data or identity becomes a class. "Message with a level" becomes an immutable LogMessage plus a LogLevel enum.
  2. Circle the verbs. Each one becomes a method on the class that owns the data it needs (that is the "Information Expert" rule from GRASP, a short list of rules for deciding which class gets which job: give a method to the class that already holds the data it needs).
  3. Ask "how many kinds of this will there be?". Sinks and formats have many kinds and will grow, so each gets an interface. A handler ties one threshold, one formatter and one sink together and links to the next handler.
  4. Split the core (stable, small) from the plug-ins (grow forever). Interfaces go on the boundary between the two. This is the sentence to say to the interviewer.
