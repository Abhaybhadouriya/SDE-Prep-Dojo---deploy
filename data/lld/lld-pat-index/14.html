Resources

  • Design Patterns catalogue (refactoring.guru) doc - the best free illustrated reference; one page per pattern with code in many languages.
  • Design Patterns (the GoF book) - Wikipedia doc - the 23 patterns, categories and the book's two core principles.
  • Head First Design Patterns, 2nd ed. (official page) book - the friendliest teaching order; starts with Strategy.
  • sourcemaking: design patterns doc - intents, checklists and "rules of thumb" comparing patterns.
  • iluwatar/java-design-patterns repo - runnable Java for almost every pattern.
  • faif/python-patterns repo - idiomatic Python versions.
  • RefactoringGuru/design-patterns-cpp repo - C++ examples to read alongside the site.
  • LWN: Object-oriented design patterns in the kernel blog - how C vtables express the same ideas.
  • awesome-low-level-design repo - pattern notes plus LLD problems.
  • AlgoMaster LLD: design patterns course - an LLD-focused pattern track.
  • Hello Interview: LLD in a hurry course - how LLD rounds are judged, including when not to force patterns.
  • LeetCode Discuss: LLD topics and design patterns blog - community roadmap of what to study.
  • LeetCode Discuss: splitting a 1-hour LLD round blog - an ATM round using State and Chain of Responsibility.
