Quiz

How many patterns are in the original GoF book?

  1. 22
  2. 26
  3. 23
23: 5 creational, 7 structural, 11 behavioral. Some sites show 22 because they drop Interpreter.

"Pricing has flat, hourly and weekend plans, and more will come." Which pattern?

  1. Strategy
  2. Singleton
  3. Composite
An algorithm that varies and is chosen per lot or per ticket: Strategy.

"A machine behaves differently when idle, holding money or dispensing, and moves between these by itself." Which pattern?

  1. Observer
  2. State
  3. Builder
Behaviour depends on internal mode and the modes drive their own transitions: State.

Which family does Decorator belong to?

  1. Creational
  2. Behavioral
  3. Structural
Decorator wraps an object to add behaviour - it is about how objects are composed.

"Add undo and redo to the editor." Which pair fits best?

  1. Command + Memento
  2. Adapter + Facade
  3. Singleton + Prototype
Commands record operations (and their inverse); mementos snapshot state to restore.

Which is the best reason to add a pattern in an interview design?

  1. It shows you know many patterns
  2. A stated requirement needs that kind of change isolated
  3. The interviewer mentioned it once
Patterns must be justified by requirements; forcing them in is a common negative signal.

Linux netfilter hooks that each return accept, drop or stolen are closest to which pattern?

  1. Prototype
  2. Flyweight
  3. Chain of Responsibility
Handlers in order; each can pass the packet on or stop it.
