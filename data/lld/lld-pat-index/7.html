Level 4: threads, testing and cost

  • Threads. A pattern does not make code thread-safe. The shared mutable parts are the danger: a listener list that changes while events fire (copy it before notifying, or use a copy-on-write list, the user-space cousin of RCU), a strategy object with fields. Stateless strategies and factories are safe to share.
  • Testing. Most patterns exist to create a seam: inject a fake strategy, register a recording observer, hand the code a fake factory. If a design is hard to test, a missing seam is usually the reason.
  • Cost. Each layer is roughly one indirect call (an ops-table call, a few nanoseconds) and sometimes one extra object. That only matters in a hot loop; measure before you remove a pattern for speed.
