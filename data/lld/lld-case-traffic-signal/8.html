APIs and interfaces

interface TimingStrategy {                  // how long a phase stays green
    int greenSeconds(Phase p, Map<Direction, Integer> queues);
}

interface ControllerState {                 // what the controller is doing; defaults are safe
    String name();
    default void enter(Controller c) {}
    default void tick(Controller c) {}
    default void emergency(Controller c, Direction d) { c.queueEmergency(d); }
    default void emergencyCleared(Controller c) { /* ignore */ }
    default void fault(Controller c) { c.setState(new FlashingState()); }
    default void repair(Controller c) { /* ignore */ }
}

interface SignalListener { void onChange(int time, Direction d, Light l); }

// Controller: what the clock, sensors, buttons and receiver call (all synchronized)
void start(); void tick(int seconds);
void arrive(Direction d, int cars);         // loop detector / camera count
void requestWalk(String phase);             // pedestrian button
void emergency(Direction d); void emergencyCleared();
void fault(); void repair();
void setTiming(TimingStrategy t);           // takes effect at the next green

The hardware edge is thin: a lamp driver is a SignalListener that switches real lamps on onChange; a loop detector calls arrive. Nothing in the states knows about hardware.
