The state machine

There are two levels of state. Each signal has a tiny fixed cycle (RED to GREEN to YELLOW to RED, plus FLASHING), enforced by TrafficSignal.set, which throws on anything else. The controller has the interesting modes, drawn here.

Each column becomes one class. The defaults ("queue the emergency", "ignore clear", "fault means flash", "ignore repair") live in the interface, so most states override only one or two methods. Note what is missing: there is no arrow from GREEN to another phase's GREEN, so the code cannot skip the clearance even in an emergency.
