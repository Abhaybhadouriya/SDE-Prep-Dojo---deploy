Intent

Command (GoF behavioral pattern): package an action, with everything it needs, into an object that has one method to run it. Because the action is now a value, you can hand it to a button, put it in a queue, write it to a log, run it later, or keep it on a stack to undo it.

In plain words: a command is a verb turned into a noun. "Insert 'hello' at 0" becomes an object of class InsertText with fields pos = 0 and s = "hello", and one method, execute(). Because it is an object, it can sit in a list, a queue, a log file or an undo stack.
