Related and confused-with patterns

Compared withLooks similar becauseThe difference
StrategyBoth wrap behaviour in an object with one methodStrategy answers how to do one job (which pricing algorithm), chosen by the context. Command answers what to do (and when, and can it be undone), carried by an invoker that does not care what it is.
MementoBoth are used for undoCommand stores the operation and reverses it; Memento stores a snapshot and restores it. Commands are smaller; mementos are simpler for complex state.
CompositeMacrosA macro command is a Composite of commands: one execute() runs all children, one undo() reverses them in reverse order.
Chain of ResponsibilityBoth pass requests around as objectsCoR is about who handles a request (walk a chain until someone does). Command is about turning the request into an object at all. A command object is often the thing that travels down a chain.
ObserverCallbacksAn observer callback reacts to an event that already happened; a command is a request to make something happen.
