Remember this

  • LSP: code written for a base type must work unchanged with every subtype. It is about behaviour, not just signatures.
  • Ask "can it keep every promise of the base?", not "is it a kind of the base in real life?".
  • Rectangle/Square: a mutable Rectangle promises independent sides. Fix with sibling types under Shape or immutable values.
  • Bird/Penguin: the base promised too much. Split into Bird and FlyingBird; the compiler then rejects penguins.
  • Rules: preconditions may only get weaker, postconditions only stronger, invariants and the history constraint must hold, and no new exception kinds.
  • Smells: instanceof in clients, overrides that throw "not supported" or do nothing. Cure: contract tests, composition, narrower interfaces.
  • Kernel: every file_operations implementation must honour the same read() contract (byte count, 0 for EOF, -errno, -EAGAIN).
