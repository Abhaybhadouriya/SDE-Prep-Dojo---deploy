Step 4 - APIs (3-5 min)

Write the public methods of the orchestrator as signatures, with what they return and how they fail. This is the contract every caller (and every test) will use. Keep it small:

Booking book(String organizer, Interval slot, int attendees)   // throws NoRoomAvailableException
void    cancel(int bookingId)                                  // throws NoSuchElementException
void    addRoom(Room room)
void    setStrategy(RoomSelectionStrategy strategy)

Return types matter. Returning a Booking object (not a room id string) means callers get the id they need for cancel(). Throwing a named exception (not returning null) means callers cannot forget to check. A sequence diagram of the main call shows the API and the collaboration in one picture:
