  • Eight steps, in order: clarify, entities, class diagram, APIs, patterns, code, extensibility, concurrency.
  • Budget for 55 minutes: 5 / 4 / 9 / 4 / 4 / 13 / 5 / 5, plus a buffer. Code gets the biggest block.
  • Write P0, P1 and out-of-scope lists and read them back.
  • Nouns with state or rules become classes; data rules live in the entity that owns the data; workflow lives in the orchestrator.
  • Patterns come from change points. One varying rule, one pattern.
  • Check-then-act is the classic race: lock the check and the act together, with the narrowest correct scope.
  • Machine coding: 15 plan + 90 code (P0 runs by minute 60) + 15 demo.
