The 8 steps and their minute budgets

We merged the frameworks taught by ByteByteGo, Hello Interview, AlgoMaster, Coding Shuttle and workat.tech into one list. The minutes are for a 45-60 minute round where design is the whole slot. If the slot is shared (Amazon often spends 20-25 minutes on Leadership Principle questions first), shrink each step proportionally but keep the order.

#StepMinutesOutput on the board / in the editorFailure it prevents
1Clarify5P0 list, P1 list, out-of-scope list, the concurrency/scale answerSolving the wrong problem
2Entities3-5Nouns as classes, enums, value objects (small immutable values with behaviour, e.g. Interval); verbs as methodsMissing a concept; one giant class
3Class diagram8-10Boxes with key fields and methods, relationships, multiplicitiesUnclear ownership of rules
4APIs3-5Public methods of the orchestrator (the one service class callers talk to, e.g. BookingService)Callers poking at internals
5Patterns3-5Interfaces at the change points, named (Strategy, State, Observer...)Hard-coded variation; forced patterns
6Code10-15Core flow and edge cases; in machine coding, runnable with a driverPretty diagram, no working logic
7Extensibility5"Add X" answered by adding a class, not editing old onesRewrite on the first follow-up
8Concurrency5Where the race is, which lock or atomic, why that scopeDouble booking, lost updates

Interviewers love hearing the plan out loud in the first minute: "I'll spend five minutes on requirements, then sketch the classes, then code the booking path, then we can talk about extensions and concurrency." It shows control of time, and it invites the interviewer to redirect early if they want something else.
