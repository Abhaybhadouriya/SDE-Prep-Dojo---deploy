Java and Python print the same hash codes (XKOaYAw, then TMcFmKs) because both use SHA-256 of url#attempt. The C++ standard library has no SHA-256, so the C++ version uses FNV-1a and prints different codes; the collision logic is identical. Python shows 4 clicks for 4c92 where Java shows 5 because the Java demo calls resolve twice in its print line.
