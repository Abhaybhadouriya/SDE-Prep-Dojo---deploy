Identify the entities (nouns and verbs)

  1. Write the problem in two sentences and confirm them.
  2. Nouns: user, long URL, short code, alias, expiry, click, owner, link.
  3. Verbs: shorten, generate, save, resolve, expire, count, delete. "Generate" is where the interviewer will push, so it gets an interface.
  4. Some nouns are fields. An alias is just a code chosen by the user (plus a custom flag); expiry is a timestamp; owner is a string id.
  5. Add the classes that the verbs need: a generator strategy, a repository with an atomic save, a validator, an injected clock, and a listener for analytics. The service ties them together.

The Amazon candidate's URLManager is a god-class trap: it ends up validating, generating, storing, expiring and counting. Name classes after one job each. "Manager" is a smell unless it is a facade that only delegates, which is what our UrlShortener is.
