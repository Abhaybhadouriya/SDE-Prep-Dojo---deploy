Remember this

  • Class = blueprint (fields, methods, constructors, statics). Object = one instance with its own field values.
  • Java: locals and references on the stack, every new object on the heap, statics once per class. C++: you choose stack, heap or static.
  • A reference is a safe pointer: no arithmetic, no dangling, can be null. A C++ reference cannot be null or re-pointed.
  • Java passes everything by value; for objects, the value is the reference. Mutate yes, re-point the caller no.
  • == is identity, equals is meaning. Override equals and hashCode together, from immutable fields.
  • Entities compare by id; value objects compare by all fields and should be immutable.
  • Make "nothing" explicit: requireNonNull, Optional returns, empty collections, Null Object.
  • GC frees unreachable objects; leaks are objects kept reachable by mistake.
