Resources

  • LeetCode concurrency problem set course - the problems on this page (some are premium).
  • The Little Book of Semaphores (Allen B. Downey) book - free, legal download from the author; dozens of classic synchronisation puzzles with hints.
  • java.util.concurrent (Java 21 API) doc - Semaphore, CountDownLatch, CyclicBarrier, Phaser, executors.
  • cppreference: concurrency support library doc - std::mutex, std::condition_variable, std::lock; which types arrived in C++20.
  • Runtime locking correctness validator (lockdep) doc - how the kernel finds lock-order cycles before they hang.
  • awesome-low-level-design repo - includes a set of concurrency problems with solutions in several languages.
  • CWA-LowLevelDesignCode repo - concurrency theory and problems in Java, in course order.
  • java-design-patterns repo - concurrency patterns such as guarded suspension, balking and monitor object.
