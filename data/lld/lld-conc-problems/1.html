The six tools that solve every puzzle

Before any code, learn to name the tool. Once you know which tool fits, the code is ten lines. These are the six tools, from simplest to most general.

ToolWhat it does (one line)Java 21C++14Kernel cousin
LatchA one-shot gate: closed until someone opens it, then open forever.CountDownLatchmutex + condition_variable + bool (std::latch is C++20)struct completion
SemaphoreA counter of permits. acquire takes one (waits at 0), release gives one back. A permit can be released by a different thread.Semaphorehand-made (counter + mutex + condvar); std::counting_semaphore is C++20struct semaphore, down()/up()
BarrierN threads wait until all N arrive, then all go on together. Reusable.CyclicBarrier, Phaserhand-made; std::barrier is C++20pthread_barrier_t in user space
MonitorOne lock + one or more condition queues. Threads sleep until a predicate on shared state is true.synchronized + wait/notifyAll, or ReentrantLock + Conditionstd::mutex + std::condition_variablewait_event() / wake_up()
Lock orderingEvery thread takes several locks in one global order, so no wait cycle can form.ReentrantLock by idstd::lock(a, b) or ordering by addressdocumented lock order + lockdep
Executor + concurrent setA pool of worker threads runs tasks; a thread-safe set removes duplicates.ExecutorService, ConcurrentHashMap.newKeySet()hand-made pool (thread pools)workqueue

Say the tool's name first: "This is a baton-passing problem, so I will use two semaphores." Interviewers grade the choice of primitive before they read a single line.
