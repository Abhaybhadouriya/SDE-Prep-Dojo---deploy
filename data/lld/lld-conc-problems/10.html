The recipe: from problem statement to primitive in one minute

Every problem above followed the same four questions. Use them in the interview, out loud.

  1. What is the shared state? A turn, a counter, a set of seen items, a room's occupancy. Write it as fields.
  2. What is each thread waiting for? Write the predicate: "stage == 2", "permits > 0", "inside == 0 or same party".
  3. Who makes it true? If a different thread hands over the turn, use a semaphore or a condition. If it happens once and stays true, a latch. If N must meet, a barrier.
  4. How does it end? Every waiting thread must eventually wake and exit: fixed loop counts, a "closed" flag plus notifyAll, or an in-flight counter.
