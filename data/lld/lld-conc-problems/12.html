Practice list and our runnable code

All code on this page lives in lld-code/lld-conc-problems/: ConcProblems.java (8 problems, self-checking driver) and conc_problems.cpp (5 problems in C++14). Build: javac ConcProblems.java && java ConcProblems and g++ -std=c++14 -O2 -pthread conc_problems.cpp (the Windows MinGW 6.3 toolchain has no std::thread, so we built the C++ with g++ 13.3 in WSL Ubuntu, and also under ThreadSanitizer: zero warnings). To repeat the TSan run: g++ -std=c++14 -g -fsanitize=thread -pthread conc_problems.cpp -o cp && setarch -R ./cp. On recent WSL kernels TSan aborts with "unexpected memory mapping" unless you turn off address randomisation, which is what setarch -R does.
