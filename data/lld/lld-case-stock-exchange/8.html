APIs and interfaces

// exchange (matching engine)
void        listStock(String symbol, long openPricePaise);        // admin
List<Trade> submit(Order o);                                      // match, rest remainder, publish trades
Order       cancel(String symbol, String orderId);                // null if not resting
void        subscribe(TradeListener l);

// broker / trading client (what the Zerodha app calls)
void   register(String userId, long cashPaise);
void   addMoney(String userId, long paise);
Order  place(String userId, String symbol, Side side, OrderType type, long limitPrice, int qty); // throws OrderRejected
boolean cancel(String userId, String orderId);
List<Trade> tradesOf(String userId);                              // history; sort by time for "date-wise"

// extension points
interface TradeListener { void onTrade(Trade t); }
interface OrderRule     { void check(Order o, Account a, long lastPrice, long blockPerUnit); }

Prices are long paise everywhere. place throws a domain exception (OrderRejected) with a reason; the order is still recorded as REJECTED so history is complete.
