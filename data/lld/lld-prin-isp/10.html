Quiz

Whose point of view does ISP take?

  1. The implementer of the interface
  2. The client (caller) of the interface
  3. The compiler
ISP is about what each caller is forced to see and depend on.

A class implements an interface method as throw new UnsupportedOperationException(). Which principles does this usually break?

  1. Only DRY
  2. Only SRP
  3. ISP and LSP
The implementer is forced to carry a method it cannot support (ISP), and it cannot stand in for the interface everywhere (LSP).

Best way to decide how to split a fat interface?

  1. Group methods by which clients call them together
  2. Exactly one method per interface
  3. Alphabetically
Cohesion from the caller's point of view. One method per interface is the "confetti" failure mode.

Why is the kernel's file_operations table with optional NULL entries acceptable?

  1. Because C programs never change
  2. One caller (VFS) checks NULL in one place, so drivers never fake methods
  3. Because every driver implements every member
NULL is an explicit "role not played", and the single caller maps it to an error such as -ENOTTY.

In a parking lot, only EVs can charge. Best design?

  1. Add charge() to Vehicle, empty for petrol cars
  2. Check instanceof ElectricCar in the spot
  3. A Chargeable role interface; the charging spot accepts only Chargeable
The role interface makes an invalid plug-in a compile error.

What is the main benefit of a read/write split (OrderReader, OrderWriter)?

  1. Read-only clients cannot write by accident and are easy to test
  2. It makes the database faster
  3. It removes the need for a database
It narrows each client's view. Performance is a separate concern (though CQRS later uses the same split).
