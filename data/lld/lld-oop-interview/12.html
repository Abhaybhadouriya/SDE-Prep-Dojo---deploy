Rapid-fire: one-line answers

QuestionOne-line answer
Can a constructor be private?Yes: singletons, factories, utility classes.
Can we override a private or static method?No. Private is invisible; static is hidden, not overridden.
Can an interface have fields?Only public static final constants.
Can an abstract class have a constructor?Yes; subclasses call it with super(...).
Can an abstract class have zero abstract methods?Yes; it just cannot be instantiated.
Covariant return type?An override may return a subtype of the parent's return type.
Can an override throw a broader checked exception?No: same, narrower, or none (Liskov in the compiler).
Can an override reduce visibility?No: public stays public.
this vs super?Current object vs the parent part of it; both can call constructors as the first line.
Association, aggregation, composition?Uses; has (parts can live alone); owns (parts die with the whole).
Coupling and cohesion?Aim for low coupling between classes, high cohesion inside a class.
Is Java pass-by-reference?No. Always by value; for objects the value is a reference.
Why prefer composition?Hides internals, swappable at runtime, avoids fragile base classes.
Pure virtual function?C++ virtual void f() = 0; makes the class abstract.
Friend class?C++ only: grants another class access to private members. Java has none.
