Quiz

Which Java access level lets a class in the same package, but not a subclass in another package, use a member?

  1. protected
  2. package-private (no keyword)
  3. private
Package-private is package only. protected adds subclasses in other packages.

A class has private List<Item> items and getItems() { return items; }. What is wrong?

  1. Nothing, the field is private
  2. It will not compile
  3. Callers can mutate the internal list and bypass the class's rules
The reference leaks. Return an unmodifiable view or a copy.

In C++, what is the default access of members in a struct?

  1. public
  2. private
  3. protected
struct defaults to public, class to private. Otherwise they are the same.

Which change best follows "tell, don't ask"?

  1. Add getStatus() and setStatus() to Order
  2. Replace order.setStatus(CANCELLED) with order.cancel(reason)
  3. Make status public final
An intention-revealing method can check whether cancelling is allowed right now.

What does self.__balance do in Python?

  1. Makes it truly private like Java
  2. Makes it read-only
  3. Name-mangles it to _ClassName__balance, a convention against accidental access
Python has no enforced privacy; mangling avoids subclass name clashes.

In C, how do you stop callers from touching a struct's fields?

  1. Declare struct foo; in the header and define it only in the .c file
  2. Mark fields const
  3. Use #define private
An incomplete type can be pointed to but not dereferenced outside its .c file.
