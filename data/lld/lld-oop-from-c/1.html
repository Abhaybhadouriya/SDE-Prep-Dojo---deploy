The object you already write in C

Here is the smallest useful "object" in C. A network device has some data (a name, a reference count) and some behaviour (open, transmit, stop). The behaviour is not stored in each device; it lives in one shared, read-only table of function pointers, and each device keeps a pointer to its table.

struct net_dev;

struct net_dev_ops {                       /* the "interface": what every device can do */
    int  (*open)(struct net_dev *dev);
    int  (*xmit)(struct net_dev *dev, const char *pkt);
    void (*stop)(struct net_dev *dev);     /* may be NULL: "use the default" */
};

struct net_dev {                           /* the common data every device has */
    char name[16];
    const struct net_dev_ops *ops;         /* pointer to this device's table */
    struct kref ref;
};

/* generic code: works for ANY device, knows only the table */
static int dev_send(struct net_dev *dev, const char *pkt)
{
    return dev->ops->xmit(dev, pkt);
}

Three ideas are already in these lines:

  1. Data and behaviour travel together. Given a struct net_dev *, you can reach both its fields and the functions that operate on it. That pairing is what an object is.
  2. The first argument is the object. Every op takes struct net_dev *dev. In Java and C++ this hidden first argument is called this; the compiler passes it for you.
  3. Callers depend on the table, not the driver. dev_send compiles once and works with drivers written years later. That is the whole point of an interface.

The same thing in Java and C++

Java and C++ give this pattern its own syntax, so the compiler builds the table, fills the pointer and passes this for you.

interface NetDevice {                 // = struct net_dev_ops
    void open();
    boolean xmit(String pkt);
    default void stop() {             // = a NULL slot with a default behaviour
        System.out.println("default stop");
    }
}

static boolean send(NetDevice dev, String pkt) {
    return dev.xmit(pkt);             // = dev->ops->xmit(dev, pkt)
}
class NetDevice {                     // abstract class = ops table + base data
public:
    virtual ~NetDevice() = default;
    virtual void open() = 0;          // pure virtual: every subclass must fill this slot
    virtual bool xmit(const std::string& pkt) = 0;
    virtual void stop() { std::cout << "default stop\n"; }  // slot with a default
};

bool send(NetDevice& dev, const std::string& pkt) {
    return dev.xmit(pkt);             // compiler emits: load vptr, load slot, call
}
