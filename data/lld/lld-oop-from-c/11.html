Remember this

  • Object = data + a pointer to shared behaviour. Struct + const ops table in C; class + vtable in C++; class + method table in the JVM.
  • Interface = a list of operations with no data. file_operations, net_device_ops and tcp_congestion_ops are interfaces.
  • Embedding + container_of = data inheritance with an unchecked downcast. extends + this = the same, checked.
  • A virtual call costs what dev->ops->fn(dev) costs: two loads and an indirect call.
  • kref, shared_ptr and GC all answer "when can it be freed?"; you still decide who owns what.
  • Unlearn switch (type) for behaviour: add a class, not a case.
  • In interviews, translate: "this interface is like a file_operations table" is a strong, honest signal.
