APIs and interfaces

Write these on the board before you code. They are what main, a test, or a REST controller would call.

Match match = new Match(new Team("Team 1", List.of("P1", "P2", ...)),
                        new Team("Team 2", List.of("P6", "P7", ...)), /*overs*/ 2);
match.addListener(new ScorecardPrinter());     // Observer registration
match.startOver("P10");                        // bowler for the next over
match.bowl("1"); match.bowl("Wd"); match.bowl("Nb4"); match.bowl("W");
Match.State s = match.state();                 // FIRST_INNINGS, SECOND_INNINGS, FINISHED
String r = match.result();                     // "Team 1 won the match by 4 runs"

interface MatchListener {                      // all default no-ops
    void onBall(Innings in, Ball b);
    void onOverEnd(Innings in);
    void onInningsEnd(Innings in);
    void onMatchEnd(Match m, String result);
}
  • Errors: a bad token or unknown bowler throws IllegalArgumentException; bowling between overs, starting an over mid-over or bowling after the match throws IllegalStateException.
  • Read side: listeners receive the Innings and read it through getters and unmodifiable maps. They cannot change the score.
  • If asked for REST (the Zepto variant): POST /matches, POST /matches/{id}/overs {bowler}, POST /matches/{id}/balls {token} (with a client ball sequence number for idempotency), GET /matches/{id}/scorecard, and a WebSocket or SSE stream for live updates.

If they ask for the database schema

Store the events, derive the scorecard. Then a correction is one row update plus a recompute, and commentary, graphs and stats all come from the same table.

match(id, team1_id, team2_id, overs, state, result)
player(id, name)                      team_player(team_id, player_id, batting_position)
innings(id, match_id, number, batting_team_id, target)
ball_event(innings_id, seq, over_no, ball_in_over, bowler_id, striker_id, non_striker_id,
           type, bat_runs, extras, wicket_player_id, created_at,  PRIMARY KEY (innings_id, seq))
-- scorecards: SELECT striker_id, SUM(bat_runs), COUNT(*) FILTER (WHERE type <> 'WIDE') ... GROUP BY striker_id
