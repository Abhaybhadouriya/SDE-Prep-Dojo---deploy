The common thread: compilers and tree tools. A programming language's grammar changes rarely (node types are stable) while new passes (type check, optimise, format, lint) arrive constantly. That is the exact bet Visitor makes.

From your world

The kernel walks directories with a callback object: iterate_dir(file, ctx) takes a struct dir_context whose actor function is called once per entry. getdents64, nfsd and overlayfs each pass their own actor, so one walk serves many operations. That is the "operation as an object passed to a traversal" half of Visitor, with single dispatch only (every entry is the same type). A true double dispatch in C is the visit[node->type] table shown above.
