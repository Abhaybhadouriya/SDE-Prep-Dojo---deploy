Structure: two hierarchies that point at each other

  • Visitor (CartVisitor<R>): one visit method per concrete element type. The generic R lets each visitor return its own result type (a Double for tax, Void for a printer). R is a type parameter, chosen per visitor; Void is Java's "returns nothing" type for generics.
  • Concrete Visitor (TaxVisitor, ShippingVisitor, ReceiptVisitor): one operation, all its cases in one file. It may hold state (a running total, a text buffer, the current indent depth).
  • Element (Item): declares accept(visitor). Nothing else is required.
  • Concrete Element (Book, ...): implements accept with one line, return v.visitBook(this);.
  • Object Structure (Cart, an AST (abstract syntax tree: the tree a parser builds from source text, one node per expression), a directory tree): holds the elements and offers a way to walk them. Often it is a Composite.
