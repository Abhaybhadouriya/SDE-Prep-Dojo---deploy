Remember this

  • Visitor = each operation is its own class with one visit per element type; elements only have accept(v).
  • Double dispatch: accept chooses the element type, visitX(this) chooses the operation.
  • New operation = one new class. New element type = edit every visitor. Use it when types are stable.
  • Natural homes: compilers and ASTs, file trees, product carts with per-category rules, document export.
  • JDK: FileVisitor/walkFileTree, ElementVisitor. Python: ast.NodeVisitor.
  • Java 21 sealed types + exhaustive switch often replace it in new code.
  • C translation: a table of function pointers indexed by the node's type tag.
