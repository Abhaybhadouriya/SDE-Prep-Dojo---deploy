What happens in the evaluation call

In machine-coding rounds the grading happens in a separate 30-45 minute call, sometimes the same day, sometimes a few days later. Candidates describe the same sequence again and again. Click through it.

  1. You explain. Start with the problem in one sentence and the package layout. workat.tech lists walking through every line instead of giving an overview as a red flag.
  2. They run it. Your driver should print a clear story: each P0 flow, then each edge case. A Flipkart candidate walked through the code "by running each test case" (2026-02-19).
  3. Edge cases. The same evaluator then pointed out missing validations that were not in the brief. Validate ids, states and inputs even when the brief is silent.
  4. "Why this?" Expect "why sort when a priority queue would do, and what is its cost?" (same report) and "which pattern would you use for the async part?" (Flipkart, 2025-04-26).
  5. "Now add..." A new rule, a real database or two threads at once. Good structure turns this into a small, calm edit. PhonePe reviews also cover production readiness and DB choice (2023-06-23).
