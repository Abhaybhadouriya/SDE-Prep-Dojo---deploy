Quiz

printReport(rows, 2) where 2 means "PDF". Which coupling is this?

  1. Data coupling
  2. Stamp coupling
  3. Control coupling
The number selects a branch inside the callee - control coupling (and connascence of meaning).

Ten classes read and one writes static double DISCOUNT. What is the kind of coupling?

  1. Common coupling
  2. Message coupling
  3. Functional coupling
Shared mutable global data is common coupling: every reader depends on every writer.

A Helpers class contains date parsing, card masking and retry logic. Its cohesion is...

  1. Functional
  2. Coincidental
  3. Sequential
Nothing relates the parts except the file they sit in.

sendSms(User u) uses only u.phone. Best fix?

  1. Make all User fields public
  2. Pass the phone number (or a narrow interface)
  3. Make User a singleton
Turn stamp coupling into data coupling: pass only what is used.

Class A has Ca = 0 and Ce = 6. Its instability I = Ce / (Ca + Ce) is...

  1. 0
  2. 0.5
  3. 1
6 / (0 + 6) = 1: maximally unstable - it depends on many and nobody depends on it, so it is safe to change but easily broken.

Why do ext4 and xfs not need to change when a new filesystem is added?

  1. Each depends only on the VFS contract (file_operations etc.), not on other filesystems
  2. They are compiled into one file
  3. The kernel uses message coupling between filesystems
Narrow ops-table seams give data-level coupling to a stable abstraction.

Which statement about events is right?

  1. Events remove all coupling
  2. Events remove compile-time coupling but keep logical coupling to the event's shape and meaning
  3. Events always make debugging easier
Consumers still rely on the event contract, and the flow becomes harder to follow.
