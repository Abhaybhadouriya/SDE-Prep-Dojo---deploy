90-minute machine-coding plan

For a 45-60 minute design round, do the first 20 minutes of this plan on a whiteboard and code only Game.move and one piece. For a 90-minute coding round:

MinutesDoOutput
0-7Requirements and scope: special moves? undo? draws? code or design?agreed list
7-15Entities, class diagram, the Game / Board / Piece split.diagram and method names
15-30Position, Color, Piece base, SlidingPiece, StepPiece, five pieces, factory, Board with fromRows and render.a printed start board
30-45Move execute/undo (normal moves), Game.move with validation messages, turn switching.play a few moves
45-55isAttacked, king safety via execute/undo, status update.Scholar's mate detected
55-70Pawn specials (double push, en passant, promotion) and castling.special moves demo
70-80Undo API, resign, perft(1..3) as the self-test.20 / 400 / 8902
80-90Clean names, remove dead code, list follow-ups (draw rules, clocks, online).walkthrough ready

If time is short, drop castling and en passant from the code but keep them in the design ("King overrides candidateMoves; Move gets a CASTLE kind that also moves the rook"). Interviewers accept "designed, not implemented" for specials far more readily than a missing check rule.
