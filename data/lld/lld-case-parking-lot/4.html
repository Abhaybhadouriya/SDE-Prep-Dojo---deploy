Class diagram

Boxes have three compartments: name, fields, methods. A filled diamond is composition (the part dies with the whole), a hollow diamond is "has a" that can be swapped, a dashed line with a hollow triangle is "implements", a plain arrow is an association, and a dashed arrow is a dependency such as "creates".

How to read this: + public, - private, «interface» a type with only method signatures (an ops table), 1..* one-to-many. Filled diamond = owns (the part dies with the whole), hollow diamond = has (can be swapped), solid line with hollow triangle = extends, dashed line with hollow triangle = implements, dashed arrow = depends on or creates.
