A car takes the large spot on level 1 and a truck is then turned away, while a medium spot on level 2 was free. Which change fixes this without touching ParkingLot?

  1. Make the truck a subclass of Car
  2. Switch the allocation strategy to best-fit
  3. Add synchronized to park()
  4. Make ParkingLot a Singleton
Best-fit tries the smallest fitting size anywhere in the lot first, so the car takes a medium spot and the large spot stays free.

Why does our ParkingSpot have no isFree field?

  1. Java records cannot have booleans
  2. To save memory
  3. The level's free set is the single source of truth, so the two cannot disagree
  4. Spots are never freed
Keeping the same state in two places invites drift and races. One owner, one truth.

A nearly full lot, spots stored in a SQL table, many gates. Which locking is the better default?

  1. Optimistic version check, retry on failure
  2. No locking; conflicts are rare
  3. Pessimistic row lock with FOR UPDATE SKIP LOCKED
  4. A table-level lock
High contention makes optimistic retries frequent; SKIP LOCKED lets each gate take a different free row without waiting.
