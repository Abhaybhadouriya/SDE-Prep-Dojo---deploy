Exceptions: one base class, a few precise children

Graders look for "fails gracefully". In practice that means: a bad id, a duplicate, a limit, a double cancel each produce a clear message, and the program keeps running. One base class makes the driver simple: catch FlipFitException, print the message, go on.

public class FlipFitException extends RuntimeException {          // unchecked: no throws clutter
    public FlipFitException(String message) { super(message); }
}
public class NotFoundException extends FlipFitException {
    public NotFoundException(String what, String id) { super(what + " not found: " + id); }
}
