Resources

  • workattech/flipkart-machine-coding-round repo - the public description of the three stages (pre-coding, coding, demo) and what is evaluated, plus practice problems.
  • workat.tech: How to ace the machine coding round blog - time management and code hygiene advice for the round.
  • iqblmoh/machineCoding repo - practice solutions organised in dao / entity / enums / exception / service folders. No licence file: read it, do not copy it.
  • kumaransg/LLD repo - a large collection of machine-coding style solutions from Indian product-company rounds, useful to compare layouts.
  • HelloInterview: LLD in a hurry course - free introduction to the round format and its common pitfalls.
  • Martin Fowler: Repository (P of EAA catalog) doc - the original short definition of the pattern our storage layer uses.
  • Mark Seemann: Composition Root blog - why all wiring belongs in one place near the entry point.
  • On this site: the machine-coding playbook, common LLD mistakes, the LLD question bank, patterns cheat sheet, the LLD interview framework, Repository, dependency injection, booking concurrency, and the company guides for Flipkart and Indian fintech (PhonePe, Razorpay, CRED).
