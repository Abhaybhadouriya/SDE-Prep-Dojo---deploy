Driver and Main: the only place that knows everything

Main does three things and nothing else: build the object graph (the composition root), run a scripted demo of every P0 feature plus edge cases, and optionally read commands from stdin. The command parser is a map from command word to a small function, so a new command is one line.

public static CommandRunner wire() {
    UserService users = new UserService(new InMemoryRepository<User>());
    ClassService classes = new ClassService(new InMemoryRepository<FitnessClass>());
    BookingService bookings = new BookingService(users, classes,
            new InMemoryRepository<Booking>(), new TierLimitPolicy(Map.of(Tier.NORMAL, 2, Tier.VIP, 5)));
    bookings.addListener((event, b) -> System.out.println("  [notify] " + b.getUserId() + ": " + event + " " + b.getId()));
    return new CommandRunner(users, classes, bookings);
}

// CommandRunner: command word -> (argument count, handler)
handlers.put("BOOK", new Command(2, a -> "booked " + bookings.book(a[1], a[2])));
handlers.put("ADD_CLASS", new Command(4, a -> "added " + classes.add(a[1],
        parseEnum(ClassType.class, a[2]), a[3], parseInt(a[4]))));   // parse errors become ValidationException

public String run(String line) {
    String trimmed = line.trim();
    if (trimmed.isEmpty() || trimmed.startsWith("#")) return "";   // blank and comment lines are skipped
    String[] parts = trimmed.split("\\s+");
    Command cmd = handlers.get(parts[0].toUpperCase());
    if (cmd == null) return "ERROR unknown command: " + parts[0];
    try {
        if (parts.length - 1 != cmd.args())          // arity checked here, so a bug inside a service stays loud
            throw new ValidationException(parts[0] + " needs " + cmd.args() + " arguments, got " + (parts.length - 1));
        return cmd.body().apply(parts);
    } catch (FlipFitException e) {                   // business or input error: expected, print it
        return "ERROR " + e.getMessage();
    }                                                // anything else is a programming bug: let it crash
}
def wire() -> CommandRunner:
    users = UserService(InMemoryRepository[User]())
    classes = ClassService(InMemoryRepository[FitnessClass]())
    bookings = BookingService(users, classes, InMemoryRepository[Booking](),
                              TierLimitPolicy({Tier.NORMAL: 2, Tier.VIP: 5}))
    bookings.add_listener(lambda event, b: print(f"  [notify] {b.user_id}: {event} {b.id}"))
    return CommandRunner(users, classes, bookings)

def run(self, line: str) -> str:
    line = line.strip()
    if not line or line.startswith("#"):         # blank and comment lines are skipped
        return ""
    parts = line.split()
    entry = self._handlers.get(parts[0].upper())   # command word -> (argument count, handler)
    if entry is None:
        return f"ERROR unknown command: {parts[0]}"
    nargs, handler = entry
    try:
        if len(parts) - 1 != nargs:              # arity checked here, so a bug inside a service stays loud
            raise ValidationError(f"{parts[0]} needs {nargs} arguments, got {len(parts) - 1}")
        return handler(parts)                    # _int() / _enum() turn parse errors into ValidationError
    except FlipFitError as e:                    # business or input error: expected
        return f"ERROR {e}"
    # anything else (a KeyError inside a service) is a programming bug: let it crash

Note what the driver does not catch. It checks the argument count and parses numbers and enums itself, turning those into a ValidationException, and then catches only the base business exception. A blanket catch (IndexOutOfBounds | IllegalArgument) would also swallow a real bug inside a service and print it as "bad input"; letting such bugs crash keeps them loud.

A demo that shows the happy path and five failure lines answers "edge cases", "error handling" and "fails gracefully" before the evaluator asks. The Flipkart practice repo describes the post-coding demo as the interviewer keying in several test cases and checking the output, so make your input format easy to type.
