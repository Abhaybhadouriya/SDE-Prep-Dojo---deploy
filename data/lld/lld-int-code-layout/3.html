The skeleton you type in minute 10

Here is the full tree of our runnable example: a FlipFit-style gym class booking app (users with tiers, classes with capacity, a FIFO waitlist, a per-tier booking limit, notifications). Fitness-class booking was reported at Flipkart, Meesho and PhonePe; the PhonePe SDE-1 version had tier limits, a waitlist and cancellation (2025-07-20). The same tree works for parking lots, Splitwise, BNPL (Buy Now Pay Later) or a task scheduler: only the names in model change.

java/src/main/java/com/dojo/flipfit/
  Main.java                      # composition root + scripted demo
  model/
    Entity.java                  # interface: String getId()
    User.java  FitnessClass.java  Booking.java
    Tier.java  ClassType.java  BookingStatus.java     # enums
  exception/
    FlipFitException.java        # base, extends RuntimeException
    NotFoundException.java  ValidationException.java  LimitExceededException.java
  repository/
    Repository.java              # interface: save, findById, findAll
    InMemoryRepository.java      # generic, ConcurrentHashMap
  strategy/
    BookingLimitPolicy.java  TierLimitPolicy.java     # the rule that varies
    BookingListener.java                              # observer hook
  service/
    UserService.java  ClassService.java  BookingService.java
  driver/
    CommandRunner.java           # "BOOK u1 c1" -> bookingService.book(...)
java/src/test/java/com/dojo/flipfit/
  BookingServiceTest.java        # plain-Java checks; JUnit if the IDE has it
python/
  flipfit/
    __init__.py
    models.py        # dataclasses + Enums (User, FitnessClass, Booking, Tier, ...)
    exceptions.py    # FlipFitError + NotFoundError, ValidationError, LimitExceededError
    repository.py    # Repository Protocol + InMemoryRepository (dict + lock)
    policies.py      # BookingLimitPolicy Protocol, TierLimitPolicy, BookingListener
    services.py      # UserService, ClassService, BookingService
    driver.py        # CommandRunner, wire(), DEMO, main()  ->  python -m flipfit.driver
  tests/
    __init__.py
    test_booking.py  # unittest, incl. a 64-thread last-seat race

The code is in the repo at lld-code/lld-int-code-layout/ (Java 17+ and Python 3.10+). Both versions print the same demo output line for line; the Java checks and the Python unittest suite both pass, including a 64-thread race for the last seat.

Practise typing the empty skeleton (folders, the base exception, Repository, InMemoryRepository, an empty Main) until it takes under five minutes. In the round you then spend those minutes thinking about the entities instead.
