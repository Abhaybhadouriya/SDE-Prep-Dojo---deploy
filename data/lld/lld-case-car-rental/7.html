APIs and interfaces

interface Spec<T> { boolean isSatisfiedBy(T t); /* and, or, not */ }
interface PricingStrategy { long price(Vehicle v, TimeSlot slot); }

class RentalService {
    RentalService(PricingStrategy pricing);
    void addBranch(Branch b);
    void addVehicle(Vehicle v);                                  // IllegalArgumentException: unknown branch, duplicate
    List<Quote> search(Spec<Vehicle> filter, TimeSlot slot);    // free for the whole slot, cheapest first
    Reservation book(String userId, String vehicleId, TimeSlot slot);   // VehicleUnavailableException
    void cancel(String reservationId);                           // IllegalStateException if not CONFIRMED
    void pickUp(String reservationId);
    long returnVehicle(String reservationId, LocalDateTime at);  // total charged incl. late fee
    List<Reservation> reservationsOf(String userId);
}

If the interviewer wants REST, map them one to one: GET /vehicles?branch=KOR&minSeats=5&from=..&to=.., POST /reservations (with an idempotency key header), POST /reservations/{id}/cancel, /pickup, /return. See API design for LLD.
