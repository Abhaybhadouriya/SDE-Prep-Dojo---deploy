  • Store reservations; derive availability for a time range. Never an isAvailable flag.
  • Half-open slots: overlap = s1 < e2 && s2 < e1; back-to-back is allowed.
  • Check and insert are one atomic step per car: per-vehicle lock in memory, exclusion constraint or row lock in the database.
  • Search is advisory, book is authoritative.
  • Filters = Specification; base price = Strategy; surcharges and coupons = Decorators.
  • Reservation status changes only through guarded transitions; only CONFIRMED and PICKED_UP block the car.
  • Never hold a lock across payment: use a HELD state with an expiry.
