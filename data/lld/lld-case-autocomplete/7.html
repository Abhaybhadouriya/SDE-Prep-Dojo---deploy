APIs and interfaces

// autocomplete
AutocompleteEngine(RankingStrategy rank, int k, boolean cacheTopK);
void             record(String phrase);                 // also record(phrase, times)
List<Suggestion> suggest(String prefix);                // best k, best first
boolean          remove(String phrase);
TypingSession    session();                              // type(char) -> suggestions; '#' records

interface RankingStrategy extends Comparator<Entry> {   // best first; scores only go up
    String name();
}

// router
void                  put(String pattern, V value);     // literal, :name, *, ** (last); throws on conflict
Optional<RouteMatch>  match(String path);               // literal > :param > * > **, backtracking
List<String>          findAll(String query);            // '*' in the query, plain keys stored

For the Atlassian wording, addRoute(path, result) is put and callRoute(path) is match(path).map(m -> m.value). Behind HTTP: GET /suggest?q=lin&k=3 returns the list; record is fire-and-forget from the search service. See API design in LLD.
