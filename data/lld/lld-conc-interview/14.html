Resources

  • java.util.concurrent (Java 21 API) doc - includes the memory consistency (happens-before) rules of every class.
  • Java Language Specification, chapter 17: Threads and Locks doc - the memory model itself.
  • cppreference: concurrency support library doc - mutexes, condition variables, std::lock, what is C++20-only.
  • Linux kernel locking documentation doc - spinlocks, mutexes, lockdep: the kernel side of every answer here.
  • The Little Book of Semaphores book - free from the author; the source of several Rubrik-style puzzles.
  • LeetCode concurrency problem set course - practice the turn-taking puzzles.
  • Devinterview-io concurrency questions repo - rapid-fire theory list (only part is free).
  • kousiknath/LowLevelDesign repo - blocking queue, connection pool, scheduled executor and multithreaded logger implementations.
  • AlgoMaster concurrency interview course - free and paid lessons; good topic map.
