Evaluator rubric checklist

  • Runs: one command demos list, search with combined filters, sort, page, shortlist, mark sold and remove.
  • Correct index: AND search, tokenizer shared by index and query, remove leaves no stale postings.
  • Modular: indexes, filters, ranking and the command facade are separate classes.
  • Extensible: a new filter or sort order shown to be a one-class change.
  • Validation: bad input, permissions and empty results handled with clear messages.
  • Stable results: total order with an id tie-breaker; pages join without repeats.
  • Thread safety: reads in parallel, writes atomic across all indexes.
  • Communication: you named the trade-offs (whole words only, no negation, offset paging limits).
