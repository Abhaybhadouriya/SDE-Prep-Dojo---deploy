One practice session, minute by minute

From week 3 on, every case is a rehearsal of the real round. Here is the 2-hour session you should repeat. It follows the 15 + 90 + 15 shape of a machine-coding round, with a review block at the end. Click through it once now so the shape is familiar.

  1. Clarify (15 min): requirements and questions, prioritised. Never start coding without them.
  2. Model (15 min): entities and a class diagram, plus the patterns you chose and the reason for each.
  3. Code (60 min): model classes, then services, then a driver that exercises them. Compile often.
  4. Demo (15 min): run it, show edge cases, explain how a new requirement would fit.
  5. Review (15 min): compare with the reference and write down what to fix next time.

The detailed version of steps 1 and 2 is on The LLD Interview Framework; the coding layout (entities, repositories, services, driver) is on Machine-Coding Code Layout.
