The template every case study follows

All 45 pages use the same sections in the same order. That is on purpose: it is also the order in which you should run a real interview. Once the shape is a habit, your attention goes to the problem, not to "what do I do next".

  1. Clarify (5-8 min). Write functional P0 and P1, non-functional needs, out of scope, and the questions you asked.
  2. Entities. Underline nouns and verbs; drop actors and plain values; turn fixed vocabularies into enums.
  3. Class diagram. Name, fields, methods; composition vs aggregation; interfaces for anything that varies.
  4. Patterns. Each pattern is named next to the requirement that pulled it in, never "because patterns are good".
  5. Flows and APIs. One sequence diagram for the main use case; the method signatures you will be graded against.
  6. Code and driver. Full runnable code (Java first, Python, C++14 where it helps) with a demo driver and assertions. Each code section opens with a short reading map and a "Reading this Java as a C programmer" box.
  7. Concurrency. Every piece of shared state and how it is protected; the locking trade-off.
  8. Extensibility and tests. The follow-ups interviewers ask and which class each one touches; the edge-case table.
  9. Interview layer. Timed plan, rubric, Q&A, mistakes, quiz and sources, so the page doubles as a mock.

The general version of this framework, with minute budgets for each round type, is in the LLD interview framework.

Section anchors. The case pages share these section ids, so a deep link works on every page: #story, #asked, #clarify, #entities, #class-diagram, #patterns, #flows, #apis, #code, #concurrency, #extensibility, #edge-cases, #plan, #rubric, #qa, #mistakes, #remember, #quiz, #resources. A few pages add one topic section (for example #algorithms on Rate Limiter). The level dividers sit in the same places too: Level 2 at Clarify, Level 3 at Patterns, Level 4 at Concurrency, Level 5 at the 90-minute plan.

How to run the code. Every case keeps its code in lld-code/<page-id>/ (for example lld-code/lld-case-parking-lot/), with java/, python/ and usually cpp/ folders and the exact commands in its run-*.txt files. Java 17+: cd java && javac -d out *.java && java -cp out Main. Python 3.10+: cd python && python main.py, tests with python -m unittest. C++: g++ -std=c++14 -O2 -o main main.cpp && ./main. The output printed on each page is the real output of these commands.
