The teaching order

The courses we surveyed agree on a direction: start with games (pure modelling, no time or money), move to state machines, then management systems, then booking with concurrency, then money, and finish with infrastructure. Each step adds exactly one new difficulty. Click through the path.

  1. Games: Tic-Tac-Toe, then Snake & Ladder, then Chess. You practise turning a story into classes with nothing else in the way.
  2. State machines: Vending Machine, ATM, Elevator. You learn to draw states first and code transitions second.
  3. Management systems: Parking Lot (the most asked of all), Library, Amazon Locker. Pools, allocation, fees.
  4. Booking: BookMyShow, Car Rental, Hotel, IRCTC, Meeting Scheduler. The concurrency step: holds, TTL, locking.
  5. Money: Splitwise, Wallet, Shopping Cart, Stock Exchange. Correct totals under retries and edge cases.
  6. Infrastructure: LRU Cache, Rate Limiter, Logger, Pub-Sub, Task Scheduler. Data structures and thread-safe policies.

The core 12 (do these first)

Picked by frequency and by pattern coverage, so that together they touch every important idea at least once:

  1. Tic-Tac-Toe warm-up: modelling and an O(1) win check.
  2. Snake & Ladder a Flipkart machine-coding classic; game loop and a dice strategy.
  3. Parking Lot rank 1; two Strategies, Observer, a Simple Factory, first concurrency.
  4. Vending Machine the canonical State pattern.
  5. Elevator state per car plus a scheduling strategy.
  6. BookMyShow rank 2; holds with TTL, pessimistic vs optimistic.
  7. Splitwise rank 3; split strategies and simplifying debts.
  8. LRU Cache the data-structure classic with pluggable eviction.
  9. Logger Chain of Responsibility and an async appender.
  10. Pub-Sub Observer, offsets, worker threads.
  11. Rate Limiter algorithms as strategies, thread safety per key.
  12. Ride Hailing trip state, matching strategy, driver allocation races.

Stretch set (after the core 12): Chess, ATM, File System, Food Delivery, Meeting Scheduler, Shopping Cart and coupons, Stock Exchange, Text Editor undo/redo.
