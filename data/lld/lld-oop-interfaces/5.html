Special kinds of interface

  • Functional interface: exactly one abstract method, so a lambda can implement it. Runnable, Comparator, Function. Mark your own with @FunctionalInterface so the compiler keeps it that way. Great for small strategies (fee rules, sort orders) in machine-coding rounds.
  • Marker interface: no methods at all; it tags a class. Serializable and Cloneable are the classic ones. Modern code often uses annotations instead.
  • Role interface: a small interface describing one capability, like Retryable or Auditable. A class picks up several. This keeps clients depending only on what they use (Interface Segregation).
  • Sealed interface (Java 17+): sealed interface Shape permits Circle, Square lists every allowed implementer, so a switch over it can be checked for completeness. Use it for closed sets like result types or protocol messages.
// A class extends ONE class but can implement MANY interfaces (role interfaces).
interface Retryable { int maxRetries(); }
interface Auditable { default String auditTag() { return "audited:" + getClass().getSimpleName(); } }

@FunctionalInterface
interface FeeRule { long fee(long minutes); }          // one abstract method -> lambda friendly

FeeRule hourly = m -> ((m + 59) / 60) * 20;   // 95 minutes -> Rs 40
