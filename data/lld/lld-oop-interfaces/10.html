Remember this

  • Interface = contract, "can do". No state, no constructors, many per class. Default, static and private helpers allowed.
  • Abstract class = partial class, "is a kind of". State, constructors, final template methods, abstract holes. One per class in Java.
  • Default to interfaces at the seams that vary (repositories, gateways, notifiers, rules). Add an abstract base only to remove duplication.
  • Diamond rule for defaults: class wins, then the more specific interface, else override and pick with X.super.m().
  • Functional (one method, lambdas), marker (no methods), role (small capability) and sealed (closed set) interfaces each have a job.
  • C++: pure virtual classes with a virtual destructor. Python: abc.ABC (nominal) or typing.Protocol (structural).
  • Program to an interface: depend on the abstraction, choose the concrete class in one place.
