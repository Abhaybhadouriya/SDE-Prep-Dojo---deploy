Quiz

Which can a Java interface NOT have?

  1. A default method
  2. A static method
  3. An instance field that each object owns
Interface fields are implicitly public static final constants. Per-object state needs a class.

Notifiers share a send counter and a fixed "format, deliver, count" sequence. What fits best?

  1. An abstract class with a final template method
  2. A marker interface
  3. A functional interface
Shared state plus fixed steps with holes is exactly what an abstract class (Template Method) is for.

A class implements interfaces A and B. Both define default String describe(). The class does not override it. What happens?

  1. A's version is used because it is listed first
  2. Compile error: the class must override describe()
  3. A runtime exception on the first call
With no class method and no more-specific interface, the clash must be resolved by overriding, optionally calling A.super.describe().

In C++, what makes a class abstract?

  1. The keyword abstract
  2. At least one pure virtual function (= 0)
  3. A private constructor
C++ has no abstract or interface keyword; one pure virtual function is enough.

A Python class has a charge() method but does not inherit from PaymentGateway(Protocol). Does it satisfy the protocol?

  1. No, it must inherit
  2. Only if registered with ABCMeta.register
  3. Yes: Protocols are structural, matching by method shape
PEP 544 Protocols check shape, not ancestry. abc.ABC is the nominal alternative.

In a food-ordering LLD, which is the weakest candidate for an interface?

  1. MenuItem (a plain data entity)
  2. PaymentGateway
  3. OrderRepository
Interfaces earn their place where implementations vary. A plain entity usually has one implementation.
