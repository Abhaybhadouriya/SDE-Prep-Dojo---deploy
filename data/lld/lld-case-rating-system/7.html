APIs and interfaces

final class RatingService {
    RatingService();                                    // Rankings.DEFAULT
    RatingService(Comparator<AgentScore> ranking);      // stage 2: pluggable tie-break
    void rate(String agentId, int stars, LocalDate date); // stage 1 (+ date from stage 3)
    List<AgentScore> averages();                        // all time, ranked
    List<AgentScore> bestOfMonth(YearMonth month);      // stage 3, ranked
    List<String> topAgents(YearMonth month);            // stage 3, everyone tied for first
    String export(List<AgentScore> rows, Exporter fmt);  // stage 4
}
interface Exporter { String export(List<AgentScore> rows); }   // CsvExporter, JsonExporter
final class AgentScore { String agentId; long sum, count; String average(); }

In stage 1 the interviewer often gives no date. Add the LocalDate parameter when stage 3 arrives and keep a rate(agentId, stars) overload that uses today's date from an injected Clock, so earlier tests compile unchanged and new tests can fix the time.
