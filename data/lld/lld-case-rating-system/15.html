Common mistakes

  • Integer division: int avg = sum / count, so 5 and 4 average to 4.
  • Storing the average and recomputing it as (avg + new) / 2, which is simply wrong after the second rating.
  • No tie-break, so the order changes between runs or between HashMap implementations and tests flake.
  • Iterating a PriorityQueue and assuming the output is sorted; or mutating keys inside it.
  • Rewriting stage 1 for stage 3 instead of adding a bucket; old tests deleted to make new ones pass.
  • Formatting inside the service (println in averages()), so export needs a rewrite.
  • No validation: a rating of 0 or 7 silently skews averages.
  • Writing all the code before any test in a round where the recruiter's guide recommends TDD.
