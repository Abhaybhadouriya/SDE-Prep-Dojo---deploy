The follow-up is in Rankings in the Java file above (and checked in the demo: one lucky 5-star ranks below a hundred ratings averaging 4.90):

/** Follow-up: Bayesian (damped) average so one lucky 5-star does not top the chart. Same Strategy seam.
 *  The prior is an exact fraction priorSum / priorCount (3.8 stars worth 10 ratings = 38 / 10), not a long
 *  mean that would truncate 3.8 to 3. Score = (sum + priorSum) / (count + priorCount), compared by
 *  cross-multiplication. Overflow: sum <= 5 * count, so a product is about 5 * n^2 and stays inside a long
 *  up to roughly 10^9 ratings per agent; multiplyExact throws instead of wrapping beyond that. */
static Comparator<AgentScore> bayesian(long priorSum, long priorCount) {
    if (priorCount <= 0 || priorSum < 0) throw new IllegalArgumentException("prior must be a positive weight");
    return (a, b) -> Long.compare(Math.multiplyExact(b.sum + priorSum, a.count + priorCount),
                                  Math.multiplyExact(a.sum + priorSum, b.count + priorCount));
}
