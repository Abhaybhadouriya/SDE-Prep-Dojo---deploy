Clarify the requirements

Atlassian interviewers reveal requirements one at a time. Ask enough to get stage 1 exactly right, write the tests, make them pass, then ask "what next?". The staged list below is how the round usually grows.

Functional, by stage

  1. Stage 1: rate and rank rate(agentId, stars) with stars an integer 1 to 5; averages() returns every rated agent with their average, highest first.
  2. Stage 2: ties When averages are equal, order deterministically. Our default: more ratings first (more evidence), then agent id A to Z. The policy must be swappable.
  3. Stage 3: per month Every rating has a date. bestOfMonth(2025-01) returns that month's ranking; topAgents(month) returns all agents tied for first.
  4. Stage 4: export Return a ranking as CSV or JSON, without the service knowing either format.
  5. Stage 5: concurrency Many ratings arrive at once from many support sessions; no rating may be lost.

Non-functional

  • Exact averages: store sum and count, never the average; display rounded half-up to 2 decimals.
  • Fast writes: rate is O(1). Ranking is O(n log n) on read, which is fine for thousands of agents.
  • Deterministic output: the same ratings always give the same order (tests depend on it).
  • Testable: each stage has its own tests that keep passing as later stages land.

Out of scope (say it out loud)

Who is allowed to rate (one rating per ticket), authentication, storage, and showing the ranking in a UI. Mention them as follow-ups.

Questions to ask

  • Are ratings integers only, 1 to 5? Is 0 allowed? (Integers 1 to 5; anything else is rejected.)
  • Should agents with no ratings appear in the list? (We list only rated agents; listing all onboarded agents with "no ratings" at the bottom is a small change.)
  • How should ties be ordered? (Ask, then make it a policy object, so the answer does not matter.)
  • How many decimals for display, and which rounding? (Two, half-up.)
  • For "per month", whose time zone? (Use the date the caller passes; the caller converts.)
  • Do we ever need to remove or change a rating? (If yes, keep the raw ratings or support "subtract", which sum/count makes easy.)
