The 60-90 minute plan

Atlassian gives 60 minutes; Razorpay-style machine coding gives 90. The plan below is for 60, with the extra 30 at the end for a 90-minute round.

MinutesDoCheckpoint
0-5Ask the stage 1 questions: integer stars? which agents appear? decimals? Say "I will store sum and count, not the average".Agreed stage 1
5-10Write three failing tests: highest first, 5+4 = 4.50, invalid stars rejected.Red tests
10-20Stats, AgentScore, RatingService.rate and averages with a comparator.Stage 1 green
20-28Stage 2: ask the tie rule, add the test, add Rankings.DEFAULT, inject it.Stage 2 green, stage 1 still green
28-42Stage 3: add the date parameter (overload for old tests), the month buckets, bestOfMonth, topAgents, and their tests.Stage 3 green
42-52Stage 4: Exporter interface, CSV with quoting, JSON.Stage 4 green
52-60Talk through concurrency (compute, LongAdder), Bayesian average, top-k. Write the concurrency test if time allows.Discussion
60-90 (90-min rounds)Concurrency test, unrated agents, edit a rating, a driver that prints every stage, README of assumptions.Submitted

More on running the round: the machine-coding round guide in the interview section, and the Atlassian guide for how the code-design round is scored.
