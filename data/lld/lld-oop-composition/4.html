Refactor walkthrough: replace inheritance with delegation

In a machine-coding round you will sometimes start with inheritance and need to back out. The standard refactoring is called Replace Inheritance with Delegation. Do it in small steps so the code compiles after each one:

  1. Add a field of the parent type to the subclass and initialise it: private final Inventory inv = new Inventory();
  2. Redirect each method the subclass uses to that field: public void add(String i) { added++; inv.add(i); }. Replace every super.x() with inv.x().
  3. Remove extends. Anything that called an inherited method you did not forward now fails to compile, which shows you exactly which methods the class really needs to offer.
  4. Extract an interface (Store) for the methods clients use, so the wrapper and the original can still be used interchangeably.
  5. Inject the part through the constructor (CountingStore(Store inner)) instead of creating it inside. Now it wraps any Store, and tests can pass a fake.

Tip: forwarding methods are boilerplate. Languages help: Kotlin has class CountingStore(inner: Store) : Store by inner, and IDEs can generate delegate methods for Java. In Python a wrapper can forward unknown attributes with __getattr__. In an interview, write only the forwarders you need and say the rest would be generated.
