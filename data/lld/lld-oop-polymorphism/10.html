Remember this

  • Overloading = same name, different parameters, picked by the compiler from declared types. Zero run-time cost.
  • Overriding = same signature in a subclass, picked at run time from the real object.
  • Under the hood: one vtable per class (array of function pointers), one hidden vptr per object, a call = two loads + an indirect call. It is file_operations generated by the compiler.
  • Java methods are virtual by default; C++ only with virtual. Static, private and final methods and all fields are not polymorphic.
  • Polymorphic C++ base classes need a virtual destructor. Never call overridable methods from constructors.
  • Two runtime types need double dispatch (accept + visit), the core of Visitor.
  • In LLD, replace repeated switch (type) with polymorphism when new types keep coming; use a sealed switch when the types are fixed.
