Quiz

In Java, Object o = "hi"; describe(o); with overloads describe(Object) and describe(String). Which runs?

  1. describe(String), because o holds a String
  2. describe(Object), because overloads are chosen from the declared type
  3. It does not compile: the call is ambiguous
Overload resolution happens at compile time using the static type of the argument, which is Object.

Where is the vtable for a C++ class usually stored?

  1. Inside every object, after the fields
  2. On the stack of the caller
  3. Once per class, in read-only data; each object holds only a pointer to it
One table per class is shared by all its objects; each object carries a vptr.

A C++ base class has a non-virtual destructor. You run Base* p = new Derived; delete p;. What does the standard say?

  1. Undefined behaviour; in practice the Derived destructor usually does not run
  2. Both destructors always run
  3. Compile error
Without a virtual destructor the call is bound to ~Base statically. The standard makes it undefined behaviour.

A base-class constructor in C++ calls virtual kind(). The object being built is an Ethernet. Which kind() runs?

  1. Ethernet::kind
  2. NetDevice::kind (the base version)
  3. Neither; it is a compile error
During the base constructor the vptr points at the base table. In Java the answer would be the subclass version, running on uninitialised fields.

Which of these Java methods can be overridden?

  1. A static method
  2. A private method
  3. A public non-final instance method
Static methods are hidden, private methods are not inherited, final methods are locked. Only non-static, non-private, non-final instance methods dispatch dynamically.

Why does the Visitor pattern need accept()?

  1. Because overloads are picked from static types, so a first virtual call is needed to learn the element's real type
  2. Because interfaces cannot have more than one method
  3. To make the visitor thread-safe
accept() is the first dispatch. Inside it, this has a known static type, so visit(this) picks the right overload, and the call on the visitor is the second dispatch.

Python defines parse(self, data: bytes) and then parse(self, data: str) in the same class. What happens?

  1. Python picks the right one by argument type
  2. The second definition replaces the first
  3. SyntaxError
Python has no overloading; a class body is a namespace and the later def wins. Use functools.singledispatch(method) for type-based dispatch.
