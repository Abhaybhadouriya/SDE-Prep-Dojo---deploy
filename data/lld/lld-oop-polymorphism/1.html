Two kinds of polymorphism

Every language that has polymorphism has to answer one question for every call: which piece of code runs? The answer can be decided at two moments.

  • Compile time (static polymorphism). The compiler picks the code while building the program. Examples: method overloading (several methods with the same name but different parameter lists), operator overloading in C++, and templates/generics. Also called early binding.
  • Run time (dynamic polymorphism). The program picks the code while running, by looking at the real object. Example: method overriding (a subclass replaces a method it inherited). Also called late binding or dynamic dispatch.
