Clarify the requirements

Spend 5 minutes here and write the list down. Interviewers grade "asked the right questions" as a separate box (see the 8-step framework).

Functional (P0)

  1. Setup Create a game with a board size N (default 3) and two or more players, each with a name and a unique symbol.
  2. Turns Players move in a fixed round-robin order. A move names the player and a cell (row, column).
  3. Validation Reject a move if the game is over, it is not that player's turn, the cell is off the board or the cell is taken. A rejected move changes nothing and the same player plays again.
  4. Win A player wins when they fill a whole row, column or one of the two diagonals.
  5. Draw When the board is full and nobody has won, the game is a draw.
  6. Display Print the board; report the state (in progress, won by X, draw).

P1 (only after P0 runs)

  • Undo the last move (and redo, if asked).
  • K in a row wins on a bigger board (Gomoku-style), instead of a full line.
  • Computer player (random, or a simple "win, else block, else centre" rule).
  • Replay / history of moves; a scoreboard across several games.

Non-functional

  • Fast win check: O(1) per move for full-line rules, not a scan of the whole board.
  • Extensible: board size, player count and win rule are parameters, not constants spread over the code.
  • Testable: the game is driven by method calls; console input is a thin layer on top.
  • Safe under concurrency if two clients (a web version) send moves at the same moment.

Out of scope (say it)

Graphics, networking, accounts, persistence and matchmaking. In a web version they sit in front of the same Game class (see the Atlassian follow-up in the Q&A).

Questions to ask

  • Board always 3 x 3, or N x N? Always 2 players, or more?
  • Does a win need a full line, or K in a row on a bigger board?
  • Who moves first? Can players choose symbols?
  • What happens on an invalid move: an error, or "Invalid Move" and the same player again?
  • Input as method calls or console commands? 0-based or 1-based cells?
  • Do we need undo, a computer player or a scoreboard now, or only later?
