  • Three classes with one job each: Board (cells), WinStrategy (winning), Game (turns, state, history).
  • O(1) win check: per-player counters for rows, columns and the two diagonals; a counter equal to N wins.
  • Two players: one signed counter per line (+1 / -1); k players: one set per player.
  • K in a row: walk 4 directions from the last move, O(K); swap the strategy, not the game.
  • Validate first (state, turn, bounds, empty), then mutate; check win before draw.
  • Undo = pop the Move, roll back the counters, clear the cell, give the turn back.
  • Code 3 x 3 first, but never hard-code 3.
