Common mistakes

  • Scanning the whole board after every move, and not knowing the complexity.
  • Hard-coding 3 in loops, diagonal checks and the draw count (9), so N x N is a rewrite.
  • Checking draw before win, so a game won on the last cell is reported as a draw.
  • Switching the turn before validating, so an invalid move skips a player.
  • Game logic in the input loop: Scanner or input() calls inside Game, which makes it impossible to test.
  • Printing from Board/Game instead of returning a state and letting the driver print.
  • A PieceX / PieceO hierarchy with no behaviour, or a singleton GameManager.
  • Undo that forgets the counters, so the next win is missed.
