Latches and barriers: waiting for a group

A CountDownLatch starts at a count. Any thread can call countDown(); threads in await() sleep until the count reaches zero. It is one-shot: once open, it stays open. Two common uses:

CountDownLatch start = new CountDownLatch(1);       // a starting gun
CountDownLatch done  = new CountDownLatch(workers); // a finish line

for (int i = 0; i < workers; i++) Thread.ofPlatform().start(() -> {
    try { start.await(); doWork(); }
    catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    finally { done.countDown(); }                   // count down even on failure
});
start.countDown();   // release all workers at the same moment (great for race tests)
done.await();        // main waits until every worker has finished

In the kernel, struct completion is a latch you can re-arm (reinit_completion()); complete_all() is the count reaching zero.
