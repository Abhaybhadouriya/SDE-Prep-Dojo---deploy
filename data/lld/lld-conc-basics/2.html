Six words to get straight first

WordMeaningExample
Shared mutable stateData that more than one thread can reach and that someone changes. No sharing or no mutation means no race.A seatsLeft field on a singleton Show object
Critical sectionA block of code that touches shared mutable state and must not interleave with another thread doing the same.Check seat, then mark booked
Race conditionThe result depends on the timing of threads. A logic bug about what interleaving happens.Two bookings of the last seat
Data raceA Java Memory Model (JMM) term: two threads access one variable, at least one writes, and nothing orders them (no happens-before edge; defined below: a rule that guarantees one thread sees another's writes). You can have a race condition with no data race (everything locked, but in pieces too small).Unsynchronised count++
AtomicityA group of steps happens as one indivisible step: other threads see all of it or none of it.AtomicInteger.incrementAndGet()
Visibility and orderingWhether, and in what order, one thread's writes become observable to another thread.A worker that never sees stop = true

And the goal word. A class is thread-safe if it behaves correctly when used from many threads, with no extra synchronisation needed from the callers, whatever the scheduling.

Two words you will meet before the locks page defines them. A monitor is the lock built into every Java object; synchronized (obj) takes obj's monitor. To park a thread is to block it in the OS until it is woken, like calling schedule() after setting the task state to sleeping. There is no Java spinlock in the kernel sense; the closest is a busy loop on an AtomicBoolean. The full mapping, with C code, is near the end of this page.
