Remember this

  • Simple Factory = one function that maps a key to a concrete class and returns the interface.
  • It is an idiom, not GoF. The GoF cousins: Factory Method (subclass decides) and Abstract Factory (matching family).
  • The win: callers stop depending on concrete classes; creation and validation live in one place.
  • A growing switch breaks Open/Closed; a registry map of makers fixes it.
  • Unknown key: throw once, clearly. Never return null.
  • Static is fine for a quick round; inject the factory when you need tests or configuration.
  • Kernel twin: name-to-object registries such as the crypto API and TCP congestion control by name.
