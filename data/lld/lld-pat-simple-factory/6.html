Real-world uses

WhereWhat the "key" isWhat you get back
Java NumberFormat.getInstance(locale), Calendar.getInstance()a localea locale-specific subclass behind the abstract type (for Calendar, usually GregorianCalendar)
Java Charset.forName("UTF-8")a charset name or aliasa Charset found among the built-in and provider-registered charsets
Java Executors.newFixedThreadPool(n), List.of(...)the method name and argumentsan ExecutorService / immutable List; the concrete class is hidden and may change between JDK versions
JDBC DriverManager.getConnection(url)the URL prefix (jdbc:postgresql:)a Connection from whichever registered driver accepts that URL
Python built-in open(path, mode)the mode string and bufferinga TextIOWrapper, BufferedReader, BufferedWriter or raw FileIO
Python codecs.lookup("utf-8")an encoding namea CodecInfo from registered search functions (a registry)
Linux crypto API crypto_alloc_skcipher(name, ...)an algorithm name such as "cbc(aes)"a cipher handle from registered algorithms; the core may load a module to find it
Linux TCP congestion control by name"cubic", "bbr"the registered tcp_congestion_ops (a Strategy object, created by name)

Notice that the Java "static factory method" idea (a named static method instead of a public constructor, such as List.of or Integer.valueOf) is a close cousin. It may hide the concrete class, cache instances, or pick a subclass by argument. Joshua Bloch's Effective Java opens with it as item 1. It is not the GoF Factory Method either, which confuses many candidates.
