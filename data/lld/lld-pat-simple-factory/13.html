Quiz

In a correct Simple Factory, which classes does the client depend on?

  1. The factory and every concrete product
  2. The factory and the product interface only
  3. Only the concrete product it needs
The client sees the factory and the interface. Only the factory names the concrete classes.

Which statement about Simple Factory is true?

  1. It is one of the 23 GoF patterns
  2. It requires a subclass per product
  3. It is an idiom; the GoF factory patterns are Factory Method and Abstract Factory
GoF has Factory Method and Abstract Factory. Simple Factory is a named coding habit and needs no inheritance.

New vehicle types arrive every sprint. What is the best change to the switch-based factory?

  1. Replace the switch with a registry of maker functions
  2. Copy the switch into each caller so teams can edit their own
  3. Return null for unknown types
A registry lets new types plug in without editing create(), keeping the factory closed to modification.

The factory gets the key "spaceship". What should happen?

  1. Return a default Car
  2. Throw a clear exception from the factory
  3. Return null and let the caller check
Fail fast in one place. Silent defaults hide bugs; nulls crash far away.

Which problem is NOT a Simple Factory problem?

  1. Choose a payment processor from the request's payment mode
  2. Create the right appender from a logger config entry
  3. Build a pizza with ten optional toppings and validate it at the end
Many optional parts with final validation is a Builder problem. The other two pick a class from a key.

crypto_alloc_skcipher("cbc(aes)", 0, 0) is closest to which variant?

  1. A registry-map simple factory: a name is looked up among registered algorithms
  2. Factory Method: a subclass overrides a create hook
  3. Abstract Factory: it returns a family of matched objects
Algorithms register themselves; the caller passes a name and gets a handle. That is the registry variant.
