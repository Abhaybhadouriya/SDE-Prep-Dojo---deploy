Level 4: threads, testing and cost

  • Threads. A switch factory has no state, so it is safe. A registry is a shared map: fill it in main() before threads start, or use a ConcurrentHashMap if types can be registered while lookups run (like a kernel registry guarded by a lock or RCU).
  • Testing. Table-driven tests: every key returns the right type, and an unknown key fails loudly. With a registry, a test can register a fake type without touching the factory.
  • Cost. One string compare chain or hash lookup per create, which is noise next to allocating the object. The real cost is the edit-on-every-new-type switch, which the registry removes.
