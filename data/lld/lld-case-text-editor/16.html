Common mistakes

  • Rebuilding a String per keystroke, or a linked list of characters, with no complexity argument.
  • Snapshotting the whole document per edit for undo, without noticing the memory cost.
  • Undo that restores the text but not the cursor.
  • Putting cursor moves into the history, so undo first walks the cursor around.
  • Not clearing redo after a new edit, which lets redo apply an edit to text it never saw.
  • Up/down without a goal column, or crashing on the first and last lines.
  • Replace-all applied left to right with stale offsets, or as N separate undo steps.
  • A switch on "action type" in undo() instead of polymorphic commands.
  • No edge cases: backspace at 0, empty search, empty history.
