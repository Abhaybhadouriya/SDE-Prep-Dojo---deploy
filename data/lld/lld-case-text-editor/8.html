APIs and interfaces

interface EditCommand {               // Command: one edit, with its inverse
    int  execute(Document d);         // apply; return the new cursor
    void undo(Document d);            // exact inverse of execute
}

// Editor: what the key handler calls (all synchronized)
void type(String s);                  // insert at cursor; single keys are grouped per word
void backspace(); void deleteForward();
int  replaceAll(String find, String with);   // one undo step; returns the match count
boolean undo(); boolean redo();       // false when there is nothing to do
void left(); void right(); void home(); void end();
void up(); void down(); void pageUp(); void pageDown();
Snapshot save(); void restore(Snapshot s);   // memento checkpoint; restore is undoable
String text(); int cursor(); String where();  // "line:col", 1-based

Notice what is not public: the gap buffer, the stacks and the command classes. A UI, a test or a macro recorder all drive the same small surface. For the TextPad variant add display(n, m), insertLine(n, text), deleteLines(n, m), copy(n, m) and paste(n); each mutating one is one more Command built from Insert and Delete.
