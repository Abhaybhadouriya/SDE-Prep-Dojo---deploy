Evaluator rubric checklist

  • Buffer choice justified with complexity: gap buffer or rope, not a String rebuilt per key.
  • Command pattern for edits, each with an exact inverse; undo code does not know concrete edit types.
  • Two stacks, redo cleared on a new edit, bounded history.
  • Cursor restored on undo; moves not in the history.
  • Up/down correct on lines of different length (goal column), page keys stop at the ends.
  • Compound edits (replace-all) undo in one step; offsets handled right to left.
  • Sensible grouping of typed characters, or at least a clear answer for it.
  • Edge cases: empty text, start and end of text, empty search, no matches.
  • Separation: buffer, document, commands, editor facade, rendering (Flyweight) are distinct.
  • Working demo and tests; thread-safety and collaboration answered at the right depth.
