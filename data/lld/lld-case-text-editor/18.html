Quiz

You type "a", "b", undo, then type "c". What does redo do now?

  1. Re-inserts "b" after "c"
  2. Re-inserts "b" before "c"
  3. Nothing: the new edit cleared the redo stack
  4. Undoes "c"
A new edit starts a new branch of history; the undone "b" no longer applies to the current text.

Why is typing at the cursor O(1) in a gap buffer?

  1. Characters are stored in a hash map
  2. The free space sits at the cursor, so new characters fill it without moving others
  3. The array is sorted
  4. It copies the whole array once per keystroke
Only moving the cursor far away moves the gap; growth is amortised by doubling.

The cursor is at column 12 of line 3. Line 2 has 2 characters, line 1 has 11. You press up twice. Where are you?

  1. Line 1, column 3
  2. Line 2, column 12
  3. Line 1, column 1
  4. Line 1, column 12 (end of line), thanks to the goal column
The first up clamps to line 2's end; the goal column 12 is kept and used for line 1.

Why does replace-all apply its edits from the last match to the first?

  1. An edit only shifts text after it, so earlier offsets stay valid
  2. It is faster for the CPU cache
  3. To find more matches
  4. Undo requires it
Left to right would need every later offset adjusted by the length difference.

Which is the best reason to prefer Command over Memento for text undo?

  1. Command is always simpler to write
  2. History memory grows with the size of the edits, not the size of the document
  3. Memento cannot restore the cursor
  4. Command needs no inverse
A snapshot per keystroke of a 10 MB file is 10 MB per key; a command is a few bytes.

In the Flyweight glyph design, which state is extrinsic?

  1. The character code
  2. The font
  3. The row and column where it is drawn
  4. The style
Position differs for every occurrence, so it is supplied at draw time, not stored in the shared glyph.
