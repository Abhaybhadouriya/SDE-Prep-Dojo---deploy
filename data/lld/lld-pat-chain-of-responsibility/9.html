Related and confused-with patterns

Compared withLooks similar becauseThe difference
DecoratorBoth are a linked series of objects with the same interface, each holding the nextA decorator always forwards and adds behaviour around the call. A CoR handler may stop the request. Middleware frameworks blur the line: a layer that always calls next is a decorator; one that can reject is a chain.
ObserverMany objects receive the same thingObserver broadcasts to all subscribers, none can stop the others, and order should not matter. CoR walks in a defined order and can stop.
CommandRequests as objectsCommand makes the request an object; CoR decides who handles it. The thing travelling down a chain is often a command.
CompositeParent linksIn a tree (GUI widgets, file system), "pass the event to my parent" is a chain built from Composite's parent pointers: event bubbling.
StateATM againThe ATM as a whole is usually modelled with State (idle, card inserted, PIN ok, dispensing); the cash dispenser inside it is the chain. Using both is a strong answer.
