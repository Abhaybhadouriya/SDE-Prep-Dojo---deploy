Real-world uses

WhereHandlersHow a handler stops the chain
Java servletsFilter objects in a FilterChainDo not call chain.doFilter(); write a response instead
Spring SecurityA SecurityFilterChain of filters (authentication, CSRF, authorization...)A filter rejects the request (for example 401 or 403)
java.util.loggingA Logger passes records to its handlers, then to its parent logger's handlersPass-through; turn it off with setUseParentHandlers(false)
Python loggingLogger hierarchy with propagate to ancestorsPass-through; propagate = False stops it
Web middlewareExpress, Django, ASGI/WSGI middleware layersReturn a response without calling the next layer
LinuxNetfilter hooks, notifier chainsNF_DROP/NF_STOLEN; NOTIFY_STOP
GUI toolkitsEvent bubbling: a click goes from the button to its parent panel to the windowA handler marks the event consumed (DOM: stopPropagation())
API gatewaysAuth, rate limit, transform, route pluginsReject at the edge before reaching a backend
