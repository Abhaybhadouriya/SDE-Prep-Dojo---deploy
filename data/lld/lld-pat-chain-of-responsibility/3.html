Structure: a linked list of handlers

  • Handler: declares handle(request) and holds a reference to the next handler. A base class usually supplies the default "pass it on" behaviour.
  • ConcreteHandler: does its one check or job. Then it either returns a result (stop) or calls the next handler (pass on).
  • Client: builds the chain (the order is a configuration decision) and sends requests to its head.

A chain does not have to be a linked list. Many frameworks keep the handlers in an array and an index, and a "chain" object moves the index forward (servlet FilterChain.doFilter() works like this; netfilter keeps an array of hook entries per hook point). The C++ tab below uses a sorted vector.
