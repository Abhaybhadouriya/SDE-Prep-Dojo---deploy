Quiz

A method uses five fields of Customer and none of its own class. Which smell and cure?

  1. Long Method - Extract Method
  2. Feature Envy - Move Method
  3. Lazy Class - Inline Class
Feature Envy: move the method to the class whose data it uses (Information Expert).

Which group does Shotgun Surgery belong to?

  1. Bloaters
  2. Dispensables
  3. Change Preventers
One change forces edits in many classes - it prevents easy change.

What must be true after every refactoring step?

  1. Tests pass and behaviour is unchanged
  2. The code is shorter
  3. A new design pattern has been added
Refactoring preserves behaviour; length and patterns are not the goal.

An order's status int changes from NEW to PAID to SHIPPED, and every method checks it. Best refactoring?

  1. Replace Conditional with Polymorphism using a subclass per order type
  2. Replace Type Code with State
  3. Introduce Parameter Object
The type changes at runtime, so the object needs swappable state objects, not fixed subclasses.

search(city, from, to, min, max) becomes search(RoomQuery q). Which refactoring?

  1. Extract Method
  2. Hide Delegate
  3. Introduce Parameter Object
Grouping parameters into an object, which then gains validation and behaviour.

Hide Delegate has gone too far: a class has 20 methods that only forward. Which smell is that, and what is the cure?

  1. Middle Man - Remove Middle Man
  2. Message Chains - Hide Delegate
  3. Data Class - Move Method
Refactorings come in opposite pairs; too much delegation is the Middle Man smell.

You notice a bug halfway through refactoring. What first?

  1. Fix it inside the same change
  2. Get back to green with behaviour unchanged, then fix the bug separately with a failing test
  3. Ignore it
The two-hats rule keeps each change reviewable and revertable.

Which is generally NOT a smell?

  1. The same type switch in four methods
  2. Money stored as double
  3. One switch inside a factory that creates the right object once
A single, central decision point is fine; repeated decisions are the smell.
