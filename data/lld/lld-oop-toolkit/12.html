Remember this

  • A Java enum is a class with a fixed set of instances. Put data and behaviour on the constants; use EnumMap/EnumSet; store name(), never ordinal().
  • Enum = closed set. If the set grows over time, use an interface and polymorphism (OCP).
  • One unchecked DomainException with an error code, a few specific children, caught once in the driver.
  • Optional is for return values of lookups. Empty list for "none" in collections.
  • Value objects (Money, Location, Slot) are immutable records; money is an integer of paise.
  • Immutable = final class, private final fields, no setters, copy in, copy (or unmodifiable) out.
  • Override equals and hashCode together, from the same fields; never mutate a key in a map.
  • Generic repository InMemoryRepo<ID, T extends Identifiable<ID>>; PECS for wildcards; erasure means no new T().
  • Comparators are ordering strategies; chain with thenComparing, add an id tie-breaker for TreeSet/TreeMap.
