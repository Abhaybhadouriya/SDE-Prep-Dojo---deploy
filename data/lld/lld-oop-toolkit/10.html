Bonus: sealed interfaces and pattern matching (Java 17-21)

Between a closed enum and an open interface sits the sealed interface: a fixed list of implementing classes, each with its own fields. With Java 21 switch pattern matching the compiler checks that you handled every case, like an enum switch.

sealed interface Payment permits Upi, Card, Wallet {}
record Upi(String vpa) implements Payment {}
record Card(String last4, int cvvLen) implements Payment {}
record Wallet(String walletId) implements Payment {}

static String describe(Payment p) {
    return switch (p) {                       // no default needed: the compiler knows all three
        case Upi u    -> "UPI " + u.vpa();
        case Card c   -> "card ending " + c.last4();
        case Wallet w -> "wallet " + w.walletId();
    };
}

Use it when the variants are fixed and carry different data (a tagged union, like a C struct with a type field and a union, but checked). If new variants will keep arriving, prefer a plain interface plus polymorphism.
