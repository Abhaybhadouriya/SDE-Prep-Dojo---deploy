From kitchen habits to Java tools

The seven kitchen habits map one-to-one to Java tools. This page takes them in this order:

Kitchen habitJava toolWhat it prevents in your design
Labelled jars, fixed kindsRich enumMagic strings and ints ("CAR", 2), typos, invalid values
One kind of leftover boxGenericsCopy-pasted UserRepo, SpotRepo, OrderRepo, and casts
Smoke alarm that names the panCustom exceptionsSilent failures, return -1, return null, swallowed errors
"Maybe there is no milk" written on the listOptionalNullPointerException three calls later
Laminated listRecords and immutabilityShared state changed behind your back; thread races
Name tags on jarsequals / hashCodeDuplicate keys, lookups that "randomly" fail in a HashMap
The fridge queue ruleComparable / ComparatorHand-written sort loops, wrong allocation order

Graders say this out loud. Flipkart's 2026 machine-coding guideline lists entity modelling, abstractions, exception handling and edge cases that "fail gracefully" among the scoring points (LeetCode Discuss post, 2026-02-18). A PhonePe problem statement asks that "exceptions should be gracefully handled" and also scores "language proficiency" (post, 2025-02-18). These tools are how you score those points in 90 minutes.
