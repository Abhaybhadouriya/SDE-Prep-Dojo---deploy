How it works: one for-each loop, step by step

What really happens when Java runs for (String s : playlist) print(s); on a playlist of three songs:

  1. The compiler turns the for-each into a call to playlist.iterator(). The loop never touches the array.
  2. The playlist builds a fresh iterator. It starts at position 0 and remembers the playlist's version number (modCount) at this moment.
  3. Before every pass the loop asks hasNext(). The iterator compares its cursor with the size.
  4. next() first checks that the version has not changed, then returns the element and moves the cursor. Only the iterator knows the storage is an array.
  5. The loop body runs with that element. Steps 3 and 4 repeat for the second and third song.
  6. When the cursor reaches the size, hasNext() says false and the loop stops. The same loop would work unchanged if Playlist switched to a linked list.
