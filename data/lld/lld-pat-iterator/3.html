Structure: four participants

  • Iterator (java.util.Iterator): the walking interface. Minimum is hasNext() and next(); some add remove(), peek() or reset().
  • ConcreteIterator (Playlist.Forward): holds the position (an index, a node pointer, a stack for a tree, a page token for an API). Usually an inner class, so it can see private fields.
  • Aggregate (java.lang.Iterable): declares iterator(). Anything that implements it works in a for-each loop.
  • ConcreteAggregate (Playlist): owns the data and returns fresh iterators. iterator() is a Factory Method: each collection decides which iterator class to build.

Python names the same roles differently: the aggregate has __iter__(), the iterator has __next__() and signals the end by raising StopIteration instead of a hasNext() check. C++ uses a pair of iterator objects, begin() and end(), and the loop runs while it != end.
