Real-world uses

WhereIteratorNotes
JDKIterable / Iterator, ListIteratorEvery collection; for-each is compiler sugar over iterator(). ListIterator adds previous(), set(), add().
JDKSpliterator, StreamA "splittable iterator" that can hand half its range to another thread; streams are internal iteration built on it.
JDKScanner, ResultSet, DirectoryStreamIterators over input tokens, database rows and directory entries.
PythonIterator protocol, generators, itertoolsfor, unpacking, zip, enumerate all use __iter__/__next__. itertools.chain, islice, groupby combine iterators lazily.
C++STL iteratorsAlgorithms are written against iterator categories (input, forward, bidirectional, random access), not containers.
Linux kernellist_for_each_entry[_safe|_rcu](), hlist_for_each_entry()Macro iterators over intrusive lists; the _rcu form lets readers walk while writers update.
Linux kernelseq_file (start/next/stop/show)An iterator interface in an ops table, used by many /proc and debugfs files.
Databases and APIsCursors, page tokensA SQL cursor or a REST next_page_token is an external iterator over a result too big to load at once.
