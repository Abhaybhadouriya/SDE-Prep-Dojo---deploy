Quiz

What is the defining purpose of a Proxy?

  1. Convert one interface into another
  2. Control access to an object while keeping its interface
  3. Simplify a large subsystem
  4. Create families of related objects
Converting is Adapter, simplifying is Facade, families is Abstract Factory.

An image viewer shows a grey box and loads the real image only when it scrolls into view. Which proxy?

  1. Protection
  2. Remote
  3. Virtual
  4. Smart reference
Delaying creation of an expensive object until it is needed is a virtual proxy.

Inside a Spring bean, method a() calls this.b(), where b() is @Transactional. What happens?

  1. No transaction starts for b(), because the call does not pass through the proxy
  2. A new transaction starts for b()
  3. Spring throws an exception
  4. The call is retried
this is the real object. Only calls arriving through the proxy are intercepted.

java.lang.reflect.Proxy.newProxyInstance can proxy:

  1. Any class
  2. Only final classes
  3. Only abstract classes
  4. Only interfaces
JDK dynamic proxies implement interfaces. For concrete classes frameworks generate subclasses with CGLIB or ByteBuddy.

The rate-limit proxy is placed in front of the caching proxy. What does that mean?

  1. Only real calls to the vendor are counted
  2. Cache hits also use up the limit
  3. The cache is bypassed
  4. Nothing; order never matters
Every call passes the limiter first, hit or miss. Swap the order to count only real calls.

Which is a protection proxy in the JDK?

  1. BufferedInputStream
  2. InputStreamReader
  3. Collections.unmodifiableList
  4. ArrayList
Same List interface, but write methods are refused. The first two are a decorator and an adapter.

Biggest risk of a remote proxy?

  1. Callers treat a network call as a cheap local call and forget timeouts, retries and partial failure
  2. It uses too much memory
  3. It cannot be tested
  4. It changes the interface
Hiding the network is the feature and the danger. Make remoteness visible and always set deadlines.
