Intent

Proxy (GoF structural pattern, also called Surrogate): in our words, put a stand-in object in front of a real one so you can decide when, whether and how the real one is reached. The proxy has the same interface as the real object, so the client cannot tell them apart.

The key word is control. A proxy does not change the interface (that is Adapter) and its purpose is not to pile on new features (that is Decorator). It decides when the real object is created, whether a call is allowed, where the call actually runs, or whether the real object is needed at all.

The kinds of proxy

KindControlsExample
VirtualWhen the real object is created (lazy)Hibernate lazy-loaded entity, image placeholder until scrolled into view, mmap pages
