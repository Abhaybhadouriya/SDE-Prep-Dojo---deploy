Quiz

What is the core intent of Composite?

  1. Add behaviour to one object at runtime
  2. Convert one interface into another
  3. Let clients treat single objects and groups of objects uniformly in a tree
  4. Share many small objects to save memory
Part-whole trees with one interface. Adding behaviour is Decorator, converting is Adapter, sharing is Flyweight.

Which type should a Directory's children list hold?

  1. List<File>
  2. List<Node> (the Component)
  3. List<Object>
  4. List<Directory>
Holding the Component type lets a directory contain files and other directories, to any depth.

In the "transparent" variant, what happens when you call add() on a leaf?

  1. It does not compile
  2. It adds the child to the parent instead
  3. It turns the leaf into a composite
  4. It throws or does nothing at run time
Transparency puts add() on the Component, so the error moves from compile time to run time.

Before adding folder C under folder P, which check prevents a cycle?

  1. Walk up from P to the root and refuse if you meet C
  2. Check that C is empty
  3. Check that P has no parent
  4. Check that the names differ
If C is an ancestor of P, adding C under P would make C its own descendant.

A Decorator differs from a Composite mainly because a Decorator:

  1. Has a different interface from its component
  2. Wraps exactly one component to add behaviour, rather than combining many children
  3. Cannot be nested
  4. Is created only by a factory
Both share the "is a Component, holds a Component" structure. Fan-out and intent differ.

Root size() on a huge tree is called very often. The best fix is:

  1. Make every file a singleton
  2. Use transparency instead of safety
  3. Cache totals in each directory and update ancestors when a file changes
  4. Flatten the tree into one list
O(1) reads, O(depth) updates, keeps the tree structure.

Which Linux structure is the clearest Composite?

  1. struct sk_buff
  2. A spinlock
  3. The syscall table
  4. The dentry tree, with a parent and children per entry
Files and directories are all dentries in one tree, walked uniformly.
