APIs and interfaces

sealed interface Request permits HallCall, CarCall { void execute(ElevatorController c); }
record HallCall(int floor, Direction direction) implements Request { ... }
record CarCall(int elevatorId, int floor) implements Request { ... }

interface MovementPolicy   { boolean continueAhead(Elevator e, Direction d); }
interface DispatchStrategy { Optional<Elevator> choose(List<Elevator> candidates, HallCall call); }
interface ElevatorState    { ElevatorState tick(Elevator e); String name(); }
interface ElevatorListener { default void onDispatch(int t, HallCall c, Elevator e) {} /* onMove, onDoorsOpen, onStateChange */ }

class ElevatorController {
    ElevatorController(int minFloor, int maxFloor, DispatchStrategy dispatch);
    Elevator addElevator(int startFloor, MovementPolicy policy);
    void addListener(ElevatorListener l);
    void submit(Request r);           // any thread; IllegalArgumentException for a button that does not exist
    void tick();                      // controller thread only: run commands, retry unassigned calls, step every car
    int  runUntilIdle(int maxTicks);  // for tests and the demo
}
class Elevator {
    boolean addCarCall(int floor);    // false if the car is going out of service
    void requestMaintenance();        // finish current stops, then OUT_OF_SERVICE
    void endMaintenance();
}

If the interviewer wants a service API: POST /floors/{f}/calls {direction}, POST /elevators/{id}/calls {floor}, POST /elevators/{id}/maintenance, and a push channel (WebSocket or server-sent events) for displays, which is the Observer moved over the network. See API design for LLD.
