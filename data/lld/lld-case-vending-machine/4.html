This table is the whole design. Its 30 cells are what a switch(state) version spreads over six methods; the State pattern puts each column into one class, so adding a state (say OUT_OF_SERVICE after a jam) is a new class with six short methods, not edits in six switches. The default answer for every cell is "refuse", so each state only overrides the events it accepts.
