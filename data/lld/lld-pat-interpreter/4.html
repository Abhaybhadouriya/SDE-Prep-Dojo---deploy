How it works: one rule, one user

  1. The client calls tree.interpret(ctx) on the root And. It does no work itself; it asks its left child.
  2. The terminal age >= 18 reads age from the context: 31, so true. Because the left side is true, And must also ask the right side.
  3. The Or node asks its left child, city == BLR. Ravi is in DEL, so false; Or keeps going.
  4. vip == true is true, so Or returns true. (Had the first child been true, || would have short-circuited and skipped it.)
  5. And combines true and true and returns true. The same tree can now be interpreted for a million users without re-parsing.
