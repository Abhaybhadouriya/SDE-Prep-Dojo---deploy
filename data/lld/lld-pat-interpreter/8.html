Related and confused-with patterns

Compared withLooks similar becauseThe difference
CompositeA tree of nodes with a shared interfaceInterpreter is a Composite whose shared operation is "evaluate". Composite is the shape; Interpreter adds the meaning of a grammar.
VisitorBoth operate on expression treesInterpreter puts the operation inside each node. Visitor moves operations out, which is better once there are several.
SpecificationComposable and / or / not predicatesSpecification is built in code by developers. Interpreter adds a text grammar and a parser so rules can arrive as data.
StrategySwappable behaviourA Strategy is one pre-written algorithm. An interpreted rule is a new behaviour assembled at runtime from small parts.
FlyweightSharing nodesTerminal nodes (constants, the tcp test) can be shared between trees as flyweights.
