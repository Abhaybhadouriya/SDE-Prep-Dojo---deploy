Structure: a Composite that can evaluate itself

  • AbstractExpression (Expr): declares interpret(context).
  • TerminalExpression (Compare, Num, Var): a leaf; reads the context and returns a value.
  • NonterminalExpression (And, Or, Not, BinOp): one class per grammar rule; interprets its children and combines the results.
  • Context: the variables, the user record, the packet. Passed down unchanged.
  • Client / Parser: builds the tree. The GoF pattern does not say how to parse; in practice you write a small recursive-descent parser, one method per grammar rule.
