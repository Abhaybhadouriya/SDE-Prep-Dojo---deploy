Resources

  • Yagni (martinfowler.com) blog - the four costs of presumptive features and what YAGNI does not cover.
  • Tell Don't Ask (martinfowler.com) blog - putting behaviour with data, and its limits.
  • Beck Design Rules (martinfowler.com) blog - the four rules of simple design in priority order.
  • The Wrong Abstraction (Sandi Metz) blog - why a bad shared helper is worse than duplication, and how to back out.
  • The Pragmatic Programmer, 20th anniversary edition book - origin of DRY (official book page).
  • Law of Demeter (Northeastern University) doc - the original Demeter project page.
  • refactoring.guru: Message Chains, Middle Man, Speculative Generality, Duplicate Code blog - the code smells behind each principle.
  • Adding reference counters (krefs) to kernel objects doc - the kernel's "tell, don't ask" API for object lifetime.
  • LeetCode Discuss: OOD interview preparation guide blog - community overview of OOD concepts asked in interviews.
  • Code smells, Coupling and cohesion, Common LLD mistakes doc - related lessons on this site.
