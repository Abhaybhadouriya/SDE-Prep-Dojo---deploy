Quiz

An override that throws UnsupportedOperationException most directly signals a violation of...

  1. SRP
  2. LSP (and often ISP)
  3. DRY
  4. KISS
Callers of the base type cannot rely on the method any more; usually the interface is also too fat.

Which statement about Dependency Inversion is correct?

  1. It means using Spring
  2. The high-level policy defines the abstraction and the detail implements it
  3. Low-level modules should own all interfaces
  4. It forbids the new keyword
DIP is about the direction of source-code dependencies: toward the policy-owned abstraction. DI is one technique to achieve it.

Two functions contain identical code, but one encodes a tax rule and the other a delivery-fee rule. What should you do?

  1. Merge them immediately (DRY)
  2. Keep them separate; they change for different reasons
  3. Delete one
  4. Make both static
DRY is about knowledge, not identical text. Merging couples two actors.

Your factory has a switch on product type. The most precise statement is...

  1. It completely breaks OCP
  2. It concentrates the one unavoidable edit in a single place; a registry can remove even that
  3. Factories cannot be extended
  4. It violates LSP
Clients stay closed; the factory is the cheap, single place of change, and a registry or ServiceLoader closes it further.

What is the best one-line test for coupling in an interview?

  1. Count the classes
  2. Ask which classes change when one requirement changes
  3. Count the interfaces
  4. Check the line count
Change impact is how coupling shows up; one change should touch one place.

order.getCustomer().getWallet().debit(x) mainly breaks...

  1. ISP
  2. Law of Demeter / Tell, Don't Ask
  3. LSP
  4. OCP
The caller reaches through objects and depends on their internals; delegate with order.checkout().
