From your world

This is release triage before a code freeze: P0 bugs block the release, P1 go in if they are low-risk, everything else waits. A coarse lock that is correct is like a big kernel lock: not elegant, but it ships. You then say, out loud, how you would split it into finer locks - that is the senior signal.
