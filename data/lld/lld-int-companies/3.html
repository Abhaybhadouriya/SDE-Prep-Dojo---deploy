Decode your round in four questions

Step through the questions to ask the recruiter. Each answer narrows the round type and tells you how to practise.

  1. Will the code be run? If no, you are in a whiteboard OOD round: spend time on classes, relationships and trade-offs. If yes, a working demo is the first gate.
  2. Own IDE or browser editor? In a browser editor (HackerRank, CodeSignal) you lose autocomplete and multi-file views, so practise writing many classes in one file.
  3. Are tests or boilerplate given? With given tests (CRED, Meesho), read them first: they are the real spec. With none (Atlassian), write your own as you go.
  4. Is AI allowed? It ranges from "banned" (Flipkart's posted 2026 rules) to "required and graded" (some Razorpay, CRED and Microsoft rounds).
  5. With four answers you know which judge you face. Practise that exact setup at least twice before the day.
