Scenario drills

Scenario: you prepared whiteboard OOD, the interviewer opens an IDE

Walmart-style round. You expected to draw classes. The interviewer says "Let's code it and run it."
Keep drawing boxes and say you will code at the end. Time runs out with nothing running.
Spend 3 minutes listing classes in comments, then code the smallest path that runs (create, then the core operation), run it, then grow it. Mention the patterns as you add them.
Likely follow-ups
  • Make it thread-safe. (find the check-then-act, lock the one object it touches (or use a compare-and-set), and show it with a race test)

Scenario: Flipkart, minute 95, bonus features tempting

P0 works except cancellation edge cases. Two bonus features (ratings, dashboard) remain.
Start the dashboard; cancellation bugs show up in the evaluator's demo.
Fix and demo the P0 edge cases first (the guideline says bonus only after P0), add driver cases for them, then try one small bonus.

Scenario: AI allowed, the assistant writes a God class

Razorpay-style AI round. You asked for "a search engine" and got one 300-line class.
Accept it and start testing.
Say out loud that it mixes indexing, storage and ranking. Split into Dataset, Index and a ranking Strategy, and use the tool only for small pieces. That is the skill being graded.
