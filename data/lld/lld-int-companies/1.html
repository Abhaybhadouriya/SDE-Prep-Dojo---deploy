The map: how long, and must it run?

Two questions sort almost every company: how long is the slot, and will someone run your code? The three round types (whiteboard OOD (object-oriented design), machine coding, code design) are explained on How LLD rounds work. This picture places each company.

The rule that saves most candidates: ask the recruiter "Will the code be run? In my own IDE or a browser editor? Are tests or boilerplate given? Are AI tools allowed?" One Walmart candidate drew on a whiteboard while the interviewer wanted IDE code (post 6146141 (2024-12-14)); a Microsoft candidate was told whiteboard only (post 7636712 (2026-03-09)). Guessing wrong costs the round.
