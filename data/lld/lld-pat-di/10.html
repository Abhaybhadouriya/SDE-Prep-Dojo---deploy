Level 4: threads, testing and cost

  • Threads. Wire the whole object graph in main() before any thread starts. Anything injected into many services is shared, so it must be thread-safe itself.
  • Testing. DI is the testing technique: pass fakes and a fixed Clock through constructors. No mocking framework needed.
  • Cost. Zero at run time with manual wiring. Containers add start-up time (scanning, reflection) and move wiring errors from compile time to start-up.
