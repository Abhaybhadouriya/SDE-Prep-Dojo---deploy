Quiz

Which is Dependency Injection?

  1. this.repo = new MySqlRepo() in the constructor
  2. OrderService(OrderRepository repo) { this.repo = repo; }
  3. this.repo = Registry.get(OrderRepository.class)
  4. Making OrderRepository a Singleton
Only option 2 receives the dependency from outside. Option 3 is a service locator: the class still reaches out for it.

Why is constructor injection preferred for required dependencies?

  1. It is faster at run time
  2. It needs no interfaces
  3. Fields can be final, the object is never half-built, and dependencies are visible
  4. It allows circular dependencies
Constructor injection actually exposes cycles instead of allowing them, which is a good thing.

A fee applies after 11 pm. What makes this rule easy to unit-test?

  1. Injecting a Clock and using Clock.fixed(...) in tests
  2. Running tests at night
  3. Making the fee a static constant
  4. Calling LocalTime.now() twice
Time is a dependency. Inject it and the test controls it.

The main drawback of a service locator compared with DI:

  1. It cannot return interfaces
  2. It always uses reflection
  3. It is slower
  4. Dependencies are hidden in method bodies and missing ones fail only at run time
Our demo's locator compiled fine and failed on first call because nothing declared the dependency.

Where should concrete service classes be instantiated in a well-structured LLD solution?

  1. Inside each service that uses them
  2. In one composition root such as main() or an AppFactory
  3. In static initialisers
  4. Inside the interfaces
One place knows the concrete classes and builds the graph; everything else depends on interfaces.

Inversion of Control is best described as:

  1. The same thing as Dependency Inversion
  2. Reversing the order of method calls
  3. The framework calling your code instead of your code calling the framework
  4. Using interfaces everywhere
"Don't call us, we'll call you." DI is one specific kind of IoC.

In the Linux driver model, probe(struct pci_dev *pdev, ...) is an example of:

  1. Dependency injection: the bus core hands the driver the device it should manage
  2. A service locator
  3. A Singleton
  4. Field injection
The driver does not search for its device; the core passes it in when a match is found.
