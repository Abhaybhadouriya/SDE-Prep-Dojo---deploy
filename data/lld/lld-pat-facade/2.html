Intent

Facade (GoF structural pattern): offer one higher-level, easy-to-use interface in front of a set of interfaces in a subsystem, so that the subsystem is simpler to use.

The key word is simplify. A facade does not change one interface into another (that is Adapter) and does not add behaviour to one object (that is Decorator). It sits in front of many classes and gives the common use cases a short, obvious API. Clients that need more control can still go around it.
