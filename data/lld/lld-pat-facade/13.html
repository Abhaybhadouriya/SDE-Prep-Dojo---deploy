Quiz

The main purpose of a Facade is to:

  1. Convert one interface into another
  2. Add behaviour to a single object
  3. Provide a simpler interface over a complex subsystem
  4. Ensure only one instance exists
Simplify many. Converting is Adapter, adding behaviour is Decorator, one instance is Singleton.

In a correct Facade design, do the subsystem classes hold a reference to the facade?

  1. No; they work without it and never call it
  2. Yes, always
  3. Only the first one
  4. Only in Java
One-way knowledge is what separates Facade from Mediator.

Chat users send messages to a ChatRoom, which forwards them to other users. The ChatRoom is a:

  1. Facade
  2. Adapter
  3. Decorator
  4. Mediator
The users (colleagues) know the room and talk through it.

Your OrderFacade now has 40 methods used by six teams. Best next step?

  1. Make it a singleton
  2. Split it into smaller facades by use case or audience
  3. Merge the subsystems into it
  4. Remove the subsystem interfaces
A god facade couples everyone again. Several focused facades keep each one simple.

Which is the best example of a Facade?

  1. BufferedInputStream
  2. Arrays.asList()
  3. The open() system call
  4. Collections.unmodifiableList()
The first and last are decorators, Arrays.asList is an adapter. open() hides many kernel subsystems.

  4. Nowhere; let it leak
