Level 4: threads, testing and cost

  • Threads. A facade that runs several steps needs them atomic or compensating: if payment fails, release the reserved stock. Never hold a lock across a remote call inside the facade.
  • Testing. Pass fake subsystems into the facade's constructor and test the failure paths, not only the happy path.
  • Cost. Close to zero at run time. The real risk is a god-object facade that every new feature grows; split it by use case.
