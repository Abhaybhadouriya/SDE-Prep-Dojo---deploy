Intent

Specification (Eric Evans and Martin Fowler, described in Evans's Domain-Driven Design, 2004): wrap a business rule in an object that answers one question, "does this candidate satisfy me?", and combine rules with boolean operators to form new rules. The same specification can then be used to select (filter a list or query a store), to validate (is this object acceptable?) and to describe what to build.

It is not one of the 23 GoF patterns. Structurally it is the Composite pattern applied to predicates, and a very small Interpreter for boolean expressions. In Java you get a lightweight version for free: java.util.function.Predicate has and, or and negate.
