Quiz

What does a specification return?

  1. A filtered list
  2. A computed price
  3. A boolean: does the candidate satisfy the rule?
  4. A SQL string, always
Filtering a list is the client's job using the spec; SQL translation is an optional second job.

Which GoF pattern gives Specification its structure?

  1. Composite
  2. Singleton
  3. Adapter
  4. Observer
AndSpec, OrSpec, NotSpec hold child specs and are specs themselves.

A search must return SUVs under 3,500 per day, then sort them by rating. Which split is best?

  1. One strategy that filters and sorts
  2. One specification that sorts
  3. An if-chain in the controller
  4. A specification for the filter, a strategy (comparator) for the order
Judge with specs, rank with a strategy. Each changes independently.

Why put cheap, selective leaves first in an AND?

  1. Java requires it
  2. Short-circuiting skips the remaining leaves for most candidates
  3. It changes the result
  4. OR needs it
Order does not change the answer for pure specs, only the cost.

Your listing table has 50 million rows. What should the specification do?

  1. Load all rows and call isSatisfiedBy
  2. Be replaced by a long if-chain
  3. Translate itself into the store's query (for example a SQL WHERE clause) so the database filters with indexes
  4. Run in a background thread
Keep the tree, push it down. Spring Data JPA Specification and Django Q work this way.

Which of these is a specification tree you may already use as a systems engineer?

  1. tcpdump 'tcp and port 443 and not host 10.0.0.5'
  2. kill -9 1234
  3. ip link set eth0 up
  4. modprobe e1000
Primitives joined with and, or, not, compiled by libpcap into a BPF program.
