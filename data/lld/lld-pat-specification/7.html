Level 4: threads, testing and cost

  • Threads. Leaf specs are immutable records, so one spec can be shared across threads and across many queries.
  • Testing. Unit-test each leaf, then truth-table tests for and/or/not, then one test of the composed query.
  • Cost. In memory it is O(items x spec nodes). Against a database, translate the spec tree into a WHERE clause instead of loading every row.
