The read-write lock

A read-write lock (RW lock) is a pair of locks that share one state: a read lock that any number of threads can hold together, and a write lock that only one thread can hold, and only when no reader holds the read lock.

class FlagStore {
    private final Map<String, Boolean> flags = new HashMap<>();
    private final ReentrantReadWriteLock rw = new ReentrantReadWriteLock();
    private final Lock r = rw.readLock(), w = rw.writeLock();

    boolean isOn(String f) {
        r.lock();
        try { return flags.getOrDefault(f, false); } finally { r.unlock(); }   // readers in parallel
    }
    void set(String f, boolean on) {
        w.lock();
        try { flags.put(f, on); } finally { w.unlock(); }                       // alone
    }
}
