StampedLock: optimistic reads

StampedLock (Java 8) adds a third mode. An optimistic read takes no lock at all. It reads a version number (the stamp), copies the fields, then asks "did any writer run since that stamp?" If not, the copy is good. If yes, it falls back to a real read lock. Readers write nothing to shared memory on the happy path, so they do not bounce a cache line.

class Point {
    private double x, y;
    private final StampedLock sl = new StampedLock();

    void move(double dx, double dy) {
        long st = sl.writeLock();
        try { x += dx; y += dy; } finally { sl.unlockWrite(st); }
    }

    double distanceFromOrigin() {
        long st = sl.tryOptimisticRead();     // 0 if a writer holds it right now
        double cx = x, cy = y;                // 1. copy into LOCALS
        if (!sl.validate(st)) {               // 2. a write happened: copy may be torn
            st = sl.readLock();               // 3. fall back to a real read lock
            try { cx = x; cy = y; } finally { sl.unlockRead(st); }
        }
        return Math.sqrt(cx * cx + cy * cy);  // 4. only now use the values
    }
}

In our run, 2,000,000 reads raced a thread moving the point every millisecond, and only 6 reads had to fall back to the read lock.

The optimistic rules. Between tryOptimisticRead and validate, the values may be inconsistent (x from before a write, y from after). So: read fields into locals only, never follow a pointer you read or index an array with a value you read before validating, never call methods that could throw on bad values, and only act after validate returns true.

  • Not reentrant. Taking writeLock() twice in one thread deadlocks it. Do not call back into code that might lock again.
  • No Conditions and no owner: any thread holding the stamp can unlock.
  • Conversions: tryConvertToWriteLock(stamp) upgrades if nobody else is reading, which is the safe form of the "upgrade" that RW locks forbid. It returns 0 on failure, and you then release and take the write lock normally.
  • asReadLock() / asWriteLock() give plain Lock views for APIs that expect one.
