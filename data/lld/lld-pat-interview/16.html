Resources

  • refactoring.guru pattern catalogue doc - the clearest free reference for all GoF patterns except Interpreter, with diagrams. Read it there; we only link to it.
  • SourceMaking design patterns doc - the 23 GoF patterns plus Object Pool, Null Object and Private Class Data.
  • Design Patterns (GoF book) on Wikipedia doc - the 23 patterns in three families and the book's two core principles.
  • Head First Design Patterns, 2nd ed. (official page) book - the friendliest book; its chapter order (Strategy first) is a good study order.
  • ByteByteGo: A framework for the OOD interview course - the free framework chapter of the paid Object-Oriented Design Interview course.
  • iluwatar/java-design-patterns repo - 100+ patterns in Java with explanations; good for "show me a real example".
  • JakubVojvoda/design-patterns-cpp repo - compact C++ versions of the GoF patterns (MIT).
  • ashishps1/awesome-low-level-design repo - LLD problems and pattern notes in six languages (GPL-3.0: read, do not copy).
  • LWN: Object-oriented design patterns in the kernel, part 1 blog - vtables of function pointers, the bridge from your world. Part 2 covers inheritance by embedding.
  • Martin Fowler: Inversion of Control Containers and the Dependency Injection pattern blog - why "inject one instance" beats a global singleton.
  • LeetCode Discuss: LLD topics and design patterns roadmap blog - a community checklist of LLD problems and patterns (2024-07-06).

Inside this site: Patterns overview, Look-alike patterns, Patterns in the Linux kernel, LLD question bank, Patterns & principles cheat sheet.
