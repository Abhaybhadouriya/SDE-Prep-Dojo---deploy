Quiz

Which change best shows code that is closed for modification?

  1. Adding an else if for the new type
  2. Copying the class and editing the copy
  3. Adding a new class that implements an existing interface, plus one registration line
  4. Adding a boolean flag parameter
Existing tested classes are untouched; only the composition root gains one line.

Who first stated "open for extension, closed for modification", and with which mechanism?

  1. Bertrand Meyer, 1988, using inheritance
  2. Barbara Liskov, 1987, using subtyping
  3. The Gang of Four, 1994, using Strategy
  4. Linus Torvalds, using modules
Meyer coined it with inheritance; Martin later popularised the interface-based version.

BNPL differs from Card only in its percentage and cap. The simplest OCP-friendly change is:

  1. A new subclass of Card
  2. A new switch case
  3. A new interface
  4. A new row of data (pct, cap) read by one generic rule
When only numbers differ, data keeps the code closed with the least code.

"Strategic closure" means:

  1. Closing every class with final
  2. Choosing which kinds of change to protect against, because you cannot protect against all
  3. Never changing an interface
  4. Putting all switches in one file
You pick the likely axes of change and put the abstraction there.

In Linux, how is a new TCP congestion-control algorithm added?

  1. By editing tcp_input.c for each algorithm
  2. By recompiling the kernel with a new #ifdef
  3. A module fills struct tcp_congestion_ops and calls tcp_register_congestion_control()
  4. Through a netlink message to the NIC
The core calls through the ops table; the algorithm plugs in by registering.

What should a registry do when a second rule registers the same key?

  1. Fail loudly (like -EEXIST or an exception)
  2. Silently keep the newest
  3. Silently keep the oldest
  4. Pick one at random
Silent overwrite hides wiring bugs; fail fast instead.

A Java enum where each constant overrides fee() is a poor fit when:

  1. The set of variants is fixed forever
  2. Product adds new variants often, because each one still edits the enum file
  3. You need a switch
  4. You use Java 21
Constant-specific methods remove the switch, but the enum itself must still be edited per new variant.
