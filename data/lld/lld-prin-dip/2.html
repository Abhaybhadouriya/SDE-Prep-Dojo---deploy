Before: an OrderService soldered to MySQL and SMTP

static class OrderServiceBefore {
    private final MySqlOrderDao dao = new MySqlOrderDao();   // hard-wired detail
    private final SmtpMailer mailer = new SmtpMailer();      // hard-wired detail

    void place(Order o) {
        if (o.amountPaise() <= 0) throw new IllegalArgumentException("amount");
        dao.insert(o);
        mailer.send(o.customerEmail(), "Order " + o.id() + " placed");
    }
}

It works. Now look at what it costs:

  • Cannot test the rule alone. To check "an order with amount 0 is rejected" you need a MySQL server and an SMTP server, or you start mocking static constructors.
  • Cannot swap. Product wants SMS for some users and WhatsApp for others. You must edit OrderService - the most important class - for a delivery-channel decision.
  • Change flows upward. If MySqlOrderDao.insert changes its signature, the business class breaks. The detail controls the policy.
  • Build coupling. The order module cannot compile without the JDBC driver and the mail library on its classpath.
