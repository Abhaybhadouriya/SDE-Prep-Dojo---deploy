The kernel's flyweights

From your world

Three more you have seen. kstrdup_const() checks whether the source string already lives in the kernel's read-only data section; if so it returns the same pointer instead of allocating a copy, and kfree_const() knows not to free it. Ops tables: every struct file for a driver has its own extrinsic state (f_pos, f_flags, private_data) but all of them point at one const struct file_operations: the behaviour is shared, intrinsic, read-only. Page cache: a shared library's text pages are one set of physical pages mapped into every process that uses it, each at its own virtual address.
