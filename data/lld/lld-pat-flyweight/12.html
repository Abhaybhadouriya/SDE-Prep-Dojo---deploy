Remember this

  • Flyweight = share the immutable common part of many small objects; pass the varying part in.
  • Intrinsic = same wherever used, stored in the flyweight. Extrinsic = depends on context, kept by the client.
  • Roles: Flyweight (immutable), Flyweight factory (pool keyed by intrinsic state), Context (extrinsic + reference).
  • It is a memory optimisation: use it only for very many objects with few distinct intrinsic values.
  • Factory must be atomic (computeIfAbsent) and bounded if keys come from users.
  • Integer.valueOf caches -128..127: compare boxed numbers with equals, never ==.
  • Kernel bridge: shared zero page + copy-on-write, kstrdup_const, shared const ops tables.
