Level 4: threads, testing and cost

  • Threads. Flyweights must be immutable to be shared across threads. The factory needs an atomic get-or-create (computeIfAbsent), not check-then-put.
  • Testing. Identity test (same key gives the same object), immutability test, and a count of objects created with and without the factory.
  • Cost. A hash lookup per request and the extrinsic state passed on every call. It saves memory only when distinct intrinsic values are far fewer than objects.
