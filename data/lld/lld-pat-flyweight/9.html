Related and confused-with patterns

PatternWhat is shared or reusedKey difference from Flyweight
FlyweightImmutable intrinsic state, used by many contexts at the same time-
Object PoolExpensive mutable objects (connections, threads, buffers), lent to one user at a timePool: borrow, use exclusively, return. Flyweight: never borrowed, never returned, used by everyone at once.
SingletonExactly one instance of a classFlyweight has one instance per distinct intrinsic value, often many. A flyweight factory itself is often a singleton.
Cache / memoisationResults of expensive computations, by keyA flyweight factory is a cache whose values are immutable objects. A cache's main goal is speed; Flyweight's is memory.
PrototypeA template object you copyPrototype makes new independent objects; Flyweight avoids making them.
Composite-Often combined: leaves of a large composite tree (characters in a document tree) are flyweights.
Value object / interningImmutable values compared by contentInterning is Flyweight applied to value objects.
