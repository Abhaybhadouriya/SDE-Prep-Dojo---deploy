In a text editor using Flyweight, which field is extrinsic?

  1. Font family
  2. Font size
  3. The row and column where the character is drawn
  4. Text colour
Position depends on where the character sits and on the window width, so it cannot live in a shared object.

Why must a flyweight be immutable?

  1. So it can be serialised
  2. Because many contexts share it at once; a change would affect all of them
  3. Because the factory needs a hash code
  4. To allow inheritance
Shared plus mutable means one caller's change leaks into everyone else's view.

Integer x = 1000, y = 1000; What does x == y print with default JVM settings?

  1. false
  2. true
  3. It does not compile
  4. It throws an exception
1000 is outside the default -128..127 cache, so two different objects are created and == compares references.

Which job belongs to the flyweight factory?

  1. Storing every character's position
  2. Rendering characters
  3. Copying flyweights for each client
  4. Returning the existing instance for a key, creating it only on a miss
The factory is a pool keyed by intrinsic state; it guarantees one instance per distinct key.

A list of 300 menu items, each with a name and price. Should you apply Flyweight?

  1. Yes, always share objects
  2. No: too few objects and little shared state, so it only adds complexity
  3. Yes, but only for the names
  4. Only if the items are mutable
Flyweight pays off with very many objects and few distinct intrinsic values.

The kernel maps the shared zero page read-only because:

  1. Zero pages cannot be written by hardware
  2. It saves TLB entries
  3. The first write must fault so copy-on-write can give the writer a private page
  4. Only root can write to it
Read-only mapping is how the kernel enforces flyweight immutability: writes trigger a fault and a private copy.

Main difference between Flyweight and Object Pool?

  1. Flyweights are shared by many users at once; pooled objects are lent to one user at a time
  2. Flyweights are mutable; pooled objects are immutable
  3. They are the same pattern
  4. Object Pool saves memory; Flyweight saves CPU
Concurrent sharing of immutable state vs exclusive borrowing of expensive mutable objects.
