Structure: factory, flyweight, context

  • Flyweight (CharStyle): holds intrinsic state only. Must be immutable, because many contexts share it. Its methods take the extrinsic state as parameters.
  • Flyweight factory (StyleFactory): the only way to get a flyweight. Looks up a pool keyed by the intrinsic state; creates on a miss, returns the cached instance on a hit.
  • Context (Document, Flow): stores the extrinsic state plus a reference to the flyweight. This is the object you still have millions of, but now it is tiny.
  • Client: asks the factory, never calls new CharStyle(...) itself.

Some descriptions also list an unshared concrete flyweight: an object that implements the same interface but is not pooled (for example a one-off style with a custom colour picked by the user). That is allowed; sharing is enabled, not forced.
