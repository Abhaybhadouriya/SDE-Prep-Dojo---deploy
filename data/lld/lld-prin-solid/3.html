O: Open/Closed Principle

Rule: code should be open for extension, closed for modification. You add behaviour by adding new code (a new class), not by editing working, tested code.

Smell: an if/else or switch on a type string or enum that appears in several places and grows every sprint: if (type.equals("PREMIUM")) ... else if ....

Cure: put the varying part behind an interface, one class per variant, and let the stable code loop over a list or look up a map of them. That is exactly the Strategy pattern.

  1. The calculator holds a list of DiscountRule objects. It only knows the interface: applies() and discount().
  2. Two rules exist today: premium customers get 10%, employees 20%. Each is its own small class.
  3. Marketing invents a student discount. We add one new class. That is the "open for extension" half.
  4. The calculator, and its tests, did not change at all. That is the "closed for modification" half.
  5. Compare with the if/else chain: every new rule edits, re-tests and re-deploys the same method, and one wrong else breaks the old rules.
interface DiscountRule { boolean applies(String customerType); long discount(long amount); }

record PercentOff(String type, int percent) implements DiscountRule {
    public boolean applies(String t) { return t.equals(type); }
    public long discount(long amount) { return amount * percent / 100; }
}

class DiscountCalculator {                       // closed: never edited for a new rule
    private final List<DiscountRule> rules;
    DiscountCalculator(List<DiscountRule> rules) { this.rules = List.copyOf(rules); }
    long discount(String type, long amount) {
        return rules.stream().filter(r -> r.applies(type)).mapToLong(r -> r.discount(amount)).max().orElse(0);
    }
}

From your world

You have used OCP for years. A new filesystem calls register_filesystem(); a new protocol registers its handler; a firewall module attaches a function at a netfilter hook. The VFS core and the IP stack are closed (nobody edits net/ipv4/ip_input.c to add a firewall rule) and open (any module can plug in).
