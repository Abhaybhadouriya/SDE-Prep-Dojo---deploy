Resources

  • SourceMaking: Object Pool doc - one of the few pattern catalogues that includes it; checklist and rules of thumb.
  • Refactoring.Guru: pattern catalogue doc - Object Pool is not in the GoF list there; compare with Flyweight and Singleton.
  • Wikipedia: Object pool pattern doc - definitions and pitfalls.
  • HikariCP on GitHub repo - configuration reference (timeouts, max lifetime, leak detection) and the wiki page "About Pool Sizing".
  • Apache Commons Pool doc - a general-purpose pool API: borrow, return, validate, evict.
  • Linux kernel docs: memory management APIs doc - kmem_cache_* and mempool_* reference.
  • Linux kernel docs: page_pool doc - page recycling for network drivers.
  • LWN: Linux kernel design patterns, part 2 blog - includes preloading a per-CPU pool before taking a lock.
  • SQLAlchemy: connection pooling doc - QueuePool, overflow, pre-ping.
