Related and confused-with patterns

Compared withLooks similar becauseThe difference
FlyweightBoth reuse objects to save resourcesFlyweight objects are immutable and shared by many clients at the same time (Integer.valueOf(7)). Pooled objects are mutable and exclusive: one borrower at a time, reset in between.
SingletonControls how many instances existSingleton: exactly one, shared. Pool: up to N, lent out one per client. The pool object itself is often a singleton per resource ("one pool per database").
FactoryClients ask something else for an objectA factory creates a new object every call. A pool usually returns an old one and only calls its factory when it needs to grow.
ProxyThe Lease wraps the real objectThe Lease is a proxy: same interface as the connection, but close() means "return to pool". Pool is the policy; proxy is the handle.
PrototypeAvoids expensive constructionPrototype makes a new object by copying a template; each client gets its own. Pool reuses the same object across clients over time.
Thread pool"Pool" in the nameA thread pool takes tasks and runs them on reused threads; the client never holds a thread. A classic object pool lends the object to the client.
