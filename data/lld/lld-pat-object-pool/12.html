Remember this

  • Object Pool = reuse expensive objects and bound how many exist. Acquire, use, release.
  • Pooled objects are exclusive and mutable; reset them on return, validate them on borrow.
  • Release through a closeable handle (try-with-resources, with, RAII) so every path returns the object.
  • Exhausted pool: block with a timeout, or fail fast. Never wait forever.
  • Detect leaks by recording borrow time and borrower; alert on leases held too long.
  • Kernel: slab caches, mempool_t (guaranteed reserve), page_pool.
  • Do not pool cheap objects; a pool is extra locking and extra risk.
