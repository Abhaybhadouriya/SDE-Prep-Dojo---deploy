APIs and interfaces

In-process API first (what the interviewer will call from main), then how it maps to HTTP if they ask about GET/POST, as the 2024 Amazon report did.

interface SlotAllocationStrategy { Size choose(Size parcel, FreeSlots free); }   // null = nothing fits
interface FreeSlots              { int count(Size size); }
interface CodeGenerator          { String next(); }
interface LockerListener         { void onDeposited(String st, Delivery d); void onPickedUp(...); void onExpired(...); }
interface Clock                  { long now(); }

final class LockerService {
    void           addStation(String stationId, int small, int medium, int large);
    DepositReceipt deposit(String stationId, Parcel parcel);       // throws NO_SLOT, DUPLICATE_PARCEL
    PickupResult   pickup(String stationId, String code);          // throws INVALID_CODE, CODE_EXPIRED, KEYPAD_LOCKED
    int            expireOverdue();                                // called by a periodic job
    List<Parcel>   collectExpired(String stationId);               // courier return run
    void           setOutOfService(String stationId, String slotId, boolean broken);  // throws SLOT_BUSY
    EnumMap<Size, Integer> availability(String stationId);
}
HTTPCallerMaps toNotes
GET /stations/{id}/availabilityCheckout pageavailabilityCacheable for seconds; a hint, not a promise
POST /stations/{id}/deposits body {parcelId, size}Courier appdepositIdempotent on parcelId: a retry returns the same slot, never a second one
POST /stations/{id}/pickups body {code}Station keypad / customer apppickupPOST, never GET: the code must not end up in URLs or logs. 401 for wrong code, 410 for expired, 429 when locked
POST /stations/{id}/returns:collectCourier appcollectExpiredReturns the parcel ids to take back
PATCH /stations/{id}/slots/{slotId} body {outOfService}TechniciansetOutOfService409 when the slot holds a parcel

The courier never sees the code. DepositReceipt carries the slot id and expiry, not the code; the code leaves the system only through a listener to the customer. If the receipt carried it, anyone with the courier app could empty the station.
