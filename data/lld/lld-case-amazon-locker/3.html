Identify the entities

Underline nouns (candidate classes) and verbs (candidate methods), then remove actors and plain values. Click through.

  1. Underline every noun. Two are people (actors), one is a duration.
  2. Underline every verb. They become the public API (deposit, pickup, expire, collect) or private steps (find a slot, notify).
  3. Drop the actors, split the overloaded word "locker", and notice the rule that varies (which size) and the link that needs its own lifecycle (a parcel sitting in a slot with a code).
  4. The final list. The Delivery record is the key modelling decision: it is what a code points to, what expires, and what the courier collects back.
EntityKindResponsibility (one line)
LockerServiceService / facadeThe API: addStation, deposit, pickup, expireOverdue, collectExpired, setOutOfService, availability. Fires events.
LockerStationAggregateOwns its slots, a free list per size, live deliveries by code and by parcel, and the keypad counter. One lock.
SlotEntityOne door: id, size, state (FREE, OCCUPIED, OUT_OF_SERVICE).
ParcelImmutable valueWhat the courier brings: id, customer id, size.
DeliveryEntity (lifecycle)Parcel + slot + code + deposited/expires times + state (DEPOSITED, PICKED_UP, EXPIRED, RETURNED).
SlotAllocationStrategyInterface (Strategy)"Which size should this parcel get?" BestFit, ExactFit, ReservingBestFit.
CodeGeneratorInterface (Strategy)Produces codes; SecureRandom in production, seeded in tests.
LockerListenerInterface (Observer)Hears deposit, pickup and expiry: SMS, email, metrics, audit.
ClockInterfaceCurrent time in ms; faked in tests.

Why a separate Delivery and not fields on Slot? A slot outlives thousands of parcels; a delivery has its own lifecycle (deposited, picked up or expired, returned) and its own key (the code). If you put code and expiresAt on Slot, an expired parcel and the next parcel fight over the same fields, and "show me the history of this parcel" becomes impossible. This is the same split as a struct page (the frame) versus the mapping that currently uses it.
