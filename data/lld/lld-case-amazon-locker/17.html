Quiz

A station has 0 free small, 1 free medium and 1 free large slot. A SMALL parcel arrives. What does best fit do?

  1. NO_SLOT
  2. Takes the large slot
  3. Takes the medium slot
  4. Waits for a small slot
Best fit picks the smallest size at or above the parcel's size that has a free slot: MEDIUM.

With ReservingBestFit keeping 1 large slot, the station has 0 small and 1 large free. A SMALL parcel arrives. Result?

  1. Evicts a parcel
  2. Takes a medium slot
  3. Takes the large slot
  4. NO_SLOT, because upgrading would use the reserve
An upgrade into LARGE is allowed only while more than 1 large slot is free. The last one is kept for a LARGE parcel.

A delivery expires. What happens to its slot?

  1. It stays OCCUPIED until a courier collects the parcel
  2. It is given to the next parcel of that size
  3. It becomes OUT_OF_SERVICE
  4. It becomes FREE at once
The parcel is still physically inside. Expiry kills the code; collection frees the slot.

Why is the code removed from byCode in the same critical section that frees the slot?

  1. So the listener can read it
  2. To save memory
  3. So a second pickup with the same code cannot open the slot after the next parcel goes in
  4. Because maps are not thread safe
Single use must be atomic with the release, or there is a window where an old code points at a reusable slot.

Which lock granularity does the design use, and why?

  1. One global lock, for simplicity
  2. One lock per slot, for maximum parallelism
  3. No locks; ConcurrentHashMap is enough
  4. One lock per station, because stations share nothing and a deposit touches several structures of one station
The station is the aggregate. Per-slot locks cannot protect "count then pop" across size lists and the code index.

A station has 400 live 6-digit codes and no lockout. Roughly what is the chance one random guess opens some door?

  1. Zero, codes are unique
  2. About 1 in 400
  3. About 1 in 2,500
  4. 1 in a million
400 valid codes out of 1,000,000: 1 in 2,500. That is why guesses are rate-limited per keypad.

Which object should carry the pickup code back to the caller of deposit()?

  1. DepositReceipt
  2. Slot
  3. None: the code goes to the customer through a listener
  4. Parcel
The courier calls deposit; the courier must never see the code.
