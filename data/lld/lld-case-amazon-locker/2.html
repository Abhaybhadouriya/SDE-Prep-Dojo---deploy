Clarify requirements

Spend about 5 minutes here. "Design Amazon Locker" can mean the box on the wall (LLD), the website that picks a nearby station (HLD), or both. Pin it to the station software in one process.

Functional (P0 - must work in the demo)

  1. Stations and slots A station has slots of three sizes (small, medium, large). One parcel per slot.
  2. Deposit A courier brings a parcel of a known size; the system picks a free slot that fits, opens it, and records the delivery. If nothing fits, it says so.
  3. Pickup code On deposit, the customer receives a 6-digit code (SMS, email, app). Typing it opens that slot. The code works once.
  4. Expiry A parcel not collected within a hold period (3 days) expires: its code stops working and the courier takes it back, freeing the slot.
  5. Availability Report free slots per size (for the website that offers this station at checkout).

Functional (P1 - say you can add them, build if time allows)

  • Slot maintenance: mark a broken slot out of service and back.
  • Swap the allocation rule (exact fit only, or keep a reserve of large slots).
  • Brute-force protection: lock the keypad after 5 wrong codes.
  • Returns: a customer drops an item for a courier to collect (same flow, roles swapped).
  • Real dimensions instead of S/M/L.

Non-functional

  • Thread safe: several couriers and customers act at once (the station's touch screen plus the mobile app); a slot is never given twice and a code never opens twice.
  • Fast: deposit and pickup are O(1) on average (free list per size, map by code), not a scan over every slot.
  • Secure enough: codes are random and unique among live codes at a station; guessing is rate-limited.
  • Testable: time and code generation are injected; the expiry demo runs in microseconds.

Out of scope (say it out loud)

  • Choosing a station near the customer, payments, the order system (HLD).
  • Hardware: door sensors, power loss, the actual lock driver (we model "door opened" as the return value).
  • Persistence and crash recovery (one sentence on it in the extensions).
