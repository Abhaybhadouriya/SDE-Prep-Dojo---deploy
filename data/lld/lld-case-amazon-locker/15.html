Common mistakes

  1. Scanning every slot A loop over all lockers for each parcel. Use a free list per size.
  2. Putting a small slot under a large parcel Getting the fit comparison backwards. Write fitsIn once and test it.
  3. One word for two things "Locker" meaning both the station and a door. Name them Station and Slot.
  4. Returning the code to the courier The receipt should name the door, not the secret.
  5. Reusable codes Forgetting to remove the code on pickup, so it opens the next parcel's door too.
  6. Freeing on expiry The parcel is still inside; only collection frees the slot.
  7. Check-then-act without a lock "If free count > 0, take one" from two threads gives one slot to both.
  8. Calling the SMS gateway under the lock One slow notification blocks the whole station.
  9. A global lock Correct but serialises every station; the lock belongs to the aggregate.
  10. No patterns named The Zeta candidate's lesson: working code without a visible Strategy or Observer read as weak design.
