Remember this

  • It is an allocator with size classes: one free list per size, best fit moves up, never down.
  • Station and Slot are different classes; a Delivery ties parcel, slot, code and expiry together.
  • The allocation rule is a Strategy (best fit, exact fit, reserve); notifications are Observers; the service is a Facade.
  • Codes: secure random, unique per station, single use, only to the customer, guessing rate-limited.
  • Expiry changes the delivery state; only courier collection frees the slot. Pickup checks expiry too.
  • One lock per station: check-then-act, the code index and the slot change in one critical section; listeners run after unlock.
  • Asked by Amazon at every stage (phone screen to onsite) and recently by Zeta; the follow-ups are OTP design, concurrency and dimensions.
