Remember this

  • 10 minutes: clarify 2, entities 2, diagram 4, API 2. Then score yourself with the same 16-point rubric.
  • Every booking-shaped problem has an offered thing and a taken thing: Slot vs Booking, Spot vs Ticket, MenuItem vs OrderLine.
  • Enum when the prompt fixes the list (specialities); data or value objects when it says "more will be added" (workout types).
  • Put the rule most likely to change behind one interface: pricing, ranking, allocation, delivery.
  • Name the one check-then-act race and where its lock goes before the interviewer asks.
  • Redo low-scoring drills from a blank page a week later; recognising shapes is the goal.
