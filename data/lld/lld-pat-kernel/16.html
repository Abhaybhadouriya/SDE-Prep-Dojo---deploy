Remember this

  • Ops tables are interfaces with hand-written vtables; NULL entries are optional methods with defaults.
  • file_operations = Bridge; tcp_congestion_ops = Strategy (a mixin table).
  • Embedding + container_of = inheritance; prefer it over void * private data.
  • kref = shared ownership with a release callback; any pointer that outlives a call holds a reference.
  • Notifier chains = Observer (priority ordered, may stop); netfilter hooks = Chain of Responsibility (verdicts).
  • Slab and mempool = Object Pool; workqueues = Command on a worker pool; TCP states = State as a switch.
  • Kernel lesson: library over midlayer, which in OOP means composition over rigid base classes.
