Resources

  • uml-diagrams.org: Use case diagrams doc - the notation for actors, include, extend, with many examples.
  • Martin Fowler: Evans Classification blog - entity, value object, service in one short page.
  • Martin Fowler: Value Object blog - why immutability and value equality go together.
  • Martin Fowler: Anemic Domain Model blog - the opposite failure: all logic in services.
  • Refactoring.Guru: Primitive Obsession doc - the smell that value objects fix.
  • Hello Interview: LLD delivery framework course - entities and the orchestrator-first approach.
  • ByteByteGo: A framework for the OOD interview book - official page of the Object-Oriented Design Interview course (paid); its framework also starts with core objects from requirements.
  • LeetCode Discuss: CRED machine coding round (registers) blog - the real class-per-instance example discussed above.
  • awesome-low-level-design repo - class diagrams for 36 problems to practise entity extraction against.
