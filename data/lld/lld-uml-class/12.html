In a class box, what does # before a member mean?

  1. private
  2. protected
  3. package
  4. static
+ public, - private, # protected, ~ package.

How is a static attribute shown?

  1. In italics
  2. Underlined
  3. With a / prefix
  4. In «static» brackets only
Static (class-level) members are underlined. Italic means abstract; / means derived.

- parked: Vehicle [0..1] most naturally becomes...

  1. A required, non-null Vehicle field
  2. A nullable/Optional Vehicle field
  3. A List<Vehicle> that must not be empty
  4. A static field
0..1 means zero or one: the field may be absent.

Which line connects a class to the interface it implements?

  1. Solid line, hollow triangle
  2. Dashed line, hollow triangle
  3. Solid line, filled diamond
  4. Dashed line, open arrow
Realization is dashed with a hollow triangle; generalization (extends) is solid with a hollow triangle.

The name of a class is in italics. It is...

  1. An interface
  2. An abstract class
  3. A static class
  4. An enum
Italic name = abstract. An interface carries the «interface» stereotype.

In a 45-60 minute LLD round, roughly how long should the class diagram take?

  1. 2 minutes
  2. 8-10 minutes
  3. 30 minutes
  4. The whole round
Enough to agree on entities, relationships and the orchestrator's API, then move to code.

Where do you write the multiplicity "1..*" for "a Level has one or more ParkingSpots"?

  1. Next to Level
  2. Next to ParkingSpot
