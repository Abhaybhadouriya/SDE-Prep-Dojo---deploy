Resources

  • uml-diagrams.org: Class diagrams overview doc - Clear reference for every element of a class diagram, with examples.
  • uml-diagrams.org: Class doc - Compartments, visibility, attributes and operations notation in detail.
  • uml-diagrams.org: Multiplicity doc - Ranges, ordering and uniqueness.
  • OMG UML specification doc - The official standard - for reference only; interviews use a small subset.
  • UmlAsSketch blog - Martin Fowler on using UML as a quick sketch - the interview mindset.
  • Mermaid class diagram syntax doc - Text-to-diagram syntax for docs and online rounds.
  • PlantUML class diagrams doc - Another text notation, common in engineering docs.
  • ashishps1/awesome-low-level-design repo - Class diagrams for many classic LLD problems to practise reading.
