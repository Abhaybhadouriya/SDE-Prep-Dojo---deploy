Abstract classes, interfaces and enums

  • Abstract class - italic name (or {abstract}). It can hold state and some implemented methods; the italic operations are the ones subclasses must provide. Subclasses connect with a solid line and a hollow triangle pointing at the parent (generalization, "is-a"). Several subclasses may share one triangle.
  • Interface - <<interface>> above an italic name, no attributes compartment, only operations. Implementing classes connect with a dashed line and a hollow triangle (realization, "implements"). The lollipop (a small circle on a stick) is a shorthand for the same thing.
  • Enumeration - <<enumeration>>, with the literals listed in the second compartment. Java enums can also carry fields and methods; add a third compartment for them.

Why this matters in an interview: the boxes you mark as interfaces are your extension points. A grader scanning your diagram for extensibility looks first for <<interface>> boxes sitting where requirements will change (pricing, allocation, notification). See Abstract Classes vs Interfaces for when to choose which.
