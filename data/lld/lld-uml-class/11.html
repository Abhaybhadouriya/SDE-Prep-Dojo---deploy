Remember this

  • A class box has three compartments: name, attributes, operations. Each member reads visibility name: Type.
  • + public, - private, # protected, ~ package. Underlined = static, italic = abstract, / = derived.
  • Interface: <<interface>>, implemented with a dashed line + hollow triangle. Inheritance: solid line + hollow triangle. Enum: <<enumeration>> with literals.
  • Multiplicity sits next to the class it counts: 1, 0..1, *, 1..*; each becomes a field shape and a check.
  • Draw the decisions, not the boilerplate: no getters/setters, yes to the orchestrator and the interfaces where change will come.
  • 8-10 minutes in a 45-60 minute round, then code. Ask early whether the interviewer wants a diagram at all.
