The class box: three compartments

  1. Name compartment. The class name in UpperCamelCase, centred and bold. Italic means abstract. A stereotype in guillemets above it (<<interface>>, <<enumeration>>, <<record>>) says what kind of thing it is.
  2. Attributes compartment. One line per field: visibility name: Type [multiplicity] = default {property}. Only the name is required; in interviews always write the type.
  3. Operations compartment. One line per method: visibility name(param: Type, ...): ReturnType. Leave out obvious getters and setters.

Any compartment may be left out when it does not matter for the point you are making: a box with only a name is fine for a high-level sketch, and interfaces usually skip the attributes compartment.
