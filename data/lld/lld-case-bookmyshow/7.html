APIs and interfaces

// service API
List<Show>   find(String city, String movieTitle);
List<String> availableSeats(String showId);
Booking start(String userId, String showId, List<String> seatIds);  // throws SeatUnavailableException
Booking pay(String bookingId, PaymentStrategy payment);              // throws HoldExpiredException
Booking cancel(String bookingId);                                    // only from CONFIRMED

// the contended core
interface SeatInventory {
    SeatHold hold(Show show, List<String> seatIds, String userId);    // all or nothing
    void confirm(SeatHold hold, String bookingId);                     // Held(mine) -> Booked
    void release(SeatHold hold);                                       // Held(mine) -> Free
    void cancel(Show show, List<String> seatIds, String bookingId);    // Booked(mine) -> Free
    Set<String> available(Show show);
}
interface PricingStrategy { long price(Show show, Seat seat, double occupancy); }
interface PaymentStrategy { boolean pay(String bookingId, long amount); }

As REST endpoints (useful when the interviewer drifts towards HLD): GET /shows?city=&movie=, GET /shows/{id}/seats, POST /shows/{id}/holds with the seat list (201 with hold id and expiry, or 409 Conflict), POST /bookings/{id}/payments with an Idempotency-Key header so a retried payment request does not charge twice, DELETE /bookings/{id} to cancel.
