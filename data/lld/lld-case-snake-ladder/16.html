Remember this

  • Board = size + a map from start cell to Jump. A cell is an int. Snake and ladder are one type.
  • Validate the board once in a Builder (range, one jump per cell, direction, no cycle); then trust it.
  • Dice is a Strategy: RandomDice for play, FixedDice for tests. Two dice is a constructor argument.
  • The game loop is a queue: poll the head, play a turn, re-queue unless they won.
  • Output is an Observer, never System.out inside the game.
  • Follow-up rules start as flags in a Rules object; after three, refactor to rule objects.
  • One game is single-threaded by design; many games share only the immutable Board.
