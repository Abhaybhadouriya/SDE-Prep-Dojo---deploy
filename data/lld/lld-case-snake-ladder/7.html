APIs and interfaces

Write these signatures on the board before any code. They are the contract the evaluator will call from main.

interface Dice { int roll(); }

interface GameListener {                       // all default no-ops
    void onMove(Player p, int roll, int from, int to, Optional<Jump> jump);
    void onOvershoot(Player p, int roll);
    void onTurnCancelled(Player p, int backTo);
    void onWin(Player p, int rank);
}

Board board = Board.builder(100).ladder(2, 23).snake(29, 9).build();   // throws IllegalArgumentException
Game game   = new Game(board, new RandomDice(1, 6, seed), Rules.classic(), List.of("Alice", "Bob"));
game.addListener(new ConsolePrinter());
game.playTurn();              // one player's full turn
int turns = game.playToEnd(10_000);   // loop with a safety limit
GameStatus s = game.status(); List<Player> w = game.winners();
  • playTurn() is public so tests can step one turn at a time and check positions. playToEnd() is just a loop around it.
  • The safety limit in playToEnd turns an infinite game (bad script, broken board) into an exception instead of a hung demo.
  • Errors: invalid boards and fewer than two players throw IllegalArgumentException; calling playTurn() after the end throws IllegalStateException.
