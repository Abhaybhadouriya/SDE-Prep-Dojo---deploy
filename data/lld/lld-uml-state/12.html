Resources

  • uml-diagrams.org: State machine diagrams doc - states, pseudostates, transitions, entry/exit, composite states.
  • uml-diagrams.org: Activity diagrams doc - actions, decisions, fork/join, partitions (swimlanes).
  • RFC 9293: Transmission Control Protocol paper - the TCP connection state diagram in section 3.3.2.
  • Refactoring.Guru: State pattern blog - the pattern behind one-class-per-state, with a clear state-machine intro.
  • Wikipedia: UML state machine doc - history, hierarchical states, run-to-completion semantics.
  • Wikipedia: Activity diagram doc - quick symbol reference.
  • Mermaid stateDiagram and PlantUML state diagrams doc - write state diagrams as text in READMEs and design docs.
  • OMG UML 2.5.1 specification paper - the official semantics of state machines and activities.
