Example 2: a vending machine, step by step

The classic. A machine sells cola for 25. You insert coins, press select, get the item and your change, or cancel and get a refund. Watch the active state move as events arrive.

  1. The machine starts in Idle. Pressing select here does nothing: no arrow leaves Idle on select.
  2. Insert 10. Idle has an arrow for insert: add to the balance and move to HasMoney.
  3. Select cola. The guard [balance >= price] is false, so the other select transition (a self-transition) fires: show "need 15 more" and stay.
  4. Insert 20. Another self-transition: the balance is now 30.
  5. Select again. Now the guard is true: subtract the price and enter Dispensing, whose entry action drops the cola.
  6. Dispensing finishes (a completion transition): return the change of 5 and go back to Idle, ready for the next customer.

A real machine also needs a SoldOut guard and maybe a Maintenance state. Each new state is a new box, not a new if sprinkled across every method. That is exactly what the State pattern buys you in code: one class per box, each method is one outgoing arrow.

interface VendingState {
    default VendingState insert(Vending m, int coin) { System.out.println("    ignored insert in " + name()); return this; }
    default VendingState select(Vending m, String item) { System.out.println("    ignored select in " + name()); return this; }
    default VendingState cancel(Vending m) { return this; }
    String name();
}
static final class Idle implements VendingState {
    public VendingState insert(Vending m, int coin) { m.balance += coin; return new HasMoney(); }
    public String name() { return "Idle"; }
}
static final class HasMoney implements VendingState {
    public VendingState insert(Vending m, int coin) { m.balance += coin; return this; }   // self-transition
    public VendingState select(Vending m, String item) {
        int price = m.price(item);
        if (m.stock(item) == 0) { System.out.println("    sold out: " + item); return this; }   // guard [in stock]
        if (m.balance < price) { System.out.println("    need " + (price - m.balance) + " more"); return this; } // guard [balance >= price]
        m.balance -= price;
        return new Dispensing(item);
    }
    public VendingState cancel(Vending m) { System.out.println("    refund " + m.balance); m.balance = 0; return new Idle(); }
    public String name() { return "HasMoney"; }
}
