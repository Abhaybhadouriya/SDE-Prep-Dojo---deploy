Web frameworksServlet filters, Express / Django middleware, gRPC interceptorsAuth, logging, compression around a handler with the same signature

Go net/httphttp.Handler wrapped by http.TimeoutHandler, http.StripPrefixTimeouts, path rewriting around any handler

Python @decorator vs the GoF Decorator. They share the name and the idea (wrap and forward), but Python's syntax wraps a function once at definition time. The GoF pattern wraps an object, usually at run time, and keeps its whole interface. In an interview, say you know the difference.
