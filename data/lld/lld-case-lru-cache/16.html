  • LRU = hash map (key to node) + doubly linked list with sentinels; get and put O(1).
  • LFU = key to freq + freq to ordered set + minFreq; ties broken by age.
  • EvictionPolicy with onPut / onAccess / onRemove / evict keeps order in sync with contents.
  • get is a write for LRU: use an exclusive lock (or stripes), not a read lock.
  • No store I/O under the lock; coalesce concurrent loads of the same key.
  • Write-through = always consistent, slow writes; write-back = fast, flush dirty entries on eviction.
  • Inject the clock and the store; a Cache that implements the store interface gives multi-level for free.
