The three extension words, in one line each: lock striping = N locks chosen by hash of the key, so unrelated keys rarely wait for each other (like per-bucket spinlocks in a kernel hash table); coalesced loads (also called single-flight) = when many threads miss the same key, only one loads it from the store and the others wait for that result; W-TinyLFU = the admission filter used by the Caffeine library: a small frequency sketch decides whether a new key is worth evicting an old one for.

For a 25-minute "implement LRU" question: say the design in one minute (map plus DLL, sentinels), write Node, the two helpers (unlink, pushFront), then get and put, then walk the a,b,c,get a,put d example by hand.
