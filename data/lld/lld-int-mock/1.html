How to use this page

  1. Pick the mock that matches your round. Not sure? Read How LLD rounds work and ask your recruiter whether running code is expected.
  2. Read only the prompt box. Close the rest of the page (collapse it, or cover the screen). Start a timer.
  3. Do the round for real: talk out loud, use a real IDE for mocks 2 and 3, a blank doc or whiteboard tool for mock 1.
  4. Stop at the time limit, even mid-line. Interviews do.
  5. Then read the walkthrough and grade yourself with the self-grading sheet. Note the two lowest rows; that is next week's practice.
  6. Repeat with a partner. Give them the "interviewer script" box so they can push back like an interviewer would.
