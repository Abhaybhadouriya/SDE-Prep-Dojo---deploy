Remember this

  • Run mocks under a real timer, in the real medium (whiteboard for Amazon-style, IDE for Flipkart and Atlassian-style), out loud.
  • Amazon-style: about 30 minutes of design. Clarify, five classes, the state machine, two core methods in real code, a traced example.
  • Flipkart-style: first flow running by minute 40, all P0 by 70, driver with refused cases by 90, bonus and a thread race after.
  • Atlassian-style: tests first, then refactor-then-extend for each follow-up; never rewrite.
  • Put each axis of change behind one table or interface early: status moves, assignment policy, charge rules, storage.
  • Money is BigDecimal / Decimal; time is an injected clock; both make tests deterministic.
  • Grade the gates first. A 0 on "runs" or "P0 complete" outweighs everything else.
