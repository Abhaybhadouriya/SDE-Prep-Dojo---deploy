What GRASP is

GRASP stands for General Responsibility Assignment Software Patterns. Craig Larman described it in his book Applying UML and Patterns. Unlike the Gang of Four design patterns (Strategy, Observer and so on), GRASP does not give you ready-made class structures. It gives you reasons - the thinking you do before a pattern even comes into the picture.

Two words first:

  • Responsibility - something a class must know (its data, things it can compute) or do (change itself, create other objects, call other objects, coordinate work).
  • Assignment - choosing which class gets that responsibility. Every method you write is an assignment decision, whether you think about it or not.

There are nine principles. It helps to see them as three groups:

PrincipleThe question it answersOne-line rule (our words)
Information ExpertWho does this calculation?The class that already holds the data needed.
CreatorWho calls new X()?The class that contains, records, closely uses, or has the start-up data for X.
ControllerWho first receives a system event (button, API call)?A non-UI class that stands for the whole system or one use case, and only coordinates.
Low CouplingIs this choice adding too many links?Prefer the option where classes know fewer other classes.
High CohesionIs this class still focused?Prefer the option where each class does one related set of things.
PolymorphismHow do I handle "it depends on the type"?Give the varying behaviour to the types themselves, not to an if/else ladder.
Pure FabricationWhat if no domain class fits?Invent a helper class (repository, service) to keep cohesion and coupling healthy.
IndirectionHow do I stop two things knowing each other?Put an object in the middle that both talk to.
Protected VariationsWhere will change come from?Wrap each predicted point of change behind a stable interface.

From your world

You already apply GRASP in C. skb_put(), skb_pull() and skb_headroom() live next to struct sk_buff because only that code should touch head, data and tail - that is Information Expert. alloc_skb() is the one place that builds an skb - Creator. The driver's ndo_start_xmit sits behind struct net_device_ops so the stack never knows which NIC it drives - Protected Variations. GRASP just gives these instincts names you can say out loud in an interview.
