Quiz

Which class should own minutesParked(exitTime)?

  1. ParkingController, because it handles the exit
  2. Ticket, because it stores the entry time
  3. ParkingLot, because it issued the ticket
Information Expert: the ticket holds the entry time, so it can compute the duration without asking anyone.

Which is NOT one of Larman's Creator conditions for "B creates A"?

  1. B contains or aggregates A
  2. B has the data needed to initialise A
  3. B is the class with the fewest methods
  4. B closely uses A
Creator looks at containment, recording, close use and initialisation data. Class size is not a criterion.

The exit gate's UI calls controller.onExit(id). What should the controller do?

  1. Coordinate: find the ticket, ask pricing for the fee, charge, free the spot
  2. Compute hours and rates itself so the logic is in one place
  3. Render the receipt HTML
A controller coordinates and handles failures. Calculations belong to experts; rendering belongs to the UI.

TicketRepository does not exist in a real parking lot. Which GRASP principle justifies it?

  1. Information Expert
  2. Pure Fabrication
  3. Creator
A pure fabrication is an invented class that keeps domain classes cohesive and decoupled from storage.

Payment vendors will change often. What is the best GRASP response?

  1. Add an if/else per vendor in the controller
  2. Make every class in the system an interface
  3. Protected Variations: a stable PaymentGateway interface with one adapter per vendor
Wrap the predicted point of change only. Interfaces everywhere is speculative generality.

The same switch (vehicleType) appears in three methods. Which principle cures it?

  1. Polymorphism
  2. Controller
  3. Low Coupling
Give the type-dependent behaviour to the types (rich enum or interface) so callers never switch.

In the Linux kernel, struct tcp_congestion_ops is closest to which GRASP idea?

  1. Creator
  2. Protected Variations (via polymorphism)
  3. Information Expert
Congestion control was predicted to vary, so TCP calls an ops table and algorithms plug in behind it.
