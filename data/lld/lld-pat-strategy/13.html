Quiz

In the Strategy pattern, what does the context know about its strategy?

  1. Its concrete class, so it can cast it
  2. Only the strategy interface
  3. Nothing; strategies call the context
  4. The list of all strategies
The context depends only on the interface. That is what makes new strategies free to add.

A parking lot needs a new "airport" tariff. With Strategy, what changes?

  1. The ExitGate's fee method gets a new branch
  2. Every existing strategy
  3. A new strategy class, plus one line where strategies are chosen
  4. The FeeStrategy interface
Add a class and register it. The context and existing strategies are untouched.

Which is a Strategy in the JDK?

  1. java.util.Comparator passed to List.sort
  2. java.lang.Thread.State
  3. java.util.Iterator
  4. java.lang.Runtime.getRuntime()
The sort is the context; the comparator decides the order. Thread.State is an enum of states, Iterator is Iterator, getRuntime is a singleton.

A vending machine moves from idle to has-coin to dispensing, and each state decides the next one. Which pattern is that?

  1. Strategy
  2. Decorator
  3. Template Method
  4. State
The delegate changes because of events and the states choose their successors: State, not Strategy.

In Linux, how does one socket choose BBR instead of the default?

  1. Recompile the kernel
  2. setsockopt(fd, IPPROTO_TCP, TCP_CONGESTION, "bbr", 3)
  3. Edit tcp_input.c
  4. It cannot; it is system-wide only
Per-socket selection by name, as long as the algorithm is registered (built in or loaded as a module); the sysctl sets the default.

When is Strategy over-engineering?

  1. When there are four payment methods
  2. When the algorithm is chosen by config
  3. When there is one algorithm and no second one is expected
  4. When strategies are stateless
One implementation behind an interface adds a type and indirection for no gain. Add it when the second variant appears.

Two threads share a stateless HourlyFee instance. Is that safe?

  1. Yes, it has no mutable state
  2. No, strategies must always be per thread
  3. Only with synchronized
  4. Only in Python
No shared mutable state means no race. Stateful strategies are the ones that need care.
