What makes an add-on class a Decorator rather than just a helper?

  1. It has a price field
  2. It extends BaseBeverage
  3. It implements Beverage and holds a Beverage it forwards to

Which construct guarantees at most N drinks brewing in parallel and queues the rest?

  1. A fixed thread pool of N threads
  2. A new thread per order
  3. A synchronized brew method
  4. A ConcurrentHashMap of outlets
A fixed pool runs at most N tasks; extra tasks wait in its queue. A synchronized brew allows only one.

Why call low-stock listeners after releasing the inventory lock?

  1. Listeners are not thread safe
  2. It makes alerts arrive in order
  3. A slow or re-entrant listener cannot stall every order or deadlock
  4. Java forbids calls under a lock
Collect the events under the lock, deliver them outside it.

When should you introduce the State pattern into this design?

  1. Always, for every LLD machine
  2. When the machine gains modes or a multi-step flow (maintenance, select-pay-pour)
  3. When there are more than 4 drinks
  4. Never
Without modes the machine behaves the same at all times; State earns its place only when behaviour depends on a mode.
