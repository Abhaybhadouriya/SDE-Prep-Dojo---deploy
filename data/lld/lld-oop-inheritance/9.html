Remember this

  • Inheritance = reuse + substitution. Use it only for a strict is-a where the child keeps every parent promise.
  • Java classes: single, multilevel, hierarchical. Multiple inheritance only through interfaces. C++ and Python allow all shapes.
  • Static init runs once per class, parent first. Constructors: super() calls go up, bodies run top-down. C++ destructors run bottom-up.
  • super(...) must be first; super.m() extends a parent method instead of copying it. Constructors are not inherited.
  • Instance methods are overridden (runtime type decides). Static methods and fields are hidden (static type decides). Always mark @Override / override.
  • Diamond: C++ two copies unless virtual; Java default methods: class wins, then most specific, else override with X.super.m(); Python C3 MRO.
