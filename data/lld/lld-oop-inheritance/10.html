  1. EthernetPort.kind()
  2. Device.kind()
  3. Compile error
Static methods are hidden, not overridden; the static type Device decides at compile time.

A Java class implements two interfaces that both have default void log(), with no superclass method. What happens?

  1. The first interface listed wins
  2. The last one wins
  3. Compile error unless the class overrides log()
Unrelated defaults conflict; the class must override and may call A.super.log().

In C++ with struct L3 : Switch, Router (both non-virtually derived from Device), how many Device sub-objects does an L3 have?

  1. Two
  2. One

Without virtual inheritance each path brings its own base sub-object.

With virtual inheritance, who constructs the shared virtual base?

  1. The first intermediate class listed
  2. The most-derived class

Intermediate classes' calls to the virtual base constructor are ignored when they are not most-derived.

For new C() where C extends B extends A, which body runs first?

  1. C
  2. B
  3. A
Constructor calls go up via super(); bodies run from the root down.

What does Python's super() call?

  1. The next class in the instance's MRO
  2. Always the first base class listed
  3. All base classes at once
That is why cooperative super() calls run each class in a diamond exactly once.
