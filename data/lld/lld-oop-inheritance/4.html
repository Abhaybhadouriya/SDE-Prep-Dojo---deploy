static: belongs to the class, not to an object

A static field has one copy per class, shared by all instances (like a global variable with a namespace and access control). A static method has no this; it can only use its parameters and static fields. You call it on the class: Vlan.of(100), Math.max(a, b).

Uses: counters and ID generators, constants (static final), factory methods, caches, the Singleton instance. Dangers: static mutable state is shared global state, so it needs synchronisation under threads and makes tests leak into each other. In machine-coding reviews, a static HashMap acting as the "database" is a common deduction; prefer an injected repository object.
