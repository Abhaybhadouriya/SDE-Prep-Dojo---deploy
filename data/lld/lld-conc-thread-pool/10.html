Every tab is a complete file from lld-code/lld-conc-thread-pool/, followed by its real output. MiniThreadPool.java has core/max, keep-alive, four rejection policies, Futures, shutdown, shutdownNow, awaitTermination, and replays the scenarios on the real JDK classes. Scenario 3b is a regression test for a shutdown bug a reviewer found in an earlier version (see the callout below).

How these were run. Java 21 and Python 3.11 on Windows. The C++ needs a POSIX-threads compiler: we built it with g++ -std=c++14 -O2 -Wall -pthread (g++ 13.3) in WSL Ubuntu 24.04; any Linux works, as does MinGW-w64 with the "posix" thread model. The MinGW.org g++ 6.3 that ships on many Windows machines uses the win32 thread model and has no std::thread or std::mutex, so it fails with "'mutex' in namespace 'std' does not name a type". import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.locks.*;

/**
 * A small ThreadPoolExecutor look-alike, written for the SDE Prep Dojo page
 * "Thread Pools, Executors & Futures". It follows the same submit algorithm as
 * java.util.concurrent.ThreadPoolExecutor: core threads first, then the queue,
 * then extra threads up to max, then the rejection policy.
 *
 * Run: javac MiniThreadPool.java && java MiniThreadPool
 */
public class MiniThreadPool implements Executor {

    // ---- Strategy: what to do when the pool is saturated -------------------
    public interface RejectionPolicy { void reject(Runnable task, MiniThreadPool pool); }

    public static final RejectionPolicy ABORT = (t, p) -> {
        throw new RejectedExecutionException("pool saturated: " + t);
    };
    public static final RejectionPolicy CALLER_RUNS = (t, p) -> {
        if (!p.isShutdown()) t.run();          // the submitting thread does the work = backpressure
    };
    public static final RejectionPolicy DISCARD = (t, p) -> { /* silently drop */ };
    public static final RejectionPolicy DISCARD_OLDEST = (t, p) -> {
        if (!p.isShutdown()) { p.queue.poll(); p.execute(t); }
    };

    // ---- state ---------------------------------------------------------------
    private static final int RUNNING = 0, SHUTDOWN = 1, STOP = 2, TERMINATED = 3;
    private volatile int state = RUNNING;

    private final int core, max;
    private final long keepAliveNanos;
    private final BlockingQueue<Runnable> queue;
    private final RejectionPolicy policy;
    private final String name;
    private final AtomicInteger threadSeq = new AtomicInteger();

    private final ReentrantLock mainLock = new ReentrantLock();   // guards workers + state changes
    private final Condition terminated = mainLock.newCondition();
    private final Set<Worker> workers = new HashSet<>();
    private int largest;

    public MiniThreadPool(String name, int core, int max, long keepAlive, TimeUnit unit,
                          BlockingQueue<Runnable> queue, RejectionPolicy policy) {
        if (core < 0 || max <= 0 || max < core) throw new IllegalArgumentException("bad sizes");
        this.name = name; this.core = core; this.max = max;
        this.keepAliveNanos = unit.toNanos(keepAlive);
        this.queue = Objects.requireNonNull(queue);
        this.policy = Objects.requireNonNull(policy);
    }

    // ---- the submit algorithm (same order as ThreadPoolExecutor.execute) -----
    @Override public void execute(Runnable task) {
        Objects.requireNonNull(task);
        if (state != RUNNING) { policy.reject(task, this); return; }
        if (addWorker(task, true)) return;                  // 1. fewer than core threads: new thread
        if (queue.offer(task)) {                             // 2. else try to queue it
            if (state != RUNNING && queue.remove(task)) policy.reject(task, this);
            else if (workerCount() == 0) addWorker(null, false);   // core may be 0
            return;
        }
        if (addWorker(task, false)) return;                 // 3. queue full: extra thread up to max
        policy.reject(task, this);                           // 4. saturated
    }

    public <T> Future<T> submit(Callable<T> c) {
        FutureTask<T> f = new FutureTask<>(c);   // the future captures the result OR the exception
        execute(f);
        return f;
    }

    private boolean addWorker(Runnable first, boolean asCore) {
        Worker w;
        mainLock.lock();
        try {
            if (state != RUNNING && !(state == SHUTDOWN && first == null && !queue.isEmpty())) return false;
            if (workers.size() >= (asCore ? core : max)) return false;   // check + add under one lock
            w = new Worker(first);
            workers.add(w);
            largest = Math.max(largest, workers.size());
        } finally { mainLock.unlock(); }
        w.thread.start();
        return true;
    }

    // ---- a worker: one thread that keeps pulling tasks -----------------------
    private final class Worker implements Runnable {
        final Thread thread;
        final ReentrantLock runLock = new ReentrantLock();   // held while a task runs
        Runnable first;
        Worker(Runnable first) {
            this.first = first;
            this.thread = new Thread(this, name + "-" + threadSeq.incrementAndGet());
        }
        @Override public void run() {
            Runnable task = first; first = null;
            try {
                while (task != null || (task = getTask(this)) != null) {
                    runLock.lock();
                    try {
                        if (state >= STOP) thread.interrupt();
                        else Thread.interrupted();          // clear a stray idle-interrupt
                        try { task.run(); }
                        catch (Throwable t) {              // real TPE: thread dies, a new one replaces it
                            System.out.println("  [" + thread.getName() + "] task threw " + t);
                        }
                    } finally { runLock.unlock(); task = null; }
                }
            } finally { workerExit(this); }
        }
    }

    /** Blocks for the next task; returns null when this worker should exit. */
    private Runnable getTask(Worker self) {
        while (true) {
            int s = state;
            if (s >= STOP || (s == SHUTDOWN && queue.isEmpty())) return null;
            boolean timed = workerCount() > core;          // extra threads may time out
            try {
                Runnable r = timed ? queue.poll(keepAliveNanos, TimeUnit.NANOSECONDS) : queue.take();
                if (r != null) return r;
                if (tryRetire(self)) return null;                // idle for keepAlive: shrink back to core
            } catch (InterruptedException e) {
                // woken by shutdown(): loop and re-check state
            }
        }
    }

    private boolean tryRetire(Worker self) {
        mainLock.lock();   // check and remove together, so two idle threads cannot both retire below core
        try {
            if (workers.size() <= core) return false;
            workers.remove(self);
            return true;
        } finally { mainLock.unlock(); }
    }

    private void workerExit(Worker w) {
        mainLock.lock();
        try {
            workers.remove(w);
            if (state == SHUTDOWN && !queue.isEmpty() && workers.isEmpty()) {
                // keep draining: start one more worker outside the lock
            } else if (state >= SHUTDOWN && workers.isEmpty()) {
                state = TERMINATED;
                terminated.signalAll();
                return;
            } else {
                // Pass the shutdown on. A worker that was busy when shutdown() ran was never
                // interrupted; if it then lost the race for the last queued task it sleeps in
                // take() forever. Each exiting worker wakes one idle worker, so the chain
                // reaches everybody (the real TPE does this in tryTerminate()).
                if (state >= SHUTDOWN) interruptIdleWorkers(true);
                return;
            }
        } finally { mainLock.unlock(); }
        addWorker(null, false);
    }

    /** Caller holds mainLock. A worker whose runLock is free is idle (blocked in getTask). */
    private void interruptIdleWorkers(boolean onlyOne) {
        for (Worker w : workers) {
            if (w.runLock.tryLock()) {
                try { w.thread.interrupt(); } finally { w.runLock.unlock(); }
            }
            if (onlyOne) return;
        }
    }

    private int workerCount() {
        mainLock.lock();
        try { return workers.size(); } finally { mainLock.unlock(); }
    }

    // ---- lifecycle -----------------------------------------------------------
    /** Stop accepting, finish queued work, wake idle workers so they can exit. */
    public void shutdown() {
        mainLock.lock();
        try {
            if (state == RUNNING) state = SHUTDOWN;
            interruptIdleWorkers(false);                     // idle = not running a task
            if (workers.isEmpty()) { state = TERMINATED; terminated.signalAll(); }
        } finally { mainLock.unlock(); }
    }

    /** Stop now: interrupt everybody and hand back the tasks that never ran. */
    public List<Runnable> shutdownNow() {
        List<Runnable> left = new ArrayList<>();
        mainLock.lock();
        try {
            if (state < STOP) state = STOP;
            for (Worker w : workers) w.thread.interrupt();
            queue.drainTo(left);
            if (workers.isEmpty()) { state = TERMINATED; terminated.signalAll(); }
        } finally { mainLock.unlock(); }
        return left;
    }

    public boolean awaitTermination(long t, TimeUnit unit) throws InterruptedException {
        long nanos = unit.toNanos(t);
        mainLock.lock();
        try {
            while (state != TERMINATED) {
                if (nanos <= 0) return false;
                nanos = terminated.awaitNanos(nanos);
            }
            return true;
        } finally { mainLock.unlock(); }
    }

    public boolean isShutdown() { return state != RUNNING; }
    public int poolSize() { return workerCount(); }
    public int largestPoolSize() { mainLock.lock(); try { return largest; } finally { mainLock.unlock(); } }

    // ======================================================================
    static void sleep(long ms) { try { Thread.sleep(ms); } catch (InterruptedException e) { Thread.currentThread().interrupt(); } }

    public static void main(String[] args) throws Exception {
        System.out.println("1) core=2 max=4 queue=2, AbortPolicy, 8 slow tasks");
        MiniThreadPool p = new MiniThreadPool("mini", 2, 4, 200, TimeUnit.MILLISECONDS,
                new ArrayBlockingQueue<>(2), ABORT);
        for (int i = 1; i <= 8; i++) {
            final int id = i;
            try {
                p.execute(() -> { sleep(300); System.out.println("  task " + id + " ran on " + Thread.currentThread().getName()); });
                System.out.println("  submit " + id + " accepted, poolSize=" + p.poolSize());
            } catch (RejectedExecutionException e) {
                System.out.println("  submit " + id + " REJECTED");
            }
        }
        sleep(900);
        System.out.println("  largest=" + p.largestPoolSize() + ", after keep-alive poolSize=" + p.poolSize());

        System.out.println("2) Future: result and exception");
        Future<Integer> ok = p.submit(() -> 6 * 7);
        Future<Integer> bad = p.submit(() -> { throw new IllegalStateException("boom"); });
        System.out.println("  ok.get() = " + ok.get());
        try { bad.get(); } catch (ExecutionException e) { System.out.println("  bad.get() threw ExecutionException caused by " + e.getCause()); }

        System.out.println("3) shutdown then submit");
        p.shutdown();
        System.out.println("  terminated in time: " + p.awaitTermination(2, TimeUnit.SECONDS));
        try { p.execute(() -> {}); } catch (RejectedExecutionException e) { System.out.println("  after shutdown: rejected"); }

        System.out.println("3b) regression: shutdown while both workers are busy and 1 task is queued");
        // Both running tasks finish together, then both workers race for the last queued task.

import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;

/** Races submit() against shutdown() many times: every ACCEPTED task must run.
 *  Run: javac FixedPool.java FixedPoolTest.java && java FixedPoolTest */
public class FixedPoolTest {
    public static void main(String[] args) throws Exception {
        int rounds = 500, lost = 0;
        for (int r = 0; r < rounds; r++) {
            FixedPool pool = new FixedPool(2, 1000);
            AtomicInteger accepted = new AtomicInteger(), ran = new AtomicInteger();
            CountDownLatch go = new CountDownLatch(1);
            Thread submitter = new Thread(() -> {
                try { go.await(); } catch (InterruptedException e) { return; }
                for (int i = 0; i < 200; i++) {
                    try { pool.submit(ran::incrementAndGet); accepted.incrementAndGet(); }
                    catch (RejectedExecutionException e) { break; }   // after shutdown: rejected, fine
                }
            });
            submitter.start();
            go.countDown();
            pool.shutdown();                       // races with the submitter
            submitter.join();
            pool.awaitTermination();
            if (ran.get() != accepted.get()) lost++;
        }
        System.out.println("rounds=" + rounds + ", rounds where an accepted task never ran: " + lost
                + (lost == 0 ? "  PASS" : "  FAIL"));
    }
}

// Fixed thread pool with futures in C++14, for the SDE Prep Dojo page
// "Thread Pools, Executors & Futures".
// Build: g++ -std=c++14 -O2 -pthread thread_pool.cpp -o thread_pool && ./thread_pool
// Needs a POSIX-threads g++ (Linux, WSL, or MinGW-w64 "posix"). We built and ran it with g++ 13.3 in
// WSL Ubuntu 24.04. The MinGW.org g++ 6.3 on Windows (win32 thread model) has no std::thread or std::mutex.
#include <condition_variable>
#include <deque>
#include <functional>
#include <future>
#include <iostream>
#include <memory>
#include <mutex>
#include <stdexcept>
#include <thread>
#include <vector>

class ThreadPool {
public:
    ThreadPool(size_t workers, size_t capacity) : capacity_(capacity) {
        for (size_t i = 0; i < workers; ++i)
            threads_.emplace_back([this] { loop(); });
    }
    ~ThreadPool() { shutdown(); }   // RAII: never leak running threads

    // Returns a future for the callable's result. Throws if the queue is full (AbortPolicy).
    template <class F>
    auto submit(F f) -> std::future<decltype(f())> {
        using R = decltype(f());
        auto task = std::make_shared<std::packaged_task<R()>>(std::move(f));
        std::future<R> fut = task->get_future();
        {
            std::lock_guard<std::mutex> g(m_);
            if (closed_) throw std::runtime_error("pool is shut down");
            if (q_.size() >= capacity_) throw std::runtime_error("rejected: queue full");
            q_.emplace_back([task] { (*task)(); });   // exceptions are stored in the future
        }
        cv_.notify_one();
        return fut;
    }

    void shutdown() {   // finish queued work, then join
        {
            std::lock_guard<std::mutex> g(m_);
            if (closed_) return;
            closed_ = true;
        }
        cv_.notify_all();
        for (auto& t : threads_) t.join();
    }

private:
    void loop() {
        for (;;) {
            std::function<void()> job;
            {
                std::unique_lock<std::mutex> lk(m_);
                cv_.wait(lk, [this] { return closed_ || !q_.empty(); });   // handles spurious wakeups
                if (q_.empty()) return;                                      // closed and drained
                job = std::move(q_.front());
                q_.pop_front();
            }
            job();   // run outside the lock
        }
    }

    std::mutex m_;
    std::condition_variable cv_;
    std::deque<std::function<void()>> q_;
    std::vector<std::thread> threads_;
    size_t capacity_;
    bool closed_ = false;
};

int main() {
    ThreadPool pool(2, 4);
    std::vector<std::future<int>> results;
    for (int i = 1; i <= 7; ++i) {
        try {
            results.push_back(pool.submit([i] {
                std::this_thread::sleep_for(std::chrono::milliseconds(100));
                return i * i;
            }));
            std::cout << "submit " << i << " accepted\n";
        } catch (const std::exception& e) {
            std::cout << "submit " << i << " " << e.what() << "\n";
        }
    }
    int sum = 0;
    for (auto& f : results) sum += f.get();
    std::cout << "sum of accepted squares = " << sum << "\n";

    auto bad = pool.submit([]() -> int { throw std::logic_error("boom"); });
    try { bad.get(); } catch (const std::exception& e) { std::cout << "future rethrew: " << e.what() << "\n"; }

    pool.shutdown();
    try { pool.submit([] { return 0; }); } catch (const std::exception& e) { std::cout << "after shutdown: " << e.what() << "\n"; }
}

"""Thread pool from scratch + concurrent.futures, for the SDE Prep Dojo page
"Thread Pools, Executors & Futures".  Run: python thread_pool.py
"""
import queue
import threading
import time
from concurrent.futures import Future, ThreadPoolExecutor, as_completed

_STOP = object()          # poison pill: one per worker on shutdown


class SimplePool:
    """Fixed workers + bounded queue. submit() returns a Future."""

    def __init__(self, workers: int, capacity: int):
        self._q: "queue.Queue" = queue.Queue(maxsize=capacity)
        self._closed = False
        self._lock = threading.Lock()
        self._threads = [threading.Thread(target=self._loop, name=f"py-{i + 1}") for i in range(workers)]
        for t in self._threads:
            t.start()

    def _loop(self) -> None:
        while True:
            item = self._q.get()
            if item is _STOP:
                return
            fut, fn, args = item
            if not fut.set_running_or_notify_cancel():   # cancelled while queued
                continue
            try:
                fut.set_result(fn(*args))
            except BaseException as e:                   # the future carries the error
                fut.set_exception(e)

    def submit(self, fn, *args) -> Future:
        with self._lock:
            if self._closed:
                raise RuntimeError("pool is shut down")
        fut: Future = Future()
        try:
            self._q.put((fut, fn, args), block=False)    # reject instead of blocking the caller
        except queue.Full:
            raise RuntimeError("rejected: queue full") from None
        return fut

    def shutdown(self) -> None:
        with self._lock:
            self._closed = True
        for _ in self._threads:
            self._q.put(_STOP)                           # queued work finishes first (FIFO)
        for t in self._threads:
            t.join()


def slow_square(x: int) -> int:
    time.sleep(0.1)
    return x * x

A bug we shipped, and the fix. An earlier MiniThreadPool could hang in awaitTermination. shutdown() interrupts only workers that are idle at that moment. Picture two workers busy and one task queued: both finish together, both see "queue not empty" and go for it, one wins, and the loser blocks in take(). Nobody ever interrupts it, so the pool never terminates. Scenario 3b reproduces it (273 of 300 rounds terminated on the old code). The fix is what the real ThreadPoolExecutor does in tryTerminate(): every worker that exits after shutdown interrupts one idle worker, so the wake-up passes down the chain until the last worker leaves (300 of 300). In an interview, "how does an idle worker learn about shutdown?" is exactly this follow-up.
