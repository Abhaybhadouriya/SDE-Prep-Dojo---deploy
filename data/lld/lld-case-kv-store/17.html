Quiz

Why does each entry store an absolute expiresAt instead of the TTL duration?

  1. It uses less memory
  2. Java requires it
  3. A read can decide "expired?" with one comparison, without knowing when the key was set
  4. It makes keys sort alphabetically
now < expiresAt is the whole lazy-expiry check; it also survives snapshots and restores.

A heap item (5 s, k, v6) is popped, but k is now at version 7. What should the sweep do?

  1. Delete k
  2. Drop the heap item and keep k
  3. Re-insert the item at 5 s
  4. Throw an exception
The item belongs to an older write; the current write has its own heap item.

Inside a transaction you delete key b, which exists in the store. How is this recorded?

  1. A tombstone entry for b in the top layer
  2. b is removed from the store immediately
  3. b is removed from the lower layers
  4. Nothing; deletes are not allowed in transactions
The tombstone hides b from this session; the store is untouched until commit.

T1 contains T2. T2 commits, then T1 rolls back. What reaches the store?

  1. T2's writes
  2. T1's writes
  3. Both
  4. Nothing
An inner commit only merges into T1; rolling back T1 discards everything.

Which transaction gets a ConflictException at commit?

  1. One that only wrote k while someone else also wrote k
  2. One that read nothing
  3. One that read k, after which another client committed a write to k
  4. One with nested levels
Only keys read from the store are validated; blind writes are last-writer-wins.

Why does get() under a read lock not remove the expired key it finds?

  1. Removing is O(n)
  2. It would need the write lock, and a read lock cannot be upgraded
  3. Expired keys must stay forever
  4. The listener would fire twice
Reporting it as absent is enough for correctness; a write or the sweeper removes it.

What makes our Snapshot a Memento rather than just a copy?

  1. Its state is private; only the store can read it or restore from it
  2. It is stored on disk
  3. It contains the transaction stack
  4. It is a Singleton
The caretaker keeps it without being able to look inside, which preserves the store's encapsulation.
