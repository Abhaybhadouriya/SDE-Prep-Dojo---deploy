Evaluator rubric checklist

  • Asked about TTL semantics, transaction scope and isolation before coding.
  • Absolute expiry stored per entry; reads correct at the deadline without a sweeper.
  • Active expiry without scanning all keys (heap or wheel), with stale items handled.
  • Transactions per client, nested, with tombstones for deletes.
  • Outer commit is atomic; others never see partial or uncommitted data.
  • Thread safety explained: what is shared, which lock, no lock upgrade, listeners outside locks.
  • Lost-update problem named and solved (version check or locks), with a retry path.
  • Memento keeps the snapshot opaque; cost of copying discussed.
  • Injected clock; tests that jump time; an invariant check.
  • Clean interface reused by store and session; clear exceptions.
