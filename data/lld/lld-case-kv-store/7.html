APIs and interfaces

interface KeyValueStore {
    Optional<String> get(String key);
    void    set(String key, String value);                 // clears an existing TTL
    void    set(String key, String value, Duration ttl);
    boolean delete(String key);
    boolean expire(String key, Duration ttl);              // false if missing
    long    ttlMillis(String key);                         // -2 missing, -1 no TTL
}

// InMemoryStore implements KeyValueStore, plus:
Session  session();
int      purgeExpired(int max);     // active expiry; call from a scheduler too
int      size();                    // live keys
Snapshot snapshot();                // Memento
void     restore(Snapshot s);
void     addListener(ExpiryListener l);

// Session implements KeyValueStore, plus:
void begin();
void commit();     // throws NoTransactionException, ConflictException (outermost only)
void rollback();   // innermost only
int  depth();

As a text protocol (the shape some rounds use, like the classic "simple database" exercise): SET k v [EX seconds], GET k, DEL k, EXPIRE k s, TTL k, BEGIN, COMMIT, ROLLBACK, SNAPSHOT / RESTORE id. A small command parser that maps each line to one interface call keeps the core free of parsing (a Command per line if they ask for undo or replay).
