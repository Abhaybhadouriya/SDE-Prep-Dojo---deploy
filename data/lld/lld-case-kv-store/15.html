Common mistakes

  • One global transaction stack shared by every client.
  • Storing the TTL as a duration instead of an absolute deadline, then not knowing when it started.
  • A thread or timer per key, or a full scan of the map on every call.
  • Forgetting stale heap items, so a rewritten key is deleted at its old deadline.
  • Deleting with remove() inside a transaction instead of a tombstone: the store's value shows through again.
  • Rollback that clears every level, or inner commit that writes to the store.
  • Applying a commit key by key without one lock: other clients see half a transaction.
  • Upgrading a read lock to a write lock in Java: the thread deadlocks on itself.
  • Calling listeners under the lock.
  • Returning the internal map as the "snapshot": later writes change it.
