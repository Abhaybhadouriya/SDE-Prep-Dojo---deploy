Identify the entities

  1. Nouns are class candidates.
  2. Verbs become methods; the same verbs exist with and without a transaction.
  3. Cut the false classes: a key is a string, a TTL is a field. A transaction is per client, so it lives in a Session, not inside the shared store.
  4. The final list. Both InMemoryStore and Session implement KeyValueStore, so any code that uses the store also works inside a transaction (Liskov substitution).

The design bug interviewers wait for: one transaction stack inside the store. It works in a single-client test and breaks the moment two clients call begin(): client B's rollback undoes client A's writes. Put the stack in a per-client session (or a ThreadLocal if the API has no session object).
