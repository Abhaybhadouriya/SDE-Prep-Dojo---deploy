Common mistakes

  • Shifting every cell on each move (an array copied per tick): O(length) per move, the exact thing Zomato asked you to avoid.
  • Deque only, no set: collision check walks the whole body.
  • Killing the snake on the tail cell, or the opposite: allowing it while growing.
  • Wrong order in advance: adding the head before removing the tail from the set loses a cell when they are the same.
  • Using % for wrap-around with negative numbers in Java or C++.
  • Reverse turn check against the current direction only, which lets a fast double turn reverse the snake.
  • Food placed under the snake, or an infinite random loop when the board is nearly full.
  • Sleeping inside the game logic: slow, flaky tests and no way to replay.
  • Printing inside Snake or Game instead of render() or a listener.
  • No tests and no exceptions: the reason the Atlassian P50 candidate was not hired despite running code.
