The multiplayer row is the one to think about out loud. With two snakes, the order of moves matters: if snake A moves first, snake B's old tail is still there. The fair way is compute all next heads, then decide collisions, then move all, the same two-phase idea as reading all inputs before updating state in a hardware simulation.
