How it is asked

Before you start: this case assumes OOP from C structs (objects as structs with an ops table) and interfaces vs abstract classes. The patterns it uses are explained on their own pages: Strategy, Observer, State. The input buffer is the producer-consumer shape.

The snake game is a favourite of Atlassian's code design round: 60 minutes, running code, tests, and new requirements added while you code. Zomato asked it as a whiteboard design with pseudocode. The P50 report is the lesson of this page: running code is not enough in a code design round. The same round graded unit tests, exceptions for bad input and corner cases. Plan time for tests from the start (see the 90-minute plan), and treat "what happens at the wall?" as a question you ask, not a detail you guess.

The algorithm core is LeetCode 353 Design Snake Game (premium): a constructor (width, height, food) and move(direction) returning the score or -1. Our code implements that exact API as one entry point, then grows it into a real game. Do not confuse this with Snake & Ladder, a dice board game asked at Flipkart and PhonePe.
