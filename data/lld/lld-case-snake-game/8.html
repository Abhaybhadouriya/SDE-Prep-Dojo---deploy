APIs and interfaces

interface BoundaryPolicy { Position next(Position head, Direction d, Board b); }   // null = wall hit
interface FoodSpawner    { Position next(Board b, Snake s); }                        // null = no food left
interface GrowthRule     { int growth(boolean ateFood, long tick); }                 // cells to add this tick
interface GameListener   { default void onFoodEaten(int score, Position at) {}
                           default void onGameEnd(Status s, Cause c, int score) {} }

// Game: the only class drivers and UIs talk to
static Game classic(int height, int width, int[][] food);    // LeetCode 353 setup
Game(Board b, Position start, Direction d, BoundaryPolicy bp, FoodSpawner fs, GrowthRule gr);
boolean  turn(Direction d);    // false if ignored: reverse, repeat, buffer full, game over
Status   tick();               // advance one step, return the new status
int      move(Direction d);    // LeetCode 353: turn + tick, returns score or -1
Status   status();  Cause cause();  int score();
Position head();  Position tail();  int length();  Position food();
String   render();             // H = head, o = body, * = food

turn() returns a boolean instead of throwing, because an ignored key press is normal in a game, not an error. Real errors (board smaller than 1 x 1, a start cell off the board) throw IllegalArgumentException in the constructor: the P50 candidate above lost points for missing exception handling, and this split (expected events return a value, broken setup throws) is the answer to give.
