How the body moves in O(1)

This is the heart of the problem, so it gets its own picture. Body cells are kept head first in a deque, and also in a set.

  1. A snake of length 3 moving right. The deque keeps order; the set keeps membership.
  2. A normal move: drop the tail, push the new head. The cells in the middle are not touched, so the cost does not depend on length.
  3. Eating: the growth is recorded before moving, so the tail stays and the length becomes 4.
  4. Tail chase: moving into the cell the tail is leaving is legal. A check that only asks "is it in the set?" wrongly kills the snake here.
  5. The same move on a growing tick is a collision, because the tail does not leave. That is why growth is applied before the collision check.

Inside advance(), remove the old tail from the set before adding the new head. If the head enters the old tail cell, the other order removes the head you just added and the set loses a cell. Our consistent() check (deque size equals set size) catches it in tests.
