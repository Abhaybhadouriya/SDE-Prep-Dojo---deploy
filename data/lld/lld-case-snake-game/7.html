Core flow: one tick

  1. The loop thread (or a test) calls tick(). Nothing moves without a tick, so tests are deterministic.
  2. The game takes its lock. If the game is over it returns at once. It applies at most one buffered turn per tick.
  3. The boundary strategy computes the next head cell: walls return null at the edge, wrap returns the cell on the other side.
  4. Null means the head left the board: end the game with cause HIT_WALL and notify listeners.
  5. Record growth first (food, or the periodic rule), then ask the snake if the next cell is its body, with the tail exception.
  6. Advance: push the head, and pop the tail unless growth is pending. O(1).
  7. If food was eaten: score +1, notify listeners, ask the spawner for a free cell. The spawner returns null when the board is full.
  8. If the snake now fills the board, the game is WON. The status goes back to the caller.
