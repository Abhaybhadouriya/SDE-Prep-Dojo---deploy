Remember this

  • Deadlock = a cycle of threads each waiting for what another holds. It needs all four: mutual exclusion, hold-and-wait, no preemption, circular wait.
  • Default fix: one global lock order (sort by id). For N resources, sort and lock in that order.
  • When order is unknown: tryLock(timeout), release on failure, random back-off, a deadline.
  • Never call listeners, callbacks or other services while holding your lock: snapshot, release, then call.
  • Detect with jstack / findDeadlockedThreads(); databases detect row-lock cycles and abort one transaction, so retry.
  • Livelock = busy but no progress (fix: jitter). Starvation = one thread never wins (fix: fair lock, short critical sections).
  • Kernel bridge: ABBA, lockdep lock classes, rt-mutex priority inheritance.
