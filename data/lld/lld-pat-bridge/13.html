Quiz

You have 4 report types and 3 export formats. With Bridge, how many concrete classes do you need?

  1. 12
  2. 4
  3. 7
  4. 1
M + N = 4 + 3. Inheritance alone would need M x N = 12.

In Bridge, what does "abstraction" mean?

  1. The high-level side that clients use, which holds a reference to an implementor
  2. Any abstract class
  3. The interface every driver implements
  4. A class with no fields
The GoF term is about layers, not the abstract keyword.

In the Linux VFS, which part plays the Implementor role?

  1. vfs_read()
  2. f_pos
  3. The syscall table
  4. struct file_operations from each filesystem or driver
Generic VFS code is the abstraction; file_operations is the implementor it calls through f_op.

The key difference between Bridge and Adapter is:

  1. Adapter uses composition, Bridge uses inheritance
  2. Bridge is designed up front to let both sides vary; Adapter retro-fits an existing mismatched interface
  3. Bridge only works in C
  4. Adapter needs two hierarchies
Both use composition; they differ in intent and timing.

Where should "trim the message to the channel's length limit" live in our notification Bridge?

  1. Copied into every channel
  2. In the client
  3. On the abstraction side, using channel.maxChars()
  4. In a global helper singleton
Shared policy goes on the abstraction side, built from implementor primitives, so it is written once.

Which situation does NOT call for Bridge?

  1. One payment interface with a single implementation and no second planned
  2. Shapes that must render on OpenGL and Vulkan
  3. Notification kinds sent over several channels
  4. A GUI toolkit for three operating systems
One dimension and one implementation: an interface (or nothing) is enough.
