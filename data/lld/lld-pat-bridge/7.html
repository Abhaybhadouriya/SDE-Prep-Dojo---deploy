Real-world uses

WhereAbstraction (what)Implementation (how)
Linux VFSstruct file, vfs_read(), vfs_write()file_operations from ext4, XFS, NFS, procfs, char drivers
Linux networkingstruct net_device and the core stacknet_device_ops per NIC driver
JDBCThe java.sql API your code calls (Connection, PreparedStatement)Vendor drivers (PostgreSQL, MySQL) found through DriverManager. Commonly cited as a Bridge.
SLF4JThe org.slf4j.Logger APIA binding to Logback, Log4j 2 or JUL chosen at deploy time
Python DB-API (PEP 249)One calling convention: connect(), cursor(), execute()sqlite3, psycopg, other driver modules
GUI toolkitsWidgets (Button, Window)Platform back-ends (Windows, macOS, X11/Wayland)
GraphicsShapes and scenesRenderers (OpenGL, Vulkan, software raster)

Notice a pattern in the list: Bridges usually show up at platform boundaries, where a library must run on many back-ends and also offer a rich, growing API to its users.
