Identification quiz

A Document holds a DocState. Draft.publish() sets the document's state to Moderation, and Moderation.approve() sets it to Published. Which pattern?

  1. Strategy
  2. Command
  3. State
  4. Observer
The states choose their successors, so behaviour changes with mode: State.

new GzipStream(new EncryptStream(new FileStream(path))). Which pattern?

  1. Decorator
  2. Composite
  3. Proxy
  4. Facade
Same interface, one wrapped object each, stacked by the client, every layer forwards: Decorator.

An ImageProxy loads a 50 MB image from disk only the first time draw() is called. Which pattern?

  1. Decorator
  2. Flyweight
  3. Adapter
  4. Proxy (virtual proxy)
It controls when the real object is created and used: a virtual proxy.

You wrap a vendor's sendSms(String phone, String text, int priority) SDK so it implements your Channel.deliver(User, Message) interface. Which pattern?

  1. Bridge
  2. Adapter
  3. Facade
  4. Strategy
One existing interface converted to a required one, after the fact: Adapter.

A request passes through AuthHandler, RateLimitHandler and CacheHandler; the cache handler returns a response without calling the next one on a hit. Which pattern best describes this?

  1. Decorator
  2. Composite
  3. Chain of Responsibility
  4. Mediator
A link may handle the request and stop: Chain of Responsibility.

A UIFactory with createButton(), createMenu() and createDialog() has DarkThemeFactory and LightThemeFactory implementations. Which pattern?

  1. Abstract Factory
  2. Factory Method
  3. Builder
  4. Prototype
A family of matching products from one factory object: Abstract Factory.

In a chat room, users never message each other directly; a ChatRoom object receives every message and decides who receives it based on mute and block rules. Which pattern?

  1. Observer
  2. Facade
  3. Proxy
  4. Mediator
Many-to-many interaction with central rules: Mediator.

An editor stores InsertText(pos, "abc") objects on a stack, and undo calls each object's undo(). Which pattern is doing the undo?

  1. Memento
  2. Command
  3. Iterator
  4. Strategy
Stored operations that know how to reverse themselves: Command.
