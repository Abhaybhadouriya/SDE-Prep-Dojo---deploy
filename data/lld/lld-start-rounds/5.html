Archetype C: code design and "running LLD" in a 60-minute slot

Uber, Atlassian and many Microsoft loops sit between A and B: the slot is a normal 60 minutes, but they expect real code that runs, and they grow the problem in stages.

  • Uber (34 reports, 28 with running code): often called "Coding 2" or "Depth in Specialization", 60 minutes on CodeSignal or HackerRank, fully running code, frequently with multithreading follow-ups. Repeats include an in-memory file system, parking lot, car rental, pub-sub and a counter with expiry.
  • Atlassian (11 reports, all "code design"): 60 minutes of runnable code with tests and staged follow-ups. Repeats: snake game, agent rating system, wildcard router, subscription cost explorer. Atlassian's own interview page describes a coding interview in two parts, data structures and code design, where you choose your language and reasoning and trade-offs count more than perfect syntax (Atlassian).
  • Microsoft (36 reports: 18 running code, 14 whiteboard): 60-75 minutes; many report near-complete code plus locking questions. Some 2026 loops run an AI-assisted LLD round.

What "done" means here

Each stage works when the interviewer asks for it, and your earlier code survives. Write a few tests or a tiny assertion driver from the start, so "does part 1 still work?" takes ten seconds. The design skill on show is making the next change cheap: a comparator you can swap, a Map you can wrap in a lock, a class you can add.
