Ask the recruiter (copy this)

Recruiters will usually tell you the format if you ask precisely. Send these questions when the loop is scheduled:

  1. Format. "Is the LLD round a discussion with a class diagram, or will I write code that runs? If code, how long is the coding part?"
  2. Tooling. "Which platform - my own IDE, CoderPad, HackerRank, CodeSignal? Can I choose the language?"
  3. AI policy. "Are AI assistants allowed, or forbidden?"
  4. Review. "Is there a separate evaluation or review call after the coding?"
  5. Scope hints. "Should I expect concurrency, database schema or API questions in this round?"

If they cannot say, prepare for archetype C: it covers both others. Practise each case study twice: once as a 45-minute talk with a diagram, once as a 90-minute running program.
