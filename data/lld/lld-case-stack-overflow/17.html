Ben's answer has one upvote (ben is at 11). The voter changes it to a downvote. What is ben's reputation now?

  1. 9
  2. 11
  3. 1 (the result, -1, is floored to 1)
  4. -1
Undo the upvote (11 - 10 = 1), then apply the downvote (1 - 2 = -1, floored to 1).

Which data structure makes "no duplicate votes" a single lookup?

  1. An int counter per post
  2. A map from voter id to vote type per post
  3. A list of all votes in the system
  4. A boolean on the user
One key per voter: a second vote finds the existing entry.

  1. A boolean flag in QaService

An answer with 1 vote is accepted; another has 5 votes. How are they shown?

  1. Accepted first, then the 5-vote answer
  2. 5-vote answer first
  3. Oldest first
  4. Random
The order is accepted, then score, then time.

Why is reputation an AtomicInteger rather than guarded by a user lock?

  1. Locks are not allowed on users
  2. Atomics are always faster than everything
  3. It is a single integer updated from many posts' votes; a CAS avoids nesting a user lock inside a post lock
  4. Reputation never changes concurrently
A single-variable update fits an atomic, and it removes the need for a lock order.
