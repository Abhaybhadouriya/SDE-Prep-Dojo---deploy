Questions people ask before starting

What is the difference between LLD and HLD in one sentence each?

HLD decides which services, stores and queues exist and how they scale and fail. LLD decides which classes, interfaces and methods exist inside one of those services, who owns each rule, and how the code absorbs change and runs safely with many threads.

How to answer

Give the zoom-level picture: city vs house. Then one example: "In HLD a notification service is one box; in LLD it is a NotificationService using a Channel interface with Email and SMS implementations."

Likely follow-ups
  • Can one round contain both? (Yes - Salesforce and Zepto reports describe LLD rounds that drift into schema and APIs.)
  • Where does a database schema belong? (Both: tables in HLD, repository classes in LLD.)
Do I need to memorise all 23 GoF design patterns?

No. A handful cover most case studies: Strategy, Observer, State, Factory, Singleton (thread-safe), Decorator, Command, Chain of Responsibility, Builder and Adapter. Know those deeply - when to use, when not to, and how they differ from their look-alikes. Recognise the rest by name.

How to answer

Show you choose patterns from change points: "The fee rule varies by vehicle type, so I used Strategy." Never start with "I will use the Factory pattern".

Likely follow-ups
  • Strategy vs State: what is the difference?
  • Why is Singleton often called an anti-pattern?
Will I have to write running code, or only draw diagrams?

It depends on the company and round type. Uber, Atlassian and many Microsoft loops expect code that runs; Flipkart, PhonePe and Razorpay run full machine-coding rounds; Amazon and Zepto lean on class diagrams plus key methods. Always ask the recruiter. How LLD rounds work has the counts.

How to answer

Practise both: a 45-minute whiteboard version and a 90-minute running version of the same problem.

Likely follow-ups
  • Which IDE and language will you use?
  • How do you test without a framework? (A driver main with assertions.)
I am a C/kernel engineer. Is it OK to answer LLD in C?

Usually the round is "any language", but an object-oriented language makes the design visible and saves time (no manual memory management, built-in collections). C++ is the natural bridge: same performance model, real classes and virtual functions. If you use Java or Python, mention that you know the C equivalent - it shows depth.

How to answer

Pick the language you can write fastest without bugs. Practise the collections and concurrency library of that language before the round.

Likely follow-ups
  • How does a virtual call work under the hood? (vptr, vtable - see polymorphism.)
  • How would you make this class thread-safe in your language?
