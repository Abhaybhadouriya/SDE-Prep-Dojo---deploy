Quiz

"Design the classes for a parking lot so a new vehicle type can be added easily." Which round is this?

  1. HLD
  2. LLD
  3. DSA
Classes and extensibility are the LLD unit. HLD would ask about servers and storage; DSA about one algorithm.

Which kernel construct is closest to a Java interface?

  1. spinlock_t
  2. list_head
  3. struct file_operations
  4. jiffies
It is a table of function slots that each driver fills, and callers use it without knowing the driver - exactly what an interface gives you.

An OrderService calls sendEmail() and sendSms() directly. What is the main LLD problem?

  1. Every new channel forces an edit to OrderService
  2. It is too slow
  3. It uses too much memory
The variation (channel) is hard-wired. An interface such as Notifier lets you add channels by adding classes (Open/Closed principle).

In a UML class diagram, a dashed line with a hollow triangle means:

  1. Composition
  2. A class implements an interface
  3. A method call
  4. A database link
Dashed + hollow triangle = realization ("implements"). A solid line + hollow triangle is inheritance ("extends").

What separates an SDE-2 LLD answer from an SDE-1 answer most?

  1. Using more design patterns
  2. Drawing UML perfectly
  3. Writing in Java
  4. Driving scope, defending choices, and handling edge cases and concurrency
The problems are the same; SDE-2 shows more ownership of requirements, trade-offs and robustness. More patterns is not better.

Where should a pattern come from in your answer?

  1. From a change point you identified ("the fee rule varies")
  2. From a list you memorised
  3. From the interviewer's company name
Patterns are solutions to a specific variation. Naming the variation first is what makes the pattern choice credible.
