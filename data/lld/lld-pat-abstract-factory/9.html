Simple FactoryOne productA static method with a switch on a keyVehicleFactory.create("car")

Abstract FactoryA family of several productsYou pass in a factory object (composition)An interface with createX(), createY(), createZ()
BuilderOne complex productStep-by-step calls, then build().a().b().c().build()
PrototypeA copy of an existing objectClone a configured instancetemplate.copy()
BridgeNothing (structural)Abstraction holds an implementorTwo hierarchies that vary independently; an abstract factory is a common way to create the right implementor

A useful way to say it: each method on an abstract factory is a factory method. Abstract Factory groups several of them on one object so they stay consistent. GoF also notes that concrete factories are often singletons (you need one per family) and are sometimes implemented with prototypes (clone a stored product instead of new). The look-alike patterns page has a quiz on telling these apart.
