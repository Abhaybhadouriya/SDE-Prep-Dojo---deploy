Level 4: threads, testing and cost

  • Threads. A builder is mutable and not thread-safe: keep it inside one method on one thread. The product it builds is immutable (all fields final), so it can be shared freely once build() returns.
  • Testing. Test build(), the single validation point: a missing required field throws, an invalid combination throws, defaults are applied.
  • Cost. One extra object and one field copy per build. Irrelevant except in a hot path, where a plain constructor or a reused builder wins.
