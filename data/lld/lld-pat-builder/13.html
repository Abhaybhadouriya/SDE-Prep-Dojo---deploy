Quiz

What is the main smell that suggests a Builder?

  1. A class with exactly one field
  2. Many subclasses of one base class
  3. Constructors with many optional parameters, several of the same type
  4. A global configuration object
Long, positional parameter lists with optional values (telescoping constructors) are the classic signal.

Where should a rule like "payload length must fit the MTU given the chosen headers" be checked?

  1. In build()
  2. In the payload setter only
  3. In the product's getters
  4. Nowhere, the caller is responsible
Rules that span several fields need every field, which is only guaranteed at build().

A teammate stores the caller's List<String> tags directly in the product in build(). What breaks?

  1. Nothing
  2. The code will not compile
  3. The builder becomes thread-safe
  4. The product is no longer really immutable: the caller can change the list afterwards
Without a defensive copy (for example List.copyOf), the product shares a mutable list with the caller.

What does the Director do in the GoF Builder?

  1. Validates the product
  2. Holds a fixed sequence of builder steps so it can drive any concrete builder
  3. Chooses which family of products to create
  4. Clones the product
The director knows the order of steps; concrete builders know how to perform each step for their representation.

Which JDK class is a textbook fluent builder producing an immutable object?

  1. java.util.ArrayList
  2. java.lang.Thread
  3. java.net.http.HttpRequest.Builder
  4. java.sql.Connection
HttpRequest.newBuilder()...build() returns an immutable request. Connection is closer to an abstract factory.

In the kernel's sk_buff analogy, what is the biggest difference from an application-level builder?

  1. The kernel validates nothing
  2. The skb is mutable and is both the builder and the product, to avoid copies
  3. Headers are added in a random order
  4. An skb can only hold one header
The kernel builds in place for zero-copy speed; application code usually pays one copy in build() to get immutability.
