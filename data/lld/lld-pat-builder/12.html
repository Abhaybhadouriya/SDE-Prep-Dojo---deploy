Remember this

  • Builder = configure a complex object step by step, then build() validates and returns the finished product.
  • Fixes telescoping constructors (unreadable positions) and setter soup (half-built mutable objects).
  • Fluent form: static nested builder, setters return this, private product constructor, final fields.
  • Required fields in the builder's constructor; cross-field rules in build(); defensive copies for arrays and lists.
  • Director = stored recipe of steps (optional). GoF form = same steps, different representations.
  • Factory = which class; Builder = how to assemble one object. In Python, keyword args often replace builders.
