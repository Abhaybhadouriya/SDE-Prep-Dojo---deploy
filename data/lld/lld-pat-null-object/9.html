Related and confused-with patterns

PatternRelation
StrategyA null object is often a "do nothing" strategy (NoDiscount is one pricing strategy among many).
StateAn "idle" or "closed" state whose handlers do nothing is a null object for that state machine.
SingletonStateless null objects are usually shared as one instance (an enum constant or a static final field).
Decorator / Chain of ResponsibilityA null object can end a chain or be the innermost component, so the last link needs no "is there a next?" test.
ProxyBoth stand in for a real object with the same interface; a proxy forwards to it, a null object has nothing to forward to.
Special Case (Fowler)The general form: a subclass for a particular case (guest, unknown, missing) that may have real behaviour, not only no-ops.
OptionalThe alternative when the caller must make a decision; see the table above.
