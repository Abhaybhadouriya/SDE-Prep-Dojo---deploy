Quiz

What does a Null Object do?

  1. Throws when called
  2. Implements the interface with neutral, do-nothing behaviour
  3. Wraps a real object and forwards calls
  4. Returns null from every method
Forwarding is Proxy or Decorator. A null object is a full, harmless implementation.

For which case is a Null Object a bad idea?

  1. Logging switched off
  2. No discount on an order
  3. No observers registered
  4. An unknown account id in a refund request
Silently treating an unknown account as "nobody" would lose money with no error. Absence must be loud here.

A method returns a list of matching products and finds none. It should return:

  1. An empty list
  2. null
  3. An exception
  4. A list containing null
"No results" is normal. The empty list is the null object for collections.

Why is NoDiscount written as an enum constant or a single static instance?

  1. Java requires null objects to be enums
  2. To make it mutable
  3. It is stateless, so one shared instance is enough and safe
  4. So it can be garbage collected
No state means no difference between instances and nothing for threads to corrupt.

Which is the closest kernel/Unix example of a Null Object?

  1. A spinlock
  2. /dev/null
  3. The page cache
  4. A NULL pointer in an ops table
/dev/null supports the normal file interface and does nothing. A NULL ops member is the opposite: callers must check it.

Callers keep writing if (customer.isGuest()) before every call. What does this tell you?

  1. The pattern is working
  2. You should return null instead
  3. The guest behaviour is not inside the guest class; the null check was only renamed
  4. You need a singleton
Move the special behaviour into GuestCustomer; keep isGuest() for the rare caller that truly must know.
