How it works: a guest checks out

  1. No customer id (a guest). The directory does not return null; it returns the shared GuestCustomer.
  2. Checkout asks for the discount exactly as it would for a member. The guest's answer is the shared NoDiscount.
  3. NoDiscount returns the neutral value, 0. No if was needed anywhere on the path.
  4. Checkout computes the total and logs. If logging is switched off, the logger is a NullLogger and that call does nothing.

The decision "what does nothing mean here?" was made once, in the null class, instead of at every call site.
