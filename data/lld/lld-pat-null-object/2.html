Intent

Null Object: provide an object that implements the expected interface with neutral, do-nothing behaviour, and use it wherever "no object" would otherwise be represented by null. Callers then treat "nothing" exactly like "something".

It is not one of the 23 Gang of Four patterns. It was first written up by Thomas Kühne (as "Void Value", 1996) and by Bobby Woolf in Pattern Languages of Program Design 3 (1998). Martin Fowler's Refactoring lists the matching step as Introduce Null Object, and his "Special Case" pattern is the general form (a GuestCustomer that does more than nothing).

The neutral value depends on the method: 0 for a discount, an empty list for a search, no-op for a log call, "guest" for a display name, false for "has permission".
