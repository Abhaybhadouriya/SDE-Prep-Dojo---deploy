The problem: null checks everywhere

An order service where the logger, the discount and the customer are all optional:

long total(String customerId, long subtotal) {
    Customer c = directory.find(customerId);          // may return null (guest, unknown id)
    long off = 0;
    if (c != null && c.discount() != null) {          // check 1 and 2
        off = c.discount().discountPaise(subtotal);
    }
    if (logger != null) {                              // check 3
        String who = (c != null) ? c.name() : "guest"; // check 4
        logger.log(who + " paid " + (subtotal - off));
    }
    return subtotal - off;
}
  • Four checks for three optional things, and every other method that touches them repeats the same checks.
  • One forgotten check is a crash. A new invoice() method calls c.discount() without the test; the first guest checkout throws NullPointerException in production.
  • The "nothing" behaviour is spread out. "Guest means no discount and the name 'guest'" is written in several places, slightly differently.
  • Business logic is buried under defensive code; the real line (subtotal - off) is hard to see.
