Structure: one interface, one real class, one null class

  • AbstractObject (DiscountPolicy): the interface the client uses.
  • RealObject (PercentOff): does real work.
  • NullObject (NoDiscount): implements every method with the neutral result. Usually stateless, so a single instance is shared.
  • Client (Checkout): calls the interface without asking which one it has.
  • Often a factory or repository hands out the null object (findOrGuest(id)), so null never enters the system in the first place.
