Remember this

  • Null Object = an implementation of the interface whose methods do the neutral thing (0, empty, no-op).
  • It moves the "what does absence mean?" decision from every caller into one class.
  • Stateless and immutable, so share one instance (enum constant, static final, function-local static).
  • Hand it out from factories, repositories-plus-services and constructor defaults so null never enters.
  • Do not use it when absence is an error; use Optional or an exception so the bug is loud.
  • Empty collections are the everyday null object: never return null for a list.
  • Kernel bridge: /dev/null, the dummy netdev and noop_llseek vs NULL ops members.
