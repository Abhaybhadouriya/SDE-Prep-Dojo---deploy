Level 4: threads, testing and cost

  • Threads. In-memory repositories need concurrent maps, but a business rule like "at most 3 loans" is check-then-update: hold one lock (or a database transaction) in the service across the check and the save.
  • Testing. The in-memory repository is the fake for service tests. Run one contract test suite against every implementation (in-memory, SQL) to prove they agree.
  • Cost. One interface call per access. The hidden cost is N+1 loading (one query per item); add intention-revealing query methods instead of looping over findById.
