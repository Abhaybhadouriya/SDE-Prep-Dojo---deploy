Remember this

  • Entity = data + own invariants. Repository = collection-like storage interface. Service = use cases + cross-entity rules + the lock.
  • Calls go down only: driver to service to repository; entities depend on nothing.
  • Repository methods use domain words and return entities (often Optional), never raw maps or rows.
  • ConcurrentHashMap makes single operations safe; compound check-then-act needs a service-level lock or transaction.
  • "Add a DB" = new repository class + one wiring line. Mention transactions and indexes.
  • Repository is domain-shaped; DAO is table-shaped.
  • Kernel bridge: VFS is the interface; ext4, NFS and in-RAM tmpfs are interchangeable implementations.
