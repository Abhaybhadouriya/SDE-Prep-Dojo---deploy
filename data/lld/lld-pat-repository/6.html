Repository vs DAO

A DAO (data access object) is table-shaped: BookDao.insert(row), updateStatus(id, s), one per table, often returning rows. A repository is domain-shaped: it returns whole entities (or aggregates) and its query names come from the business ("open loans of a member"). In practice a repository is often implemented using DAOs or an ORM. In an interview, say: "DAO abstracts the database; repository abstracts a collection of domain objects. In an in-memory LLD they look the same, but I name methods in domain words."
