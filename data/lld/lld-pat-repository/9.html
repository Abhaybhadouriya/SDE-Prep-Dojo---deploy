Related and confused-with patterns

PatternWhat it hidesHow it differs from Repository
RepositoryWhere entities are storedCollection-like, domain words, returns entities
DAODatabase access per tableLower level, table-shaped
FacadeA complex subsystemA service can look like a facade to the driver, but its purpose is use cases and rules, not just simplification
Dependency InjectionWho creates dependenciesDI is how the service gets its repositories; Repository is what they are
SpecificationA query rulePass a spec to repo.findAll(spec) instead of adding a new findByXAndYAndZ each time
SingletonInstance countRepositories are often single instances, but create one in main and inject it; a static getInstance() repository makes tests share data
Unit of WorkWhich changes form one commitPairs with repositories: tracks changed entities and commits them together
