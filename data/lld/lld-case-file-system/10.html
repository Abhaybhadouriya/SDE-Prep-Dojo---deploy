The command map, which some interviewers ask for when they want a console program. Strictly it is a dispatch table of command handlers (Command-lite): it becomes the full Command pattern only when each parsed request is an object you can queue, log or undo. The task scheduler's Task is the full version.

interface Command { String run(Shell sh, List<String> args); }

Map<String, Command> commands = Map.of(
    "pwd",   (sh, a) -> sh.pwd(),
    "cd",    (sh, a) -> { sh.cd(a.get(0)); return ""; },
    "mkdir", (sh, a) -> { if (a.get(0).equals("-p")) sh.mkdirP(a.get(1)); else sh.mkdir(a.get(0)); return ""; },
    "ls",    (sh, a) -> String.join("  ", sh.ls(a.isEmpty() ? "." : a.get(0))));

String exec(Shell sh, String line) {
    List<String> parts = List.of(line.trim().split("\\s+"));
    Command c = commands.get(parts.get(0));
    if (c == null) return "unknown command: " + parts.get(0);
    try { return c.run(sh, parts.subList(1, parts.size())); }
    catch (FsException | IndexOutOfBoundsException e) { return "error: " + e.getMessage(); }
}
