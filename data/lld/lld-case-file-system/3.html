Identify the entities

Underline the nouns and verbs in the prompt. Nouns that hold state or rules become classes, verbs become methods, and nouns that are just data become fields or are dropped. Click through.

  1. Nouns first. "Tree" and "directory" will turn out to be the same idea seen from the top; "user" is really a session with a current directory.
  2. Verbs become methods. Most land on the shared tree (FileSystem); cd and pwd only change or read one session's state.
  3. The classes: Node is the common parent of Directory and FileNode (Composite). Glob does the matching verb; Spec is a filter object for find.
  4. Nouns that do not earn a class. A path is parsed into segments when a command runs; a class for it is fine but optional. Keep the model as small as the requirements.

The key split: the tree is shared by everyone, the current directory belongs to one session. Putting cwd inside FileSystem is the most common design mistake on this problem; it breaks the moment a second user logs in. A process in Linux works the same way: current->fs->pwd is per process, the dentry tree is global.
