Why is the current directory kept in Shell and not in FileSystem?

  1. Java does not allow mutable fields in a facade
  2. Each session needs its own; the tree is shared by all sessions
  3. It makes pwd faster
cwd is per-user state. In the shared object, one user's cd would move everyone, exactly like processes each having their own cwd.

From /home/asha with children projects, what does a bare * segment expand to in our design?

  1. asha, home and projects
  2. asha and projects
  3. Only projects
The Uber rule: * matches ".", ".." or any child directory, so itself, its parent and its children.

Which pattern lets find take new filters without editing find?

  1. Observer
  2. Singleton
  3. Specification
Each filter is a predicate object; and/or/not combine them; find only calls test(node).

In the safe Composite variant, what happens if code calls add() on a file?

  1. It silently does nothing
  2. It throws UnsupportedOperationException at runtime
  3. It does not compile: FileNode has no add()
The safe variant declares child operations only on the Composite, so the mistake is a compile error.

What is the dangerous case when implementing mv for directories?

  1. Moving a directory into its own subtree
  2. Moving a file to a new name
  3. Moving into an empty directory
mv /a /a/b/c would create a cycle detached from root. Walk up from the target and refuse if you reach the source.

Why does the code take only a read lock for wildcard cd?

  1. cd never needs a lock
  2. Resolving does not change the shared tree; only the session's cwd changes
  3. Read locks are always faster than write locks
The tree is only read during resolution; the cwd update is the Shell's own state, outside the lock.

Which kernel structure plays the role of our Directory children map?

  1. The socket buffer list
  2. The dentry tree (names to child dentries) looked up during path walk
  3. The page cache radix tree
Path walk looks up each component in the parent dentry's children (via the dentry hash), the same job as our map lookup.
