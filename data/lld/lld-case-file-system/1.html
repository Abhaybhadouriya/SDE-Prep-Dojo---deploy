Two LeetCode problems are the same core and make good warm-ups: 588. Design In-Memory File System (ls, mkdir, addContentToFile, readContentFromFile) and 71. Simplify Path (the . / .. rules on their own).

Read the pattern in those posts. Uber asks for working code first. The basic commands are easy; the reports single out wildcard cd as "the difficult part". So plan your hour so that mkdir, cd, pwd, ls work by minute 30, and spend the rest on *, errors and the follow-up.
