Common mistakes

  • cwd inside FileSystem. Works in a single-user demo, fails the first "what if two users?" question.
  • One Node class with a type flag and if ladders in every command.
  • Storing full path strings as keys in one big map ("/a/b" -> node). mv and rm -r then have to rewrite every key under the subtree.
  • Forgetting .. of root, trailing slashes, or the "ls on a file" rule.
  • Wildcard as a single DFS path that gives up after the first branch fails instead of trying every candidate.
  • No dedupe in wildcard expansion, so /*/* returns root twice.
  • Changing cwd before the cd succeeded, leaving the shell in a half-walked directory after an error.
  • Regex for globs without escaping, so a name like a.b matches axb.
  • Spending 20 minutes on a command parser before mkdir works. The API plus a driver is enough unless they ask.
