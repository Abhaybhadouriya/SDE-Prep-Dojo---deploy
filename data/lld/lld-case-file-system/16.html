  • Composite: Node with FileNode (leaf) and Directory (children map of Node). Safe variant: add/remove only on Directory.
  • The tree is shared; the current directory belongs to a Shell (session).
  • Path walk: split on /, drop empties, root or cwd start, . stays, .. goes up, root's parent is root.
  • Wildcard cd: a set of directories per segment, dedupe, sort, agreed tie rule.
  • find = one walk + Specification objects combined with and/or/not.
  • Locking ladder: one RW lock, then a lock per directory with ordered locking for mv, then copy-on-write reads.
  • It is the VFS in miniature: dentry tree (Composite), link_path_walk (our walk), ops tables (Bridge), dentry refcounts (deleted cwd).
