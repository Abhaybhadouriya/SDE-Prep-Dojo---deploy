  • Four ideas: follow graph, candidates (pull, push, global, hybrid), ranking, pagination.
  • Two Strategies: FeedGenerator decides which posts, FeedRanker decides the order; per-user ranking is a map from user to ranker.
  • Push fan-out is an Observer on post(); keep listeners fast or put a queue in between.
  • Pull = k-way heap merge, O(k + n log k); push = O(followers) on write, O(page) on read; hybrid for celebrities.
  • One vote per user: map user to direction plus atomic counters; time comes from an injected clock with a sequence tie-break.
  • Cursors are opaque; keyset cursors survive new posts, ranked feeds need a snapshot.
  • Unfollow and delete in push: filter lazily at read time (tombstones), backfill on follow.
