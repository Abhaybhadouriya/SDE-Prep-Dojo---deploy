APIs and interfaces

class SocialNetwork {                                   // facade
    User signup(String id);
    void follow(String a, String b);  void unfollow(String a, String b);
    Post post(String author, String text);  void deletePost(String user, String postId);
    Comment comment(String user, String postId, String text);
    Comment reply(String user, String commentId, String text);
    void votePost(String user, String postId, int direction);   // +1, -1, 0 = clear
    void setRanking(String user, FeedRanker r);
    FeedPage feed(String user, int pageSize, String cursor);     // cursor null = first page
    void useGenerator(FeedGenerator g);                          // pull (default), push, global
}

interface FeedGenerator { List<Post> candidates(String userId, int limit); }
interface FeedRanker    { Comparator<Post> order(String viewerId, FollowGraph graph); }
interface FeedListener  { void onPost(Post p); default void onFollow(String a, String b) {} }
record FeedPage(List<Post> items, String nextCursor) {}       // nextCursor null = last page

Errors are one unchecked FeedException with a clear message (no such user, cannot follow yourself, only the author can delete, bad cursor). The console turns it into an error: ... line instead of crashing, which is what machine-coding graders check.
