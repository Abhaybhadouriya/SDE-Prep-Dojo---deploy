Clarify the requirements

Functional (P0 = must, P1 = if time)

  1. P0 users and follows Sign up; follow and unfollow another user. Following yourself is an error; following twice is a no-op.
  2. P0 posts A user posts text. Each post gets an id and a creation time.
  3. P0 feed A user's feed shows posts from people they follow (and their own), newest first by default, a page at a time.
  4. P0 votes and comments Upvote or downvote a post (one vote per user; voting again changes it). Comment on a post.
  5. P1 ranking Other orders: Flipkart's (followed first, then score, then comment count, then newest), "top" (score), and each user may choose their own (Uber).
  6. P1 extras Delete your own post; reply to a comment; show time as "2m ago"; a console that reads command~arg~arg lines.

Non-functional

  • In memory. No database; a console or driver program shows it working.
  • Fast feed reads. Reading a feed must not scan every post in the system.
  • Correct under concurrency. Many users vote and post at once: no lost votes, no double votes, no torn feed.
  • Extensible. A new ranking rule or a new way to build the feed must not change the service.

Out of scope

Media uploads, privacy settings, notifications, search, ads, ML ranking, persistence and sharding. Name them; the extensibility table shows where each would plug in.
