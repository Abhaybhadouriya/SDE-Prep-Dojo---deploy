Failure modes to mention: Redis shard loss (recent swipes and matches - reconcile from Kafka/Cassandra); search index drift (periodic re-sync job, as Tinder does); a user moving faster than the indexer (ordering by user id); notification failure (the match is stored, so the "Matches" tab still shows it - the push is best effort).
