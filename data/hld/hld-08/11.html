  • Pick by shape + access pattern + guarantee, then name the product and its cost.
  • Default to Postgres; switch when a number (write rate, data size, latency) forces it.
  • Wide-column (Cassandra, DynamoDB): one table per query, partition key spreads load, clustering key sorts; watch hot partitions.
  • Redis: sub-ms, 16,384 hash slots, loss of minutes with default RDB snapshots, ~1 s with AOF everysec. Great for derived data, not the ledger.
  • Elasticsearch: inverted index, ~1 s refresh, never the source of truth; feed it with CDC.
  • Bytes in S3 (erasure coded, 11 nines), metadata in a DB, reads through a CDN.
  • TSDB for metrics (compression, rollups, beware cardinality); columnar (ClickHouse) for big aggregates.
  • Real systems are polyglot: write once to the truth, stream changes to the copies.
