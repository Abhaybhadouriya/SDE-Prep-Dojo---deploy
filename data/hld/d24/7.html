Where Kafka, Kubernetes and Docker fit

📨

Kafka

Every committed journal row becomes an event on file-changes, keyed by namespace id (ordered per namespace). Consumers: thumbnails and previews, full-text indexing, virus scan, notifications to sharers, audit, analytics. The SFJ stays the source of truth; Kafka is the fan-out.

 👥

Consumer groups

Each downstream job is its own consumer group, so a slow thumbnailer never delays search. Lag per group tells you which feature is behind.

 ☸️

Kubernetes

Metadata API, block API and notification servers are stateless Deployments with HPA (block API on network throughput, notifier on open connections). Thumbnail workers scale on Kafka lag. The exabyte block store itself usually runs on dedicated storage hardware or a cloud blob service, not in pods.

 🐳

Docker

Local lab: MinIO (S3-compatible) for blocks + Postgres for the journal. Test resumable upload by killing the client mid-file.

MinIO stopped publishing free community Docker images in late 2025, so this lab uses Chainguard's free MinIO build. It takes the same server /data arguments and MINIO_ROOT_* variables. (SeaweedFS with weed server -s3 is another free S3-compatible option.)

# compose.yaml - local lab for the sync protocol
services:
  minio:
    image: cgr.dev/chainguard/minio:latest   # free MinIO build; minio/minio is no longer published
    command: server /data --console-address ":9001"
    ports: ["9000:9000", "9001:9001"]
    environment:
      MINIO_ROOT_USER: devuser
      MINIO_ROOT_PASSWORD: devpassword123   # local lab only
  postgres:
    image: postgres:16
    environment:
      POSTGRES_PASSWORD: devpassword123     # local lab only
    ports: ["5432:5432"]
-- journal table: one row per file version, append-only, sharded by ns_id in production
CREATE TABLE file_journal (
  ns_id      BIGINT       NOT NULL,
  jid        BIGINT       NOT NULL,
  path       TEXT         NOT NULL,
  rev        INT          NOT NULL,
  blocklist  TEXT[]       NOT NULL,      -- ordered SHA-256 hex strings
  size_bytes BIGINT       NOT NULL,
  deleted    BOOLEAN      NOT NULL DEFAULT FALSE,
  created_at TIMESTAMPTZ  NOT NULL DEFAULT now(),
  PRIMARY KEY (ns_id, jid)
);
-- change feed for a device: everything after its cursor
SELECT jid, path, rev, blocklist, deleted FROM file_journal
 WHERE ns_id = 9001 AND jid > 1003 ORDER BY jid;
