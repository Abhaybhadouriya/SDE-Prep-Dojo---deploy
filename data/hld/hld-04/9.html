Quick quiz

About how many requests per second is 100 million requests per day?

  1. About 100
  2. About 1,200
  3. About 12,000
  4. About 100,000
100M / 86,400 is about 1,160. Using 10^5 seconds gives 1,000 - the same order of magnitude.

2^30 bytes is about...

  1. 1 MB
  2. 1 TB
  3. 1 GB
  4. 1 PB
2^10 is KB, 2^20 MB, 2^30 GB, 2^40 TB.

Which is the slowest?

  1. A round trip from California to the Netherlands and back
  2. A disk seek
  3. Reading 1 MB sequentially from SSD
  4. A round trip within one data centre
About 150 ms, versus 10 ms for a seek, 1 ms for 1 MB from SSD, and 0.5 ms within a data centre.

1 million viewers each stream at 4 Mbps. What is the egress in bytes per second?

  1. 4 GB/s
  2. 4 TB/s
  3. 40 GB/s
  4. 500 GB/s
1M x 4 Mbps = 4 Tbps (bits). Divide by 8: 0.5 TB/s = 500 GB/s.

A service promises 99.99% availability. About how much downtime does that allow per month?

  1. About 43 minutes
  2. About 4.3 minutes
  3. About 26 seconds
  4. About 7 hours
0.01% of 30 days (43,200 minutes) is about 4.3 minutes. 43 minutes is 99.9%.

5 million new 1 KB records a day, kept 1 year, 3 replicas. About how much storage?

  1. About 18 GB
  2. About 550 TB
  3. About 5.5 TB
  4. About 55 PB
5M x 1 KB = 5 GB/day; x 365 = about 1.8 TB; x 3 = about 5.5 TB.

After computing "about 40 writes per second", what should you say next?

  1. What the number means for the design, e.g. "so one database primary handles writes easily"
  2. The exact value to three decimals
  3. Nothing - move on
  4. The number of CPU cores needed
Numbers only matter for the decision they drive. Always finish with "so...".

An API gets 2,000 requests/s and each request holds a database connection for 50 ms. Roughly how many connections are busy at once?

  1. About 40
  2. About 2,000
  3. About 100
  4. About 40,000
Little's Law: L = arrival rate x time in system = 2,000/s x 0.05 s = 100. Add headroom for bursts and slow queries, which raise the time each request holds a connection.
