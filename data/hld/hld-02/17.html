Quick quiz

A store has N = 5 replicas. Which setting guarantees that a read overlaps the latest write?

  1. W = 2, R = 2
  2. W = 1, R = 4
  3. W = 3, R = 3
  4. W = 2, R = 3
You need W + R > N, so W + R must be at least 6. Only 3 + 3 = 6 qualifies. 2 + 3 = 5 is not greater than 5.

Why is 2PC called a blocking protocol?

  1. It blocks all reads in the database
  2. If the coordinator fails after the votes, participants hold locks and cannot decide on their own
  3. It requires a single-threaded database
  4. It blocks the network
After voting YES a participant may not change its mind, but it does not know the final decision. It waits, holding locks, until the coordinator recovers.

An order service writes an order row and an event row to an outbox table in one transaction. What problem does this solve?

  1. The dual-write problem between the database and Kafka
  2. Duplicate messages at consumers
  3. Slow database queries
  4. Kafka partition rebalances
Both rows commit together, so the event cannot be lost. Duplicates can still happen at the relay, so consumers still dedupe.

A Bloom filter says "maybe present" for a key. What do you know?

  1. The key is definitely present
  2. The key is definitely absent
  3. The filter is corrupted
  4. The key is probably present; check the real store
Bloom filters can give false positives but never false negatives. "Maybe" must be confirmed; "no" never needs confirming.

In a count-min sketch, why take the minimum across rows?

  1. To under-count on purpose
  2. Collisions only add to counters, so the smallest counter is closest to the true count
  3. It is faster than the average
  4. The minimum is always exact
Every counter is the true count plus collisions from other items. The minimum has the fewest collisions. It is still never below the true count.

A driver is 15 m away from a rider, but their geohashes have different prefixes. Why, and what do you do?

  1. A bug in the geohash library; switch to a quadtree
  2. GPS error; ignore the driver
  3. They are on opposite sides of a cell border; search the rider's cell plus its 8 neighbours
  4. Geohash only works in one country
Cells have hard borders. Close points can fall in different cells, so proximity search always includes the neighbouring cells and then filters by real distance.

A token bucket has capacity 10 and refills 2 tokens per second. It is full. 15 requests arrive at once. How many are allowed immediately?

  1. 10
  2. 2
  3. 15
  4. 12
Capacity is the burst size. All 10 tokens are spent at once; the other 5 get 429 (or wait) until tokens refill at 2 per second.

Consumer lag on a Kafka group rises steadily every minute. What does it tell you?

  1. The brokers are down
  2. The consumers are processing faster than producers
  3. Retention is too short
  4. Consumers drain slower than producers fill; scale or speed them up
Lag is like queue depth. Steadily rising lag means the drain rate is below the fill rate. Large but flat lag means behind but keeping up.

A team cuts a Kafka consumer's session.timeout.ms to 3 seconds for "faster failover". The consumers run on a JVM that sometimes pauses for 5 seconds during garbage collection. What happens?

  1. Nothing; GC pauses do not affect heartbeats
  2. Healthy consumers are declared dead during pauses, causing repeated rebalances
  3. Messages are lost
  4. The broker slows down to match the consumer
A paused process sends no heartbeats, so to the group coordinator it looks dead. A timeout shorter than the longest normal pause turns every pause into a false failure and a rebalance. Failure detection trades detection speed against false positives.
