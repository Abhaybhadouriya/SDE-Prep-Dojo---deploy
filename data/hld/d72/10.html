How real systems do it

Seen in 3 recent reports. Every variant, with company, level, date and source post, is in Recently Asked HLD Questions #54. Company view: the Amazon guide and the Meta guide.

  • eBay automatic bidding: bidders set a maximum; eBay bids in increments for them, never above it; increment size depends on the price; outbid notifications let people raise their maximum.
  • Hello Interview: Online Auction: frames the core as post an auction, bid (only if higher than the current highest), view the current highest bid; deep dives on strong consistency for bids, fault tolerance, real-time highest bid, and scaling to 10M concurrent auctions (full answer is premium).
  • DynamoDB conditional writes: the managed-NoSQL version of the bid check; conditions are evaluated against the latest item version, and a failed check returns ConditionalCheckFailedException.
  • Redis pub/sub: the usual fan-out layer for live prices; at-most-once, so pair it with versions and refetch.
