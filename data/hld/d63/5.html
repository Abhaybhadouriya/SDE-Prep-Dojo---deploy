Architecture: from a tick to a phone buzz

Click Next or Play. Interviewers in these reports jumped into deep dives early, so draw this basic picture first and fast (one report said exactly that), then go deep.

  1. Feed handler. Keeps the connection to the exchange or data vendor, normalises messages to {symbol, price, close, ts, seq}, and drops duplicates by sequence number. Run two handlers (active and standby) so one disconnect does not stop the feed.
  2. Ticks into Kafka, keyed by symbol. All ticks for a symbol land in one partition, in order. A separate consumer writes ticks and 1-minute bars to a time-series database for charts and recovery. Retention of a few days lets evaluators replay.
  3. Subscriptions. The app calls the subscription service, which validates the rule (known symbol, sane percent, window from the menu), stores it in the alerts DB with expires_at = now + 1 month, and returns at once.
  4. Change events, same key. In the same transaction, an outbox row produces AlertCreated / AlertCancelled on alert-changes, keyed by symbol with the same partition count as ticks. So the evaluator that owns TSLA ticks also receives TSLA rule changes.
  5. Evaluate in memory. Each evaluator in a consumer group owns some partitions, so some symbols. Per symbol it keeps sorted threshold books and rolling-window state. On each tick it finds only the rules that fire: no database call on the hot path. This is the "separate threshold-detection service" the Uber interviewer wanted.
  6. Fire once. For each hit the evaluator removes the rule from memory, emits an event to alerts-fired keyed by the alert id's user, and the alert row is set to FIRED (conditional update WHERE status = 'ACTIVE'), which is the fire-once guard.
  7. Notify. The notification service consumes alerts-fired, applies user preferences and channel rate limits, and sends push, SMS or email. It is scaled for the crash-day burst, separately from the evaluators.

The funnel, running: thousands of ticks per second go in; only a trickle of crossings come out.
