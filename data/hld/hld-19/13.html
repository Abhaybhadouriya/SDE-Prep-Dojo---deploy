Quick quiz

Why does Amazon-style item-to-item CF scale better online than user-based CF?

  1. It uses a neural network
  2. Similarities are precomputed offline, and the online cost depends only on the items the user touched
  3. It does not need any user data
The expensive part runs offline; a request is just a few KV lookups and a merge.

Dune = (5, 4, 0, 0) and a second item = (10, 8, 0, 0). What is their cosine similarity?

  1. 0.5
  2. 0.8
  3. 1.0
Same direction, double the length. Cosine ignores magnitude, so it is exactly 1.

Why can't you just run textbook SVD on the ratings matrix?

  1. It needs a complete matrix; filling unknowns with zeros teaches the model that almost everything is zero
  2. SVD only works on square matrices
  3. SVD cannot produce vectors
Recommender "SVD" fits only the observed cells (Funk SVD) or weights the missing ones (WALS).

What makes each ALS half-step easy to parallelise?

  1. It uses a learning rate schedule
  2. With one side frozen, every user (or item) is an independent small least-squares problem
  3. It skips regularisation
No shared writes inside a half-step; only the frozen matrix is broadcast.

In implicit ALS, a user played a song 30 times. With alpha = 40, what is the confidence for that cell?

  1. 30
  2. 40
  3. 1,201
c = 1 + alpha x r = 1 + 40 x 30 = 1,201. Empty cells have confidence 1.

Your Redis KNN 500 query returns only 10 results. Most likely cause?

  1. FT.SEARCH's default LIMIT of 10; add LIMIT 0 500
  2. HNSW only supports k = 10
  3. The index is corrupt
KNN k and the result page size are separate settings in Redis.

What does ScaNN's anisotropic quantization penalise most?

  1. Error perpendicular to the data point
  2. Error parallel to the data point, because it distorts the high inner products that decide the top-k
  3. Errors in the query vector
Parallel error changes the scores that matter for ranking; perpendicular error mostly does not.
