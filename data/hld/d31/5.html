Architecture: from one counter to Snowflake

Walk the interviewer up a ladder of options. Each step fixes the last one's problem. Click Next or Play.

  1. One counter. A single database AUTO_INCREMENT. Simple and sorted, but every ID is a write to one box: a throughput ceiling and a single point of failure.
  2. Ticket servers (Flickr, 2006). Two MySQL boxes; one hands out odd numbers, the other even (auto-increment-increment = 2, offsets 1 and 2). Clients round-robin. No SPOF, but still a network hop per ID, and IDs from the two servers drift apart, so they are not time-sorted.
  3. Snowflake workers. Each worker builds IDs locally from clock + its own worker ID + a sequence. It can be a small service or a library inside each app.
  4. Coordination only at startup. A worker gets its unique worker ID from ZooKeeper or etcd once (Meituan Leaf uses a persistent sequential znode), caches it on disk, and heartbeats its clock.
  5. Steady state. Every nextId() is pure local CPU work: read clock, bump sequence, shift and OR. No network call per ID, so it scales linearly with workers.

What happens inside one nextId()

This mirrors the logic in Twitter's open-sourced 2010 IdWorker.scala, rewritten in Python:

import threading, time

class Snowflake:
    EPOCH = 1288834974657
    def __init__(self, dc, worker):
        assert 0 <= dc < 32 and 0 <= worker < 32
        self.dc, self.worker = dc, worker
        self.seq, self.last = 0, -1
        self.lock = threading.Lock()

    def next_id(self):
        with self.lock:                                   # one generator, many threads
            now = int(time.time() * 1000)
            if now < self.last:                           # clock went backwards
                raise RuntimeError(f"clock moved back {self.last - now} ms; refusing")
            if now == self.last:
                self.seq = (self.seq + 1) & 0xFFF         # 12-bit sequence
                if self.seq == 0:                         # 4,096 used this ms
                    while now <= self.last:               # spin to next ms
                        now = int(time.time() * 1000)
            else:
                self.seq = 0
            self.last = now
            return ((now - self.EPOCH) << 22) | (self.dc << 17) | (self.worker << 12) | self.seq
