ReactionsStore each tapWindowed countsCounts in 2 s windows; individual taps are worthless later.
Strengths
  • Writes are cheap and durable; delivery scales out by adding gateways.
  • Failures lose only connections, never data.
  • Graceful degradation: sample harder, then switch to CDN.
Weaknesses
  • Viewers see different subsets of comments.
  • Hash-by-video can overload a gateway when one stream explodes; needs spill-over logic.
  • Many moving parts: endpoint store freshness, relay tree, mode switching.
  • Endpoint store stale (a gateway died but is still listed): dispatcher pushes fail fast; remove entries on failed push and rely on TTL + heartbeats.
  • Dispatcher hot spot: LinkedIn measured about 5,000 events per second per dispatcher node, so scale dispatchers horizontally and keep them stateless.
  • Comment store hot partition: one video bucket taking 5,000 writes/s is fine for Cassandra, but time-bucket the partition key so a 4-hour match does not create one enormous partition.
