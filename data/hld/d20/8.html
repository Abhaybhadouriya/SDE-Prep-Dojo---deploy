Say the choice out loud (pattern: "I would pick X because A; the cost is B; if C becomes a problem I would switch to Y"):

  • "I would pull (scrape) inside the cluster because the server controls the rate and a failed scrape gives me up == 0 for free; the cost is that every target must be reachable from Prometheus; if I had short-lived batch jobs or devices behind NAT, I would let those push through a gateway or an OpenTelemetry collector."
  • "I would use histograms instead of summaries because bucket counts add up across pods, so I can compute a fleet-wide p99; the cost is choosing bucket boundaries; if accuracy near my SLO threshold suffered, I would move to native histograms."
  • "I would remote-write to a horizontally scaled store because one Prometheus cannot hold 13 months for 10M series; the cost is a second system and its ingest path; if the team were small, I would start with Thanos sidecars that just upload blocks."
