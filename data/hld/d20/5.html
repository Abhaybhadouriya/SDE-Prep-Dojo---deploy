Architecture: from a counter to a page

Click Next or Play. We follow http_requests_total{status="500"} from the checkout pod until it pages the on-call engineer.

  1. Discover. Nobody types IP addresses. Prometheus watches the Kubernetes API (service discovery) for pods, services and nodes, and keeps only the ones marked for scraping. New pod, new target, within seconds.
  2. Scrape (pull). Targets are split across N Prometheus servers (sharding by a hash of the target address). Every 15 s each server does GET /metrics on its targets, parses the text, adds job/instance labels and a timestamp. A failed scrape sets up=0 - a free health check.
  3. Store locally. Samples go first to a write-ahead log (WAL) on disk for crash safety, then into the in-memory head block. Every 2 hours the head is cut into an immutable block on disk (chunks + index), and blocks are later compacted into bigger ones. Default local retention is 15 days.
  4. Remote write. Each Prometheus also streams its samples to a horizontally scalable long-term store (Mimir/Cortex, Thanos receive, or M3). Distributors hash each series to 3 ingesters (replication), ingesters build blocks and upload them to object storage. This gives one global view and months of history.
  5. Query. Grafana sends PromQL such as sum by (service) (rate(http_requests_total{status=~"5.."}[5m])). A query frontend splits long ranges by day, caches results, and fans out to ingesters (recent) and store gateways (old blocks), then merges.
  6. Evaluate rules. A rule evaluator runs recording rules (precompute expensive queries into new series) and alert rules every 30 s. If the 5xx ratio stays above 5% for 5 minutes (for: 5m), the alert becomes firing.
  7. Route the alert. Alertmanager receives the firing alert (from every HA replica - it deduplicates them), groups alerts with the same service and alertname into one notification, applies silences and inhibition rules, and routes to the checkout team's PagerDuty.
  8. Meta-monitoring. The monitoring system can fail too. A "Watchdog" alert is always firing on purpose; an external service expects to receive it every few minutes and pages a human if it stops. This is a dead-man's switch.

Whiteboard version: Targets → (service discovery) → Scrapers (sharded, HA pairs) → Long-term TSDB (distributor → ingesters → object storage), then Query frontend → Grafana and Rule evaluator → Alertmanager → Pager.
