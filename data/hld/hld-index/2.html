What you will be able to do

1

Explain why big websites need more than one server

Using the lemonade-stand story: load balancers, caches, copies of data, and splitting data across machines.

2

Name every standard box and when to use it

CDN, load balancer, API gateway, app server, cache, SQL and NoSQL databases, queue, Kafka, blob store, search index - one line each.

3

Run the 45-minute framework

Requirements, estimates, API, data model, high-level diagram, deep dives, trade-offs, wrap-up. Same order every time.

4

Handle the hard parts

Hot keys, double booking, exactly-once payments, ordering, fan-out to celebrities, failover - and say what breaks first.

5

Drive a full round like an SDE-2

Pick technologies with reasons, quantify, choose your own deep dives, and answer "what if this box fails?" for every box.
