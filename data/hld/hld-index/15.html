Resources

  • System Design Primer repo - the classic free primer with Anki decks and worked designs. Bookmark it.
  • awesome-scalability repo - the best index of real engineering blog posts, sorted by topic. Use it to find "how company X did it".
  • ByteByteGo system-design-101 repo - one-page visual explainers. Great for a 5-minute refresh.
  • Hello Interview: delivery framework course - a clear, modern take on how to run the round.
  • ByteByteGo: a framework for system design interviews book - Alex Xu's 4-step framework.
  • Amazon Builders' Library blog - how Amazon really handles retries, timeouts, shuffle sharding and load shedding.
  • Azure cloud design patterns doc - Microsoft's catalogue; the names (cache-aside, sharding, saga) match interview vocabulary.
