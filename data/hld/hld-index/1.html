Use the links in the list below the map, not the Next button. The sidebar and the Next/Previous buttons follow the page numbers (01, 02, 03 ...), and page 02 is Level 4. Fundamentals then Next would take you straight into Raft and 2PC. Until the sidebar order matches this map, click the links in the list.

  1. Fundamentals (week 1). Scale, caching, databases, sharding, CAP, then networking for HLD (your easiest on-ramp), API design, data modeling and choosing storage.
  2. Framework + estimation (week 2). The 45-minute plan and back-of-envelope maths. Learn these before any design so every practice run uses the same order.
  3. Warm-up designs (week 2-3). URL shortener, rate limiter, notifications, autocomplete.
  4. Building blocks (week 3). Now the Level 4 material: consistency, quorums, Raft, sagas, Bloom filters, then consensus, transactions and events, resilience and streaming. They make far more sense after you have drawn a few designs.
  5. Patterns (week 3-4). Ten patterns that keep coming back: real-time updates, contention, scaling reads and writes, fan-out.
  6. Big designs (weeks 4-7). Pick 2-3 per day from the gallery. Say each one out loud.
  7. Advanced and mocks (week 8). Reliability and multi-region, security, edge defense and bots (before the flash-sale and login designs) and recommendation algorithms (before the recommendation design), then the Interview Hub.
