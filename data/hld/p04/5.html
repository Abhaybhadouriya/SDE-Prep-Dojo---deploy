Kafka, Kubernetes and Docker

  • Kafka keeps caches and read models fresh. CDC (Debezium) turns every committed row change into an event in a topic. One consumer group deletes cache keys; another updates the Elasticsearch index; another builds the feed view. Because Kafka keeps the log, a new read model can be built by replaying from the beginning, and a lost invalidation can be replayed - the same idea as Facebook's mcsqueal. Partition by entity ID so changes to one row stay in order. See Kafka Connect & Streams and Core Concepts.
  • Kubernetes runs the read tier. Stateless read services scale with the Horizontal Pod Autoscaler on CPU or request rate (Scheduling & Autoscaling). Redis or Memcached run as StatefulSets with stable names, usually through an operator (StatefulSets & Operators). Beware: a rolling restart of cache pods is a cold start - roll one pod at a time with a pause, or use a PodDisruptionBudget.
  • Docker for local practice. docker run -d -p 6379:6379 redis:7 plus a Postgres container is enough to try cache-aside, TTL jitter and single-flight on your laptop (Docker Compose).
# Cache-aside with jittered TTL, single-flight and negative caching (sketch)
import json, random, threading
inflight, lock = {}, threading.Lock()

def get_product(pid):
    key = f"product:{pid}"
    hit = redis.get(key)
    if hit is not None:
        return None if hit == b"__none__" else json.loads(hit)
    with lock:                       # single-flight per key, per process
        ev = inflight.get(key)
        leader = ev is None
        if leader:
            ev = inflight[key] = threading.Event()
    if not leader:
        # A slow or crashed leader must never turn into a false "not found":
        # if the wait times out or the key is still absent, read the DB
        # ourselves (or raise a retryable 503). Only the sentinel means missing.
        if not ev.wait(timeout=2.0) or (hit := redis.get(key)) is None:
            return db.fetch_product(pid)
        return None if hit == b"__none__" else json.loads(hit)
    try:
        row = db.fetch_product(pid)
        ttl = 300 + random.randint(-30, 30)      # jitter against avalanches
        redis.set(key, json.dumps(row) if row else "__none__",
                  ex=ttl if row else 30)          # short TTL for "not found"
        return row
    finally:
        with lock:
            inflight.pop(key).set()
