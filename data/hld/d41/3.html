Key APIs

POST /v1/wallet/transfers
  Idempotency-Key: 5d1e...           # client-generated UUID, the same on every retry
  { "from": "acct_A", "to": "acct_B", "amount": "100.00", "currency": "INR", "note": "dinner" }
  -> 201 { "transferId": "tr_9f..", "status": "COMPLETED" | "PENDING" }

POST /v1/wallet/topups      { "account": "acct_A", "amount": "500.00", "source": "upi|card", ... }
POST /v1/wallet/withdrawals { "account": "acct_A", "amount": "200.00", "bankAccountRef": "ba_.." }
GET  /v1/wallet/accounts/{id}/balance
GET  /v1/wallet/accounts/{id}/entries?cursor=...&limit=50   # statement, paginated

# internal ledger API (used by wallet, payments, payouts, refunds)
POST /internal/ledger/journal-entries
  { "entryId": "je_..", "postings": [ {"account":"acct_A","amount":-10000},
                                      {"account":"acct_B","amount": 10000} ] }   # paise, sum must be 0

Never use floating point for money. ByteByteGo passes the amount as a string in the API. Inside the system, store integer minor units (paise or cents) in a BIGINT, plus a currency code. 0.1 + 0.2 != 0.3 in IEEE-754 floating point.
