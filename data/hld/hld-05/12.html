  • DNS picks a region and is slow to change (TTL); a load balancer picks a server and reacts in seconds.
  • Anycast = one IP announced over BGP from many places; nearest site answers, failures route around, DDoS gets spread out.
  • Reverse proxy fronts servers; LB spreads over identical replicas; API gateway routes by API and runs auth and rate limits. Same software can do all three.
  • L4 balances connections (fast, any protocol, great for WebSockets). L7 balances requests (routing, retries, auth; needed for gRPC/HTTP/2).
  • HTTP/1.1: one request at a time. HTTP/2: multiplexed but TCP head-of-line blocking. HTTP/3: QUIC streams, 1-RTT handshake, survives network changes.
  • TLS: terminate at the edge for speed and L7 features; re-encrypt (mTLS) for sensitive data; passthrough when the LB must never see plaintext.
  • CDN: pull for long-tail and user content, push for known big files; version URLs instead of purging; origin shield against stampedes.
  • In interviews: one box "LB + gateway", say routing plus auth plus rate limiting, and move on unless asked.
