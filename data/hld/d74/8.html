RetriesImmediateBackoff + jitter + capAlways backoff with jitter; immediate retries turn an outage into a storm.
  • Poison message: one malformed PDF crashes the OCR worker every time. Without a DLQ it loops forever and eats capacity.
  • Orphan uploads: user got a URL but never uploaded. A cleanup job expires PENDING_UPLOAD rows after a day; an S3 lifecycle rule removes stray objects.
  • Event without status or status without event: dual write. Use the outbox.
  • Stuck jobs: a document sits in VALIDATING for an hour because the worker died after receiving. Visibility timeout returns it; also alarm on "age of oldest message" and on documents in a non-final state older than X.
  • Security: pre-signed URLs are bearer tokens - short expiry, one key each, no listing; scan before any human opens a file; encrypt with KMS; strip EXIF; never log URLs.
