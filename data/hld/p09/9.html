  • Ask first: how exact, how fresh?
  • Hot counter: shard it (sum on read) or batch deltas; never one locked row.
  • Per-minute numbers: Kafka keyed by entity + stream processor with event-time windows and watermarks.
  • Tumbling = fixed buckets, sliding = overlapping, session = gap-based.
  • Uniques: HyperLogLog (12 KB, 0.81%, mergeable). Heavy hitters: count-min sketch + heap (overestimates only).
  • Ranks: Redis sorted sets, O(log N); durable log behind them.
  • No double counting: event IDs, dedupe in the stream, idempotent upserts, reconciliation.
  • Lambda = stream + batch (two codebases); Kappa = one stream job, replay the log.
