The story

Explain like I'm 5

The school is voting for its favourite fruit. If every child walks up to one teacher and says "apple!", and the teacher writes a tally mark, there is a huge line and the teacher's pencil is the bottleneck. So the school gives each class its own tally sheet. Every few minutes a helper walks around, adds up each class's sheet, and writes the total on the big board. Much faster!

Now the head teacher asks two harder questions. "How many different children voted?" Keeping a list of every name is a lot of paper, so the helper uses a clever trick that guesses the number almost perfectly with a tiny card. And "What were the top 3 fruits in the last 10 minutes?" So the helper draws a line on the sheet every 10 minutes and only counts marks between the lines. Finally, one naughty child votes five times. The helper checks each child's sticker so a vote counts only once.

Every part of that story is a real technique. The per-class tally sheets are sharded counters (many small counters added up later). The helper's walk is batching or aggregation. The "draw a line every 10 minutes" is a window (a time bucket). The tiny guessing card is a sketch such as HyperLogLog. The top-3 list is ranking / top-K. And the sticker check is idempotent counting, or deduplication: the same event counted once, even if it arrives twice.
