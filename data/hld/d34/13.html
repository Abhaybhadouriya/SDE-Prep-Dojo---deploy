  • Mares and Blackham: A New Contest Sandbox paper - why isolate is designed the way it is.
  • Judge0 repo - open-source code execution system (90+ languages, webhooks, scalable workers).

  • gVisor documentation doc - runsc, Sentry, Gofer, and how it differs from VMs and seccomp-only containers.
  • Firecracker microVMs doc - under 125 ms boot, under 5 MiB overhead, used by AWS Lambda.
  • Docker: Seccomp security profiles doc - the default profile blocks about 44 of 300+ syscalls.
  • Redis sorted sets doc - the data structure behind the leaderboard.
  • CMS - Contest Management System repo - a full contest system to read for workers, rankings and rejudging.
