How real systems do it

  • LeetCode - Hello Interview notes that LeetCode's browser polls a check endpoint for the result, the same async pattern as above.
  • Judge0 (open source) - "sandboxed compilation and execution of untrusted code" for 90+ languages, with a scalable worker architecture and webhooks for results. Its 2024 sandbox-escape CVEs (CVE-2024-28185) are a lesson in hardening the privileged setup code.
  • isolate - the sandbox used by CMS, the contest system behind programming olympiads. It is built directly on Linux namespaces and cgroups, and its manual is the best short reference for judge limits.
  • gVisor (Google) - an OCI runtime (runsc) whose Sentry re-implements the Linux syscall interface in user space; usable from Docker and Kubernetes.
  • Firecracker (AWS) - microVMs that power AWS Lambda and Fargate; under 125 ms boot and up to 150 microVMs per second per host.
