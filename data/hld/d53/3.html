Key APIs

Plain REST for users; a narrow ingest API for the extension. Background in API Design & Client-Server Communication.

# look up a product from a shop URL (used by the extension on every product page)
GET  /v1/products/lookup?url=https%3A%2F%2Fshop.example%2Fdp%2FB0ABC123
  -> 200 { "productId": "p_91", "current": { "price": 2999, "currency": "INR", "asOf": "2026-11-23T08:00:00Z" },
           "stats": { "min": 2499, "max": 3999, "avg30d": 3150 }, "watching": false }

# price history for a chart; the server picks the resolution
GET  /v1/products/p_91/history?range=1y&resolution=day&condition=new
  -> 200 { "points": [ ["2025-11-23", 3499], ["2025-11-24", 3499], ... ] }

# create, list, change, delete watches (auth required)
POST   /v1/watches   { "productId": "p_91", "condition": "new", "targetPrice": 2700 }
POST   /v1/watches   { "productId": "p_91", "dropPercent": 20 }
GET    /v1/watches?cursor=...
PATCH  /v1/watches/w_55  { "targetPrice": 2600, "paused": false }
DELETE /v1/watches/w_55

# the extension reports what the user's browser saw (untrusted input)
POST /v1/observations
  { "url": "https://shop.example/dp/B0ABC123", "price": 2899, "currency": "INR",
    "seenAt": "2026-11-23T08:12:31Z", "clientId": "ext_8f2", "extVersion": "4.2.0" }
  -> 202 Accepted        # accepted for checking, not yet trusted

Stock variant

POST /v1/alerts   { "symbol": "AAPL", "direction": "below", "price": 180.00 }
POST /v1/alerts   { "symbol": "AAPL", "movePercent": 5, "window": "1d" }
GET  /v1/quotes/stream?symbols=AAPL,MSFT    # server-sent events with live prices

Two details interviewers notice. (1) POST /v1/observations returns 202, not 201: the server has not decided whether to believe it yet. (2) The client never asks "check my alerts". Matching is server-side and event-driven; the client only creates rules.
