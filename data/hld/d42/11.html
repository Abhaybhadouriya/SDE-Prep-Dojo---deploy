  • Email is store-and-forward: SMTP between servers, MX records for routing, HTTP/IMAP for clients.
  • Ack SMTP only after the message is durably replicated; make delivery idempotent with a dedupe key.
  • Partition everything by user_id; one primary per mailbox gives strong per-mailbox consistency.
  • Split metadata (small, hot), body and attachments (big, cold, object store, dedupe by hash).
  • Search is per user; indexing is async from events and can be rebuilt from the mailbox.
  • Threads come from Message-ID, In-Reply-To and References, computed at write time.
  • Outbound: per-domain queues, exponential backoff for days, DKIM signing, IP reputation.
  • Inbound spam: cheap checks first (IP, SPF/DKIM/DMARC), then ML, with user feedback.
