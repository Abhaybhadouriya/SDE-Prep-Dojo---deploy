How real companies do it

  • Uber: built Cadence, a code-first workflow platform used by over a thousand Uber services; Temporal is its open-source successor.
  • Netflix: Conductor, a JSON-blueprint orchestrator for content-platform processes that can run for days, built after ad-hoc pub/sub plus REST lost visibility.
  • Airbnb: Orpheus, an idempotency library splitting each call into pre-RPC, RPC and post-RPC phases so payments move money at most once.
  • AWS: Step Functions Standard (up to a year, exactly-once tasks) and Express (up to five minutes, at-least-once).
  • Debezium / Red Hat: the reference CDC-based outbox implementation with an EventRouter for Kafka.
