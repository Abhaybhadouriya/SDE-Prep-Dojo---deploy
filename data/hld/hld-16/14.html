Quick quiz

"Support equal, exact and percentage splits, and more later." Which pattern fits best?

  1. Singleton
  2. Strategy
  3. Observer
  4. Decorator
Different interchangeable algorithms for one job, chosen at runtime, is exactly Strategy. Adding a split type means adding a class.

An elevator behaves differently when idle, moving or with doors open, and each state decides the next one. Which pattern?

  1. Factory
  2. State
  3. Strategy
  4. Chain of responsibility
Behaviour that depends on status, with the states triggering their own transitions, is the State pattern.

Bicycle extends Vehicle and startEngine() throws "not supported". Which principle is broken?

  1. Single responsibility
  2. Dependency inversion
  3. Liskov substitution
  4. DRY
A subclass that cannot do what its parent promises breaks code written against the parent. That is an LSP violation.

A parking spot cannot exist without its floor. In UML this relationship is:

  1. Association
  2. Aggregation (hollow diamond)
  3. Inheritance
  4. Composition (filled diamond)
Composition means the part's lifetime is owned by the whole. Aggregation is a looser "has" where the part can live alone.

Two gates try to assign the same spot at the same time. The best in-memory fix is:

  1. An atomic take from a concurrent free-spot queue (or putIfAbsent per spot)
  2. Make every method in the parking lot synchronized
  3. Retry until it works
  4. Use a Singleton
An atomic per-resource operation is correct and does not serialise the whole system. A global lock works but scales badly.

According to Hello Interview, which principle do candidates violate most in LLD interviews?

  1. KISS (over-engineering)
  2. DRY
  3. Interface segregation
  4. Law of Demeter
Adding patterns and layers that the problem does not need is the most common mistake.

In a Flipkart-style machine-coding round, what matters most at the end of 90 minutes?

  1. A complete UML diagram
  2. Code that runs the required flows, is modular, and can be extended in the review
  3. Using as many design patterns as possible
  4. A database schema
The round grades working, readable, extensible code with in-memory storage, plus your ability to explain and extend it.
