  • HLD is the map (services, stores, scale, failure). LLD is one building (classes, interfaces, state, in-process locks).
  • Indian SDE-2 loops usually test both. Flipkart leads with a roughly 90-minute machine-coding round plus a code viva.
  • Machine coding: scope, entities, run the core path by minute 60, then edge cases, then demo. Code that runs beats perfect abstractions.
  • SOLID in one domain. Put interfaces only where things vary. KISS is the most violated principle.
  • Four patterns cover most problems: Strategy (ways to do X), Observer (notify), State (behaviour by status), Factory (create from input).
  • Every classic has one scarce resource. Make its assignment atomic (putIfAbsent, compute, per-object lock, versioning).
  • Parking lot = composition + strategies. Elevator = State + LOOK. BookMyShow = hold with TTL, then confirm. Splitwise = split strategies + net balances + greedy settle.
  • In combined rounds, ask "broad or deep?" early and budget the time.
