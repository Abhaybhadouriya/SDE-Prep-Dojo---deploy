Quick quiz

Four layers each make up to 3 attempts. How many calls can one user click cause at the bottom layer?

  1. 12
  2. 81
  3. 27
  4. 3
3 x 3 x 3 x 3 = 81. Retries multiply across layers, which is why you retry at one layer only.

Why add jitter to exponential backoff?

  1. To stop clients that failed together from retrying together in waves
  2. To make each retry faster
  3. To make retries idempotent
Without randomness, clients stay synchronized and hit the server in spikes. Jitter spreads retries into a flat rate.

In the half-open state a circuit breaker...

  1. Lets a few trial calls through to test if the dependency recovered
  2. Rejects every call
  3. Lets all calls through and resets the counters
Half-open is the probe. Success closes the breaker; any failure re-opens it.

The reviews service hangs and the payment calls in the same app start failing. Which pattern was missing?

  1. Service discovery
  2. Rate limiting
  3. Bulkhead (separate pools per dependency)
Without isolation, hung review calls used all shared threads. A bulkhead caps each dependency's share.

Which response code fits load shedding best?

  1. 429 for a client over its quota
  2. 503 when the server is over capacity
  3. 400 Bad Request
Load shedding is about the server's own capacity: 503 (optionally with Retry-After). 429 is for per-client rate limits.

How should you pick a request timeout?

  1. Always 30 seconds
  2. Equal to the average latency
  3. From the dependency's latency at an accepted false-timeout percentile (e.g. p99.9), within the caller's deadline
Average latency would time out about half the calls. Use a high percentile and respect the remaining deadline.

In Istio, which component actually carries request traffic?

  1. istiod
  2. The Kubernetes API server
  3. The Envoy proxies (data plane)
Only the Envoy proxies touch requests. istiod configures them and issues certificates.
