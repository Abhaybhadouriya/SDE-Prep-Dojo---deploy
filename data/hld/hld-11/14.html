Remember this

  • Microservices trade function calls for network calls. Split for team or scaling reasons, not fashion. Start with a modular monolith.
  • Discovery = registry + registration + client-side or server-side lookup. Kubernetes Service is server-side via VIP + DNS + iptables/IPVS.
  • A mesh moves retries, timeouts, mTLS and metrics into sidecar proxies. The control plane configures, the data plane carries.
  • Every remote call needs a timeout picked from a latency percentile, and the deadline should travel down the call chain.
  • Retries are selfish: one layer only, 2-3 attempts, capped exponential backoff with full jitter, a retry budget, idempotent operations only.
  • Circuit breaker: closed, then open (fail fast + fallback), then half-open (probe). Key breakers per host/shard.
  • Bulkheads give each dependency its own pool so one hang cannot eat all threads.
  • Rate limiting = per-client quota (429). Load shedding = protect goodput under overload (503). Backpressure = consumer slows producer.
  • Decide degraded modes in advance, never degrade auth or money correctness, and test fallbacks regularly.
