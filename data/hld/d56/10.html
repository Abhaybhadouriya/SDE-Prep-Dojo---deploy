How real companies do it

  • Google Maglev (NSDI 2016): software L4 LB on commodity Linux since 2008, ECMP in front, Maglev hashing + conntrack, GRE encapsulation, DSR, kernel bypass; also Google Cloud's network LB.
  • Meta Katran (open source, 2018): XDP/eBPF forwarding, extended Maglev hash with weights, LRU conntrack, IP-in-IP, DSR; replaced an IPVS-based LB that ran for over four years.
  • GitHub GLB Director: stateless DPDK director, rendezvous hashing into a 65k-row table with primary and secondary proxies, GUE encapsulation, second chance via a Netfilter module, HAProxy behind it.
  • Cloudflare Unimog: LB runs on every edge server in XDP; buckets with current and previous server; a control loop moves buckets based on CPU load from Prometheus.
  • AWS Elastic Load Balancing: NLB (L4) and ALB (L7) with round robin, least outstanding requests and weighted random, 300 s deregistration delay, slow start, sticky cookies and fail-open health.
  • Envoy: the L7 proxy behind Istio and many gateways; P2C least-request, ring hash, Maglev, outlier detection.
