Key APIs

The data plane has no API: it is just packets and HTTP. The control plane has one, used by deploy tools, autoscalers and service discovery.

PUT    /v1/vips/{vip}                 {protocol: TCP|HTTPS, port, cert_id, pool_id}
PUT    /v1/pools/{pool_id}            {algorithm: maglev|least_request|round_robin,
                                       health_check: {path:"/healthz", interval_s:5,
                                                      timeout_s:2, unhealthy:3, healthy:2}}
POST   /v1/pools/{pool_id}/backends   {ip, port, weight, zone}
PATCH  /v1/pools/{pool_id}/backends/{id}   {state: draining|active, weight}
DELETE /v1/pools/{pool_id}/backends/{id}?drain_timeout_s=300
PUT    /v1/routes/{vip}               [{match:{host:"api.shop.com", path_prefix:"/cart"},
                                        pool:"cart", retries:2, timeout_ms:800}]
GET    /v1/pools/{pool_id}/health     -> per-backend state, last check, error rate
  • Config is versioned; every node reports which version it runs, so you can see partial rollouts.
  • Deletes default to drain, never hard remove. AWS ALB's default deregistration delay is 300 s.
  • The health-check thresholds above (interval 5-10 s, timeout 2-3 s, 2-3 failures to mark down) are the typical values AlgoMaster uses; they prevent flapping.
