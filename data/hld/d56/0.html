The story

Explain like I'm 5

A huge restaurant has one front door and fifty tables. At the door stands a host. When a family walks in, the host looks around and takes them to a table with a free waiter. If a waiter goes home sick, the host stops sending families to that waiter's tables. If the waiter is just going on a break, the host lets the families already eating finish, but sends no new ones.

On a busy holiday, one host is not enough. So there are four doors, each with a host, and all hosts follow the same rule card, so a family that walks out and back in through a different door still ends up at its own table. That rule card is consistent hashing, and the hosts are the load balancer.

A load balancer (LB) spreads incoming connections or requests across a pool of servers, hides failed servers, and lets you add capacity without changing the address clients use. The system-design-primer lists its classic jobs: keep requests off unhealthy servers, avoid overloading any one server, remove the single point of failure, terminate TLS, and keep sessions sticky when needed.

In our gap analysis "design a load balancer" appears once (AlgoMaster's list), and no company interview report names it directly. We still include it because it is a strong question to steer towards with your background, and because every other design on this site draws "LB" as a box: here we open that box. From your world

You already know most of this. An L4 load balancer is ECMP plus a NAT/encapsulation table: hash the 5-tuple, pick a next hop, keep a flow on one path to avoid reordering. Health checks are BFD. Draining is like setting a link's cost to infinity and waiting for flows to move. The new parts are the L7 layer (HTTP awareness) and doing all of this in software on ordinary Linux servers.

New words, once each: L4 vs L7: an L4 balancer looks only at IP and port (the 5-tuple); an L7 balancer reads the HTTP request (path, headers, cookies). A VIP is a virtual IP that belongs to the service, not to one machine. Anycast means many sites announce the same IP and the network delivers to the nearest. ECMP is equal-cost multipath at the router. DSR (direct server return) means replies skip the L4 tier. Conntrack is the per-flow table that remembers which backend a connection went to. Consistent hashing maps keys to servers so that a change moves only a few keys. A health check is a periodic probe that marks a backend up or down. p99 means "99 out of 100 are faster than this". The rest are in the glossary.
