Quick quiz

Why does the L4 tier need far fewer machines than the L7 tier?

  1. L4 nodes have bigger disks
  2. L4 forwards packets without TLS or HTTP parsing, and with DSR it carries only inbound traffic
  3. L4 nodes cache responses
TLS and HTTP processing are the CPU cost; DSR removes the large outbound bytes from L4.

An L4 node fails and ECMP moves its flows to another node. What keeps them on the same proxy?

  1. Every node computes the same consistent-hash table from the same backend list
  2. Nodes replicate their connection tables
  3. Clients reconnect
Determinism replaces state sharing.

Why is Maglev's table size a prime like 65,537?

  1. It fits in one cache line
  2. Required by ECMP
  3. So every skip value generates a full permutation of the slots
With a prime M, stepping by any skip in 1..M-1 visits every slot.

What does "fail open" mean for health checks?

  1. Open all firewall ports
  2. If too few backends look healthy, send traffic to all of them
  3. Remove the LB from DNS
A total outage reading is more likely a checker bug; AWS ALB behaves this way.

Thirty LB nodes each send to "the server with fewest connections". What goes wrong?

  1. They herd onto the same server; use power of two choices
  2. Nothing
  3. TLS fails
Independent identical decisions synchronise; randomness breaks the tie.

What is connection draining?

  1. Closing all connections immediately
  2. Moving connections to another region
  3. Stopping new requests to a backend while in-flight ones finish, then removing it
ALB's default wait is 300 s.

Why shouldn't you put a normal L7 load balancer in front of Kafka brokers?

  1. Kafka has no TCP
  2. Clients must talk to the specific broker leading each partition
  3. Kafka is too slow
Kafka clients discover broker addresses and connect directly.

An ALB has the default 60 s idle timeout. Which backend setting avoids intermittent 502s on reused connections?

  1. Keep-alive timeout of 5 s, so connections are recycled often
  2. Disable keep-alive on the backend entirely
  3. Keep-alive timeout of 65 s, longer than the ALB's idle timeout
The side that reuses connections (the ALB) should also be the one that closes them. A backend that closes first creates a race in which the ALB sends a request onto a closing socket.
