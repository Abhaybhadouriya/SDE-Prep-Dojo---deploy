How real systems do it

  • Amazon sales rank - system-design-primer's worked solution: hourly MapReduce over sales logs in S3 into a sales_rank table, cached for 40k reads/s.
  • Redis Stack ships CMS.* (count-min sketch) and TOPK.* (HeavyKeeper: count with exponential decay plus a min-heap); its docs list trending hashtags and DDoS detection as use cases.
  • Apache Druid TopN - per-segment top 1,000, merged at the broker; explicitly approximate for high-cardinality dimensions.
  • Apache Flink windows (tumbling, sliding, session) with incremental aggregation and checkpointed state are the standard streaming engine for this pipeline.
