The story

Explain like I'm 5

Imagine one hundred newspapers land on your doorstep every hour. You cannot read them all. So you hire a helper robot. Every few minutes the robot walks to each newspaper's shop and asks, "Anything new since last time?" Many shops print the same story - "Big storm tomorrow!" - with slightly different words. The robot staples all the storm pages together into one pile, puts the best page on top, and writes "Storm - 40 papers" on a little card. Then it pins the cards on a big board, newest and most important first. You just walk to the board, read the cards, and if one looks fun, you go to that shop to read the whole page.

That is the whole design. The shops are publishers. Asking "anything new?" is feed ingestion (polling RSS feeds, or being told by a push hub). Stapling the same story together is de-duplication and clustering. The board is a precomputed feed that we serve from a cache. Walking to the shop is the click-through redirect - an aggregator shows a headline, a snippet and a thumbnail, and sends you to the publisher for the full article.

New words, once each: RSS / Atom feeds are small XML files a publisher updates with its latest articles. WebSub is a push protocol: a hub calls you when a feed changes, so you do not have to poll. A CDN is a network of edge caches near readers. Redis is an in-memory key-value store; a sorted set in Redis keeps members ordered by a score. A fingerprint is a short value computed from a document so that copies can be compared cheaply. Hamming distance is the number of bit positions in which two fingerprints differ. A cursor is an opaque token that means "continue after this item" (see pagination). Kafka is a durable, ordered log that many services read. QPS is requests per second. The rest are in the glossary.

Who asks this? Our gap analysis found it in two curricula: Hello Interview (Medium, tagged with the "Scaling Reads" pattern) and Grokking System Design II. We found no self-reported target-company interview for it, but it is Google's own product, so expect it in Google loops. The core skill - a read-heavy feed with fresh writes - is the same one Meta, Amazon and Flipkart test with feeds and catalogs.
