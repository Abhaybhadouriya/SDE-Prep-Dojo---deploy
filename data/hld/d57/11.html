  • Three stages: crawl, index (dedupe, canonical, invert), serve (match, rank).
  • Inverted index: sorted, delta-compressed posting lists with positions; intersect shortest first.
  • Shard by document (random), replicate shards; every query fans out to all shards.
  • Rank in two phases: cheap at leaves (BM25 + static rank like PageRank), ML at the root.
  • PageRank is offline: d = 0.85, iterate over the link graph.
  • Fan-out multiplies tail latency: hedging, deadlines, good-enough results, canaries.
  • Freshness: batch main index + stream-fed real-time tier; immutable segments.
