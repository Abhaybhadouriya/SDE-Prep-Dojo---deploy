  • OLTP = small keyed transactions on row stores. OLAP = big scans on columnar stores. Feed OLAP by CDC, never query the primary.
  • Warehouse = schema-on-write, managed. Lake = cheap open files. Lakehouse = lake + table format (Iceberg/Delta/Hudi) for ACID.
  • MapReduce: split, map (+combiner), shuffle by hash(key), reduce. Re-run failed tasks, back up stragglers, watch for skew.
  • Spark is faster for multi-step work: in-memory data, lineage-based recovery, lazy DAG.
  • Use streaming only when you need fresh, stateful results. Flink = keyed state + checkpoints (barriers) + transactional or idempotent sinks.
  • Windows: tumbling (no overlap), sliding (overlap), session (gap). Event time + watermark (max seen - delay) decides when a window is complete.
  • Late data policy: delay, allowed lateness, side output, batch reconciliation. State the freshness vs completeness trade-off.
  • Lambda = two code paths. Kappa = one path + log replay (needs retention). Uber's Kappa+ replays the same stream code over the lake.
  • Bloom = "definitely not / maybe" (~9.6 bits/item at 1%). HLL = distinct count in 12 KB at 0.81%. Count-min = frequency, overestimates only; + heap for top-K.
