Quick quiz

A query sums one column over 2 billion rows. Which storage layout is fastest?

  1. Row-oriented with a B-tree index
  2. Columnar (e.g. Parquet)
  3. A key-value store
A columnar store reads only that column, compressed, instead of every full row.

In MapReduce, what guarantees that all counts for the word "apple" reach the same reducer?

  1. The shuffle partitions by hash(key) mod R
  2. The combiner
  3. Data locality
Partitioning by the key's hash sends every pair with that key to one reducer.

A watermark of 10:05 means...

  1. The machine clock reads 10:05
  2. The system expects no more events with event time at or before 10:05
  3. 10:05 is the last event that arrived
Watermarks track event-time progress, not wall-clock time.

"Length of each user visit, ending after 30 minutes of inactivity" needs which window?

  1. Session
  2. Tumbling
  3. Sliding
Session windows close after a gap of inactivity and have no fixed size.

A Bloom filter says "probably present". What do you know for sure?

  1. The item was definitely added
  2. Nothing for sure; it may be a false positive
  3. The item was definitely not added
Only "not present" is certain. "Present" can be caused by other items' bits.

Why does a count-min sketch take the minimum of its counters?

  1. Collisions only add to counters, so the smallest one has the least extra noise
  2. To round the result down
  3. Because counters can be negative
Every counter is the true count plus collisions. The minimum is the tightest upper bound.

What is the main cost of the Lambda architecture that Kappa removes?

  1. The same logic must be written and kept in sync in two systems
  2. It needs Kafka
  3. It cannot give low latency
Kreps' critique: two code paths for batch and speed layers drift apart and double the operations work.

Redis HyperLogLog uses about how much memory per key at most?

  1. 1 MB
  2. Grows with the number of distinct items
  3. 12 KB
Up to 12 KB with 0.81% standard error, regardless of how many distinct items it has seen.
