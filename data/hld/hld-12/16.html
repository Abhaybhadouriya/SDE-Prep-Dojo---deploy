Resources

  • Dean & Ghemawat: MapReduce (OSDI 2004) paper - the model, locality, backup tasks, the 1 TB grep and sort numbers.
  • Zaharia et al.: Resilient Distributed Datasets (NSDI 2012) paper - why Spark keeps data in memory and recovers by lineage.
  • Armbrust et al.: Lakehouse (CIDR 2021) paper - the two-tier lake + warehouse problem and the lakehouse answer.
  • Fu & Soman: Real-time Data Infrastructure at Uber paper - Kafka at trillions of messages a day, Flink, Pinot, surge pricing, Kappa+.
  • Jay Kreps: Questioning the Lambda Architecture blog - the original Kappa argument. (archived copy if the original is blocked)
  • Apache Flink: Timely stream processing doc - event time, processing time, watermarks, lateness.
  • Apache Flink: Windows doc - assigners, allowed lateness, side outputs, triggers.
  • Apache Flink: Stateful stream processing doc - keyed state, barriers, exactly-once vs at-least-once.
  • Hello Interview: Data structures for big data course - Bloom, count-min, HLL and when not to use them.
  • Hello Interview: Flink deep dive course - "do you really need real time?"
  • Redis: HyperLogLog doc - 12 KB, 0.81%, PFADD/PFCOUNT/PFMERGE.
  • Redis: Count-min sketch doc - CMS commands.
  • Flajolet et al.: HyperLogLog (2007) paper - 1.04/sqrt(m) error, 109 items in 1.5 KB at ~2%.
  • Chang et al.: Bigtable (OSDI 2006) paper - Bloom filters per SSTable to skip disk reads.
  • Apache Cassandra: Bloom filters doc - fp_chance defaults and the memory trade-off.
  • Apache Parquet overview doc - the columnar file format under most lakes.
