  • Passwords: Argon2id (m=19 MiB, t=2, p=1 minimum), salted, parameters stored; NIST: length, blocklist, no forced rotation.
  • Validation is the data plane (300k/s, local signature check); login and refresh are the control plane (thousands/s, central).
  • Short JWT access tokens + rotating refresh tokens with reuse detection + a small pushed denylist.
  • Asymmetric signing with JWKS and kid; keys in KMS/HSM; rotate with overlap.
  • OIDC = OAuth 2.0 + ID token. Use code flow + PKCE, exact redirect URIs, state and nonce; no implicit or password grant.
  • SSO works because the IdP has its own session; single logout is best effort.
  • Stop stuffing before the hash: multi-key rate limits, throttle not lockout, breached-password checks, passkeys.
