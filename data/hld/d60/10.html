How real systems do it

  • Netflix edge authentication - authentication and token handling moved to the Zuul edge; an integrity-protected, token-agnostic identity ("Passport") is propagated inside; client tokens never cross the edge (Netflix Tech Blog, 2021, and the QCon talk "User & Device Identity for Microservices @ Netflix Scale").
  • Google BeyondCorp - no trusted internal network: every request is authenticated and authorised based on user and device, wherever it comes from (the "zero trust" model that mTLS meshes implement for services).
  • Standards you implement rather than invent - OAuth 2.0 (RFC 6749), its Security BCP (RFC 9700), PKCE (RFC 7636), JWT (RFC 7519), OpenID Connect Core 1.0, NIST SP 800-63B-4 for authenticator rules.
  • Managed IdPs - Microsoft Entra ID, Amazon Cognito, Google Identity, Okta and Auth0 all expose the same OIDC endpoints described here, which is why the design is worth learning even if you buy one. Okta's refresh-token guide shows rotation with a configurable grace period, the same reuse window as deep dive 2.
