Quiz

Which is OWASP's preferred password hashing choice?

  1. SHA-256 with a salt
  2. AES encryption with a master key
  3. Argon2id with at least 19 MiB memory and 2 iterations
Fast hashes and encryption are wrong for passwords. Argon2id is slow and memory-hard on purpose.

Why should microservices verify JWTs locally rather than call the auth service each time?

  1. JWTs cannot be sent over the network
  2. At about 300k requests/s a central check is a bottleneck and single point of failure
  3. Local checks are more secure than signatures
A signature check with cached public keys is fast and works even if the auth service is down.

A refresh token that was already rotated is presented again. What should the server do?

  1. Assume theft and revoke the whole token family
  2. Accept it, it is still signed
  3. Ignore it silently
Outside a short grace window (30-60 s, for a lost response or two tabs), reuse means the token was copied; revoking the family stops the thief.

What does PKCE protect against?

  1. Weak passwords
  2. An attacker who intercepts the authorization code redeeming it
  3. Clock skew
Only the party holding the original code_verifier can exchange the code.

According to RFC 9700, which grant must not be used?

  1. Authorization code
  2. Client credentials
  3. Resource owner password credentials
It exposes the user's password to the client and gets in the way of MFA.

Why does a second app in an SSO setup not ask for the password again?

  1. The identity provider has its own session cookie and issues a code immediately
  2. The two apps share a database
  3. The browser remembers the password
The IdP session is the "single" in single sign-on.

Which MFA factor is phishing-resistant?

  1. SMS code
  2. Passkey (WebAuthn)
  3. TOTP app code
A passkey's signature is bound to the real site's origin, so a fake site cannot reuse it.
