Resources

  • OWASP Password Storage Cheat Sheet doc - Argon2id, scrypt, bcrypt and PBKDF2 parameters; salt and pepper.
  • OWASP Session Management Cheat Sheet doc - session id entropy, cookie attributes, timeouts.
  • RFC 9700: OAuth 2.0 Security Best Current Practice doc - PKCE, exact redirect matching, no implicit or password grant, refresh-token rotation, sender-constrained tokens.
  • Okta: Refresh access tokens and rotate refresh tokens doc - rotation, reuse detection and the grace period for lost responses.
  • OpenID Connect Core 1.0 doc - ID token claims and the client's validation steps.
  • NIST SP 800-63B-4 doc - password length, blocklists, 100-failure cap, SMS restricted, phishing resistance, re-authentication timeouts.
  • Karan Pratap Singh: System Design (OAuth 2.0 / OIDC, SSO, TLS/mTLS chapters) repo - clear beginner explanations of the roles and flows.
  • QCon / InfoQ: User & Device Identity for Microservices @ Netflix Scale video - edge authentication and the Passport identity object.
  • Netflix Tech Blog: Edge Authentication and Token-Agnostic Identity Propagation blog - the original post (it blocked our scripted fetch; we used search summaries and the talk).
  • Google: BeyondCorp paper - zero-trust access based on user and device, not network location.
  • AlgoMaster: awesome-system-design-resources repo - lists "design an authentication system" among its problems.
