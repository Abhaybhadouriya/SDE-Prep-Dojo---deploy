Remember this

  • Schema = answer to the access patterns. List APIs, write each query, put an index next to each one.
  • Normalize the source of truth; denormalize derived copies for hot reads, and say how copies stay in sync.
  • Composite index rule: equality columns first, range or sort column last. Covering index = no table read.
  • Every index speeds some reads and slows every write.
  • B-tree: update in place, great reads. LSM: append + compaction, great writes. Bloom filters cut LSM read cost.
  • Postgres defaults to Read Committed, InnoDB to Repeatable Read; snapshot isolation still allows write skew.
  • MVCC = readers never block writers; long transactions cause bloat.
  • Low contention: optimistic (version check). High contention: guarded atomic update, row lock, or redesign the hot spot.
