Where Kafka, Kubernetes and Docker fit

Concrete settings. Partition key stream_id puts all beacons for one stream together, so per-stream rebuffer rates are computed in one place; video segments never touch Kafka. Consumer-group sizing: 64 partitions allow 64 aggregator pods for a big match. The playback HPA scales on CPU and request rate with a scheduled pre-scale before the event; transcoders are protected by PodDisruptionBudgets because evicting one cuts a live stream.
