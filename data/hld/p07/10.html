Quick quiz

What should the API return right after accepting a 10-minute job?

  1. 200 OK with the finished file
  2. 202 Accepted with a job ID and status URL
  3. 504 Gateway Timeout
  4. 301 redirect to the worker
202 means "accepted, not finished". The job ID lets the client check status later.

A worker receives an SQS message and crashes. What brings the job back?

  1. The DLQ
  2. The client retries
  3. The visibility timeout expires and the message becomes visible again
  4. Nothing; the job is lost
The message was only hidden, not deleted. When the visibility timeout ends it reappears for another consumer.

Why must job handlers be idempotent?

  1. Because delivery is at-least-once, so a job can run twice
  2. Because queues reorder messages
  3. Because workers share memory
  4. To make them faster
Leases expire on slow (not only dead) workers, and redelivery means the same job may run more than once.

What is the best metric to autoscale queue workers on?

  1. Worker CPU
  2. API request rate
  3. Number of workers
  4. Age of the oldest message (or depth relative to throughput)
Age directly measures how late jobs are. CPU can be low while jobs wait on I/O.

A job fails on every attempt because its input file is corrupt. What should happen?

  1. Retry forever with backoff
  2. After maxReceiveCount attempts move it to a DLQ, mark FAILED, and alarm
  3. Delete it silently
  4. Restart all workers
A poison message must leave the main queue so it stops wasting worker time, and someone must look at it.

Jobs arrive at 50 per second and each takes 4 seconds. How many concurrent workers do you need at minimum?

  1. 12
  2. 50
  3. 200
  4. 4
Little's Law: concurrency = arrival rate x time = 50 x 4 = 200.

When is a workflow engine like Temporal the better choice?

  1. Many dependent steps over hours, and you must resume where it stopped
  2. One 2-second thumbnail job
  3. Serving a cached web page
  4. Counting likes
Durable execution records each finished step and replays to resume after a crash.
