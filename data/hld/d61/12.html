100M concurrent listeners at 160 kbps need about how much egress?

  1. 16 Gbps
  2. 160 Gbps
  3. 16 Tbps
100,000,000 x 160 kbps = 16,000,000,000 kbps = 16 Tbps. Only CDNs plus client caching handle that.

Control path through our services, data path from the CDN.

How do you model a song that is a single, not part of an album?

  1. A release of type "single" containing one track
  2. A track with album_id = NULL
  3. A separate singles table
Every track belongs to a release; the type distinguishes album, single and EP, so queries need no special cases.

With fuzziness AUTO, how many edits are allowed for a 4-letter term like "shap"?

  1. 0
  2. 1
  3. 2
AUTO allows 0 edits for 1-2 characters, 1 for 3-5, and 2 for longer terms.

Why store a rank key instead of an integer position for playlist items?

  1. Ranks use less disk
  2. Ranks are faster to sort
  3. A move or insert updates one row instead of renumbering many
Ranks leave gaps between neighbours; rebalance rarely in the background.

Which data needs strong consistency?

  1. Subscription status and payments
  2. Play counts on an artist page
  3. The search index
Money and access rights must be right now; counts and the index can lag.

Which fix best prepares for a midnight mega-release?

  1. Double the catalogue database primary size
