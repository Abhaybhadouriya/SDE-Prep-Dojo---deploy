Failure modes

  • Kiosk offline: pickups still work from cached hashes; drop-offs use pre-assigned boxes; events queue in the outbox; capacity service stops selling after a threshold.
  • Door opens but parcel not inserted (driver walks away): sensor says empty when the door closes, so the assignment rolls back and the box returns to AVAILABLE after a short timeout.
  • Code delivered, kiosk never got the hash: the kiosk falls back to an online check; if offline too, the app's barcode or support phone line (printed on Amazon lockers) handles it.
  • Holiday surge: capacity counters fill; checkout shows fewer lockers; that is the system working, not failing.
  • Clock skew on the kiosk: deadlines come from the server; the kiosk receives explicit revocations rather than computing expiry from its own clock alone.
