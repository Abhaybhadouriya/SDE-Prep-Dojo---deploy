  • Load is small (about 500K parcels a day, 60 drop-offs per second at peak); the problems are correctness, the edge and security.
  • Reserve capacity per (locker, size, day) at checkout; assign the exact compartment at drop-off.
  • Allocate with a conditional update on state + version; add idempotency keys for retries. A version column is a fencing token.
  • Issue the code only when the door closes on an occupied box; free a box only when the sensor says empty.
  • Push code hashes to the kiosk so pickups work offline; desired vs reported state with versions; an outbox with sequence numbers.
  • 6-digit codes with 40 active per kiosk: 1 in 25,000 per guess. Escalating lockouts, single-use, bound to kiosk and deadline. Store an HMAC with the key in a TPM/KMS: a salted hash of only 106 codes is cracked offline in seconds.
  • Store pickup is the same pattern: hold inventory and a labour-limited slot, then hand over on check-in.
