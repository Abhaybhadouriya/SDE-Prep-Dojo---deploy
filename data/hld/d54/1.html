Requirements

A few words first. A location (or locker bank) is one physical kiosk with many compartments in sizes S, M, L. A reservation is a promise that a parcel for an order will have room at a location on a given day. An assignment is the moment a specific compartment is given to a specific parcel. A pickup code is a short secret that opens that compartment once.

Functional

  1. Find lockers At checkout, show nearby locations that can take this order (size, weight, hours, and space on the delivery day).
  2. Reserve When the order is placed, hold capacity at the chosen location for the expected delivery day.
  3. Drop off The driver authenticates at the kiosk, scans the parcel, and a free compartment of the right size opens. When the door closes on a parcel, the system issues a pickup code.
  4. Notify Email and app notification with the code (or a barcode), location and deadline. A reminder before expiry.
  5. Pick up The customer enters the code or scans the barcode or uses the app; the right door opens once.
  6. Expire After the pickup window, revoke the code, create a task for a driver to remove the parcel, and trigger the return and refund.
  7. Returns A customer can drop a return into a compartment with a return code; a carrier collects it later.
  8. Store pickup variant (Walmart) Reserve items from store inventory and a pickup time slot; staff pick and stage the order; the customer checks in and receives it.
