  • Catalog = truth (strong). Search index and review views = derived, eventually consistent copies.
  • Flexible attributes: JSON bag + category schema registry; filtering belongs to search.
  • Sync the index with CDC (or outbox) into Kafka keyed by product_id; never dual-write.
  • Split by change rate: text in the inverted index, price/stock in an in-place NRT store.
  • Shards sized by data (10-50 GB), replicas by QPS; ranking is retrieve then re-rank.
  • Reviews are ~1000:1 read-heavy: CQRS, idempotent summary counters, Bayesian average.
  • Search is a hint; product page and checkout check live stock.
