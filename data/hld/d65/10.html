Related: Distributed Configuration Service (d69) uses the same ideas - versioned documents, watch or long-poll, last-known-good - but pushes one config to a whole fleet of servers, with staged rollouts and rollback. This page syncs one user's devices, so the hard parts are conflicts between devices and large encrypted backups.

  • AWS IoT Device Shadow: the public model for multi-device state. Each shadow has desired and reported sections, a delta, per-attribute timestamps, and a version incremented on every update; an update with an old version is rejected so the client must resync, and a client can ignore messages older than the version it already has.
  • Android Auto Backup: backs up app data to the user's Google Drive, up to 25 MB per app, end-to-end encrypted on Android 9+ with the screen lock; runs when 24 hours have passed, the device is idle and on Wi-Fi; restores during setup, after install and before first launch; supports direct device-to-device transfer with separate rules.
  • Apple iCloud Backup and Quick Start: backups hold data and settings that do not already sync to iCloud; a new iPhone can transfer from an old device nearby or restore from iCloud, and media keeps downloading on Wi-Fi after the device is usable.
  • Dropbox-style sync: files split into blocks addressed by hash so only changed blocks upload; see the file sync design on this site.
