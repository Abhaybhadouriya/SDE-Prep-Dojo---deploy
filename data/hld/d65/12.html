Quick quiz

The interviewer asks how to cut storage for old-to-new device setup. Best first answer?

  1. Compress the settings with gzip
  2. Pull settings directly from the old device at setup time instead of keeping cloud copies
  3. Move the copies to cheaper storage
That was the accepted answer in the Amazon round; then add the offline fallback.

A device sends an update with base_version 7, but the server is at version 9. What happens?

  1. The write is applied as version 10
  2. The server merges silently
  3. The write is rejected; the device gets the current state and rebases
Optimistic locking, the same rule as AWS IoT Device Shadow versions.

Why content-defined chunking instead of fixed 4 MB blocks?

  1. An insert near the start of a file then changes only nearby chunks
  2. It uses less CPU
  3. It makes encryption unnecessary
Fixed blocks shift every boundary after an insert, so everything after it re-uploads.

100 TB of daily incremental backups all happen in one hour. Roughly what ingest rate is needed?

  1. 1.2 GB/s
  2. 28 GB/s
  3. 280 MB/s
100 TB / 3,600 s = about 28 GB/s; spread over 24 h it is about 1.2 GB/s. Jitter matters.

When is a backup snapshot safe to restore?

  1. As soon as the first chunk uploads
  2. When the device says it finished
  3. After the manifest commit, which happens only when every referenced chunk is stored and verified
The manifest commit is the atomic visibility point.

Why per-user dedup rather than global dedup?

  1. Global dedup leaks whether a file exists elsewhere and conflicts with end-to-end encryption
  2. Global dedup saves less space
  3. Per-user dedup is required by HTTP
Privacy and E2E encryption usually outweigh the extra savings.
