Gotchas

  • Origin exposed: attackers bypass the whole edge by hitting the origin IP. Lock the origin to the edge.
  • Straight to Block: new rules in Block mode cause self-inflicted outages. Count first.
  • Per-IP limits behind CGNAT block thousands of real users; per-IP limits are useless against residential proxy farms.
  • Trusting X-Forwarded-For blindly: clients can set it. Only use the address your own trusted proxy appended.
  • Client-side score checks: a score the browser reports is worthless; assess server-side and check the action name.
  • One signal = block: data centre IPs include VPNs, extensions trigger automation signals; combine signals.
  • Mobile apps have no JavaScript challenge: use the vendor's mobile SDK or app attestation, or bots will simply call your API directly.
