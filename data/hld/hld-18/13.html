Quick quiz

A credential-stuffing attack uses valid login requests from thousands of residential IPs, 3 attempts each. Which layer is most likely to catch it?

  1. A WAF SQL-injection rule
  2. A per-IP rate limit of 100 per 5 minutes
  3. Bot management using fingerprints and behaviour, plus login risk scoring
The requests are valid and slow per IP, so only client and behaviour signals (and step-up auth) catch them.

In reCAPTCHA Enterprise, what does a score of 0.9 mean?

  1. Likely a legitimate user
  2. Likely a bot
  3. The token is invalid
Scores run 0.0 to 1.0 and higher means lower risk.

What does the Count action do in an AWS WAF rule?

  1. Blocks after a count threshold
  2. Records the match (and labels) and continues evaluating
  3. Allows and stops evaluation
Count is non-terminating, which is why it is used to test rules safely.

Why is a strict per-IP rate limit risky for a consumer mobile app?

  1. Mobile phones have no IP address
  2. WAFs cannot see mobile traffic
  3. IPv6 is not supported
  4. Carrier-grade NAT puts many real users behind one IP
One shared address can carry thousands of users; a per-person limit on it blocks all of them.

The User-Agent says Chrome on Windows, but the JA4 fingerprint matches a Python HTTP library. What does this indicate?

  1. A TLS misconfiguration on the server
  2. A script pretending to be a browser
  3. A normal browser update
The mismatch between claimed and real client stack is a classic automation signal.

In OWASP CRS anomaly scoring with default settings, when is a request blocked?

  1. On the first rule that matches
  2. Only at paranoia level 4
  3. When the summed severity score reaches the inbound threshold (5 by default)
Rules add points (critical 5, error 4, warning 3, notice 2); the threshold check decides.

One challenge token is seen from 40 IP addresses in 6 countries within five minutes. What is the best reading?

  1. The token was shared across a bot farm
  2. The user is travelling
  3. The CDN is misrouting
Token reuse across many IPs, countries or ASNs is a strong coordination signal; AWS Bot Control has rules for exactly this.
