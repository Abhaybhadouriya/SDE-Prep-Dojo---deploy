  • Prefill is compute-bound (TTFT); decode is memory-bandwidth bound (TPOT). Latency = TTFT + TPOT x output tokens, so stream.
  • The KV cache grows per token per request; GPU memory left after weights caps concurrency. Size fleets by KV memory per concurrent stream.
  • Continuous batching refills slots every step; PagedAttention pages the KV cache like OS virtual memory (60-80% waste down to under 4%).
  • RAG = ingestion (chunk, embed, index, propagate deletes) + query (embed, hybrid retrieve with ACL filter, rerank, prompt, cite).
  • Vector DBs trade recall vs latency vs memory; HNSW is the default; the index is rebuildable, not the source of truth; version your embeddings.
  • Three caches: exact, semantic (false-hit risk), prefix/KV (exact prefix, stable content first, affinity routing).
  • Rate limit by tokens and concurrency, reserve prompt + max_tokens then refund; separate interactive and batch lanes.
  • Evaluate retrieval and answers separately, offline and online; guardrails on both sides; OWASP LLM Top 10 as the checklist.
