Resources

  • Netflix: Distributed Counter Abstraction blog - four rejected designs, idempotency tokens, immutable-window rollups, real numbers.
  • systemdesign.one: Distributed Counter System Design blog - every approach compared, CRDT counters, key suffix splitting.
  • TAO: Facebook's Distributed Data Store for the Social Graph (ATC 2013) paper - assoc_count, separate count table, production count distribution.
  • Firestore: Distributed counters doc - the sharded counter pattern with code and its read-cost trade-off.
  • DynamoDB: Write sharding doc - random vs calculated suffixes; plus partition limits (1,000 writes/s per partition).
  • Redis: HyperLogLog doc - 12 KB, 0.81% error, PFADD/PFCOUNT/PFMERGE.
  • Cassandra: CQL data types (counters) doc - why counter updates are not idempotent.
  • SoundCloud: Keeping counts in sync blog - batch + speed layer for play/like counts, cache invalidation with random TTL.
  • Cloudflare: Counting things, a lot of different things blog - local per-PoP counters and sliding-window estimates with measured error.
  • Reddit: View Counting at Reddit (2017) blog - the primary source: Kafka, a rules consumer, Redis HyperLogLog per post, Cassandra persistence.
  • InfoQ: Counting at Reddit (QCon.ai 2018) video - Reddit's view counting with probabilistic algorithms.
  • Tinybird: Counting 100 billion unique IDs blog - summarises Reddit's pipeline and compares an exact-count alternative.
  • awesome-scalability repo - more counting case studies (Pinterest, Quora, SoundCloud).
  • On this site: Pattern: Scaling Writes, Pattern: Counting & Aggregation, Pattern: Contention, Big Data & probabilistic structures, Replication & consensus (CRDTs), Top-K, Leaderboard, Key-Value Store.
