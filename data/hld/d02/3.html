Key APIs

A rate limiter has two "APIs": the internal check the gateway calls, and the HTTP contract clients see.

# Internal: gateway -> limiter (often a library call or gRPC, not HTTP)
ShouldAllow(descriptors=[("api_key","k_8f2"), ("route","POST /v1/orders")], cost=1)
  -> { allowed: false, limit: 100, remaining: 0, reset_after_ms: 4200 }

# Rules (config, hot-reloaded; stored in a config service or a K8s ConfigMap)
rules:
  - match: { api_key: "*" }          ; limit: 100 per minute ; algorithm: token_bucket
  - match: { route: "POST /login" }  ; key: username ; limit: 5 per minute ; fail: closed
  - match: { route: "*" }            ; limit: 50000 per second (global) ; algorithm: token_bucket

# What the client sees when limited
HTTP/1.1 429 Too Many Requests
Retry-After: 4
RateLimit-Policy: "default";q=100;w=60
RateLimit: "default";r=0;t=4
Content-Type: application/json
{"error":"rate_limited","retry_after_seconds":4}

The RateLimit-Policy and RateLimit headers come from an IETF draft (q = quota, w = window seconds, r = remaining, t = seconds until reset). Many public APIs still send the older informal X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset trio. Either is fine in an interview; what matters is telling the client when to come back, so well-behaved clients back off instead of hammering.

429 or 503? 429 means "you sent too much" (a per-client limit). 503 Service Unavailable means "we are overloaded" (load shedding, for everyone). Stripe's write-up uses exactly this split: 429 for its per-user limiters, 503 from its load shedders.

Try it: a toy limited API

A 30-line server using only the Python standard library: a per-API-key token bucket with capacity 5 and refill 1 token per second.

# rl_server.py - toy API protected by a per-client token bucket (5 burst, 1 token/s)
import math, threading, time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

CAPACITY, RATE = 5, 1.0
buckets, lock = {}, threading.Lock()

def take(key):
    now = time.monotonic()
    with lock:
        tokens, last = buckets.get(key, (CAPACITY, now))
        tokens = min(CAPACITY, tokens + (now - last) * RATE)   # refill
        allowed = tokens >= 1
        if allowed:
            tokens -= 1                                        # spend
        buckets[key] = (tokens, now)
        return allowed, tokens

class H(BaseHTTPRequestHandler):
    def do_GET(self):
        key = self.headers.get("X-Api-Key", self.client_address[0])
        allowed, tokens = take(key)
        self.send_response(200 if allowed else 429)
        self.send_header("RateLimit-Policy", f'"burst";q={CAPACITY};w={int(CAPACITY / RATE)}')
        self.send_header("RateLimit", f'"burst";r={int(tokens)};t={0 if tokens >= 1 else math.ceil((1 - tokens) / RATE)}')
        if not allowed:
            self.send_header("Retry-After", str(math.ceil((1 - tokens) / RATE)))
        body = b'{"ok":true}\n' if allowed else b'{"error":"rate_limited"}\n'
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

if __name__ == "__main__":
    ThreadingHTTPServer(("127.0.0.1", 8082), H).serve_forever()
