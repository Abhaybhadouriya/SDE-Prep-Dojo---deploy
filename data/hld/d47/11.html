  • Two latency SLOs: TTFT (prefill) and TPOT (decode). Stream with SSE.
  • Decode is memory-bound; throughput = how many sequences fit in a batch.
  • Continuous batching refills slots every iteration (Orca); PagedAttention pages the KV cache (vLLM, <4% waste vs 60-80%).
  • KV cache per token = 2 x layers x hidden x bytes (~0.8 MB for 13B fp16).
  • Route by KV memory and prefix affinity; separate or chunk prefill to protect streaming.
  • Rate-limit in tokens: reserve input + max_tokens, refund the rest; tiered priority queues.
  • Decouple generation from the connection: buffer tokens, resume with Last-Event-ID, propagate cancel.
