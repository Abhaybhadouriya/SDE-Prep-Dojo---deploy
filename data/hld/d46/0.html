The story

Explain like I'm 5

Imagine a giant playground with a million kids who want to play chess. A friendly teacher stands at the gate. She looks at how good each kid is and pairs them with someone just as good, so the game is fun. Then she sends each pair to a table with a referee. The kids never touch each other's pieces directly. They tell the referee "I move my knight here", the referee checks the rule book, moves the piece, and presses the chess clock. If a kid runs away and comes back, the referee still remembers the board. At the end of the day, the teacher writes everyone's score on a big wall chart.

That is the whole system. The teacher at the gate is the matchmaking service. Each referee is a game server that owns one game. It is authoritative, which means its copy of the board is the truth and the players' screens are only copies. The chess clock is a server-side timer. The wall chart is the leaderboard.

Why do interviewers like it? It looks like a toy, but it tests real-time connections (WebSockets), routing many messages to the one server that owns a game, strong consistency inside a tiny piece of state, timers at scale, crash recovery and ranking. Walmart has asked "online chess with real-time play and leaderboards" as an HLD round, and Amazon has used chess as a bar-raiser LLD question (see the interview reports in our gap analysis). Hello Interview lists it as a full problem breakdown.

Say this early: "The game server is authoritative. Clients send intents, the server validates, applies, timestamps and broadcasts. Every game lives on exactly one server at a time." Everything else in the design follows from that sentence.

New words, once each: WebSocket is a long-lived two-way connection, so the server can push the opponent's move. Ply is one half-move (White moves = 1 ply). QPS is requests per second. Authoritative means the server's copy is the truth. Idempotent means safe to retry: doing it twice has the same effect as once. Lease is a lock that expires on its own unless renewed, and a fencing token is the increasing number that comes with it. Consistent hashing maps each game id to one server so that adding a server moves only a few games. p99 means "99 out of 100 are faster than this". The rest are in the glossary.
