How the real platforms do it

  • Lichess (open source): Scala 3 server, MongoDB for over 12 billion games, Elasticsearch for search, a separate WebSocket server lila-ws connected to the main app through Redis, rules in the pure scalachess library, and computer analysis on a donated Stockfish cluster coordinated by fishnet.
  • Chess.com, January 2023: 10M active members on a day, 31.7M games on one day, more than 1M games per hour and about 16,000 moves per second on average. Fixes included splitting tables, sharding databases, moving services into memory and separating the database with user and gameplay data.
  • Chess.com Realtime Chess Network: its help centre says the old live server was a single machine in Virginia, and that more than 99.7% of live games now run on the distributed RCN. Its Google Cloud migration places gameplay nodes worldwide, with bullet chess as the latency-critical case.
  • Glicko-2: used by Lichess and Chess.com; tracks rating, rating deviation (starts at 350) and volatility (0.06 for new players).
