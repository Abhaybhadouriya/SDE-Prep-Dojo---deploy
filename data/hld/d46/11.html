  • Authoritative server: clients send intents; the server validates, timestamps and broadcasts.
  • One owner per game (consistent hash + lease + fencing); gateways only hold sockets.
  • Ply numbers make moves idempotent and make reconnection a simple "send me after ply N".
  • Atomic Redis claim (Lua + ZREM) stops double matching; bucket queues by time control and region.
  • Server clocks with capped lag compensation; one timer per game in a timing wheel.
  • Journal moves before ack so a crash costs seconds, not the game.
  • Kafka only for game-finished fan-out (ratings, archive, anti-cheat); leaderboard in a Redis sorted set.
