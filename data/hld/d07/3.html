Key APIs

Three apps talk to us: the customer app, the restaurant tablet and the rider app. Keep the API small and name the one or two that carry the hard guarantees.

# Discovery (read heavy, cacheable, cursor paginated)
GET  /v1/restaurants?lat=12.970&lng=77.640&cuisine=south-indian&cursor=abc
GET  /v1/restaurants/{restaurantId}/menu          # served from cache, has a version

# Cart lives per user (a key-value record)
PUT  /v1/cart                       { "restaurantId": "r1", "items": [{ "itemId": "dosa", "qty": 2 }] }

# Place the order - MUST be idempotent
POST /v1/orders
Idempotency-Key: 7f9c2d1e-...       # created by the app once per checkout attempt
{ "cartVersion": 12, "addressId": "a9", "paymentMethodId": "upi-1" }
-> 201 { "orderId": "o_81234", "status": "PLACED", "etaMinutes": 32 }

GET  /v1/orders/{orderId}           # status + ETA
WS   /v1/orders/{orderId}/track     # server pushes rider location + ETA every few seconds
POST /v1/partner/orders/{orderId}/accept   { "prepMinutes": 15 }
POST /v1/partner/orders/{orderId}/reject   { "reason": "ITEM_UNAVAILABLE" }
POST /v1/partner/orders/{orderId}/ready    # food is packed
PUT  /v1/partner/status                    { "online": false }   # kitchen is full
PUT  /v1/partner/menu/items/{itemId}       { "inStock": false }
# Batched pings save battery and connections
POST /v1/rider/locations
{ "riderId": "rd_17", "pings": [ { "lat": 12.9716, "lng": 77.6420, "ts": 1763920800000 },
                                 { "lat": 12.9719, "lng": 77.6424, "ts": 1763920804000 } ]   # ms since epoch }

POST /v1/rider/offers/{offerId}/accept     # conditional: only if offer still OPEN
POST /v1/rider/orders/{orderId}/picked-up
POST /v1/rider/orders/{orderId}/delivered  { "otp": "4821" }

Why the cart has a version. Menus and prices change. When the order is placed, the order service re-reads the prices and checks cartVersion. If the price changed, it returns 409 Conflict with the new total instead of silently charging a different amount. The same rule appears in e-commerce checkout.
