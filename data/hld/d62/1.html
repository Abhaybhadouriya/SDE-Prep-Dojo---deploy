Requirements

Functional

  1. Tag an entity Add or remove a tag on any entity from any product (Jira issue, Confluence page, Bitbucket PR). Create the tag if it does not exist.
  2. Tags of an entity List the tags on one entity (shown on every issue and page view).
  3. Entities of a tag List everything with a tag, across products, newest first, paginated; optionally filter by product or type.
  4. Tag search Autocomplete tag names while typing ("perf" suggests "performance", "perf-q3").
  5. Popular and trending Top-10 tags for a tenant: all-time popular and trending in the last 24 hours or week (asked in a 2025-03 Atlassian report).
  6. Multi-tag query (stretch) Entities with tag A AND tag B.

Out of scope unless asked: who may see an entity (each product owns its permissions; we must respect them), full-text search of entity content, tag hierarchies and synonyms.

Ask: "Are tags shared across products within one customer, and are they free-text or managed?" In the reports, tags are shared across products in one tenant and created on first use, like Jira labels. That single answer fixes the uniqueness rule: one tag name per tenant.
