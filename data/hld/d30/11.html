  • Webhook → Kafka → controller → ephemeral pod → signed image → GitOps commit → Argo CD → canary.
  • Every job is untrusted: fresh non-root pod, no Docker socket, short-lived OIDC credentials.
  • Speed = cache (layers, remote build cache) + sharding + affected-only builds.
  • Merge queue tests PRs as they will land, so main stays green.
  • CI never holds prod credentials: GitOps pull, rollback = git revert.
  • Deploy digests, not tags; sign and verify at admission.
  • Canary + metrics analysis + automatic abort; waves across clusters and regions.
