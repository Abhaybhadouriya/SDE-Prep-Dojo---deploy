How real systems do it

  • Uber described SubmitQueue, a speculative merge queue that keeps a huge monorepo's main branch green. Keeping master green at scale (opens in a browser).
  • GitHub ships a merge queue and OIDC tokens for Actions, and Actions Runner Controller runs self-hosted runners as autoscaled Kubernetes pods. Merge queue, OpenID Connect, actions-runner-controller.
  • Argo project (CNCF): Argo CD for GitOps and Argo Rollouts for canary/blue-green with metric analysis. Argo CD docs, Argo Rollouts.
  • Tekton (CD Foundation) models CI as Kubernetes CRDs. Tekton overview.
  • Amazon Builders' Library on shuffle sharding - the technique for limiting blast radius in shared fleets like runner pools. Workload isolation using shuffle sharding.
  • Supply chain: SLSA (build provenance levels) and Sigstore cosign (signing). Metrics: DORA's software delivery metrics.
