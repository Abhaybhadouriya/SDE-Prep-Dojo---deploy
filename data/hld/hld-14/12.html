The 60-second answer

The 60-second answer. "Users log in through an OIDC identity provider with MFA, using the authorization code flow with PKCE; passwords, if we hold them, are hashed with Argon2id or bcrypt. The client gets a short-lived JWT access token, 5 to 15 minutes, in an HttpOnly cookie or as a bearer token, plus a rotating refresh token kept server-side so I can revoke a user. The gateway verifies signatures locally against cached JWKS and returns 401 on failure; each service checks object-level ownership and returns 403. Service-to-service traffic uses mTLS with workload identities from the mesh. Data at rest uses envelope encryption with keys in a KMS, secrets come from Vault as short-lived credentials, and the edge has rate limits per key plus a CDN or WAF that absorbs floods before they reach the origin."
