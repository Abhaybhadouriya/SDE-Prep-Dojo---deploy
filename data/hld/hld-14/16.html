Resources

  • Karan Pratap Singh: System Design repo - chapters on OAuth 2.0 and OIDC, SSO and SAML, and SSL/TLS/mTLS.
  • System Design Primer: Security repo - the short baseline list: encrypt, sanitize, parameterize, least privilege.
  • ByteByteGo: A Cheatsheet to Build Secure APIs blog - HTTPS, rate limits, validation, tokens, RBAC, monitoring.
  • OWASP API Security Top 10 (2023) doc - the ten API risks with examples and prevention.
  • RFC 9700: OAuth 2.0 Security Best Current Practice doc - PKCE, deprecated grants, exact redirect matching, sender-constrained tokens.
  • RFC 7636: PKCE doc - the verifier and challenge mechanics.
  • RFC 7519: JSON Web Token doc - JWT structure and registered claims.
  • OpenID Connect Core 1.0 doc - ID tokens, userinfo and the identity layer on OAuth.
  • OWASP Password Storage Cheat Sheet doc - Argon2id, scrypt, bcrypt, PBKDF2 parameters; salt and pepper.
  • OWASP Session Management Cheat Sheet doc - session id entropy, cookie attributes, timeouts.
  • SPIFFE overview doc - workload identity, SVIDs and SPIRE for service-to-service mTLS.
  • Google: BeyondCorp, A New Approach to Enterprise Security paper - zero trust: no privileged intranet.
  • Google Cloud: Default encryption at rest doc - a real envelope-encryption key hierarchy.
  • HashiCorp Vault: Database secrets engine doc - dynamic, leased database credentials.
  • Cloudflare DDoS threat report, 2024 Q4 blog - 2024 attack volumes and the 5.6 Tbps record at the time.
  • Cloudflare: Blocking a 7.3 Tbps DDoS attack blog - anycast plus XDP/eBPF fingerprinting, in detail.
