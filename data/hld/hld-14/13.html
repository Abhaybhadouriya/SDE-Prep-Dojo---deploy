  • AuthN = who you are (401). AuthZ = what you may do (403), on every request and every object.
  • Passwords: Argon2id with a per-user salt; never plaintext, never a fast hash.
  • Sessions revoke instantly but need a lookup; JWTs verify locally but are hard to revoke. Use short JWT + rotated refresh token.
  • A JWT is signed, not encrypted; check signature, alg, iss, aud, exp.
  • OAuth 2.0 = delegated authorization (access token). OIDC adds identity (ID token). SAML = XML enterprise SSO.
  • Use authorization code + PKCE; implicit and password grants are deprecated (RFC 9700).
  • TLS at the edge, mTLS with short-lived workload certs inside: zero trust.
  • Envelope encryption: DEK per chunk, wrapped by a KEK in KMS; rotate by re-wrapping.
  • Secrets live in a vault, ideally short-lived and dynamic, never in code or images.
  • OWASP API #1 is BOLA: check ownership in the service. DDoS is absorbed at an anycast edge, not by autoscaling.
