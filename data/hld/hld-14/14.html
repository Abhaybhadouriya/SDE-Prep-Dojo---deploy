Quick quiz

A logged-in user requests an admin-only page. Which status code fits best?

  1. 403 Forbidden
  2. 401 Unauthorized
  3. 404 Not Found
  4. 500
They are authenticated (we know who they are) but not authorized, so 403. 401 means "we do not know who you are".

What is the main drawback of a stateless JWT access token?

  1. It needs a database lookup on every request
  2. It cannot carry user claims
  3. It cannot easily be revoked before it expires
Verification is local, which is the benefit; the cost is revocation. Hence short lifetimes plus refresh tokens.

What does PKCE protect against?

  1. Weak user passwords
  2. A stolen authorization code being redeemed by another app
  3. DDoS on the token endpoint
Only the client that holds the code verifier can exchange the code, so an intercepted code is useless.

Which token tells the client app who the user is?

  1. OAuth access token
  2. OIDC ID token
  3. Refresh token
  4. Session cookie of the API
The ID token's audience is the client; the access token is meant for the resource API.

Why does envelope encryption make key rotation cheap?

  1. Because data is stored unencrypted
  2. Because KMS keys never expire
  3. Rotating the master key only requires re-wrapping small data keys, not re-encrypting all data
Data is encrypted by DEKs; only the wrapped DEKs change when the KEK rotates.

Changing /orders/101 to /orders/102 shows someone else's order. Which OWASP API risk is this?

  1. API1 Broken Object Level Authorization
  2. API4 Unrestricted Resource Consumption
  3. API7 SSRF
The object-level ownership check is missing.

What best defends against a multi-terabit volumetric DDoS?

  1. Autoscaling the app servers
  2. A bigger database
  3. An anycast edge network that spreads and drops traffic near its sources
No single site can absorb Tbps floods; anycast spreads them and edge filters drop them before the origin.
