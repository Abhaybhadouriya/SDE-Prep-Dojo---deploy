  • A vote is state keyed by (user, thing), not an increment. Deltas are derived; counters are rebuildable.
  • Hot = log10(score) + created_time / 45,000 s. 12.5 hours of newness = 10x the votes. It changes only on votes.
  • "Best" for comments = Wilson score lower bound (Reddit: 80% confidence).
  • Never sort on read. Precompute listings as a denormalized index, mutate them on votes.
  • Partition the vote pipeline by listing key so each listing has one writer; split per query type.
  • Comment trees: shard by post_id, precompute the shape, render within a budget, update async in batches.
  • Every queue needs a quota; every cache tier needs a warm-up plan; watch p99, not averages.
