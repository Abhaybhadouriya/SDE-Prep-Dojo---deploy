You might confuse these

Thisvs thisThe difference in one line
ReplicationShardingReplication = same data on many machines (survive, read scale). Sharding = different data on each machine (size, write scale). Big systems do both.
Consistency in CAPConsistency in ACIDCAP's C = all replicas look like one copy. ACID's C = a transaction keeps the database's rules (constraints) true. Same word, different idea.
LatencyThroughputLatency = how long one request takes. Throughput = how many per second. Batching raises throughput and often raises latency.
Load balancerAPI gatewayAn LB spreads traffic. A gateway is an L7 proxy with extra jobs: auth, rate limits, request shaping, routing to many services.
CDNCache (Redis)A CDN caches HTTP responses near users, worldwide. Redis caches data next to your servers, in one region.
QueueLog (Kafka)A queue deletes a message once consumed. A log keeps it, so many groups can read it and you can replay.
Partition (Kafka/DB shard)Partition (CAP)A data partition is a slice of data. A network partition is a network failure that splits nodes into groups.
