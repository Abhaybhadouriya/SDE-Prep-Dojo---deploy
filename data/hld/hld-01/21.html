Resources

  • Latency numbers every programmer should know doc - the original list; print it.
  • Interactive latency numbers by year doc - drag a slider to see how the numbers changed over time.
  • Azure: Cache-Aside pattern doc - clear write-up with the consistency caveats.
  • Azure: Sharding pattern doc - lookup, range and hash strategies with their trade-offs.
  • Amazon Builders' Library: Caching challenges and strategies blog - cold starts, thundering herds, and how Amazon thinks about cache risk.
  • Scaling Memcache at Facebook (NSDI 2013) paper - leases, regional pools and invalidation from the DB commit log.
  • Discord: How Discord stores trillions of messages blog - partition keys, hot partitions and request coalescing in a real system.
  • DynamoDB: partition key design doc - how to avoid hot partitions.
  • Amazon Dynamo paper (2007) paper - consistent hashing, virtual nodes and N/R/W quorums in the original.
  • Jepsen: consistency models doc - the map of strong to weak consistency.
  • PACELC theorem doc - short summary with database examples; Abadi's paper for depth.
  • System Design Primer repo - the same fundamentals in a different voice, with Anki cards.
  • Bigtable: A Distributed Storage System for Structured Data paper - the original tablets, tablet servers and METADATA table design.
  • MongoDB: Sharded cluster balancer doc - range size, migration threshold and balancing window.
  • DynamoDB: burst and adaptive capacity doc - how hot partitions and hot items are handled.
