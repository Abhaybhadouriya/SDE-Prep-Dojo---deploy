Remember this

  • A day is ~105 seconds: 1M requests/day is about 12 RPS. Peaks are a few times the average (much more in flash sales).
  • Memory : SSD : same-DC round trip : cross-continent is roughly 100 ns : 150 us : 0.5 ms : 150 ms. Network hops are the expensive part.
  • Scale up first; scale out needs stateless servers; the database is the hard part.
  • L4 balances connections (fast, blind); L7 reads HTTP (routes, TLS, retries). Real systems layer both.
  • Cache-aside + TTL + delete-on-write is the default. Watch stampedes, hot keys and penetration.
  • SQL for rules and transactions; wide-column/KV for huge single-key write volume; pick by access pattern.
  • Replication = same data many places. Sharding = different data on each machine. W + R > N gives overlapping quorums.
  • Consistent hashing moves ~1/N of keys when a node joins; virtual nodes even out the load.
  • CAP is C vs A during a partition; PACELC adds latency vs consistency the rest of the time.
  • Queues decouple and absorb spikes; delivery is at-least-once, so make consumers idempotent.
