Resources

  • The Raft Consensus Algorithm (site, paper, visualisation) paper - start here; the paper "In Search of an Understandable Consensus Algorithm" is very readable.
  • The Secret Lives of Data: Raft course - an animated walkthrough of elections and log replication.
  • Raft (Wikipedia) doc - safety properties, timing rule and a list of production users.
  • etcd FAQ doc - cluster size vs fault tolerance table and heartbeat/election tuning.
  • Building and deploying MySQL Raft at Meta blog - real failover numbers and FlexiRaft quorums.
  • Martin Kleppmann: How to do distributed locking blog - fencing tokens and the Redlock critique.
  • Amazon's Dynamo (full paper, HTML) paper - quorums, sloppy quorum, vector clocks, Merkle trees, gossip.
  • Apache Cassandra: Dynamo architecture doc - consistency levels, gossip and phi accrual in a real database.
  • The Morning Paper: Chubby lock service paper - summary of Google's Paxos-backed lock service.
  • Paxos Made Live paper - Google on turning Paxos into a real system.
  • Leslie Lamport: Paxos Made Simple paper - the 14-page original explanation.
  • Patterns of Distributed Systems (Unmesh Joshi, martinfowler.com) book - lease, generation clock, heartbeat, gossip, version vector and more.
  • Twitter Snowflake (2010 README) repo - the original ID layout and requirements.
  • System Design Primer repo - replication and failover sections plus a Chubby link.
  • Awesome System Design Resources repo - heartbeats, consensus, gossip and locking reading list.
  • Awesome Scalability repo - real engineering articles on locking and consensus.
