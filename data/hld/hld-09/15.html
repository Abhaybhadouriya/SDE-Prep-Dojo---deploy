Quick quiz

N = 5 replicas. Which (W, R) guarantees a read overlaps the latest write?

  1. W=2, R=2
  2. W=1, R=3
  3. W=2, R=3
  4. W=3, R=3
You need R + W > N, so R + W >= 6. Only 3 + 3 = 6 qualifies; 2 + 3 = 5 is not greater than 5.

Why does Raft use randomized election timeouts?

  1. To save CPU
  2. To hide the leader from clients
  3. To make it unlikely that several followers become candidates at the same moment and split the vote
If all timers fired together, every follower would vote for itself and no one would win. Random timeouts let one node usually start first.

A 4-node Raft cluster tolerates how many failures?

  1. 1
  2. 2
  3. 3
Majority of 4 is 3, so only 1 can fail - the same as a 3-node cluster.

Client 1 holds a lock with token 33, pauses, and client 2 writes with token 34. What stops client 1's late write?

  1. The storage rejects any token lower than the highest it has seen
  2. Client 1 checks its lease before writing
  3. A longer TTL
A pause can happen after any check, so only the storage-side fencing check is safe.

Versions [A:2, B:1] and [A:1, B:2] are...

  1. Ordered: the first is newer
  2. Concurrent: neither dominates, so it is a conflict
  3. Identical
A is bigger in the first, B is bigger in the second, so neither happened-before the other.

What does a Merkle tree let two replicas do?

  1. Elect a leader
  2. Find the differing key ranges by comparing hashes top-down, transferring data proportional to the difference
  3. Encrypt data in transit
Equal subtree hashes mean equal data, so you only descend into branches that differ.

In Snowflake, how many IDs can one machine generate per millisecond?

  1. 4,096
  2. 1,024
  3. 69
12 sequence bits = 4,096 values per millisecond; 10 machine bits give 1,024 machines.
