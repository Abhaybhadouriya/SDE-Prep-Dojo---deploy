Resources

  • Uber Engineering: H3, Uber's hexagonal hierarchical spatial index blog - why hexagons, resolutions, and how Uber uses them for supply, demand and surge.
  • H3 resolution table doc - average cell area and edge length per resolution (res 5 about 253 km2, res 8 about 0.74 km2).
  • Uber Engineering: Operating Apache Pinot blog - real-time city operations dashboards over Kafka and FlinkSQL.
  • Apache Flink: Windows doc - tumbling, sliding, session windows, allowed lateness, side outputs.
  • Redis: Pub/Sub doc - at-most-once semantics and sharded pub/sub, the details interviewers probe.
  • TimescaleDB: Continuous aggregates doc - background rollups, real-time aggregates, and how they interact with retention.
  • AWS IoT Core endpoints and quotas doc - real MQTT broker limits to design around.
  • MQTT.org doc - the protocol, QoS levels and specifications.
  • System Design Primer repo - background on queues, caches and databases used here.
