Why this design is good
  • Tiny: one Redis + one DB covers 5M DAU
  • Every query is O(log N)
  • Rebuildable from the event log
Where it hurts
  • Global order resists sharding
  • Ties and windows need careful encoding
  • Redis memory cost per member is far above the raw 26 bytes
