Trade-offs, bottlenecks and failure modes

Use the sentence pattern: "I would pick X because of A; the cost is B; if C becomes a problem I would switch to Y."

DecisionOur pickWhyAlternative and when
TransportWebSocket (MQTT on very weak mobile networks)Two-way, low overhead per message, one connectionLong polling as a fallback when proxies block WebSocket; Facebook Messenger used MQTT for mobile efficiency
Message storeWide-column (Cassandra/Scylla)Huge append-heavy writes, single-partition readsStore-and-forward only (delete after delivery) if history lives on devices

OrderingPer-chat seqExact order per chat, cheapSnowflake ids if you can not afford a counter per chat

ConsistencyQuorum writes for messages, eventual for presenceMessages must not be lost; presence can be staleStronger (linearizable) only for things like group admin changes

What if this box fails?

BoxWhat breaksMitigation
One gatewayIts users disconnectClients reconnect with jittered backoff to another gateway; registry TTL expires the old entry; inbox covers the gap
Session registry (Redis)Can not find receiversReplicas + automatic failover; if missing, treat receiver as offline (inbox + push) - slower, never lost
Chat serviceSends failStateless, many replicas behind internal LB; client retries with the same client_msg_id
Message store nodeSome writes slowerRF=3, QUORUM; one node down still gives 2 of 3
KafkaPush and group fan-out delayedReplicated topics (RF 3, min.insync.replicas=2); producers buffer and retry; 1:1 still works
Whole regionUsers in that region disconnectedDNS/anycast steer to another region; messages replicated cross-region asynchronously (accept a few seconds of possible lag)
APNs / FCMNo notificationsRetry with backoff; messages still wait in the inbox
Strengths of this design
  • Hot path is short: 4 hops, one quorum write.
  • Every component scales horizontally.
  • Message never lost after the first tick.
Weak spots to name
  • Reconnect storms after gateway restarts.
  • Presence fan-out can explode.
  • Cross-region chats pay the inter-region round trip (tens of ms within a continent, about 150-250 ms India to US East).
