  • CDC reads the database's own log (MySQL binlog, Postgres WAL) - no app change, captures deletes, low load.
  • Debezium = Kafka Connect source connectors; one connector (one task) per database log.
  • One topic per table, key = primary key → per-row order. Nothing is ordered across rows or tables.
  • Deletes = delete event + tombstone; compacted topics hold the latest row per key.
  • Snapshot then stream; incremental watermark snapshots (DBLog) need no locks.
  • At-least-once transport + idempotent upsert sinks = effectively-once results.
  • Biggest real outage: an abandoned Postgres replication slot fills the disk. Alert and cap it.
  • Outbox for service contracts; raw table CDC for analytics, search and cache.
