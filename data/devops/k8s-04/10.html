Common mistakes and gotchas

Good to know (SDE-2)
MistakeWhat you seeFix
Selector does not match template labelskubectl apply rejects it: "selector does not match template labels"Keep selector.matchLabels a subset of template.metadata.labels
Using the latest tagPod template unchanged, so no rollout; nodes run different buildsUse immutable tags (git SHA or semver) or image digests
No readiness probe502s / connection refused on every deployAdd an honest readiness endpoint
Liveness probe checks the databaseDB blip restarts every pod at once (cascading failure)Liveness checks only the process itself
App ignores SIGTERM (or shell form CMD so PID 1 is sh)Waits 30 s then SIGKILL; dropped requestsExec form CMD, handle SIGTERM, add preStop sleep
Breaking DB change in the same releaseOld pods crash mid-rolloutExpand/contract migrations: add columns first, remove later
replicas in YAML while HPA is onReplica count jumps back on every applyDrop the field; let HPA own it
Editing pods directlyChanges vanish when the pod is replacedAlways change the Deployment template
