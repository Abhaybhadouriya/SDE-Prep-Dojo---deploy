Your first Deployment (try it on kind or minikube)

Must know (SDE-1)

Save this as web.yaml. Read the comments: every field here matters in interviews.

apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
  labels:
    app: web
spec:
  replicas: 3                     # desired number of pods
  revisionHistoryLimit: 10        # old ReplicaSets kept for rollback (default 10)
  progressDeadlineSeconds: 600    # mark rollout "failed" if stuck this long (default 600)
  minReadySeconds: 5              # a new pod must stay Ready 5 s before it counts as available
  selector:
    matchLabels:
      app: web                    # MUST match template labels below
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1                 # at most 1 extra pod above 3 during an update
      maxUnavailable: 0           # never go below 3 ready pods
  template:                       # the pod "cookie cutter"
    metadata:
      labels:
        app: web
    spec:
      containers:
      - name: web
        image: nginx:1.27
        ports:
        - containerPort: 80
        readinessProbe:           # only send traffic once this passes
          httpGet:
            path: /
            port: 80
          periodSeconds: 5
        resources:
          requests:
            cpu: 100m
            memory: 64Mi
$ kubectl apply -f web.yaml
deployment.apps/web created

Look at the names. The ReplicaSet is web-6d8f7b9c54: the Deployment name plus a pod-template-hash (a hash of the pod template). Each pod is the ReplicaSet name plus 5 random characters. Change anything in the template (image, env, probe) and the hash changes, which means a new ReplicaSet, which means a rollout. Change only replicas and the hash stays the same: that is a plain scale, not a rollout.

kubectl scale deployment web --replicas=5
kubectl get pods -l app=web          # 5 pods, same ReplicaSet
kubectl set image deployment/web web=nginx:1.28
kubectl rollout status deployment/web
# or, the GitOps way: change image in web.yaml and kubectl apply -f web.yaml
kubectl rollout history deployment/web
kubectl rollout undo deployment/web                # back to previous revision
kubectl rollout undo deployment/web --to-revision=1
kubectl rollout pause deployment/web     # batch several edits without a rollout each
kubectl rollout resume deployment/web
kubectl rollout restart deployment/web   # new pods, same image (e.g. to reload a Secret)
