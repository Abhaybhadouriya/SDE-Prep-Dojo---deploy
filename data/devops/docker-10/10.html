Follow-up traps and the right reply

Interviewer saysTrapRight reply
"So a container is a small VM?"AgreeingNo kernel, no hypervisor; a process with namespaces and cgroups.
"EXPOSE opens the port, right?"AgreeingIt is documentation; -p publishes.
"Deleting the file in the next RUN makes the image smaller?"AgreeingNo, layers are additive; delete in the same RUN or use multi-stage.
"Containers are secure isolation?""Yes" or "no"Weaker than VMs because the kernel is shared; harden it, or sandbox for untrusted code.
"CPU limit exceeded, so it gets killed?"AgreeingMemory kills; CPU throttles.
"Kubernetes doesn't support Docker images anymore?"AgreeingIt removed dockershim; Docker images are OCI and run fine.
"ufw protects published ports?"AgreeingDNAT happens before INPUT; use DOCKER-USER or bind to 127.0.0.1.
"Kubernetes namespaces are Linux namespaces?"AgreeingNo; K8s namespaces scope API objects. Linux namespaces isolate kernel resources.
":latest means the newest image?"AgreeingIt is just the default tag name, a movable pointer.
