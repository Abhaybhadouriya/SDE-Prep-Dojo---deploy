  • Docker is usually a follow-up topic in SDE loops: be short and precise, offer depth.
  • Answer pattern: define, mechanism, trade-off, gotcha with detection, Kubernetes link.
  • Decode exit codes as 128 + signal: 137 SIGKILL (often OOM), 143 SIGTERM.
  • Memory limits kill, CPU limits throttle. Name memory.max and cpu.max.
  • Chain: CLI, dockerd, containerd, shim, runc, process. Kubernetes skips dockerd via CRI.
  • Security in rings: image, runtime, host, pipeline. Socket access equals root. Patch runc.
  • Scenarios: gather facts, hypothesis, test, fix root cause, prevent.
