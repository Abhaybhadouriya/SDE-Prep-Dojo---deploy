Quick quiz

A container exits with code 143. What happened?

  1. It was OOM-killed
  2. It ended on SIGTERM (128 + 15), usually a clean stop
  3. The image was missing
  4. A segmentation fault
143 = 128 + 15. SIGTERM was delivered and the process exited because of it. 137 would be SIGKILL; a segfault is 139 (128 + 11).

Which part of the Docker stack does Kubernetes talk to directly on a modern node?

  1. dockerd
  2. The docker CLI
  3. containerd (or CRI-O) via CRI
  4. runc via REST
kubelet speaks the Container Runtime Interface to containerd or CRI-O. dockershim, the adapter for dockerd, was removed in v1.24.

Inside a container, an app connects to localhost:5432 expecting a Postgres container. Why does it fail?

  1. localhost is the container's own loopback in its own network namespace
  2. Postgres cannot run in containers
  3. Port 5432 is blocked by seccomp
  4. DNS is disabled by default
Each container has its own net namespace. Use the service name on a shared user-defined network.

The best first step when a Docker host's disk is full?

  1. docker system prune -a --volumes
  2. Reboot the host
  3. Delete /var/lib/docker
  4. Measure with docker system df and du to find what is big
Measure first. The usual culprit is unrotated logs. Blind pruning of volumes can delete data: on Engine 23+ --volumes only touches anonymous volumes, but on older engines (or with docker volume prune -a) a stopped database's named volume can go too.

Which isolation would you choose for running strangers' code in an online judge?

  1. Plain containers with --privileged for speed
  2. gVisor or Firecracker microVMs plus cgroup limits and no network
  3. One Kubernetes namespace per user
  4. Running code directly on the host as root
Untrusted code needs a stronger boundary than a shared kernel. Kubernetes namespaces are only API scoping.

Docker stop always takes exactly 10 seconds. The most likely Dockerfile cause?

  1. A large image
  2. Too many layers
  3. Shell-form CMD, so /bin/sh is PID 1 and does not forward SIGTERM
  4. A missing EXPOSE
10 seconds is the default grace period before SIGKILL. Use exec form and handle SIGTERM.
