The bring-up, step by step

Here is the whole sequence first as a picture. Click through it, then we run each step for real.

  1. Make a cluster. kind create cluster starts four Docker containers, each running a kubelet and a container runtime, and boots Kubernetes inside them.
  2. Install the operator. One YAML file adds Strimzi's CRDs (new API types) and the strimzi-cluster-operator Deployment.
  3. Describe Kafka. You apply a Kafka and two KafkaNodePool resources. Nothing runs yet; they are records in etcd.
  4. The operator acts. It watches those records and creates pods, Services, ConfigMaps, certificates and PVCs, then rolls out the controllers and brokers carefully.
  5. Topics as code. The Topic Operator (inside entity-operator) turns each KafkaTopic into a real Kafka topic.
  6. Autoscaler and images. Install KEDA. Copy your locally built images into the kind nodes so no registry is needed.
  7. Apps. Apply ConfigMap, Secret, Postgres, the four services and the NetworkPolicies. Orders flow.
