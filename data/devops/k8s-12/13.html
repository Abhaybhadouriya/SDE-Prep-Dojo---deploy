Quick quiz

A request fails with 403 Forbidden. Which gate rejected it?

  1. Authentication
  2. Authorization (RBAC)
  3. Schema validation
401 means "I do not know who you are" (authentication). 403 means "I know who you are, and you may not do this" (authorization).

You bind the built-in ClusterRole edit to a group using a RoleBinding in namespace shop. What can the group edit?

  1. Everything in every namespace
  2. Nothing, this is invalid
  3. Resources in namespace shop only
A RoleBinding always limits the grant to its own namespace, even when it references a ClusterRole. That is a common way to reuse standard roles.

Why is giving someone "create pods" in a namespace risky?

  1. They can mount any Secret in that namespace and run as any of its ServiceAccounts
  2. Pods use a lot of CPU
  3. It grants cluster-admin automatically
A pod spec can reference any Secret and ServiceAccount in its namespace, so the creator can read those secrets through the pod.

Your cluster has no NetworkPolicies. Can a pod in namespace a reach a pod in namespace b?

  1. No, namespaces block traffic
  2. Yes, the default is allow-all
  3. Only via a LoadBalancer
The Kubernetes network model is flat. Namespaces do not affect networking; only NetworkPolicies (enforced by the CNI) do.

You add a default-deny egress policy and suddenly every service says "cannot connect to database". What did you most likely forget?

  1. An ingress rule on the database
  2. A RoleBinding
  3. An egress allow for DNS (port 53 to CoreDNS)
Without DNS the database hostname never resolves, so the error looks like a connection problem.

Which Pod Security Standard level requires non-root, dropping ALL capabilities and seccomp RuntimeDefault?

  1. Restricted
  2. Baseline
  3. Privileged
Baseline blocks known escalations but still allows root. Restricted adds the hardening requirements.

What does kubectl get secret X -o yaml show for the secret's value by default?

  1. An encrypted blob only the pod can read
  2. The value in base64, which anyone can decode
  3. Asterisks
The API returns the base64 form. Encryption at rest protects etcd's disk, but anyone allowed to read the object still sees the decodable value.
