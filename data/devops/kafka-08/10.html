Which Kafka version removed ZooKeeper support completely?

  1. 3.3
  2. 4.0
  3. 3.9
  4. 2.8
3.3 made KRaft production ready, 3.9 is the last release with ZooKeeper (the migration bridge), and 4.0 removed ZooKeeper.

You have 4 controllers. How many can fail while the quorum still works?

  1. 0
  2. 2
  3. 1
  4. 3
A majority of 4 is 3, so only 1 can fail. That is why even numbers add cost but no tolerance.

  3. They watch ZooKeeper znodes

Brokers replicate __cluster_metadata by fetching, the same pull model followers use for partitions.

Why does KRaft refuse to auto-format an empty storage directory?

  1. To save disk space
  2. Because Docker cannot format disks
  3. An empty voter could help elect a leader that lacks committed data
  4. Formatting needs root
Explicit formatting with a known cluster ID prevents silent data loss from blank voters.
