Resources

  • Kafka docs: monitoring doc - the broker and client metrics that matter (under-replicated, offline partitions, active controller, request latency).
  • danielqsj/kafka_exporter repo - the exporter behind every lag panel on this page; lists each metric it produces.
  • linkedin/Burrow repo - lag evaluated as a status over a window, not a raw number.
  • Prometheus overview doc - the pull model, PromQL and alerting in one place.
  • Google SRE book: Monitoring Distributed Systems book - the four golden signals and symptom-based alerting.
  • Principles of Chaos Engineering doc - hypothesis, small blast radius, then production: the method behind the drills.
  • Grafana documentation doc - building and provisioning dashboards like shopstream-lag.json.
  • ShopStream README: failure drills and troubleshooting repo - the drill table and the symptom-to-fix table this page builds on.
