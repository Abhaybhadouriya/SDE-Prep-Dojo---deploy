Remember this

  • A container is a normal Linux process with a fenced-in view (namespaces) and limited resources (cgroups).
  • All containers on a host share one kernel. A VM has its own kernel on a hypervisor.
  • Image = frozen template (like a binary). Container = running instance with a writable layer (like a process).
  • docker run chain: CLI, dockerd, containerd, shim, runc, your process as PID 1.
  • Over the memory limit: OOM kill, exit code 137. Over the CPU limit: throttled, not killed.
  • Containers are fast and dense but less isolated; use gVisor or microVMs for untrusted code.
