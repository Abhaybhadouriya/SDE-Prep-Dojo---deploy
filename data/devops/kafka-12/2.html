Meet the contenders

Here is the cast, each in one line. Do not try to memorise everything; memorise the shape and one superpower per system.

📜

Apache Kafka

Partitioned, replicated log. Pull consumers, replay, huge throughput, big ecosystem (Connect, Streams). You run it, or buy it managed (Amazon MSK, Confluent Cloud).

 🐰

RabbitMQ

Smart broker with exchanges that route messages into queues. Push to consumers, per-message ack, priorities. Also has a log-style "Streams" feature.

 📮

Amazon SQS + SNS

Fully managed queue (SQS) and fan-out (SNS). Nothing to run, pay per request. No replay; Standard queues may deliver duplicates.

 🌟

Apache Pulsar

Log with stateless brokers and separate storage (BookKeeper). Built-in multi-tenancy and geo-replication; both queue and stream styles.

 ☁️

Kinesis, Event Hubs, Pub/Sub

Cloud-managed streams. Kinesis has shards (like partitions); Azure Event Hubs even speaks the Kafka protocol; Google Pub/Sub is managed and auto-scaling.

 ⚡

Redpanda and "diskless" Kafka

Same Kafka API, different engine: Redpanda in C++ with Raft per partition; AutoMQ-style designs keep data on object storage.
