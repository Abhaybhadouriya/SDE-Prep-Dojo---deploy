Quick quiz

What problem is Docker's "standard box" mainly solving?

  1. Programs running too slowly
  2. A program behaving differently on different machines
  3. Computers running out of disk
Shipping the environment with the program means the same image behaves the same on a laptop, in CI and in production.

Which sentence about containers is correct?

  1. Each container boots its own kernel
  2. A container needs a hypervisor
  3. A container is a host process isolated by namespaces and limited by cgroups
All containers on a host share that host's kernel. Namespaces control what a process can see, cgroups control how much it can use.

Kubernetes removed dockershim in v1.24. What happens to images built with Docker?

  1. They still run, because they are standard OCI images
  2. They must be rebuilt with a new tool
  3. They only run on Docker Swarm now
The kubelet now talks to containerd or CRI-O, which run the same OCI images Docker builds.

Where does a Docker image usually live so that servers can download it?

  1. In a Git repository
  2. In a registry such as Docker Hub, GHCR or ECR
  3. Inside the Dockerfile
A registry is an HTTP server that stores image layers and manifests. Servers pull images from it by name and tag or digest.

Why does Docker Desktop on Windows or macOS run a small Linux VM?

  1. To make containers faster
  2. Because Docker is written in Linux-only code
  3. Because Linux containers need a Linux kernel to share
A container shares the host kernel. On Windows and macOS there is no Linux kernel, so Docker Desktop provides one in a lightweight VM (WSL 2 on Windows).
