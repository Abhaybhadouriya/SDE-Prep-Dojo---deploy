What you will be able to do

By the end of this track you should be able to do each of these out loud, without notes. They come straight from the learner wish list for this site.

  1. Explain in 60 seconds why a container is not a VM. Shared kernel, namespaces for "what you can see", cgroups for "how much you can use". (Page 01, deepened in page 08.)
  2. Describe what an image is on disk. Layers as content-addressed tarballs, a config JSON, a manifest, and OverlayFS merging them. (Page 02.)
  3. Write a multi-stage Dockerfile and explain the cache of every line. Why copying requirements.txt before your source code makes rebuilds fast. (Page 03.)
  4. Draw what happens on the host for docker run -p 8080:80 nginx. Pull, unpack, namespaces, veth, bridge, DNAT rule, PID 1. (Pages 01, 05, 08.)
  5. Debug "works on my laptop, fails in the container". localhost inside a container, missing env vars, wrong CPU architecture. (Pages 04, 05.)
  6. Choose volumes vs bind mounts vs tmpfs and explain why containers should be stateless. (Page 06.)
  7. Run a 3-service app (app, database, Kafka) with Compose. Healthchecks and start order included. (Page 07 and the pipeline build page.)
  8. Harden and ship an image like a real company. Non-root, dropped capabilities, scan, sign, deploy by digest. (Page 09.)
