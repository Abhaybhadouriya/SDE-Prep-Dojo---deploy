The track map

There are ten lessons plus this overview. Follow them in order the first time. The map shows the path: from the first idea of a container, through building and running images, to the kernel internals and the interview room. Use Mark as done at the bottom of each page; your progress shows in the top bar and the sidebar.

🧒

Level 1 - Kid

Lunchboxes, shipping boxes and recipes. You will be able to say what a container is to a friend who has never coded.

🌱

Level 2 - Beginner

Real names: image, container, registry, Dockerfile. Your first docker run and docker build.

🔧

Level 3 - Intermediate

Layer caching, networks, volumes, Compose. Why your build is slow and how to fix it.

🚀

Level 4 - Advanced

Namespaces, cgroups, OverlayFS, the runtime chain, security hardening and CI pipelines.

🎯

Level 5 - Interview-ready

Exit code 137, PID 1 problems, "make this 1.2 GB image small", packet-level -p answers.
