Where Docker fits in the big picture

Docker is the first of three tools on this site, and each one builds on the last. Docker packs one program into a box. Kubernetes runs thousands of those boxes across many machines and heals them when they break. Kafka carries messages between the programs running in those boxes. The pipeline project joins all three, and system design shows where they appear in real products.

Myth buster: "Kubernetes dropped Docker, so Docker is dead." Not true. Kubernetes removed dockershim (an adapter inside the kubelet) in v1.24 in May 2022. The kubelet now talks directly to containerd or CRI-O. Images built with Docker are standard OCI images, so they still run on every Kubernetes cluster. Docker remains the most common tool developers use to build and test images on their laptops. Read the official Dockershim FAQ if an interviewer brings it up.
