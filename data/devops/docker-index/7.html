Remember this

  • Docker packs a program and its environment into an image, and runs it as a container.
  • A container is a normal Linux process fenced in by namespaces and limited by cgroups. It is not a VM.
  • Images are stacks of read-only layers; the build cache and small images come from understanding them.
  • Docker builds standard OCI images, so they run on Kubernetes even though Kubernetes no longer uses Docker itself.
  • Study order: idea (01-03), daily use (04-07), internals and production (08-09), interview (10).
