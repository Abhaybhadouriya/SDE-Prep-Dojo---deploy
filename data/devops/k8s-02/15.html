Quick quiz

Which component is the only one that reads and writes etcd?

  1. kube-scheduler
  2. kubelet
  3. kube-apiserver
Everyone else goes through the API server. This keeps etcd safe and gives one place for security checks.

Who actually starts the containers of a pod on a node?

  1. The kubelet, through the container runtime (CRI)
  2. The scheduler
  3. The ReplicaSet controller
The scheduler only writes nodeName. The kubelet on that node sees the pod and asks containerd or CRI-O to create it.

Your kubectl apply returned "created" but the pod is still Pending. Which component has not done its job yet?

  1. etcd
  2. The scheduler (no node assigned yet)
  3. kube-proxy
Pending with no node means it is not scheduled: often not enough free CPU or memory requests, or taints and affinity rules that no node satisfies.

How many etcd member failures can a 4-member cluster survive?

  1. 0
  2. 2
  3. 1
Quorum for 4 is 3, so only 1 can fail. Same tolerance as 3 members, which is why odd sizes are used.

The whole control plane is down for 10 minutes. What happens to a web app with 3 running pods?

  1. All pods stop
  2. Pods keep serving; no scaling, rollouts or rescheduling until it is back
  3. Pods restart every minute
The data plane continues on its last known state, like non-stop forwarding.

Why do the scheduler and controller manager use leader election when you run 3 copies?

  1. So that only one copy acts at a time and decisions are not duplicated
  2. To share CPU between them
  3. Because etcd needs them to vote
Two active schedulers could make conflicting decisions. A Lease object picks one leader; others stand by.

The kubelet can be at most how many minor versions older than the API server?

  1. 0, they must match
  2. 1
  3. 3
The version skew policy allows the kubelet to lag by up to 3 minor versions, never to be newer. Upgrade the control plane first.
