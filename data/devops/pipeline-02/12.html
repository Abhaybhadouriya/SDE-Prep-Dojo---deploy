Low-RAM option, stopping and resetting

docker compose -f compose.single-broker.yml up -d --build
docker compose -f compose.single-broker.yml down -v

The single-broker file runs the same services against one Kafka node (kafka:19092) with replication factor 1, and leaves out Prometheus and Grafana to save memory. Everything on this page works except failover: with one broker there is no second copy, so the broker-failure drill does not apply. Do not run both files at the same time; they publish the same host ports.

docker compose down        # stop and remove containers, keep data volumes
docker compose down -v     # also delete Kafka and Postgres data (a clean slate)

Data lives in named volumes (kafka1-data ... pg-data), so a plain down and up brings back every topic, offset and row. -v deletes the volumes; next start formats fresh storage and re-runs init.sql.
