Step 0: check your laptop

Open a terminal (PowerShell on Windows is fine) in the project folder. Every command on this page runs from pipeline/code.

cd pipeline/code
docker version --format "{{.Server.Version}}"
docker compose version
python --version
$ docker version --format "{{.Server.Version}}"
27.5.1
$ docker compose version
Docker Compose version v2.32.4
$ python --version
Python 3.12.7

Your exact numbers will differ. You need Docker Engine 27 or newer, Compose v2 (the command is docker compose with a space; the old docker-compose with a dash is v1), and Python 3.9 or newer for the load generator.

Give Docker enough memory. The 3-broker stack wants at least 6 GB. In Docker Desktop open Settings, Resources (or on WSL 2, the .wslconfig file) and check the memory limit. Each broker runs a JVM with -Xms512m -Xmx512m, and Postgres, Grafana, Prometheus and five Python services add up. If your laptop is small, use the single-broker file at the end of this page.

Optionally copy the example settings file. Defaults are built into the compose file, so this is only needed if you want to change the demo knobs later:

cp .env.example .env          # PowerShell: Copy-Item .env.example .env

The .env file holds only local, non-secret defaults (image tag, cluster id, a demo Postgres password, and three enricher knobs). Compose reads it automatically and substitutes values such as ${KAFKA_IMAGE:-apache/kafka:4.3.2}: "use KAFKA_IMAGE if set, otherwise this default".
