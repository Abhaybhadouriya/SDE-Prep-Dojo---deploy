Before you start

You need just two things from earlier tracks. Everything else is explained when it first appears.

  1. What a container is. A normal Linux process fenced in with namespaces and cgroups. Read What is a Container? and, if you like kernel details, Docker Internals.
  2. What an image is. A read-only bundle of filesystem layers that you can run anywhere. See Images & Layers.
  3. Basic Linux and networking. You already have this. IP addresses, NAT, iptables, routing and processes will be reused all over this track.
  4. Words you will meet. If a word stops you, open the Glossary. Every term there has a one-line meaning and a "from your world" hint.
