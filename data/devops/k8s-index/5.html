Set up your free lab (10 minutes)

You do not need a cloud account. We use kind ("Kubernetes IN Docker"). It runs each Kubernetes node as a Docker container on your laptop, so a whole cluster starts in about a minute and you can delete it just as fast. You need Docker Desktop (or Docker Engine on Linux) running first.

# PowerShell, with Docker Desktop running
winget install Kubernetes.kind
winget install Kubernetes.kubectl
kind version
kubectl version --client
brew install kind kubectl
kind version
kubectl version --client
# follow https://kind.sigs.k8s.io/docs/user/quick-start/#installation for the latest binary,
# and https://kubernetes.io/docs/tasks/tools/ for kubectl
kind version
kubectl version --client

Now create a small cluster with one control-plane node and two workers. Save this as kind-dojo.yaml:

kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
nodes:
  - role: control-plane
  - role: worker
  - role: worker
kind create cluster --name dojo --config kind-dojo.yaml
kubectl get nodes

You should see something like this (your version numbers and ages will differ):

$ kind create cluster --name dojo --config kind-dojo.yaml
Creating cluster "dojo" ...
 ✓ Ensuring node image (kindest/node:v1.35.0)
 ✓ Preparing nodes
 ✓ Writing configuration
 ✓ Starting control-plane
 ✓ Installing CNI
 ✓ Installing StorageClass
 ✓ Joining worker nodes
Set kubectl context to "kind-dojo"
You can now use your cluster with:

kubectl cluster-info --context kind-dojo

$ kubectl get nodes
NAME                 STATUS   ROLES           AGE   VERSION
dojo-control-plane   Ready    control-plane   62s   v1.35.0
dojo-worker          Ready    <none>          41s   v1.35.0
dojo-worker2         Ready    <none>          41s   v1.35.0

When you are done for the day, delete it with kind delete cluster --name dojo. Nothing is left behind.

No Docker at all? Killercoda playgrounds give you a free Kubernetes cluster in the browser. Other local options are minikube and k3d; they all speak the same Kubernetes API, so every command in this track works on them.

Careful: kind is for learning and CI. It is not how production clusters are built. Real companies use managed services (Amazon EKS, Azure AKS, Google GKE) or tools like kubeadm on their own servers.
