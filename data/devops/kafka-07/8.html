Lab: look inside a real segment

good to know

You can do this with the single-broker setup from the Build It Locally page, or just one container:

docker run -d --name broker -p 9092:9092 apache/kafka:4.4.0

docker exec -it broker /opt/kafka/bin/kafka-topics.sh --bootstrap-server localhost:9092 \
  --create --topic orders --partitions 1 --replication-factor 1

# send three keyed records
docker exec -it broker bash -c 'printf "o1:created\no2:created\no1:paid\n" | \
  /opt/kafka/bin/kafka-console-producer.sh --bootstrap-server localhost:9092 \
  --topic orders --reader-property parse.key=true --reader-property key.separator=:'

# decode the segment file
docker exec -it broker /opt/kafka/bin/kafka-dump-log.sh --print-data-log \
  --files /tmp/kraft-combined-logs/orders-0/00000000000000000000.log

(Output wrapped and trimmed; exact fields vary a little by version.) Read it slowly: one batch (baseOffset 0, lastOffset 2, count 3) holding three records, a producerId and sequence numbers because the idempotent producer is on by default, and magic: 2, the batch format from earlier. Try these next:

  • kafka-dump-log.sh --files .../00000000000000000000.index shows the sparse offset-to-position entries (none yet for a tiny log, because an entry is added only every 4 KiB).
  • kafka-log-dirs.sh --bootstrap-server localhost:9092 --describe --topic-list orders prints the size of each partition on each broker as JSON.
  • kafka-get-offsets.sh --bootstrap-server localhost:9092 --topic orders prints orders:0:3, the log-end offset.
