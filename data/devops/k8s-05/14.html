  • Network model: one IP per pod, pod-to-pod without NAT, implemented by a CNI plugin.
  • CNI ADD: veth pair into the pod netns, IP from IPAM (node's pod CIDR), bridge or routes. Config in /etc/cni/net.d.
  • Cross-node: VXLAN overlay (+50 bytes, UDP 8472 in Flannel), BGP routing (Calico), cloud VPC IPs, or eBPF (Cilium).
  • ClusterIP = virtual IP = DNAT rules on every node by kube-proxy; not on any interface; ping fails; conntrack reverses replies.
  • kube-proxy modes 2026: iptables default, nftables GA and recommended, IPVS deprecated (removal planned ~1.40), eBPF via Cilium.
  • Service types are layered: ClusterIP -> NodePort (30000-32767) -> LoadBalancer. Headless returns pod IPs (StatefulSets, Kafka).
  • CoreDNS names: svc.ns.svc.cluster.local. ndots:5 makes external lookups expensive.
  • Debug top-down: DNS -> endpoints -> ports -> direct pod IP -> NetworkPolicy -> node dataplane.
