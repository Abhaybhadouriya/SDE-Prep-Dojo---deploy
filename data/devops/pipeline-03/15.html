  • Kafka docs: transaction protocol doc - the current (v2, KIP-890) protocol; per-transaction epoch bumps need a client that supports it.
  • Kafka Streams core concepts doc - time, windows, state stores and processing guarantees.
  • Flink: timely stream processing doc - event time and watermarks, with per-partition watermark diagrams.
  • Event streaming patterns catalogue doc - DLQ, outbox, idempotent reader and more, one short page each.
  • ShopStream README repo - the project this page is built on, with the delivery-guarantee table and troubleshooting.
