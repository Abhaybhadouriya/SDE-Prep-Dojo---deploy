Which of these can you NOT run on Fargate?

  1. A Kubernetes DaemonSet
  2. A sidecar container
  3. An ARM64 container
  4. A task with 16 vCPU
Fargate has no nodes for you, so per-node agents (DaemonSets) are not supported; use sidecars instead.

The runtime started an amd64-only binary on an ARM node. Build multi-arch images or pin those pods to amd64.

How much warning does a Spot instance get before reclaim?

EKS pods are Pending with "failed to assign an IP address", yet nodes have free CPU. Best fix?

  1. Enable VPC CNI prefix delegation and/or give pods bigger subnets
  2. Raise CPU requests
  3. Switch to Fargate Spot
