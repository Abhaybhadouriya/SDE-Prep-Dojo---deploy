  • ECS: task definition (pod spec, versioned) -> task (pod) -> service (keeps desiredCount, rolls out, registers in target group).
  • awsvpc: one ENI per task, own IP and security groups; ALB target type ip. Task role = app's AWS creds; execution role = pull image, secrets, logs.
  • Fargate: no nodes, per-task microVM isolation (Firecracker on KVM), billed per vCPU/GB-second; no DaemonSets, privileged mode or GPUs.
  • ECS for simple AWS-only teams; EKS for the Kubernetes ecosystem and portability - decide from team, ecosystem and cost.
  • EKS VPC CNI: pods get real VPC IPs (no overlay); plan big subnets, use prefix delegation.
  • Karpenter: pending pods -> choose instance types -> EC2 Fleet -> node joins; consolidation, drift, expiry; NodePool + EC2NodeClass; set limits and budgets.
  • Spot: diversify types and AZs, interruption queue, SIGTERM handling, PDBs, spread on capacity type; keep state on On-Demand.
  • Graviton: multi-arch images (buildx, image index), check native dependencies, roll out service by service.
