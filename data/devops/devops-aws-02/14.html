Quick quiz

Which statement about security groups is true?

  1. They are attached to subnets and evaluated in rule-number order
  2. They support explicit deny rules
  3. They are stateful: replies to allowed traffic are allowed automatically
  4. They can only reference CIDR blocks
SGs are stateful, allow-only, attached to ENIs, and can reference other SGs. The other options describe NACLs.

A custom NACL allows inbound TCP 443 and outbound TCP 443 only. HTTPS clients cannot load the site. Why?

  1. NACLs do not support TCP
  2. Responses go to the client's ephemeral port (1024-65535), which outbound rules do not allow
  3. The security group overrides the NACL
NACLs are stateless; the reply leaves from port 443 to the client's ephemeral port, which needs its own outbound rule.

Which metric is the best target for a target tracking policy on a web tier behind an ALB?

  1. ALBRequestCountPerTarget
  2. Total ALB RequestCount
  3. Number of HTTP 200 responses
  4. Disk free space
Per-target request count falls as you add instances (inversely proportional), which makes scaling proportional.

Instances created by a new ASG (made with the CLI) are terminated two minutes after launch, again and again. The app needs 4 minutes to start. Most likely cause?

  1. Spot interruptions
  2. The AMI is corrupt
  3. The max size is too small
  4. ELB health checks fail during startup and the health check grace period is 0
The CLI default grace period is 0 s, so instances are judged before they are ready. Raise it or use lifecycle hooks.

To keep serving 100 % of peak with zero launches when any single AZ fails, how much capacity do you need across 3 AZs?

  1. 100 %
  2. 120 %
  3. 150 %
  4. 300 %
Each AZ must hold half of peak so any two together hold 100 %: 3 x 50 % = 150 %.

How much warning does EC2 give before reclaiming a Spot instance (stop/terminate)?

  1. None
  2. Two minutes
  3. Fifteen minutes
  4. One hour
A two-minute interruption notice via EventBridge and instance metadata (spot/instance-action). A rebalance recommendation may arrive even earlier.

A pod on a new Graviton node fails with "exec format error". What is wrong?

  1. The image (or a sidecar image) only has an amd64 build
  2. The node ran out of memory
  3. The security group blocks the registry
The binary's architecture does not match the CPU. Build multi-arch images with buildx.
