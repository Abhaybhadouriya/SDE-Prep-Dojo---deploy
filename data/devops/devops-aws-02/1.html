EC2: virtual machines and how to read an instance type

Must know (SDE-1)

EC2 (Elastic Compute Cloud) rents you virtual machines called instances. Each instance boots from an AMI (Amazon Machine Image: a disk image plus metadata), lives in one subnet of one AZ, gets one or more ENIs with private IPs, and stores data on EBS volumes (network block storage in the same AZ) or on local instance store NVMe that vanishes when the instance stops.

From your world

Modern instances run on the Nitro system: a thin KVM-based hypervisor, with networking, EBS and security offloaded to dedicated Nitro cards - think SmartNIC or DPU. Your instance's network device is an ENA (Elastic Network Adapter), an SR-IOV virtual function, so packets go from your kernel's driver ring buffer to hardware without a software switch in the host. EBS volumes appear as NVMe devices backed by the network. Per-instance limits you will meet - packets per second, tracked connections, bandwidth - are enforced by that card, which is why the ENA driver exposes counters like pps_allowance_exceeded through ethtool -S.
