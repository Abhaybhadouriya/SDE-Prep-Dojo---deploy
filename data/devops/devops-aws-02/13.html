  • Read instance types as family + generation + attributes + size (m7g.large = general, gen 7, Graviton, 2 vCPU).
  • Launch template = versioned recipe; ASG = control loop keeping healthy instances at desired, within min/max.
  • Use ELB health checks plus a sane grace period; the CLI default grace period is 0.
  • Target tracking is the default policy; pick a metric that halves when capacity doubles; add scheduled/predictive for known patterns.
  • Security groups: stateful, per ENI, allow-only, can reference SGs. NACLs: stateless, per subnet, ordered allow/deny, need ephemeral ports.
  • Multi-AZ is per component: LB and ASG shift automatically, RDS Multi-AZ fails over in about 1-2 minutes, EBS never moves. Design for static stability.
  • Spot = up to 90 % off with a 2-minute notice: diversify and keep an On-Demand base. Graviton = cheaper ARM, needs multi-arch images.
