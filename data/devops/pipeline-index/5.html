What your laptop needs

ThingVersion / sizeWhy
Docker Desktop4.30+ (Engine 27+, Compose v2)Runs every service as a container
Memory given to DockerAt least 6 GB for 3 brokers, about 4 GB for the single-broker fileThree Kafka JVMs with 512 MB heap each, plus Postgres, Grafana and five Python services
Python on the host3.9+ (standard library only)Runs the load generator loadgen/loadgen.py
kubectl + kindOnly for page 04A Kubernetes cluster inside Docker

Images used by the project (pinned in the compose file, checked November 2026): apache/kafka:4.3.2, postgres:17-alpine, python:3.12-slim, provectuslabs/kafka-ui:v0.7.2, danielqsj/kafka-exporter:v1.11.0, prom/prometheus:v3.15.1, grafana/grafana:13.2.6. The Python Kafka client is confluent-kafka==2.16.2, which wraps the C library librdkafka.
