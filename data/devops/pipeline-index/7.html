Your questions, and where they are answered

The learner input for this site listed 16 honest questions about pipelines. Here is a short answer to each, with the page that goes deep.

QuestionShort answerDeep dive
What does a pipeline look like from click to dashboard?The big picture above: API, Kafka, processor, sinks, dashboard.01
Where does data enter Kafka: the app, a log shipper, or CDC?In ShopStream the app writes directly. CDC (reading the database's change log) is the other common way.01
What is CDC, the outbox pattern, and the dual-write problem?Writing to a DB and to Kafka are two separate actions; one can fail. ShopStream avoids it by writing only to Kafka first.01
Batch vs streaming: when is a nightly job fine?When nobody needs the answer before tomorrow. Revenue per minute needs streaming.01
What is a stream processor and where is its state?A program that reads events and keeps running results. ShopStream's analytics keeps state in memory (a teaching shortcut).03
Windowing, late events, event vs processing time?Bucket by when the order happened, not when you read it, and wait a little for stragglers.03
Where does the result go?Postgres for the order record, metrics for the dashboard.01
How do I replay after a bug?Reset the consumer group's offsets and read again; the sink is idempotent so it is safe.05
What do I monitor?Consumer lag, under-replicated partitions, DLQ arrivals, error rates.05
How do I test locally? Is one broker enough?One broker is enough to learn the API; three brokers are needed to see failover. Both files are provided.02
What is backpressure here?Kafka absorbs it: a slow reader builds lag. If Kafka itself is slow, the API returns 503 so clients back off.01
How do I avoid duplicates at the sink?INSERT ... ON CONFLICT (order_id) DO UPDATE, and commit the offset after the DB commit.02
How do schema changes roll out?Every event carries schema_version; add fields, never rename. A Schema Registry enforces this in bigger systems.01
How does it run on Kubernetes? Is that a good idea?With the Strimzi operator. It works well if you treat brokers as stateful pods with real disks.04
