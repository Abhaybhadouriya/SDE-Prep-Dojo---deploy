The network drivers, in one picture

When you create a container, you choose which network it joins. A network uses a driver, which decides how packets move. There are six built-in drivers. You will use bridge 90% of the time, but interviews (and your background) make the others worth knowing.

$ docker network ls
NETWORK ID     NAME      DRIVER    SCOPE
4b1d2e3f9a01   bridge    bridge    local
7c8d9e0a1b22   host      host      local
9e0f1a2b3c33   none      null      local

These three networks exist on every Docker host. The one called bridge is the default bridge, backed by the Linux bridge docker0. Any container started without --network lands there.
