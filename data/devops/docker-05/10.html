ThisIs not the same asThe difference
EXPOSE 80-p 8080:80EXPOSE is metadata in the image. -p creates a real DNAT rule and a listening port on the host.
Default bridge networkA user-defined bridgeBoth are Linux bridges, but only a user-defined bridge gives containers the embedded DNS (reach each other by name) and better isolation.
localhost in a containerlocalhost on the hostEach container has its own network namespace, so its 127.0.0.1 is itself, not the host and not other containers.
Docker overlay networkKubernetes CNI overlaySame VXLAN idea on the wire, but a totally different control plane: Swarm's gossip vs a CNI plugin such as Calico, Cilium or Flannel.
--network host-p on a bridgeHost mode has no namespace and no NAT: the app binds the host's ports directly, and -p is ignored.
ufw / INPUT chain rulesDOCKER-USER rulesPublished ports are DNATed and forwarded, so they skip INPUT (where ufw lives). Filtering for containers belongs in DOCKER-USER.
