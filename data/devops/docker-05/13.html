Quick quiz

Two containers are on the default bridge network. Container A runs ping api and gets "bad address". Why?

  1. ICMP is blocked by Docker
  2. The containers are on different subnets
  3. The default bridge has no DNS by container name; use a user-defined network
Name resolution via the embedded DNS (127.0.0.11) is only available on user-defined networks.

Which netfilter step makes -p 8080:80 work for traffic from another machine?

  1. A DNAT rule reached from nat PREROUTING
  2. A MASQUERADE rule in POSTROUTING
  3. An ACCEPT rule in INPUT
DNAT rewrites the destination to the container IP:port before the routing decision. MASQUERADE is for outbound traffic.

A Flask app in a container listens on 127.0.0.1:5000. You run with -p 5000:5000. What happens when you curl it from the host?

  1. It works, Docker forwards to loopback
  2. It fails: forwarded traffic arrives on the container's eth0, not its loopback
  3. It works only with --privileged
The container's loopback is private to its namespace. The app must listen on 0.0.0.0.

Why don't ufw rules block a published container port?

  1. Docker disables ufw
  2. ufw only filters UDP
  3. After DNAT the packet is forwarded (FORWARD chain), never reaching INPUT where ufw filters
Put your rules in DOCKER-USER, bind to 127.0.0.1, or do not publish the port.

What does --network container:web do?

  1. Copies web's iptables rules
  2. Joins web's network namespace: same IP, same ports, shared localhost
  3. Connects to web over a new veth pair
It shares the namespace itself. Kubernetes pods use the same mechanism with a pause container.

Docker overlay networks across hosts encapsulate traffic using...

  1. VXLAN over UDP 4789
  2. GRE over IP protocol 47
  3. MPLS labels
Overlay uses VXLAN on UDP 4789 (Swarm also uses TCP 2377 and TCP/UDP 7946 for control and gossip).

Small HTTP requests from a container work, but large downloads hang on a VPN. Most likely cause?

  1. DNS caching
  2. MTU mismatch: packets larger than the path MTU are dropped
  3. The bridge is out of MAC table space
Classic MTU symptom. Set a smaller MTU on the Docker network or clamp TCP MSS.
