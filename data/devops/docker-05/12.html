Remember this

  • Container network = its own network namespace (think VRF). Its localhost is its own.
  • Default bridge: docker0 Linux bridge (usually 172.17.0.1/16) + one veth pair per container.
  • Inbound -p H:C = DNAT in nat PREROUTING (DOCKER chain) + docker-proxy. Outbound = MASQUERADE.
  • Published ports bind 0.0.0.0 and bypass ufw (FORWARD, not INPUT). Filter in DOCKER-USER or bind 127.0.0.1.
  • User-defined networks give DNS by name via 127.0.0.11; the default bridge does not.
  • host = no namespace, no NAT. none = loopback only. container:x = share a namespace (how pods work).
  • Overlay = VXLAN on UDP 4789, MTU about 1450. macvlan/ipvlan = containers on the real LAN, VLAN sub-interfaces.
  • Debug: ss -ltn, docker network inspect, nsenter -n, tcpdump, conntrack -L.
