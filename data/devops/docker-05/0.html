The story: a hotel with a front desk and room phones

Explain like I'm 5

Imagine a hotel. Every room (a container) has its own phone with a short extension number, like 201 or 202. All the room phones are wired to the hotel's own little phone switchboard (the bridge), so room 201 can ring room 202 directly, for free.

The hotel has only one real outside phone number. When someone in the town calls it and says "extension 8080, please", the front desk looks at its list: "8080 means the pizza chef in room 202, his phone 80", and puts the call through. When a guest calls out to the town, the front desk dials for them from the hotel's main number, so the town never learns the room extensions. That front-desk trick is NAT.

Next to every phone there is a small book of names (DNS): you dial "chef" instead of remembering "extension 172.18.0.3". If the chef moves to another room, the book is updated, and you still dial "chef".

(The "building of flats" picture from page 01 is about walls between containers. This page is about the phones and the front desk.)

That is all of single-host Docker networking: a private network world for each container, a software switch joining them, address translation at the edge, and a name service. You already know every one of these pieces from Linux and routers. Docker just wires them together automatically every time you type docker run.

From your world

A Linux network namespace is a VRF: its own interfaces, routing table, ARP/neighbour table, iptables rules and sockets. Every container gets one. docker0 is a plain Linux bridge (a soft L2 switch, the same kind you create with ip link add type bridge). A veth pair is a virtual patch cable with one end in the container's namespace and one end plugged into the bridge. -p 8080:80 is a DNAT rule; outbound traffic is MASQUERADE (source NAT). It is a home router, in software, on every Docker host. Where the analogy breaks: a VRF on a router still shares one control plane process, while each container's namespace has no routing daemon at all; it just gets one default route to the bridge.
