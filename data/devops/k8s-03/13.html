Remember this

  • Pod = one or more co-located containers sharing a network namespace (one IP, localhost), IPC, UTS and volumes.
  • The pause container holds the pod's namespaces; container restarts keep the pod IP, pod replacement does not.
  • Use Services, never pod IPs. Use Deployments, never bare pods.
  • Init containers run first, in order; native sidecars (init + restartPolicy Always, GA 1.33) start before and stop after the app.
  • Five phases: Pending, Running, Succeeded, Failed, Unknown. CrashLoopBackOff is a container reason, not a phase.
  • Back-off: 10 s doubling to a 5-minute cap. Debug with describe, logs --previous and the exit code (1, 137, 143).
  • Readiness removes from traffic; liveness restarts; startup protects slow boots. Never put dependency checks in liveness.
  • Shutdown: endpoints removal in parallel with preStop, then SIGTERM, then SIGKILL after 30 s by default.
