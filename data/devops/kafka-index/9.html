Quick quiz

In the school notebook story, what is the "bookmark"?

  1. A topic
  2. An offset: each reader's own position in the log
  3. A broker
Each reader keeps its own bookmark (offset), so the cook and the nurse can read the same notebook at different speeds.

A consumer reads a message from a Kafka topic. What happens to the message?

  1. It is deleted immediately
  2. It is moved to an "archive" topic
  3. Nothing: it stays until retention or compaction removes it
Kafka is a log, not a classic queue. Many readers can read the same message, and you can re-read it later.

5 systems produce data and 6 systems need it. How many connections do you build with a Kafka hub?

  1. 11
  2. 30
  3. 6
N + M = 5 + 6 = 11 connections to the hub, instead of up to N x M = 30 point-to-point pipes.

What changed in Kafka 4.0?

  1. It became a paid product
  2. ZooKeeper was removed; clusters run in KRaft mode only
  3. Messages are now deleted after reading
Kafka 4.0 (March 2025) removed ZooKeeper. Metadata now lives in Kafka's own Raft-replicated log, run by controller nodes.

Why is the single-container lab not a production setup?

  1. Docker cannot run Java
  2. It only supports one topic
  3. One node is both broker and controller with no replicas, so losing it loses everything
Production uses at least 3 brokers, replication factor 3 and separate controllers. Page 05 shows why.
