Gotchas

  1. Rebasing a shared branch. Teammates' clones still hold the old hashes; their next pull duplicates commits. Only rebase what only you use.
  2. --force instead of --force-with-lease --force-if-includes. Silently deletes whatever someone else pushed to that branch. A bare --force-with-lease after a fetch (or an IDE auto-fetch) can do the same, because the fetch updated the ref it compares against.
  3. Long-lived feature branches. Two weeks without syncing = one giant conflict. Sync from main daily, ship behind flags.
  4. Continuing on a branch after it was squash-merged. Conflicts against your own work. Delete it and branch fresh.
  5. Trusting a clean merge. No textual conflict does not mean correct code. Run tests on the merged result (that is what merge queues automate).
  6. Mixing reformatting with logic. Huge diffs, hard reviews, endless conflicts. Do formatting in its own PR.
  7. Committing secrets. Removing the file in a new commit does not remove it from history. Rotate the secret first, then clean history if needed.
  8. Mixing up ours and theirs during rebase. They are swapped compared with merge.
