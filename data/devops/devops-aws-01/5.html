NAT gateway: outbound-only internet for private subnets

Must know (SDE-1)

Private app servers still need the internet: to download packages, call Stripe or a payment gateway, pull images from Docker Hub. A NAT gateway lets them start connections outward while nothing outside can start a connection inward. Connections must always be initiated from inside the VPC.

  1. The app opens a TCP connection. Its subnet's route table sends 0.0.0.0/0 to the NAT gateway in the same AZ.
  2. The NAT gateway rewrites the source to its own private IP and a free port, and remembers the mapping.
  3. The IGW maps the NAT gateway's private IP to its Elastic IP. The outside world sees only that one public address.
  4. The reply is translated back twice, using the stored state, and lands on the app server.
  5. A connection started from outside matches no state, so it is dropped. Outbound-only.

Numbers and limits worth knowing (AWS docs)

5 -> 100Gbps: starts at 5, scales automatically to 100
1M -> 10Mpackets per second, then drops
55,000simultaneous connections per IP to one destination (IP, port, protocol)
8IPv4 addresses per zonal NAT gateway (1 primary + 7)
  • A zonal NAT gateway lives in one AZ. If AZ-a holds the only NAT gateway and AZ-a fails, private subnets in AZ-b and AZ-c lose internet too. Production: one NAT gateway per AZ, each private table pointing to the one in its own AZ (this also avoids cross-AZ data charges).
  • Regional NAT gateways (newer mode) expand automatically into every AZ where you have workloads, need no public subnet, and support up to 32 IPs per AZ. One route target serves all AZs. Expansion into a new AZ can take up to 60 minutes; private NAT still needs the zonal kind.
  • Port exhaustion: thousands of pods calling the same API endpoint can hit the 55,000 limit. The CloudWatch metric ErrorPortAllocation goes non-zero. Fix: add secondary IPs to the NAT gateway, or spread the load.
  • No security group can be attached to a NAT gateway; filter with the instances' security groups or the subnet's network ACL (allow ports 1024-65535 for the return traffic).
  • Cost: you pay per hour per NAT gateway and per GB processed (in us-east-1 the list price is USD 0.045 for each at the time of writing; check the VPC pricing page for your region). Pulling container images or S3 data through NAT is the classic surprise bill.

From your world

This is PAT / NAPT, the same thing iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE does on a Linux home router, with conntrack keeping the 5-tuple mapping. The 55,000 limit is the source-port space of one IP towards one fixed (dst IP, dst port, proto) tuple - the same ceiling you hit with a single SNAT address on a carrier-grade NAT box. The two-stage translation (NAT to private IP, then IGW to Elastic IP) is a quirk of how AWS split the jobs.
