What a VPC is: your own network inside a region

Must know (SDE-1)

A VPC (Virtual Private Cloud) is a logically isolated virtual network that you own inside one AWS Region (for example ap-south-1, Mumbai). You choose its IP range, you cut it into subnets, and you decide every route in and out. Nothing reaches your machines unless you build a path for it.

  1. Region - a geographic area (Mumbai, N. Virginia, Frankfurt). A VPC lives in exactly one region.
  2. Availability Zone (AZ) - one or more physically separate data centres inside the region, with their own power and cooling, linked to the other AZs by low-latency fibre. Most regions have 3 or more AZs.
  3. Subnet - a slice of the VPC's IP range that lives in one AZ. A subnet never spans AZs. This is the single most important constraint for high availability.
  4. ENI (Elastic Network Interface) - a virtual NIC. Every EC2 instance, load balancer node, NAT gateway and Lambda-in-VPC gets one or more ENIs, each with a private IP from its subnet.
  5. Route table - attached to a subnet; decides where packets leaving that subnet go.
  6. Gateways - Internet Gateway (IGW), NAT gateway, VPC endpoints, peering, Transit Gateway: the only doors out of the VPC.

From your world

A VPC is a VRF with a fixed address space: an isolated routing domain whose tables you own. Every subnet is a connected network on an invisible distributed router, and the router's interface address is always the subnet base + 1 (for example 10.0.0.1). There is no layer 2 you can touch: no ARP spoofing, no broadcast, no multicast by default, no VLAN tags. The hypervisor (the AWS Nitro card) delivers each frame straight to the right ENI, a bit like a perfectly programmed SDN fabric. Think "pure L3 with a mapping service", not "a switch".

Every account comes with a default VPC in each region: 172.31.0.0/16 with one public /20 subnet per AZ. It is great for a quick test and wrong for production, because every subnet in it is public. Real teams create their own VPCs, almost always with Terraform or CloudFormation, so the network is reviewed like code.
