Remember this

  • A VPC is your isolated network in one region; a subnet lives in exactly one AZ.
  • VPC and subnet blocks are /16 to /28; 5 addresses per subnet are reserved; plan non-overlapping, hierarchical CIDRs from day one.
  • "Public" = the subnet's route table has 0.0.0.0/0 -> IGW. Private = default route to a NAT gateway. Isolated = no default route.
  • The IGW does 1:1 NAT for public IPv4 addresses; the NAT gateway does many-to-one SNAT for outbound-only access.
  • One NAT gateway per AZ (or a regional NAT gateway); watch the 55,000-connections-per-destination limit and the per-GB cost.
  • Gateway endpoints (S3, DynamoDB) are free routes; interface endpoints are ENIs with private IPs.
  • On EKS, pods take real VPC IPs: size private subnets big or use 100.64.0.0/10 / IPv6.
