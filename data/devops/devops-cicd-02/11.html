Remember this

  • Maven phases are cumulative: validate, compile, test, package, verify, install (local), deploy (remote).
  • pom.xml = GAV coordinates + pinned dependencies + plugins; -SNAPSHOT means mutable, releases never change.
  • Jenkins = controller schedules, agents build, Jenkinsfile in git; GitHub Actions = events, jobs on runners, steps, matrix, cache, secrets.
  • Nexus/Artifactory: hosted (yours), proxy (cached public), group (one URL). Release repos forbid redeploy.
  • Cache inputs (dependencies) keyed on the manifest hash; rebuild outputs.
  • Build once, promote the same immutable version everywhere; config is injected; rollback is a pointer change.
