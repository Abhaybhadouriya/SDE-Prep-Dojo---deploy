Quick quiz

You run mvn package. Which phases run?

  1. Only package
  2. package, verify, install
  3. validate, compile, test, package (and the minor phases between)
  4. compile and package only
Requesting a phase runs every earlier phase of the default lifecycle in order, then that phase.

What is the difference between mvn install and mvn deploy?

  1. None, they are aliases
  2. install copies the artifact to the local ~/.m2; deploy uploads it to the remote repository
  3. install uploads to Nexus; deploy starts the app
install is local to the machine; deploy (after install) copies to the shared remote repository from distributionManagement.

A second mvn deploy of version 1.4.2 fails with "Repository does not allow updating assets". What is going on?

  1. The release repository forbids redeploy, enforcing immutability - bump the version
  2. Nexus is down
  3. The credentials expired
Release repositories are set to disable redeploy so a version can be written only once.

In GitHub Actions, which cache key is best for Maven dependencies?

  1. m2
  2. m2-${{ github.sha }}
  3. m2-${{ runner.os }}-${{ hashFiles('**/pom.xml') }}
A constant key never refreshes; a per-commit key never hits. The manifest hash changes exactly when dependencies change.

A matrix with os: [ubuntu, windows] and java: [21, 25] creates how many jobs?

  1. 2
  2. 4
  3. 1
  4. 8
One job per combination: 2 x 2 = 4, each on its own runner.

Which practice breaks "build once, promote many"?

  1. Deploying images by digest
  2. Injecting the DB URL via environment variables
  3. Disabling redeploy on the release repo
  4. Rebuilding from the release tag in the production deploy job
A rebuild creates a new, untested artifact that may differ from what staging validated.

In a Nexus setup, what does a proxy repository do?

  1. Caches artifacts from a remote repository like Maven Central
  2. Stores your team's release jars
  3. Merges several repositories under one URL
Hosted stores yours, proxy caches remote, group merges.
