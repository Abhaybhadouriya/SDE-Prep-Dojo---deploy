Quick quiz

You change a ConfigMap used through envFrom. When does the running container see it?

  1. Within a minute
  2. Only after the container restarts
  3. Instantly
Environment variables are copied into the process when the container starts and never change after that.

Which mount never receives ConfigMap updates?

  1. A whole-volume mount
  2. A mount with items
  3. A mount using subPath
subPath mounts are a one-time bind of a single file, so later updates are not reflected.

What does echo UzNjcjN0IQ== | base64 -d show about Secrets?

  1. That stored Secret values are only encoded, so anyone with read access can decode them
  2. That Secrets are encrypted with AES
  3. Nothing; it fails
Base64 is a reversible encoding with no key. Protection must come from RBAC and encryption at rest.

In KMS v2 envelope encryption, what does the external KMS hold?

  1. Every Secret value
  2. The etcd database
  3. The kubelet certificates
  4. The key-encryption key that wraps the data keys
The API server encrypts objects with data keys; the KMS only wraps and unwraps those keys, and the master key never leaves it.

A pod shows CreateContainerConfigError. Most likely cause?

  1. The image tag is wrong
  2. A referenced ConfigMap or Secret key is missing
  3. The node is out of memory
A wrong image gives ImagePullBackOff; out of memory gives OOMKilled or eviction.

What is the best way for a pod to read from S3 or Azure Key Vault?

  1. Access keys in a Secret
  2. Keys baked into the image
  3. Workload identity with short-lived federated credentials
No static credentials to leak or rotate, and access is scoped per workload.
