Common mistakes and gotchas

Good to know (SDE-2)
MistakeWhat happensFix
Thinking base64 is encryptionSecrets readable by anyone with API or etcd accessRBAC, encryption at rest (KMS v2), external store
Committing Secret YAML to gitCredentials in history foreverSealed Secrets/SOPS, or ESO; rotate anything leaked
Expecting env vars to updateOld value until restartRolling restart or mount as files
Using subPath for a config fileFile never updatesMount the whole volume in a directory
Editing a shared ConfigMap in placeAll pods pick up the change at different times, no rollbackVersioned names or checksum annotation, then roll
Secret and pod in different namespacesPod cannot reference itSecrets are namespaced; copy or sync it
Logging the environment at startupPasswords in log storageNever print env; prefer files
Trailing newline in a --from-file secret"Wrong password" though it looks rightCreate files with printf, not echo
