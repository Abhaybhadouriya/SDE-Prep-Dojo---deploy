Remember this

  • An image = index, manifest, config JSON and layer tarballs, all named by SHA-256 digest (OCI standard).
  • Only RUN, COPY and ADD make filesystem layers (plus a tiny one from WORKDIR if it creates the directory); other instructions change config only.
  • Layers are shared and cached: pulled once, stored once, cached between builds.
  • OverlayFS: lowerdir (image, read-only) + upperdir (container, writable) = merged root. First write copies up the whole file; delete adds a whiteout.
  • Layers only add: deleting later never shrinks the image or removes a secret.
  • Tag = movable pointer; digest = immutable. Deploy immutable references, never latest.
