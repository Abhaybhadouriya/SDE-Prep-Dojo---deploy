Resources

  • Docker docs: OverlayFS storage driver doc - lowerdir, upperdir, copy-up and whiteouts in detail.
  • Linux kernel docs: Overlay Filesystem doc - the kernel's own description, for when you want the real semantics.
  • OCI Image Spec doc - the standard behind index, manifest, config and layers.
  • Fly.io: Docker without Docker blog - walks the registry protocol and shows an image is just tarballs plus JSON.
  • wagoodman/dive repo - explore each layer of an image and find wasted space.
