ThisIs not the same asThe difference
Tag (nginx:1.30)Digest (nginx@sha256:...)A tag is a movable name label; the owner can point it at new bytes tomorrow. A digest is the SHA-256 fingerprint of the manifest, so it can never point at anything else.
Digest (repo digest)Image IDThe repo digest is the hash of the manifest stored in the registry, and is the same on every machine. The image ID is what docker images shows in the IMAGE ID column. With the classic overlay2 store it is the sha256 of the image's config JSON. With the containerd image store (the default on fresh Engine 29 installs) it is a manifest or index digest. Either way it is a local identifier; deploy by the repo digest.
ImageLayerA layer is one tar of file changes. An image is an ordered list of layers plus a config (command, env, user), tied together by a manifest.
ManifestImage index (manifest list)A manifest describes one image for one CPU and OS. An index is a list of manifests, one per platform, behind one tag.
latest"the newest version"It is only the default tag name used when you do not type one. Nobody guarantees it is new, or that it is the same tomorrow.
Image layersContainer layerImage layers are read-only and shared by every container. The container layer is the thin writable sheet on top, one per container, deleted with docker rm.
