Remember this

  • A module is a folder with inputs, resources and outputs. Root module calls child modules; outputs feed inputs.
  • Pin module versions: version for registry sources, ?ref= tag for Git. The lock file pins providers, not modules.
  • Workspaces split state but share backend and credentials: good for short-lived copies, weak for prod. Use a folder (and ideally an account) per long-lived environment.
  • Split state by layer (network, data, cluster, apps) to cut plan time, lock contention and blast radius.
  • Drift = reality changed outside Terraform. Detect with scheduled plan -detailed-exitcode (exit 2), inspect with plan -refresh-only, then revert or codify.
  • Plan on PR, review (human + policy), apply the saved plan on merge, from CI only.
  • prevent_destroy + provider deletion protection on stateful resources; moved for renames; -target only in emergencies.
