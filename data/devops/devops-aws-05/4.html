Pattern 2: S3 events for log files (VPC Flow Logs, ALB logs)

Good to know (SDE-2)

Many AWS logs land as files in S3, not as streams: VPC Flow Logs, ALB and CloudFront access logs, CloudTrail. An S3 event notification (event type s3:ObjectCreated:*) invokes Lambda asynchronously with the bucket and key. The function downloads the object, streams through it line by line, and writes results somewhere else.

  • Delivery is at least once and usually within seconds, but sometimes a minute or more. So the handler must be idempotent: processing the same file twice must not double-count.
  • Use a prefix filter (for example raw/) and write output to a different bucket or prefix. If the function writes back into the prefix that triggers it, it triggers itself in a loop. Lambda has recursive-loop detection for some services, but do not depend on it.
  • A big file can be gigabytes. Stream it (get_object()["Body"].iter_lines()) instead of loading it all into memory, and watch the timeout.
import gzip, boto3, urllib.parse
s3 = boto3.client("s3")

# VPC Flow Log default format (version 2):
# version account-id interface-id srcaddr dstaddr srcport dstport protocol packets bytes start end action log-status
def handler(event, context):
    rejects = {}
    for rec in event["Records"]:
        bucket = rec["s3"]["bucket"]["name"]
        key = urllib.parse.unquote_plus(rec["s3"]["object"]["key"])
        body = s3.get_object(Bucket=bucket, Key=key)["Body"]
        for line in gzip.GzipFile(fileobj=body):
            f = line.decode().split()
            if len(f) >= 14 and f[12] == "REJECT":
                rejects[(f[4], f[6])] = rejects.get((f[4], f[6]), 0) + 1   # (dstaddr, dstport)
    top = sorted(rejects.items(), key=lambda kv: -kv[1])[:10]
    print({"rejected_flows_top10": top})

From your world

VPC Flow Logs are AWS's NetFlow / IPFIX: one record per flow per capture window, with the 5-tuple, packets, bytes and an ACCEPT or REJECT verdict from security groups and network ACLs. Counting REJECTs by destination port is the same thing you would do on a collector to find a port scan or a misconfigured ACL. The interface-id is an ENI, which is AWS's name for a virtual NIC.

This is a real building block of the log aggregation design: small, event-driven functions do the "parse and enrich" step at the edge of the pipeline, while the heavy indexing lives in a search cluster.
