CMDENTRYPOINTENTRYPOINT is the program; CMD is its default arguments (or the default command if there is no ENTRYPOINT). Anything after the image name in docker run replaces CMD; only --entrypoint replaces ENTRYPOINT.
ARGENVARG exists only while building (set with --build-arg). ENV is baked into the image and seen by the running container. Neither is safe for secrets.
COPYADDBoth copy files into a layer. ADD also unpacks local tar files and can download URLs, which surprises people. Use COPY unless you need those extras.
EXPOSE 8000-p 8080:8000EXPOSE is documentation in the image config. -p on docker run actually publishes the port (a NAT rule on the host).
Build cacheImage layersImage layers are what you ship and push. The build cache is the builder's local store of step results (including cache mounts) used to skip work; it is never pushed unless you export it with --cache-to.
docker build --no-cachedocker build --pull--no-cache reruns every step. --pull re-downloads the base image to get its newest version, but still reuses cached steps where inputs did not change. Use both to be sure you get fresh packages.
Shell formExec formShell form (CMD python app.py) runs under /bin/sh -c. Exec form (CMD ["python","app.py"]) runs the program directly as PID 1.
