Quick quiz

You edit only app.py. In which Dockerfile does pip install stay cached?

  1. COPY . . then RUN pip install
  2. COPY requirements.txt ., RUN pip install, then COPY . .
  3. Neither; pip always reruns
In the second order, the COPY of requirements.txt still matches, so the install step is a cache hit. Only the final COPY reruns.

What does EXPOSE 8080 do?

  1. Opens port 8080 in the host firewall
  2. Publishes 8080 to the internet
  3. Documents the port; publishing needs -p
EXPOSE is metadata only. -p 8080:8080 at run time creates the actual port mapping (and -P publishes all EXPOSEd ports to random host ports).

With CMD npm start (shell form), what is PID 1 in the container?

  1. /bin/sh
  2. node
  3. dockerd
Shell form wraps the command in /bin/sh -c, so the shell is PID 1 and typically does not forward SIGTERM to the app.

docker stop always takes 10 seconds and the exit code is 137. What is the most likely cause?

  1. The image is too big
  2. PID 1 ignores SIGTERM, so Docker SIGKILLs after the 10 s timeout
  3. The network is slow
10 s is the default stop timeout; 137 = 128 + 9 (SIGKILL). Fix with exec form, a SIGTERM handler or --init.

What is the safe way to use an npm token during a build?

  1. ARG NPM_TOKEN
  2. COPY .npmrc then RUN rm .npmrc
  3. RUN --mount=type=secret,id=npmrc,...
Secret mounts exist only during that RUN and never reach a layer. ARG is visible in history; COPY-then-delete leaves the file in the earlier layer.

What does COPY --from=build /out/server /server do?

  1. Copies a file from an earlier stage named build into this stage
  2. Downloads a file from a server called build
  3. Copies from the host's /out folder
In a multi-stage build, --from copies artifacts from another stage (or another image), leaving that stage's tools behind.

Why can Alpine make a Python image build slower?

  1. Alpine has no internet access
  2. It uses musl libc, so many prebuilt glibc wheels do not apply and packages compile from source
  3. Alpine is bigger than Debian
Standard "manylinux" wheels target glibc. On musl, pip may need to compile, which needs build tools and time.

Your image built on an M-series Mac fails on an x86 server with exec format error. Best long-term fix?

  1. Use a bigger server
  2. Switch to Alpine
  3. Build multi-platform images in CI with docker buildx build --platform linux/amd64,linux/arm64
The binary is ARM code. A multi-platform image index gives each server the right architecture under one tag.
