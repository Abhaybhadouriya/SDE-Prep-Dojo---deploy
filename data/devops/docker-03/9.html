Common mistakes and gotchas

  1. COPY . . before installing dependencies. Every code change reinstalls everything. Copy the lock file first.
  2. Shell-form CMD. docker stop takes 10 seconds and the app is killed mid-request. Use exec form, handle SIGTERM, or --init.
  3. Secrets in ARG, ENV or a COPY that is deleted later. All readable from the image forever. Use --mount=type=secret.
  4. apt-get update alone on its own line. Stale cached package lists. Combine update, install and cleanup in one RUN.
  5. Running as root. Add a USER with a numeric UID in the final stage.
  6. Unpinned bases (FROM python). Today's build differs from yesterday's. Pin python:3.12-slim, and in strict pipelines pin by digest with an automated updater.
  7. Thinking EXPOSE opens a port. It is documentation. Publishing happens with -p at run time.
  8. Using RUN cd /dir. Each RUN is a new shell, so the cd is forgotten. Use WORKDIR.
