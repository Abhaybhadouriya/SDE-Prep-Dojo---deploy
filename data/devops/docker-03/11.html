Remember this

  • Cache rule: a step is reused only if its parent was reused, its text is identical, and (for COPY/ADD) its files are identical. One miss rebuilds everything below.
  • Order steps from rarely to often changing: copy the lock file, install, then copy the source.
  • ENTRYPOINT = the program, CMD = default args. Use exec form so the app is PID 1 and gets SIGTERM.
  • docker stop = SIGTERM, wait 10 s, SIGKILL (exit 137). PID 1 ignores signals it has no handler for: handle SIGTERM or use --init.
  • Multi-stage: build fat, ship thin. Final stage on slim/distroless, non-root numeric USER.
  • Secrets: RUN --mount=type=secret, never ARG, ENV or COPY-then-delete. Use a .dockerignore.
