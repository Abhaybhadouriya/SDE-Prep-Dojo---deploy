Every instruction you will actually use

InstructionWhat it doesNew layer?Tip
FROM image AS nameStart a stage from a base imageBase layersPin a version (python:3.12-slim), never a bare name
WORKDIR /appSet (and create) the working folderTinyUse it instead of RUN cd, which does not persist
COPY src dstCopy files from the context or another stageYes--chown, --chmod, --from=stage, --link
ADD src dstLike COPY, plus auto-extracts local tar files and can fetch URLsYesPrefer COPY; surprise extraction bites. For URLs use ADD --checksum=sha256:...
RUN cmdRun a command at build timeYesChain related commands and clean up in the same RUN
ENV K=VSet an environment variable for later steps and at run timeNo (config)Never put secrets here; docker inspect shows them
ARG K=VA variable that exists only during the buildNoVisible in docker history: no secrets. An ARG before FROM only works in FROM lines
USER 10001Run later steps and the container as this userNoUse a numeric UID so Kubernetes runAsNonRoot can verify it
EXPOSE 8000Document the portNoPublishes nothing; -p does that
CMD [...]Default command or default argumentsNoReplaced by anything after the image name in docker run
ENTRYPOINT [...]The fixed program the container runsNoReplaced only with --entrypoint
HEALTHCHECK CMD ...A command Docker runs to test if the app is healthyNoDefaults: every 30 s, 30 s timeout, 3 retries
LABEL k=vMetadata such as source repo or ownerNoStandard keys: org.opencontainers.image.source
STOPSIGNAL SIGINTSignal docker stop sends instead of SIGTERMNoFor apps that shut down cleanly on a different signal
