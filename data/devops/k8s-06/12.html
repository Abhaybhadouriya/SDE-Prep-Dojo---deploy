Quick quiz

You create an Ingress but its ADDRESS stays empty forever. Most likely cause?

  1. The Service has too many pods
  2. No Ingress controller is installed (or the class does not match)
  3. DNS is down
The Ingress object is just data. A controller must watch it and configure a proxy.

In the Gateway API, which object does an application team normally own?

  1. GatewayClass
  2. Gateway
  3. HTTPRoute
Routes belong to app teams; the Gateway (listeners, certificates) belongs to the platform team.

What was retired in March 2026?

  1. The community Ingress NGINX controller project
  2. The Ingress API
  3. The Gateway API
The Ingress API remains (frozen). Only that controller project stopped receiving releases and security fixes.

How do you send 10% of traffic to a new version with an HTTPRoute?

  1. Add an annotation canary: 10
  2. Two backendRefs with weights 90 and 10
  3. Scale the new Deployment to 10 replicas
Weighted backendRefs are part of the standard spec and portable across implementations.

An HTTPRoute references a Service in another namespace and shows RefNotPermitted. Fix?

  1. Restart the gateway
  2. Make the Service a LoadBalancer
  3. Create a ReferenceGrant in the Service's namespace
The target namespace must explicitly allow the reference - a safety feature.

Which TLS mode lets the gateway route on URL paths?

  1. Terminate
  2. Passthrough
  3. Neither
With passthrough the gateway never decrypts, so it can only see the SNI host name, not paths.
