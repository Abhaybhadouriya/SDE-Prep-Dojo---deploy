The story: the hotel receptionist

Explain like I'm 5

A big hotel has one front door, and a receptionist stands there. Every visitor shows a slip: "I am here for the swimming pool" or "I am here for room 204". The receptionist reads the slip and points the way. The hotel does not need a separate front door for every room.

The receptionist also checks your badge at the door (so the rooms do not have to), and if the pool is crowded, can send 9 visitors to the big pool and 1 visitor to the new pool to see if they like it.

In Kubernetes, the rooms are your Services (from the previous page). The front door with a receptionist is an L7 proxy (a program that reads HTTP requests, such as Envoy, NGINX, HAProxy or Traefik). The rules on the receptionist's clipboard are written as Kubernetes objects: the older Ingress object, or the newer Gateway API objects. The "badge check" is TLS (HTTPS) termination, and the "9 to 1" split is a canary release.

New words: L4 means the network layer that sees IPs and TCP/UDP ports only. L7 means the application layer that can read HTTP: the host name, the path (/cart), headers and cookies. A reverse proxy is a server that accepts client connections and opens its own connection to the backend on the client's behalf.
