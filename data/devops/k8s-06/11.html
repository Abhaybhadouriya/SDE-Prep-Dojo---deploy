Remember this

  • LoadBalancer Service = one L4 LB per Service. Ingress/Gateway = one L7 proxy for many Services.
  • An Ingress object does nothing without an Ingress controller; ingressClassName picks it.
  • Ingress API: stable but frozen. Community Ingress NGINX controller: retired March 2026.
  • Gateway API roles: GatewayClass (infra) -> Gateway (platform: listeners, TLS) -> Routes (apps). ReferenceGrant for cross-namespace.
  • HTTPRoute does path/header matching, redirects and weighted canaries in the spec, not annotations.
  • A controller watches the objects and pushes config to the proxies (xDS for Envoy); proxies usually send to pod IPs directly.
  • TLS: terminate (common), passthrough (TLSRoute), or re-encrypt (BackendTLSPolicy); cert-manager renews certificates.
