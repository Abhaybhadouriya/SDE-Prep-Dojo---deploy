Storage lifecycle tiers

Good to know (SDE-2)

Data gets colder with age. Logs from yesterday are read often; logs from last year almost never. S3 has storage classes priced by how often you read them: Standard, Standard-IA (infrequent access), One Zone-IA, Glacier Instant Retrieval, Glacier Flexible Retrieval and Glacier Deep Archive, plus Intelligent-Tiering, which moves objects between tiers by itself when access patterns are unknown. Colder classes cost less to store but more to read, and they have minimum storage durations.

{
  "Rules": [
    {
      "ID": "logs-age-out",
      "Filter": { "Prefix": "logs/" },
      "Status": "Enabled",
      "Transitions": [
        { "Days": 30,  "StorageClass": "STANDARD_IA" },
        { "Days": 90,  "StorageClass": "GLACIER_IR" },
        { "Days": 180, "StorageClass": "DEEP_ARCHIVE" }
      ],
      "Expiration": { "Days": 730 },
      "NoncurrentVersionExpiration": { "NoncurrentDays": 30 },
      "AbortIncompleteMultipartUpload": { "DaysAfterInitiation": 7 }
    }
  ]
}
$ aws s3api put-bucket-lifecycle-configuration --bucket acme-app-logs \
    --lifecycle-configuration file://lifecycle.json
$ aws s3api get-bucket-lifecycle-configuration --bucket acme-app-logs --query 'Rules[].ID'
[
    "logs-age-out"
]

Two lines in that rule are pure waste removal: NoncurrentVersionExpiration deletes old versions in a versioned bucket (otherwise every overwrite keeps a full copy forever), and AbortIncompleteMultipartUpload cleans parts of uploads that never finished, which are invisible in a normal listing but still billed.

Block storage and logs: move gp2 EBS volumes to gp3 (IOPS and throughput set separately, generally cheaper per GB), put snapshots under a retention policy (Data Lifecycle Manager or AWS Backup), and set CloudWatch Logs retention, whose default is "never expire".

The minimum-duration trap. Moving data to Glacier and deleting it a week later still bills the full 90 or 180 days. Lifecycle rules for short-lived data (build artifacts, temp exports) should expire them in Standard, not archive them.
