Key takeaways

Remember this

  • Brokers never check content. Schemas are the contract; Schema Registry stores, versions and enforces them.
  • Wire format: byte 0 = magic 0, bytes 1-4 = schema ID (big-endian), then the payload. Never the whole schema.
  • Default subject = <topic>-value / <topic>-key (TopicNameStrategy). Registry data lives in the _schemas topic.
  • BACKWARD (default): new reads old, upgrade consumers first. FORWARD: old reads new, upgrade producers first. FULL: both. TRANSITIVE: against all versions.
  • Avro: add/remove fields only with defaults; matched by name; aliases for renames. Protobuf: never reuse tags; use reserved.
  • Register in CI, auto.register.schemas=false in apps; breaking change = new topic + migration.
