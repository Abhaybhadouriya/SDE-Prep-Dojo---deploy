Lifecycle: binding, release and protection

Good to know (SDE-2)

A PV moves through a small state machine. Knowing it explains most "why is my disk still there?" questions.

  • Storage object in use protection. If you delete a PVC that a running pod still uses, it does not vanish. It gets stuck in Terminating because of the finalizer kubernetes.io/pvc-protection, and is removed only when no pod uses it. PVs have kubernetes.io/pv-protection too. This is a safety feature, not a bug.
  • Expansion. Edit the PVC's request (for example 20Gi to 50Gi). The external-resizer sidecar calls ControllerExpandVolume, then the kubelet grows the filesystem (NodeExpandVolume). Watch kubectl describe pvc for FileSystemResizeSuccessful.
  • Snapshots. VolumeSnapshot (namespaced, like a PVC), VolumeSnapshotContent (cluster-scoped, like a PV) and VolumeSnapshotClass (like a StorageClass) - the same three-object pattern again. They need the snapshot CRDs and snapshot controller installed, plus a driver that supports snapshots. You restore by creating a new PVC with dataSource pointing at the snapshot. VolumeGroupSnapshot (several volumes at one consistent instant, useful for an app with data and log disks) became stable in v1.36.
apiVersion: snapshot.storage.k8s.io/v1
kind: VolumeSnapshot
metadata:
  name: pg-before-migration
spec:
  volumeSnapshotClassName: ebs-snapclass
  source:
    persistentVolumeClaimName: data-postgres-0
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: pg-restore-test
spec:
  storageClassName: fast-ssd
  accessModes: ["ReadWriteOnce"]
  resources: { requests: { storage: 20Gi } }
  dataSource:
    apiGroup: snapshot.storage.k8s.io
    kind: VolumeSnapshot
    name: pg-before-migration

Careful: a disk snapshot is crash-consistent - like pulling the power cord. Databases usually recover from that, but for a clean backup, flush or freeze the app first, or use the database's own backup tool (pg_basebackup, WAL archiving). Snapshots are not a replacement for application-level backups stored in another region.
