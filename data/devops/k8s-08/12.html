Quick quiz

A container writes a file to /tmp (no volume mounted), then crashes and is restarted by the kubelet. Is the file there?

  1. Yes, the pod is the same
  2. No, the new container gets a fresh writable layer
  3. Only if the image has a VOLUME line
A restart creates a new container from the image. Use an emptyDir to survive container restarts, or a PVC to survive pod deletion.

Which of these objects is namespaced?

  1. PersistentVolume
  2. StorageClass
  3. PersistentVolumeClaim
  4. VolumeAttachment
Only the request (PVC) belongs to a namespace. The real disk (PV), the recipe (StorageClass) and the attachment are cluster-wide.

Your new PVC shows Pending and its event says "waiting for first consumer". What is wrong?

  1. Nothing - it binds once a pod uses it
  2. The CSI driver is broken
  3. The disk is full
With volumeBindingMode WaitForFirstConsumer, provisioning waits for the scheduler to choose a node so the disk lands in the right zone.

Two pods on the same node mount one ReadWriteOnce PVC. What happens?

  1. The second pod is refused
  2. Both can mount it, because RWO is per node
  3. The volume is converted to RWX
RWO limits nodes, not pods. ReadWriteOncePod is the mode that limits it to a single pod.

Which component calls the CSI NodePublishVolume to bind-mount the disk into the pod's directory?

  1. kube-scheduler
  2. external-provisioner
  3. kube-controller-manager
  4. kubelet on that node
The node side of CSI is driven by the kubelet talking gRPC to the node plugin over a Unix socket.

A single-replica Deployment with an RWO PVC shows "Multi-Attach error" during every rollout. Best fix?

  1. Use ReadWriteMany on EBS
  2. Increase maxSurge
  3. Use strategy: Recreate (or a StatefulSet)
  4. Delete the PV
RollingUpdate starts the new pod before stopping the old one; if it lands on another node the disk is still attached elsewhere. Recreate stops the old pod first.

You delete a PVC whose StorageClass has reclaimPolicy: Retain. What happens to the PV?

  1. It becomes Released and the real disk is kept
  2. It is deleted along with the disk
  3. It is immediately bound to the next PVC
Retain keeps the disk and its data. A Released PV is not reused automatically because it still holds the old data; an admin decides.
