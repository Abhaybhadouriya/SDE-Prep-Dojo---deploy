Remember this

  • States: created → running ↔ paused → exited → removed. run = create + start.
  • A container lives exactly as long as its main process (PID 1 inside it).
  • Chain: CLI → dockerd → containerd → shim → runc → your process. The shim lets the daemon restart without killing containers.
  • Debug order: ps -a → logs → inspect → exec → stats / events.
  • stop = SIGTERM, wait 10 s, SIGKILL. kill = SIGKILL now. 137 = 128+9, 143 = 128+15.
  • PID 1 gets no default signal actions and must reap zombies: exec form + handler, or --init.
  • Memory limit = OOM kill. CPU limit = throttling. Both are cgroup files.
  • Rotate logs and prune regularly; removing a container keeps its image and named volumes.
