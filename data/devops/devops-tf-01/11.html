Remember this

  • Terraform is declarative: you write the end state in HCL, it computes create / update / delete actions. Re-running is a no-op.
  • Blocks: terraform, provider, resource (owned), data (read-only), variable, locals, output. Address = type.name.
  • init downloads providers and sets up the backend; plan refreshes and diffs; apply walks the graph and writes state.
  • Dependencies are inferred from references. depends_on is a last resort for hidden, behavioural dependencies.
  • The graph is a DAG, walked with up to 10 parallel operations; destroy runs in reverse.
  • Providers are gRPC plugins; pin them with ~> and commit .terraform.lock.hcl. Multi-cloud = one workflow, not portable resources.
  • Read every -/+. Prefer for_each over count for changing collections.
