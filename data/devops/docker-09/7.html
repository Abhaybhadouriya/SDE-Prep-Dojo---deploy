Common mistakes and gotchas

  1. "Our ufw blocks it." Not for published ports. Use DOCKER-USER or bind to 127.0.0.1.
  2. Secrets in ENV. Visible in docker inspect, inherited by every child process, often dumped in crash reports. Mount them as files.
  3. Deleting a secret in a later layer. Still in the earlier layer forever. Rotate the secret if it ever got in.
  4. Unrotated json-file logs. The default log driver has no size cap. One chatty container fills the disk and takes down every other container on the host.
  5. Scanning only at build time. New CVEs are published daily for images you built last month. Rescan what is running, and rebuild regularly on patched bases.
  6. Re-tagging and redeploying :latest. Two nodes can pull two different images under the same tag. Deploy by digest.
  7. Distroless with no plan for debugging. No shell means docker exec sh fails. Use docker debug, a debug sidecar (a helper container running next to the app and joining its namespaces) sharing namespaces (--pid=container:x --network=container:x), or kubectl debug in Kubernetes.
  8. Alpine everywhere. Alpine uses musl libc. DNS behaviour and prebuilt Python wheels differ; Python builds can get slower. Debian slim or distroless is often the better default.
  9. Docker Desktop licensing. Docker Desktop is free for personal use, education, open source and small businesses (under 250 employees and under USD 10 million revenue); larger companies need a paid plan. Docker Engine on Linux is Apache 2.0.
