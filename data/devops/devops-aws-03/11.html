  • S3 = flat key-value store; prefixes fake folders; PUT replaces the whole object; strongly consistent since 2020.
  • Private by default. Block Public Access on. Explicit deny > allow > implicit deny. Cross-account needs both IAM and bucket policy (and KMS key policy).
  • Pre-signed URL = time-limited bearer ticket for one operation; max 7 days, shorter with temporary credentials.
  • Every new object is encrypted (SSE-S3 since Jan 2023); SSE-KMS adds a second gate + audit; use Bucket Keys.
  • Versioning: delete = delete marker (recoverable); version-id delete = permanent. Pair with lifecycle.
  • Lifecycle: transitions downhill, expiration = TTL, noncurrent expiry, abort incomplete multipart. Mind 30/90/180-day minimums and the 128 KB rule.
  • Replication: versioning both sides, IAM role, only new objects, async; RTC = 99.99% in 15 minutes.
  • Multipart: 5 MiB-5 GiB parts, up to 10,000, max object 48.8 TiB; resumable; ETag ends in -N.
