Key takeaways

Remember this

  • A producer is a library in your process. send() only buffers; the callback tells you the truth. Always flush()/close() on shutdown.
  • Pipeline: serialize, partition, append to a per-partition batch, Sender thread ships batches to each leader, ack, callback.
  • Key set: murmur2(key) % partitions. No key: uniform sticky partitioner. librdkafka clients need partitioner=murmur2_random to match Java.
  • A batch is sent when it reaches batch.size (16 KiB) or after linger.ms (5 ms since 4.0). Compression is per batch and stays compressed end to end.
  • acks=all + RF 3 + min.insync.replicas=2 = no loss on one broker failure; writes stop if two replicas are gone.
  • Idempotent producer: PID + per-partition sequence numbers, no retry duplicates, order kept with up to 5 in flight. Not a fix for app resends, restarts or consumers.
  • delivery.timeout.ms (2 min) is the real retry limit. A full buffer.memory blocks send() for up to max.block.ms (60 s): set it low in request paths.
