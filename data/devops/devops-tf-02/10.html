Remember this

  • State maps each resource address to a real object ID and caches attributes and dependencies. Lose it and Terraform loses control.
  • Plan = load state, refresh from the cloud (finds drift), diff against config. Apply writes a new serial.
  • Teams use a remote backend. On AWS: S3, versioned, SSE-KMS, locked, one key per stack per environment.
  • Locking is a compare-and-swap: use_lockfile = true (S3 .tflock, 1.11+) or the deprecated DynamoDB LockID table.
  • Prefer moved, import and removed blocks over state mv/import/rm; back up with state pull first.
  • sensitive only hides output. Secrets live in state and plan files unless you keep them out (managed secrets, ephemeral, _wo).
  • Protect the backend: KMS, least-privilege IAM, TLS-only, Block Public Access, CloudTrail data events.
