Common mistakes and gotchas

Good to know (SDE-2)
MistakeWhy it hurtsDo this instead
terraform.tfstate committed to GitSecrets in history forever; merge conflicts corrupt state.gitignore: *.tfstate*, .terraform/, *.tfplan
Remote backend without lockingTwo applies overwrite each otheruse_lockfile = true (or a DynamoDB table on older setups)
State bucket without versioningOne bad write and history is goneVersioning + lifecycle on noncurrent versions
One giant state for everythingSlow plans, one lock blocks every team, huge blast radiusSplit by stack and environment
Believing sensitive = true encryptsPassword readable by anyone with s3:GetObjectKeep secrets out of state; KMS; tight IAM
Uploading tfplan as a public CI artifactPlan files contain the same values as stateTreat plan files like state: encrypted, short retention
-lock=false "because it was stuck"You may be racing a real applyFind the holder from Lock Info, then force-unlock
Using variables in the backend blockError: Variables not allowedPartial config with -backend-config
terraform state rm when you meant "delete it"Object keeps running (and billing), now unmanagedRemove the block and apply to destroy; rm only to hand it over
