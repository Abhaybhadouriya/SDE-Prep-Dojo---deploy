Real incidents and what they teach

Deep dive (platform teams)
🥧

Reddit Pi-Day outage (2023)

314 minutes down after a 1.23 to 1.24 upgrade. Calico route reflectors were picked by the removed master node label, so pod networking broke. Lesson: read removals, keep all config in git.

 🐶

Datadog, March 2023

An automatic OS update restarted systemd-networkd, which flushed Cilium's ip rule entries. Pods lost networking across regions. Lesson: node OS changes need a staged rollout too.

 📈

OpenAI at 7,500 nodes

API servers and etcd were the bottleneck; they moved Events into a separate etcd cluster and alerted on API server 429 and 5xx rates. Lesson: monitor the control plane, not only apps.

 📚

Kubernetes Failure Stories

A public collection of post-mortems: DNS ndots:5 slowness, CPU-limit throttling, OOM storms, etcd trouble. Read three before your interview.

From your world

The Datadog story is one you can tell better than most candidates. Cilium relies on Linux policy routing (ip rule plus extra routing tables). systemd-networkd, after an update, decided it owned all rules and deleted the ones it did not create. To Kubernetes everything looked "Running"; the packets just had no route. Lesson for debugging: when every pod on a node breaks at once, suspect the node data plane (CNI, routes, iptables/nftables, conntrack), not the apps.
