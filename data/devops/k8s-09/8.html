Remember this

  • Scheduler = watch unscheduled pods, filter, score, bind (writes nodeName). The kubelet runs the pod.
  • Scheduling uses requests, not real usage. Limits are kernel-enforced: CPU throttled, memory OOMKilled (137).
  • QoS: Guaranteed (req = limit), Burstable, BestEffort (evicted first).
  • Affinity attracts (pod side); taints repel (node side); dedicate nodes with both.
  • Spread replicas with topologySpreadConstraints on topology.kubernetes.io/zone.
  • HPA: every 15 s, ceil(current x metric / target), 10% tolerance, 5-min scale-down window, needs requests.
  • Node autoscalers react to Pending pods, not node CPU. Reactive scaling takes minutes: pre-scale known spikes.
  • Kafka consumers: scale on lag (KEDA), max replicas = partitions.
