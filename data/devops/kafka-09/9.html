Key takeaways

Remember this

  • Connect and Streams are part of Apache Kafka but run outside the brokers; Debezium plugs into Connect; Flink is a separate cluster.
  • Connect = workers run connector tasks; converters do formats; SMTs do light edits; state in connect-configs/offsets/status.
  • Sink DLQ: errors.tolerance=all + errors.deadletterqueue.topic.name. Sinks are at-least-once: upsert.
  • Dual write is broken; outbox + CDC fixes it; consumers still deduplicate.
  • Debezium reads binlog/WAL; events carry before, after, op; watch Postgres slot lag.
  • Streams: task per partition, RocksDB stores, changelog and repartition topics, standbys, exactly_once_v2.
  • Windows: tumbling, hopping, sliding, session. Use event time; watermarks or grace decide when a window is done.
  • Flink: JobManager + TaskManagers, barrier checkpoints to durable storage, two-phase-commit Kafka sink.
