The story: the class notebooks

Explain like I'm 5

Your class keeps a notebook for every subject: one for Lunch, one for Library, one for Sports. Each subject notebook is a topic.

The Lunch notebook gets so busy that kids queue up to write in it. So the teacher splits it into three Lunch notebooks, and three kids can write at the same time. Each of those notebooks is a partition. The teacher has one rule: "Always write about the same kid in the same notebook." So everything about Asha goes in notebook 1, and you can read Asha's lunches in the right order.

Every line in a notebook has a number written in the margin: line 0, line 1, line 2... That number is the offset. You never rub out a line and you never write in the middle - only at the bottom.

The notebooks live on shelves in three different rooms, so that if one room is locked, the others still work. Each room is a broker, and all the rooms together are the Kafka cluster.

That story contains the whole Kafka model. The rest of this page gives each piece its real name, shows it moving, and then lets you poke at it on your own laptop. Nothing here is optional: every later page (producers, consumers, replication, exactly-once) is built on these words.
