Common mistakes and tips from the posts

Mistakes that cost offers or levels
  • Not asking clarifying questions, even "obvious" ones (down-levelled, 8293408).
  • Telling a generic "add caches, add shards" scaling story when the interviewer wanted concrete tech justification (6850728).
  • Spending too long on scale and stumbling on the API itself (6907694).
  • A vague engagement metric and an unconvincing DB choice (7196860).
  • Running out of time in the combined coding + design screen (8585621).
  • A good design round does not save a weak code design round: hire on design, overall reject (6990017).
Habits that worked
  • Study the past Atlassian list (Jira, tagging, leaderboard) before the loop; a selected candidate did exactly this (7196860).
  • Redis sorted sets for "top N tags" got positive feedback (6587244).
  • Write extensible, tested code in your own IDE for code design (8293408).
  • Think out loud and say "I don't know" honestly; the official guide asks for this.
  • Practise 5-minute answers for rapid-fire design prompts for the Karat screen.
