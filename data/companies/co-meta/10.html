Interview questions with best answers

Level 5 - Interview-ready
What is the difference between Meta's System Design and Product Architecture rounds?

Both are 45 minutes. System Design leans on scale and infrastructure; Product Architecture leans on APIs, data model and how the client uses them. Ask your recruiter which you will get.

How to answer

Give one example prompt for each and what you would emphasise.

Likely follow-ups
  • Which would you choose and why?
Design top-K trending hashtags for the last hour.

Events to Kafka, partitioned counting per hashtag in time windows, periodic merge into a global top-K sorted set, approximate sketches if exact counts are too expensive. See Trending Topics (Twitter/X).

How to answer

Lead with the event rate; it decides everything.

Likely follow-ups
  • How do you handle one hashtag going viral?
  • Sliding or tumbling windows?
Design Dropbox. How do other machines learn that a file changed?

Upload chunks to object storage, commit metadata with a version, publish a change event; clients keep a long-lived connection (SSE or WebSocket) or long-poll for change notices, then download only changed chunks. See File Sync (Dropbox/OneDrive).

How to answer

Separate the data path (chunks) from the control path (metadata and notifications).

Likely follow-ups
  • Two people edit the same file offline: what happens?
  • SSE or WebSocket here?
Design a ticket booking service for a very popular concert.

A virtual waiting room to smooth the spike, seat holds with a TTL using conditional writes, payment confirms the hold, and a read-optimised seat map cache. See Ticket Booking (BookMyShow).

How to answer

Start with the spike and the contention point, not the boxes.

Likely follow-ups
  • What if payment fails?
  • How do you stop bots?
Design a live leaderboard for a coding contest.

Submissions scored asynchronously; scores kept in a sorted set (Redis ZSET) per contest; top-N served from cache; user's own rank via rank query. Shard by contest. See Real-time Leaderboard.

How to answer

Mention the update rate vs read rate and how fresh the board must be.

Likely follow-ups
  • Millions of players in one game?
  • How do you handle ties?
Design YouTube Live comments.

Clients connect to a gateway tier (WebSocket or SSE); comments go to a log keyed by stream; a pub/sub layer fans out to gateways holding viewers of that stream; sample or rate-limit for huge streams. See Live Comments & Reactions (FB Live / Hotstar).

How to answer

Explain why fan-out per stream, not per user.

Likely follow-ups
  • 10 million viewers on one stream?
  • How do you order comments?
How do you avoid being down-levelled in the design round?

Drive without hints, finish the basic design by about minute 30, then complete two deep dives, and raise failure modes yourself.

How to answer

Practise with a timer and a friend who interrupts.

Likely follow-ups
  • What would you cut if time ran short?
Tell me about a conflict with a coworker.

A networking example: another team wanted to change a shared config format late in a release. You set up a meeting, showed the test impact, agreed a staged rollout, and both teams shipped on time.

How to answer

Show empathy, a clear action and a measurable result.

Likely follow-ups
  • What would you do if they refused?
  • What did you learn?
