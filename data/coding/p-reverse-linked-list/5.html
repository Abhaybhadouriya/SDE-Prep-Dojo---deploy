Dry run

Iterative version on [3,8,1,6]. Grey arrows are original links, accent arrows are flipped links, green nodes are in the reversed part.

  1. Start: prev = null, cur = head (3). The reversed part is empty.
  2. Iteration 1, line 1: nxt = cur.next (8). Save it first: the next line destroys the only pointer to the rest of the list.
  3. Line 2: cur.next = prev. Node 3 now points to null. Without nxt, nodes 8, 1, 6 would be unreachable (a leak in C).
  4. Lines 3-4: prev = cur (3), cur = nxt (8). The reversed part is [3].
  5. Iteration 2: save 1, point 8 back at 3, advance. Reversed part: 8 → 3. Rest: 1 → 6.
  6. Iteration 3: save 6, point 1 back at 8, advance. Reversed part: 1 → 8 → 3.
  7. Iteration 4: save null, point 6 back at 1, advance. cur is null, so the loop stops.
  8. Return prev (6): the list is 6 → 1 → 8 → 3 → null. Each node was touched once: O(n) time, three pointers: O(1) space.
