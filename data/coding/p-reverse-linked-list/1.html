The problem (in our words)

You get head, the first node of a singly linked list (each node has an integer val and a next pointer; the last node's next is null). Reverse the list, so that the old last node comes first and every next pointer points to the node that used to be before it, and return the head of the reversed list. An empty list (head is null) stays empty.

Signature: ListNode reverseList(ListNode head). Lists are written as arrays in the examples: [3,8,1,6] means 3 → 8 → 1 → 6 → null.

  • The number of nodes is in the range [0, 5000]
  • -5000 <= Node.val <= 5000

Follow-up asked by the original: a list can be reversed iteratively or recursively. Can you write both?

Practice it: LeetCode 206 · GfG Reverse a linked list · TUF article

Constraints tell you: up to 5000 nodes, so time is not an issue; the interesting number is the depth. A recursive solution makes 5000 nested calls, which is fine in C++ and Java but over Python's default limit of 1000 frames. Zero nodes is allowed, so the null head must work.
