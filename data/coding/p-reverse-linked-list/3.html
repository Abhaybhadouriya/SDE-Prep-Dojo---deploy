Recognise the pattern

When you see "reverse", "read from the back", "compare the first half with the second half" on a singly linked list, think in-place reversal with prev / cur / nxt. If only part of the list is reversed, add a dummy node in front and reconnect the two ends of the reversed part afterwards.
