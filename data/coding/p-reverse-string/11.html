Interview follow-ups

Write it recursively. What does that cost?

Swap s[lo] and s[hi], then recurse on (lo+1, hi-1); stop when lo >= hi. Time stays O(n), but the stack holds n/2 frames, so space is O(n), and at n = 105 Python's default limit of 1000 frames fails.

How to answer

Point out that the recursive call is in tail position, so a compiler that eliminates tail calls (C/C++ with -O2 often does) turns it back into the loop.

Likely follow-ups
  • Recursion that halves instead: reverse each half, then swap the halves - O(n log n) moves, worse.
The string is UTF-8, not ASCII. Does your loop still work?

No: a multi-byte code point (for example a 3-byte character) would be split and its bytes reversed, producing invalid UTF-8. Reverse the bytes of the whole buffer, then walk it and reverse the bytes inside each multi-byte sequence back; or decode to code points (Go: []rune) and reverse those. Combining marks and emoji sequences need grapheme clusters, which is a library job.

How to answer

Name the three levels: bytes, code points, grapheme clusters, and say which one the product needs.

Likely follow-ups
  • How do you detect the start of a UTF-8 sequence? Bytes of the form 10xxxxxx are continuation bytes.
Reverse only the vowels (or only the letters).

Same two pointers, but before each swap move lo right until it sits on a vowel and hi left until it sits on a vowel, both guarded by lo < hi. Each character is still passed once, so O(n).

How to answer

Show the guard inside the skip loops: without it, a string with no vowels runs the pointers off the ends.

Likely follow-ups
  • Upper-case vowels count too: use a set of 10 characters, or lower-case before testing.
Rotate an array right by k positions in O(1) extra space.

Use this loop as reverse(a, l, r) three times: reverse the whole array, then the first k mod n elements, then the rest. Every element moves exactly twice, so O(n) time, O(1) space.

How to answer

Trace it on [1,2,3,4,5], k = 2: all -> [5,4,3,2,1], first 2 -> [4,5,3,2,1], rest -> [4,5,1,2,3].

Likely follow-ups
  • Why k mod n? k can be larger than n; rotating by n is the identity.
Reverse the order of words in a sentence in place.

Reverse the whole character array, then reverse each word back (find each word's bounds with a scan). The words end up in reverse order and each word reads forward again. Extra spaces need a compaction pass (reader/writer pointers).

How to answer

Say the two-level trick out loud: "reverse everything, then fix each piece". It is the same idea as the rotation.

Likely follow-ups
  • Do it on a stream of words: push words on a stack or write them from the end of an output buffer.
Make the loop faster for a very large byte buffer.

Swap machine words instead of bytes: load 8 bytes from each end, byte-swap them (__builtin_bswap64), store them crosswise, and finish the middle byte by byte. SIMD shuffles do the same with 16 or 32 bytes. It is still O(n), but with about n/16 loads and stores instead of n.

How to answer

Mention alignment and the leftover middle part; the asymptotic answer does not change, only the constant.

Likely follow-ups
  • Is the plain loop cache friendly? Yes: two sequential streams, one forward and one backward, both prefetchable.
