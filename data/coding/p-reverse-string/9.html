60-second recall

  • Cue: reverse / mirror in place -> opposite-end pointers.
  • Insight: index i pairs with n-1-i; the pairs are disjoint, so swap each once.
  • State: lo from the left, hi from the right; done when lo >= hi.
  • Trap: a full-length loop swaps twice (no change); Python s = s[::-1] does not mutate.
  • Cost: O(n) time, floor(n/2) swaps, O(1) space.
def reverse(a, lo, hi):          # reusable on any sub-range
    while lo < hi:
        a[lo], a[hi] = a[hi], a[lo]
        lo += 1; hi -= 1

How many swaps does the two-pointer loop do on an array of length 7?

  4. 6
floor(7 / 2) = 3 pairs: (0,6), (1,5), (2,4). Index 3 is the middle and is never swapped.

A solution loops for i in range(n) and swaps s[i] with s[n-1-i]. What is the result?

  1. The original array, unchanged
  2. The reversed array
  3. An index error
  4. Only the first half reversed
Each mirror pair is swapped once in the first half and swapped back in the second half.

Why is the recursive version not O(1) space?

  1. It copies the array
  2. It uses a hash map
  3. Each of the n/2 calls keeps a stack frame
  4. It is O(1); recursion is free
Without tail-call elimination (Python, Java, Go do not do it) the stack grows to n/2 frames.
