Common mistakes

Looping over the whole array. for i in range(n): swap(s[i], s[n-1-i]) swaps every pair twice and puts the string back as it was. Loop while lo < hi (or i < n / 2).

Rebinding instead of mutating. In Python, s = s[::-1] creates a new list bound to a local name; the caller's list is unchanged and the judge sees the original. Use s.reverse() or s[:] = ... if you go the library way, and still be ready to write the loop.

XOR swap on the same slot. a ^= b; b ^= a; a ^= b zeroes the value when both refer to the same memory. With lo < hi it cannot happen here, but a plain temporary is clearer and just as fast.

Unsigned underflow in C/C++. size_t hi = s.size() - 1 is fine here because n >= 1, but on an empty input it wraps to a huge number. Use signed int indices or check for empty first.
