Revision card

  • Cue: Subarray sum equals k (with negatives), range sums, "balanced" counts, divisible by k.
  • Insight: sum(l..r) = P[r + 1] - P[l], so a subarray is a pair of prefixes.
  • State: a map from prefix value to count (how many) or to first index (longest), seeded {0: 1} or {0: -1}.
  • Trap: Looking up after inserting the current prefix; forgetting the seed; negative remainders in C++/Java.
  • Cost: O(n) time, O(n) space; difference array O(n + q) for range updates.

More to remember

  • P has n + 1 entries, P[0] = 0; sum(l..r) = P[r + 1] - P[l].
  • Exact target plus negatives: walk with run, look up run - k in a map, then record run.
  • Seed {0: 1} for counts, {0: -1} for first indexes.
  • "How many" stores counts; "longest" stores the first index.
  • Change the key to change the problem: +1/-1 balance, remainder mod k, parity mask, XOR.
  • Difference array: diff[l] += v; diff[r + 1] -= v, one prefix sweep at the end.
  • Trees: the same map along the DFS path, undone on return.
  • 64-bit sums; non-negative remainders.
