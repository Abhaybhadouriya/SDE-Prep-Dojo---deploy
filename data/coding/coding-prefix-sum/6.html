2D prefix sums (rectangles)

Range Sum Query 2D - Immutable asks for the sum of any rectangle of a matrix, many times. Let S[i][j] = sum of the top-left block of i rows and j columns (again with an extra row and column of zeros). Build it with

S[i+1][j+1] = grid[i][j] + S[i][j+1] + S[i+1][j] - S[i][j]
sum(r1, c1, r2, c2) = S[r2+1][c2+1] - S[r1][c2+1] - S[r2+1][c1] + S[r1][c1]

Build O(R × C), query O(1). A harder cousin is Number of Submatrices That Sum to Target: fix a pair of rows (O(R²) pairs), squash the columns between them into a 1D array of column sums, and run the 1D "count subarrays with sum k" on it: O(R² × C).
