Count or first index? If the question is "how many", store a count. If it is "longest", store the first index where each key appeared and never overwrite it: the earliest start gives the longest block. (For "shortest" you would keep the latest index instead.)

Contiguous Array: turn it into a sum of zero

Contiguous Array: a binary array; return the length of the longest subarray with as many 0s as 1s. Replace every 0 with -1. "Equal counts" now means "sum is 0", and a sum of 0 between two boundaries means the running total was the same at both. Picture the running total as a walk up and down:

first = {0: -1}            # balance 0 "happened" before index 0
bal = best = 0
for i, x in enumerate(nums):
    bal += 1 if x == 1 else -1
    if bal in first: best = max(best, i - first[bal])
    else:            first[bal] = i        # keep the FIRST index only

The seed is now {0: -1} because we store indexes: a balanced block that starts at 0 and ends at i has length i - (-1) = i + 1.

Remainders: "multiple of k"

Two prefix totals with the same remainder mod k differ by a multiple of k. So the key is run % k.

  • Continuous Subarray Sum asks for a block of length at least 2 whose sum is a multiple of k. Store the first index per remainder (seed {0: -1}) and answer true when the same remainder shows up again at least 2 positions later. Keeping the first index matters: [5, 0, 0, 0], k = 3 is true because of [0, 0], and overwriting would lose it.
  • Subarray Sums Divisible by K counts them, and the values may be negative. In C, C++, Java and Go, -1 % 5 is -1, not 4, so -1 and 4 would land in different buckets. Normalise: ((run % k) + k) % k (Java: Math.floorMod). Python's % is already non-negative. Because there are only k possible keys you can use an array of size k instead of a map.

A neat remark for an interview: with n >= k, some two prefix totals must share a remainder (n + 1 prefixes, k buckets: the pigeonhole principle), so a subarray with sum divisible by k always exists. That is also why the counts array never needs more than k slots.
