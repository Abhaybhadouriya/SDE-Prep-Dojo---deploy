Path Sum III: prefix sums down a tree

Path Sum III: count the paths in a binary tree whose node values add up to a target, where a path goes only downward (parent to child) but may start and end at any node. The brute force starts a DFS at every node: O(n²) on a skewed tree.

Any downward path lies on one root-to-node line, and on that line it is just a subarray. So do the array trick along the current root-to-node path: run = sum from the root to this node, and the map holds the totals of the nodes above this one. The count of paths ending here is seen[run - target].

The one new step is undo on the way back. When the DFS returns from a node, decrement its total in the map, so that a sibling subtree does not see prefixes from a path it is not on. It is the same as backtracking: add, recurse, remove.

def dfs(node, run):
    if not node: return 0
    run += node.val
    found = seen[run - target]
    seen[run] += 1                 # visible to my subtree
    found += dfs(node.left, run) + dfs(node.right, run)
    seen[run] -= 1                 # gone before my sibling runs
    return found

O(n) time, O(h) for the recursion plus up to O(h) live map entries (h = height). Tree values here go up to 109 with up to 1,000 nodes, so the total needs 64 bits. More tree patterns are in the trees lesson.
