Recognise the pattern

Cue: a grid + "connected cells with the same value" + "change / count / measure the region" -> DFS or BFS from the start cell over 4 neighbours, marking cells as you go.

The template is the same for every grid component problem: bounds check, condition check, mark, push neighbours. Only the condition and what you do with the component change.
