Common mistakes

No early return when the colours match. The most common wrong answer: stack overflow or time limit on [[0,0],[0,0]], 0, 0, 0.

Comparing neighbours with the current pixel's colour instead of the original colour. After painting, the current pixel reads color, so the comparison must use the saved old.

Painting at pop time instead of push time in BFS/iterative DFS. A pixel can then be pushed several times by different neighbours; still correct, but the stack grows and the work is no longer one push per pixel.

Bounds check after indexing. Check 0 <= r < m and 0 <= c < n before reading image[r][c]; in Python a negative index silently wraps to the other edge.
