Approaches: brute -> better -> optimal

Hint 1

Treat each pixel as a graph node with up to four neighbours. Which neighbours belong to the region?

Hint 2

Once a pixel is repainted, can it ever be confused with an unvisited region pixel again? When can it?

1. Brute force - repeat sweeps until nothing changes

Idea: paint the start pixel, then sweep the whole grid repeatedly, painting any old-colour pixel that has a painted neighbour, until a sweep changes nothing. Correct, but a snake-shaped region needs one sweep per cell: O((m·n)2).

O((mn)2)time
O(1)space

2. Better - recursive DFS

Idea: dfs(r, c): if out of bounds or image[r][c] != old, return; otherwise paint it and recurse into the four neighbours. Five lines, and the expected first answer.

def dfs(r, c):
    if not (0 <= r < m and 0 <= c < n) or image[r][c] != old:
        return
    image[r][c] = color          # the repaint is the visited mark
    dfs(r + 1, c); dfs(r - 1, c); dfs(r, c + 1); dfs(r, c - 1)
if old != color: dfs(sr, sc)
O(mn)time
O(mn)recursion depth, worst case

What is wasted: nothing in time, but the call stack can reach m·n frames (2,500 here, millions on a real image), which breaks Python's default limit and risks stack overflow in C on large inputs.

3. Optimal - iterative DFS (explicit stack) or BFS (queue)

Idea: the same traversal with your own stack: paint the start pixel and push it; pop a pixel, and for each in-bounds neighbour that still has the old colour, paint it and push it. A queue instead of a stack gives BFS with the same cost; only the order differs.

O(mn)time
O(mn)stack, heap-allocated

Why it works: a pixel is pushed only if it has the old colour and is next to a pixel already in the region, so everything painted belongs to the region. Conversely, every region pixel is reachable by a chain of old-coloured neighbours from the start, and the traversal follows every edge out of every painted pixel, so the chain is painted link by link. Painting at push time means a pixel's colour no longer equals old once it is in the stack, so each pixel is pushed at most once: O(m·n). This argument needs color != old; otherwise the mark is invisible, hence the early return.
