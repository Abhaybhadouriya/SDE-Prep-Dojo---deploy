  4. a[1] = 6 > 5: swap it with a[6] = 1 and gt--. i does not move: the 1 that came in is not checked yet.

The size-k min-heap on the same input (usually asked first)

Interviewers usually want the heap answer first, then quickselect as the O(n) average follow-up. Push each value; when the heap holds more than k = 3, pop its top (the smallest). The top after the last value is the answer.
