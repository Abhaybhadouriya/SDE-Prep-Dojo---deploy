Common mistakes

  • Using a max-heap of all n values and popping k times. Correct, but O(n + k log n) time and O(n) space; the size-k min-heap is the expected answer.
  • Wrong heap direction. For the k-th largest, the heap must be a min-heap so the smallest of the top k can be dropped.
  • Off-by-one target. The k-th largest in ascending order is at n - k, not k or n - k - 1.
  • Fixed pivot plus 2-way partition. Sorted input or many duplicates make it O(n^2) and time out.
  • Advancing i after swapping with gt. The value swapped in from the right is unchecked; only the left swap may advance both.
  • Deduplicating first (a set). The task counts duplicates.
