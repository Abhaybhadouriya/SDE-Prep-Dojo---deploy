Palindrome partitioning II: fewest cuts

Problem (restated from LeetCode 132, Palindrome Partitioning II). Cut s into pieces so that every piece is a palindrome. Return the fewest cuts needed. Example: "banana" needs 1 ("b" | "anana"); a string that is already a palindrome needs 0. Limits: 1 <= length <= 2000, lowercase letters.

The state here is a prefix, not an interval. cut[i] = the fewest cuts for s[0..i). If the last piece is the palindrome s[l..i-1], then cut[i] = cut[l] + 1, so take the minimum over all such l. Set cut[0] = -1 so that a prefix that is a single palindrome gets 0 cuts.

The textbook version first builds an n x n isPal table (O(n2) memory; at n = 2000 that is 4 million booleans), then runs the cut loop. The neater version, used by many of the most-voted solutions, merges the two steps. Expand around every centre. Each palindrome s[l..r] you find relaxes cut[r+1] from cut[l]. O(n2) time and O(n) memory.

// Palindrome partitioning II. cut[i] = min cuts for s[:i]; cut[0] = -1.
// Every palindrome s[l..r] found by centre expansion relaxes cut[r+1] from cut[l].
func minCut(s string) int {
	n := len(s)
	cut := make([]int, n+1)
	for i := range cut {
		cut[i] = i - 1
	}
	for c := 0; c < n; c++ {
		for odd := 1; odd >= 0; odd-- {
			for l, r := c, c+1-odd; l >= 0 && r < n && s[l] == s[r]; l, r = l-1, r+1 {
				cut[r+1] = min(cut[r+1], cut[l]+1)
			}
		}
	}
	return cut[n]
}
// Palindrome partitioning II: fewest cuts so every piece is a palindrome.
// cut[i] = min cuts for the prefix s[0..i). Expanding around each centre finds
// every palindrome s[l..r] once and relaxes cut[r+1] from cut[l]. O(n^2), O(n).
int minCut(const string& s) {
    int n = s.size();
    vector<int> cut(n + 1);
    for (int i = 0; i <= n; i++) cut[i] = i - 1;               // cut[0] = -1 sentinel
    for (int c = 0; c < n; c++)
        for (int odd = 1; odd >= 0; odd--)                     // odd then even length
            for (int l = c, r = c + 1 - odd; l >= 0 && r < n && s[l] == s[r]; l--, r++)
                cut[r + 1] = min(cut[r + 1], cut[l] + 1);
    return cut[n];
}
// Palindrome partitioning II. cut[i] = min cuts for prefix s[0..i); cut[0] = -1.
// Expand around each centre; every palindrome s[l..r] relaxes cut[r+1] from cut[l].
static int minCut(String s) {
    int n = s.length();
    int[] cut = new int[n + 1];
    for (int i = 0; i <= n; i++) cut[i] = i - 1;
    for (int c = 0; c < n; c++)
        for (int odd = 1; odd >= 0; odd--)
            for (int l = c, r = c + 1 - odd; l >= 0 && r < n && s.charAt(l) == s.charAt(r); l--, r++)
                cut[r + 1] = Math.min(cut[r + 1], cut[l] + 1);
    return cut[n];
}
def min_cut(s: str) -> int:
    """cut[i] = min cuts for s[:i]; cut[0] = -1. Each palindrome s[l..r] found by
    centre expansion relaxes cut[r+1] from cut[l]. O(n^2) time, O(n) memory."""
    n = len(s)
    cut = list(range(-1, n))
    for c in range(n):
        for l, r in ((c, c), (c, c + 1)):          # odd, then even length
            while l >= 0 and r < n and s[l] == s[r]:
                cut[r + 1] = min(cut[r + 1], cut[l] + 1)
                l, r = l - 1, r + 1
    return cut[n]

A cut at position r+1 is relaxed from cut[l] with l <= r, and centres go left to right. Is cut[l] final by the time it is read? Yes. Every palindrome that ends at l-1 has its centre at or before l-1, which is before the current centre, so all of them have been processed already.
