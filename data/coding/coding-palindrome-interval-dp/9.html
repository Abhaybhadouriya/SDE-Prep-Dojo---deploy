Common mistakes

  • Filling i from 0 upward. Cell (i, j) reads row i+1, which is still empty. Fill by length, or loop i downward.
  • Only odd centres. "abba" has no single middle letter. Use 2n-1 centres, or the c / 2, c % 2 trick.
  • Substring vs subsequence. LeetCode 5 is contiguous (centres); 516 is not (table). Using the wrong one gives plausible but wrong answers.
  • Length 2 with equal ends. dp[i+1][j-1] would be an empty range (i+1 > j-1); its value is 0, so make sure the table holds 0 there or special-case it.
  • cut[0] not -1. Without the sentinel, a whole-string palindrome reports 1 cut.
  • Burst balloons with "first". Choosing the first balloon does not split the problem. Choose the last, and use open intervals with padded 1s.
  • Forgetting to sort the cuts (1547) or to add 0 and n as walls.
  • Egg drop update order. In the 1-D flipped form, update e from k down to 1, or f[e-1] already holds the new t.
  • Integer overflow in egg drop. f grows fast with many eggs. Stop as soon as it reaches n, or use 64-bit values.
