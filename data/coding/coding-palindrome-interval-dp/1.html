Palindromic substrings: expand around centres

Problem (restated from LeetCode 5, Longest Palindromic Substring). Given a string s, return its longest contiguous piece that reads the same forwards and backwards. Any one of several equally long answers is accepted. Example: "civicky" gives "civic"; "abbe" gives "bb". Limits: 1 <= length <= 1000; letters and digits only.

Problem (restated from LeetCode 647, Palindromic Substrings). Given a string s, count how many of its substrings are palindromes. Substrings at different positions count separately, even if they have the same letters. Example: "abba" has 6 (a, b, b, a, bb, abba). Limits: 1 <= length <= 1000, lowercase letters.

A table isPal[i][j] = s[i] == s[j] and isPal[i+1][j-1] works, but it uses O(n2) memory for something we can do with none. Every palindrome has a centre, and once you know the centre you can grow outwards one letter on each side at a time. There are 2n-1 centres: n letters (odd lengths) and n-1 gaps (even lengths).

Growing from a centre stops at the first mismatch. Each step finds one more palindrome, so the same loop solves both problems: keep the longest for LeetCode 5, count every step for LeetCode 647. O(n2) time in the worst case (a string of one repeated letter), O(1) extra memory.

// Expand around all 2n-1 centres. O(n^2) time, O(1) memory.
func longestPalindrome(s string) string {
	n, bestL, bestLen := len(s), 0, 0
	for c := 0; c < 2*n-1; c++ {
		l, r := c/2, c/2+c%2 // even c: on a char; odd: between two
		for l >= 0 && r < n && s[l] == s[r] {
			if r-l+1 > bestLen {
				bestL, bestLen = l, r-l+1
			}
			l--
			r++
		}
	}
	return s[bestL : bestL+bestLen]
}

// Same loop, counting every palindrome found (LeetCode 647).
func countSubstrings(s string) int {
	n, cnt := len(s), 0
	for c := 0; c < 2*n-1; c++ {
		for l, r := c/2, c/2+c%2; l >= 0 && r < n && s[l] == s[r]; l, r = l-1, r+1 {
			cnt++
		}
	}
	return cnt
}

// Returns the longest palindromic substring; `count` gets the number of
// palindromic substrings (LeetCode 647) as a by-product.
string longestPalindrome(const string& s, long long* count = nullptr) {
    int n = s.size(), bestL = 0, bestLen = 0;
    long long cnt = 0;
    for (int c = 0; c < 2 * n - 1; c++) {
        int l = c / 2, r = l + c % 2;        // even c: centre on a char; odd: between two
        while (l >= 0 && r < n && s[l] == s[r]) {
            cnt++;
            if (r - l + 1 > bestLen) { bestL = l; bestLen = r - l + 1; }
            l--; r++;
        }
    }
    if (count) *count = cnt;
    return s.substr(bestL, bestLen);
}

def longest_palindrome(s: str) -> str:
    """Expand around all 2n-1 centres. O(n^2) time, O(1) memory."""
    n, best_l, best_len = len(s), 0, 0
    for c in range(2 * n - 1):
        l, r = c // 2, c // 2 + c % 2   # even c: on a char; odd: between two
        while l >= 0 and r < n and s[l] == s[r]:
            if r - l + 1 > best_len:
                best_l, best_len = l, r - l + 1
            l, r = l - 1, r + 1
    return s[best_l:best_l + best_len]


def count_substrings(s: str) -> int:

    n, cnt = len(s), 0
    for c in range(2 * n - 1):
        l, r = c // 2, c // 2 + c % 2
        while l >= 0 and r < n and s[l] == s[r]:
            cnt += 1
            l, r = l - 1, r + 1
    return cnt

Index trick. Loop c from 0 to 2n-2 and set l = c / 2, r = l + c % 2. Even c starts on a letter (l == r), odd c starts on a gap (r = l + 1). One loop, no duplicated code for the odd and even cases.

There is an O(n) method, Manacher's algorithm, which reuses the mirror image of palindromes already found. It is rarely expected in an interview. Name it if asked for something faster, and say that expand-around-centre is the answer you would write.
