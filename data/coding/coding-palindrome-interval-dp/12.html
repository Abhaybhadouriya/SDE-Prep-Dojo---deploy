LPS table: which loop order is wrong?

  1. i from 0 up to n-1, j from i up
  2. Memoised recursion on (i, j)
  3. len from 1 to n, then i
  4. i from n-1 down to 0, j from i up
Row i reads row i+1, which an ascending i loop has not filled yet.

In palindrome partitioning II, why is cut[0] set to -1?

  1. To avoid an index error
  2. To mark it as unvisited
  3. Because the answer is always one less than the pieces, so all values are shifted
  4. So that a prefix which is itself a palindrome gets cut[0] + 1 = 0 cuts
cut[r+1] = cut[l] + 1 counts a cut before the last piece; when l = 0 there is no cut before it.

With 2 eggs, what is the most floors that 5 moves can always resolve?

  1. 15
  2. 5
  3. 32
  4. 10
f[t][2] = t(t+1)/2 = 15. (32 would need unlimited eggs: 25 - 1 = 31.)

Minimum cost to cut a stick: what do you add to dp[l][r] beyond the best split?

  1. p[r] - p[l], the length of the piece being cut
  2. p[k], the cut position
  3. The number of cuts inside
  4. Nothing
The first cut inside this piece costs the piece's full length; the two sub-pieces pay for their own cuts.
