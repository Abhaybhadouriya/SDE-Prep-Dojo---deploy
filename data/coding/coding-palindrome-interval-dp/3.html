Palindromic subsequences: peel the ends

Problem (restated from LeetCode 516, Longest Palindromic Subsequence). Given s, return the length of the longest subsequence (letters in order, gaps allowed) that is a palindrome. Example: "character" gives 5 ("carac"). Limits: 1 <= length <= 1000, lowercase letters.

dp[i][j] = the answer for s[i..j]. A single letter gives 1. If the two end letters are equal, they can both be used as the outer pair: dp[i+1][j-1] + 2. If they differ, at least one of them is not in the answer, so drop one: max(dp[i+1][j], dp[i][j-1]). (For length 2 with equal ends the inside is empty, so the value is 2.)

The important part is the fill order. Cell (i, j) reads (i+1, j-1), (i+1, j) and (i, j-1): all shorter intervals. So fill by increasing length, one diagonal at a time:

  1. Length 1 (the main diagonal): every single letter is a palindrome, so dp[i][i] = 1.
  2. Length 2: only "bb" (2..3) has equal ends, so dp[2][3] = 2. Others: max of the two length-1 cells = 1.
  3. Length 3: "cbb" (1..3) has different ends, so max(dp[2][3], dp[1][2]) = 2. Same for "bba". Each cell reads cells one diagonal closer to the middle.
  4. Length 4: "acbb" and "cbba" have different ends: each takes the better of dropping the left or the right letter = 2.
  5. Length 5: "acbba" has a = a at both ends, so dp[0][4] = dp[1][3] + 2 = 4 ("abba"). The answer sits in the top-right corner.
// Longest palindromic SUBSEQUENCE. dp[i][j] = answer for s[i..j], filled by length.
func longestPalindromeSubseq(s string) int {
	n := len(s)
	if n == 0 {
		return 0
	}
	dp := make([][]int, n)
	for i := range dp {
		dp[i] = make([]int, n)
		dp[i][i] = 1
	}
	for length := 2; length <= n; length++ {
		for i := 0; i+length-1 < n; i++ {
			j := i + length - 1
			if s[i] == s[j] {
				inner := 0
				if length > 2 {
					inner = dp[i+1][j-1]
				}
				dp[i][j] = inner + 2
			} else {
				dp[i][j] = max(dp[i+1][j], dp[i][j-1])
			}
		}
	}
	return dp[0][n-1]
}

// Minimum insertions to make s a palindrome = n - LPS(s).
func minInsertions(s string) int { return len(s) - longestPalindromeSubseq(s) }

// Fill by increasing length so dp[i+1][j-1], dp[i+1][j], dp[i][j-1] are ready.
int longestPalindromeSubseq(const string& s) {
    int n = s.size();
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int i = 0; i < n; i++) dp[i][i] = 1;                 // length 1
    for (int len = 2; len <= n; len++)
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s[i] == s[j]) dp[i][j] = (len == 2 ? 0 : dp[i + 1][j - 1]) + 2;
            else dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]);
        }
    return n ? dp[0][n - 1] : 0;
}

// Longest palindromic SUBSEQUENCE. dp[i][j] = answer for s[i..j], filled by length.
static int longestPalindromeSubseq(String s) {
    int n = s.length();
    if (n == 0) return 0;
    int[][] dp = new int[n][n];
    for (int i = 0; i < n; i++) dp[i][i] = 1;
    for (int len = 2; len <= n; len++)
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s.charAt(i) == s.charAt(j)) dp[i][j] = (len == 2 ? 0 : dp[i + 1][j - 1]) + 2;
            else dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
        }
    return dp[0][n - 1];
}

def longest_palindrome_subseq(s: str) -> int:
    """dp[i][j] = longest palindromic subsequence of s[i..j], filled by length."""
    n = len(s)
    if n == 0:
        return 0
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 1
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                dp[i][j] = (dp[i + 1][j - 1] if length > 2 else 0) + 2
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
    return dp[0][n - 1]


def min_insertions(s: str) -> int:
    """Minimum insertions to make s a palindrome = n - LPS(s)."""
    return len(s) - longest_palindrome_subseq(s)

Minimum insertions to make a palindrome

Problem (restated from LeetCode 1312, Minimum Insertion Steps to Make a String Palindrome). In one step you may insert any character at any position of s. Return the fewest steps that make s a palindrome. Example: "dojo" needs 1 ("dojod"); "abcda" needs 2. Limits: 1 <= length <= 500, lowercase letters.

Letters that already belong to a palindromic subsequence can stay as they are; every other letter needs a partner inserted on the opposite side. So the answer is n - LPS(s), and it is already in the template above. The same count answers "fewest deletions to make a palindrome". Also, LPS(s) = LCS(s, reverse(s)). That is a fine answer in an interview if you have just written LCS, but the interval form is the one that generalises.

Close cousins: Valid Palindrome III (1216, Premium): "can you make it a palindrome by removing at most k letters?" is n - LPS <= k. Count Different Palindromic Subsequences (730) is the hard counting version. The ends work the same way, but you have to remove duplicate inner counts.
