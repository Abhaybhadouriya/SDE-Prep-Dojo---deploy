Common mistakes

Reading s[i + 1] without the bounds check. In C++ s[s.size()] is '\0' (it happens to work), but in Java charAt throws and in Python the index raises. Guard with i + 1 < n or scan right to left.

Using <= instead of <. "II" would become -1 + 1 = 0. Only a strictly bigger next symbol means subtraction.

Subtracting the pair twice. Some write total += next - cur for a pair but forget to skip the next symbol, so it is added again. With the sign rule you never skip anything.

Rebuilding the map inside the loop. A hash map literal inside a function called per test case is fine in interviews but slow in tight loops; a switch or a 128-entry array indexed by the character is the "C engineer" answer.
