The problem (in our words)

Roman numerals use seven symbols with these values:

SymbolIVXLCDM
Value1510501005001000

A numeral is usually written from the largest symbol to the smallest, left to right, and its value is the sum of its symbols: XXVI = 10 + 10 + 5 + 1 = 26. Six pairs break this order and mean subtraction instead:

  • I before V or X: IV = 4, IX = 9.
  • X before L or C: XL = 40, XC = 90.
  • C before D or M: CD = 400, CM = 900.

Given a string s holding a valid Roman numeral, return its integer value.

  • Input: a string s.
  • Output: an integer. Signature: int romanToInt(String s).

Constraints

  • 1 <= s.length <= 15
  • s contains only the characters 'I', 'V', 'X', 'L', 'C', 'D', 'M'.
  • s is guaranteed to be a valid Roman numeral in the range [1, 3999].
