Bidirectional BFS: search from both ends

In Word Ladder (LeetCode 127), each word can have up to 25 x L neighbours, so a BFS several levels deep touches an enormous number of words. If you know both the start and the target, grow two BFS frontiers, one from each end, and stop the moment they touch. Two searches of half the depth are far smaller than one full search:

  1. Two sets, not queues. front = {begin}, back = {end}. Remove both from the dictionary, which doubles as the visited set.
  2. Expand the smaller set by one whole level. This is what makes it fast in practice: you always pay for the cheaper side.
  3. Check for contact while generating. If a generated word is in the other set, the answer is the current level count. Otherwise, if it is still in the dictionary, remove it and add it to the next level.
  4. Stop when either set becomes empty: the two sides can never meet, return 0.
// ladderLength: bidirectional BFS. Grow the SMALLER frontier one level at a
// time until it touches the other one. Returns the number of words (0 if none).
func ladderLength(begin, end string, words []string) int {
	dict := map[string]bool{}
	for _, w := range words {
		dict[w] = true
	}
	if !dict[end] {
		return 0
	}
	a, b := map[string]bool{begin: true}, map[string]bool{end: true}
	delete(dict, begin)
	delete(dict, end)
	for length := 2; len(a) > 0 && len(b) > 0; length++ {
		if len(a) > len(b) {
			a, b = b, a // always expand the smaller side
		}
		next := map[string]bool{}
		for word := range a {
			w := []byte(word)
			for i := range w {
				orig := w[i]
				for ch := byte('a'); ch <= 'z'; ch++ {
					if ch == orig {
						continue
					}
					w[i] = ch
					s := string(w)
					if b[s] {
						return length // the frontiers met
					}
					if dict[s] {
						delete(dict, s) // delete = visited
						next[s] = true
					}
				}
				w[i] = orig
			}
		}
		a = next
	}
	return 0
}
// Bidirectional BFS (Word Ladder): grow the SMALLER frontier one level at a time
// until it touches the other one. Returns the number of words in the ladder.
int ladderLength(const string& begin, const string& end, const vector<string>& list) {
    unordered_set<string> dict(list.begin(), list.end());
    if (!dict.count(end)) return 0;
    unordered_set<string> a{begin}, b{end};
    dict.erase(begin); dict.erase(end);
    for (int len = 2; !a.empty() && !b.empty(); len++) {
        if (a.size() > b.size()) swap(a, b);          // always expand the smaller side
        unordered_set<string> next;
        for (string w : a) {
            for (size_t i = 0; i < w.size(); i++) {
                char orig = w[i];
                for (char ch = 'a'; ch <= 'z'; ch++) {
                    if (ch == orig) continue;
                    w[i] = ch;
                    if (b.count(w)) return len;       // the frontiers met
                    if (dict.count(w)) { dict.erase(w); next.insert(w); }  // erase = visited
                }
                w[i] = orig;
            }
        }
        a.swap(next);
    }
    return 0;
}
// Bidirectional BFS (Word Ladder): grow the SMALLER frontier one level at a time
// until it touches the other one. Returns the number of words in the ladder.
static int ladderLength(String begin, String end, List<String> list) {
    Set<String> dict = new HashSet<>(list);
    if (!dict.contains(end)) return 0;
    Set<String> a = new HashSet<>(List.of(begin)), b = new HashSet<>(List.of(end));
    dict.remove(begin); dict.remove(end);
    for (int len = 2; !a.isEmpty() && !b.isEmpty(); len++) {
        if (a.size() > b.size()) { Set<String> t = a; a = b; b = t; }  // expand the smaller side
        Set<String> next = new HashSet<>();
        for (String word : a) {
            char[] w = word.toCharArray();
            for (int i = 0; i < w.length; i++) {
                char orig = w[i];
                for (char ch = 'a'; ch <= 'z'; ch++) {
                    if (ch == orig) continue;
                    w[i] = ch;
                    String s = new String(w);
                    if (b.contains(s)) return len;               // the frontiers met
                    if (dict.remove(s)) next.add(s);             // remove = visited
                }
                w[i] = orig;
            }
        }
        a = next;
    }
    return 0;
}
def ladder_length(begin: str, end: str, words: List[str]) -> int:
    """Bidirectional BFS: grow the SMALLER frontier one level at a time until it
    touches the other one. Returns the number of words in the ladder (0 if none)."""
    dict_ = set(words)
    if end not in dict_:
        return 0
    a, b = {begin}, {end}
    dict_.discard(begin)
    dict_.discard(end)
    length = 2
    while a and b:
        if len(a) > len(b):
            a, b = b, a                          # always expand the smaller side
        nxt = set()
        for w in a:
            for i in range(len(w)):
                for ch in "abcdefghijklmnopqrstuvwxyz":
                    if ch == w[i]:
                        continue
                    s = w[:i] + ch + w[i + 1:]
                    if s in b:
                        return length            # the frontiers met
                    if s in dict_:
                        dict_.remove(s)          # remove = visited
                        nxt.add(s)
        a = nxt
        length += 1
    return 0

Bidirectional BFS needs a known single target and reversible moves (if A can reach B in one step, B can reach A), which holds for word ladder, open the lock, sliding puzzle and knight moves. It does not apply to multi-source problems or when the target is a condition ("any cell on the border") rather than a single state. For Word Ladder II (all shortest ladders), run BFS to build the layered parent graph first, then DFS backwards from the end to list the paths; generating paths during BFS runs out of memory.

From your world

Generating neighbours by changing one letter at a time instead of comparing every pair of words is the same trade you make when you hash on a key instead of scanning a list: 25 x L hash lookups per word versus N string compares. A common alternative builds buckets keyed by patterns like h*t, which is an inverted index.
