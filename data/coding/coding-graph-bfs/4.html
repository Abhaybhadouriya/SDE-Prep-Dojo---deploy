0-1 BFS: Dijkstra with a deque

When moves cost different amounts, plain BFS breaks: the first arrival is no longer the cheapest. Dijkstra fixes that with a priority queue, at O(E log V). When every edge costs only 0 or 1, you can keep the queue sorted for free with a deque:

  • Relax an edge of weight 0: the neighbour has the same distance as the current node, so push it to the front.
  • Relax an edge of weight 1: the neighbour is one more, so push it to the back.

The deque then always holds distances d at the front and d + 1 at the back, the same two-layer shape plain BFS has, so popping from the front always gives a smallest-distance node. Time O(V + E). Unlike plain BFS, a node can be improved after it was first seen, so keep a dist array and relax with dist[u] + w < dist[v], exactly as in Dijkstra.

  1. Start: dist[S] = 0, deque = [S]. Everything else is infinity.
  2. Pop S. A gets 1 (weight 1, push to the BACK). B gets 0 (weight 0, push to the FRONT).
  3. Pop B (front). B to A costs 0, so dist[A] improves from 1 to 0: push A to the FRONT. C gets 1, to the back. The old A entry is now stale (marked *).
  4. Pop A with distance 0. T gets 0 + 1 = 1, pushed to the back.
  5. Pop the stale A. Relaxing its edges improves nothing, so it does no harm. (Some versions skip it explicitly by storing the distance with the entry.)
  6. Pop C. C to T would give 1 + 0 = 1, not better than 1. Nothing pushed.
  7. Pop T. The deque is empty: dist[T] = 1 (S, B, A, T). The deque stayed sorted by distance the whole time, which is all Dijkstra's heap was for.

Typical disguises: "minimum number of walls to remove" (LeetCode 2290, free cell = 0, obstacle = 1), "minimum arrow changes so a path exists" (LeetCode 1368, follow the arrow = 0, change it = 1), or "minimum reversed edges" in a directed graph (original direction 0, reversed 1).

// minimumObstacles: 0-1 BFS. Weights are only 0 or 1, so a deque replaces
// Dijkstra's heap: weight-0 neighbours go to the FRONT, weight-1 to the BACK.
// Go has no deque: keep a "front" stack (top = front of the deque) and a
// "back" queue; everything in front comes before everything in back.
func minimumObstacles(g [][]int) int {
	R, C := len(g), len(g[0])
	dist := make([][]int, R)
	for i := range dist {
		dist[i] = make([]int, C)
		for j := range dist[i] {
			dist[i][j] = math.MaxInt32
		}
	}
	var front, back [][2]int
	bi := 0 // next unread index in back
	popFront := func() [2]int {
		if n := len(front); n > 0 {
			v := front[n-1]
			front = front[:n-1]
			return v
		}
		v := back[bi]
		bi++
		return v
	}

	dist[0][0] = 0
	back = append(back, [2]int{0, 0})
	for len(front) > 0 || bi < len(back) {
		cell := popFront()
		r, c := cell[0], cell[1]
		for _, d := range dirs {
			nr, nc := r+d[0], c+d[1]
			if nr < 0 || nr >= R || nc < 0 || nc >= C {
				continue
			}
			w := g[nr][nc]
			if dist[r][c]+w >= dist[nr][nc] { // relax like Dijkstra
				continue
			}
			dist[nr][nc] = dist[r][c] + w
			if w == 0 {
				front = append(front, [2]int{nr, nc}) // to the front
			} else {
				back = append(back, [2]int{nr, nc}) // to the back
			}
		}
	}
	return dist[R-1][C-1]
}
// 0-1 BFS: edge weights are only 0 or 1. A deque replaces Dijkstra's heap:
// weight-0 neighbours go to the FRONT, weight-1 neighbours to the BACK.
// Minimum Obstacle Removal to Reach Corner (0 free = cost 0, 1 obstacle = cost 1).
int minimumObstacles(const vector<vector<int>>& g) {
    int R = g.size(), C = g[0].size();
    vector<vector<int>> dist(R, vector<int>(C, INT_MAX));
    deque<pair<int, int>> dq;
    dist[0][0] = 0;
    dq.push_back({0, 0});
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    while (!dq.empty()) {
        int r = dq.front().first, c = dq.front().second; dq.pop_front();
        for (int d = 0; d < 4; d++) {
            int nr = r + dr[d], nc = c + dc[d];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            int w = g[nr][nc];
            if (dist[r][c] + w >= dist[nr][nc]) continue;   // relax like Dijkstra
            dist[nr][nc] = dist[r][c] + w;
            if (w == 0) dq.push_front({nr, nc});
            else dq.push_back({nr, nc});
        }
    }
    return dist[R - 1][C - 1];
}

static int minimumObstacles(int[][] g) {
    int R = g.length, C = g[0].length;
    int[][] dist = new int[R][C];
    for (int[] row : dist) Arrays.fill(row, Integer.MAX_VALUE);
    ArrayDeque<int[]> dq = new ArrayDeque<>();
    dist[0][0] = 0;
    dq.addLast(new int[]{0, 0});
    while (!dq.isEmpty()) {
        int[] cell = dq.pollFirst();
        int r = cell[0], c = cell[1];
        for (int d = 0; d < 4; d++) {

def minimum_obstacles(g: List[List[int]]) -> int:
    """0-1 BFS: weights are only 0 or 1, so a deque replaces Dijkstra's heap.
    Weight-0 neighbours go to the FRONT, weight-1 neighbours to the BACK."""
    R, C = len(g), len(g[0])
    INF = float("inf")
    dist = [[INF] * C for _ in range(R)]
    dist[0][0] = 0
    dq = deque([(0, 0)])
    while dq:
        r, c = dq.popleft()
        for dr, dc in DIRS:
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C:
                w = g[nr][nc]
                if dist[r][c] + w < dist[nr][nc]:    # relax like Dijkstra
                    dist[nr][nc] = dist[r][c] + w
                    if w == 0:
                        dq.appendleft((nr, nc))
                    else:
                        dq.append((nr, nc))
    return dist[R - 1][C - 1]
