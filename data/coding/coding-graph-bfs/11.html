Quiz

Why should a grid BFS mark a cell visited when it is pushed rather than when it is popped?

  1. Otherwise several neighbours can push the same cell, multiplying the work and memory
  2. Marking on pop gives wrong distances in every case
  3. Popping is slower than pushing
  4. The queue cannot hold duplicates
Distances stay correct, but a cell can be enqueued up to 4 times (or many more in dense graphs), which can time out or run out of memory.

01 Matrix asks for each cell's distance to the nearest 0. What do you put in the queue first?

  1. Every 1-cell
  2. The top-left cell
  3. Every 0-cell, at distance 0
  4. The cell with the largest value
The zeros are the sources; one multi-source BFS gives every cell its distance to the nearest zero in O(R x C).

In Shortest Path with Obstacles Elimination, what is the BFS state?

  1. (row, col)
  2. (removals left)
  3. (row, col, removals left)
  4. (row, col, steps taken)
Steps are the BFS level, not part of the state. Removals left changes what you can do next, so it is part of the state.

In 0-1 BFS, where does a neighbour reached by a weight-0 edge go?

  1. The back of the deque
  2. A separate queue
  3. Nowhere; weight-0 edges are skipped
  4. The front of the deque
It has the same distance as the node just popped, so it must be processed before anything at distance + 1.

Bidirectional BFS: which frontier do you expand at each round?

  1. Always the start side
  2. Both, one node each
  3. The larger of the two
  4. The smaller of the two
Expanding the smaller frontier keeps the work near 2 bd/2, which is the whole point.

Rotting Oranges on a grid where every orange is already rotten. What should the answer be?

  1. 1
  2. -1
  3. The number of oranges
  4. 0
No fresh orange exists, so zero minutes are needed. Loop only while fresh oranges remain, or you return 1.

Edges cost 1, 2 or 5. Which algorithm fits best?

  1. DFS with memoisation
  2. Plain BFS
  3. Dijkstra (or Dial's buckets for small integer costs)
  4. 0-1 BFS
Plain BFS needs equal costs and 0-1 BFS needs costs 0 or 1. Arbitrary non-negative costs call for Dijkstra.
