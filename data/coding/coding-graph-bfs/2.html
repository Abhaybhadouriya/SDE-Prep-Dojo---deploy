Multi-source BFS: rotting oranges, 01 matrix, walls and gates

Many grid problems ask for the distance from each cell to the nearest of many sources: the nearest rotten orange, the nearest 0, the nearest gate, the nearest land. Running one BFS per source costs O(sources x R x C). Instead, push every source into the queue at distance 0 before the loop starts, then run one ordinary BFS. The rings from all sources grow together, and each cell is claimed by whichever ring reaches it first, which is the nearest source.

Here is Rotting Oranges (LeetCode 994) on a 3 x 3 grid. Every minute, every rotten orange infects its fresh neighbours; we want the minutes until nothing fresh is left, or -1 if some orange can never be reached. Each BFS level is one minute:

  1. Minute 0: every rotten orange goes into the queue first. Here there is one, at (0,0). Count the fresh ones: 6.
  2. Minute 1: pop the whole level; its fresh neighbours (0,1) and (1,0) rot and are pushed. Mark them when pushing so nobody pushes them twice.
  3. Minute 2: (0,2) and (1,1) rot. (1,1) is next to both (0,1) and (1,0), but it was pushed once because it was marked on the first push.
  4. Minute 3: only (2,1) is reachable from the level-2 cells.
  5. Minute 4: (2,2) rots. Fresh count reaches 0.
  6. Done: the answer is the number of levels after the first one, 4. If fresh were still above 0, the answer would be -1.

// orangesRotting: multi-source BFS, level by level (0 empty, 1 fresh, 2 rotten).
// Every rotten cell starts in the queue at time 0; each level = one minute.
func orangesRotting(g [][]int) int {
	R, C := len(g), len(g[0])
	q := [][2]int{}
	fresh, minutes := 0, 0
	for r := 0; r < R; r++ {
		for c := 0; c < C; c++ {
			if g[r][c] == 2 {
				q = append(q, [2]int{r, c}) // all sources at distance 0
			} else if g[r][c] == 1 {
				fresh++
			}
		}
	}
	for len(q) > 0 && fresh > 0 {
		next := [][2]int{} // one slice per level: no size freezing needed
		for _, cell := range q {
			for _, d := range dirs {
				nr, nc := cell[0]+d[0], cell[1]+d[1]
				if nr < 0 || nr >= R || nc < 0 || nc >= C || g[nr][nc] != 1 {
					continue
				}
				g[nr][nc] = 2 // mark when PUSHED, not when popped
				fresh--
				next = append(next, [2]int{nr, nc})
			}
		}
		q = next
		minutes++
	}
	if fresh > 0 {
		return -1
	}
	return minutes
}
// Multi-source BFS, level by level (Rotting Oranges: 0 empty, 1 fresh, 2 rotten).
// Every rotten cell starts in the queue at time 0; each level = one minute.
int orangesRotting(vector<vector<int>>& g) {
    int R = g.size(), C = g[0].size(), fresh = 0, minutes = 0;
    queue<pair<int, int>> q;
    for (int r = 0; r < R; r++)
        for (int c = 0; c < C; c++) {
            if (g[r][c] == 2) q.push({r, c});        // all sources at distance 0
            else if (g[r][c] == 1) fresh++;
        }
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    while (!q.empty() && fresh > 0) {
        for (int n = q.size(); n > 0; n--) {          // freeze the level size
            int r = q.front().first, c = q.front().second; q.pop();
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr < 0 || nr >= R || nc < 0 || nc >= C || g[nr][nc] != 1) continue;
                g[nr][nc] = 2;                        // mark when PUSHED, not when popped
                fresh--;
                q.push({nr, nc});
            }
        }
        minutes++;
    }
    return fresh == 0 ? minutes : -1;
}

static int orangesRotting(int[][] g) {
    int R = g.length, C = g[0].length, fresh = 0, minutes = 0;
    ArrayDeque<int[]> q = new ArrayDeque<>();
    for (int r = 0; r < R; r++)
        for (int c = 0; c < C; c++) {

            else if (g[r][c] == 1) fresh++;
        }

        for (int n = q.size(); n > 0; n--) {             // freeze the level size

}
def oranges_rotting(g: List[List[int]]) -> int:
    """Multi-source BFS, level by level (0 empty, 1 fresh, 2 rotten).
    Every rotten cell starts in the queue at time 0; each level = one minute."""
    R, C = len(g), len(g[0])
    q = deque((r, c) for r in range(R) for c in range(C) if g[r][c] == 2)
    fresh = sum(row.count(1) for row in g)
    minutes = 0
    while q and fresh:
        for _ in range(len(q)):                  # freeze the level size
            r, c = q.popleft()
            for dr, dc in DIRS:
                nr, nc = r + dr, c + dc
                if 0 <= nr < R and 0 <= nc < C and g[nr][nc] == 1:
                    g[nr][nc] = 2                # mark when PUSHED, not when popped
                    fresh -= 1
                    q.append((nr, nc))
        minutes += 1
    return minutes if fresh == 0 else -1

Wrong turn people take on 01 Matrix: BFS from every 1-cell to find its nearest 0. That is O((R x C)2). Flip it: the 0-cells are the sources. "Distance from every X to the nearest Y" almost always means "start from all Y".
