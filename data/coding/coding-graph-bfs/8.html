Practice problems (in this order)

Each link opens our write-up page with the full problem, hints and code. "Premium" marks problems that need a LeetCode subscription to submit.

Grid BFS basics

  • Number of Islands Medium - BFS flood fill; mark on push.
  • Shortest Path in Binary Matrix Medium - 8 directions, distance counts cells.
  • Nearest Exit from Entrance in Maze Medium - the target is a condition (border cell), not a cell.
  • Snakes and Ladders Medium - BFS on a 1-D board with jumps; the boustrophedon index mapping is the hard part.
  • Jump Game III Medium - BFS on array indices.

Multi-source

  • Rotting Oranges Medium - the stepper above.
  • 01 Matrix Medium - start from the zeros.
  • Walls and Gates Medium Premium - start from the gates, fill in place.
  • As Far from Land as Possible Medium - the last level reached.
  • Map of Highest Peak Medium - heights are distances from water.
  • Shortest Bridge Medium - DFS one island, BFS out from all of it.
  • Pacific Atlantic Water Flow Medium - two reverse searches from the two oceans' borders.
  • Shortest Distance from All Buildings Hard Premium - one BFS per building, summed: when multi-source does not apply.

State BFS

  • Open the Lock Medium - strings as states, dead ends pre-visited.
  • Minimum Genetic Mutation Medium - word ladder with a 4-letter alphabet.
  • Word Ladder Hard - plain BFS first, then bidirectional.
  • Shortest Path in a Grid with Obstacles Elimination Hard - (r, c, breaks left).
  • Sliding Puzzle Hard - the board as a 6-character string.
  • Minimum Knight Moves Medium Premium - use symmetry (fold into the first quadrant) or bidirectional BFS.
  • Bus Routes Hard - BFS over routes, not stops.
  • Shortest Path to Get All Keys Hard - keys as a bitmask in the state.
  • Shortest Path Visiting All Nodes Hard - multi-source and bitmask state together.

0-1 BFS and bidirectional

  • Minimum Obstacle Removal to Reach Corner Hard - the deque template.
  • Minimum Cost to Make at Least One Valid Path in a Grid Hard - follow the arrow = 0, change it = 1.
  • Word Ladder II Hard - BFS for the layered parent graph, then DFS back for the paths.
