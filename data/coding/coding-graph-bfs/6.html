How to recognise these problems

Cue in the statementTool
"minimum number of steps / moves / minutes", every move costs the sameBFS (never DFS)
"distance from every cell to the nearest X", "spreads every minute from all X"Multi-source BFS from all X
"you may remove up to k", "you hold keys", "with a coupon / jump / fuel left"State BFS: add the extra resource to the state
"the board / lock / string changes one piece at a time", "minimum moves to reach this configuration"BFS over configurations as strings or integers
"minimum number of walls to break", "minimum changes so a path exists"0-1 BFS (cost 0 to move, 1 to break or change)
Known start and known single target, huge branching factorBidirectional BFS
Weights are arbitrary non-negative numbersDijkstra, not BFS (see the graphs primer)
"is there any path", "count regions", "fill a region"BFS or DFS, either works; DFS is shorter to write
