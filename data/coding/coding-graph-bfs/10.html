Remember this

Revision card

  • Cue: Fewest moves / steps / minutes on a grid or puzzle, "nearest X from every cell".
  • Insight: When every move costs the same, BFS reaches each state first by a shortest path.
  • State: queue of states, seen set marked on push, dist by levels; state = position + whatever changes the next move.
  • Trap: Marking on pop (queue blow-up); leaving keys or obstacles-removed out of the state.
  • Cost: O(states x moves); 0-1 BFS with a deque for costs 0 and 1.

More to remember

  • BFS gives shortest paths only when every move costs the same. First arrival = shortest.
  • Mark visited on push. Freeze the queue size for level counting.
  • "Nearest X from everywhere" = push all X at distance 0 (multi-source).
  • If anything besides position changes what you can do next, it belongs in the state. State count = time bound.
  • Costs 0 or 1: deque, 0 to the front, 1 to the back, with a dist array. O(V + E).
  • Known start and single target with big branching: bidirectional, always expand the smaller frontier.
  • Generate neighbours on the fly; never build the graph of all pairs.
