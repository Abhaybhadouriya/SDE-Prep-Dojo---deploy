Pattern 1: matching brackets

Valid Parentheses (LeetCode 20) is the most-asked stack question in our company data. The rule: an opening bracket is pushed and waits. A closing bracket must match the bracket on top, because the most recently opened group must close first. At the end, the stack must be empty, or some group never closed.

  1. ( is an opener: push it. It waits for its partner.
  2. [ is an opener: push. Now [ is the most recent unclosed group.
  3. ] must close the most recent group. The top is [: match, pop.
  4. {: push.
  5. } matches the top {: pop.
  6. ) matches the top (: pop.
  7. End of string with an empty stack: every group closed in the right order, so the string is valid. A leftover item would mean "unclosed"; a closer with an empty stack or a wrong top means "invalid" immediately.

The loop behind the steps. Invariant: the stack holds the openers not yet closed, newest on top; every closer must match the top, and the string is valid only if the stack ends empty. Lifted unchanged from the tested templates below.

// BEGIN TEMPLATE
// 1. Matching brackets: push openers, pop on a closer and compare.
bool isValid(const string& s) {
    vector<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') { st.push_back(c); continue; }
        char want = c == ')' ? '(' : c == ']' ? '[' : '{';
        if (st.empty() || st.back() != want) return false;   // check empty BEFORE top
        st.pop_back();
    }
    return st.empty();                                       // leftovers = unclosed
}
# BEGIN TEMPLATE
def is_valid(s: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    st = []
    for c in s:
        if c in "([{":
            st.append(c)
        elif not st or st.pop() != pairs[c]:     # empty check comes first
            return False
    return not st                                 # leftovers = unclosed

Variations change what you push. Minimum Remove to Make Valid Parentheses (1249) pushes the index of each (; unmatched ) indices and the indices left on the stack are the characters to delete. Longest Valid Parentheses (32) pushes indices too, and keeps the index of the last unmatched ) at the bottom as a "wall" so that i - top is the length of the current valid run. Minimum Add to Make Valid (921) needs no stack at all: with only one bracket type, a counter of open brackets is the stack.

One bracket type: a counter is enough. Several types, or you need positions: you need a real stack.
