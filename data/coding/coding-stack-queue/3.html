Pattern 2: cancelling adjacent items

Some questions remove pairs that touch, and a removal can make two new items touch: in abbaca, removing bb makes aa adjacent. Re-scanning the string after each removal is O(n^2). A stack does it in one pass: the stack holds the processed text with no cancellable pair in it, and each new character is compared only with the top.

  • Remove All Adjacent Duplicates in String (1047): same character as the top cancels it. Use the output string builder itself as the stack.
  • ... II (1209): remove runs of k equal characters. Push (char, count) pairs; when a count reaches k, pop.
  • Removing Stars From a String (2390): a * pops the top. Backspace String Compare is the same with #.
  • Simplify Path (71): split by /; a name is pushed, .. pops (if not empty), . and empty parts are ignored. Join with /.
  • Asteroid Collision (735): a left-moving asteroid may destroy several right-movers on top before it settles or dies, so the comparison is a while, not an if.

"A loop inside a loop but still O(n)" is the amortised argument every stack question needs: each item is pushed once and popped at most once, so the total work of all inner loops together is at most n. Say this sentence out loud whenever you write a while that pops.
