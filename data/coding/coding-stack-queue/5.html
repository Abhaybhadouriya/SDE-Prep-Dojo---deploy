Pattern 4: nested decode

Decode String (394) expands 3[a2[c]] into accaccacc. When you meet [, you are starting an inner string, but you still owe the outer one: you must remember the text built so far and the repeat count in front of the bracket. Push both and start fresh. On ], pop them and set current = savedText + current * count.

Counts can have several digits (10[a]), so build the number with k = k * 10 + digit and reset it after pushing. The same shape appears in Number of Atoms (726, multiply counts of a bracketed group), Exclusive Time of Functions (636, a log of nested start/end events where the stack holds running function ids), and Reverse Substrings Between Each Pair of Parentheses (1190).

From your world

Exclusive Time of Functions is a profiler built from start/end trace events, exactly like reading an ftrace function-graph log: when a child starts, the parent's running time pauses; when the child ends, the parent resumes. The stack holds the call chain, and "self time" is what perf report --no-children shows.
