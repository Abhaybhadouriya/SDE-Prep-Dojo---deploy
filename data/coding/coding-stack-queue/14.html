Remember this

Revision card

  • Cue: Brackets, calculators, decode strings, undo, "next greater", process in arrival order.
  • Insight: A stack resolves the newest unresolved item next; a queue the oldest.
  • State: stack of openers or (count, text) pairs; pending operator and last term for calculators.
  • Trap: top() on an empty stack; not checking the stack is empty at the end; unary minus.
  • Cost: O(n) time, O(n) space.

More to remember

  • Stack = the newest unresolved item is resolved next. Queue = the oldest. Deque = old items expire at one end, dominated items leave at the other.
  • Matching: push openers, check empty before top, require empty at the end.
  • Calculator: apply the pending operator when a number ends; * and / change the last term; recurse on brackets.
  • Nested decode: push (count, text so far) on [.
  • Monotonic stack: indices waiting for an answer; each pushed once, popped once: O(n).
