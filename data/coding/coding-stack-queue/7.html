Introduction to the monotonic deque

Sliding Window Maximum (239): report the maximum of every window of size k. A heap gives O(n log n). The monotonic deque gives O(n). Keep indices in a deque with values decreasing from front to back. For each new index i: drop the front if it has slid out of the window (front <= i - k); pop from the back every index whose value is <= the new value, because the new value is both bigger and will stay in the window longer, so those can never be a maximum again; push i at the back. The front is now the window's maximum.

Use a deque (not a stack) when the window has a left edge that moves: old items leave from the front while dominated items leave from the back. The same structure solves "longest subarray where max - min <= limit" (1438, keep one max-deque and one min-deque) and "shortest subarray with sum at least K" (862, a deque of prefix sums).
