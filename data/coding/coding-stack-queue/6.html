Introduction to the monotonic stack

"For every element, find the next element to the right that is greater" (Next Greater Element, Daily Temperatures 739, Online Stock Span 901) looks like O(n^2): for each i scan right. The monotonic stack makes it O(n). Keep a stack of indices that are still waiting for their answer. Their values are decreasing from bottom to top, because if a bigger value had arrived, it would already have answered the smaller ones below it. When a new value arrives, it is the answer for every waiting index with a smaller value: pop them and record the answer. Then push the new index; it now waits.

  1. i=0, value 2: nothing to compare. Push index 0; it waits for something bigger.
  2. i=1, value 1: not bigger than the top (2). Push 1. The stack values are decreasing: 2, 1.
  3. i=2, value 5: bigger than the top (1), pop it, answer 5; bigger than the new top (2), pop, answer 5. Push 2.
  4. i=3, value 3: smaller than 5. Push 3. Stack values 5, 3.
  5. i=4, value 4: bigger than 3, pop index 3 with answer 4; not bigger than 5, stop. Push 4.
  6. End: the indices still waiting (values 5 and 4) have no greater element to their right: answer -1. Every index was pushed once and popped at most once: O(n).

The loop behind the steps. Invariant: the stack holds indexes still waiting for a greater value, with decreasing values; each index is pushed once and popped at most once, so the loop is O(n). Lifted unchanged from the tested templates below.

// 7. Monotonic stack: index of the next strictly greater element, or -1.
//    The stack holds indices still waiting for their answer; values decrease bottom->top.
vector<int> nextGreaterIndex(const vector<int>& a) {
    vector<int> ans(a.size(), -1), st;
    for (int i = 0; i < (int)a.size(); ++i) {
        while (!st.empty() && a[st.back()] < a[i]) { ans[st.back()] = i; st.pop_back(); }
        st.push_back(i);
    }
    return ans;
}
def next_greater_index(a: List[int]) -> List[int]:
    ans, st = [-1] * len(a), []                   # st: indices waiting for an answer
    for i, x in enumerate(a):
        while st and a[st[-1]] < x:
            ans[st.pop()] = i
        st.append(i)
    return ans

Four knobs give the whole family: greater or smaller (flip the comparison), next or previous (the previous greater of i is whatever is on the stack right before you push i), strict or not (< versus <= when popping, important with duplicates), and circular (Next Greater Element II, 503: loop twice over the array with i % n). The harder members, Largest Rectangle in Histogram (84), Sum of Subarray Minimums (907), Remove K Digits (402) and Trapping Rain Water, use the same loop but need their own page; this is the foundation.

Daily Temperatures asks for the distance to the next warmer day: record i - popped instead of the value. Store indices, not values, on the stack; you can always read the value as a[index], but not the other way round.
