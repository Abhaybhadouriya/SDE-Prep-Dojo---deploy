Which input does a bracket checker reject only at the final "stack must be empty" check?

  1. )(
  2. ((
  3. (]
"((" never sees a closer, so nothing fails during the scan; two openers are left on the stack.

In Reverse Polish evaluation of a b -, what is the first value popped?

  1. b, the right operand
  2. It does not matter
  3. a, the left operand
b was pushed last, so it comes off first; compute a - b.

In the pending-operator calculator, what happens when the number ends and the pending operator is *?

  1. Multiply the top term by the number
  2. Push the number
  3. Push the number and the operator
* and / change the last term, which is how they bind tighter than + and -.

Decoding 2[ab]: what is pushed at [?

  1. The pair (2, text built so far)

  3. The letter a

Why is a monotonic stack solution O(n) even with a while loop inside the for loop?

  1. The stack never holds more than 2 items
  2. The while loop runs at most once per element
  3. Each index is pushed once and popped at most once overall
The inner loop's total work across the whole run is bounded by the number of pushes.
