Common mistakes

Pushing temperatures instead of indices. You then cannot compute day - prev or know which slot to fill. Push the index; read the temperature through it.

Using <= in the pop condition. That treats an equal day as warmer: [50,50,51] would give [1,1,0]. Strict < for "strictly warmer".

Writing the answer for today when you push. Today's answer is unknown when it is pushed; it is written by a future day when it is popped.

Java Stack<Integer> on 105 items. It works, but Stack is synchronised and boxes every int. Use ArrayDeque or an int[] with a top index.
