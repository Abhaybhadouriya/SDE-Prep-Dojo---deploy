The problem (in our words)

You get an integer array temperatures, where temperatures[i] is the temperature on day i. Return an array answer of the same length where answer[i] is the number of days you must wait after day i to reach a day that is strictly warmer. If no later day is warmer, answer[i] = 0.

Signature: int[] dailyTemperatures(int[] temperatures).

  • 1 <= temperatures.length <= 105
  • 30 <= temperatures[i] <= 100

Practice it: LeetCode 739 · GfG Next Greater Element (same engine, returns the value)

Constraints tell you: n up to 105, so the O(n²) "scan forward from every day" is up to 5·109 steps on a falling sequence and times out. Temperatures live in a tiny range (71 values), which opens a second O(n·71) idea, but the expected answer is the O(n) stack.
