Interview follow-ups

Why is a while loop inside a for loop still O(n)?

Each index enters the stack once and leaves it at most once. The total number of inner-loop iterations over the whole run is therefore at most n, so the whole algorithm is at most 2n stack operations.

How to answer

Count work per element (one push, at most one pop), not per loop.

Likely follow-ups
  • Worst case for a single day? (O(n) pops, e.g. a long falling run then a hot day, but it happens once.)
Can you do it without the extra stack?

Yes: the backward hop (rung 3b). Scan from the right; for day i follow j = i+1, then j += answer[j] while t[j] <= t[i] and answer[j] > 0. Only the output array is used.

How to answer

Justify the skip: everything between j and j+answer[j] is no warmer than t[j], hence no warmer than t[i].

Likely follow-ups
  • Is it still linear? (Yes, amortised: the hops are the pops of a right-to-left stack.)
Return the temperature of the next warmer day instead of the wait.

Same loop; on pop write t[day] into res[prev], and initialise res with -1 (or any "none" marker). That is the classic next-greater-element problem.

How to answer

Point out that only the write on pop changes.

Likely follow-ups
  • Circular week? (Loop i over 0..2n-1 using i % n; push only when i < n.)
Readings arrive as a stream and you must answer "how many past days were not warmer than today" on each arrival.

That is Online Stock Span. Keep a stack of (temperature, span) pairs. For a new reading pop every pair with temperature <= today and add their spans to today's span (starting at 1); push (today, span). Amortised O(1) per reading.

How to answer

Show that the popped days can be merged because any future warmer day also covers them.

Likely follow-ups
  • The original question online? (Not possible to answer each day when it arrives: its answer depends on the future. You can only emit answers when they resolve, which is what the stack does.)
Answer "first warmer day after day i, but only among the next k days".

Run the normal algorithm and replace any answer greater than k with 0: the first warmer day is unique, so if it is beyond k there is none within k. Still O(n).

How to answer

Avoid reaching for a sliding-window deque; the window does not change which day is first.

Likely follow-ups
  • The hottest day within the next k days? (That one needs the monotonic deque of Sliding Window Maximum.)
