Recognise the pattern

Cue: "for each element, the nearest element to the right (or left) that is bigger (or smaller)" -> monotonic stack. Asking for the distance, the index or the value only changes what you write when you pop.

Four flavours, one loop; only the comparison and the scan direction change:

QuestionStack keepsPop while
Next strictly greater to the right (this problem)decreasing valuesa[top] < a[i]
Next greater or equalstrictly decreasinga[top] <= a[i]
Next smaller to the rightincreasing valuesa[top] > a[i]
Previous greater (stock span)decreasing valuespop smaller, then the top is the answer for i
