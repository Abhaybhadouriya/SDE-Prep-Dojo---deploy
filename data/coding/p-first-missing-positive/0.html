The story

Explain like I'm 5

A cloakroom has 4 hooks numbered 1 to 4, and guests hand in tags with random numbers on them: 4, -2, 1, 3. Hang each tag on the hook with its number, if that hook exists. Tags like -2 or 99 have no hook, so they are put anywhere. Now walk along the hooks: the first hook without its own tag is the smallest number nobody has. Here hook 2 is empty, so the answer is 2.

From your world

It is the smallest free PID, file descriptor or port problem: the kernel hands out the lowest unused fd. A bitmap of size n finds it in O(n), and here the input array itself plays the bitmap, the way an in-place algorithm reuses a buffer instead of allocating one. The "only 1..n matter" step is the same bound check you do before indexing a table with a value from the wire.
