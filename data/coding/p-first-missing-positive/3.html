Recognise the pattern

Cue: "missing / duplicate number" + the values that matter fit in 1..n + "O(1) extra space" -> use the indexes as the hash: either cyclic sort (swap each value home) or sign marking (negate slot v-1). The "first missing positive" twist: first throw away what is outside 1..n.

Try a few by hand (n = 3):

numsValues in 1..3Answer
[1,2,3]1, 2, 34 = n + 1 (the only case above n)
[3,3,3]31 (duplicates waste slots)
[7,-1,2]21
[1,5,2]1, 23
