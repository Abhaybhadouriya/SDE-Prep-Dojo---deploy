Common mistakes

Guarding with i != nums[i]-1 instead of comparing values. For [1,1] the second 1 is not at home, its home holds 1, and the loop swaps two equal values forever. Compare nums[nums[i]-1] != nums[i].

Python: nums[i], nums[nums[i]-1] = nums[nums[i]-1], nums[i]. The left side is assigned left to right, so nums[i] changes before the second target index is computed and the wrong slot is written. Save h = nums[i]-1 first.

Advancing i after one swap. The value that arrives at i must be placed too; use while, not if.

Sign marking without the clean-up pass. Input negatives then look like "seen" marks, and 0 cannot be negated. Replace everything outside 1..n by n + 1 first.

Returning n instead of n + 1 when every slot is correct, or returning 0 for an empty-looking result: the answer is always ≥ 1.
