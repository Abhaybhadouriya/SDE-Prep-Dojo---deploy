The problem (in our words)

You are given an integer array nums sorted in non-decreasing order. Every value occurs exactly twice, except one value that occurs exactly once. Return that single value.

Your solution must run in O(log n) time and use O(1) extra space.

Signature: int singleNonDuplicate(int[] nums).

Constraints:

  • 1 <= nums.length <= 105
  • 0 <= nums[i] <= 105
  • nums is sorted; exactly one value appears once and all others appear twice.

Practice it: LeetCode 540 · GfG Single Among Doubles in a Sorted · TUF article

Constraints tell you: the length is always odd (2k + 1), so the last index is even. An O(n) scan or XOR passes the judge, but the statement explicitly demands O(log n): the interviewer wants the binary search, and will stop you if you open with XOR as the final answer.
