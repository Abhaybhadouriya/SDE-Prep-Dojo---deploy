The story

Explain like I'm 5

You are sending several notes to a friend through one long paper tube, glued end to end. If you separate them with a star, a note that itself contains a star gets cut in the wrong place. Instead, write a number before each note: "5" then the note "hello". Your friend reads the number, counts out exactly five letters, and knows the next thing is the next number. What the note says no longer matters.

From your world

This is message framing on a byte stream. TCP has no message boundaries, so protocols use a length header (HTTP/2 frames, gRPC's 4-byte length prefix, netlink's nlmsg_len, TLV in many kernel interfaces) rather than a sentinel byte. Sentinels need escaping (byte stuffing in HDLC/PPP, or SLIP's ESC sequences) and cost a scan of every byte; a length prefix lets the reader jump straight to the next frame.
