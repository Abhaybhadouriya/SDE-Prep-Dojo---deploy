Common mistakes

Searching for the last '#' or splitting on '#'. Only the first '#' after the header start is safe. s.split("#") breaks as soon as a string contains '#'.

Searching from 0 every time. indexOf('#') without the start index i finds an old '#'. Always search from the current position.

Length in the wrong unit. In Go, len(s) is bytes and slicing is by bytes, which matches. In Java, length() counts UTF-16 units; encode and decode must use the same unit.

Treating [] and [""] the same. The plain join gives "" for both. The length prefix keeps them apart.

Using strlen / char* in C or C++. A NUL byte inside a string cuts it short. Use std::string with explicit lengths.
