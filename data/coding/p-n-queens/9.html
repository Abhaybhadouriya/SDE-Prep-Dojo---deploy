Revision card

  • Cue: all layouts, small n, pieces may not share a line -> backtracking.
  • Insight: one queen per row; a cell is safe iff col, r - c, r + c are all unused.
  • State: queenCol[r], col[n], diag[2n-1] (r - c + n - 1), anti[2n-1] (r + c).
  • Trap: undo all three flags; shift r - c; copy the board when recording.
  • Cost: O(n!) time, O(n) extra space; bitmasks cut the constant.
def dfs(r):
    if r == n: record(); return
    for choice in options(r):
        if not ok(choice): continue
        claim(choice); dfs(r + 1); release(choice)

Which diagonal index is shared by all cells on one '\' diagonal?

  1. r + c
  2. r - c (add n - 1 to keep it non-negative)
  3. r * c
Moving down-right adds 1 to both r and c, so r - c stays fixed; r + c is fixed on '/' diagonals.

Why place exactly one queen per row?

  1. Two queens in one row attack each other, so the row is the decision level
  2. It is faster to print
  3. Columns are checked later
That removes row checks entirely; only columns and the two diagonals need sets.

How many solutions does n = 5 have?

  1. 2
  2. 10
  3. 40
n = 4 has 2, n = 5 has 10, n = 6 has 4, n = 8 has 92.
