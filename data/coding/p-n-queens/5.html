Dry run

n = 4, until the first solution is found. Green = placed queen, red row = no safe column.

  1. Row 0, column 0 is free. Place it and mark column 0, diagonal r - c = 0, anti-diagonal r + c = 0.
  2. Row 1: c0 shares the column, c1 shares diagonal 0. c2 is free: place (1, 2).
  3. Row 2: c0 column, c1 anti-diagonal 3, c2 column, c3 diagonal -1. Nothing is safe: return and undo (1, 2).
  4. Row 1 tries c3: free. Row 2 then finds c1 free (r - c = 1, r + c = 3 unused). Place both.
  5. Row 3: every column is attacked. Row 2 has no further column either, nor row 1, so the search returns to row 0.
  6. Row 0 moves to c1. Row 1: c0 anti-diagonal, c1 column, c2 diagonal; c3 is free.
  7. Row 2: c0 is free (r - c = 2, r + c = 2). Place it.
  8. Row 3: c2 is free. All four rows are filled: record [".Q..", "...Q", "Q...", "..Q."], undo and keep searching (the mirror board comes from row 0 = c2).
