The problem (in our words)

Given an integer n, place n queens on an n x n chessboard so that no two queens attack each other (no two share a row, a column or a diagonal). Return all distinct placements, in any order.

Each placement is a board given as a list of n strings of length n: 'Q' marks a queen and '.' an empty square.

Signature: List<List<String>> solveNQueens(int n)

  • Constraints:
  • 1 <= n <= 9

Practice it: LeetCode 51 - N-Queens · GfG - N-Queen Problem

Constraints tell you: n <= 9 means exponential search is expected. 9! = 362,880 column orders, and pruning visits far fewer. The output itself is up to 352 boards (n = 9), so the cost is dominated by the search, not by copying.
