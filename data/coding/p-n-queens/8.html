Common mistakes

  • Forgetting the undo. Without clearing the three flags after the recursive call, later branches see ghost queens and miss solutions.
  • Indexing the "\" diagonal with r - c directly. It is negative for c > r; shift it by n - 1 (array of size 2n - 1) or use a hash set.
  • Arrays of size n for the diagonals. There are 2n - 1 diagonals in each direction; size n overflows the index for n >= 2.
  • Appending a reference to the shared board. In Python/Java, record a copy (new strings), or every stored board ends up as the last state (empty after undo).
  • Checking rows below the current one. Only earlier rows hold queens; the rows below are empty by construction.
