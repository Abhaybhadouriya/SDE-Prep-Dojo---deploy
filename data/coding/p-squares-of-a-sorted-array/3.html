Recognise the pattern

Cue: "sorted input + a transform that is monotone on each side of a point (square, abs, quadratic)" -> the results are two sorted runs; merge them with two pointers from the ends.

When you see "sorted array, apply f, return sorted", think "where does f change direction?". If it has one turning point, the extreme values are at the ends: fill the output from the back (or front) with two pointers.

When you see "merge two sorted sequences into one", think two read cursors and one write cursor.

Taxonomy: Two pointers → merge two sorted sequences. Pattern lesson: Two pointers.
