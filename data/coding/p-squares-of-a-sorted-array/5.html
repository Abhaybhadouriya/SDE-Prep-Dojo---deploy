Dry run

On [-5, -2, 0, 3, 4]. Grey cells are already consumed; green is the end that wins this step.

  1. lo = 0 (-5² = 25), hi = 4 (4² = 16). 25 > 16: the negative end wins. Write 25 at out[4], then lo++.
  2. lo = 1 (-2² = 4), hi = 4 (4² = 16). 16 >= 4: write 16 at out[3], then hi--.
  3. lo = 1 (-2² = 4), hi = 3 (3² = 9). 9 >= 4: write 9 at out[2], then hi--.
  4. lo = 1 (-2² = 4), hi = 2 (0² = 0). 4 > 0: the negative end wins. Write 4 at out[1], then lo++.
  5. lo = hi = 2: one element left, 0² = 0. It goes into slot 0 and the loop ends. Output: [0, 4, 9, 16, 25].
