Common mistakes

  • Wrong heap direction. k largest needs a min-heap; k smallest needs a max-heap. Check with a 3-element example before you code.
  • C++ comparator backwards. priority_queue puts on top the element that is "greatest" by your comparator. For a min-heap you pass greater<>, which feels upside down.
  • Java comparator overflow. (a, b) -> a - b breaks for large or negative values. Use Integer.compare(a, b) or Long.compare.
  • Python tuples with uncomparable payloads. (dist, node) where node is a ListNode crashes on equal distances. Add a unique counter: (dist, i, node).
  • Go: calling the method instead of the package function. h.Push(x) only appends; heap.Push(h, x) appends and sifts up.
  • 32-bit overflow in times. Meeting Rooms III and similar simulations add durations to end times. Use 64-bit.
