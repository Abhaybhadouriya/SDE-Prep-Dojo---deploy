The problem (in our words)

You get an m x n integer matrix shelf. Each cell is 0 (empty), 1 (good crate) or 2 (mouldy crate). Every minute, any good crate that is 4-directionally adjacent to a mouldy crate becomes mouldy. Return the minimum number of minutes that must pass until no cell holds a good crate. If that can never happen, return -1.

Signature: int orangesRotting(int[][] shelf)

  • Constraints:
  • m == shelf.length, n == shelf[i].length
  • 1 <= m, n <= 10
  • shelf[i][j] is 0, 1 or 2.

Practice it: LeetCode 994 - Rotting Oranges · GfG - Rotten Oranges · TUF article

Constraints tell you: at most 100 cells, so even a slow simulation passes on LeetCode. The interview still expects the O(m·n) BFS, because the follow-up is always "now the grid is 10^3 x 10^3".
