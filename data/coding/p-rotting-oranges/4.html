Approaches: brute → better → optimal

Hint 1

The minute at which a crate turns mouldy equals its grid distance (through non-empty cells) to the nearest mouldy crate.

Hint 2

BFS from one source gives distances to everything. How do you get the distance to the nearest of many sources in one run?

1. Brute force - simulate minute by minute

Idea: each minute, scan the whole grid, collect good crates next to a mouldy one, then flip them all (flip after the scan, or a crate turned this minute would spread in the same minute). Stop when nothing changes.

O((m·n)^2)time (up to m·n minutes, full scan each)
O(m·n)space

What is wasted: every minute rescans cells that cannot change. Only the neighbours of the crates that turned in the previous minute can turn now. -> keep that frontier in a queue.

2. Better - one BFS per mouldy crate

Idea: run a BFS from each source, keep best[cell] = min over sources; answer = max of best over good crates.

O(k·m·n)time for k sources
O(m·n)space

What is wasted: k separate floods of the same grid. Running them "in parallel" gives the same minimum in a single pass.

3. Optimal - multi-source BFS, level = minute

while q and fresh:
    for _ in range(len(q)):              # cells that turned last minute
        r, c = q.popleft()
        for nr, nc in neighbours(r, c):
            if grid[nr][nc] == 1:
                grid[nr][nc] = 2; fresh -= 1; q.append((nr, nc))
    minutes += 1
  1. Graph: cells are nodes; edges join 4-neighbours that are not empty.
  2. Traversal: start the queue with all mouldy crates (distance 0) and count the good ones.
  3. Visited rule: flip a crate to 2 when you push it, so it is queued once and counted once.
  4. Answer: process the queue one level at a time; each finished level is one minute. Stop when no good crate is left; if some remain when the queue empties, return -1.
O(m·n)time
O(m·n)space (queue)

Why it works: BFS from a set of sources visits cells in non-decreasing order of distance to the nearest source. That is the same as adding a virtual node S joined to every mouldy crate and running ordinary BFS from S (every distance shifts by one). A crate's turning minute is exactly that distance, so the last level reached is the answer.

Proof (optional)

By induction on t: after processing t levels, the cells marked are exactly those at distance at most t from some source. Level t + 1 consists of unmarked non-empty neighbours of level-t cells, which are precisely the cells at distance t + 1. Physically, a crate turns at minute t + 1 if and only if a neighbour turned at minute t, which is the same recurrence. So simulation and BFS agree, and unreachable crates (no path through non-empty cells) are never marked, which gives -1.
