Common mistakes

Adding the same island twice. A zero inside a bay touches one island from two or more sides. Collect neighbour ids in a set (or a 4-slot array with a duplicate check, as the C++ version does).

Using 1 as the first island id. Painted cells must be distinguishable from unpainted land; start ids at 2 and keep area[0] = area[1] = 0.

Forgetting the all-land grid. If there is no 0, pass 2 never updates best; initialise best with the largest island.

Recursive DFS on 500 x 500. Fine in C++ with a big stack on LeetCode, but a 250,000-deep recursion crashes Python and can crash Java. Use an explicit stack or BFS.
