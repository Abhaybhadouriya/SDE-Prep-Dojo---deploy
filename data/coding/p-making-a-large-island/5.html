Dry run

Example 1. Pass 1 paints three islands; pass 2 scores the zeros. Watch the two zeros that touch the same island twice.

  1. The grid. Pass 1 scans row by row; every time it meets an unpainted 1 it floods that whole island with a new id (2, 3, ...) and counts its cells.
  2. Flood from (0,0): cells (0,0), (0,1), (1,0) get id 2. area[2] = 3.
  3. Next unpainted 1 is (0,3): its island (0,3), (1,3), (2,3), (2,2) gets id 3, area[3] = 4.
  4. (3,0) is island 4 with area 1. Pass 1 is done: every land cell holds an id and the areas are in a table. best = 4.
  5. Pass 2 tries each 0. (1,1) touches island 2 twice (from above and from the left). A set of ids counts it once: 1 + 3 = 4.
  6. (1,2) touches island 3 from below and from the right. Without de-duplication you would report 9, larger than the true answer.
  7. (0,2) sits between island 2 and island 3: flipping it joins them. 1 + 3 + 4 = 8, the new best.
  8. The other zeros give at most 5: (2,0) joins islands 2 and 4 for 5, and (3,1) gives 2. Answer 8, found with two passes over the grid.
