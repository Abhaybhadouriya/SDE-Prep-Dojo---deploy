Interview follow-ups

You may flip up to k zeros instead of one.

It stops being local: the best set of flips can form a path through water. For small k it becomes a search over subsets of zeros (exponential); for k = 2 you can still score pairs of zeros near each other. Say clearly that the one-flip trick does not generalise and ask about the constraints.

How to answer

Explain why one flip is local (only 4 neighbours matter) and two flips are not.

Likely follow-ups
  • What if the k flipped cells must be adjacent to each other?
Flips arrive one at a time, and after each you must report the largest island.

Union-find with sizes and a running maximum: each new land cell becomes a set of size 1 and is unioned with its land neighbours; update max with the merged size. O(α(n)) per flip. Painting would need repainting after every merge.

How to answer

Name LC 305 as the related problem; this is where DSU beats painting.

Likely follow-ups
  • Now cells can also turn back into water (deletion is hard for DSU: offline reverse processing).
Islands connect 8-directionally (diagonals too).

Use 8 directions in both passes. The set of neighbour ids now has up to 8 entries; everything else is unchanged.

How to answer

Point to the single direction array as the only change.

Likely follow-ups
  • Does the "all land" answer change? (no)
Can you do it without modifying the input grid?

Keep a separate int label[n][n] (or a flat array of n2 ints) for the ids. Same O(n2) extra memory; the input is untouched, which matters if the caller reuses it.

How to answer

Mention it up front: interviewers like asking whether mutating input is acceptable.

Likely follow-ups
  • What is the peak memory of your explicit stack? (up to n2 cells)
Return the cell to flip, not just the size.

Track the argmax in pass 2. If there is no 0, say so (return -1 or any cell, as agreed). Ties: pick the first in row-major order unless told otherwise.

How to answer

Clarify the tie and no-zero behaviour before coding.

Likely follow-ups
  • Return all cells that achieve the maximum.
