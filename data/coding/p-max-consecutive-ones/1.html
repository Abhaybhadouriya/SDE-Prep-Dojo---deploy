The problem (in our words)

You get a binary array nums: every element is either 0 or 1. Return the length of the longest block of consecutive 1s in the array. If the array contains no 1, the answer is 0.

Signature: int findMaxConsecutiveOnes(int[] nums).

Constraints

  • 1 <= nums.length <= 10^5
  • nums[i] is either 0 or 1.

Practice it: LeetCode 485 - Max Consecutive Ones · GfG - Max Same Consecutive · TUF - Count maximum consecutive ones

Constraints tell you: n up to 105: an O(n2) "try every start" scan is about 5 * 109 steps on an all-1s array, too slow. One linear pass is the target, and the answer fits easily in an int.
