Dry run

On [1, 0, 1, 1, 1]: the longest run ends at the last index, which is where the bug in the last frame bites.

  1. i = 0: a 1, so run = 1. It beats the old best (0): best = 1, updated right here inside the loop.
  2. i = 1: a 0. The run breaks: run = 0. best stays 1 (a separate variable).
  3. i = 2: a 1, so run = 1. Not longer than best (1), so best stays.
  4. i = 3: a 1, so run = 2. It beats the old best (1): best = 2, updated right here inside the loop.
  5. i = 4: a 1, so run = 3. It beats the old best (2): best = 3, updated right here inside the loop. End of the array: the answer is 3, the run that touches the last index.
  6. The common bug: updating best only when a 0 arrives. The last run (3) is never followed by a 0, so it is never compared and the function returns 1. Update best on every 1 (as above), or do one more max after the loop.
