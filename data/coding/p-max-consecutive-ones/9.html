60-second recall

  • Cue: longest streak of 1s (or of anything) in a row.
  • State: run = streak ending here, best = best so far.
  • Step: 1 → run + 1; 0 → run = 0.
  • Trap: update best inside the loop (array may end on a 1).
  • Next: k flips allowed → sliding window counting zeros (LC 1004).
best = run = 0
for x in nums:
    run = run + 1 if x == 1 else 0
    best = max(best, run)

What does run hold after processing index i?

  1. The number of 1s in nums[0..i]
  2. The longest block so far
  3. The number of consecutive 1s ending exactly at i
best holds the longest block; run is the block ending here.

Which input breaks "update best only when you see a 0"?

  1. [1, 1, 1]
  2. [0, 1, 0]
  3. [0, 0]
No 0 ever closes the final run.

You may flip at most k zeros. What changes?

  1. Nothing; reset less often
  2. Use a window [l, r] with at most k zeros inside; shrink l when it has k + 1
  3. Sort the array first
That is LC 1004; LC 487 is the k = 1 case.
