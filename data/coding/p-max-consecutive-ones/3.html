Recognise the pattern

Cue: "longest run of elements that pass a test" -> one counter that resets on a failure, best updated inside the loop; with "flip up to k" -> sliding window.

When you see "longest run / streak of elements that satisfy a property", think a running counter that resets when the property fails, plus a best-so-far.

When you see "... if you may flip up to k zeros", think sliding window with a count of zeros inside (LC 1004).

This is the simplest form of "best value of something that ends at index i": the run ending at i is run(i-1) + 1 if nums[i] == 1, else 0, and the answer is the max over all i. Kadane's algorithm for maximum subarray has exactly this shape, with "+ x" instead of "+ 1" and "restart" instead of "reset to 0".

Taxonomy: Sliding window → longest valid window. Pattern lessons: Arrays & hashing, Sliding window (for the follow-ups).
