Common mistakes

Updating best only when a 0 is seen. Then [1, 1, 1] returns 0. Either update on every 1 or do a final max(best, run) after the loop.

Resetting run to 1 on a 0 (copy-paste from "count equal neighbours"). A 0 is not part of any run of 1s.

Reaching for a sliding window with two pointers. It works, but for this version it is more code and more ways to be off by one. Keep the window for the k-flips follow-up.
