Revision card

  • Cue: count splits of a string into 1- or 2-char valid pieces → prefix DP, Fibonacci style.
  • Insight: the last letter uses 1 digit (if 1..9) or 2 digits (if 10..26).
  • State: ways(i) for prefix length i; ways(0) = 1.
  • Trap: '0' alone is invalid; "0x" pairs are invalid (use >= 10).
  • Cost: O(n) time, O(1) space with two variables.
a, b = 1, int(s[0] != "0")         # ways(i-2), ways(i-1)
for i in range(1, len(s)):
    c = (b if s[i] != "0" else 0) + (a if "10" <= s[i-1:i+1] <= "26" else 0)
    a, b = b, c
return b

"1 2 6", "12 6", "1 26". ways = 1, 1, 2, 3.

Which two-digit pieces are valid codes?

  1. 01..26
  2. 00..26
  3. 1..26 written with two digits
  4. 10..26
A piece with a leading zero is not a code, so two-digit pieces are exactly 10..26.

What changes if '*' can stand for any digit 1-9 (Decode Ways II)?

  1. Same recurrence, but each gate becomes a multiplier (how many digit choices fit)
  2. You need backtracking
  3. The DP becomes 2-D
  4. Nothing
'*' alone has 9 choices; "1*" has 9 two-digit choices, "2*" has 6, "**" has 15. Multiply and take the result mod 1e9+7.
