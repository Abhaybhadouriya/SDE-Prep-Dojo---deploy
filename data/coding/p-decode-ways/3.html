Recognise the pattern

Cue: "count the ways to split a string into valid pieces" where each piece has a small, fixed length (1 or 2) → 1-D DP over prefixes, Fibonacci style. If pieces could be any length (Word Break), it is still prefix DP but with an inner loop.

Compare with Climbing Stairs (1 or 2 steps): here each step has a gate.

With all gates open (for example a string of 1s) the counts are exactly the Fibonacci numbers.
