Technique: count the ways to split a string into valid short pieces by adding the counts of the shorter prefixes each possible last piece leaves behind.

  • Same: the same prefix DP, last piece is 1 or 2 characters.
  • Different: '*' stands for any digit 1-9, so the answer is huge: return it mod 10^9 + 7.
  • So: replace each 0/1 gate with a count of valid choices (e.g. '*' alone = 9, "1*" = 9, "2*" = 6, "*x" = 2 or 1, "**" = 15) and multiply, using 64-bit arithmetic before the modulo.

How to recognise it:

  • "Count the ways to split / decode / segment a string" with a validity rule per piece.
  • The piece length is bounded by a small constant, so the DP looks back a fixed number of steps.

Practice order:

  1. Climbing Stairs, then this problem (table first, then two variables).
  2. Count Number of Texts (look back 3-4 steps), Word Break (look back any length).
  3. Decode Ways II, then Number of Ways to Separate Numbers.
