How to recognise it:

  • The output order is described geometrically (clockwise, layer, ring, snake, diagonal).
  • No search or optimisation: every cell is visited once, and the only difficulty is the bookkeeping.

Practice order:

  1. Warm-up: 59 Spiral Matrix II (square, write instead of read).
  2. This problem: boundaries with both guards; test 1×n and n×1.
  3. Harder twin: 885 Spiral Matrix III (outward walk with growing run lengths).
