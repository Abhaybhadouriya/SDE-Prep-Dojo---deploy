Interview follow-ups

Print it counter-clockwise, starting from the top-left going down.

Swap the roles: read the left column downwards, then the bottom row to the right, then the right column upwards (guarded by left <= right), then the top row to the left (guarded by top <= bottom). In the step-count version, change only the direction table.

How to answer

Say which guard goes with which side before coding: a row needs rows left, a column needs columns left.

Likely follow-ups
  • Start from the centre and go outward? (That is LC 885's walk.)
Return only the k-th element of the spiral without building the list.

Skip whole rings: ring d has 2·(h + w) - 4 cells for an h×w ring (or h·w if h or w is 1), where h = m - 2d and w = n - 2d. Subtract ring sizes until k falls inside one, then walk that ring's four sides by arithmetic. O(min(m, n)) time, O(1) space.

How to answer

Start from the boundary loop, then point out the per-ring count is a closed formula.

Likely follow-ups
  • What if the ring is a single row or column? (Handle h == 1 or w == 1 separately.)
Fill an m×n grid in spiral order with 1, 2, 3, ... instead.

Same loop, writing instead of reading (LC 59 for squares). For a non-square grid the guards matter exactly as in this problem.

How to answer

Reuse your function body; show the one-line change.

Likely follow-ups
  • Fill from a linked list and pad with -1 (LC 2326).
The matrix is huge and stored row-major on disk. What changes?

Rows are cheap (sequential), columns are expensive (one seek or cache miss per cell). Read a band of rows at a time: the top and bottom rows of the current ring come from sequential reads, and the column cells of the ring come from the same rows, so process the matrix in row blocks and emit each ring's column parts from the buffered rows. Output order still needs the ring structure, so you may buffer per ring.

How to answer

Name the cost model first (row stride 1 vs column stride n), then propose blocking.

Likely follow-ups
  • Memory bound of the buffer for one ring? (O(m + n) values per ring.)
Can you do it with one loop and no guards?

Yes: the step-count version (rung 3). Horizontal runs are n, n-1, n-2, ... and vertical runs are m-1, m-2, ...; alternate them with a direction table and stop when the current run length is 0.

How to answer

Write out the run lengths for a 3×4 grid (4, 2, 3, 1, 2, 0) and the rule appears.

Likely follow-ups
  • Why does it stop correctly on a 1-row grid? (The first vertical run is m-1 = 0.)
