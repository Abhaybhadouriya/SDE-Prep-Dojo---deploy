Dry run

Four boundaries on example 2 (3 rows × 4 columns). Orange cells are read in this step, green cells were read earlier, the blue frame is the rectangle still unread.

  1. Start: top = 0, bottom = 2, left = 0, right = 3. The four boundaries frame the part not read yet: the whole matrix.
  2. Top row, left to right: 10, 11, 12, 13. Row 0 is used up, so top = 1.
  3. Right column, rows 1..2: 23, 33. Column 3 is used up, so right = 2.
  4. top (1) <= bottom (2), so a bottom row is still there. Read row 2 right to left: 32, 31, 30. bottom = 1.
  5. left (0) <= right (2), so read column 0 upwards, rows 1..1: 20. left = 1. The outer ring is done.
  6. Second lap. Top row (row 1), columns 1..2: 21, 22. top = 2.
  7. Right column: rows 2..1 is an empty range, nothing read, right = 1. Now top (2) > bottom (1): the guard skips the bottom row, which would re-read 22, 21. The left column range is empty too; the loop ends. Output has all 12 values.
