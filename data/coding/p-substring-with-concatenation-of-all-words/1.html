The problem (in our words)

You are given a string s and a list words of k strings that all have the same length w (the list may contain repeats). A substring of s is a concatenation if it is all of the words, each used exactly as many times as it appears in the list, written one after another in some order. Return every start index of such a substring in s, in any order.

For example, with words = ["ab", "cd", "ef"] the strings "abcdef", "abefcd", "cdabef", "cdefab", "efabcd" and "efcdab" are concatenations, while "acdbef" is not (it does not split into the words).

Signature: List<Integer> findSubstring(String s, String[] words).

Constraints

  • 1 <= s.length <= 10^4
  • 1 <= words.length <= 5000
  • 1 <= words[i].length <= 30, and all words have the same length.
  • s and every words[i] contain only lowercase English letters.

Practice it: LeetCode 30 - Substring with Concatenation of All Words · Codeforces 367B - Sereja ans Anagrams (the same structure on integer sequences)

Constraints tell you: k · w can reach 150,000, more than n, so check k · w > n first. The match length L = k · w is fixed, which smells like a fixed window. But a window start can be any index, and words only line up when you read in steps of w from that start: that is where the w offsets come from. n · k · w (check every start word by word) is up to 10^4 · 5000 · 30 in the worst case, far too slow; n · w = 3 · 10^5 is easy.
