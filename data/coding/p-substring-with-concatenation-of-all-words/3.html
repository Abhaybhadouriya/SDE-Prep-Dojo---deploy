Recognise the pattern

When you see "a substring made of all these pieces in any order" with pieces of equal length, think anagram search where the alphabet is the set of words: a hash map of counts and a fixed window of k words.

When you see fixed-size units inside a flat string, think "one pass per offset mod w": inside one offset the string is a clean list of units.

The window is fixed in size (k words) like LC 438, but the code is written like LC 76: grow on the right, shrink from the left while a word is over-used. That form also handles a "stranger" (a token that is not a word) by throwing the window away, which a pure fixed-size slide would only notice k steps later.

Pattern: Sliding window > fixed-size window > fixed window frequency match · Lessons: Fixed window frequency match, Variable window (grow / shrink), Counting with hash maps
