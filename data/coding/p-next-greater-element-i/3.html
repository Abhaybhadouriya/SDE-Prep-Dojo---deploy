Recognise the pattern

Cue: "for each element, the first element to its left/right that is bigger/smaller" -> monotonic stack. Next greater keeps a decreasing stack; next smaller keeps an increasing one. Queries on a subset (nums1) -> build the answer for everything once, then look up in a hash map.

Try a few (nums2)Next greater of eachWhat it shows
[1, 2, 3][2, 3, -1]Increasing: each value is answered at once.
[3, 2, 1, 4][4, 4, 4, -1]A falling run waits, then one bigger value answers all of it.
[3, 1, 2][-1, 2, -1]2 answers 1 but not 3: popping stops at the first value not smaller.
