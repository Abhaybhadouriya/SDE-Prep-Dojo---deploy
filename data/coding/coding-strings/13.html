  1. 12

In Java, what is the cost of building a string of n characters with s = s + c in a loop?

  1. O(n)
  2. O(1) per step, amortised
  3. O(n2)

Strings are immutable, so each + copies the whole string built so far: 1 + 2 + ... + n.

For a 32-bit result, which check prevents overflow before computing val * 10 + d?

  1. val > (INT_MAX - d) / 10
  2. val * 10 + d > INT_MAX
  3. val > INT_MAX / 10 + d
  4. val + d > INT_MAX
It is the same inequality rearranged so that nothing overflows. Option B computes the overflowing value first.

Encoding ["a#b", ""] with the length-prefix scheme gives:

  1. a#b#
  2. 3a#b0
  3. #3a#b#0
  4. 3#a#b0#
Each string becomes its length, '#', then the raw characters: "3#" + "a#b" + "0#" + "".

What is lps for the pattern abab?

  1. [1, 0, 1, 0]
  2. [0, 0, 0, 0]
  3. [0, 0, 1, 2]
  4. [0, 1, 2, 3]
"aba" has border "a" (1); "abab" has border "ab" (2). The first entry is always 0.

How do you check that goal is a rotation of s in one line?

  1. sorted(s) == sorted(goal)
  2. goal in s
  3. s[::-1] == goal
  4. len(s) == len(goal) and goal in s + s
Every rotation of s appears as a window of s + s; the length check rules out shorter goals.

"Longest palindromic subsequence" is best solved with...

  1. expand around the centre
  2. 2D dynamic programming
  3. KMP
  4. a read/write head
A subsequence may skip characters, so centre expansion (contiguous) does not apply; use DP on (i, j).
