Practice ladder

In order, easiest first inside each group. The links open our write-up of each problem, with the restated task, references to the original and the editorial, and code.

Basics and in place

  • Reverse String Easy - two pointers, the warm-up.
  • Valid Anagram Easy - int[26] count table.
  • Longest Common Prefix Easy - vertical scan column by column.
  • Reverse Words in a String Medium - squash spaces, reverse twice.
  • String Compression Medium - read head and write head (the stepper above).
  • Group Anagrams Medium - a count table or the sorted word as the map key.
  • Zigzag Conversion Medium - simulate rows, or compute the cycle 2 · (rows - 1).

Palindromes

  • Valid Palindrome Easy - skip non-alphanumerics.
  • Valid Palindrome II Easy - branch once.
  • Longest Palindrome Easy - counting, not substrings.
  • Longest Palindromic Substring Medium - template 1.
  • Palindromic Substrings Medium - count every expansion.
  • Shortest Palindrome Hard - lps on s + "#" + reverse(s).

Parsing and formatting

  • Add Strings Easy - schoolbook addition from the right with a carry.
  • String to Integer (atoi) Medium - template 2.
  • Compare Version Numbers Medium - two indices, no split.
  • Validate IP Address Medium - per-part rules, trailing separator.
  • Multiply Strings Medium - digit i times digit j lands at i + j + 1.
  • Count and Say Medium - run-length, repeated.
  • Valid Number Hard - three flags.
  • Integer to English Words Hard - chunks of three digits.
  • Text Justification Hard - greedy lines, spread the spaces.

Encode / decode and matching

  • Find the Index of the First Occurrence in a String Easy - naive, then template 3.
  • Rotate String Easy - search inside s + s.
  • Repeated Substring Pattern Easy - doubling trick or lps.
  • Encode and Decode Strings Medium - length prefix.
  • Decode String Medium - stack of (count, partial).
  • Repeated DNA Sequences Medium - rolling hash or a 2-bit-per-letter integer.
  • Longest Happy Prefix Hard - it is literally lps[n-1].
