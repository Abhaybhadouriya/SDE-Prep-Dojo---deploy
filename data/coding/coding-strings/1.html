The hidden O(n2). In Java or Python, res = res + ch inside a loop copies the whole string every time: 1 + 2 + ... + n = O(n2). For n = 105 that is about 5 x 109 byte copies. Always use the builder or a list and join once.

Counting characters: the int[26] table

Anagrams, "first unique letter", "how many of each": when the alphabet is small (lowercase English is the usual constraint), use a fixed array, count[ch - 'a']++, instead of a hash map. Faster, no collisions, and two tables compare in 26 steps. Use 128 for ASCII and a map for full Unicode.
