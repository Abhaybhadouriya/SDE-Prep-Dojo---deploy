Encode and decode: length prefixes beat delimiters

LeetCode 271 (Premium; asked at Google, Meta, Amazon and TikTok) says: design encode(list of strings) -> one string and decode(one string) -> the same list. The strings may contain any character, including the one you wanted to use as a separator. Joining with a comma fails on ["a,b"]. Escaping works but is fiddly. The clean answer is a length prefix: write each string as its length, a marker such as #, then the raw characters.

From your world

This is TLV, the type-length-value layout of netlink attributes (struct nlattr), BGP path attributes, DHCP options and LLDP. You read the length, then you skip that many bytes without interpreting them. A fixed 4-byte binary length (like nla_len) also works; the # version just keeps the encoding printable.
