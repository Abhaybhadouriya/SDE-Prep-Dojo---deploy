How to recognise which string tool to use

When the problem says...ThinkCost
"in place", "O(1) extra space", reverse, remove, compresstwo pointers from the ends, or a read head and a write headO(n), O(1)
"same letters", anagram, "first unique", frequencyint[26] or int[128] count tableO(n), O(1)
"longest / count palindromic substring"expand around 2n-1 centres (Manacher as a follow-up)O(n2), O(1)
"palindrome after deleting at most one"two pointers, branch once at the first mismatchO(n)
"convert", "valid", "parse", version, IP, numberordered list of parts + one index; overflow check before multiplyO(n)
"encode a list so it can be decoded", any character allowedlength prefix (TLV)O(total length)
"find pattern", "repeated", "rotation", "prefix that is also a suffix"KMP lps, Z-function, rolling hash, or the s + s trickO(n + m)
"longest substring with / without ..." and a window conditionnot this page: sliding window with a count tableO(n)
"minimum edits", "longest common subsequence", "palindromic subsequence"not this page: 2D dynamic programmingO(n · m)

The last two rows matter: substring means contiguous, subsequence means you may skip characters. That one word usually decides between this page and DP.
