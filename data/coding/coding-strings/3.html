Palindromes: expand around the centre

The interview favourite is the longest palindromic substring (LeetCode 5; Microsoft, Amazon, Google and PhonePe in the Premium data). Checking every substring is O(n3). The key idea: every palindrome is symmetric around a centre, so guess the centre and grow outwards while the two sides match.

From each of the 2n-1 centres, expansion costs up to n/2 steps, so the total is O(n2) time and O(1) space. That is the answer interviewers expect. Watch it run:

  1. String abaccabd, n = 8, so 15 centres. We follow the two that matter.
  2. Odd centre at index 1 (b): lo = hi = 1, then s[0] = s[2] = a, so the window grows to aba.
  3. Next step would need s[-1]: out of bounds, stop. The palindrome is s[lo+1 .. hi-1] = aba, length hi - lo - 1 = 3. Best so far.
  4. Even centre between 3 and 4: s[3] = s[4] = c, window cc (length 2).
  5. s[2] = s[5] = a: window acca (length 4), now the best.
  6. s[1] = s[6] = b: window baccab (length 6).
  7. s[0] = a but s[7] = d: mismatch, stop. Answer baccab. Every other centre gives something shorter.

Counting palindromic substrings (LeetCode 647) is the same loop: every successful expansion step is one more palindrome, so add 1 each time the sides match. Same O(n2) time.

Other palindrome shapes

  • Valid palindrome (125): two pointers that skip characters that are not letters or digits and compare in lowercase. The skip loops need their own l < r check.
  • Valid palindrome II (680): you may delete one character. Run the two pointers; at the first mismatch try both options, skip left or skip right, and check the rest with a plain loop. O(n), because you branch only once.
  • Longest palindrome you can build (409): not a substring question at all. Count letters; use every pair; add 1 if any odd count exists.
  • Manacher's algorithm does it in O(n) by reusing mirror information. Name it as a follow-up; almost nobody asks you to code it.
  • Shortest palindrome (214, Hard): add characters in front to make the string a palindrome. The fast answer uses the KMP failure table on s + "#" + reverse(s), which you will meet at the end of this page.
