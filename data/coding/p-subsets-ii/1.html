The problem (in our words)

You are given an integer array nums that may contain duplicate values. Return every possible subset (the power set), but without duplicate subsets: two subsets that hold the same values with the same multiplicities count as one. The subsets may be returned in any order, and the order of values inside a subset does not matter.

Signature: List<List<Integer>> subsetsWithDup(int[] nums).

Constraints:

  • 1 <= nums.length <= 10
  • -10 <= nums[i] <= 10

Practice it: LeetCode 90 · GfG Distinct Subsets

Constraints tell you: n ≤ 10, so at most 210 = 1024 subsets. Exponential output is expected and unavoidable; the interviewer is grading the dedup logic, not speed. Values are tiny and may be negative, which matters only if you were tempted to index an array by value.
