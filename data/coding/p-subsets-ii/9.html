Revision card

  • Cue: all subsets/combinations, input has duplicates, output must not -> sort + sibling skip.
  • Insight: equal values at the same level build identical subtrees; keep only the first.
  • State: start index, cur path; record cur at every node; recurse with i + 1.
  • Trap: skip with i > start (not i > 0); sort first; append a copy of cur.
  • Cost: O(n * 2^n) time, O(n) stack; count = product of (count(v) + 1).
nums.sort()
def dfs(start):
    record(path)                       # subsets: every node; combos: only valid leaves
    for i in range(start, len(nums)):
        if i > start and nums[i] == nums[i - 1]: continue
        path.append(nums[i]); dfs(i + 1); path.pop()
dfs(0)

Quick quiz

How many distinct subsets does [2,2,2,7,7] have?

  1. 32
  2. 10
  3. 12
  4. 6
(3 + 1) x (2 + 1) = 12.

With the condition i > 0 instead of i > start, which subset of [1,3,3] is lost?

  1. [1]
  2. [3,3]
  3. []
  4. [3]
Inside [3] (start = 2), i = 2 has nums[2] == nums[1] and i > 0, so the second 3 is wrongly skipped.

Why must the input be sorted?

  1. So equal values are adjacent and the skip compares only with nums[i-1]
  2. The output must be sorted
  3. For the recursion depth
  4. It need not be
The rule is a local check; it only works when all copies of a value are neighbours.
