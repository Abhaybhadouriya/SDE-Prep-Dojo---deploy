Dry run

coins = [1, 2, 4], amount 6. Each row is the 1D array after one more coin is allowed; glowing cells changed in this pass. The arrows into a = 6 show the two terms: straight down = combinations without the new coin, curved = combinations that use it (read from the same row).

  1. One row per coin; in the code all rows share one 1D array, each row overwrites the one above. Start: one way to make 0 (the empty set), no way to make anything else.
  2. Add coin 1, amounts going up: ways[a] += ways[a - 1]. Every amount has exactly one combination: all 1s. The arrow into a = 6 reads the old value above (without coin 1) plus the new value at a = 5 in the same row (combinations that use coin 1 at least once).
  3. Add coin 2: ways[a] = (old ways[a], no 2s) + (ways[a - 2] in this row, already allowed to contain 2s). For a = 6: 1 + 3 = 4, i.e. 1+1+1+1+1+1, 2+1+1+1+1, 2+2+1+1, 2+2+2.
  4. Add coin 4: only a >= 4 change. ways[6] = 4 + ways[2] = 4 + 2 = 6; the two new ones are 4+1+1 and 4+2. Because coins are added one at a time, every combination is counted exactly once, in coin order, and 2+4 / 4+2 are never both counted.
