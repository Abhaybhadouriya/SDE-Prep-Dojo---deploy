How to recognise it:

  • "In how many ways", a target sum, unlimited copies of each value, and the example treats 1+2 and 2+1 as one way.
  • Values and target in the low thousands, so an O(target · items) table is expected.

Practice order:

  1. Warm-up: 322 Coin Change (min).
  2. This problem: write the 2D recurrence, then shrink it and justify the loop order.
  3. Then: 377 (orderings), 416 and 494 (use once), 2585 (limited counts).
