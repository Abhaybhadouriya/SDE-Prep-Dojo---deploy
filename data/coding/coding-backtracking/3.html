Permutations: order matters, so track used[]

Permutations. Given an array of distinct integers (length 1 to 6, values -10 to 10), return all orderings of it, in any order. (Original: LeetCode 46.)

Now [1, 2] and [2, 1] are different answers, so a start index is wrong: after picking 2 we still need 1. Instead keep a boolean used[i]. At every depth, loop over all indices and take any that is not used. The path is complete when its length is n.

Permutations II (LC 47) allows duplicates. Sort, and skip a[i] when a[i] == a[i-1] and used[i-1] is false. In words: equal values must be used in their original order, so the second copy may only be placed after the first one is already on the path. That makes each distinct ordering appear once.
