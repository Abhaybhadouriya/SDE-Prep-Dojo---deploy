Subsets: every node is an answer

Subsets. You get an array of distinct integers (length 1 to 10, values -10 to 10). Return every possible subset (the power set), with no duplicate subsets, in any order. (Original: LeetCode 78.)

A subset is unordered, so {1, 2} and {2, 1} are the same. To avoid producing both, we only add items to the right of the last one we added: the recursion carries a start index, and the loop runs from start. Every node of the tree is a valid subset, so we record at every call, not just at leaves.

  1. Call with an empty path and start 0. Record [ ] (the empty subset counts).
  2. Choose 1 (push), recurse with start 1, record [1].
  3. Choose 2, recurse with start 2, record [1, 2].
  4. Choose 3, record [1, 2, 3]. No items remain, so the loop ends; unchoose 3, return, unchoose 2.
  5. Back in the [1] call, the loop moves on to 3: record [1, 3]. Then unchoose 3 and 1.
  6. Back at the root, choose 2. The loop starts at index 1, so 1 is never added after 2: no duplicate {2, 1}.
  7. Record [2, 3], unchoose.
  8. Finally [3]. Eight nodes, eight subsets. Time O(n x 2n): 2n subsets, each copied in O(n).

Subsets II (LC 90) is the same task when the array may contain duplicates, and the output must still have no duplicate subsets. Sort first. Then, inside one loop (one depth of the tree), skip a value equal to the one just tried: if i > start and a[i] == a[i-1]: continue. The check uses i > start, not i > 0: picking the second 2 after the first 2 (going deeper) is allowed; picking it instead of the first 2 (a sibling) is the duplicate.
