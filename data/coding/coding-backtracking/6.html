Board search: Word Search, N-Queens, Sudoku

Word Search. Given an m x n grid of letters (m and n from 1 to 6) and a word (length 1 to 15), return true if the word can be traced through cells that touch horizontally or vertically, using each cell at most once in that trace. (Original: LeetCode 79.)

Start a DFS from every cell. The path is the index k into the word; a call fails fast if the cell is off the board or does not match word[k]. To remember "used in this trace" without a set, overwrite the cell with a marker such as '#' (choose) and put the letter back after the four recursive calls (unchoose).

Word Search II (LC 212) looks for many words at once: walk a trie alongside the DFS so one search covers every word with the current prefix, and remove trie leaves once found.

N-Queens. Place n queens on an n x n chessboard (n from 1 to 9) so that no two share a row, a column or a diagonal. Return every distinct board, written as strings of 'Q' and '.' (or, in N-Queens II, just the count). (Original: LeetCode 51, LeetCode 52.)

Place one queen per row, so rows never clash. For columns and the two diagonals keep three sets (or bitmasks). On the "\" diagonal row - col is constant; on the "/" diagonal row + col is constant. A cell is free if its column and both diagonals are free: an O(1) check.

  1. One queen per row. Row 0, column 0.
  2. Row 1: column 0 shares the column, column 1 shares a diagonal. Column 2 is free.
  3. Row 2: every column is attacked by the two queens above. Dead end, so unchoose the row 1 queen.
  4. Row 1 tries its next free column, 3.
  5. Row 2: column 1 is free now.
  6. Row 3: dead again. Row 2 has no other free column, nor does row 1, so we back up to row 0. Pruning already skipped most of the 44 = 256 raw placements.
  7. Row 0 moves to column 1.
  8. Row 1: only column 3 is free.
  9. Row 2: column 0.
  10. Row 3: column 2. All four rows placed: record the board. The search continues and finds the mirror image too; n = 4 has exactly 2 solutions.

From your world

The bitmask version in the templates below is pure C-style bit work: cols, d1 and d2 are words with one bit per column, free & -free isolates the lowest free column (like ffs()), and shifting the diagonal masks by one per row moves the attacked squares down the board. n = 8 gives 92 solutions in microseconds.

Sudoku Solver. Fill a 9 x 9 grid (digits and '.' for blanks) in place so that every row, column and 3 x 3 box holds 1 to 9 exactly once; the puzzle has exactly one solution. (Original: LeetCode 37.) Same template: the path is the board, a choice is a digit for the next blank, validity is three lookups. Keep 9 row masks, 9 column masks and 9 box masks (box index (r / 3) * 3 + c / 3) so the check is O(1). The pruning that matters most is choose the blank with the fewest legal digits next (minimum remaining values): a cell with one option is forced, and a cell with zero options proves the current path wrong immediately.
