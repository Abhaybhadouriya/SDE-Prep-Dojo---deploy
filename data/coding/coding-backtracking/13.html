Revision card

  • Cue: "All" / "every" subsets, permutations, combinations, boards, n up to about 15-20.
  • Insight: Build the answer one choice at a time; undo the choice after exploring it.
  • State: path + start index (unordered) or used[] (ordered); recurse with i (reuse) or i + 1 (once).
  • Trap: Recording the path itself instead of a copy; forgetting to undo state in reverse order; duplicate siblings.
  • Cost: O(2^n n) for subsets, O(n! n) for permutations; prune before recursing.

More to remember

  • Three questions: what is the path, what are the choices, when is it complete.
  • Choose, explore, unchoose. Undo every piece of state, in reverse order. Record a copy.
  • Unordered answers (subsets, combinations): start index. Ordered answers (permutations): used[].
  • Reuse allowed: recurse with i. Use once: i + 1.
  • Duplicates in input: sort, skip siblings with i > start (permutations: !used[i-1]).
  • Prune before recursing: sorted break, validity checks, bounds, most-constrained first.
  • Grid search: mark the cell, recurse four ways, restore.
  • Say the output size first: it is the lower bound on the cost.
