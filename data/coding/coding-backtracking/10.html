Common mistakes

  • Storing the path, not a copy. Every recorded answer ends up as the same empty list.
  • Forgetting to unchoose one of several pieces of state: the path, used[i], the column set, the board cell. Undo everything you did, in reverse order.
  • Dedup with i > 0 instead of i > start. That also blocks legal answers such as [1, 1, 6].
  • Dedup without sorting. The sibling skip only works when equal values sit next to each other.
  • Start index for permutations (misses orderings) or used[] for subsets (produces each subset many times).
  • i versus i + 1 in the recursive call: the only difference between "reuse allowed" and "use once".
  • continue where break is right (and the reverse): break only when the list is sorted and every later item fails too.
  • Word Search: returning before restoring the cell, which corrupts the board for the next starting cell.
  • Mutable defaults and shared lists in Python (def dfs(path=[])); in Java, path.remove(x) on a List<Integer> removes by index, not by value: use path.remove(path.size() - 1).
