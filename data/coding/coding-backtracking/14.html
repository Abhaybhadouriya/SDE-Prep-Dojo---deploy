For permutations of distinct numbers, which state tells you what may be chosen next?

  1. A used[] array
  2. The remaining sum
  3. A start index
Order matters, so earlier items must stay available. used[] marks only the items already on the path.

Combination Sum with unlimited reuse: the recursive call passes...

  1. start + 1
  2. i + 1
  3. i
Passing i lets the same candidate be chosen again at the next depth, while items to the left stay excluded (no duplicate orderings).

Sorted input [1, 1, 2]. With the check i > 0 and a[i] == a[i-1] instead of i > start, Subsets II would...

  1. work the same
  2. miss [1, 1] and [1, 1, 2]
  3. produce duplicates
Inside the [1] call, start is 1 and i = 1 is the second 1; i > 0 skips it, so the child [1, 1] is never built.

How many subsets does an array of 10 distinct numbers have?

  1. 100
  2. 3,628,800
  3. 1024
210 = 1024, including the empty subset. 3,628,800 is 10!, the number of permutations.

In N-Queens, which value is the same for all cells on one "/" anti-diagonal?

  1. row - col
  2. row + col
  3. row x col
Moving down-left adds 1 to row and subtracts 1 from col, so row + col stays constant. row - col is constant on "\" diagonals.

Word Search finds the word on the first starting cell. What must still happen before returning?

  1. Restore the marked cells (the unchoose step) if the board is reused
  2. Nothing, returning true is enough
  3. Clear the whole board
Each call restores its own cell before returning, so the board is intact for the caller. Returning before the restore corrupts it.

Which prune helps a Sudoku solver the most?

  1. Trying digits 9 down to 1
  2. Filling the blank with the fewest legal digits first
  3. Checking validity only when the board is full
Most-constrained-first forces single-option cells and detects dead ends (zero options) immediately.
