Approaches: brute -> better -> optimal

Hint 1

Ask one question about two people. Whatever the answer, can you say for sure that one of them is not the celebrity?

Hint 2

After n - 1 such questions, how many people are still possible?

1. Brute force - test every person

Idea: for each person c, ask knows(c, j) and knows(j, c) for every other j; return the first c that knows nobody and is known by all. Equivalent to computing in-degree and out-degree of every node of the "knows" graph.

O(n²)calls and time
O(1)space

What is wasted: every single answer already rules somebody out, yet we keep asking about people who are already disqualified.

2. Better - stack elimination

Idea: push everyone on a stack. Pop two, ask one question, push back the one who survives. After n - 1 questions one person remains; verify it with 2(n - 1) more calls. This is the classic GfG / TUF solution.

O(n)calls: about 3n
O(n)stack

What is wasted: the stack is unnecessary. The survivor can be held in one variable while we walk the labels in order.

3. Optimal - one candidate, then verify (under 3n calls)

cand = 0
for i in range(1, n):
    if knows(cand, i): cand = i          # cand is out; i might be it
for i in range(n):
    if i != cand and ((i < cand and knows(cand, i)) or not knows(i, cand)): return -1
return cand
  1. Pass 1 (n - 1 calls): compare the candidate with each next person. A "yes" disqualifies the candidate, so the next person takes over; a "no" disqualifies the next person.
  2. Only the survivor can be the celebrity. Everyone else was ruled out by an answer. But the survivor is not proven: a graph with no celebrity still leaves one survivor (example 2).
  3. Pass 2 (verify): the survivor must not know anyone and must be known by everyone.
  4. Save calls: for every i > cand, pass 1 already asked knows(cand, i) and got "no" (that is why cand stayed). Only i < cand needs that check again.
≤ 3n - 3calls: (n-1) + cand + (n-1)
O(n)time
O(1)space

Why it works: after comparing the candidate with person i, everyone in 0..i except the candidate is ruled out. Induction: when the candidate changes to i, the old candidate (and, by the hypothesis, everyone it had beaten) is out; when it does not change, i is out. So at the end at most one person, the survivor, can be the celebrity, and pass 2 checks the definition directly. The most-voted community solutions use exactly this two-pass shape.

Proof (optional)

Invariant after step i of pass 1: no person in [0, i] other than cand is a celebrity. Step i+1: if knows(cand, i+1), cand knows someone, so cand is not a celebrity, and the new cand = i+1 keeps the invariant. Otherwise cand does not know i+1, so i+1 is not known by everybody and is not a celebrity. After i = n-1, only cand remains possible. In pass 2, for i > cand, cand was the candidate when i was examined (cand never changes once set to its final value), and that call returned false, so knows(cand, i) is false without asking again.
