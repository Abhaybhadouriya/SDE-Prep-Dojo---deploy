Dry run

Example 1 (celebrity 2): pass 1 elimination, then pass 2 verification.

  1. Start with candidate 0. Pass 1 asks one question per person and each answer rules exactly one person out.
  2. knows(0, 1) = no. Person 1 is not known by 0, so 1 cannot be the celebrity (everyone must know them). Keep candidate 0.
  3. knows(0, 2) = yes. A celebrity knows nobody, so 0 is out. Candidate becomes 2.
  4. knows(2, 3) = no, so 3 is out. Pass 1 ends: 2 is the only person not ruled out (3 calls).
  5. Pass 2 verifies 2. For i = 0 < 2 we never asked whether 2 knows 0: knows(2, 0) = no, good.
  6. knows(0, 2) = yes: 0 knows 2, good. (Pass 1 asked this already; a cache could skip it.)
  7. i = 1 < 2: knows(2, 1) = no, good.
  8. knows(1, 2) = yes, good.
  9. i = 3 > 2: pass 1 already showed knows(2, 3) = no, so only knows(3, 2) is asked: yes.
  10. Everyone knows 2 and 2 knows nobody: return 2. Total 8 calls, under the 3n = 12 budget.
