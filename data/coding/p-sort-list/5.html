Dry run

On [5, 1, 4, 2]:

  1. Start: one list of 6 nodes. sortList finds the middle with slow/fast pointers (fast starts at head.next), so slow stops on 4, the end of the left half.
  2. Cut: slow.next = null. Two independent lists of 3 nodes. No array, no copy: only one pointer changed.
  3. Recurse. For 3 nodes (5, 1, 4) fast starts on 1, jumps once to past 4, and slow stops on 1: the split is 2 + 1. The depth of this recursion is about log2 n.
  4. Single nodes are sorted by definition (the base case head.next == null). Now the merges run on the way back up.
  5. Merge pairs: [5] + [1] gives 1 → 5, [2] + [8] gives 2 → 8. Each merge relinks next pointers behind a dummy head.
  6. Merge [1, 5] + [4] = 1 → 4 → 5 and [2, 8] + [3] = 2 → 3 → 8. Each level of merges touches every node once: O(n) per level.
  7. Last merge: compare the two heads, take the smaller, advance. 1, 2, 3, 4, 5, then the rest (8) is appended in one step. log n levels x O(n) = O(n log n).
