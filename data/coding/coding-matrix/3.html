Diagonals: i + j and i - j are the keys

Every anti-diagonal (running from top-right to bottom-left) has a constant r + c. Every main diagonal (top-left to bottom-right) has a constant r - c. That one fact replaces all the "walk diagonally and bounce off the edges" logic.

For Diagonal Traverse, a robust version is: for each d from 0 to R + C - 2, the rows on that anti-diagonal run from max(0, d - C + 1) to min(d, R - 1); collect them top-down and reverse the list when d is even (the up-right direction). Diagonal Traverse II has ragged rows: bucket every existing cell by r + c while scanning rows bottom-up, then concatenate the buckets. A Matrix Diagonal Sum (n x n) adds m[i][i] and m[i][n-1-i] and subtracts the centre once when n is odd. In tic-tac-toe style problems (Find Winner, Valid Tic-Tac-Toe State), the two diagonals are exactly r == c and r + c == n - 1.
