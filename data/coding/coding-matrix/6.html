Validation: rows, columns and boxes

Valid Sudoku (LeetCode 36) asks whether a partly filled 9 x 9 board breaks a rule: no digit twice in any row, any column or any of the nine 3 x 3 boxes. You do not solve the puzzle; you only check the filled cells. One pass over the 81 cells with three sets of "seen" records is enough. The only new idea is the box number.

Sets of characters work just as well and read more naturally in Python; the bitmask version (see bit manipulation) is what a C engineer reaches for and it is a nice detail to mention. The same row / column / unit bookkeeping appears in Sudoku Solver (backtracking that uses these masks to find legal digits fast), N-Queens (columns plus the two diagonal families r + c and r - c from the diagonals section), and Find Winner on a Tic Tac Toe Game (keep a counter per row, per column and per diagonal, +1 for player A and -1 for B; a counter reaching +-n is a win, O(1) per move).

Sorted matrices are a separate family worth recognising: if rows and columns are both sorted (Search a 2D Matrix II), start at the top-right corner and step left when the value is too big, down when too small: O(R + C). If the whole matrix is sorted row after row (Search a 2D Matrix), treat it as a flat array with k = r * C + c and binary search. Both belong to the binary search family.
