How to recognise which matrix tool to use

When the problem says...ThinkCost
"spiral order", "fill in spiral", "layer by layer"four walls with guards, or turn-when-blocked with direction arraysO(RC)
"diagonal", "anti-diagonal", "each diagonal sorted / equal"group by r + c or r - cO(RC)
"rotate 90", "flip", "transpose", n x n, in placetranspose + reverse rows (or the 4-way cycle per layer)O(n2), O(1)
"in place" and each cell depends on the original neighboursspare bits (next state in bit 1) or first row/column as markersO(RC), O(1)
"valid board", "no repeats in row / column / box"one seen-set or bitmask per unit; box = (r/3)*3 + c/3O(RC)
"rows and columns sorted", "find target", "k-th smallest"staircase from a corner, or binary search on the value / flat indexO(R + C) or O(log)
"islands", "shortest path in grid", "flood fill", "connected"not this page: grid BFS / DFSO(RC)
"sum of any sub-rectangle", many queriesnot this page: 2D prefix sumsO(1) per query
