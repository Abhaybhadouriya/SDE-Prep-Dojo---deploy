Rotate and transpose in place

Rotate Image (LeetCode 48) gives an n x n matrix and asks you to rotate it 90 degrees clockwise in place. Where does a cell go? Clockwise, the cell at (r, c) moves to (c, n - 1 - r). That mapping is two simpler moves glued together: a transpose (swap (r, c) with (c, r)) followed by a horizontal flip of every row (swap column c with column n - 1 - c).

Two bugs to avoid. First, the transpose loop must touch only the upper triangle (j > i); looping over every (i, j) swaps each pair twice and leaves the matrix unchanged. Second, rotation in place only works for square matrices; for R x C, the result is C x R and needs a new array (Transpose Matrix, 867, returns a new one for that reason).

The other in-place method rotates layer by layer: for each ring and each offset, move four cells in a cycle (top to right, right to bottom, bottom to left, left to top) with one temporary. It does the same O(n2) work with fewer total writes, and it is the version to mention if the interviewer says "do it in one pass".

From your world

The four-way cycle is a rotation of a permutation, the same trick as rotating a ring buffer in place with a cycle-leader loop. Transpose-and-flip is like doing a byte swap by two simpler shuffles: each step is easy to prove correct on its own.
