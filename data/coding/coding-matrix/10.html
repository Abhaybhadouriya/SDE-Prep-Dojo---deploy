Common mistakes

  1. Assuming a square. Using n for both dimensions. Read R and C separately unless the problem says n x n.
  2. Spiral without guards. Missing if top <= bottom / if left <= right before the return legs repeats the middle row or column.
  3. Transposing the full square. Looping j from 0 swaps every pair twice and undoes the transpose. Loop j = i + 1 .. n - 1.
  4. Updating from half-updated values. In Game of Life or Set Zeroes, writing final values during the scan corrupts later reads. Encode, then decode.
  5. The shared corner. In Set Zeroes, m[0][0] cannot mark both row 0 and column 0. Keep one extra flag, and wipe row 0 and column 0 last.
  6. Negative indices in Python. m[-1][c] is the last row, not an error. Always bounds-check neighbours.
  7. Wrong box formula. r / 3 + c / 3 collides (box (0,1) and (1,0) both give 1). It is (r / 3) * 3 + c / 3.
  8. Row and column swapped. m[x][y] with x as the column. Name variables r and c, never i and j with a mental note.
