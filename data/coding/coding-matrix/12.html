Remember this

Revision card

  • Cue: Grids as arrays: spiral order, rotate in place, set zeroes, valid sudoku, diagonals.
  • Insight: A cell is (r, c) or a flat index r * C + c; in-place updates need spare bits or marker cells.
  • State: four walls for spiral; transpose + reverse rows for rotate; row 0 / column 0 as markers plus one flag.
  • Trap: Mixing up R and C on non-square input; overwriting a marker before it is read; spiral return legs on a single row or column.
  • Cost: O(R C) time, O(1) extra for the in-place versions.

More to remember

  • Read R and C separately; flat index k = r * C + c.
  • Spiral: four walls, move each after use, guard the return legs.
  • Diagonals: r + c is constant on anti-diagonals, r - c on main diagonals.
  • Rotate clockwise = transpose (upper triangle only) + reverse each row.
  • In place with original neighbours: store the new state in spare bits or in marker cells, then decode.
  • Set Zeroes: row 0 / column 0 are the markers, one flag for column 0, row 0 processed last.
  • Validation: one seen-mask per row, column and box; box = (r / 3) * 3 + c / 3.
  • Grid graphs (islands, paths) and sub-rectangle sums belong to BFS/DFS and prefix sums.
