Basics: indices, flattening, directions

Call the matrix m with R rows and C columns. Cell (r, c) means row r (top to bottom), column c (left to right). Four facts carry you through most problems.

  • Shape first. R = len(m), C = len(m[0]), and guard the empty matrix. Many inputs are not square; never assume R == C unless the problem says "n x n".
  • Flat index. k = r * C + c and back with r = k / C, c = k % C. This turns a sorted matrix into a sorted array for binary search (Search a 2D Matrix) and lets you reshape or shift a grid (Shift 2D Grid) with one counter.
  • Direction arrays. dr = [-1, 0, 1, 0], dc = [0, 1, 0, -1]. Turning right is d = (d + 1) % 4. Add the four diagonals for eight neighbours (Game of Life).
  • Bounds check first. Test 0 <= nr < R and 0 <= nc < C before reading m[nr][nc]. In Python a negative index silently wraps to the other side, so the bug does not even crash.

Grid graphs live elsewhere. When cells are nodes and you search for islands, shortest paths or flood fills (Number of Islands, Rotting Oranges, Word Search), the tool is BFS/DFS or backtracking. This page covers problems about the matrix itself: order of visits, in-place transforms, and validation.
