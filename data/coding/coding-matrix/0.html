The story: the cinema seat map

Explain like I'm 5

A cinema has rows of seats, and every seat has a row number and a seat number. An usher who wants to check every seat can walk row by row, like reading a book. Or she can walk around the edge of the hall, then the next ring inside, then the next, like peeling an onion. That is a spiral.

If the manager says "turn the whole seat map sideways", the usher does not need a second hall. She can move people around inside the same hall, four at a time. And if she must remember "this row needs cleaning", she can put a sticky note on the first seat of that row instead of carrying a notebook. Those sticky notes are the trick behind the hardest-looking matrix problems.

Matrix problems are common in first rounds: Spiral Matrix, Rotate Image, Set Matrix Zeroes and Valid Sudoku all sit near the top of the Premium company lists for Amazon, Microsoft, Apple, Google and Bloomberg. None needs a fancy algorithm. They test whether you can keep four indices straight and stop at the right moment.

From your world

You have used a matrix every day: a C 2D array int a[R][C] is one flat block where a[i][j] lives at offset i * C + j (row-major). Walking along a row is sequential and cache friendly; walking down a column strides by C elements and touches a new cache line each step. A page table is a matrix indexed by (directory, table) bits, and a routing table indexed by (VRF, prefix) is one too.
