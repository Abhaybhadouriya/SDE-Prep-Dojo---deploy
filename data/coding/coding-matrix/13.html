Rotating an n x n matrix 90 degrees clockwise sends cell (r, c) to...

  1. (n-1-c, r)
  2. (n-1-r, n-1-c)
  3. (c, r)
  4. (c, n-1-r)
Transpose gives (c, r); reversing the row then moves column r to column n-1-r.

Without the guard before the "bottom row" leg, what does spiral order print for the 1 x 3 matrix [[1, 2, 3]]?

  1. 1 2 3 2 1
  2. an index error
  3. 3 2 1
  4. 1 2 3
After the top leg, top = 1 and bottom = 0, but the unguarded bottom leg still walks row 0 backwards from column 1: 2 1.

Which box does Sudoku cell (7, 2) belong to (boxes numbered 0..8 row by row)?

  1. 8
  2. 6
  3. 2
  4. 7
(7 / 3) * 3 + 2 / 3 = 2 * 3 + 0 = 6.

In Game of Life with the 2-bit trick, how do you read a neighbour's current state during the scan?

  1. cell & 2
  2. cell >> 1
  3. cell & 1
  4. cell
Bit 0 keeps the current state untouched; bit 1 holds the next state until the final shift.

Cells on the same main diagonal (top-left to bottom-right) share...

  1. max(r, c)
  2. r - c
  3. r * c
  4. r + c
Moving one step down-right adds 1 to both r and c, so r - c does not change.

Why does the O(1) Set Matrix Zeroes solution need one extra boolean?

  1. Because the matrix may not be square
  2. To count the zeros
  3. Because m[0][0] cannot mark both row 0 and column 0
  4. To remember the original value of each marker cell
Row markers live in column 0 and column markers in row 0; they overlap at the corner, so column 0 needs its own flag.
