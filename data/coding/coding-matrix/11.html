Interview questions

Return the elements of an R x C matrix in spiral order.

Keep four walls: top, bottom, left, right. Each lap: walk the top row and move top down; walk the right column and move right left; if top <= bottom, walk the bottom row backwards and move bottom up; if left <= right, walk the left column upwards and move left right. Stop when the walls cross. O(R * C) time, O(1) extra space.

How to answer

Draw a 3 x 4 matrix and the four walls before coding. Say why the two guards exist, then test on a 1 x 3 row and a 3 x 1 column.

Likely follow-ups
  • Fill a matrix with 1..n2 in spiral order (Spiral Matrix II).
  • Counter-clockwise or starting from the centre (reorder the legs; for outward spirals use leg lengths 1, 1, 2, 2, ...).
Rotate an n x n image by 90 degrees clockwise in place.

Clockwise rotation maps (r, c) to (c, n-1-r). Do it as a transpose (swap (r, c) with (c, r) for c > r) followed by reversing each row. Both are pure swaps: O(n2) time, O(1) space. Counter-clockwise: transpose and reverse each column. 180 degrees: reverse rows and reverse each row.

How to answer

Write the mapping first, then show that transpose-then-flip produces it. Offer the layer-by-layer 4-way swap as the alternative and say both are O(n2).

Likely follow-ups
  • Rotate an R x C matrix (cannot be in place; allocate C x R).
  • Check if one matrix is a rotation of another (compare after 0-3 rotations).
Set Matrix Zeroes with O(1) extra space. Why do you need an extra flag?

Use row 0 and column 0 as the marker arrays: for every zero at (r, c), set m[r][0] = 0 and m[0][c] = 0. The corner m[0][0] can only mean one thing, so it marks row 0, and a separate boolean records whether column 0 must be zeroed. Second pass: zero every cell (r, c) with c >= 1 whose row or column is marked, going bottom-up so row 0's markers survive until last; then apply the column-0 flag.

How to answer

Give the O(R + C) version with two boolean arrays first (it is correct and clear), then move the arrays into the matrix. Walk through a tiny example where row 0 has a zero.

Likely follow-ups
  • What if the matrix is read-only and huge? (Two bitsets of size R and C, streamed.)
  • Why not use a sentinel like -1? (Values may be any integer; a sentinel can collide.)
Determine whether a 9 x 9 Sudoku board is valid (only filled cells matter).

One pass over the cells. Keep a seen-record for each of the 9 rows, 9 columns and 9 boxes, where the box id is (r / 3) * 3 + c / 3. For a digit d at (r, c), if d is already in rows[r], cols[c] or boxes[b], return false; otherwise record it. With 9-bit masks each check is one OR and one AND. O(81) time and space, which is O(1) for fixed size.

How to answer

Clarify that you check validity, not solvability. Derive the box formula on one cell. Mention sets for readability, masks for speed.

Likely follow-ups
  • Solve the board (backtracking that reuses the masks to list allowed digits).
  • Generalise to n2 x n2 (box = (r / n) * n + c / n).
Game of Life: compute the next board in place. What if the board were infinite?

Values are 0 or 1, so bit 1 is free. Count live neighbours using cell & 1 (the current state). If the cell lives next round (2 or 3 neighbours when alive, exactly 3 when dead), set bit 1. After the full scan, shift every cell right by one. O(R * C) time, O(1) extra space. For an infinite board, store the set of live coordinates, count neighbours for every live cell and its eight neighbours with a hash map, and build the next set.

How to answer

Explain the "simultaneous update" problem with one example where naive in-place updating gives the wrong answer, then show the 2-bit encoding.

Likely follow-ups
  • Board too large for memory (process three rows at a time from disk).
  • Parallelise it (split into strips; each strip needs one halo row from its neighbours).
Traverse an R x C matrix diagonally in zigzag order.

All cells on one anti-diagonal share d = r + c, with d from 0 to R + C - 2. For each d, the rows run from max(0, d - C + 1) to min(d, R - 1). Collect them top-down and reverse when d is even, so even diagonals go up-right and odd ones go down-left. O(R * C) time.

How to answer

Label a small grid with r + c and the pattern becomes obvious. The group-by-d version avoids all edge-bouncing cases; mention the simulation version only if asked.

Likely follow-ups
  • Rows of different lengths (Diagonal Traverse II: bucket by r + c).
  • Sort each main diagonal (bucket by r - c).
Search for a target in a matrix whose rows and columns are both sorted.

Start at the top-right corner. If the value equals the target, done. If it is larger, everything below in that column is larger too, so move left. If it is smaller, everything to the left in that row is smaller, so move down. Each step removes a row or a column: O(R + C).

How to answer

Explain why the top-right (or bottom-left) corner works and the top-left does not: from there one direction increases and the other decreases.

Likely follow-ups
  • Whole matrix sorted in row-major order (binary search on k = r * C + c).
  • K-th smallest in such a matrix (binary search on the value, count with the staircase).
