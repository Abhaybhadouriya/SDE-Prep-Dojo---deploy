Spiral order: four walls that move inward

LeetCode 54 asks for all elements of an R x C matrix in clockwise spiral order. The clean method keeps four walls, top, bottom, left, right, that mark the part of the matrix not yet visited. Each lap walks along the top wall, down the right wall, back along the bottom wall and up the left wall, moving each wall inward right after it is used.

  1. A 3 x 4 matrix. The four walls enclose everything: top = 0, bottom = 2, left = 0, right = 3.
  2. Walk the top row left to right, then move the top wall down (top = 1). Row 0 is done for good.
  3. Walk the right column from top to bottom (rows 1-2), then move the right wall left (right = 2).
  4. If a row is still left between the walls (top <= bottom), walk the bottom row right to left and move bottom up.
  5. If a column is still left (left <= right), walk the left column bottom to top and move left right.
  6. Second lap: the top row now holds only 6 and 7. After it, top > bottom, so the remaining legs do nothing and the loop ends.
  7. Output: 1 2 3 4 8 12 11 10 9 5 6 7. O(R * C) time, O(1) extra space besides the output.

The two if guards before the third and fourth legs are the whole difficulty. Without them, a single remaining row is walked twice (once left to right, then again right to left), and a 1 x 3 matrix prints 1 2 3 2 1. Test your code on a single row, a single column and a 1 x 1 matrix.

Variants: Spiral Matrix II fills 1..n2 in the same order (same walls, write instead of read). Spiral Matrix III walks a spiral outwards from a start cell with leg lengths 1, 1, 2, 2, 3, 3, ... and records only the cells that fall inside the grid. An alternative to the walls is the "turn when blocked" simulation with direction arrays and a visited mark; it is easier to get right under pressure, at the cost of O(R * C) extra space unless you mark cells in place.
