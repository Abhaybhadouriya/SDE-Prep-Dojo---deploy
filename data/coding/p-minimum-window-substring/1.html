The problem (in our words)

A warehouse log is a string s of length m: one letter per arriving package type, in arrival order. An order is a string t of length n, and it may contain the same letter more than once.

Find the shortest contiguous part (substring) of s that contains every character of t, with duplicates: if t has two 'a', the window needs at least two 'a'. Return that substring, or the empty string "" if no such window exists. The tests guarantee that the shortest window is unique.

Signature: String minWindow(String s, String t).

Constraints

  • m == s.length, n == t.length
  • 1 <= m, n <= 10^5
  • s and t contain only uppercase and lowercase English letters (case matters: 'a' ≠ 'A').

Follow-up from the original: can you do it in O(m + n) time?

Practice it: LeetCode 76 - Minimum Window Substring · GfG - Smallest window containing all characters of another string · TUF - Minimum window substring

Constraints tell you: m up to 10^5 rules out trying all O(m²) substrings. The alphabet is 52 letters, so a fixed array of 128 counters replaces a hash map, and comparing two count arrays costs 52 steps; the "missing" counter removes even that.
