Common mistakes

Mixing the two counter styles. This page counts missing copies. Another common style counts distinct letters whose count is met ("formed == required"); then formed may change only when a count becomes exactly equal to t's count. Bumping it on every useful copy over-counts and declares the window valid too early.

Recording the answer after the shrink loop. For a shortest window, record inside the loop, while the window is still valid. After the loop it is already invalid. (For a longest window it is the other way round.)

Calling substring on every improvement. Store start and length; cut the string once at the end. Building strings in the loop can turn O(m) into O(m²).

Using 0 or m as the "no answer" length. If the whole string is the answer, length m is a real result. Use m + 1 (or infinity) as the sentinel.

Signed char indexes in C/C++. Indexing an array with a plain char is fine for letters but undefined for bytes ≥ 128. Cast to unsigned char if the alphabet can grow.
