Recognise the pattern

When you see "shortest substring/subarray" + "that contains / covers / satisfies X", where adding elements can only help and removing can only hurt, think variable sliding window: expand right until valid, shrink left while valid.

When you see "contains all characters of t with counts", think a need[] array plus one counter of how many characters are still missing.

The property that makes the window work is monotonicity: if s[l..r] covers t, any longer window s[l'..r'] with l' ≤ l and r' ≥ r covers it too. So for each right edge, the best left edge only moves right as the right edge moves right. Neither pointer ever moves back.
