The story

Explain like I'm 5

You have n lids and n boxes to line up. A lid may only go on after a box that is still open. Walking left to right, you can always add a new box if you have boxes left, and you can add a lid only if some box is still waiting for one. Follow these two rules and every line you finish is a correct one; you never have to throw any away.

From your world

It is the same balance counter you would use to check nesting in a parser or to match lock/unlock calls: depth goes up on open, down on close, and must never go below zero. Here you run that check while generating, so illegal prefixes are never built.
