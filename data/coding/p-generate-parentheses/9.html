  • Insight: well-formed ⇔ every prefix has close ≤ open ≤ n, and the end has open = close = n.
  • State: (open, close) counts: add '(' if open < n, ')' if close < open; record at length 2n.
  • Trap: close < n is wrong; undo the char after each call.
  • Cost: C(n) answers, O(4^n / √n) total; O(n) extra space.

When may you append ')'?

  1. When close < n
  2. Always, then check at the end
  3. When close < open
A ')' must close an unmatched '('; close < open says one exists.

How many strings for n = 6?

  1. 132
  2. 64
  3. 720
The Catalan numbers are 1, 2, 5, 14, 42, 132, ...; C(6) = 12! / (7! · 6!) = 132.

Why does the counter method never hit a dead end?

  1. Because n ≤ 8
  2. Any prefix with close ≤ open ≤ n can be completed by adding the missing ')'
  3. Because '(' is tried first
So every branch reaches a leaf, and every leaf is an answer: the work matches the output.
