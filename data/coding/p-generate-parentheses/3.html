Recognise the pattern

When you see "return all strings / combinations" + a validity rule that can be checked on a prefix, think backtracking: choose a character, recurse, un-choose, and cut a branch as soon as its prefix cannot be completed.

When you see brackets, think balance counter: open - close must stay ≥ 0 and end at 0.

The key step is turning "well-formed" into two prefix rules. A string is well-formed exactly when (a) every prefix has close ≤ open and (b) the full string has open = close = n. So while building: add '(' only if open < n, add ')' only if close < open. Each rule blocks only prefixes that can never be completed.

Taxonomy: Backtracking → Generate strings → Generate. Pattern lesson: Backtracking. Validity check alone: Valid Parentheses.
