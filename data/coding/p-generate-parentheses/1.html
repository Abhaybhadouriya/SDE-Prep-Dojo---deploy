The problem (in our words)

A code formatter wants every possible way to nest n pairs of round brackets. Given the integer n, return all strings of length 2n made of '(' and ')' that are well-formed: every opening bracket is closed later, and no closing bracket appears without an unmatched opening bracket before it.

The answer may be returned in any order, and each string must appear exactly once.

Signature: List<String> generateParenthesis(int n).

Constraints

  • 1 <= n <= 8

Practice it: LeetCode 22 - Generate Parentheses · GfG - Generate Parentheses

Constraints tell you: n ≤ 8 means at most 1,430 answers of length 16, so even generating all 2^16 = 65,536 strings and filtering would pass. The interviewer wants the pruned backtracking and a clear reason why each pruning rule is safe, plus the output-sensitive complexity.
