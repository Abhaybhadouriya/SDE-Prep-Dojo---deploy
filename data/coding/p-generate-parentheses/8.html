Common mistakes

Using close < n instead of close < open. That allows "())("-style prefixes and produces invalid strings.

Forgetting to undo the character. With a shared StringBuilder or list, skipping pop() after the call leaks characters into the sibling branch.

Generating with a Set to remove duplicates. Approaches like "insert '()' at every position of each n-1 answer" create duplicates and need a set; the counter method never makes a duplicate, so no set is needed.

Calling the complexity O(2^(2n)) for the pruned version. It is output-sensitive: O(C(n) · n) ≈ O(4^n / √n). Say "proportional to the size of the output", then give the Catalan bound.
