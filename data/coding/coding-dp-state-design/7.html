The checklist

  1. Brute force first. Write the recursive search in one or two sentences: "at position i, I either ... or ...".
  2. List its parameters and shrink each to an integer in a small range (index, count, mask, mode).
  3. Say the state sentence: what is measured, over which part of the input, under which condition.
  4. Run the photo test: two histories with the same state, same best future? If not, add the missing fact.
  5. Write the transition from the decision whose consequences the state fully describes (last character, both ends, the balloon burst last).
  6. Base cases with the right identity: 0 for sums, 1 for counts of "do nothing", -infinity or infinity for impossible, true for the empty match.
  7. Find the answer cell: dp[0] for suffix states, dp[n] for prefix states, dp[0][n-1] for intervals, or a max over a whole row.
  8. Count the cost (states x work) against the constraints, before typing.
  9. Memo, then table, then compress if time allows: only keep the rows the transition reads.
  10. Test on the smallest cases: empty input, one element, all equal, the example from the statement traced by hand.
