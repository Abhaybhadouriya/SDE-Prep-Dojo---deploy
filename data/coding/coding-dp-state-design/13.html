In the exam-points problem, why is the running score not part of the state?

  1. It is always zero
  2. Memoisation cannot handle two parameters
  3. It is too large to store
  4. The best way to continue does not depend on it; we add points on the way back up
best(i) returns "most points from i onward". The score so far changes nothing about the future, so including it would only multiply the states.

A recursion best(i) calls best(i + 1) and best(i + 3). The table should fill:

  1. i from 0 up to n-1
  2. in any order
  3. i from n-1 down to 0
  4. by length of interval
Calls go to larger i, so larger i must be ready first: fill in the reverse direction.

LCS of "CABD" and "ABCD" is:

  1. 3
  2. 1
  3. 4
  4. 2
"ABD" appears in both in order. No common subsequence of length 4 exists, because "CABD" and "ABCD" differ. The bottom-right cell of the table is 3.

For an interval table pal[l][r] that reads pal[l+1][r-1], pal[l+1][r] and pal[l][r-1], a valid loop is:

  1. r from n-1 down, l from 0 up
  2. l from n-1 down to 0, r from l up to n-1
  3. l from 0 up, r from 0 up
  4. any order, as long as it is a nested loop
Row l+1 must be done before row l, and within a row the cell to the left must be done first.

Interleaving String uses state (i, j) instead of (i, j, k) because:

  1. s3 is never longer than 100
  2. k is always 0
  3. the third index is stored in a hash map
  4. k is always i + j
Every character of s3 produced so far came from s1 or s2, so its position is determined by the other two.

In stock with cooldown, why is hold initialised to minus infinity?

  1. To make the code shorter
  2. Before the first day you cannot own a share, so that state must be unreachable
  3. Prices can be negative
  4. So that the answer is negative when there is no profit
Starting hold at 0 would mean "you own a share for free", which inflates the profit of the first sale.

n ≤ 16 people must each be assigned to exactly one task. Which state shape fits?

  1. Interval (l, r)
  2. Index + bitmask of tasks already taken
  3. Index + 2 modes
  4. Pair of prefixes
"Assign every item" with n that small is the bitmask family: 216 x 16 states is about a million.
