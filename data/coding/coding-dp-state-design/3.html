Two inputs: the pair-index state

When the problem gives you two sequences and asks how they line up (match, edit, interleave, merge), one index is not enough: the future depends on how far you are in each. The state is a pair (i, j), and almost always it means "the first i characters of a and the first j characters of b".

The problem (Longest Common Subsequence, restated). Given two lowercase strings, each up to 1,000 characters, return the length of the longest sequence of characters that appears in both in the same order, not necessarily next to each other. "ace" is common to "abcde" and "ace"; for "abc" and "def" the answer is 0.

  • State: lcs[i][j] = the LCS length of a[:i] and b[:j].
  • Choices, by looking at the last characters: if a[i-1] == b[j-1], use them together: lcs[i-1][j-1] + 1. Otherwise one of them is not in the answer, so drop it: max(lcs[i-1][j], lcs[i][j-1]).
  • Base: row 0 and column 0 are 0 (an empty prefix).
  • Answer and cost: lcs[n][m]; (n+1)(m+1) states x O(1) = O(n x m).
  1. Two sequences, so the state needs one index into each: lcs[i][j] is the answer for the first i letters of a and the first j letters of b.
  2. Row 0 and column 0 stand for an empty prefix. Making them part of the table removes every "if i == 0" branch from the loop.
  3. Row C: the only match is column C (green), built from the orange diagonal cell. Every other cell copies the larger of up and left.
  4. Row A: A matches column A, so 0 + 1 = 1, and the 1 spreads right through "max(up, left)".
  5. Row B: B matches column B with diagonal 1, giving 2. The C we matched in row 1 is now beaten: "AB" is better than "C".
  6. Row D: D matches D with diagonal 2, giving 3. Each row read only the row above it, so one row plus a saved diagonal is enough.
  7. The answer is the bottom-right cell. Walking back through the green matches recovers the subsequence itself: "ABD".
// PAIR-INDEX state: lcs[i][j] = LCS length of the prefixes a[:i] and b[:j].
func lcsTable(a, b string) int {
	n, m := len(a), len(b)
	lcs := make([][]int, n+1) // row 0 / column 0 = empty prefix
	for i := range lcs {
		lcs[i] = make([]int, m+1)
	}
	for i := 1; i <= n; i++ {
		for j := 1; j <= m; j++ {
			if a[i-1] == b[j-1] {
				lcs[i][j] = lcs[i-1][j-1] + 1 // both last chars used together
			} else {
				lcs[i][j] = max(lcs[i-1][j], lcs[i][j-1]) // drop one last char
			}
		}
	}
	return lcs[n][m]
}

// Same recurrence in one row; `diag` remembers lcs[i-1][j-1] before it is overwritten.
func lcs(a, b string) int {
	m := len(b)
	row := make([]int, m+1)
	for i := 0; i < len(a); i++ {
		diag := 0
		for j := 1; j <= m; j++ {
			above := row[j]
			if a[i] == b[j-1] {
				row[j] = diag + 1
			} else {
				row[j] = max(row[j], row[j-1])
			}
			diag = above
		}
	}
	return row[m]
}
// PAIR-INDEX state: lcs[i][j] = LCS length of the prefixes a[0..i) and b[0..j).
int lcsTable(const string& a, const string& b) {
    int n = a.size(), m = b.size();
    vector<vector<int>> lcs(n + 1, vector<int>(m + 1, 0));       // row 0 / column 0 = empty prefix
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            lcs[i][j] = a[i - 1] == b[j - 1] ? lcs[i - 1][j - 1] + 1          // both last chars used
                                             : max(lcs[i - 1][j], lcs[i][j - 1]);  // drop one
    return lcs[n][m];
}

// Same recurrence in one row; `diag` remembers lcs[i-1][j-1] before it is overwritten.
int lcs(const string& a, const string& b) {
    int m = b.size();
    vector<int> row(m + 1, 0);
    for (char ch : a) {
        int diag = 0;
        for (int j = 1; j <= m; j++) {
            int above = row[j];
            row[j] = ch == b[j - 1] ? diag + 1 : max(row[j], row[j - 1]);
            diag = above;
        }
    }
    return row[m];
}
// PAIR-INDEX state: lcs[i][j] = LCS length of the prefixes a[0..i) and b[0..j).
static int lcsTable(String a, String b) {
    int n = a.length(), m = b.length();
    int[][] lcs = new int[n + 1][m + 1];                         // row 0 / column 0 = empty prefix
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            lcs[i][j] = a.charAt(i - 1) == b.charAt(j - 1) ? lcs[i - 1][j - 1] + 1
                                                           : Math.max(lcs[i - 1][j], lcs[i][j - 1]);
    return lcs[n][m];
}

def lcs_table(a, b):
    n, m = len(a), len(b)
    lcs = [[0] * (m + 1) for _ in range(n + 1)]      # row 0 / column 0 = empty prefix
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if a[i - 1] == b[j - 1]:

            else:
                lcs[i][j] = max(lcs[i - 1][j], lcs[i][j - 1])   # drop one last char

# Same recurrence in one row; `diag` remembers lcs[i-1][j-1] before it is overwritten.
def lcs(a, b):
    row = [0] * (len(b) + 1)
    for ch in a:
        diag = 0
        for j in range(1, len(b) + 1):
            above = row[j]
            row[j] = diag + 1 if ch == b[j - 1] else max(row[j], row[j - 1])
            diag = above
    return row[-1]

The same skeleton, with a different last-character rule, solves a whole family. Edit Distance uses min of insert, delete and replace, each costing 1. Delete Operation for Two Strings is n + m - 2 x LCS. Distinct Subsequences counts instead of maximising. Uncrossed Lines is LCS on numbers with a story about lines. From your world

LCS is the core of diff: the lines you keep are the common subsequence, everything else is a + or a -. GNU diff uses Myers' algorithm, which explores the same (i, j) grid but only along the cheapest diagonals, which is why it is fast on files that are mostly equal.
