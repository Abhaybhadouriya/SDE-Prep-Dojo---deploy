Revision card

  • Cue: A DP problem where you cannot see the recurrence yet.
  • Insight: The state is the least you must know about the past to finish optimally (two histories, same state, same best future).
  • State: Write the brute force, then shrink its parameters to small integers: index, index + mode, two prefixes, interval, budget, mask.
  • Trap: A state that misses a condition (holding, used k); keeping coordinates that are implied (k = i + j).
  • Cost: Number of states x work per state.

More to remember

  • The state is the "photo": the least you must know about the past to finish optimally.
  • Photo test: two histories with the same state must have the same best future.
  • Find it by writing the brute force and shrinking its parameters to small integers.
  • State sentence = what is measured + over which part of the input + under which condition.
  • Shapes: index (prefix/suffix), index + mode, pair of prefixes, interval, index + budget, bitmask.
  • Transition from the decision the state fully describes: last item, both ends, the one done last.
  • Fill in reverse of the call direction; cost = states x work; drop coordinates that are implied (k = i + j).
