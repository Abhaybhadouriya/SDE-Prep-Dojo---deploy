Euler paths: Hierholzer and the itinerary problem

An Euler path uses every edge exactly once; an Euler circuit also ends where it started. Unlike the Hamiltonian path (every vertex once), which is NP-hard, existence is a simple degree check.

Reconstruct Itinerary: you have airline tickets [from, to]; use all of them exactly once in one trip starting at JFK; if several trips work, return the one that is smallest when read as a list of airport names. A valid trip is guaranteed. The natural first attempt, "always fly to the alphabetically smallest unused destination", fails: it can walk into an airport with no tickets left while other tickets are still unused. The stepper shows the smallest example of that trap and how Hierholzer escapes it.

  1. Tickets: JFK → AMS, JFK → BOM, BOM → JFK. Start with JFK on the stack. Each airport's unused tickets are kept sorted so we always try the smallest name first.
  2. JFK has unused tickets; take the smallest, AMS, and push it. Ticket t1 is now used.
  3. AMS has no unused tickets. A plain greedy walk would stop here with a ticket left over. Hierholzer instead pops AMS and appends it to the route: AMS must be the final stop.
  4. Back on JFK, which still has a ticket: walk to BOM and push it.
  5. BOM → JFK: push JFK. All three tickets are used.
  6. JFK has nothing left: pop it into the route.
  7. BOM has nothing left: pop it into the route.
  8. Pop the last JFK. The stack is empty. The route was built backwards, so reverse it: JFK → BOM → JFK → AMS uses every ticket once.

Hierholzer's rule: walk unused edges as far as you can. When the current vertex has no unused edge left, it is finished: move it to the output. Because a vertex is only emitted once all its outgoing edges are used, any sub-tour you discover later is spliced in before it. The output comes out in reverse order. Trying the smallest destination first, and emitting in post-order, gives the lexically smallest trip.

// 4. Hierholzer: Euler path using every ticket once, smallest lexical order (Reconstruct Itinerary).
func findItinerary(tickets [][]string, start string) []string {
	adj := map[string][]string{}
	for _, t := range tickets {
		adj[t[0]] = append(adj[t[0]], t[1])
	}
	for k := range adj {
		sort.Sort(sort.Reverse(sort.StringSlice(adj[k]))) // reverse: last = smallest
	}
	route, st := []string{}, []string{start}
	for len(st) > 0 {
		u := st[len(st)-1]
		if out := adj[u]; len(out) > 0 {
			st = append(st, out[len(out)-1]) // walk an unused edge
			adj[u] = out[:len(out)-1]
		} else {
			route = append(route, u) // dead end: u is final, emit it
			st = st[:len(st)-1]
		}
	}
	for i, j := 0, len(route)-1; i < j; i, j = i+1, j-1 {
		route[i], route[j] = route[j], route[i]
	}
	return route
}
// 4. Hierholzer: Euler path using every ticket once, smallest lexical order (Reconstruct Itinerary).
vector<string> findItinerary(const vector<vector<string>>& tickets, const string& start) {
    unordered_map<string, vector<string>> adj;
    for (const auto& t : tickets) adj[t[0]].push_back(t[1]);
    for (auto& kv : adj) sort(kv.second.rbegin(), kv.second.rend());   // reverse: back() = smallest
    vector<string> route, st(1, start);
    while (!st.empty()) {
        string u = st.back();                     // copy: push_back below may reallocate
        auto it = adj.find(u);
        if (it != adj.end() && !it->second.empty()) {
            st.push_back(it->second.back());      // walk an unused edge
            it->second.pop_back();
        } else {
            route.push_back(u);                   // dead end: u is final, emit it
            st.pop_back();
        }
    }
    reverse(route.begin(), route.end());
    return route;
}
// 4. Hierholzer: Euler path using every ticket once, smallest lexical order (Reconstruct Itinerary).
static List<String> findItinerary(List<List<String>> tickets, String start) {
    Map<String, PriorityQueue<String>> g = new HashMap<>();
    for (List<String> t : tickets) g.computeIfAbsent(t.get(0), k -> new PriorityQueue<>()).add(t.get(1));
    LinkedList<String> route = new LinkedList<>();
    ArrayDeque<String> st = new ArrayDeque<>();
    st.push(start);
    while (!st.isEmpty()) {
        PriorityQueue<String> out = g.get(st.peek());
        if (out != null && !out.isEmpty()) st.push(out.poll());   // walk the smallest unused edge
        else route.addFirst(st.pop());                            // dead end: emit (in reverse)
    }
    return route;
}
from collections import defaultdict

# 4. Hierholzer: Euler path using every ticket once, smallest lexical order (Reconstruct Itinerary).
def find_itinerary(tickets, start='JFK'):
    adj = defaultdict(list)
    for a, b in tickets:
        adj[a].append(b)
    for a in adj:
        adj[a].sort(reverse=True)             # reverse: pop() gives the smallest
    route, stack = [], [start]
    while stack:
        u = stack[-1]
        if adj[u]:
            stack.append(adj[u].pop())        # walk an unused edge
        else:
            route.append(stack.pop())         # dead end: u is final, emit it
    return route[::-1]

Cost. Each ticket is pushed and popped once: O(E) for the walk, O(E log E) for sorting the destination lists. The adjacency lists are sorted in reverse so that taking the smallest is a pop from the end, O(1). A min-heap per airport also works.

Where else it shows up

  • Valid Arrangement of Pairs: reorder pairs so each one's end equals the next one's start. It is a directed Euler path; the start vertex is the one with out-degree - in-degree = 1, or any vertex if all are balanced. Then the same stack loop.
  • Cracking the Safe: the shortest string that contains every n-digit code over k digits. Make each (n - 1)-digit string a vertex and each n-digit code an edge; every vertex has in-degree = out-degree = k, so an Euler circuit exists. Its length is kn + n - 1. This is a de Bruijn sequence.

From your world

The explicit stack in Hierholzer and in the iterative Tarjan is the same trade you make in kernel code, where stacks are a fixed few pages (16 KB on x86-64) and deep recursion is not acceptable: keep the "frame" (vertex, next edge index) in your own array and loop. Interviewers like hearing why you would do this, not just that you can.
