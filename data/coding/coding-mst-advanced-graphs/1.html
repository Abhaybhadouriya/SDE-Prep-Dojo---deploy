Spanning trees and the cut property

A spanning tree of a connected undirected graph is a set of edges that connects all V vertices with no cycle. It always has exactly V - 1 edges: fewer cannot connect everyone, more must close a cycle. A minimum spanning tree is a spanning tree whose total weight is as small as possible. If the graph is not connected there is no spanning tree, only a minimum spanning forest, and most problems want you to return -1.

Two facts carry every MST proof, and you should be able to say both in one sentence each:

  • Cut property. Split the vertices into any two groups. The lightest edge crossing between the groups belongs to some MST (to every MST if that edge is strictly lightest). Reason: if a tree avoided it, adding it creates a cycle that crosses the split twice; drop the other, heavier crossing edge and the tree got cheaper.
  • Cycle property. On any cycle, a strictly heaviest edge belongs to no MST. You can always reconnect without it more cheaply.

If all weights are distinct the MST is unique. With ties there can be several MSTs, but they all have the same total weight, and every one of them has the same multiset of edge weights. That last fact matters for the "critical and pseudo-critical edges" problem later.
