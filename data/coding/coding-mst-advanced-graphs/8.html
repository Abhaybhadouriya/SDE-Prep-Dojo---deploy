How to recognise it

  • MST: the answer is one number, a total cost, and the chosen edges must connect everything. "Total cost" plus "no need for a direct link, any path will do" is the giveaway. If the question asks for the cheapest route between two points, it is shortest paths instead.
  • MST on a hidden graph: points on a plane, words with a distance, houses with wells. You build the edges yourself; count them before choosing Kruskal or array Prim.
  • Bridges / cut vertices: the words "critical", "vulnerable", "single point of failure", "removing one connection / one server / one cell". Constraints of 105 rule out "remove each edge and BFS".
  • Euler: every edge (ticket, domino, pair, code) is used exactly once. If it says every vertex once, it is Hamiltonian: bitmask DP for n ≤ 20 or so, not this page.
