Choosing the tool

Signal in the problemReach for
"connect all cities / points / houses with minimum total cost"MST: Kruskal (edge list) or array Prim (all pairs possible)
"each node may pay its own cost instead of connecting"virtual vertex 0, then MST
"minimise the largest edge / height / effort on a path"Kruskal stopped when the two ends join, or minimax Dijkstra
many (p, q, limit) reachability queriessort queries and edges, sweep with union-find
"which edges are in every MST / some MST"Kruskal with each edge excluded / forced
"connection whose removal disconnects", "single point of failure"bridges, low[v] > tin[u]
"server / cell whose removal disconnects"articulation points, low[v] ≥ tin[u] plus the root rule
"use every ticket / domino / pair exactly once", "shortest string containing all codes"Euler path, Hierholzer
