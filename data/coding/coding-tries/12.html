Revision card

  • Cue: Prefix search, autocomplete, word search on a board with many words, maximum XOR pair.
  • Insight: Shared prefixes are stored once, so a walk of length L answers prefix questions.
  • State: node = children[26] or a map + end flag; bit trie with MSB first.
  • Trap: Search forgetting the end flag; not pruning found words in Word Search II.
  • Cost: O(L) per operation; O(total characters x alphabet) space.

More to remember

  • A trie node = children (array of 26 or a map) + an end flag. Path from root = prefix.
  • Insert, search and startsWith are one O(L) walk; only search checks the end flag.
  • Wildcard: follow one edge for a letter, all edges for a dot, stop at the first match.
  • Word Search II: all words in one trie, one DFS per cell with a moving trie pointer; store words at end nodes, clear on hit, prune empty nodes.
  • Autocomplete: sorted list + binary search, or top-k lists stored at trie nodes.
  • Bit trie: insert MSB first; to maximise XOR, take the opposite bit whenever it exists. O(31·n).
