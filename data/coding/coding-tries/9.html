Common mistakes

  • Forgetting the end flag. Without it, search("ca") returns true because the path exists. Every word lookup must check end.
  • Treating "has children" as "is a word end". "car" is a word and also has the child for "card". The two facts are independent.
  • Reporting a word twice in Word Search II. The same word can be traced along two grid paths. Clear the marker after the first hit (or use a set).
  • Not restoring the board cell after DFS, so later starts see '#' where a letter was.
  • Wrong bit width in a bit trie. Values up to 231 - 1 need bits 30..0. If negative numbers are possible, handle the sign bit (offset the values) or the greedy breaks.
  • Array nodes with a large alphabet. 128 or 256 slots per node for "any ASCII character" can blow the memory limit. Use a map, or compress.
  • Rebuilding strings at every node during DFS (string concatenation per step). Store the word at the end node, or keep one mutable buffer.
