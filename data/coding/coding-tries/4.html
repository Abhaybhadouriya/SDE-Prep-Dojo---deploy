Wildcard search: branch only where you must

In "Design Add and Search Words" a query may contain ., which matches any single letter. A normal letter still follows one edge. A dot tries every child at that depth, recursively, and returns true as soon as one branch reaches the end of the query on a node with end = true.

The worst case is a query made only of dots on a full trie: up to 26k branches for k dots, bounded by the number of nodes at that depth. LeetCode limits the dots per query (at most 2 in LC 211), which keeps it fast. Two practical speed-ups: bucket words by length first (a query of length 5 can only match words of length 5), and stop at the first match.
