Approaches: brute → better → optimal

Hint 1

sum(l+1..r) = pre[r] - pre[l]. When is a difference divisible by k?

Hint 2

a - b is a multiple of k exactly when a mod k = b mod k. Which index of an earlier remainder should you keep so that the length check is easiest to pass?

1. Brute force - try every subarray

Idea: for every pair l < r, sum nums[l..r] and test sum % k == 0.

O(n3)time
O(1)space

What is wasted: the sum for r + 1 is the sum for r plus one value. -> rung 2.

2. Better - prefix sums, all pairs

Idea: keep a running sum per start l (or a prefix array) and test each pair with r - l ≥ 1 in O(1).

O(n2)time
O(1)space

What is wasted: for each end r we try every start, but divisibility only depends on pre[r] mod k: we need ONE earlier prefix with the same remainder, far enough back. -> rung 3.

3. Optimal - first index of each remainder

first = {0: -1}; rem = 0
for i, x in enumerate(nums):
    rem = (rem + x) % k
    if rem in first:
        if i - first[rem] >= 2: return True
    else: first[rem] = i             # never overwrite
  1. Divisible difference = equal remainders. pre[r] - pre[l] ≡ 0 (mod k) iff pre[r] mod k = pre[l] mod k.
  2. Carry only the remainder. (rem + x) % k equals pre % k, so the running value stays below k.
  3. Seed {0: -1}. The empty prefix has remainder 0; a good prefix nums[0..r] (r ≥ 1) is then found.
  4. The length is i - first[rem]. It must be ≥ 2, so the earliest index is the best partner: if the earliest one is too close, every later one is closer.
  5. Never overwrite. On a repeat that is too short (a single element that is a multiple of k, or a single 0), keep the old index: the next element may complete a good run against it.
O(n)time (average, hashing)
O(min(n, k))space (distinct remainders)

Why it works: a good subarray nums[l+1..r] exists iff there are indices l < r - 1 (l may be -1) with equal prefix remainders. When the loop reaches r, first[rem] is the smallest such l; if even that one is less than 2 behind, no l works for this r. So the scan returns true at the first r that has any valid partner, and false only if no r has one.

Proof (optional)

Let R(i) = pre(i) mod k with R(-1) = 0. A good subarray is a pair (l, r) with r - l ≥ 2 and R(l) = R(r). Entries of first are written once, at the first occurrence of each remainder, and before any later index reads them. For a fixed r, first[R(r)] = min{l < r : R(l) = R(r)}; a valid l exists iff r - min ≥ 2. The loop checks exactly this for every r, so it returns true iff a good subarray exists. A side note from the pigeonhole principle: with n ≥ k + 1 there are n + 1 ≥ k + 2 remainders over k values, so some value repeats; still, the length rule means you cannot simply return true when n ≥ k.
