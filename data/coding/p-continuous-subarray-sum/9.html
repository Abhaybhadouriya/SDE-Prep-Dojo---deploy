Revision card

  • Cue: subarray sum is a multiple of k, length ≥ 2 -> prefix mod k + first index.
  • Insight: equal remainders at l and r mean nums[l+1..r] is divisible by k.
  • State: rem = prefix % k, first[rem] = earliest index (seed 0 : -1).
  • Trap: length = i - first ≥ 2; never overwrite first; 0 is a multiple; k ≥ 1.
  • Cost: O(n) time, O(min(n, k)) space; brute O(n²).
first = {0: -1}; rem = 0
for i, x in enumerate(a):
    rem = (rem + x) % k              # key = prefix mod k
    if rem in first:
        if i - first[rem] >= MIN_LEN: return True
    else:
        first[rem] = i               # first index only
return False

Quick quiz

The remainders after index 4 and after index 5 are both 3. What does that tell you?

  1. A good subarray exists
  2. nums[5] is a multiple of k, but length 1 does not count
  3. nums[4..5] is good
  4. Nothing at all
The run between is nums[5] alone: divisible, but too short.

Why is the seed first[0] = -1 and not 0?

  1. Arrays are 1-indexed
  2. To handle k = 0
  3. The empty prefix ends before index 0, so a prefix nums[0..r] has length r - (-1)
  4. It does not matter
Lengths are computed as i - first; the empty prefix sits at position -1.

To COUNT subarrays with sum divisible by k (any length), what changes?

  1. Store counts of remainders, seed {0: 1}, add count[rem] each step
  2. Keep the first index and count repeats
  3. Use a sliding window
  4. Nothing
That is LC 974; with negative values also normalise ((x % k) + k) % k.
