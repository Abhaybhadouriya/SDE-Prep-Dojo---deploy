Example 2, nums = [5,4,2,7,3], k = 7. The rem row is the remainder after each index; a red ring is a repeat that is too short, a green ring the good subarray.

  1. Start: rem = 0, first = {0: -1}. The seed stands for the empty prefix, so a run that starts at index 0 can be found.
  2. x = 5: rem = 5 % 7 = 5. New remainder: store first[5] = 0.
  3. x = 4: rem = (5 + 4) % 7 = 2. New: store first[2] = 1.
  4. x = 2: rem = (2 + 2) % 7 = 4. New: store first[4] = 2.
  5. x = 7: rem = (4 + 7) % 7 = 4, seen at index 2. The run between is [7], length 3 - 2 = 1: a multiple of 7 but too short. Keep first[4] = 2 (do not overwrite).
  6. x = 3: rem = (4 + 3) % 7 = 0, seen at -1 (the seed). Length 4 - (-1) = 5 >= 2: the whole array sums to 21 = 3 x 7. Return true.
