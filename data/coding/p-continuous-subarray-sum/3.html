Recognise the pattern

When you see "subarray sum is a multiple of k / divisible by k" think prefix sum mod k + hash map: equal remainders mean the run between is divisible. "Does one exist with length ≥ 2" -> store the first index; "how many" (LC 974) -> store counts.
