The problem (in our words)

You get an array of non-negative integers nums (crate weights on a belt) and an integer k (the size of a pallet). Return true if there is a good subarray, else false. A good subarray:

  • is contiguous and has length at least 2, and
  • has a sum that is a multiple of k: sum = m · k for some integer m. 0 counts as a multiple of k.

Signature: bool checkSubarraySum(vector<int>& nums, int k).

Constraints:

  • 1 <= nums.length <= 105
  • 0 <= nums[i] <= 109
  • 0 <= sum(nums[i]) <= 231 - 1
  • 1 <= k <= 231 - 1

Practice it: LeetCode 523 - Continuous Subarray Sum

Constraints tell you: n = 105 means O(n) or O(n log n); the O(n2) pair scan is 5·109 additions. k is at least 1, so there is no division by zero (older versions of this problem allowed k = 0). Values are non-negative, so the remainder is never negative. The total fits in a signed 32-bit int, so even the raw prefix sum cannot overflow; k can be huge, so the number of distinct remainders is bounded by min(n + 1, k), not by k.
