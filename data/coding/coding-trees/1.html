The words, with one picture

A binary tree is a set of nodes where each node has a value and at most two child pointers, left and right. Interview code always uses the same node shape:

struct node { int val; struct node *left, *right; };   /* NULL = no child */
WordMeaning
Root, leafThe root has no parent. A leaf has no children.
Depth vs heightDepth = edges from the root down to a node (goes top-down). Height = edges on the longest path from a node down to a leaf (computed bottom-up). LeetCode's "maximum depth" counts nodes, so read each problem's definition.
SubtreeA node plus everything below it. Every subtree is itself a binary tree, which is why recursion fits so well.
Full / complete / perfectFull: every node has 0 or 2 children. Complete: every level is full except maybe the last, which fills from the left (the shape of a binary heap). Perfect: all leaves on the same level, 2h+1 - 1 nodes.
BalancedFor every node, left and right heights differ by at most 1. Height is then O(log n). A skewed tree (every node has only one child) is a linked list with height n - 1.
BSTBinary search tree: everything in the left subtree is smaller than the node, everything in the right subtree is larger. Inorder visits it in sorted order.

One number drives every space bound on this page: h, the height. Recursion and the explicit stack both use O(h) memory: O(log n) for a balanced tree, O(n) for a skewed one.
