Revision card

  • Cue: "Binary tree", depth, diameter, path sum, level order, views, rebuild from traversals.
  • Insight: Every node is a smaller tree: decide what to pass down (state) and what to return up (one arm).
  • State: recursion with a return value and a global best; BFS with a frozen level size.
  • Trap: Returning both arms to the parent (only one arm can continue); recursion depth on a skewed tree.
  • Cost: O(n) time; O(h) recursion stack.

More to remember

  • Pre / in / post order = when you visit the node: before, between, after its children. Inorder of a BST is sorted.
  • Iterative inorder: dive left pushing, pop and visit, turn right. O(h) stack. Morris replaces the stack with temporary threads: O(1).
  • Level BFS: freeze the queue size before each level. Views, zigzag, width, min depth are one-line changes.
  • Bottom-up: return one arm to the parent, update the global answer with both arms.
  • Top-down: pass state (sum, max, bounds, path) down; decide at leaves; undo on the way back.
  • Rebuild needs two traversals or null markers. Preorder + "#" is the easiest serialize.
  • BST validity is an interval inherited from all ancestors, not a parent-child comparison.
