Quiz

Which traversal must you use to free every node of a tree in C without reading freed memory?

  1. Level order
  2. Postorder
  3. Preorder
  4. Inorder
Postorder frees both children before the node, so you never dereference a freed pointer.

In level-order BFS, why do you read the queue size before processing a level?

  1. Children pushed during the level would otherwise be counted in the same level
  2. The queue cannot be read while it changes
  3. To avoid a null pointer
  4. It makes BFS O(log n)
The frozen size is the exact number of nodes in the current level; children pushed meanwhile belong to the next one.

In Binary Tree Maximum Path Sum, what does the recursive helper return to its parent?

  1. The node's value plus the larger non-negative child gain
  2. The global best so far
  3. The node's value plus both child gains
  4. The height of the subtree
The parent can extend only one arm; both arms (the bent path) go into the global answer instead.

Root 6, right child 9, and 9 has a left child 4. Is it a BST?

  1. Yes, every child is on the correct side of its parent
  2. No, 4 is in the right subtree of 6 but smaller than 6
  3. No, because 9 has two children
  4. Yes, because inorder has 6 numbers
Each node must lie inside the interval set by all its ancestors; 4 must be in (6, 9).

What is the extra space of Morris inorder traversal?

  1. O(n)
  2. O(h)
  3. O(1)
  4. O(log n)
It uses a couple of pointers; the stack's job is done by temporary threads in null right pointers.

Why can preorder alone not rebuild a general binary tree?

  1. Preorder is not O(n)
  2. Preorder loses node values
  3. Different shapes can share the same preorder, e.g. [1, 2] with 2 as left or right child
  4. Preorder needs a BST
Add null markers, or a second traversal such as inorder, to make the shape unique. A BST is the exception: values fix the shape.

Minimum depth of the tree [1, 2] (root 1 with only a left child 2)?

  1. 2
  2. Undefined
  3. 1
  4. 0
Depth is measured to a leaf. Node 1 has a child, so it is not a leaf; the only leaf is 2, at depth 2 (counting nodes).
