Common mistakes

  • Validating a BST by comparing only with the children. The subtree 9 → 4 under root 6 passes the local test and is still wrong. Pass bounds down, or check that inorder is strictly increasing.
  • Using int bounds. A node with value INT_MAX makes val < INT_MAX false. Use long, or pass nullable node pointers as bounds.
  • Starting max path sum at 0. All-negative trees must return the largest single value. Start at minus infinity; clamp only the child gains at 0.
  • Returning the bent path to the parent. The parent can extend only one arm. Return max(L, R)-based values, update with L + R.
  • Treating a one-child node as a leaf in path-sum and minimum-depth problems. A leaf has no children; minimum depth of [1, 2] is 2, not 1.
  • Reading q.size() inside the loop condition in level-order BFS. It changes as you push; freeze it first.
  • Copying the path at null instead of at the leaf, which adds every path twice (once per null child).
  • Forgetting to remove Morris threads by breaking out early. The tree stays corrupted and later code loops forever.
  • Deep recursion in Python on a skewed tree of 104 - 105 nodes. Raise sys.setrecursionlimit or go iterative, and say so in the interview.
