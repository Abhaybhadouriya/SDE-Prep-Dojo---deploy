Top-down: carry state along a root-to-leaf path

The mirror image of bottom-up. Here the parent passes something down: the sum so far, the path so far, the maximum seen so far, the allowed value range. The answer is usually decided at a leaf.

# Path Sum II shape: collect every root-to-leaf path with the given total.
def paths(node, remaining, path, out):
    if not node:
        return
    path.append(node.val)                         # choose
    if not node.left and not node.right and remaining == node.val:
        out.append(path[:])                       # copy at a LEAF, never at null
    paths(node.left, remaining - node.val, path, out)
    paths(node.right, remaining - node.val, path, out)
    path.pop()                                    # un-choose (backtrack)
  • Path sum / path sum II: pass the remaining target; check only at leaves. A node with one child is not a leaf.
  • Sum root-to-leaf numbers: pass cur * 10 + val.
  • Count good nodes: pass the max value on the path; a node is good if val >= maxSoFar.
  • Any-start path sum (Path Sum III): prefix sums in a hash map along the path, added on the way down and removed on the way back, the tree version of "subarray sum equals k".

Ancestor questions sit in between. LCA of p and q: return the node if it is p or q; if both children return non-null, this node is the LCA; otherwise pass up whichever side is non-null. For all nodes at distance k or time to infect the tree, first record each node's parent in a hash map (one DFS), then run BFS from the target on the now undirected graph.
