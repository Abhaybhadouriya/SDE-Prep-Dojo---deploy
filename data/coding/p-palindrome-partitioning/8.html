Common mistakes

Saving the path by reference. out.append(path) stores the same list every time, which is empty at the end. Save a copy (path[:], new ArrayList<>(path); in Go copy the slice, since later appends overwrite the shared backing array).

Forgetting to pop. Without the undo step, pieces from a finished branch leak into the next one.

Filling the table in the wrong order. pal[i][j] reads pal[i+1][j-1]; looping i upward reads cells that are not computed yet. Loop i from n-1 down, or loop by length.

Off-by-one in the base case. Save when start == n (all characters used), not when start == n - 1.
