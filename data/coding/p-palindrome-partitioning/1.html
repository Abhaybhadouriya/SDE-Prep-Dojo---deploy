The problem (in our words)

You are given a string s. Split it into one or more contiguous pieces so that every piece is a palindrome (reads the same left to right and right to left). Return all such splits. Each split is a list of the pieces in order; the splits may be returned in any order.

Signature: List<List<String>> partition(String s).

  • 1 <= s.length <= 16
  • s contains only lowercase English letters.

Practice it: LeetCode 131 · GfG All Palindromic Partitions · TUF article

Constraints tell you: n <= 16 is the signal for exponential search. A string of 16 equal letters has 215 = 32,768 valid partitions (every one of the 15 gaps can be cut or not), so the output alone is about n · 2n-1 characters and no polynomial algorithm exists.
