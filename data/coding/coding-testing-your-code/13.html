A loop does lo = mid in one branch and hi = mid - 1 in the other, with mid = (lo + hi) // 2. What happens?

  1. It skips the last element
  2. It is correct
  3. It can loop forever on a range of size two
With two cells, mid rounds down to lo, so lo = mid changes nothing. Round mid up.

In Java, what does -7 % 3 evaluate to?

  1. -2
  2. -1
  3. 2
Java, C, C++ and Go truncate toward zero, so the remainder takes the sign of the dividend. Python gives 2.
