Revision card

  • Cue: You finished typing and want to say "done".
  • Insight: A dry run follows the code you wrote, not the code you meant.
  • State: a table with one column per changing variable; six universal edge cases.
  • Trap: Testing only the given example; fixing a bug without re-running the failing case.
  • Cost: Five minutes of testing per problem.

More to remember

  • Test before you are asked: re-read examples, dry run with a table, edge sweep, fix small, re-run and state complexity.
  • A dry run follows the code you wrote, line by line, with one column per changing variable.
  • Six universal edge cases: empty, one, duplicates, negatives and zero, overflow, cycles. Then the data-type list.
  • Decide what your range means (half-open or closed), then check init, condition, updates and return against it.
  • Binary search: lo = mid needs a rounded-up mid; a size-two range finds the bug.
  • Fix calmly: symptom, smallest failing input, cause in one sentence, one-line patch, re-run.
  • At home, stress test: tiny random inputs, a brute-force oracle, a fixed seed.
