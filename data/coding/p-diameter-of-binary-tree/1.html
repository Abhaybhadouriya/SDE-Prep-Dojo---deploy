The problem (in our words)

You are given the root of a binary tree. Return the length of its diameter: the number of edges on the longest path between any two nodes of the tree. The longest path may bend at any node; it does not have to go through the root.

Signature: int diameterOfBinaryTree(TreeNode root). The tree is given in LeetCode's level-order form, e.g. [10,20,30,40,50], where null marks a missing child.

  • The number of nodes is in the range [1, 104].
  • -100 <= Node.val <= 100

Practice it: LeetCode 543 · GfG Diameter of a Binary Tree · TUF article

Constraints tell you: 104 nodes allows even O(n2) (108 simple steps, borderline), but the expected answer is one O(n) traversal. The values are irrelevant; only the shape matters. The length is counted in edges, not nodes, and a chain of 104 nodes is 104 recursion levels deep.
