Common mistakes

Answering height(root.left) + height(root.right). That is only the best path through the root. Example 3 gives 4 instead of 6.

Returning l + r to the parent. The parent cannot use both branches of its child; return 1 + max(l, r) and keep l + r only in best.

Counting nodes instead of edges. If heights count edges (leaf = 0, null = -1), the bend is l + r + 2. Pick one convention; with "nodes, null = 0" the bend is exactly l + r.

Not resetting the global. A member variable best that is not set to 0 at the start of each call leaks answers between test cases on a judge that reuses the object.
