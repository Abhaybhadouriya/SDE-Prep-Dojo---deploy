Recognise the pattern

When you see "longest / best path between any two nodes" in a tree, think bottom-up DFS: each call returns the best one-branch value to its parent and updates a global with the best two-branch value at itself. Same skeleton as Binary Tree Maximum Path Sum and Longest Univalue Path.
