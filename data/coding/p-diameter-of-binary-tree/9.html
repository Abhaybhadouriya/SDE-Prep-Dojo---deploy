  • Cue: longest/best path between ANY two nodes of a tree -> bottom-up DFS.
  • Insight: each path bends at one top node; bend value = height(left) + height(right).
  • State: best (global max of l + r); function returns 1 + max(l, r).
  • Trap: return ONE branch, record TWO; edges not nodes; reset best.
  • Cost: O(n) time, O(h) stack; brute recompute heights O(n2).
best = 0
def down(t):                     # best one-branch value below t
    global best
    if not t: return 0
    l, r = down(t.left), down(t.right)
    best = max(best, combine(l, r))   # two branches: answer candidate
    return extend(max(l, r))          # one branch: for the parent

What does the recursive helper RETURN to its parent?

  1. left + right
  2. 1 + max(left, right), one branch
  3. the diameter so far
  4. the number of nodes
A parent can extend only one branch of the child. Two branches (left + right) are recorded in the global best, never returned.

A single node: is the diameter 0 or 1?

  1. 0, it counts edges
  2. 1, it counts nodes
  3. undefined
  4. 2
LeetCode counts edges. Height of a null child is 0, so l + r = 0 at a leaf.

Must the longest path pass through the root?

  1. yes
  2. no; it can bend at any node, which is why best is checked at every node
  3. only in a balanced tree
  4. only when the tree has more than 2 nodes
A deep left subtree can hold the longest path entirely, so the root's l + r is just one candidate.
