60-second recall

  • Cue: a value must beat both neighbours on some order, minimise the total -> two passes.
  • Insight: candies[i] = max(left climb, right climb); each pass sees one rule.
  • State: give[] (pass 1 left rule, pass 2 right rule with max); or up/down/peak.
  • Trap: max in pass 2, ties ask nothing, peak +1 only when down > peak.
  • Cost: O(n) time, O(n) space; slope counting is O(1) space.
L = [1] * n; R = [1] * n         # two-pass skeleton
for i in range(1, n):
    if cond(i, i - 1): L[i] = L[i - 1] + 1
for i in range(n - 2, -1, -1):
    if cond(i, i + 1): R[i] = R[i + 1] + 1
ans = sum(max(l, r) for l, r in zip(L, R))
