  • Cue: equal / mirror / copy of a tree -> walk two subtrees in lockstep.
  • Insight: symmetric = root.left mirrors root.right; pairs cross (outer, inner).
  • State: a pair (a, b): recursion arguments or a queue of pairs.
  • Trap: nil checks before values; never compare left with left.
  • Cost: O(n) time; O(h) recursion or O(w) queue; brute copy+invert O(n) extra.
def pair_ok(a, b):
    if a is None or b is None:
        return a is b
    return (a.val == b.val
            and pair_ok(a.left, b.right)   # same tree: (a.left, b.left)
            and pair_ok(a.right, b.left))  # same tree: (a.right, b.right)

Which pairs of nodes must match in the mirror check?

  1. left.left with right.left
  2. left.left with right.right, and left.right with right.left
  3. each node with its sibling only
A mirror swaps sides, so outer children pair with outer children and inner with inner.

isMirror(a, b) where exactly one of a, b is null returns?

  1. true
  2. false
  3. it depends on the values
A missing node on one side and a present node on the other breaks the mirror.

Extra space of the recursive check?

  1. O(1)
  2. O(h), the tree height (O(n) for a skewed tree)
  3. O(n^2)
The recursion stack goes as deep as the tree.
