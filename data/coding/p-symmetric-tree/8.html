Common mistakes

Pairing left with left. mirror(a.left, b.left) checks "same tree", not "mirror". The pairs must cross: outer (left, right), inner (right, left).

Comparing only level values. Reading each level and testing for a palindrome passes example 1 and fails example 2, unless the nulls are written out too.

Checking values before nulls. a.val == b.val when one of them is null crashes (NPE / segfault). Test for missing nodes first.

In-order traversal as a palindrome. Different shapes can give the same in-order list (for example [1,2,2,2,null,2] reads 2 2 1 2 2 and is not symmetric). One traversal does not fix the shape.

Iterative version that skips nil pairs before pushing. If you only push children that exist, a (6, nil) pair is never seen and a wrong shape passes. Push the pair, decide when you pop it.
