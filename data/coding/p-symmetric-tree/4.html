Approaches: brute -> better -> optimal

Hint 1

Could you solve "are these two trees the same?" first? What changes if one of them is flipped?

Hint 2

The left child of one side must be compared with the right child of the other side.

1. Brute force - build the mirror, then compare

Idea: copy the tree and invert the copy (swap every node's children, as in Invert Binary Tree). Then run Same Tree on the original and the copy. Correct, but it allocates a whole second tree.

O(n)time
O(n)extra space (the copy)

What is wasted: the copy exists only to be read once. We can read the "mirror" on the fly by visiting the right subtree in reverse child order. A second weak idea is to compare level values as palindromes: it fails on example 2 unless you also print the nulls.

2. Optimal - lockstep recursion over mirror pairs

def mirror(a, b):
    if a is None or b is None: return a is b
    return a.val == b.val and mirror(a.left, b.right) and mirror(a.right, b.left)
return mirror(root.left, root.right)
  1. The question is about two subtrees, not one tree. Symmetric means root.left is the mirror of root.right; the root itself always matches.
  2. Missing nodes decide first. Both missing: match. Exactly one missing: the shape differs, stop.
  3. Then the values, then the crossed children. Outer pair (a.left, b.right), inner pair (a.right, b.left). and short-circuits, so the first mismatch stops the whole walk.
O(n)time (each node in one pair)
O(h)stack; h = height, n in a skewed tree

Why it works: flipping a tree means: swap left and right at every node. So subtree A is the mirror of subtree B exactly when their roots are equal, A's left is the mirror of B's right, and A's right is the mirror of B's left. That definition is recursive, and the code is the definition.

Proof (optional)

Induction on the total size of the pair. Size 0: both nil, true; one nil, false, which is correct because a mirror has the same number of nodes. Otherwise both exist. If the values differ, the flip of A has a different root than B. If they are equal, the flip of A is "root, flip(A.right), flip(A.left)", which equals B exactly when flip(A.right) = B.left and flip(A.left) = B.right; both pairs are smaller, so by induction mirror answers them correctly.

3. Iterative - a queue of pairs (the follow-up)

Idea: the same check without recursion. Push the pair (root.left, root.right); pop a pair, apply the three rules, and push the outer and inner child pairs. A stack works just as well as a queue: the order of the checks does not matter, only that every pair is checked.

O(n)time
O(w)queue; w = widest level

Use it when the interviewer asks for no recursion, or when the tree can be deep enough to overflow a thread stack (kernel stacks are 8-16 KB, so this is the version you would ship in C there).
