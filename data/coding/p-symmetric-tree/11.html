Interview follow-ups

Do it without recursion.

A queue (or stack) of node pairs, as in rung 3. Push nil pairs too and decide when you pop them, otherwise a one-sided child is never examined.

How to answer

Say that recursion and the queue check the same set of pairs in a different order, so the cost is the same O(n).

Likely follow-ups
  • Queue or stack: which uses less memory on a complete tree? (Stack: O(h); queue: O(w) ≈ n/2 at the last level.)
Can a level-order traversal decide it?

Yes, if you write the missing children as a marker and test that each level, markers included, reads the same both ways. It costs O(w) per level and is more code than the pair walk; without the markers it is wrong (example 2).

How to answer

Show the counterexample first; then explain the marker fix.

Likely follow-ups
  • Which marker is safe when values can be anything? Use a null pointer, not a sentinel value.
Check symmetry for an n-ary tree.

Pair child i of A with child k-1-i of B, after checking that both have the same number of children k. The recursion is the same; each node is still in one pair.

How to answer

Generalise "outer and inner pair" to "the children list read backwards".

Likely follow-ups
  • Can you stop early? Yes: and short-circuits the first failing pair.
Return how many nodes would need a value change to make it symmetric (the shape already is).

Walk the same pairs, but instead of returning false, add 1 for each pair with different values. The two nodes of a pair can be made equal with one change, so the count of mismatched pairs is the answer.

How to answer

Change the return type from bool to int; the walk stays the same.

Likely follow-ups
  • What if the shape can differ too? Then define a cost for a missing node and it becomes a small tree DP.
What is the worst-case recursion depth, and when does it matter?

The depth of the deeper side, up to n/2 for a tree that is two long chains. With n ≤ 1000 it is safe; for a million-node tree in Python or on a small thread stack, switch to the explicit queue.

How to answer

Connect the space bound O(h) to a real limit: Python's 1000-frame default, a kernel's fixed stack.

Likely follow-ups
  • Morris-style O(1) space? Possible but rarely expected; mention it, do not code it.
