The problem (in our words)

You are given the root of a binary tree that models a hanging mobile: each node carries a weight value. Return true if the mobile is a mirror image of itself around the vertical line through the root (the left half, flipped, is exactly the right half in both shape and values), and false otherwise.

Signature: boolean isSymmetric(TreeNode root). Trees are written in LeetCode's level-order form, with null for a missing child.

  • The number of nodes is in the range [1, 1000].
  • -100 <= Node.val <= 100

Follow-up: solve it both recursively and iteratively.

Practice it: LeetCode 101 · GfG Symmetric Tree · TUF article

Constraints tell you: n <= 1000, so anything linear is far below the limit; the real test is correctness on shape. A skewed tree can be 1000 deep, which is still a safe recursion depth in every language here (Python's default limit is 1000 frames, but the mirror walk only goes as deep as half the tree on each side). At least one node, so the root is never null on LeetCode, but handle it anyway.
