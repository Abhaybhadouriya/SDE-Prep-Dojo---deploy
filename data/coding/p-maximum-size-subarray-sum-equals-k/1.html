The problem (in our words)

You get an integer array nums (daily profit and loss, so values can be negative) and an integer k. Return the maximum length of a contiguous subarray whose elements sum to exactly k. If no such subarray exists, return 0.

Signature: int maxSubArrayLen(vector<int>& nums, int k).

Constraints:

  • 1 <= nums.length <= 2 * 105
  • -104 <= nums[i] <= 104
  • -109 <= k <= 109

Practice it: LeetCode 325 - Maximum Size Subarray Sum Equals k Premium · TUF - longest subarray with sum k (free)

Constraints tell you: n = 2·105 means O(n2) = 4·1010, far too slow, so O(n). Values down to -104 mean the running sum is not monotonic: no sliding window. |prefix| can reach 2·105 · 104 = 2·109 and run - k up to 3·109, both above INT_MAX (2.147·109): use 64-bit sums in C++ and Java.
