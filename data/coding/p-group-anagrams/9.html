Revision card

  • Cue: group items equal up to reordering → canonical key + hash map.
  • Insight: key = 26 letter counts (or sorted word); equal key exactly for anagrams.
  • State: map key → list of words (plus first-seen order if needed).
  • Trap: set/sum keys collide; "1"+"11" vs "11"+"1" without a separator; lists not hashable.
  • Cost: O(N·K) with counts, O(N·K log K) with sorting; brute O(N²·K).
groups = defaultdict(list)
for item in items:
    groups[canonical(item)].append(item)
return list(groups.values())
