Common mistakes

Joining counts without a separator. Building the key as "".join(str(c) for c in count) makes counts 1,11 and 11,1 both "111". Use a tuple, a separator ("1#11"), or one char per count.

Using the set of letters or the sum of codes. Both collide for non-anagrams ("aab"/"abb", "ad"/"bc").

Using a mutable list as a dict key in Python. Lists are not hashable; convert to a tuple.

Sorting the word in place in Java/C++ and storing the sorted copy. Keep the original word in the group and use only the sorted copy as the key.

Expecting a fixed output order in tests. The judge accepts any order; your own tests must sort inside groups and then sort the groups before comparing.
