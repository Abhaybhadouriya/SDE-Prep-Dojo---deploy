Recognise the pattern

When you see "minimum number of moves" on a line where each position allows a range of next positions, think BFS by levels; if the reachable set is always a prefix, the levels are index ranges and BFS collapses to a greedy scan.

When you see "can you reach the end" (yes/no), think one variable farthest (Jump Game I). Minimum hops adds a second variable: the end of the current level.

The naive greedy "always hop as far as possible" is wrong (second example: hopping to pad 2 lands on a 0). The right greedy does not pick a pad at all; it only asks "how far can the next hop reach from anywhere in this level?"

Taxonomy: Greedy → Reachability → Jump. Pattern lessons: Greedy and Graph BFS.
