The story

Explain like I'm 5

A room has light switches, one per number. Every time you read a number, you flip its switch. A number that shows up twice flips its switch on and then off again. At the end only one switch is still on: the number you saw once. XOR is that switchboard, one switch per bit.

The interview point is not the trick itself but the constraint: linear time and constant extra space. Sorting breaks the time bound, a hash map breaks the space bound. XOR is the only standard tool that meets both, and the reason it works is a two-line algebra argument you should be able to say out loud.

From your world

This is RAID-5 parity: XOR of all blocks is a parity block, and XORing the parity with every surviving block rebuilds the missing one. Here the "missing block" is the value whose twin never came.
