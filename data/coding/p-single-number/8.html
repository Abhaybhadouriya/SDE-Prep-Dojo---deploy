Common mistakes

Using the sum trick with plain int. 2·sum(distinct) - sum(all) needs a set (O(n) space), and on bigger inputs the sums can overflow in C++/Java. XOR never overflows.

Starting the accumulator at nums[0] and looping from 0. That XORs the first value twice and cancels it. Start at 0, or start at nums[0] and loop from 1.

Using XOR for "appears three times". Triples do not cancel (x^x^x = x). That is Single Number II: count bits mod 3.

Python reduce(xor, nums) without an initial value. Fine for this problem (n >= 1), but crashes on an empty list in variants. reduce(xor, nums, 0) is safe.
