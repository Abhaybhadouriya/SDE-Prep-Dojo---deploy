The problem (in our words)

You are given a non-empty integer array nums. Every element appears exactly twice, except for one element that appears exactly once. Return that single element.

Your solution must run in linear time and use only constant extra space.

Signature: int singleNumber(int[] nums).

  • 1 <= nums.length <= 3 * 104
  • -3 * 104 <= nums[i] <= 3 * 104
  • Each element appears twice except for one element, which appears once.

Practice it: LeetCode 136 · GfG Unique Number I · TUF article

Constraints tell you: the length is always odd (2k + 1). Negative numbers are allowed; XOR works on the two's-complement bits, so no special case is needed. n is small, so any approach runs fast; the O(1)-space requirement is what the interviewer grades.
