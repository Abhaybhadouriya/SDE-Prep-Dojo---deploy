60-second recall

  • Cue: merge two sequences keeping each order; yes/no -> grid DP on prefix lengths.
  • Insight: position in s3 is i + j, so state = (i, j); down = take s1, right = take s2.
  • Recurrence: up and s1[i-1] == s3[i+j-1], or left and s2[j-1] == s3[i+j-1].
  • Trap: length check first; greedy fails on ties; s3 index i+j-1.
  • Cost: O(mn) time, O(n) space with one row.
if len(a) + len(b) != len(s): return False
ok = [False] * (len(b) + 1)
for i in range(len(a) + 1):
    for j in range(len(b) + 1):
        ok[j] = (i == j == 0) or (i and ok[j] and a[i-1] == s[i+j-1]) \
                or (j and ok[j-1] and b[j-1] == s[i+j-1])
return ok[-1]
