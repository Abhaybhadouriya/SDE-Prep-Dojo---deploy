Recognise the pattern

Cue: two sequences consumed left to right, a choice at each step of which one to advance, and a yes/no or count question -> 2-D DP on (i, j) = prefix lengths, the same grid as LCS and Edit Distance.

Key observation: the position in s3 is not a third dimension. After using i characters of s1 and j of s2, exactly i + j characters of s3 are matched, so k = i + j is implied.
