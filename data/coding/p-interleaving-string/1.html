The problem (in our words)

Given strings s1, s2 and s3, decide whether s3 can be formed by interleaving s1 and s2.

An interleaving cuts s1 into pieces a1, a2, ..., ap and s2 into pieces b1, b2, ..., bq with |p - q| <= 1, and alternates them: a1 + b1 + a2 + b2 + ... or b1 + a1 + b2 + a2 + .... In plain terms: every character of s1 and s2 is used exactly once, and each string keeps its own character order.

  • Input: three strings s1, s2, s3.
  • Output: true or false. Signature: boolean isInterleave(String s1, String s2, String s3).

Constraints

  • 0 <= s1.length, s2.length <= 100
  • 0 <= s3.length <= 200
  • s1, s2 and s3 consist of lowercase English letters.

Follow-up: can you solve it using only O(s2.length) additional memory?

Practice it: LeetCode 97 - Interleaving String · GfG - Interleaved Strings

Constraints tell you: at most 101 × 101 states, so an O(mn) table is tiny; the plain recursion without memo is exponential (two choices per character whenever both strings match). The follow-up asks for the rolling-array trick. Empty strings are allowed, so the base cases matter.
