The story

Explain like I'm 5

You have a pile of weights, some of them identical, and a scale that must balance at exactly one target. List every different set of four weights that balances it. Two sets that use the same numbers count once, even if you picked different physical copies of a weight.

Nobody asks 4Sum for its own sake: interviewers ask it to see whether you can generalise 3Sum, keep the duplicate rules straight across more loops, and notice the overflow. The natural follow-up is "now write k-Sum".

From your world

The overflow is the classic C trap: int a = 1e9, b = 1e9; long long s = a + b; is already wrong, because the addition happens in int before the widening. Cast the first operand.
