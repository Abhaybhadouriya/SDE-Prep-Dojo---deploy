The problem (in our words)

A raffle drum holds n numbered tickets, given as the integer array nums (several tickets may carry the same number), and the prize is won by any four tickets whose numbers add up to exactly target. List every winning set of four numbers. Formally, report each list [nums[a], nums[b], nums[c], nums[d]] where:

  • a, b, c, d are four distinct positions in [0, n);
  • the four numbers at those positions sum to target.

Each set of values may appear only once: two answers that hold the same four numbers (as a multiset) are duplicates, even if they come from different tickets. The lists, and the numbers inside them, may be in any order.

Signature: List<List<Integer>> fourSum(int[] nums, int target).

  • 1 <= nums.length <= 200
  • -109 <= nums[i] <= 109
  • -109 <= target <= 109

Practice it: LeetCode 18 · GfG 4 Sum - All Quadruples · TUF article

Constraints tell you: n <= 200 means n³ = 8 · 106, fast; n⁴ = 1.6 · 109 is too slow. Values up to 109 in magnitude mean a sum of four can reach 4 · 109, beyond a 32-bit int (max about 2.1 · 109).
