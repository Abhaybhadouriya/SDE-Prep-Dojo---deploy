Recognise the pattern

When you see "longest subarray with equal count of A and B" (0/1, vowels/consonants, L/R) think map A to +1, B to -1, then "longest subarray with sum 0" = prefix sum + first index of each prefix. "How many such subarrays" -> same transform, but keep counts instead of first indices.

The answer is always "the widest gap between two equal balances", with the start of the array counted as balance 0.
