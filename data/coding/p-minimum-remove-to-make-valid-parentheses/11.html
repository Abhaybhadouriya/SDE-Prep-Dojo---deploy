Just return the minimum number of removals.

One counter pass: count ')' that arrive with balance 0, and add the final balance. O(n) time, O(1) space.

How to answer

Say it is LC 921; insertions and removals need the same count.

Likely follow-ups
  • Why is the count the same for insertions? Each bad bracket can be fixed by adding its partner instead of deleting it.
Support three bracket types: (), [], {}.

Push (index, type) pairs. A closing bracket pops only if the top has the matching type. If the types differ, the problem changes: you can drop the closer or the opener on top, and greedy no longer gives the minimum in general; it becomes an interval DP (O(n3)) like the "minimum deletions to make a bracket sequence regular" family.

How to answer

Show a case where greedy fails, such as "([)]": either pair can survive, and the choice matters for longer strings.

Likely follow-ups
  • If the input is guaranteed to have only nesting errors at closers, the stack version still works.
Return all strings with the minimum number of removals.

That is LC 301. Use this scan to get the exact budget (c bad ')' and o bad '('), then DFS over positions, removing ')' while the ')' budget lasts and '(' while the '(' budget lasts, skipping duplicates of adjacent equal brackets, and keep results that are valid.

How to answer

Reuse today's answer as the pruning bound; the search is exponential only in the number of removals.

Likely follow-ups
  • How do you avoid duplicate outputs? Only remove the first bracket of a run of identical brackets at each level.
The input is a stream too big to hold. Can you output the answer on the fly?

Bad ')' can be dropped immediately. A '(' cannot be emitted until you know it gets matched, so you must buffer from the earliest unmatched '(' onward; with the two-pass idea you need either a second read of the input or a buffer of the unmatched region.

How to answer

Separate the part that is decidable online (closers) from the part that needs the future (openers).

Likely follow-ups
  • If you may read the input twice, pass 1 counts the final balance B and pass 2 streams, dropping the last B '(' by counting them from the total.
