The problem (in our words)

A log line s is made of the characters '(', ')' and lowercase English letters. Delete the fewest possible parentheses (at any positions) so that what is left is a valid parentheses string, and return any such result. Letters are never deleted.

A string is valid if it is empty or only letters; or it is AB where A and B are valid; or it is (A) where A is valid. Equivalently: reading left to right, the number of ')' never exceeds the number of '(' so far, and both counts are equal at the end.

Signature: String minRemoveToMakeValid(String s). If several answers remove the same minimum number of characters, any one is accepted.

  • 1 <= s.length <= 105
  • s[i] is '(', ')' or a lowercase English letter.

Practice it: LeetCode 1249

Constraints tell you: n up to 105 rules out trying subsets of removals (that is the Hard problem LC 301, which asks for all answers). One linear pass is the target. Building the answer with repeated string concatenation or erase in a loop can be O(n2): use a builder, a char list, or one final filter.
