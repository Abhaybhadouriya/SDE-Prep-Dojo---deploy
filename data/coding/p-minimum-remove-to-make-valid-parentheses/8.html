Common mistakes

Removing '(' from the front after one counter pass. With only a balance count, dropping the first extra '(' breaks "()(" into ")(". Drop the leftover ones from the right, or use their exact indices from the stack.

Pushing characters instead of indices. A stack of '(' characters tells you how many are left over but not where they are, so you cannot delete them.

O(n2) string building. s = s[:i] + s[i+1:] or s.erase(i, 1) inside the loop copies the string each time; on 105 characters that times out. Mark, then build once.

Erasing while scanning shifts indices. Deleting position i during the loop moves every later character, so the stored indices on the stack point at the wrong places.

Placeholder clashes. Marking removals with '*' and then deleting all '*' is safe here only because the input alphabet has no '*'; say so, or use a separate boolean array.
