Interview questions

Partition an array into k subsets with equal sums. Give a solution with a guaranteed bound.

Check total % k == 0 and max <= target. Fill buckets one at a time: the state is the mask of used items, and the open bucket's level is sum(mask) % target, a function of the mask, so the DP only stores reachability (or the level, -1 if unreachable). From each reachable mask add any unused item that fits in the open bucket. Answer: the full mask is reachable with level 0. O(n 2n) time, O(2n) memory.

How to answer

Start with backtracking with pruning (sort descending, skip equal values after a failure), then say "it can be exponential in bad cases; here is a bounded DP because n <= 16".

Likely follow-ups
  • Why is the level determined by the mask? (Buckets are closed only when exactly full, so the used sum is (closed buckets) x target + level.)
  • k = 2? (Plain subset-sum DP on target total/2, O(n x sum), no mask needed.)
Shortest path that visits every node of a graph with up to 12 nodes.

State (node, visited mask). Unit edges, so BFS from all (i, 1 << i) at once; the first popped state with a full mask gives the answer. A seen array of size n x 2n stops repeats while still allowing the walk to pass through the same node with a different mask. O(2n (n + E)).

How to answer

Explain why "visited nodes" alone is the wrong state (you may need to go back through a hub). Mention multi-source start because the start is free.

Likely follow-ups
  • Weighted edges? (All-pairs shortest paths first, then Held-Karp dp[mask][last], O(n2 2n).)
  • Must return to the start? (Classic TSP: add w[last][start] at the end.)
Match n workers to n jobs (n <= 14) minimising total cost. Why does one mask suffice as the state?

Process workers in fixed order. If mask is the set of jobs already given out, exactly popcount(mask) workers have been served, so the next worker is implied. dp[mask] = min cost for those workers; dp[mask | 1 << j] = min(dp[mask] + cost[popcount(mask)][j]). O(n 2n), versus n! for permutations.

How to answer

The "popcount = next worker" observation is the insight. Say it before writing code.

Likely follow-ups
  • n = 500? (Hungarian algorithm O(n3) or min-cost flow.)
  • Fewer workers than jobs (m < n)? (Same DP over job masks, stop at popcount = m: Campus Bikes II.)
How do you iterate over all submasks of a mask, and what is the total cost over all masks?

for (sub = mask; sub; sub = (sub - 1) & mask), plus the empty submask if needed. Subtracting 1 clears the lowest set bit and sets the bits below it; ANDing with mask keeps only bits in the set, so the walk counts down through exactly the subsets. Over all masks the pairs (mask, sub) number 3n because each element is in neither, mask only, or both.

How to answer

Show one example by hand (1011 is a good one because of the hole at bit 2), then the 3n argument in one line.

Likely follow-ups
  • Iterate supersets instead? (for (s = mask; s < 1 << n; s = (s + 1) | mask).)
  • Sum over all submasks for every mask in less than 3n? (SOS DP: for each bit, for each mask with that bit, f[mask] += f[mask ^ bit], O(n 2n).)
Distribute n bags among k children to minimise the largest share. Backtracking or DP?

With n <= 8, backtracking (give bag i to each child, prune when a share exceeds the best answer, skip children with equal current shares) is short and fast. The DP: precompute sum[mask]; best_1 = sum; best_c[mask] = min over submasks sub of max(best_(c-1)[mask ^ sub], sum[sub]). O(k 3n) with a proven bound. Binary search on the answer plus a feasibility check is a third option.

How to answer

Offer backtracking first, then the DP as the scalable answer, and state both complexities.

Likely follow-ups
  • Why skip children with the same current share? (They are interchangeable; trying both explores mirror-image states.)
Can I Win: players pick unused numbers 1..m (m <= 20) adding to a running total; whoever reaches the target first wins. Does the first player win?

The total so far is the sum of the used numbers, so the mask of used numbers is the whole state. win(mask) = true if some unused x reaches the target, or win(mask | x) is false for the opponent. Memo on 2m masks, O(m 2m). Handle the edge cases first: if the sum 1..m is below the target nobody can win (return false); if the target is <= 0 the first player wins at once.

How to answer

Point out that the turn and the running total are both functions of the mask, so they do not need to be in the state.

Likely follow-ups
  • Why not bottom-up? (Most masks are unreachable once the target is hit; top-down memo explores only reachable states.)
The constraints say n <= 16. What does that tell you?

That exponential in n is intended, and the usual targets are 216 x 16 (about 106) or 316 (about 4.3 x 107). It suggests bitmask DP or backtracking with pruning. n <= 20 suggests n 2n; n <= 40 suggests meet in the middle; n <= 12 with a position in the state suggests n2 2n.

How to answer

Read constraints aloud at the start of every problem. Mapping n to a complexity budget is a skill interviewers notice.

Likely follow-ups
  • What is 220? (1,048,576, about a million.)
