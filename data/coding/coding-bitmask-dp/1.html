A subset is a number

Number the items 0 to n-1. Item i is in the set when bit i is 1. So the integers 0 to 2n - 1 list every subset exactly once, and a plain for mask in 0 .. 2^n - 1 loop visits them all. Because adding an item only sets a bit, mask | (1 << i) > mask: every superset has a larger number than its subsets, so increasing order is already a valid DP order.

Is n small enough?

The cost is the number of states times the work per state. With an inner loop over n items, the total is n * 2^n: about 2 x 107 for n = 20, fine in any language. With a state of (mask, last node) and a loop over the next node it is n^2 * 2^n: about 5.9 x 105 for n = 12, about 1.7 x 107 for n = 16. So when you read n <= 12, 14, 16 or 20 in the constraints, think bitmask before anything else. When n is 105, it is never a bitmask over items (but the mask may be over something small: 26 letters, 10 digits, 40 hat types).
