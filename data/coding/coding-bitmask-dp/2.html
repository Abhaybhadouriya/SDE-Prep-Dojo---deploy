Mask iteration tricks

Two expressions do most of the work. x & (x - 1) clears the lowest set bit, and x & -x keeps only the lowest set bit. Both come from how subtracting 1 flips the trailing zeros and the lowest one:

The first trick gives an O(2n) table of all subset sums: sum[mask] = sum[mask & (mask - 1)] + a[lowest bit of mask]. Each subset reuses the subset without its lowest item, which has a smaller number and is already computed.

Walking the submasks of a mask

Many DPs split a set into "the part one person takes" and "the rest". You need every submask of mask (every subset of the set). The loop for (sub = mask; sub > 0; sub = (sub - 1) & mask) visits them in decreasing order. Subtracting 1 turns the lowest 1 into 0 and the zeros below it into 1s; the & mask then throws away the bits that are not in the set.

  1. Start with sub = mask itself (the whole set).
  2. Subtract 1 and keep only the bits of mask: the lowest item is removed.
  3. The borrow moves up: bit 1 is cleared, bit 0 comes back.
  4. Only bit 3 is left.
  5. The interesting step: 1000 - 1 = 0111 sets bit 2 too, but bit 2 is not in mask, so & mask removes it. The walk never leaves the set.
  6. Counting down inside the lower two bits.
  7. The last non-empty submask.
  8. sub reaches 0 and the loop stops. Each mask with k set bits has 2^k submasks.

Why all submasks of all masks cost 3n, not 4n: for each item there are three cases: not in mask, in mask but not in sub, in both. So the pairs (mask, sub) number exactly 3n: about 6,561 for n = 8, 4.8 x 107 for n = 16, 3.5 x 109 for n = 20. Submask DP is therefore for n up to about 16.

// subsetSums: sum of every subset in O(2^n); reuse the subset without its lowest set bit.
func subsetSums(a []int) []int {
	n := len(a)
	sum := make([]int, 1<<n)
	for mask := 1; mask < 1<<n; mask++ {
		low := bits.TrailingZeros(uint(mask))  // index of the lowest set bit
		sum[mask] = sum[mask&(mask-1)] + a[low] // mask & (mask-1) clears that bit
	}
	return sum
}

// submasks: every non-empty submask of mask, largest first. Over all masks this is 3^n in total.
func submasks(mask int) []int {
	var out []int
	for sub := mask; sub > 0; sub = (sub - 1) & mask {
		out = append(out, sub)
	}
	return out
}
// Sum of every subset in O(2^n): reuse the subset without its lowest set bit.
vector<int> subsetSums(const vector<int>& a) {
    int n = a.size();
    vector<int> sum(1 << n, 0);
    for (int mask = 1; mask < (1 << n); mask++) {
        int low = __builtin_ctz(mask);               // index of the lowest set bit
        sum[mask] = sum[mask & (mask - 1)] + a[low]; // mask & (mask-1) clears that bit
    }
    return sum;
}

// Every non-empty submask of mask, largest first. Over all masks this is 3^n in total.
vector<int> submasks(int mask) {
    vector<int> out;
    for (int sub = mask; sub > 0; sub = (sub - 1) & mask) out.push_back(sub);
    return out;
}

def subset_sums(a: List[int]) -> List[int]:
    """Sum of every subset in O(2^n): reuse the subset without its lowest set bit."""
    n = len(a)
    s = [0] * (1 << n)
    for mask in range(1, 1 << n):
        low = (mask & -mask).bit_length() - 1  # index of the lowest set bit
        s[mask] = s[mask & (mask - 1)] + a[low]  # mask & (mask-1) clears that bit
    return s


def submasks(mask: int) -> List[int]:
    """Every non-empty submask of mask, largest first. Over all masks this is 3^n in total."""
    out, sub = [], mask
    while sub:
        out.append(sub)
        sub = (sub - 1) & mask
    return out
