Partition into k equal-sum subsets

Partition to K Equal Sum Subsets (LeetCode 698), told our way: given an array of positive integers and an integer k, decide whether the array can be split into k non-empty groups with the same sum (every element in exactly one group). Constraints: 1 <= k <= n <= 16, values between 1 and 104, each value appears 1 to 4 times. Example: [3, 6, 2, 4, 5, 1, 3] with k = 4 is true: {6}, {2, 4}, {5, 1}, {3, 3}.

First the cheap checks: the total must divide by k, giving target, and no value may exceed target. Then the insight that makes the DP small: fill buckets one at a time. If you know which items are used, you know their sum, and the open bucket holds exactly sum(mask) % target. So the state is just the mask, and the value is "is this mask reachable by filling buckets in order without overflowing?". We store fill[mask] (the open bucket's level, or -1 for unreachable). From a reachable mask, add any unused item that still fits in the open bucket; when the bucket hits target exactly, the level wraps to 0 and a new bucket opens.

Watch it on [2, 1, 3] with k = 2 (target 3). Bit i is item i, so mask 011 is {2, 1}.

  1. Mask 000: the empty set is reachable with level 0. Try every item.
  2. Mask 001 = {2}: adding 1 fills the bucket exactly, so mask 011 is reached with level 0.
  3. Mask 010 = {1}: nothing new. 011 is already known (its level must be the same, because it is sum % target).
  4. Mask 011 = {2, 1}: one bucket done; 3 fills the second bucket exactly.
  5. Mask 100 = {3}: reaches 101 and 110. They will not help, but the DP does not know that yet.
  6. Mask 101: its only move leads to 111, already reached.
  7. Mask 110: same.
  8. The full mask is reachable with level 0: the answer is true.

Time O(n 2n) (about 106 for n = 16), memory O(2n). The DP does not need k at all after computing target: reaching the full mask with level 0 means exactly total / target = k buckets were closed.

// canPartitionKSubsets (LC 698), O(n * 2^n).
// fill[mask] = how full the current bucket is after using the items in mask, -1 = unreachable.
func canPartitionKSubsets(nums []int, k int) bool {
	n, total, biggest := len(nums), 0, 0
	for _, x := range nums {
		total += x
		biggest = max(biggest, x)
	}
	if total%k != 0 || biggest > total/k {
		return false
	}
	target := total / k
	fill := make([]int, 1<<n)
	for i := range fill {
		fill[i] = -1
	}
	fill[0] = 0
	for mask := 0; mask < 1<<n; mask++ {
		if fill[mask] < 0 {
			continue
		}
		for i := 0; i < n; i++ {
			next := mask | 1<<i
			if next == mask || fill[next] >= 0 { // item used, or state already reached
				continue
			}
			if fill[mask]+nums[i] <= target { // fits in the open bucket
				fill[next] = (fill[mask] + nums[i]) % target // full bucket -> open a new one
			}
		}
	}
	return fill[1<<n-1] == 0
}
// Partition to K Equal Sum Subsets (LC 698), O(n * 2^n).
// fill[mask] = how full the current bucket is after using the items in mask, -1 = unreachable.
bool canPartitionKSubsets(const vector<int>& nums, int k) {
    int n = nums.size(), total = accumulate(nums.begin(), nums.end(), 0);
    if (total % k) return false;
    int target = total / k;
    if (*max_element(nums.begin(), nums.end()) > target) return false;
    vector<int> fill(1 << n, -1);
    fill[0] = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        if (fill[mask] < 0) continue;
        for (int i = 0; i < n; i++) {
            if (mask & (1 << i)) continue;           // item i already used
            int next = mask | (1 << i);
            if (fill[next] >= 0) continue;           // already reached another way
            if (fill[mask] + nums[i] <= target)      // fits in the open bucket
                fill[next] = (fill[mask] + nums[i]) % target;  // full bucket -> open a new one
        }
    }
    return fill[(1 << n) - 1] == 0;
}

static boolean canPartitionKSubsets(int[] nums, int k) {
    int n = nums.length, total = Arrays.stream(nums).sum();
    if (total % k != 0) return false;
    int target = total / k;
    if (Arrays.stream(nums).max().getAsInt() > target) return false;
    int[] fill = new int[1 << n];
    Arrays.fill(fill, -1);
    fill[0] = 0;
    for (int mask = 0; mask < (1 << n); mask++) {
        if (fill[mask] < 0) continue;
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) continue;    // item i already used
            int next = mask | (1 << i);
            if (fill[next] >= 0) continue;           // already reached another way
            if (fill[mask] + nums[i] <= target)      // fits in the open bucket
                fill[next] = (fill[mask] + nums[i]) % target;  // full bucket -> open a new one
        }
    }
    return fill[(1 << n) - 1] == 0;
}
def can_partition_k_subsets(nums: List[int], k: int) -> bool:
    """LC 698, O(n * 2^n). fill[mask] = how full the open bucket is, -1 = unreachable."""
    n, total = len(nums), sum(nums)
    if total % k:
        return False
    target = total // k
    if max(nums) > target:
        return False
    fill = [-1] * (1 << n)
    fill[0] = 0
    for mask in range(1 << n):
        if fill[mask] < 0:
            continue
        for i in range(n):
            nxt = mask | (1 << i)
            if nxt == mask or fill[nxt] >= 0:  # item used, or state already reached
                continue
            if fill[mask] + nums[i] <= target:  # fits in the open bucket
                fill[nxt] = (fill[mask] + nums[i]) % target  # full bucket -> open a new one
    return fill[-1] == 0

The other accepted answer is backtracking: sort descending, fill bucket by bucket, skip a value equal to the one that just failed, and stop trying an empty bucket after the first failure. It is often faster in practice, but its worst case is hard to state. In an interview, say both and explain that the mask DP has a guaranteed bound.
