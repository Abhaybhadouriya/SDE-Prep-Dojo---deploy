The story: a row of light switches

Explain like I'm 5

You have 4 toys and a wall with 4 light switches, one per toy. When a toy is packed in the box, its switch is up. Look at the wall and you know exactly which toys are packed. Every possible "which toys are packed" picture is one pattern of switches, and there are only 2 x 2 x 2 x 2 = 16 patterns.

Now a puzzle like "pack the toys into two bags of equal weight" becomes: walk through the 16 patterns, and for each one write down one fact in a notebook ("with these toys packed, the open bag weighs 3"). Each pattern only needs facts from patterns with one switch fewer.

The switch pattern is a bitmask: an integer whose bit i says whether item i is in the set. Bitmask DP is DP whose state includes such a set. It is the standard tool when the brute force is "try every order" (n! orders) but the future only depends on which items are used, not the order they were used in. That collapses n! (20! is about 2.4 x 1018) into 2n (220 is about 106).

From your world

You already think in masks: cpumask_t, interrupt enable registers, fd_set for select(), VLAN membership bitmaps, for_each_set_bit(), __ffs() (lowest set bit) and hweight32() (popcount). Bitmask DP just uses the mask as an array index: dp[mask] is "the best answer when exactly the items in mask are done".
