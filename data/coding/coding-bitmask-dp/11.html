Revision card

  • Cue: n ≤ 20 items, "visit all", "assign each", "partition into k equal groups".
  • Insight: A subset is an integer; bit i says item i is used, and supersets are larger numbers.
  • State: dp[mask] or dp[mask][last]; next item from popcount(mask) or a free bit.
  • Trap: 1 << n overflow for n ≥ 31; iterating states in an order that reads unfilled entries.
  • Cost: O(2^n n) or O(2^n n^2) time; 3^n for submask walks.

More to remember

  • A subset is an integer; bit i = item i. Supersets have bigger numbers, so increasing order is a valid DP order.
  • x & (x-1) drops the lowest bit, x & -x isolates it, popcount counts the set.
  • Submask walk: sub = (sub - 1) & mask; all submasks of all masks = 3n.
  • Equal-sum buckets: fill one at a time; level = sum(mask) % target, so the mask alone is the state.
  • Visit-all: BFS or Held-Karp over (node, mask); revisiting a node is fine, repeating a state is not.
  • Assignment: next person = popcount(mask), O(n 2n).
  • Budget: n 2n for n <= 20, n2 2n for n <= 16, 3n for n <= 16, meet in the middle for n <= 40.
