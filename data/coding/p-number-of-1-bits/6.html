Kernighan's loop in four languages. Each file in coding-code/number-of-1-bits/ also checks 20,000 random values against a 32-step shift count and the language's built-in popcount; the C++ and Java drivers include 0xFFFFFFFF (all 32 bits set, negative as a Java int).

The C++ version takes uint32_t n on purpose, while LeetCode's current C++ stub is int hammingWeight(int n). Either works: with the stub's signature, copy it once (uint32_t u = n;) and loop on u, so that u & (u - 1) and the shifts never touch a sign bit.

class Solution {
public:
    int hammingWeight(uint32_t n) {   // unsigned: no sign-bit surprises in n - 1 or shifts
        int count = 0;
        while (n) {
            n &= n - 1;   // n - 1 flips the lowest 1 and the 0s below it; AND drops that 1
            ++count;      // one loop turn per set bit
        }
        return count;
    }
};
func hammingWeight(n int) int {
	count := 0
	for n != 0 {
		n &= n - 1 // n - 1 flips the lowest 1 and the 0s below it; AND drops that 1
		count++    // one loop turn per set bit
	}
	return count
}
