Dry run

Kernighan's loop on n = 52 = 0b00110100 (8 bits shown). Green = 1 bits of n, orange = the bits that n - 1 flipped, blue row = the result that becomes the next n.

  1. Start with n = 52 = 0b00110100 (three 1s). The loop never looks at single bits: each turn deletes exactly the lowest 1, so it runs once per set bit, here 3 times instead of 32.
  2. Turn 1: subtracting 1 borrows through the trailing zeros, so n - 1 flips the lowest 1 (bit 2) and every 0 below it (orange). AND keeps only the bits the two agree on: the lowest 1 is gone, the rest is untouched. 52 -> 48, count 1.
  3. Turn 2: 48 = 0b00110000. The lowest 1 is now bit 4; n - 1 = 47 flips bits 4..0. 48 & 47 = 32, count 2.
  4. Turn 3: 32 & 31 = 0, count 3. n is zero, the loop stops: 3 set bits. A number with k ones always takes exactly k turns.
