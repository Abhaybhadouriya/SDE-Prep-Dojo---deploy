Common mistakes

Arithmetic shift on a negative value. In Java n >> 1 keeps the sign bit, so while (n != 0) { ...; n >>= 1; } loops forever on -1. Use >>>, an unsigned type in C++ (uint32_t), or Kernighan's loop, which is safe for any bit pattern.

Loop condition n > 0. Wrong whenever bit 31 can be set. Write n != 0.

Precedence. In C/C++/Java, n & 1 == 1 parses as n & (1 == 1). Parenthesise: (n & 1) == 1.

Python and negatives. Python ints are unbounded, so -1 & (-1 - 1) never reaches 0. If a variant passes negatives, mask first: n &= 0xFFFFFFFF.
