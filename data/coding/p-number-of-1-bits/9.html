60-second recall

  • Cue: count set bits / lowest set bit -> n & (n - 1).
  • Proof: n = X10..0, n-1 = X01..1, AND = X00..0: exactly one 1 removed.
  • Cost: k turns (k = popcount) vs 32 for the shift loop.
  • Many calls: 256-entry byte table, SWAR masks 0x55/0x33/0x0F, or POPCNT.
  • Trap: while (n != 0), unsigned/logical shifts, parenthesise &.
count = 0
while n:
    n &= n - 1
    count += 1
# power of two: n > 0 and n & (n - 1) == 0;  lowest bit: n & -n

What is 52 & 51 (52 = 0b110100)?

  1. 52
  2. 51
  3. 48
  4. 4
51 = 0b110011; the AND clears the lowest 1 of 52 and gives 0b110000 = 48.

How many loop turns does Kernighan's method take for n = 220?

  1. 20
  2. 1
  3. 32
  4. 21
One turn per set bit, and a power of two has exactly one.

In Java, which loop never ends for n = -1?

  1. while (n != 0) n &= n - 1
  2. while (n != 0) n >>>= 1
  3. Integer.bitCount(n)
  4. while (n != 0) n >>= 1
An arithmetic right shift copies the sign bit, so -1 stays -1 forever.
