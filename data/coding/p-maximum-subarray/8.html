Common mistakes

Starting best at 0. Then an all-negative array returns 0, the sum of an empty subarray, which the problem forbids. Start at nums[0].

Resetting to 0 and then comparing. cur = max(0, cur + x); best = max(best, cur) is the "empty allowed" version. It also fails on all-negative input. Update best before the reset, or use max(x, cur + x).

Restarting when x is negative. The test is the sign of the running sum, not of x. [2, -1, 5] keeps the -1.

Using "minus infinity" as the start in C++/Java. INT_MIN + x overflows for negative x. Starting from nums[0] avoids the problem.
