The array is circular.

A wrapping subarray is the total minus a non-wrapping middle part, so its best value is total - minSubarray. Answer = max(maxKadane, total - minKadane), except when every number is negative (then the min subarray is everything and the formula gives an empty answer): return maxKadane. LC 918.

How to answer

Draw the circle: what you skip is a contiguous piece, so minimise it.

Likely follow-ups
  • Window length at most k on a circle? Prefix sums over two copies plus a monotonic deque.
Best sum of a sub-rectangle in a 2D matrix.

Fix a top row and a bottom row, collapse the columns between them into one array of column sums, and run Kadane on it. O(rows² × cols).

How to answer

Reduce to 1D first, then mention the cost and that you loop over the smaller dimension twice.

Likely follow-ups
  • Sum no larger than k (LC 363): replace Kadane with prefix sums and an ordered set.
Answer many range queries: "best subarray inside [l, r]".

Build a segment tree where each node stores (total, best prefix, best suffix, best). Merge: best = max(L.best, R.best, L.suffix + R.prefix). Each query is O(log n), updates too.

How to answer

Say it is the divide-and-conquer rung, stored instead of recomputed.

Likely follow-ups
  • Point updates in a stream? The same tree handles them in O(log n).
Maximum product instead of sum.

A negative number turns the smallest product into the largest. Carry both maxHere and minHere; for each x compute the three candidates x, maxHere × x, minHere × x. Zeros reset both. LC 152.

How to answer

Explain why one state is no longer enough: the order of values is not preserved by multiplying by a negative.

Likely follow-ups
  • Overflow? Use 64-bit or doubles; ask about the value range.
