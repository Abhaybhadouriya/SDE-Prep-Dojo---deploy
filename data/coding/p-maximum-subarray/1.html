The problem (in our words)

A shop records its daily profit, which can be negative, as an integer array profit. Pick a run of consecutive days (at least one day) whose total profit is as large as possible, and return that total.

  • Input: an integer array nums.
  • Output: one integer, the largest sum of a non-empty contiguous subarray. Signature: int maxSubArray(int[] nums).

Constraints

  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4

Follow-up from the original: once you have the O(n) solution, also try a divide-and-conquer solution.

Practice it: LeetCode 53 - Maximum Subarray · GfG - Kadane's Algorithm · takeuforward

Constraints tell you: n up to 10^5 rules out the O(n²) "every subarray" scan (10^10 steps). Aim for O(n). The largest possible sum is 10^5 × 10^4 = 10^9, which still fits in a 32-bit int. The array is never empty and the answer must be non-empty, so an all-negative input returns its largest element, not 0.
