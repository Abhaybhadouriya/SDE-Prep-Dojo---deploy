  • Cue: best sum of a contiguous, non-empty subarray → Kadane.
  • Insight: best ending at i = max(x, best ending at i-1 + x); a negative past is dropped.
  • State: cur (best ending here), best (best anywhere), both start at nums[0].
  • Trap: best = 0 or max(0, ...) breaks all-negative input; answer must be non-empty.
  • Cost: O(n) time, O(1) space; brute O(n²), divide and conquer O(n log n).
cur = best = a[0]
for x in a[1:]:
    cur = max(x, cur + x)      # extend or restart
    best = max(best, cur)
return best

Quick quiz

For [-4, -2, -9], what does the version with best = 0 and cur = max(0, cur + x) return?

  1. -2
  2. 0
  3. -15
  4. -4
It never sees a positive running sum, so best stays 0: the empty subarray. The correct answer is -2.

What decides whether Kadane restarts at x?

  1. x < 0
  2. x > best
  3. the running sum before x is negative
  4. cur + x < best
cur + x < x exactly when cur < 0: a negative prefix only lowers every future sum.

In the prefix-sum view, Kadane's cur at index i equals...

  1. P[i+1] minus the smallest P[k] with k ≤ i
  2. P[i+1] minus P[0]
  3. the largest P[k]
  4. best minus x
For a fixed end, the best start is the lowest prefix before it.
