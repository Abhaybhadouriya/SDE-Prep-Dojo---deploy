The story

Explain like I'm 5

A teacher hands out name stickers at the door and wants to know if any child came in twice. She keeps a list of the names she has already written. Each new child: "is your name on my list?" If yes, she has her answer and can stop. If no, she writes the name down. She never has to compare two children directly.

The list is a hash set: "have I seen this value before?" in O(1) on average. The question is only yes or no, so the set does not need positions or counts.

From your world

This is the duplicate-ACK or replay check in a network stack: keep a table of sequence numbers (or nonces) you already accepted and drop any packet whose key is already present. Same trade-off too: a hash table costs memory per entry, and when memory is tight you fall back to sorting, a bitmap over a small key range, or a Bloom filter that can say "maybe seen".
