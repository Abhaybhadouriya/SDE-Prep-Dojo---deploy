Common mistakes

Comparing a[i] with a[i+1] without sorting. It only finds repeats that happen to be adjacent; [4, 9, 2, 4] returns false.

Sorting the caller's array silently. Fine on LeetCode, a side effect in real code. Ask, or sort a copy (and then the space is O(n) anyway).

A counting array indexed by value. Values go down to -109 and span 2·109: the array does not fit and negative indices crash. Use it only when the range is small and known.

Off-by-one in the neighbour loop. Start at i = 1 and compare with i - 1, or stop at n - 2 when comparing with i + 1; reading a[n] is out of bounds.
