  • Cue: "any value twice?", "all unique?" → hash set while scanning.
  • Insight: a value already in the set means an earlier index had it; stop there.
  • State: seen = set of values in nums[0..i-1].
  • Trap: neighbours only work after sorting; sorting mutates input; no counting array for a 2·109 range.
  • Cost: O(n) time and space; sort O(n log n) time, O(1) extra; brute O(n²).
seen = set()
for x in a:
    if x in seen: return True     # or key(x): a window, a bucket, a canonical form
    seen.add(x)
return False
