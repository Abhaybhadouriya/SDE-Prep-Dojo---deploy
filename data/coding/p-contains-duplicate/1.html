The problem (in our words)

A badge reader logs the ID numbers of everyone who taps in, as an integer array nums. Return true if some value appears two or more times in the array, and false if all the values are different from each other.

  • Input: an integer array nums.
  • Output: a boolean. Signature: bool containsDuplicate(vector<int>& nums).
  • Only values matter: you do not have to say which value repeats or where.

Constraints

  • 1 <= nums.length <= 105
  • -109 <= nums[i] <= 109

Practice it: LeetCode 217 - Contains Duplicate · GfG - Check if array contains duplicates · takeuforward

Constraints tell you: n = 105 means the all-pairs check (about 5·109 comparisons) times out; you need O(n log n) or O(n). Values span 2·109, so a plain counting array indexed by value is out (it would need 2·109 slots); a hash set or a sort is the tool. Everything fits in a 32-bit int, and no arithmetic is done on the values, so overflow is not a concern.
