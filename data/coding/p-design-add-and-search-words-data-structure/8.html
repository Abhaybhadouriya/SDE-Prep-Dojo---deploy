Common mistakes

Returning true when the walk ends instead of returning node.end. "sta" then matches because "star" is stored.

Returning the first child's result on a dot. for c in kids: return match(c, i+1) gives up after one child. Return true only on success, and false after the loop.

Python dict trie with an end marker key: when looping over children for a dot, skip the marker key, or the DFS tries to descend into True.

Copying substrings in the recursion (match(node, word[1:])): O(L) per call and O(L²) per path. Pass an index.

Go: a value receiver. func (d WordDictionary) AddWord is fine only because the root is a pointer; storing the root by value would silently lose every insert.
