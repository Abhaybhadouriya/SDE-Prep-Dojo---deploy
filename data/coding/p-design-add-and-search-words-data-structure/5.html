Dry run

The trie after adding cab, tab and cap, then three searches. Watch the DFS back up from a dead branch to the last dot.

  1. Three addWord calls built this trie. Shared prefixes share nodes (c-a is stored once for cab and cap). Green rings mark word ends.
  2. search("..t"). At the root the pattern says '.', so we must try every child. Children are tried in letter order: c first.
  3. At c the pattern says '.' again; c has only one child, a. Follow it.
  4. At ca the pattern needs the letter t: there is no t edge. This branch returns false, and the call stack unwinds to the last '.' that still has untried children: the root.
  5. The root tries its next child t, then t's only child a. At ta there is no t either. No '.' has untried children left: the answer is false. We visited 5 nodes, not the whole word list.
  6. search("ta."): letters t and a are a single forced walk. At ta, '.' tries the first child b; the pattern is used up and tab is a word end: true, and we stop without trying other children.
  7. search("ca"): the walk succeeds but ca has no end ring: "ca" is only a prefix. Answer false. The end flag, not the walk, decides.
