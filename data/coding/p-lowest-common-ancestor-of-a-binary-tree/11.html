Interview follow-ups

What if p or q might not be in the tree?

The short version would return p when q is missing. Traverse the whole tree, do not return early at a target, and count targets found: a node is a candidate if (left found) + (right found) + (node is a target) reaches 2. Return the candidate only if both were found. Still O(n).

How to answer

Give the failing input first (q missing -> returns p), then the counting fix. This is LC 1644.

Likely follow-ups
  • Return a pair (found count, candidate) from each call instead of a global.
Each node has a parent pointer and you are not given the root.

Walk two pointers up: a from p, b from q; when one hits null, restart it at the other's start. They meet at the LCA after at most depth(p) + depth(q) steps, the same trick as intersecting two linked lists. O(h) time, O(1) space.

How to answer

Draw the two chains up to the root and point out it is list intersection. This is LC 1650.

Likely follow-ups
  • Why does the switch make the walks the same length?
The tree is fixed and you get 105 LCA queries.

Preprocess once. Binary lifting: up[j][v] = 2j-th ancestor plus depths, O(n log n) build, O(log n) per query. Or an Euler tour + sparse-table range-minimum on depth, O(1) per query. Offline, Tarjan's union-find LCA answers all queries in near-linear time.

How to answer

Lead with binary lifting (simplest to code), then mention Euler tour + RMQ.

Likely follow-ups
  • Distance between two nodes = depth(a) + depth(b) - 2·depth(lca).
The tree has 106 nodes in a chain. Will your code survive?

The recursion depth equals the height, 106 frames; that overflows a default 1-8 MB stack in C++/Java and certainly CPython's limit. Use the iterative parent-map version (rung 2), or an explicit-stack post-order that stores each node's state.

How to answer

Estimate frame size times depth out loud, then switch to the iterative version.

Likely follow-ups
  • Write the explicit-stack post-order version.
Return the distance (number of edges) between p and q.

Find the LCA, then distance = depth(p) + depth(q) - 2·depth(LCA). In one pass, return (found, distance-so-far) from each call, or run BFS from p over parent + child edges.

How to answer

Reduce to LCA plus depths; check on the example (2 and 9: 3 + 2 - 0 = 5 edges).

Likely follow-ups
  • Print the path itself (LC 2096 style).
