The problem (in our words)

You are given the root of a binary tree and two different nodes of that tree, p and q. Return their lowest common ancestor: the deepest node that has both p and q as descendants, where a node counts as a descendant of itself. So if p is an ancestor of q, the answer is p.

Signature: TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q). The tree is given in LeetCode's level-order form, e.g. [7,4,12,1,5,9,15,null,null,2,6], and p and q are given by value; you receive and return node references.

  • The number of nodes is in the range [2, 105].
  • -109 <= Node.val <= 109
  • All Node.val are unique.
  • p != q
  • p and q both exist in the tree.

Practice it: LeetCode 236 · GfG LCA in Binary Tree · TUF article

Constraints tell you: 105 nodes means one O(n) traversal; the tree is not a BST, so values give no direction. A skewed tree can be 105 deep: recursion is fine in C++/Java/Go on LeetCode, but CPython's default limit is 1000, so mention an iterative fallback. "Both exist" is what lets the short recursion be correct.
