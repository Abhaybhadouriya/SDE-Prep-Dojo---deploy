  • Cue: two nodes, "lowest common ancestor" / "where paths meet" in a plain binary tree.
  • Insight: return null / p / q / LCA upward; both children non-null -> this node is the LCA.
  • State: the return value only (no globals); left, right results per node.
  • Trap: return early at p or q; correct only if both exist (else count found nodes).
  • Cost: O(n) time, O(h) stack; parent map O(n) space, no recursion.
def lca(t, p, q):
    if t is None or t is p or t is q:
        return t
    l, r = lca(t.left, p, q), lca(t.right, p, q)
    if l and r:
        return t
    return l or r

At a node, left returns p and right returns q. What do you return?

  1. p
  2. q
  3. this node
  4. null
p and q are in different subtrees, so this node is where their paths meet.

q is in p's subtree. What does the recursion return?

  1. q
  2. p, because it stops as soon as it meets p
  3. the root
  4. null
Returning at p is correct only because both nodes are guaranteed to exist. Without that guarantee you must count what you found.

The tree is a 10^5-node chain. What can break in Python?

  1. nothing
  2. the default recursion limit (1000) raises RecursionError
  3. the answer is wrong
  4. it becomes O(n²)
Raise sys.setrecursionlimit (LeetCode raises it already) or use the iterative parent-map version.
