Common mistakes

Using BST logic. "Go left if both values are smaller" only works in a BST (LC 235). Here values are arbitrary, so you must search both sides.

Forgetting that a node is its own descendant. Code that requires p and q to be in different child subtrees misses the case p = 4, q = 6 and returns 7.

Using the short recursion when a target may be missing. If q is not in the tree, it returns p, not null. LC 1644 needs a count of how many targets were really found.

Comparing values instead of references. The function receives nodes; compare root == p (identity). Comparing val also works only because values are unique; it breaks on trees with duplicates.
