Recognise the pattern

When you see "common ancestor", "where do two paths meet", "distance between two nodes" in a tree, think a post-order DFS that returns information upward. If the tree is a BST, values steer you (LC 235). If nodes have parent pointers, it becomes the two-list intersection problem.
