Recognise the pattern

When you see "design a cache" + "O(1) each" + evict by a count with ties broken by recency, think a map of handles + one doubly linked list per count + a pointer to the smallest non-empty count. Evict by recency alone -> one list (LRU). Need max and min count -> a linked list of count buckets (All O'one).
