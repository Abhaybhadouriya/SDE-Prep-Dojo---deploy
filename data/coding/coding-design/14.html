Remember this

Revision card

  • Cue: O(1) get / put / evict, or O(1) insert / delete / getRandom, or an iterator class.
  • Insight: A map stores a handle (node pointer or array index) into a list or array that keeps the order.
  • State: map + doubly linked list (LRU); map + frequency buckets + minFreq (LFU); array + index map with swap-delete (RandomizedSet).
  • Trap: Forgetting to erase the map entry on eviction; not resetting minFreq to 1 when a new key is put.
  • Cost: O(1) per operation, O(capacity) space.

More to remember

  • LRU: on get, move the node to the front; on put of a full cache, evict the tail and erase its key from the map.
  • LFU: buckets of DLLs per frequency; minFreq moves up only when its bucket empties, and resets to 1 on a new key.
  • RandomizedSet: swap the deleted element with the last, update the moved element's index, pop the back.
  • Iterators: do the work in hasNext() and cache it; next() only returns the cached value.
  • Say the per-operation cost of every method before you code.
