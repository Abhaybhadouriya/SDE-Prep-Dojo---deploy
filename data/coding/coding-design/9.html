Combining structures (SDE-3 level)

The hardest design problems need three structures and careful invariants. Two you should be able to code from memory:

Maximum Frequency Stack (895): pop() removes the most frequent value, the most recent one on ties. Keep freq[x] and one stack per frequency level, group[f]. Pushing x with new count f puts x on stack f (x also still sits on stacks 1..f-1). Pop takes the top of group[maxFreq]. Everything is O(1); no heap needed.

// 8. Maximum frequency stack (LC 895).
type FreqStack struct {
	freq    map[int]int
	group   map[int][]int
	maxFreq int
}

func NewFreqStack() *FreqStack { return &FreqStack{freq: map[int]int{}, group: map[int][]int{}} }

func (s *FreqStack) Push(x int) {
	s.freq[x]++
	f := s.freq[x]
	if f > s.maxFreq {
		s.maxFreq = f
	}
	s.group[f] = append(s.group[f], x)
}

func (s *FreqStack) Pop() int {
	g := s.group[s.maxFreq]
	x := g[len(g)-1]
	s.group[s.maxFreq] = g[:len(g)-1]
	s.freq[x]--
	if len(s.group[s.maxFreq]) == 0 {
		s.maxFreq--
	}
	return x
}
// 8. Maximum frequency stack (LC 895): freq -> stack of values.
class FreqStack {
    unordered_map<int, int> freq;
    unordered_map<int, vector<int>> group;
    int maxFreq = 0;
public:
    void push(int x) {
        int f = ++freq[x];
        maxFreq = max(maxFreq, f);
        group[f].push_back(x);
    }
    int pop() {
        int x = group[maxFreq].back();
        group[maxFreq].pop_back();
        freq[x]--;
        if (group[maxFreq].empty()) maxFreq--;
        return x;
    }
};
// 8. Maximum frequency stack (LC 895).
static class FreqStack {
    final Map<Integer, Integer> freq = new HashMap<>();
    final Map<Integer, Deque<Integer>> group = new HashMap<>();
    int maxFreq = 0;
    void push(int x) {
        int f = freq.merge(x, 1, Integer::sum);
        maxFreq = Math.max(maxFreq, f);
        group.computeIfAbsent(f, z -> new ArrayDeque<>()).push(x);
    }
    int pop() {
        int x = group.get(maxFreq).pop();
        freq.merge(x, -1, Integer::sum);
        if (group.get(maxFreq).isEmpty()) maxFreq--;
        return x;
    }
}
# 8. Maximum frequency stack (LC 895).
class FreqStack:
    def __init__(self):
        self.freq, self.group, self.max_freq = defaultdict(int), defaultdict(list), 0

    def push(self, x):
        self.freq[x] += 1
        f = self.freq[x]
        self.max_freq = max(self.max_freq, f)
        self.group[f].append(x)

    def pop(self):
        x = self.group[self.max_freq].pop()
        self.freq[x] -= 1
        if not self.group[self.max_freq]:
            self.max_freq -= 1
        return x

All O`one Data Structure (432): inc, dec, getMaxKey, getMinKey in O(1). It is LFU's bucket idea turned into a sorted list: a doubly linked list of count buckets in increasing order, each holding a set of keys, and a map from key to its bucket. A count changes by one, so a key only moves to the neighbouring bucket (creating it if needed, deleting the old one if it empties). Min and max are the two ends.

Same family: Design Twitter (per-user tweet lists, k-way merge with a heap), Design In-Memory File System (a trie keyed by path segment), Design Search Autocomplete System (trie with top-3 per node).

Thread safety follow-up: one lock around every method is the correct first answer. Then: a read-write lock helps only if reads do not mutate (an LRU get does move the node, so it is a write); shard the cache by key hash into N independent LRUs with N locks (that is how Guava and many production caches scale); or approximate LRU (CLOCK, as the kernel's reference bits do) so reads only set a flag.
