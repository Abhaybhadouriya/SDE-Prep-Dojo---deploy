In an LRU cache, why does each list node store its key?

  1. It is not needed
  2. To compute the hash faster
  3. So that evicting the tail can also delete the key from the map
  4. To sort the list
Eviction starts from the list (tail.prev). Without the key inside the node you cannot find the map entry to remove.

In an LFU cache, a new key is inserted. What is minFreq afterwards?

  1. 1
  2. Unchanged
  3. The largest frequency
  4. The old minFreq + 1
A new key has been used once, and nothing can have a smaller count, so minFreq is 1.

A queue made of two stacks: when is the in stack poured into out?

  1. When in is full
  2. On every pop
  3. After every push
  4. Only when out is empty and we need to pop or peek
Pouring while out still has items would put newer items above older ones. Pouring only into an empty out keeps queue order and gives amortized O(1).

RandomizedSet holds [10, 20, 30]. You remove 30. What must the code handle?

  1. Re-hashing the map
  2. Shifting all elements left
  3. x is the last element, so "move last into the hole" moves 30 onto itself; the map update must not leave 30 behind
  4. Nothing special
Write idx[last] = i first, then delete idx[x]. When x is last, the delete wins and the entry is gone, as it should be.

Hit counter with 300 buckets indexed by t % 300. A hit arrives at t = 305 and bucket 5 holds second 5. What happens?

  1. Add to the existing count
  2. Grow the array
  3. Ignore the hit
  4. The bucket is stale: set its second to 305 and its count to 0, then add 1
Second 5 is outside the 300 s window by now, so the bucket is reused for second 305.

Maximum Frequency Stack after pushes 4, 4, 6, 6, 4. What does the first pop return?

  1. 4, because it has the highest frequency (3)
  2. Nothing, ties are not allowed
  3. The most recent value, 4, because of recency only
  4. 6
4 has frequency 3, 6 has 2. The top of group[3] is 4. Recency only breaks ties within the same frequency.
