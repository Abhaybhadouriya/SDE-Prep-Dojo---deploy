Shape 3: two passes (candy)

Candy. n children stand in a row, each with a rating. Give each child at least one candy, and any child with a higher rating than an adjacent child must get more candies than that neighbour. Return the minimum total. n is 1 to 5 x 104, ratings 0 to 5 x 104. (Original: LeetCode 135.)

Each child has two constraints, one per neighbour, and they pull in opposite directions. A single left-to-right pass cannot see a long falling slope coming. So split the problem: the left pass gives every child the least that satisfies the left rule, the right pass raises children just enough for the right rule, keeping the larger of the two numbers. Each value is the least that satisfies both rules, so the sum is minimal.

  1. Everyone starts with one candy.
  2. Left pass: a child rated higher than the left neighbour gets left + 1. Only child 1 (rating 4 > 2) changes, to 2. The falling slope 4, 3, 2, 1 is still all ones: wrong for the right rule.
  3. Right pass, from the end. Child 4 keeps 1. Child 3 (2 > 1) needs right + 1 = 2.
  4. Child 2 (3 > 2) needs 3.
  5. Child 1 (4 > 3) needs 4. The left pass said 2; we keep max(2, 4) = 4, so both rules hold.
  6. Child 0 (2 < 4) has no right-side demand and keeps 1. Sum = 11. Two passes, O(n) time, O(n) space.

The loop behind the steps. Invariant: after the left pass every child beats a lower-rated left neighbour; the right pass fixes right neighbours with max(), which keeps the left-pass promise. Lifted unchanged from the tested templates below.

// 3. Two-pass: candy (each pass fixes one neighbour rule)
int candy(const vector<int>& r) {
    int n = r.size();
    vector<int> c(n, 1);
    for (int i = 1; i < n; ++i)                 // left neighbour rule
        if (r[i] > r[i - 1]) c[i] = c[i - 1] + 1;
    for (int i = n - 2; i >= 0; --i)            // right neighbour rule, keep the left result
        if (r[i] > r[i + 1]) c[i] = max(c[i], c[i + 1] + 1);
    return accumulate(c.begin(), c.end(), 0);
}
# 3. Two-pass: candy (each pass fixes one neighbour rule)
def candy(ratings):
    n = len(ratings)
    c = [1] * n
    for i in range(1, n):              # left neighbour rule
        if ratings[i] > ratings[i - 1]:
            c[i] = c[i - 1] + 1
    for i in range(n - 2, -1, -1):     # right neighbour rule, keep the left result
        if ratings[i] > ratings[i + 1]:
            c[i] = max(c[i], c[i + 1] + 1)
    return sum(c)
