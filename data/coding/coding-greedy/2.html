When greedy is safe: the exchange argument

The tool that proves almost every interview greedy is the exchange argument. Take any optimal answer that disagrees with greedy. Show that you can swap its choice for the greedy choice without making it worse. Then an optimal answer that agrees with greedy exists, and greedy is safe.

The classic: remove the fewest intervals so the rest do not overlap. You get a list of intervals [start, end] (between 1 and 105 of them, with -5 x 104 ≤ start < end ≤ 5 x 104). Two intervals that only touch at a point, like [1,2] and [2,3], do not overlap. Return the smallest number of intervals to delete so that the remaining ones never overlap. (Original: LeetCode 435 Non-overlapping Intervals.) Deleting the fewest is the same as keeping the most.

Why ending earliest is safe (the exchange). Let OPT be any largest set of non-overlapping intervals, and let its first interval be X. Greedy's first choice is G, the interval that ends earliest of all. G ends no later than X, so if we replace X by G inside OPT, G cannot hit OPT's second interval (that one starts after X ends, hence after G ends). OPT keeps the same size and now starts with G. Repeat the argument on the intervals that start after G ends. Greedy never falls behind.

Why sorting by start is not safe. An interval that starts first may be very long, like B above: it would block both A and C. Sorting by length fails too: a short interval can sit across the boundary of two long ones that do not overlap each other. When you propose a greedy order, try to break it with a tiny counterexample like these before you code it.

  1. State the greedy choice. "Keep the interval that ends first."
  2. Take an optimal answer that differs. "OPT starts with X instead."
  3. Swap and check. "Replacing X by G keeps OPT valid and the same size."
  4. Recurse. "The rest is the same problem on what remains."

A second proof style is greedy stays ahead: show that after k steps greedy is at least as good as any other strategy after k steps (for example, its k-th kept interval ends no later). Jump Game II below uses this: after k jumps, greedy has reached at least as far as anyone could.

When you say "greedy" in an interview, the next question is "why is it correct?". Say the exchange in two sentences. If you cannot, say so and offer the DP; a correct O(n2) beats a wrong O(n).
