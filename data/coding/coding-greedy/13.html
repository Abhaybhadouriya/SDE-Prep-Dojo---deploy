Remember this

Revision card

  • Cue: "Minimum number of", intervals, jumps, gas stations, a choice that looks locally obvious.
  • Insight: A local rule is safe when an exchange argument or "greedy stays ahead" proves it.
  • State: a sort order + one running value (furthest reach, tank, last end).
  • Trap: Trusting a greedy rule without a proof or a counterexample check; strict vs non-strict overlap.
  • Cost: Usually O(n log n) for the sort, then O(n).

More to remember

  • Greedy = order + rule + reason. The reason is an exchange argument or "greedy stays ahead".
  • Reachability: one number (furthest reach) replaces a whole DP because reachable indices form a prefix.
  • Gas station: total ≥ 0 decides existence; a negative tank at i rules out every start up to i.
  • Intervals: sort by end. Watch strict vs non-strict overlap.
  • Rules from both sides: two passes, take the max.
  • One bracket type: a counter. Wildcards: a [lo, hi] range with lo clamped at 0.
  • Arrangement problems: the pairwise swap test is the comparator (a + b > b + a).
  • Counting ways, arbitrary weights with a capacity, or a small counterexample: use DP, not greedy.
