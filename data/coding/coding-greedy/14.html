To keep the most non-overlapping intervals, sort them by...

  1. start time
  2. it does not matter
  3. end time
  4. length
Ending earliest leaves the most room for the remaining intervals; the exchange argument proves it. Start and length both have small counterexamples.

Jump Game on [3, 0, 0, 0, 1]: what does the reach pass return?

  1. true, reach becomes 4
  2. false, reach stays 3 and index 4 is beyond it
  3. true, because the last value is 1
From index 0 reach is 3. Indices 1 to 3 hold 0, so reach stays 3, and index 4 is never reached.

Gas station: gains are +2, -5, +1, +1. What is the answer?

  1. 2
  2. -1, because the total is negative
  3. 0
The total is -1. No start can finish a lap, whatever the single pass would pick.

Why does Candy need a second pass from the right?

  1. To make the sort stable
  2. To handle equal ratings
  3. A falling slope is invisible to a left-to-right pass, so the right-neighbour rule is never enforced
The left pass only enforces "more than the left neighbour". The right pass enforces the other rule; the max keeps both.

In the [lo, hi] method for Valid Parenthesis String, when do you return false early?

  1. When hi < 0
  2. When lo > hi
  3. When lo < 0
hi < 0 means even treating every star as "(" leaves too many ")". A negative lo is just clamped to 0.
