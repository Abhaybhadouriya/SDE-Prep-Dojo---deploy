Common mistakes

  • Sorting by the wrong key. Intervals by start instead of end; boats sorted but paired heaviest with heaviest. Write the exchange sentence first, then the key.
  • Forgetting the global check. Gas station without total >= 0 returns a start even when no lap is possible.
  • Off-by-one at the last index. Jump Game II loops to n - 2; jumping from the last index adds a phantom jump.
  • Strict vs non-strict overlap. In LC 435, [1,2] and [2,3] do not overlap, so the test is start >= lastEnd. In "minimum arrows" (LC 452) touching balloons share a point, so it flips to start > lastEnd.
  • One pass where two are needed. Candy with a single pass fails on any falling slope.
  • Not clamping lo. In the [lo, hi] trick, a negative lo makes valid strings look invalid at the end.
  • "000" instead of "0" in Largest Number, and integer comparison instead of string concatenation (overflow at 109 x 109 digits).
  • Comparator that is not a strict weak order. In C++ returning a + b >= b + a can crash std::sort; use strict >.
  • Claiming greedy without a proof and then defending it after a counterexample appears. Switch to DP early instead.
