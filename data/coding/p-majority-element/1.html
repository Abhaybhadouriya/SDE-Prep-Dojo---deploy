The problem (in our words)

An array nums of size n holds the ballots of an election. One value appears more than ⌊n / 2⌋ times: the majority value. Return it.

  • Input: an integer array nums.
  • Output: the majority value. Signature: int majorityElement(int[] nums).
  • You may assume the majority value always exists.

Constraints

  • n == nums.length
  • 1 <= n <= 5 * 10^4
  • -10^9 <= nums[i] <= 10^9
  • The input guarantees that a majority value exists.

Follow-up: can you solve it in linear time and O(1) extra space?

Practice it: LeetCode 169 - Majority Element · GfG - Majority Element · takeuforward

Constraints tell you: n ≤ 5 × 10^4 lets even O(n log n) sorting pass easily, so the follow-up is what is being tested: O(n) time and O(1) space. Values span ±10^9, so you cannot use a counting array indexed by value; a hash map or the vote trick is needed. "Guaranteed to exist" means no verification pass is required (a variant drops that guarantee).
