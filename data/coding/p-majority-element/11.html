The majority might not exist. Return -1 in that case.

Run the vote to get a candidate, then a second pass counts it; return it only if the count is greater than n/2. Still O(n) time, O(1) space.

How to answer

Explain that the vote only promises "if a majority exists, it is the candidate", using [1, 2, 3] as the counterexample.

Likely follow-ups
  • Can you avoid the second pass? Not in general with O(1) space and one read.
Find all values appearing more than n/3 times (LC 229).

At most two such values exist. Keep two candidates; on a match increment that counter; else if a counter is 0, take over that slot; else decrement both. Verify both candidates with a counting pass.

How to answer

Generalise: for n/k, keep k - 1 candidates (Misra-Gries summary).

Likely follow-ups
  • Why check "match" before "counter is 0"? Otherwise both slots can hold the same value.
The data is a huge stream across many machines. Find the majority.

Votes merge: each machine returns (cand, count). Merging two summaries: same candidate, add counts; different, keep the larger and subtract the smaller. The global candidate is then verified with one more distributed count. This is also how a segment tree merges votes (LC 1157).

How to answer

State the merge rule and why it is associative: it is still pairing different values.

Likely follow-ups
  • Top heavy hitters with error bounds: Misra-Gries or Count-Min sketch.
Give a one-line solution and its cost.

Sort and return nums[n/2]: the majority block is longer than half, so it covers the middle. O(n log n) time; it mutates the input. In C++, nth_element gives O(n) average.

How to answer

Good for showing range, then move to the vote for the O(1) space O(n) follow-up.

Likely follow-ups
  • Randomised: pick a random element and check it; expected fewer than 2 tries.
Solve it with bit manipulation.

For each bit b in 0..31, count how many values have bit b set. If more than n/2 do, the majority has bit b set. Rebuild the number; in Java the int wraps naturally, in Python subtract 2^32 if bit 31 is set. O(32n), O(1).

How to answer

Point out the same "more than half" argument applied per bit.

Likely follow-ups
  • Does the bit method work for n/3? No: two values can mix their bits.
