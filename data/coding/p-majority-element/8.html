Common mistakes

Checking count == 0 after the update. If you do count-- and then immediately replace the candidate with the current value, you lose the cancel step. Reset only when the count is already 0 before looking at x.

Trusting the candidate without the guarantee. On [1, 2, 3] the vote returns 3. In variants where a majority might not exist (GfG asks for -1), add a second pass that counts the candidate.

Using >= n/2. The majority is strictly more than ⌊n/2⌋. With [1, 2] neither value qualifies; an off-by-one in the hash-map version returns 1.

Bit counting with signed values. In Python, rebuilding the number from 32 bits gives a large positive for negative answers; convert back with x - (1 << 32) when bit 31 is set.
