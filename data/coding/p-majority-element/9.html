Revision card

  • Cue: value appearing more than n/2 times, O(1) space asked → Boyer-Moore vote.
  • Insight: cancel pairs of different values; the majority outnumbers all others, so it survives.
  • State: cand (current leader), count (unpaired copies of cand).
  • Trap: reset only when count is 0 before x; verify with a 2nd pass if no guarantee.
  • Cost: O(n) time, O(1) space; hash map O(n)/O(n); sort O(n log n).
cand, count = None, 0
for x in stream:
    if count == 0: cand = x             # prefix fully cancelled
    count += 1 if x == cand else -1
# if no guarantee: verify stream.count(cand) > n // 2

What does count mean at any moment?

  1. How many times cand appeared so far
  2. Copies of cand not yet cancelled by a different value
  3. The number of distinct values seen
  4. n/2 minus the frequency
It is the unpaired surplus of the current candidate within the current segment.

You need all values appearing more than n/3 times. How many candidates do you keep?

  1. 1
  2. 3
  3. 2
  4. n/3
At most two values can exceed n/3. Keep two candidates and two counters, then verify both (LC 229).

Why is nums[n/2] after sorting always the majority?

  1. A block longer than n/2 must cover the middle index
  2. Sorting puts the most frequent value first
  3. It only works for odd n
  4. It is the median, which equals the mean
Wherever the block of majority copies starts, its length > n/2 makes it cross index n/2.
