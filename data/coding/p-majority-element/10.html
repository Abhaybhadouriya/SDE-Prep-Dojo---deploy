Technique: cancel pairs of different values with a candidate and a counter (Boyer-Moore), so a strict-majority value is found in one pass and O(1) space.

Closest match: LC 229 Majority Element II Medium

  • Same: the vote-and-cancel idea, O(n) time, O(1) space.
  • Different: return every value appearing more than ⌊n/3⌋ times, and none is guaranteed.
  • So: keep two candidates and two counters; a value that matches neither decrements both; finish with a counting pass to verify each candidate.
