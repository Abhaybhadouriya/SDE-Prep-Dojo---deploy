Why BFS is not enough, and the one operation everything shares

On an unweighted graph BFS gives shortest paths because it finishes all vertices at distance 1 before any at distance 2. With weights that argument breaks: the path with the fewest edges is not always the cheapest.

Every algorithm on this page is built from one operation called relaxation. Keep a table dist[v] = the cheapest cost found so far from the source to v (start with 0 for the source and infinity for everyone else). To relax an edge u → v with weight w:

if dist[u] + w < dist[v]:
    dist[v] = dist[u] + w      # found a cheaper way into v: through u
    parent[v] = u              # optional: remember it to rebuild the path

Relaxation never makes a distance wrong; it can only lower an over-estimate towards the truth. The three algorithms differ only in which edges they relax, in what order, and how many times:

AlgorithmRelaxation orderWhy it is enough
DijkstraEdges out of the cheapest unsettled vertex, each vertex onceWith non-negative weights, the cheapest unsettled vertex can never get cheaper later
Bellman-FordAll edges, in any order, V - 1 timesA shortest path has at most V - 1 edges; round r fixes paths with r edges
Floyd-WarshallEvery pair (i, j), through every intermediate vertex kAfter step k, d[i][j] is the best path using only vertices 0..k in the middle
