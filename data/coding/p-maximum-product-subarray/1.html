The problem (in our words)

A trading desk records the daily growth factor of a position as an integer array nums (negative factors mean the position flipped). Find the non-empty contiguous subarray whose product is the largest, and return that product.

Signature: int maxProduct(int[] nums). A subarray is a block of consecutive elements; it has at least one element.

Constraints:

  • 1 <= nums.length <= 2 * 104
  • -10 <= nums[i] <= 10
  • The product of any subarray of nums fits in a 32-bit signed integer.

Practice it: LeetCode 152 · GfG Maximum Product Subarray · TUF Maximum product subarray

Constraints tell you: n = 2·104 allows O(n²) (4·108 multiplications is slow but sometimes passes), so the brute force is a fine first answer; the target is O(n). Values include 0 and negatives, which is the whole difficulty. "Non-empty" means an all-negative single element like [-7] must return -7, not 0 or 1.
