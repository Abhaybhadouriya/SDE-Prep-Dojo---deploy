Common mistakes

Keeping only the maximum. Plain Kadane on products fails [-2,3,-4]: it returns 3 instead of 24, because the -6 it threw away was the run that the next negative needed.

Updating hi, then using the new hi for lo. hi = max(x, hi*x, lo*x); lo = min(x, hi*x, lo*x) reads the already-changed hi. Save the old values first (or swap on negative as in our code).

Starting best at 0 or 1. [-7] must return -7. Initialise with nums[0].

Prefix/suffix without the reset. After a zero the running product stays 0 forever unless you restart it at 1 (or treat 0 as "start again").
