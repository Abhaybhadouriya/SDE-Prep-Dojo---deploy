The problem (in our words)

You get an integer array nums of length n + 1. Every value lies in the range [1, n]. Exactly one value is repeated (it may appear two or more times); every other value appears at most once. Return the repeated value.

You must not modify nums, and you may use only constant extra space.

Signature: int findDuplicate(int[] nums).

Constraints:

  • 1 <= n <= 105
  • nums.length == n + 1
  • 1 <= nums[i] <= n
  • All values appear once except exactly one value, which appears two or more times.

Follow-ups in the original: prove that a repeated value must exist; solve it in linear time.

Practice it: LeetCode 287 · TUF article · GfG: all duplicates variant

Constraints tell you: n up to 105, so O(n2) (1010) is out, O(n log n) is fine, O(n) is the target. "Values 1..n, length n + 1" is the pigeonhole principle and also the hint that values can be used as indices. "Two or more times" kills the sum and XOR tricks: with [3,3,3,3] the values 1 and 2 are missing, so sum(nums) - n(n+1)/2 means nothing.
