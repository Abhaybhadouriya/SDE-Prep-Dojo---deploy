Dry run

Example 1, nums = [2,5,4,1,3,4]. The arrows are 0->2, 1->5, 2->4, 3->1, 4->3, 5->4: tail 0 -> 2, cycle 4 -> 3 -> 1 -> 5 -> 4.

  1. Phase 1 starts: slow and fast both stand on index 0.
  2. Move 1: slow = nums[0] = 2. fast takes two hops: 0 -> 2 -> 4.
  3. Move 2: slow 2 -> 4 (now inside the cycle). fast 4 -> 3 -> 1.
  4. Move 3: slow 4 -> 3. fast 1 -> 5 -> 4. fast gains one node per move on slow.
  5. Move 4: slow 3 -> 1, fast 4 -> 3 -> 1. They meet at index 1. Slow walked 4 = tail 2 + 2 nodes into the cycle; the cycle length is 4.
  6. Phase 2: a new pointer finder starts at 0; slow stays at the meeting point. Both now move one hop at a time.
  7. finder 0 -> 2, slow 1 -> 5.
  8. finder 2 -> 4, slow 5 -> 4. They meet at 4: the entry of the cycle. Answer: 4. The array was only read, never written.
