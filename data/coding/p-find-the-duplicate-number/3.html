Recognise the pattern

Cue: n + 1 values in 1..n (or any array whose values are valid indices) + "do not modify" + "O(1) space" -> treat i -> nums[i] as a linked list and run Floyd's cycle detection. Without the no-modify rule, the cue for "values in 1..n" is index marking or cyclic sort instead.
