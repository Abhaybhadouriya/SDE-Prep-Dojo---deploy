Recognise the pattern

When you see "design a class" + "each operation O(1)" + an order that changes on access (recent, oldest, insertion), think hash map whose values are handles into a doubly linked list. Order by frequency instead -> buckets of lists (LFU). Random element in O(1) -> array + index map.
