The story

Explain like I'm 5

Two friends carry a pile of parcels home and want the loads to weigh the same. You do not need to plan both bags. Fill one bag until it weighs exactly half the total: whatever is left over is the other half, automatically. So the only question is "can I pick some parcels that weigh exactly half?". Keep a list of every weight you can make so far, and each new parcel adds "old weight + this parcel" to the list.

The two-sided problem collapses to a one-sided subset sum, and subset sum is the 0/1 knapsack with a yes/no value. The whole interview is about getting that reduction out loud and then writing the 1-D table without letting a number be used twice.

From your world

The reachable-sums row is a bitmap. Adding a number x is bits |= bits << x: every set bit s also sets bit s + x. It is the same move as building a set of reachable offsets in a scatter-gather list, one segment length at a time.
