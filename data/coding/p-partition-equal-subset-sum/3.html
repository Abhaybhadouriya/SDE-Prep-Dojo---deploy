Recognise the pattern

Cue: "split into two groups with equal (or closest) sums" + small positive values -> fix one group's target (total / 2) and ask "is this sum reachable with each item used at most once?" -> 0/1 knapsack on sums, one boolean row, inner loop downward.

Try a few small inputs and the rule appears: the answer depends only on which sums are reachable, never on the order of the array.

numstotalreachable sumshalf reachable?
[1, 5, 11, 5]220,1,5,6,10,11,...11: yes ✓
[1, 2, 5]80,1,2,3,5,6,7,84: no ✗
[4, 4]80,4,84: yes ✓
[7]70,7odd: no ✗
