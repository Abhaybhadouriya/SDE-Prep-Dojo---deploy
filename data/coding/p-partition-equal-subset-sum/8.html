Common mistakes

Inner loop upward. for s in range(x, target + 1) reads cells set by the same x, so x is used unlimited times. That solves Coin Change II style problems, not this one. With nums = [2] and target 4 it wrongly says 4 is reachable.

Stopping at "total is even". [1,1,1,9] has an even total and no split. Parity is only the first filter.

Greedy (sort and fill the lighter bag). [3,3,2,2,2] totals 12: greedy puts 3 | 3, then 2 | 2, then 2 -> 7 vs 5, but {3,3} vs {2,2,2} works. Greedy has no exchange argument here.

Indexing the DP by element value or array index only. The state needs the sum; a 1-D array over indexes cannot tell which sums are reachable.

Forgetting can[0] = true. Without the empty subset nothing ever becomes reachable and every answer is false.
