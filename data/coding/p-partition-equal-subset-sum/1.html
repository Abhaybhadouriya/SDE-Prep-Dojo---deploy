The problem (in our words)

You are given an array nums of positive integers (think of them as parcel weights). Decide whether the array can be split into two subsets with equal sums: every element goes into exactly one of the two subsets. Return true if such a split exists, otherwise false.

Signature: boolean canPartition(int[] nums).

Constraints:

  • 1 <= nums.length <= 200
  • 1 <= nums[i] <= 100

Practice it: LeetCode 416 · GfG Partition Equal Subset Sum · TUF article

Constraints tell you: the total is at most 200 x 100 = 20,000, so the target total / 2 is at most 10,000. A table indexed by sum has 10,001 cells and n x target is 2 million steps: tiny. Values are small and positive, which is exactly when a sum-indexed DP (pseudo-polynomial) beats 2200 subsets.
