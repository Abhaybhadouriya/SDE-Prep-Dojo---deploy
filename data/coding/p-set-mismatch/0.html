The story

Explain like I'm 5

A cloakroom has hooks numbered 1 to 5 and hands out one ticket per hook. At the end of the night the attendant collects five tickets, but the printer jammed: one number was printed twice and another never. She walks along the hooks and, for each ticket, hangs a little flag on its hook. When she reaches for a hook that already has a flag, she has found the repeated ticket. Afterwards, the one hook with no flag is the number that was never printed.

From your world

This is a bitmap allocator check done without a separate bitmap. The values are block numbers 1..n, and the sign bit of each array word is borrowed as the "allocated" bit for block i + 1. A block marked twice is a double allocation; a block never marked is a leak. Borrowing a spare bit of the data itself is the same trick as storing flags in the low bits of an aligned pointer.
