Edge cases

InputExpectedWhy it matters
[2,2][2,1]Smallest n; the missing value is 1, slot 0.
[1,1][1,2]The missing value is n: a scan that looks only for "a gap between neighbours" misses it.
[4,2,1,4,5][4,3]The second 4 sits in a slot that was already flipped: forgetting abs() indexes nums[-5].
[3,2,3,4,6,5][3,1]The duplicate is read before the missing slot is even reached; order of discovery does not matter.
n = 104, last value replaced by 1[1,10000]Largest case: sum of squares is about 3.3 · 1011, which overflows 32-bit int.
