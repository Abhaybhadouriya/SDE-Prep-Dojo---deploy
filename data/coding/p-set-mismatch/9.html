60-second recall

  • Cue: values in 1..n, length n, one repeated and one absent.
  • Insight: slot v-1 is value v's flag; sign bit = seen. Already negative = duplicate.
  • State: the array itself (signs), dup; the positive slot after the pass = missing.
  • Trap: index with abs(); return [dup, miss]; restore the signs; 64-bit sums.
  • Cost: O(n) time, O(1) space; read-only: sum + sum of squares, or XOR split.
for x in a:                      # values 1..n
    v = abs(x)
    if a[v - 1] < 0: report_dup(v)
    else: a[v - 1] = -a[v - 1]
absent = [i + 1 for i in range(n) if a[i] > 0]
for i in range(n): a[i] = abs(a[i])   # restore

Why do we index with abs(nums[i])?

  1. Values can be negative in the input
  2. The cell may already have been marked negative by an earlier value
  3. To avoid overflow
The input is all positive; the minus signs are our own marks, and the magnitude still holds the original value.

nums = [3,1,3]. After the marking pass, which slot is still positive?

  1. slot 0
  2. slot 2
  3. slot 1
Values 3 and 1 mark slots 2 and 0; nothing marks slot 1, so 2 is missing and the answer is [3, 2].

The input must not be modified, even temporarily. Which approach still gives O(1) space?

  1. Sum and sum of squares (or XOR split)
  2. Sign marking
  3. Count array
Two cancelling equations need only two accumulators and never write to the array.
