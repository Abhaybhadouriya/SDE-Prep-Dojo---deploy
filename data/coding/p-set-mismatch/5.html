Example 3, [4,2,1,4,5], with sign marking. Pink cells are marked (negative); the green cell is the slot the current value points at.

  1. Start: value v belongs to slot v - 1. Nothing is marked yet. We will flip a slot to negative the first time its value shows up.
  2. i = 0: |nums[0]| = 4. Slot 3 is positive, so this is the first 4: flip it to -4.
  3. i = 1: |nums[1]| = 2. Slot 1 is positive, so this is the first 2: flip it to -2.
  4. i = 2: |nums[2]| = 1. Slot 0 is positive, so this is the first 1: flip it to -4.
  5. i = 3: |nums[3]| = 4, and slot 3 is already negative: value 4 was seen before. dup = 4; leave the slot as it is.
  6. i = 4: |nums[4]| = 5. Slot 4 is positive, so this is the first 5: flip it to -5.
  7. Second pass: slot 2 is the only positive cell, so nobody ever marked it and value 3 is missing. Answer [4, 3]; the pass also flips the negatives back, so the caller's array is unchanged.
