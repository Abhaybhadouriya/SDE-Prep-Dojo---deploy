Common mistakes

Returning [missing, duplicate]. The order is fixed: the repeated value first, then the missing one. Both values are in range, so a swapped answer still "looks" right.

Using nums[i] instead of abs(nums[i]) as the index. Cells you have not read yet may already be marked; a negative index crashes in C++/Java and silently reads from the end in Python.

Neighbour scan after sorting finds only the duplicate. The missing value can be 1 or n, outside every adjacent pair. Check nums[0] != 1 and nums[n-1] != n, or use the expected-sum trick.

32-bit overflow in the math version. n(n+1)(2n+1)/6 for n = 104 is about 3.3 · 1011. Use 64-bit accumulators or running differences.

XOR split without the final check. The two halves give {d, m} but not which is which; scan the array once to see which of the two values is present.
