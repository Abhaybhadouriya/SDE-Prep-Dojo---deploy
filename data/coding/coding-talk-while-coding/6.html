Narrating while you code: say the invariant

Once you start typing, talk at the level of blocks, not keystrokes. Before each block, say what it is for; inside a loop, say the invariant: the fact that is true every time the loop starts. The invariant is the proof of correctness in one sentence, and interviewers write it down.

  1. Before the loop, say the plan in one sentence. The bookings are already sorted here; in code, the sort is the line before the loop.
  2. First booking: the result is empty, so it starts a new block. Say the empty case out loud once, so the interviewer knows you thought of it.
  3. [2,6] starts at 2, inside the last block [1,3], so it overlaps. Extend the end to max(3, 6). Say "max" and why (a nested booking could be shorter).
  4. [8,10] starts after 6: a gap. Say the invariant here, because this is the moment it does work: since starts are sorted, no later booking can overlap [1,6], so that block is final.
  5. [15,18]: another gap, another block. No new reasoning; keep the narration short when nothing new happens.
  6. Finish with cost and the next step: "now I will run the touching and nested cases". That hands you straight into testing.

Here is the same solution as a template: the comments are the sentences you say. The second block is the tiny test harness you type at the end, running the examples you wrote in minute three.

Every version on this page, Go included, was compiled and run (Go 1.27, C++14, Java 21, Python 3.11) and passes its checks.

// Say: "I will sort by start, then sweep once, keeping a result list."
// Spec agreed: intervals [start, end], start <= end; touching ([1,4],[4,5]) counts as overlap.
func merge(intervals [][]int) [][]int {
	res := [][]int{}
	if len(intervals) == 0 {
		return res // say: "empty in, empty out"
	}
	iv := append([][]int(nil), intervals...) // say: "copy so I do not reorder the caller's slice"
	sort.Slice(iv, func(a, b int) bool { return iv[a][0] < iv[b][0] })
	for _, cur := range iv {
		// Invariant (say it): res is sorted and disjoint; only the last block can still grow.
		if n := len(res); n > 0 && cur[0] <= res[n-1][1] {
			res[n-1][1] = max(res[n-1][1], cur[1]) // say: "max, because cur may be nested"
		} else {
			res = append(res, []int{cur[0], cur[1]}) // say: "a gap: start a new block"
		}
	}
	return res // O(n log n) time, O(n) output
}

// Spec agreed: intervals [start, end], start <= end; touching ([1,4],[4,5]) counts as overlap.
vector<vector<int>> merge(vector<vector<int>> intervals) {
    if (intervals.empty()) return {};                    // say: "empty in, empty out"
    sort(intervals.begin(), intervals.end());            // say: "O(n log n), now overlaps are neighbours"
    vector<vector<int>> res;
    for (const auto& cur : intervals) {
        // Invariant (say it): res is sorted and disjoint; only res.back() can still grow.
        if (!res.empty() && cur[0] <= res.back()[1]) {
            res.back()[1] = max(res.back()[1], cur[1]); // say: "max, because cur may be nested"
        } else {
            res.push_back(cur);                          // say: "a gap: start a new block"
        }
    }
    return res;                                          // O(n log n) time, O(n) for the output
}

static int[][] merge(int[][] intervals) {
    if (intervals.length == 0) return new int[0][];            // say: "empty in, empty out"
    int[][] iv = intervals.clone();                             // say: "I will not reorder the caller's array"
    Arrays.sort(iv, (a, b) -> Integer.compare(a[0], b[0]));     // say: "O(n log n), overlaps become neighbours"
    List<int[]> res = new ArrayList<>();
    for (int[] cur : iv) {
        // Invariant (say it): res is sorted and disjoint; only the last block can still grow.
        int[] last = res.isEmpty() ? null : res.get(res.size() - 1);
        if (last != null && cur[0] <= last[1]) {
            last[1] = Math.max(last[1], cur[1]);                // say: "max, because cur may be nested"
        } else {
            res.add(new int[]{cur[0], cur[1]});                 // say: "a gap: start a new block"
        }
    }
    return res.toArray(new int[0][]);                           // O(n log n) time, O(n) output
}
# Say: "I will sort by start, then sweep once, keeping a result list."
# Spec agreed: intervals [start, end], start <= end; touching ([1,4],[4,5]) counts as overlap.
def merge(intervals: list[list[int]]) -> list[list[int]]:
    res: list[list[int]] = []
    for start, end in sorted(intervals):       # say: "O(n log n), overlaps become neighbours"
        # Invariant (say it): res is sorted and disjoint; only res[-1] can still grow.
        if res and start <= res[-1][1]:
            res[-1][1] = max(res[-1][1], end)  # say: "max, because this one may be nested"
        else:
            res.append([start, end])           # say: "a gap: start a new block"
    return res                                 # empty in -> empty out, no special case

Do not narrate syntax. "Now I write for, open bracket..." is noise. "This loop walks the sorted bookings; the result's last block is the only one that can still grow" is signal. When you need silence to get a tricky index right, say so: "give me twenty seconds to get the boundaries right, then I will walk you through it."
