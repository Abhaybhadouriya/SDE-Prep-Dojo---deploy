Quiz

Which clarifying question is most worth asking for "merge overlapping intervals"?

  1. Will the interviewer run my code?
  2. Which language should I use?
  3. Do intervals that only touch at an end count as overlapping?
  4. Are the numbers written in decimal?
Its answer changes one character in the code (< versus <=) and the output on real inputs.

Which narration gives the interviewer the most useful evidence?

  1. "Everything in res is disjoint and sorted, so only its last block can grow."
  2. "Now I type a for loop over i."
  3. "I have seen this one before."
  4. "OK. Hmm. OK."
An invariant is a one-sentence correctness argument; the interviewer can write it down as problem-solving evidence.

The interviewer asks "what if the input were sorted?". The best first reply is...

  1. Repeat the idea, connect it to the problem, then act on it
  2. "It is not sorted, though."
  3. Stay quiet and keep coding the current plan
  4. Ask for the full solution
Repeat, connect, act. A hint used quickly is a positive signal.

Ten minutes left and the optimal solution fails. What usually scores best?

  1. Keep debugging silently until time runs out
  2. Start a third, different approach
  3. Stop and ask to end the interview
  4. Code the correct brute force, test it, and explain the fast idea in words
Correct plus a clear explanation beats broken and clever. Say the plan out loud before switching.

Which complexity statement is the most complete?

  1. "O(1) because I use a hash map."
  2. "O(n log n + n + 1)."
  3. "O(n log n) from the sort, linear sweep; O(n) output and the sort's extra space."
  4. "It's fast."
Dominant term, its source, and space split into output and extra.

You are stuck. Which step most often reveals the algorithm?

  1. Typing random code to see what happens
  2. Solving a tiny example by hand and describing what you did
  3. Asking "what's the trick?"
  4. Waiting silently for a hint
The steps you take by hand (looking back for the nearest bigger value, keeping a running count) are usually the data structure you need.
