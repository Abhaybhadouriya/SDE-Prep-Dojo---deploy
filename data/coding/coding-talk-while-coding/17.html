Revision card

  • Cue: Every round, from the first minute.
  • Insight: The interviewer grades what they hear: say why, not what.
  • State: restate, clarify, examples, brute force with cost, plan with cost, "shall I code it?".
  • Trap: Long silences; ignoring a hint; arguing for a greedy you have not checked.
  • Cost: Talk in blocks; one sentence per decision.

More to remember

  • The interviewer grades what they can hear: say why, not what.
  • First five minutes: restate, clarify, examples, brute force with cost, plan with cost, "shall I code it?".
  • Ask questions whose answers change the code; propose defaults for the rest.
  • Optimise with one sentence: "slow because ___, avoid it with ___, now ___."
  • While coding, talk in blocks and say the loop invariant.
  • Hints: repeat, connect, act. Bugs: name the input, the line, the fix.
  • Stuck: constraints, tiny example by hand, the slow query, the pattern list, a narrow question, then the brute force.
  • End with time and space and their sources, then test out loud.
