Stating complexity like an engineer

Say time and space at the end without being asked, and say where each comes from:

  • Name the dominant term. "O(n log n), from the sort; the sweep is O(n)." Not "O(n log n + n)".
  • Separate output from extra space. "O(n) for the output; extra space is whatever the sort uses." Then know your sort: C++ std::sort uses O(log n) stack; Java's Arrays.sort on objects is TimSort, O(n) worst case; Python's sorted is O(n).
  • Say "amortised" and "expected" correctly. A hash map lookup is O(1) expected; a dynamic array append is O(1) amortised; KMP's inner loop is amortised O(1) per character.
  • Name the variables. For two inputs, use both: O(n + m), O(V + E), O(rows · cols).
  • Count recursion. A recursive DFS on a tree is O(h) stack, which is O(n) for a degenerate tree. Say it before the interviewer does.
