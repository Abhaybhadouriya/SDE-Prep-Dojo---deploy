Examples: small, drawn and slightly nasty

The examples in the prompt are chosen to be friendly. Write your own: one normal case, one boundary case, one that breaks the naive idea. Draw them if the input has shape (intervals, trees, grids): pictures make bugs visible before code exists.

Say why each example is there: "this nested one is to make sure I take the max of the two ends". That sentence alone tells the interviewer you think about correctness before you type.
