The problem (in our words)

A sensor logs integer readings into an array arr. For each distinct reading, count how many times it appears. Return true if no two distinct readings appear the same number of times (every occurrence count is unique), and false otherwise.

Signature: boolean uniqueOccurrences(int[] arr).

Constraints

  • 1 <= arr.length <= 1000
  • -1000 <= arr[i] <= 1000

Practice it: LeetCode 1207 Unique Number of Occurrences (in the LeetCode 75 list)

Constraints tell you: n <= 1000, so any approach up to O(n2) passes; the interviewer wants the O(n) two-hash version and the reasoning. Values are negative too, so an array counter needs an offset (+1000). A count can be at most 1000, which bounds the second table as well.
