Recognise the pattern

Cue: a question about how often things occur ("unique counts", "same frequency", "frequencies can be made equal") -> build the value -> count map first, then treat the counts as a new array and apply an ordinary technique to it (duplicate check, sort, bucket).

Here the second technique is Contains Duplicate on the counts. In Determine if Two Strings Are Close it is "compare the sorted counts", in Minimum Deletions to Make Frequencies Unique it is a greedy over the counts. Pattern page: Arrays & hashing · explorer node Arrays > hashing > frequency count.
