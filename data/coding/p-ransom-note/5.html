Dry run

ransomNote = "added", magazine = "dread". Green slots still have copies, grey slots are used up, red means the note asked for a copy that does not exist.

  1. Note length 5 <= magazine length 5, so no early exit. One pass over the magazine "dread" fills the stock: d = 2, r = 1, e = 1, a = 1 (the real array has 26 slots).
  2. Note letter 0 is 'a'. Take one copy: a drops from 1 to 0. Zero is fine, it means the last copy was just used.
  3. Note letter 1 is 'd'. d drops from 2 to 1. The order in which the note asks for letters does not matter, only how many.
  4. Note letter 2 is 'd' again. d drops to 0: both copies of 'd' in the magazine are now glued onto the note.
  5. Note letter 3 is 'e'. e drops to 0. The spare 'r' is never needed; extra magazine letters are allowed.
  6. Note letter 4 is a third 'd'. d would go to -1: the note needs one more copy than the magazine has. Return false immediately, without reading the rest.
