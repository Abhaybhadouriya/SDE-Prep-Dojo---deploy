Recognise the pattern

Cue: "build X from the letters of Y", "each letter used once", "can we form" -> a multiset containment check: count Y, spend the counts on X. Small fixed alphabet -> counter array; open alphabet -> hash map.

This is the "subset" member of the frequency-count family: Valid Anagram asks for equal counts, Ransom Note for "enough" counts, and Find Words That Can Be Formed and Maximum Number of Balloons ask the same question many times.
