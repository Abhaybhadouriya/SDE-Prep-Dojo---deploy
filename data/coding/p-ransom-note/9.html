Revision card

  • Cue: "build X from the letters of Y, each used once" -> multiset containment.
  • Insight: count Y into a stock, spend it on X; the first negative slot means false.
  • State: int stock[26]; optional early exit when len(X) > len(Y).
  • Trap: leftovers are fine, do not demand all zero; presence is not enough.
  • Cost: O(n + m) time, O(1) space (26 ints); cross-out is O(n·m).
stock = Counter(supply)          # or [0] * 26
for ch in demand:
    stock[ch] -= 1
    if stock[ch] < 0:
        return False
return True

Quick quiz

Which string do you count first into the stock?

  1. the note
  2. the shorter one
  3. the magazine
  4. it does not matter
The magazine is the supply; the note consumes it. Counting the note first only works if you then flip the check (count needs, and spend magazine letters until every need is met).

After the spend pass, the stock is a:0, o:1, p:0. What is the answer?

  1. false, because o is not 0
  2. true, because no slot is negative
  3. false, because a is 0
  4. cannot tell
Leftover supply is allowed. Only a negative slot (a letter the note needed but the magazine lacked) means false.

Why is a set of the magazine's letters not enough?

  1. it forgets how many copies each letter has
  2. sets are slow
  3. sets are unordered
  4. it is enough
"pp" from "op": the set {o, p} contains p, but there is only one copy and the note needs two.
