How to recognise it:

  • A supply string and a demand string; "each letter used once".
  • Positions never matter, only how many of each letter.

Practice order:

  1. 242 Valid Anagram (equal counts), then this problem (enough counts).
  2. 1189 Maximum Number of Balloons and 2287 (how many copies fit), then 1160 (many words).
  3. 691 Stickers to Spell Word (the same counts as a DP state).
