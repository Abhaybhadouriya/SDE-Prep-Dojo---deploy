The problem (in our words)

A kidnapper in a crime novel wants to send a note without handwriting, so every letter of the note must be cut out of one magazine. You get two strings: ransomNote (the message to compose) and magazine (the letters available). Return true if the note can be assembled from the magazine's letters, otherwise false. Each letter of the magazine can be cut out and used at most once; letters of the magazine that the note does not need may be left unused.

Signature: boolean canConstruct(String ransomNote, String magazine).

Constraints

  • 1 <= ransomNote.length, magazine.length <= 105
  • ransomNote and magazine contain only lowercase English letters.

Practice it: LeetCode 383 Ransom Note · same idea on Codeforces: CF 43B Letter (case-sensitive, spaces free)

Constraints tell you: up to 105 letters on each side, so O(n·m) cross-out is 1010 steps and too slow; O(n + m) is the target. "Only lowercase letters" says a fixed array of 26 counters beats a hash map. Unlike Valid Anagram, the lengths may differ, and that is legal as long as the note is not longer.
