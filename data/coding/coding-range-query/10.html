Practice problems, in order

Fenwick tree: updates and counting

  • 307. Range Sum Query - Mutable Medium - the anchor: Fenwick (or segment tree) with update = add the difference. original
  • 308. Range Sum Query 2D - Mutable Medium Premium - a 2D Fenwick: two nested lowbit loops, O(log R log C). original
  • 315. Count of Smaller Numbers After Self Hard - compress values, walk from the right, count ranks below. original
  • 1395. Count Number of Teams Medium - for each middle soldier: smaller on the left times larger on the right (n is small, but the BIT version scales). original
  • 1649. Create Sorted Array through Instructions Hard - cost = min(count below, count above) at insert time; BIT over values. original
  • 493. Reverse Pairs Hard - count j > i with nums[i] > 2 nums[j]; merge sort or BIT over compressed 2x values. original
  • 327. Count of Range Sum Hard - prefix sums plus counting: how many earlier P in [P - upper, P - lower]. original
  • 2179. Count Good Triplets in an Array Hard - map one array into the other's positions, then count increasing triplets with two BITs. original

Segment tree

  • 2080. Range Frequency Queries Medium - warm-up: positions per value plus binary search; then explain the segment tree alternative. original
  • 2407. Longest Increasing Subsequence II Hard - segment tree over values: dp[v] = 1 + max over [v - k, v - 1]. original
  • 2286. Booking Concert Tickets in Groups Hard - max and sum per node; descend to the first row with enough seats. original
  • 699. Falling Squares Hard - range assign plus range max (lazy), or O(n²) since n is 1,000. original
  • 218. The Skyline Problem Hard - classic sweep with a max-heap; a segment tree over compressed x also works. original
  • 850. Rectangle Area II Hard - sweep line plus a segment tree of covered length (or O(n³) compression for n = 200). original

Ordered map: floor, ceiling and sweeps

  • 729. My Calendar I Medium - floor and ceiling of the new start: two neighbours to check. original
  • 731. My Calendar II Medium - allow double, refuse triple: keep the overlaps of the bookings as a second list, or sweep a +1/-1 map. original
  • 732. My Calendar III Hard - max overlap so far: sparse difference map and a sweep (or a lazy segment tree). original
  • 981. Time Based Key-Value Store Medium - floor by timestamp: binary search on an append-only list. original
  • 1146. Snapshot Array Medium - per index, a list of (snap_id, value); floor lookup on snap_id. original
  • 352. Data Stream as Disjoint Intervals Hard - merge a new number with its floor and ceiling intervals. original
  • 715. Range Module Hard - add / remove / query half-open ranges: ordered map of start to end, merge and split. original
  • 2276. Count Integers in Intervals Hard - same merging, plus a running count of covered integers. original
  • 220. Contains Duplicate III Hard - ordered set of the last k values: is the ceiling of x - t at most x + t? (buckets give O(n)). original
  • 2034. Stock Price Fluctuation Medium - a map of time to price plus an ordered multiset (or two lazy heaps) for max and min. original
