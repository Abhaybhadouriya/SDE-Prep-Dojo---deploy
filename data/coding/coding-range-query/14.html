In a Fenwick tree, which cells does t[12] cover? (12 = 1100 in binary)

  1. a[8..12]
  2. a[9..12]
  3. a[12] only
  4. a[1..12]
lowbit(12) = 4, so t[12] covers the 4 cells ending at 12: a[9..12].

Which indices does prefix(13) read? (13 = 1101)

  1. 13, 9, 1
  2. 13, 11, 7, 3
  3. 13, 12, 8
  4. 13, 14, 16
Clear the lowest bit each time: 1101 to 1100 (12) to 1000 (8) to 0. Blocks of 1, 4 and 8 cells.

You need range maximum with point updates. Which structure?

  1. Segment tree
  2. Difference array
  3. Prefix max array
  4. Fenwick tree of maxima
Max cannot be undone, so a range cannot be two prefixes subtracted. A segment tree combines any associative operation over O(log n) nodes.

In the iterative segment tree with leaves at t[n..2n-1], what does an odd l mean during a query?

  1. Take t[l + 1]
  2. l is a right child: take t[l] and move l one to the right
  3. l is a left child: go up without taking it
  4. The query is finished
An odd index is a right child. Its parent also covers the left sibling, which is outside the range, so t[l] must be taken on its own.

My Calendar I has accepted [5, 10) and [20, 30). Is [10, 20) accepted?

  1. Only if it is booked first
  2. Yes: half-open intervals that only touch do not overlap
  3. No, it touches 10
  4. No, it touches 20
Floor [5, 10) ends at 10, which is not after 10; ceiling [20, 30) starts at 20, which is not before 20.

Count of Smaller Numbers After Self with values from -109 to 109. What do you do before building the Fenwick tree?

  1. Sort the array
  2. Add 109 to every value
  3. Nothing, the tree handles it
  4. Compress the values to ranks 0..m-1
A tree indexed by value needs small non-negative indices. Ranks keep the order and need only m slots.

In C++, how do you get the floor of x (largest key <= x) in a std::map?

  1. prev(lower_bound(x))
  2. lower_bound(x)
  3. upper_bound(x)
  4. prev(upper_bound(x)), if it is not begin()
upper_bound gives the first key > x; the one before it is the last key <= x. lower_bound is the ceiling.
