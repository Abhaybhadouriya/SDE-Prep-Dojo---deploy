Choosing the structure

  • Values huge but few? Compress them first (sort the distinct values, use ranks). Every Fenwick and segment tree "over values" starts here.
  • Offline? If all queries are known in advance, sorting the queries is often simpler than any tree (sweep line, or process queries by right end).
  • Static range min / max? A sparse table gives O(1) queries after O(n log n) build. A sliding window of fixed size is even simpler: the monotonic deque.
