Common mistakes

  • Calling a nested two-pointer loop O(n²) (or an O(n²) loop "linear") without counting total pointer moves.
  • Forgetting the cost of string building, slicing, or contains on a list inside a loop.
  • Saying "O(1) space" for recursive code: the call stack is O(depth).
  • Mixing variables: writing O(n²) when it is O(n · m), or ignoring string length L in a trie or hash of strings.
  • Quoting average-case quicksort or hash map bounds as worst case without saying "average".
  • Counting the output as extra space without saying so, or forgetting it when the output is huge (all subsets).
  • Not reading constraints, then optimising an O(n²) solution that n ≤ 1,000 already allows (or coding O(n²) when n is 10⁵).
  • Writing (lo + hi) / 2 with 32-bit ints: overflows when both are near 2³¹. Use lo + (hi - lo) / 2.
