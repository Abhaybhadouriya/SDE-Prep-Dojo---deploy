Logarithms: halving until one is left

log₂ n is "how many times can I halve n before reaching 1?". log₂ 1,000 ≈ 10, log₂ 10⁶ ≈ 20, log₂ 10⁹ ≈ 30. In Big-O the base does not matter (log₂ n and log₁₀ n differ by a constant factor), so we just write log n. You meet it whenever each step throws away a constant fraction of the work: binary search, balanced binary search trees, heaps (height log n), and divide and conquer.

  1. Start with the whole array: lo = 0, hi = 16 (one past the end). 16 candidates. mid = 8 holds 51, smaller than 72, so the answer is to the right: lo = 9.
  2. 7 candidates left. mid = 12 holds 77, which is ≥ 72, so index 12 might be the answer but nothing to its right can be the first: hi = 12.
  3. 3 candidates left. mid = 10 holds 64 < 72: lo = 11.
  4. 1 candidate left. mid = 11 holds 72 ≥ 72: hi = 11.
  5. lo == hi, loop ends: index 11. Candidates went 16 → 7 → 3 → 1: each step keeps at most half, so about log₂ 16 = 4 steps. For n = 10⁹ that is about 30.

Here is the binary search template worth memorising: the half-open lower_bound. It returns the first index whose value is at least the target, works on duplicates, never loops forever, and is the base of "binary search on the answer" (replace a[mid] < target by "is mid not yet feasible?").

// lowerBound returns the first index i with a[i] >= target (len(a) if none). O(log n) time, O(1) space.
func lowerBound(a []int, target int) int {
	lo, hi := 0, len(a) // answer lives in [lo, hi]
	for lo < hi {       // each pass halves hi - lo
		mid := lo + (hi-lo)/2
		if a[mid] < target {
			lo = mid + 1 // answer is right of mid
		} else {
			hi = mid // mid itself may be the answer
		}
	}
	return lo
}
// First index i with a[i] >= target (n if none). O(log n) time, O(1) space.
int lowerBound(const vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size();          // answer lives in [lo, hi]
    while (lo < hi) {                        // each pass halves hi - lo
        int mid = lo + (hi - lo) / 2;        // never (lo + hi) / 2: it can overflow
        if (a[mid] < target) lo = mid + 1;   // answer is right of mid
        else hi = mid;                       // mid itself may be the answer
    }
    return lo;
}

def lower_bound(a, target):
    """First index i with a[i] >= target (len(a) if none). O(log n) time, O(1) space."""
    lo, hi = 0, len(a)            # answer lives in [lo, hi]
    while lo < hi:                # each pass halves hi - lo
        mid = (lo + hi) // 2
        if a[mid] < target:
            lo = mid + 1          # answer is right of mid
        else:
            hi = mid              # mid itself may be the answer
    return lo

Time O(log n) because the gap hi - lo at least halves each pass; space O(1). The same loop over a numeric range (for example "smallest speed that finishes in h hours" in Koko Eating Bananas) costs O(log(range) · cost of the check).
