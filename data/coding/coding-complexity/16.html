Quiz

The constraints say 1 ≤ n ≤ 2 × 10⁵. Which complexity should you aim for?

  1. O(n³)
  2. O(2ⁿ)
  3. O(n²)
  4. O(n log n) or better
n² would be 4 × 10¹⁰ steps. n log n is about 3.5 × 10⁶: comfortably fast.

What is the time complexity of for (i = 1; i < n; i *= 2) for (j = 0; j < n; j++) work();?

  1. O(log n)
  2. O(n log n)
  3. O(n²)
  4. O(n)
The outer loop runs log n times (doubling) and the inner loop n times each: n log n.

A dynamic array grows by adding 100 slots each time it is full. What is the total cost of n appends?

  1. O(n²)
  2. O(n log n)
  3. O(n)
  4. O(log n)
Copies are 100 + 200 + 300 + ... up to n, about n²/200: quadratic. Only multiplicative growth gives amortised O(1).

T(n) = 2T(n/2) + O(1). What is T(n)?

  1. O(n log n)
  2. O(n²)
  3. O(n)
  4. O(log n)
The tree has n leaves with constant work each; the leaves dominate. Example: recursive traversal of a binary tree.

Memoised DP over a grid of m rows and n columns where each cell looks at two neighbours. Time?

  1. O(m + n)
  2. O((m · n)²)
  3. O(2^(m+n))
  4. O(m · n)
States × work per state = mn × O(1).

Recursive DFS on a tree of n nodes that is shaped like a linked list. Extra space?

  1. O(n) for the call stack
  2. O(n²)
  3. O(1)
  4. O(log n)
Depth equals height, and a skewed tree has height n.
