Recursion trees and the master theorem

For recursive code, write a recurrence: the cost of a call in terms of the cost of its sub-calls. Then draw the recursion tree: total work = sum over levels of (number of calls at that level × work per call). Two trees cover most interviews.

Branching recursion with overlapping sub-problems blows up exponentially. The fix is to cache each answer: memoisation. The complexity of memoised recursion (and of any dynamic programming) is a simple product: number of distinct states × work per state. Climbing stairs has n states and O(1) work each, so O(n). A grid DP over m × n cells with O(1) transitions is O(mn).

// countWaysSlow: plain recursion, about 1.6^n calls.
func countWaysSlow(n int) int64 {
	if n <= 1 {
		return 1
	}
	return countWaysSlow(n-1) + countWaysSlow(n-2)
}

// countWays: memoised, each n computed once -> O(n) time, O(n) space.
func countWays(n int, memo map[int]int64) int64 {
	if n <= 1 {
		return 1
	}
	if v, ok := memo[n]; ok {
		return v
	}
	memo[n] = countWays(n-1, memo) + countWays(n-2, memo)
	return memo[n]
}

Divide and conquer recurrences have the form T(n) = a · T(n/b) + f(n): a sub-problems of size n/b plus f(n) work to split and combine. The master theorem compares f(n) with nlog_b a, the number of leaves of the tree:

RecurrenceWhere you see itResultWhy
T(n) = T(n/2) + O(1)binary searchO(log n)one path down, log n levels
T(n) = 2T(n/2) + O(n)merge sort, quicksort best caseO(n log n)equal work on each of log n levels
T(n) = 2T(n/2) + O(1)tree traversal, max of an array by halvesO(n)leaves dominate: n leaves
T(n) = T(n/2) + O(n)quickselect (average), halving with a scanO(n)n + n/2 + n/4 + ... < 2n: the root dominates
T(n) = T(n-1) + O(n)selection sort, quicksort worst caseO(n²)not a division: n + (n-1) + ... (master theorem does not apply)
T(n) = 2T(n-1) + O(1)naïve subsets, Tower of HanoiO(2ⁿ)the tree doubles each level

In words: if the leaves dominate, the answer is the number of leaves, nlog_b a; if every level does equal work, multiply that by log n; if the root dominates, the answer is f(n). "Two halves plus a linear merge gives n log n because every level does n work" is the sentence interviewers expect.

Backtracking is counted the same way: number of leaves × cost per leaf. Subsets: 2ⁿ leaves, O(n) to copy each, so O(n · 2ⁿ). Permutations: n! leaves, O(n) each, O(n · n!). N-Queens: at most n! partial placements, usually quoted as O(n!).
