Practice problems

Each of these is worth doing with the complexity analysis spoken out loud first.

  • Two Sum LC 1 Easy - O(n²) pairs vs O(n) with a hash map: the classic time-for-space trade.
  • Contains Duplicate LC 217 Easy - three answers: O(n²), O(n log n) sort with O(1) extra beyond the sort's own stack (O(log n); Python's Timsort O(n)), O(n) set.
  • Binary Search LC 704 Easy - the O(log n) loop; use the lower_bound template.
  • Sqrt(x) LC 69 Easy - binary search over a value range, watch the overflow in mid * mid.
  • Koko Eating Bananas LC 875 Medium - O(n log(max)) binary search on the answer.
  • Pow(x, n) LC 50 Medium - T(n) = T(n/2) + O(1): fast exponentiation in O(log n).
  • Climbing Stairs LC 70 Easy - exponential recursion to O(n) memo to O(1) space.
  • Fibonacci Number LC 509 Easy - draw the recursion tree, then count states.
  • Sort an Array LC 912 Medium - write merge sort and derive 2T(n/2) + n yourself.
  • Longest Substring Without Repeating Characters LC 3 Medium - sliding window: prove each pointer moves at most n times.
  • Daily Temperatures LC 739 Medium - monotonic stack: amortised O(n) by push/pop counting.
  • Kth Largest Element in an Array LC 215 Medium - compare O(n log n) sort, O(n log k) heap, O(n) average quickselect.
  • Subsets LC 78 Medium - O(n · 2ⁿ) output-sensitive backtracking.
