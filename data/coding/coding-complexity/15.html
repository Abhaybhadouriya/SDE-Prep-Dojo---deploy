Revision card

  • Cue: The constraints line (n ≤ ...) and "can you do better?".
  • Insight: Roughly 10^8 simple steps a second: n picks the complexity class before you pick the algorithm.
  • State: Count total work: sequential adds, nested multiplies, a forward-only pointer is O(n) overall.
  • Trap: Ignoring the call stack and hidden copies in space; library calls inside loops.
  • Cost: 10^5 needs O(n log n); 5,000 allows O(n^2); 20 allows 2^n.

More to remember

  • Read n first. About 10⁸ simple steps per second: 10⁵ needs O(n log n), 5,000 allows O(n²), 20 allows 2ⁿ.
  • Sequential steps add, nested steps multiply, different inputs keep different letters.
  • Count total pointer moves: a forward-only inner pointer is O(n) overall.
  • Amortised = total over a sequence / count, worst case. Geometric growth makes append O(1).
  • Recursion: draw the tree. Memoised recursion and DP = states × work per state.
  • Master theorem shortcuts: T(n/2)+1 → log n; 2T(n/2)+n → n log n; 2T(n/2)+1 → n; T(n/2)+n → n.
  • Space includes the call stack (O(depth)) and hidden copies; usually excludes the output.
  • State it in four beats: variables, dominant step, time and space, justification.
