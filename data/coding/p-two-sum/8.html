Common mistakes

Inserting before looking up. With [3, 2, 4], target 6, storing 3 first and then looking up 3 returns [0, 0]: the same position twice.

Building the whole map first, then scanning. It works only if you also check seen[need] != i. The one-pass version avoids the extra condition.

Sorting the original array. The answer is indices; sorting in place destroys them. Sort (value, index) pairs if you use two pointers.

Integer overflow in target - x. In C++/Java, -10^9 - 10^9 overflows int32 and can produce a false hit. Use long / long long.
