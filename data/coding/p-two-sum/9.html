Revision card

  • Cue: unsorted array, pair with sum k, return indices → complement lookup in a map.
  • Insight: the partner of x must be exactly target - x; ask the map before storing x.
  • State: seen = {value: index} of elements left of i.
  • Trap: insert after lookup (no self-pair); 64-bit target - x in C++/Java.
  • Cost: O(n) time, O(n) space; sort + two pointers O(n log n); brute O(n²).
seen = {}
for i, x in enumerate(a):
    want = complement(x)          # target - x, or x - k, ...
    if want in seen: return seen[want], i
    seen[x] = i
