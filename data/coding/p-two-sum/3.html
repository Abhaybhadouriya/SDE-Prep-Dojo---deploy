Recognise the pattern

When you see "find a pair with sum (or difference) k" in an unsorted array, and you must return indices, think complement lookup in a hash map. If the array is sorted (or you only need the values), two pointers is the alternative.

Unsorted, need indiceshash map, one passsorting would lose the original indices
