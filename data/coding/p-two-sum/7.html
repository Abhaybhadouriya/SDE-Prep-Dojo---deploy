Edge cases

InputExpectedWhy
[6, 6], 12[0, 1]Equal values: works because the first 6 is stored before the second is read.
[2, 5, 5, 11], 10[1, 2]Duplicate that IS the answer.
[8, 1, 5, 4, 6], 10[3, 4]5 + 5 would be 10 but there is only one 5: look up before insert.
[-4, 9, 1, 13], 9[0, 3]Negative numbers: no special handling.
[10^9, -10^9, 3], 0[0, 1]Extreme values. With target = -10^9 and x = 10^9, target - x = -2 × 10^9 overflows int32: compute it in 64 bits.
n = 2[0, 1]Smallest input: the pair is the whole array.
