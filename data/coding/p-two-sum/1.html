The problem (in our words)

A shop keeps a list nums of item prices and a gift card worth target. Find the two different positions i and j whose prices add up to exactly target, and return them as [i, j].

  • Input: an integer array nums and an integer target.
  • Output: an array of the two indices; any order is accepted. Signature: int[] twoSum(int[] nums, int target).
  • Every input has exactly one valid answer.
  • You may not use the same position twice (two equal prices at different positions are fine).

Constraints

  • 2 <= nums.length <= 10^4
  • -10^9 <= nums[i] <= 10^9
  • -10^9 <= target <= 10^9
  • Only one valid answer exists.

Follow-up asked by the original: can you do better than O(n²) time?

Practice it: LeetCode 1 - Two Sum · GfG - 2 Sum, find a pair with given sum · takeuforward

Constraints tell you: n ≤ 10^4 means even O(n²) (10^8 simple steps) may pass, which is why the interviewer asks for better. Values up to 10^9 in size mean target - x can reach 2 × 10^9: that overflows a 32-bit int in C++/Java.
