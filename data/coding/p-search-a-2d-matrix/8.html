Common mistakes

Dividing by m instead of n. The row is k / (number of columns). With a square test matrix the bug is invisible; a 3x4 or a single column exposes it.

hi = m * n with a <= loop. Mixing half-open and closed intervals reads matrix[m][0], out of range. Pick one style.

Using the staircase for LC 74 and calling it "binary search". It is O(m + n), not the required O(log(m·n)).

Applying the flat trick to LC 240. If rows can overlap (each column is sorted but row 1 can start below row 0's end), the flattened order is not sorted and the search gives wrong answers.
