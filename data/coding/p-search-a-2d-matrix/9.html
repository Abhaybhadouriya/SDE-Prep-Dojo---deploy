  • Cue: sorted rows, each row starts above the previous row's end.
  • Insight: row-major order is one sorted array of m·n values.
  • State: lo = 0, hi = m·n - 1; value = matrix[mid / n][mid % n].
  • Trap: divide by n (columns); the flat trick fails for LC 240 (use the staircase).
  • Cost: O(log(m·n)) time, O(1) space.
lo, hi = 0, m * n - 1
while lo <= hi:
    mid = (lo + hi) // 2
    v = matrix[mid // n][mid % n]
    if v == target: return True
    lo, hi = (mid + 1, hi) if v < target else (lo, mid - 1)
return False

Flat index k in an m x n matrix maps to which cell?

  1. (k / m, k % m)
  2. (k / n, k % n)
  3. (k % n, k / n)
Each row holds n values, so the row is k / n.

Which property makes the flat binary search valid?

  1. Columns are sorted
  2. The matrix is square
  3. Each row starts above the previous row's last value
Without it the row-major order is not sorted (that is LC 240).

What does the staircase search from the top-right do when the value is smaller than the target?

  1. Moves down: the rest of the row is smaller
  2. Moves left
  3. Stops
Everything to the left in that row is even smaller, so the row is done.
