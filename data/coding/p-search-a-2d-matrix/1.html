The problem (in our words)

A shelf of m rows with n integer labels each is laid out so that labels grow left to right inside a row (equal neighbours allowed), and every row starts above the largest label of the row before it. Read row by row, the shelf is one long sorted list. Given a target label, say whether it is on the shelf (true) or not (false), in O(log(m·n)) time.

Signature: boolean searchMatrix(int[][] matrix, int target).

Constraints

  • m == matrix.length, n == matrix[i].length
  • 1 <= m, n <= 100
  • -10^4 <= matrix[i][j], target <= 10^4

Practice it: LeetCode 74 - Search a 2D Matrix · GfG - Search in Sorted Matrix · TUF - Search in a sorted 2D matrix

Constraints tell you: m·n ≤ 104, so even a full scan passes; the required O(log(m·n)) is what is tested. m·n - 1 ≤ 9,999 fits easily in an int, so lo + hi cannot overflow here (but write lo + (hi - lo) / 2 anyway; it is the habit interviewers look for). m and n are at least 1, so no empty-matrix check is needed.
