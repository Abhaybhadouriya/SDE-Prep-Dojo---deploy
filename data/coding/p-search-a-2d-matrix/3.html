Recognise the pattern

When you see a matrix where rows are sorted and each row starts after the previous ends, think "one sorted array": binary search on k in [0, m·n) with (k / n, k % n).

When you see rows sorted and columns sorted but rows may overlap (LC 240), think staircase from the top-right corner, O(m + n).

Taxonomy: Binary search → matrix search (variant: flat index or staircase). Pattern lesson: Binary search.
