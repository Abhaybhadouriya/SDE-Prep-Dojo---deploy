The story

Explain like I'm 5

A phone book is printed in columns on many pages, but the names keep going in order from page to page. To find a name you don't first pick a page and then search it; you open the book roughly in the middle, look at one name, and throw away half of the whole book. The page breaks don't matter, only the overall order does.

From your world

A 2D array in C is already one flat block in row-major order: a[r][c] is base[r * n + c]. This problem just says the values in that block are sorted, so bsearch() over m * n elements works directly. The divide and modulo are the same address arithmetic the compiler does for you.
