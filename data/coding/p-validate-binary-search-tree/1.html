The problem (in our words)

You are given the root of a binary tree. Decide whether it is a valid binary search tree and return true or false. A tree is a valid BST when, for every node:

  • every key in its left subtree is strictly smaller than the node's key,
  • every key in its right subtree is strictly larger than the node's key,
  • and both subtrees are valid BSTs themselves.

Signature: boolean isValidBST(TreeNode root) (the tree is given as a level-order list with null for missing children).

  • The number of nodes is in the range [1, 10^4]
  • -2^31 <= Node.val <= 2^31 - 1

Practice it: LeetCode 98 · GfG Check for BST · TUF article

Constraints tell you: 10^4 nodes means O(n) or O(n log n) is fine; the real content is correctness. Values cover the whole 32-bit range, so INT_MIN/INT_MAX cannot serve as "no bound" sentinels - use 64-bit bounds or nullable bounds. A skewed tree is 10^4 deep: recursion is usually fine (raise the limit in Python), the iterative in-order is the fully safe option.
