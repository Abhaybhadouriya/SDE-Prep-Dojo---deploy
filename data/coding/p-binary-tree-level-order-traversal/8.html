Common mistakes

Using q.size() in the loop condition. for (int i = 0; i < q.size(); i++) re-reads the size while children are being pushed, so the row swallows part of the next level. Read the size once into a variable.

Pushing null children. Either skip them when pushing (as here) or skip them when popping; mixing the two either crashes or adds empty rows at the end.

Using a stack or list.pop(). In Python, list.pop(0) is O(n) per pop (use deque.popleft()), and list.pop() pops from the wrong end, turning BFS into DFS.

Go: appending to the slice you are ranging over by index. for i := 0; i < len(q); i++ keeps growing. Fix the width first and slice q = q[width:] after the level, as in the Go tab.
