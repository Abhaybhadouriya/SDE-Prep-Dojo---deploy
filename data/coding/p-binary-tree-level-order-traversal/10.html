Technique: BFS that snapshots the queue length to process one depth per round, then does something per level (collect, reverse, average, take the last).

Closest match: GfG Level Order Traversal

  • Same: visit the tree level by level, left to right.
  • Different: GfG wants one flat list, not a list per level.
  • So: plain BFS is enough; the frozen width is only needed when the output is grouped.

How to recognise it:

  • The output is grouped by depth, or a question asks about "each level" or "each row".
  • The answer is about the first, last, sum, max or count of something per level.

Practice order:

  1. Warm-up: LC 104 with BFS (count rounds).
  2. This problem: BFS with the frozen width, then the DFS-with-depth variant.
  3. Then LC 103, 199 and 637 (one-line changes), then LC 662 (position indices).
