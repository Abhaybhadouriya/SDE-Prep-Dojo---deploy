The story

Explain like I'm 5

A family photo is taken generation by generation. The photographer calls the grandparents first and they stand in a row. Then she says "everyone the people in this row brought along, form the next row". She counts the current row before anyone new arrives, so the newcomers never sneak into the wrong row. Read the rows top to bottom, each left to right, and you have the answer.

From your world

It is a FIFO run queue processed in batches: snapshot len, drain exactly that many entries, and anything enqueued during the drain waits for the next batch. The same "snapshot the count, then drain" trick is how NAPI polls a budget of packets without starving new arrivals. In C you would use a ring buffer of node pointers sized to the widest level.
