Recognise the pattern

When you see "level by level", "per depth", "row of the tree", "left to right at each level", think BFS with a queue and a frozen level size.

When you see "nearest", "minimum depth" or "first level where..." on a tree or an unweighted graph, think the same loop: BFS reaches nodes in order of depth.

A plain BFS already visits nodes in level order; what it does not give you is the boundaries between levels. There are three ways to recover them: store a depth with each queued node, push a sentinel marker after each level, or (simplest) read queue.size() before draining a level.

Taxonomy: Trees → BFS by levels → level order. Pattern lesson: Trees; the same loop on grids and graphs in Graph BFS.
