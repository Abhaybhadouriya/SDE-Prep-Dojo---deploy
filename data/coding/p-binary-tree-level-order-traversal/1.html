The problem (in our words)

A company's reporting chart is stored as a binary tree: every manager has at most two direct reports, a left one and a right one. Each node holds an employee badge number val. You are given the root of the tree.

Return the badge numbers level by level: a list of lists where list d holds the values of all nodes at depth d (the root is depth 0), ordered from left to right. An empty tree gives an empty list.

Signature: List<List<Integer>> levelOrder(TreeNode root). The tree is given in LeetCode's level-order array form, with null for a missing child.

Constraints

  • The number of nodes is in the range [0, 2000].
  • -1000 <= Node.val <= 1000

Practice it: LeetCode 102 - Binary Tree Level Order Traversal · GfG - Level Order Traversal · TUF - Level order traversal

Constraints tell you: 2000 nodes means anything linear is instant; the interviewer is checking that you can group by level cleanly, handle the empty tree, and explain the queue's memory. Depth can reach 2000 on a chain, which matters only for the recursive (DFS) variant.
