  • Cue: "does the walk ever repeat?" with O(1) memory.
  • Insight: in the loop the gap shrinks by exactly one per round, so fast cannot jump over slow.
  • State: slow += 1, fast += 2, compare after moving.
  • Trap: guard fast and fast.next; compare nodes, not values.
  • Cost: O(n) time (at most μ + λ rounds), O(1) space.
slow = fast = head
while fast and fast.next:
    slow, fast = slow.next, fast.next.next
    if slow is fast: return True
return False

Inside the loop, how does the distance from fast to slow change each round?

  1. It grows by one
  2. It halves
  3. It shrinks by exactly one
Relative speed is 2 - 1 = 1, so fast closes one node per round.

Why is the loop condition fast and fast.next?

  1. fast moves two steps, so both must exist
  2. To detect the loop entry
  3. To make slow stop at the middle
fast.next.next needs fast.next to be non-null.

Where do slow and fast meet?

  1. Always at the loop entry
  2. Somewhere inside the loop
  3. At the head
Finding the entry needs the second phase from LC 142.
