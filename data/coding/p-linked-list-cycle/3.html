Recognise the pattern

When you see "does following next / f(x) ever repeat?" with O(1) memory, think Floyd: a slow pointer at speed 1 and a fast pointer at speed 2.

When you see any function from a finite set to itself (an array of indices, a digit-square map), think "it is a linked list in disguise", and the same check applies.

A list with a loop has the shape of the letter rho: μ nodes before the loop and λ nodes in it. Walking it never ends, so you need a way to notice repetition without remembering everything you saw.

Taxonomy: Linked list → fast/slow pointers (variant: cycle). Pattern lesson: Linked lists.
