Common mistakes

Checking slow == fast before moving. They start equal, so a check at the top of the loop returns true at once. Move first, then compare (or start fast at head.next and adjust).

Guarding only fast.next. while fast.next crashes on an empty list or when fast became null. Use while fast and fast.next.

Comparing values. slow.val == fast.val returns true for [6,6] with no loop.

Using speed 3 "to be faster". With a relative speed of 2 the pointers can skip each other forever on an even-length loop. Speeds 1 and 2 are the safe pair.
