Approaches: brute → better → optimal

Hint 1

Fix the sell day j. Which buy day is best for it?

Hint 2

The best buy day for j is the cheapest day in rates[0..j-1]. Can you keep that value while you walk?

1. Brute force - try every pair

Idea: for every buy day i and every later sell day j, compute rates[j] - rates[i] and keep the largest (start from 0).

best = 0
for i in range(n):
    for j in range(i + 1, n):
        best = max(best, rates[j] - rates[i])
O(n^2)time
O(1)space

What is wasted: for each j we rescan the whole prefix to find its minimum, although the prefix only grew by one element since j - 1. -> rung 2.

2. Better - prefix minimum array

Idea: precompute low[j] = min(rates[0..j]) in one pass, then answer max(rates[j] - low[j-1]) in a second pass.

O(n)time
O(n)space

What is wasted: we only ever read low[j-1] right before low[j]; the array can collapse into one variable. -> rung 3.

3. Optimal - one pass with the running minimum

cheapest, best = rates[0], 0
for p in rates[1:]:
    best = max(best, p - cheapest)   # sell today
    cheapest = min(cheapest, p)      # today can be a future buy day
  1. Every sale is tested. Each day j is tried once as the sell day.
  2. Its best partner is known. cheapest holds the minimum of all days before j, which is the best buy for that sale.
  3. No trade is the floor. best starts at 0, so falling prices return 0, never a negative number.
O(n)time
O(1)space
1pass

Why it works: the optimal deal (i*, j*) has rates[i*] = min(rates[0..j*-1]); otherwise a cheaper earlier day would give a bigger profit. When the loop reaches j*, cheapest equals that minimum, so the loop computes the optimal profit at that moment.

Proof (optional) - the Kadane view

Let d[k] = rates[k] - rates[k-1]. For i < j, rates[j] - rates[i] = d[i+1] + ... + d[j], a contiguous sum. So the answer is the maximum subarray sum of d, floored at 0 (the empty subarray = no trade). Kadane's cur = max(0, cur + d[k]) is exactly "profit if I bought at the running minimum": cur resets to 0 at the same moment a new minimum appears. This is the view the top-voted community post uses, and it matters when an interviewer hands you the change array instead of prices.
