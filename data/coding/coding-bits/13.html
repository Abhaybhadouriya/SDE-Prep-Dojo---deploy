Resources

  • Bit Twiddling Hacks (Sean Anderson, Stanford) doc - the classic list: popcount, reverse, next power of two, with explanations.
  • Bit manipulation (cp-algorithms) doc - clear notes on lowest set bit, submask enumeration and built-ins.
  • A summary: how to use bit manipulation (LeetCode discuss) blog - the most-read community post on these idioms, with many worked problems.
  • Single Number II: detailed explanation and generalisation (LeetCode discuss) blog - why ones/twos works, and how to extend it to k copies.
  • linux/bitops.h repo - the kernel's own versions: hweight, ffs/fls, for_each_set_bit, rotate.
  • Hacker's Delight (Henry S. Warren) book - the book behind most bit tricks, if you want the proofs.
  • Python int.bit_count / bit_length doc - built-ins that save you a loop in Python rounds.
