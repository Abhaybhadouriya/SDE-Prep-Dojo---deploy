Arithmetic with only bit operators

Sum of Two Integers (no + or -) is a ripple-carry adder written in software. XOR adds each column and ignores carries. AND finds the columns that produce a carry, and the shift moves each carry one column left, where it belongs. Feed (sum, carry) back in until the carry is zero.

  1. a = 5 (0101), b = 3 (0011). XOR adds each column and forgets the carry. AND finds the columns where both are 1: those make a carry, which belongs one column to the left.
  2. Now a = 6 (0110), b = 2 (0010): "6 plus a carry of 2 still to add". The sum is the same (8), it is just written differently.
  3. a = 4, b = 4. The carry keeps moving left, one column per round, like a ripple-carry adder.
  4. a = 0, b = 8. One more round and the carry lands in an empty column.
  5. b = 0: nothing left to add, so a = 8 = 5 + 3. At most 32 rounds for 32-bit ints, because the carry moves at least one column left each round.

Negative numbers need no special case, because two's complement addition is the same bit operation. Only the language matters. In C++ do the loop on unsigned. In Python, mask to 32 bits on every round and turn the result back into a signed value at the end. Otherwise a negative carry grows forever.

Divide Two Integers (no *, /, %) is long division in base 2: find the largest divisor << k that still fits, subtract it, and add 1 << k to the quotient. Work with negative values or 64-bit values, because -INT_MIN does not fit in an int, and return INT_MAX for INT_MIN / -1.

Bitwise AND of a range [left, right]: any bit that changes between left and right is 0 in at least one number of the range. So the answer is the common binary prefix: shift both right until they are equal, then shift back.
