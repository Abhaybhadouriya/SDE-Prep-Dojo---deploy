  • Cue: "appears k times except", O(1) space, no + or *, set bits, n ≤ 20 subsets.
  • Insight: XOR cancels pairs; n & (n-1) drops the lowest 1; x & -x keeps it.
  • State: one accumulator, or per-column counts mod k, or a mask as the set.
  • Trap: == binds tighter than &; Java >> vs >>>; C++ UB on signed shifts; Python ~x.
  • Cost: O(n) or O(32 n) time, O(1) space; subsets O(n 2^n).

for x in nums: acc ^= x             # pairs cancel
