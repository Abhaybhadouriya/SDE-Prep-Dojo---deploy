What does x & (x - 1) do?

  1. Keeps only the lowest set bit
  2. Flips every bit
  3. Clears the lowest set bit
  4. Sets the lowest zero bit
x - 1 turns the lowest 1 into 0 and the zeros below it into 1s; ANDing with x keeps the high part and drops that one bit.

Which expression isolates the lowest set bit of x?

  1. x ^ (x >> 1)
  2. x | (x - 1)
  3. ~x & (x + 1)
  4. x & -x
-x is ~x + 1, which equals x at the lowest set bit and is the opposite above it. (The last option gives the lowest ZERO bit.)

Every value appears twice except one. Why does XOR of all values work for any order?

  1. XOR sorts the bits
  2. XOR is the same as addition mod 2^32
  3. XOR is commutative and associative, and x ^ x = 0
  4. It only works if equal values are next to each other
You can regroup the XORs so equal values meet; each pair gives 0, and 0 ^ single = single.

In Single Number II (others appear three times), what do you compute per bit column?

  1. The count of ones mod 3
  2. The column's XOR
  3. The count of ones mod 2
  4. The maximum bit
Triples add 0 or 3 to each column, so count mod 3 is exactly the single number's bit.

Why can while (n != 0) { ...; n >>= 1; } loop forever in Java on a negative int?

  1. It cannot; Java shifts are always logical
  2. >> is an arithmetic shift that keeps copying the sign bit
  3. Java masks the shift count
  4. Java ints are 64-bit
Use >>> for a logical shift. -1 >> 1 is still -1.

How many subsets does a loop for mask in 0 .. 2^n - 1 visit for n = 4?

  1. 4
  2. 16
  3. 8
  4. 15
2^4 = 16, including the empty set (mask 0).

Adding 5 + 3 with sum = a ^ b, carry = (a & b) << 1: when does the loop stop?

  1. After exactly one round
  2. After 32 rounds always
  3. When the sum is 0
  4. When the carry is 0
When there is no carry left to add, a holds the full sum.
