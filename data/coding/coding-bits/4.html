Bitmasks as sets

Give each item an index 0..n-1. A number mask stands for the set of items whose bit is 1. With n items, the 2n numbers from 0 to 2n - 1 are exactly all the subsets, so a plain for loop enumerates the power set. There is no recursion and no list copying.

for mask in range(1 << n):              # every subset
    subset = [items[i] for i in range(n) if mask >> i & 1]

s = m                                    # every non-empty submask of m
while s:
    visit(s)
    s = (s - 1) & m                      # next smaller number that only uses m's bits

Where masks show up in interviews:

  • Subsets (n ≤ 10 to 20): the loop above, O(n · 2n).
  • Letters as a set: 26 bits fit in an int. Two words share no letter when m1 & m2 == 0 (Maximum Product of Word Lengths). A palindrome permutation needs at most one bit set after XOR-ing 1 << (c - 'a') for every character.
  • Visited state in search or DP: dp[mask][last] for shortest path visiting all nodes or assigning n workers to n jobs, when n ≤ about 16. The mask is the "who is already used" set.
  • Prefix XOR of parities: "count substrings where every vowel appears an even number of times" stores a 5-bit parity mask in a hash map, exactly like prefix sums.

Size check. 220 is about 106 (fine), 225 is about 3.3 · 107 (fine for a simple loop), and 230 is about 109 (too slow). If n is 40, think meet in the middle (2 · 220), not one mask.
