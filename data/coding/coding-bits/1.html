The six operators and two's complement

Integers are stored as bits. Bit 0 is the right-most (least significant) bit. A 32-bit int stores negative numbers in two's complement: -x is ~x + 1 (flip every bit, then add one). So -1 is all ones, and the top bit (bit 31) is the sign.

Language traps, before any problem. C/C++: shifting by 32 or more is undefined, left-shifting a negative int is undefined (before C++20), and -x on INT_MIN overflows: do bit tricks on unsigned / uint32_t. Java: no unsigned types; >> copies the sign bit and >>> shifts in zeros; the shift count is taken mod 32, so 1 << 32 == 1. Go: int is 64-bit; use uint32 when the problem says 32 bits; &^ is AND NOT. Python: integers never overflow and ~x == -x - 1, so mask with 0xFFFFFFFF whenever the problem has a fixed width.
