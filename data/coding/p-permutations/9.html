How many leaves does the recursion tree have for n distinct numbers?

  1. 2n
  2. n!
  3. nn
  4. n·n!
n choices for slot 1, n - 1 for slot 2, ...: n! leaves, one per permutation.

What changes if you replace "loop from 0, skip used" with "loop from start, recurse with i + 1"?

  1. Nothing
  2. Duplicates appear
  3. Only one ordering (the input order) reaches depth n
  4. Infinite recursion
A start index forbids earlier elements from coming later, so only increasing-index orders survive, and the only one of length n is the input order. Record at every node and you get subsets (LC 78); stop at size k and you get combinations (LC 77).

  1. The slots already fixed on this path
  2. The unused elements
  3. The sorted input
  4. The last recorded permutation
The prefix is the current path; the suffix nums[k..] holds exactly the unused elements.
