The input may contain duplicates. Return each distinct permutation once.

Sort first. In the loop, skip i when nums[i] == nums[i-1] and used[i-1] is false: equal values must be used in index order, so a copy may only be picked after the previous copy is already on the path. This is LeetCode 47.

How to answer

Walk [1,1,2]: without the rule, swapping the two 1s doubles every answer.

Likely follow-ups
  • Why "not used[i-1]" and not "used[i-1]"? (Both work; the first prunes earlier, at the sibling level.)
Return only the k-th permutation in sorted order, n up to 9.

Do not enumerate. Each choice of the first element covers (n-1)! permutations, so the first element is index (k-1) / (n-1)! in the remaining sorted list; continue with the remainder. O(n²) with a list, O(n log n) with a Fenwick tree. LeetCode 60.

How to answer

Show the factorial number system on n = 4, k = 9.

Likely follow-ups
  • The reverse: rank of a given permutation (count smaller unused elements per slot).
Generate permutations one at a time without recursion.

Sort, then call next-permutation repeatedly: find the rightmost i with a[i] < a[i+1], swap a[i] with the rightmost larger element, reverse the suffix. Amortised O(1) per step, O(1) extra space, and it handles duplicates for free. Heap's algorithm is another option (one swap per step).

How to answer

Turn it into an iterator: the state is the array itself.

Likely follow-ups
  • Previous permutation? (Mirror every comparison.)
n is 12. What happens, and how do you change the API?

12! ≈ 4.8·108 rows of 12 ints is about 23 GB: it cannot be returned. Stream them through a callback or iterator (O(n) memory), or ask what the caller really needs (count = n!, a random one = Fisher-Yates shuffle, the k-th = factorial number system).

How to answer

Do the size arithmetic out loud, then separate generation from consumption.

Only orders where no two adjacent numbers differ by more than d.

Same backtracking, plus a check before choosing: abs(nums[i] - cur[-1]) <= d. Invalid prefixes are cut at once instead of being filtered at the leaves; this is the main reason to prefer the slot-filling template over rung 2.
