Common mistakes

Appending cur instead of a copy. In Java, Python and Go every stored row then aliases one list, which is empty at the end. Copy at the leaf.

Using a start index as in Subsets. for i in range(start, n) with start = i + 1 produces only the one sorted order of each set: combinations, not permutations.

Checking "is x in cur" instead of a mask. It works for distinct values but costs O(n) per check and breaks as soon as values repeat (LC 47). Track indexes, not values.

Forgetting to unmark used[i]. The first branch then blocks the element for all siblings and you get only one permutation.

Swap variant: not swapping back. Without the second swap the array drifts and some orders repeat while others are missing.
