The story

Explain like I'm 5

Three friends, Asha, Ben and Chen, want a photo in a row. Who stands first? Any of the three. Second? One of the two who are left. Last? Whoever remains. So there are 3 × 2 × 1 = 6 different photos. To list them all, pick a first person, then list every way to arrange the rest, then put that person back and try the next one first.

That "put them back" step is backtracking: you undo the last choice so the next branch starts from a clean state.

From your world

It is like testing every order in which n interrupts can fire, or every boot order of n modules: a depth-first walk with an explicit "already used" bitmask, exactly like a visited bitmap in a graph walk. The bitmask is cleared on the way back up, so sibling branches see the same state.
