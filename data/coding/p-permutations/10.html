Closest match: GfG Permutations of a given string GfG

  • Same: list every ordering of the input.
  • Different: characters may repeat, and the output must be distinct and sorted.
  • So: sort the characters and add the LC 47 skip rule (skip a[i] if it equals a[i-1] and a[i-1] is not used); sorted input then gives sorted output.

How to recognise it:

  • "All arrangements / orders / sequences" using each item exactly once, n ≤ ~10.
  • Order matters -> used[] (or swap); order does not -> start index.

Practice order:

  1. 78 Subsets and this problem, back to back, to feel the start-index vs used[] difference.
  2. Then 47 Permutations II (one skip rule) and 31 Next Permutation.
  3. Then 60 Permutation Sequence and 51 N-Queens.
