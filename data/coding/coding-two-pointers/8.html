Same direction 3: merge two sorted arrays (from the back)

The problem, in our words. Two sorted (non-decreasing) arrays are given: a of length m + n whose first m slots hold real values and whose last n slots are 0 placeholders, and b of length n. Merge b into a in place, so that a holds all m + n values in sorted order. Return nothing. 0 <= m, n <= 200; 1 <= m + n <= 200; -109 <= values <= 109. Follow-up: O(m + n) time. Example: a = [2, 5, 8, 0, 0], m = 3, b = [1, 6], n = 2 -> a = [1, 2, 5, 6, 8]. Example: a = [0], m = 0, b = [4] -> [4]. Practice it: LeetCode 88 - Merge Sorted Array, our write-up Merge Sorted Array.

Why the loop runs while j >= 0 only: once b is empty, the values left in a[0..i] are already sorted and already in their final slots. If a runs out first, the i >= 0 test makes every remaining step copy from b. The code is in the same-direction tabs above (merge_into / mergeInto).
