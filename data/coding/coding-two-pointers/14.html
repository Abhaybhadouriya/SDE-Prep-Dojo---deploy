Quiz

Sorted array, a[lo] + a[hi] is less than the target. Which move is safe?

  1. Both
  2. lo++
  3. hi--
a[hi] is the biggest partner a[lo] can still have; if even that is too small, a[lo] is in no answer.

Container with most water: h[lo] = 3, h[hi] = 8. Which pointer moves?

  1. hi, the taller one
  2. Whichever is closer to the middle
  3. lo, the shorter one
The level is capped by the shorter wall. Moving the taller one only reduces the width.

What is the time complexity of 3Sum with sort + two pointers?

  1. O(n)
  2. O(n log n)
  3. O(n2)
n choices of the first element, each followed by an O(n) scan.

In 3Sum, why do we skip i when a[i] == a[i-1]?

  1. Equal values cannot be in a triplet
  2. To avoid an index error
  3. It would produce triplets that were already found
The same first value with the same suffix gives the same triplets. Equal values can still appear inside one triplet, as in [-2, 1, 1].

Dutch flag: after swapping a[mid] with a[hi], what do you do with mid?

  1. mid++
  2. Leave it: the new a[mid] is unchecked
  3. mid = lo
The value that came from hi has never been classified, so it must be looked at in the next step.

Remove duplicates from a sorted array in place. When does the write pointer move?

  1. Only when a[r] equals a[w-1]
  2. Only when a[r] differs from the last kept value
  3. On every step
The writer advances only when the reader finds a value worth keeping.

Why merge two sorted arrays into a from the back?

  1. The free space is at the back, so no unread value is overwritten
  2. It is more cache friendly
  3. Sorting requires it
Writing at w = m + n - 1 downwards only touches placeholders or values already copied.
