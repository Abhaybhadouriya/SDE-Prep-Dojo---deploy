3Sum: fix one, two-pointer the rest, skip duplicates

The problem, in our words. Given an integer array a, return every distinct triplet of values [a[i], a[j], a[k]] with i, j, k pairwise different and a[i] + a[j] + a[k] = 0. The output must not contain the same triplet twice (as a multiset of values); the order of triplets and of values inside a triplet does not matter.

  • 3 <= a.length <= 3000; -105 <= a[i] <= 105.
  • Example: [-2, 0, 1, 1, 2, -2, 0] -> [[-2, 0, 2], [-2, 1, 1]]. Example: [0, 0, 0, 0] -> [[0, 0, 0]]. Example: [1, 2, -4] -> [].

Practice it: LeetCode 15 - 3Sum · takeuforward · NeetCode · our write-up: 3Sum.

Plan: sort (O(n log n)). For each index i, the problem "find pairs to the right of i that sum to -a[i]" is exactly the sorted pair sum above: O(n) per i, O(n2) in total. n <= 3000 means about 9 x 106 steps: fine. The constraints are telling you O(n2) is the target, so do not hunt for O(n log n).

Dedup, the part people get wrong. Sorting puts equal values next to each other, so two rules remove every duplicate without a set:

  1. Skip a repeated first value. If a[i] == a[i-1], every triplet starting with this value was already produced by i-1. continue.
  2. After a hit, skip repeated middle values. Move lo past every copy of the value just used (hi then follows automatically, because the sum must change).
  3. Stop early. If a[i] > 0, the three smallest remaining values are positive: break.
  1. Sort first: [-2, -2, 0, 0, 1, 1, 2]. Equal values are now neighbours, so skipping duplicates is a simple 'same as the previous one?' check.
  2. i = 0, lo = 1, hi = 6: the sum is -2, below 0. Only a bigger middle value can help, so lo moves right.
  3. i = 0, lo = 2, hi = 6: -2 + 0 + 2 = 0. Record [-2, 0, 2] and move both pointers inwards.
  4. lo landed on 0, the value we just used, so it would only rebuild the same triplet. Skip copies: lo moves to 4.
  5. i = 0, lo = 4, hi = 5: -2 + 1 + 1 = 0. Record [-2, 1, 1] and move both pointers inwards.
  6. i = 1: a[i] = -2 is the same value as a[0]. Every triplet it could start was already found, so skip it.
  7. i = 2 (value 0): the pair search starts at lo = 3, hi = 6. Every sum is positive, so hi walks left 3 times until it meets lo. Nothing found.
  8. i = 3: a[i] = 0 is the same value as a[2]. Every triplet it could start was already found, so skip it.
  9. i = 4: a[i] = 1 is positive. Everything to its right is at least as big, so no triplet can sum to 0. Stop early.
func threeSum(nums []int) [][]int {
	sort.Ints(nums)
	out := [][]int{}
	n := len(nums)
	for i := 0; i+2 < n; i++ {
		if nums[i] > 0 {
			break // smallest is positive: done
		}
		if i > 0 && nums[i] == nums[i-1] {
			continue // same first value: same triplets
		}
		lo, hi := i+1, n-1
		for lo < hi {
			s := nums[i] + nums[lo] + nums[hi]
			if s < 0 {
				lo++
			} else if s > 0 {
				hi--
			} else {
				out = append(out, []int{nums[i], nums[lo], nums[hi]})
				lo, hi = lo+1, hi-1
				for lo < hi && nums[lo] == nums[lo-1] {
					lo++ // skip the value we just used
				}
			}
		}
	}
	return out
}
vector<vector<int>> threeSum(vector<int> nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> out;
    int n = nums.size();
    for (int i = 0; i + 2 < n; i++) {
        if (nums[i] > 0) break;                          // smallest is positive: done
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // same first value: same triplets
        int lo = i + 1, hi = n - 1;
        while (lo < hi) {
            int s = nums[i] + nums[lo] + nums[hi];
            if (s < 0) lo++;
            else if (s > 0) hi--;
            else {
                out.push_back({nums[i], nums[lo], nums[hi]});
                lo++; hi--;
                while (lo < hi && nums[lo] == nums[lo - 1]) lo++;   // skip used value
            }
        }
    }
    return out;
}

def three_sum(nums):
    nums.sort()
    out, n = [], len(nums)
    for i in range(n - 2):
        if nums[i] > 0:
            break                      # smallest of the three is positive: no zero sum left
        if i > 0 and nums[i] == nums[i - 1]:
            continue                   # same first value -> same triplets again
        lo, hi = i + 1, n - 1
        while lo < hi:
            s = nums[i] + nums[lo] + nums[hi]
            if s < 0:
                lo += 1
            elif s > 0:
                hi -= 1
            else:
                out.append([nums[i], nums[lo], nums[hi]])
                lo += 1
                hi -= 1
                while lo < hi and nums[lo] == nums[lo - 1]:
                    lo += 1            # skip copies of the value we just used
    return out
