  • Cue: ratios / conversion rates between names, queries on pairs -> weighted graph, path product.
  • Insight: consistent ratios telescope, so any path gives the answer; store x / root to make it O(α).
  • State: parent[x], ratio[x] = x / parent[x]; find returns (root, x / root).
  • Trap: reverse edge, unknown variable -> -1 even for x/x, link roots with v·wb/wa.
  • Cost: DFS O(Q·(V+E)); weighted union-find O((E+Q)·α), O(V) space.
def find(x):                       # -> (root, x / root)
    if parent[x] != x:
        root, up = find(parent[x]); parent[x] = root; ratio[x] *= up
    return parent[x], ratio[x]
# union a/b = v:  ra,wa = find(a); rb,wb = find(b); parent[ra] = rb; ratio[ra] = v*wb/wa

Equation a / b = 4. Which edges go into the graph?

  1. a -> b with 4 only
  2. a -> b with 4 and b -> a with 0.25
  3. b -> a with 4 only
Every equation also gives its reciprocal, or reverse queries fail.

The query is ["x", "x"] and x appears in no equation. Answer?

  1. 1.0
  2. 0.0
  3. -1.0
An unknown variable cannot be evaluated, even divided by itself.

In weighted union-find, what does ratio[x] store?

  1. x / parent[x]
  2. parent[x] / x
  3. x / the first variable read
