Common mistakes

Adding only one edge per equation. a / b = k also gives b / a = 1/k. Without the reverse edge, half the queries return -1.

Answering x / x = 1 for an unknown x. The expected answer is -1. Check membership before the equality shortcut.

Union by linking the variables, not the roots. parent[a] = b loses a's old group. Always link ra to rb, with the ratio solved from the invariant.

Updating ratio[x] before the recursive find(parent) returns. The parent's ratio must already be "parent / root" when you multiply. Recurse first, then multiply, then re-point.

Comparing doubles with == in tests. Use a tolerance such as 1e-5; 1/3 is not exact in binary.
