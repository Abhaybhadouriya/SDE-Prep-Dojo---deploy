Example 2 with weighted union-find. An arrow points from a child to its parent; its label is child / parent.

  1. Equation a1 / b1 = 2. Both are new, so each is its own root. Hang a1 under b1 with ratio 2: it stores a1 = 2 · b1.
  2. Equation c1 / d1 = 5: a second, separate group. At this point a1 / d1 would answer -1 (different roots).
  3. Equation b1 / c1 = 0.5 joins them. b1 = 1 · b1 (root b1) and c1 = 5 · d1 (root d1). Hang root b1 under root d1 with ratio v · wc / wb = 0.5 · 5 / 1 = 2.5, so b1 = 2.5 · d1.
  4. Query a1 / d1. find(a1) walks a1 -> b1 -> d1, multiplies 2 · 2.5 = 5 and re-points a1 straight at d1 (path compression). Same root, so the answer is 5 / 1 = 5.
  5. Every later query is two finds and one division: d1 / a1 = 1 / 5, a1 / c1 = 5 / 5 = 1. A variable never seen in any equation gives -1, even for zz / zz.
