Recognise the pattern

Cue: pairwise ratios / conversion rates / relations between named things, and questions about pairs that were never given directly. Things = nodes, given relation = weighted edge (plus the inverse edge), derived relation = combine weights along a path. If the relation is "multiply", a path product; if many queries, store each node's value relative to a group root (weighted union-find).
