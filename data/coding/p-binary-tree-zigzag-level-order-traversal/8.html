Common mistakes

Reading queue.size() inside the loop condition. for (i = 0; i < q.size(); i++) grows as children are pushed, so levels merge. Freeze width first.

Flipping the child push order with a single queue. Pushing right-then-left on odd levels mirrors the next level's queue too, so level 2 comes out reversed. Only the two-stack version may swap the push order.

Returning [[]] for an empty tree. Check root == null before the loop.

Toggling the direction per node. The flag flips once, after the whole level is written.

Java: ArrayList.add(0, x) on odd levels. Inserting at the front of an ArrayList is O(width) per insert, O(w²) per level. Use a pre-sized array, a LinkedList/Deque, or the slot trick.
