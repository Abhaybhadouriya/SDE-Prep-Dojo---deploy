The problem (in our words)

You are given the root of a binary tree. Return the values of its nodes level by level, where the reading direction alternates: the first level (the root) is read left to right, the second level right to left, the third left to right again, and so on. The answer is a list of lists, one inner list per level, from the top level down. An empty tree gives an empty list.

Signature: List<List<Integer>> zigzagLevelOrder(TreeNode root) (LeetCode style; the tree is given as a level-order list with null for missing children).

  • The number of nodes is in the range [0, 2000]
  • -100 <= Node.val <= 100

Practice it: LeetCode 103 · GfG Zig-Zag Tree Traversal · GfG Level Order in Spiral Form

Constraints tell you: 2000 nodes is tiny, so even reversing every odd level is fine; the interviewer is checking that you know level-order BFS, that you handle the empty tree, and that you can avoid the extra reverse. A skewed tree has 2000 levels, so a recursive DFS version is still safe.
