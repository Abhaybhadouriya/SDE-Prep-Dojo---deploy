Dry run

Example 2, [1,2,3,4,null,null,5,6,null,null,7]. Blue = being popped in this step, green = finished, grey = waiting in the queue. The row underneath shows the slot each value is written into.

  1. Start: the queue holds the root. leftToRight = true. Grey = waiting in the queue.
  2. Level 0 has width 1. Pop 1, write it into slot 0, push its children 2 and 3. Row [1] goes to the output; flip the direction.
  3. Level 1, width 2, right to left. Pop 2 (i = 0): it goes into slot width - 1 - i = 1. Push its left child 4.
  4. Pop 3 (i = 1): slot 0. Push its right child 5. The row reads [3, 2], although the queue still holds the nodes left to right (4, 5).
  5. Level 2, left to right: 4 goes to slot 0, 5 to slot 1. Their children 6 and 7 are queued in normal order.
  6. Level 3, right to left: 6 (i = 0) lands in slot 1, 7 (i = 1) in slot 0, so the row is [7, 6]. Nothing new is queued.
  7. The queue is empty. Answer [[1], [3, 2], [4, 5], [7, 6]]. Each node was queued and popped once: O(n).
