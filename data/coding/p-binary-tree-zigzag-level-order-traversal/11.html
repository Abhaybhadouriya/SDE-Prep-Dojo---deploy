Interview follow-ups

Do it without reversing any list and without two stacks.

That is the slot trick: allocate the row with the level width and write the i-th popped node at width - 1 - i on odd levels. In Java a LinkedList with addFirst on odd levels works too, at O(1) per insert.

How to answer

Say why the width is known: it is frozen before any child is pushed.

Likely follow-ups
  • Why not ArrayList.add(0, x)? (O(w) per insert.)
Write it recursively (DFS) instead of BFS.

Pre-order DFS with the depth: create levels[depth] on the first visit to that depth, then append the value on even depths and prepend on odd depths (a deque per level), or append always and reverse odd levels at the end. Left is visited before right, so each level is built left to right.

How to answer

Point out the recursion depth equals the tree height (up to 2000 here, fine).

Likely follow-ups
  • Which one uses less memory on a complete tree? (DFS: O(log n) stack vs BFS: O(n/2) queue.)
Return one flat list of values in spiral order (the GfG form).

Same BFS; append each finished row to the result instead of storing it. Or use two stacks and output while popping.

How to answer

Ask which direction the root level uses; GfG's spiral version starts right to left on some statements.

Likely follow-ups
  • Start the spiral from the bottom level.
The tree is huge and streamed to you; you may only hold O(width) memory.

BFS already uses O(w) for the queue. Emit each row as soon as it is complete instead of collecting the whole answer, so memory is the queue plus one row.

How to answer

Separate the working memory (queue) from the output; the output can be a callback or a writer.

Likely follow-ups
  • Bound the width of a complete tree with n nodes (about n/2 leaves).
Zigzag every k levels instead of every level.

Use the level number: the direction is right-to-left when (level / k) % 2 == 1. The queue and slot logic do not change.

How to answer

Show that the direction is a function of the depth only, which is why a single flag (or depth % 2) was enough.

Likely follow-ups
  • Print the boundary of the tree anticlockwise (a different traversal: left edge, leaves, right edge reversed).
