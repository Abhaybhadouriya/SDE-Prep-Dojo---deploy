Interview follow-ups

Return all the ways to split s into words.

That is Word Break II. Backtrack from index 0, but memoise the list of sentences for each start index, and (optionally) first run this DP from the right so you never enter a start that cannot finish. The output itself can be exponential ("aaaa" with a, aa, aaa), so say that no algorithm beats the output size.

How to answer

Reuse the boolean DP as a pruning filter, then backtrack.

Likely follow-ups
  • What is the worst-case output size? (Up to 2^(n-1) sentences.)
Return the minimum number of words in a split (or -1).

Replace the boolean with a count: best[0] = 0, best[i] = min(best[j] + 1) over words s[j..i) with best[j] finite. Same loops, same complexity. "Count the number of splits" is the same again with += (and a modulus if asked).

How to answer

Show that only the combine operator changes: OR, min, or sum.

Likely follow-ups
  • Reconstruct one optimal split: store the j that gave the min (a parent pointer).
The dictionary has a million words and s is a 1 MB document.

Build a trie of the words once. For each i with ok[i] true, walk the trie along s from i; each node that ends a word marks ok[i + depth]. That is O(n·L) with no substring hashing. With many queries on the same dictionary, the trie is built once; a multi-pattern matcher (Aho-Corasick) finds all word occurrences in one pass if L is large.

How to answer

Name where the time goes (substring hashing) and remove it.

Likely follow-ups
  • Memory of the trie: 26 pointers per node vs a hash map per node.
What is the time complexity of the plain recursion, and why?

O(2^n) in the worst case. A split is a choice of cut / no cut at each of the n - 1 gaps, so there are at most 2^(n-1) splits, and "aaa...ab" with all short a-words makes the recursion try every one before failing. The memo collapses this to n + 1 states.

How to answer

Count the leaves of the recursion tree by describing a split as a bitmask of cuts.

Likely follow-ups
  • Can you make the brute force pass by pruning? (Only partly: checking that every letter of s appears in some word catches the "b" trap, but not all traps.)
Explain the same solution as a graph problem.

Nodes are positions 0..n. There is an edge i → j when s[i..j) is a word. The question is whether n is reachable from 0. BFS or DFS with a visited array visits each node once and tries at most L edges per node: the same O(n·L²) bound.

How to answer

Show that "visited" plays the role of the memo.

Likely follow-ups
  • Shortest split in words = BFS distance to n.
