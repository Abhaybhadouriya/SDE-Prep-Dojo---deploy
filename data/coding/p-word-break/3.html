Recognise the pattern

When you see "can this string be split / segmented / partitioned into pieces from a set" (or "minimum pieces", "number of ways"), think prefix DP over cut positions: ok[i] for the prefix of length i.

When you see that pieces are short (≤ 20 here), think "only look back L positions", which turns O(n²) into O(n·L).

Try greedy first; it breaks in both directions:

carpetscar, carpet, petslongest match first"carpet" + "s"? falsetrue (car + pets)✗

The choice of the first word changes what is left, and you cannot tell locally which choice is right. You have to try them all, but the leftover is always a suffix (or, read the other way, the finished part is a prefix), and there are only n + 1 of those. That is the signal for DP.
