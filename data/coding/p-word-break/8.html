Common mistakes

Greedy matching. Taking the longest (or shortest) word at each step fails on "carpets" (car, carpet, pets) and "carpet" (car, carpet).

Forgetting ok[0] = true. Then every ok[i] stays false and the function always returns false.

Off-by-one in the slice. ok[i] is about the first i letters, so the last word is s[j..i) (Python s[j:i], C++ s.substr(j, i - j)), not s[j..i].

Looking words up in the list. word in wordDict on a list is O(D) per check; build a hash set (or trie) once.

Memoising on the suffix string. memo[s[i:]] works but copies O(n) characters per key; memoise on the index i.
