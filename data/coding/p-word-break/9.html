Revision card

  • Cue: split / segment a string into pieces from a set; yes-no, min pieces or count ways.
  • Insight: the last word s[j..i) needs a splittable prefix s[0..j): ok[i] = OR ok[j].
  • State: ok[0..n], ok[0] = true; look back only L = longest word.
  • Trap: greedy longest/shortest match fails; slice s[j:i], not s[j:i+1]; use a set.
  • Cost: O(n·L²) time, O(n) extra space; plain recursion O(2^n).
ok = [True] + [False] * n
for i in range(1, n + 1):
    for j in range(max(0, i - L), i):
        if ok[j] and s[j:i] in words:
            ok[i] = True; break
return ok[n]

What does ok[i] mean?

  1. s[i] is the end of a word
  2. The first i letters can be split into dictionary words
  3. s[i..n) can be split
ok[i] is about the prefix of length i; the answer is ok[n]. (A suffix version, read right to left, works too.)

Why is ok[0] set to true?

  1. Because s is never empty
  2. To make the answer true by default
  3. The empty prefix is split by zero words, and every real split extends it
Without the seed, no first word can ever be accepted.

Why can j stop L positions before i?

  1. The last word is at most L letters long
  2. Because n ≤ 300
  3. Because dictionary words are distinct
s[j..i) must be a word, and no word is longer than L.
