The problem (in our words)

A label printer has dropped every space from a slogan, leaving one string s. You are also given a list wordDict of allowed words. Decide whether s can be cut into a sequence of one or more words, each of which appears in wordDict, so that the words joined in order give back s exactly.

A dictionary word may be used any number of times in the split. Return true if such a split exists, otherwise false.

Signature: boolean wordBreak(String s, List<String> wordDict).

Constraints

  • 1 <= s.length <= 300
  • 1 <= wordDict.length <= 1000
  • 1 <= wordDict[i].length <= 20
  • s and every wordDict[i] contain only lowercase English letters.
  • All strings in wordDict are distinct.

Practice it: LeetCode 139 - Word Break · GfG - Word Break

Constraints tell you: n ≤ 300 and words ≤ 20 letters. There are at most 300 × 20 = 6,000 (end, length) pairs, and each costs one hash of ≤ 20 characters, so the DP does about 10^5 character operations. The danger is not n² but exponential backtracking: 2^299 splits of "aaa...ab".
