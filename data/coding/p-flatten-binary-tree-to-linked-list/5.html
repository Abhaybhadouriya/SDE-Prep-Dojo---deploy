Dry run

On the first example, tree 1(2(3, 4(5)), 6):

  1. Start: cur = 1. It has a left subtree (2, 3, 4, 5), so its right subtree (6) must end up after all of it. Black arrows are right pointers, grey lines marked L are left pointers.
  2. Find pre, the rightmost node of the left subtree: 2 → 4. Note 4 is not the last node of that subtree in preorder (5 is), but 4 has no right child, so a right child hung on 4 comes after 4's left part (5) in preorder: right where 6 belongs.
  3. Three pointer writes: 4.right = 6, 1.right = 2, 1.left = null. The preorder is still 1, 2, 3, 4, 5, 6, and node 1 is final.
  4. cur = 2. Left child 3 is a leaf, so pre = 3.
  5. 3.right = 4, 2.right = 3, 2.left = null.
  6. cur = 3 has no left child: just step right. cur = 4 has left child 5, so pre = 5.
  7. 5.right = 6, 4.right = 5, 4.left = null. The tree is now a right chain.
  8. cur moves 5 → 6 → null. Result: 1 → 2 → 3 → 4 → 5 → 6, the preorder. The pre walks only follow right edges of left subtrees, and each edge is walked at most once over the whole run, so the total work is O(n).
