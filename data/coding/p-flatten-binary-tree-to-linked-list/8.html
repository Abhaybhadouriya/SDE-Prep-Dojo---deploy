Common mistakes

Forgetting cur.left = null. The chain looks right when you follow right, but the judge checks every left pointer, and the old left edge also creates a second path to the same nodes.

Preorder recursion that overwrites root.right before saving it. Save right = root.right first, or visit right before left as in rung 2.

Using a class-level prev without resetting it between test cases on the judge: the second test links into the first tree. Reset it at the start of flatten.

Building new nodes (a new list) instead of rewiring: the function returns nothing, so the caller only sees changes made to the original nodes.
