Interview follow-ups

Do it without recursion and without a stack.

The rightmost-of-left rewiring: walk the right spine; at each node with a left child, attach its right subtree to the rightmost node of the left subtree, move the left subtree to the right, clear left. O(n) time, O(1) space. State the invariant "the preorder never changes".

How to answer

Draw one rewire on a small tree first; the code is then six lines.

Likely follow-ups
  • Prove it is O(n) and not O(n2) (each edge is walked by a pre search at most once).
Flatten in inorder instead of preorder.

Use reverse inorder (right, node, left) with a prev pointer: visit the right subtree; then save left = node.left, set node.right = prev, node.left = null, prev = node; then visit the saved left. Saving the left child first matters, because you clear it before visiting it. Or run a Morris inorder traversal and link each visited node to the previous one. This is LC 897 for BSTs.

How to answer

Show which pointer you must save before overwriting.

Likely follow-ups
  • Make it a circular doubly linked list (LC 426).
Undo it: rebuild the tree from the flattened list.

The chain alone is just the preorder, which is not enough to rebuild a general tree. You need more information: for example an inorder sequence as well (LC 105), or null markers in the preorder (serialization, LC 297). For a BST the preorder alone is enough (LC 1008).

How to answer

Explain why preorder alone is ambiguous with a two-node example (left child vs right child).

Likely follow-ups
  • Which extra traversal pairs work? (Preorder + inorder, postorder + inorder.)
Write the iterative stack version.

Push the root. While the stack is not empty: pop node; push node.right then node.left (if not null) so left is popped first; set node.right = stack.top() (or null if empty) and node.left = null. O(n) time, O(h) stack.

How to answer

Note why right is pushed before left.

Likely follow-ups
  • Why is it safe to overwrite node.right after pushing it? (The stack holds the reference.)
The tree must be restored afterwards (read-only use).

Then do not flatten: if you only need the preorder sequence with O(1) space, use Morris preorder traversal, which creates temporary threads from rightmost nodes back to the current node and removes each thread when it is used, leaving the tree exactly as it was.

How to answer

Contrast "thread and remove" (Morris) with "rewire permanently" (this problem).

Likely follow-ups
  • Is Morris traversal safe with concurrent readers? (No: the tree is temporarily modified.)
