The problem (in our words)

You get the root of a binary tree. Rearrange it in place into a "linked list" made of the same nodes:

  • each node's right pointer points to the next node of the list, and its left pointer is null;
  • the order of the list is the tree's preorder traversal (node, then left subtree, then right subtree).

Signature: void flatten(TreeNode root); nothing is returned, the tree is modified. Trees are written in LeetCode level order in the examples, with null for a missing child.

Constraints

  • The number of nodes is in the range [0, 2000].
  • -100 <= Node.val <= 100

Follow-up asked by the original: can you flatten it in place with O(1) extra space?

Practice it: LeetCode 114 - Flatten Binary Tree to Linked List · GfG - Flatten binary tree to linked list · TUF - Flatten binary tree to linked list

Constraints tell you: 2000 nodes is small, so any O(n) or even O(n2) idea passes; the real test is the follow-up. A skewed tree of 2000 nodes means recursion depth 2000: fine in Java and C++, but Python's default recursion limit is 1000, so the recursive version can fail there without sys.setrecursionlimit.
