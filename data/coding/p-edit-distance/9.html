  • Cue: two strings + min insert/delete/replace (or LCS, or count matches) -> d[i][j] on prefixes.
  • Insight: decide the last chars only: match -> diag; else 1 + min(diag, up, left).
  • State: d[i][j] for a[0..i), b[0..j); d[i][0] = i, d[0][j] = j; keep prev and cur rows.
  • Trap: zero base cases; a[i] vs a[i-1]; one-row version loses the diagonal.
  • Cost: O(m·n) time, O(min(m,n)) space; plain recursion 3^(m+n).
prev = list(range(n + 1))                 # row 0
for i in range(1, m + 1):
    cur = [i] + [0] * n                   # column 0
    for j in range(1, n + 1):
        same = a[i-1] == b[j-1]
        cur[j] = prev[j-1] if same else 1 + min(prev[j-1], prev[j], cur[j-1])
    prev = cur
return prev[n]
