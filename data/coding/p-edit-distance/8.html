Common mistakes

Base cases left at 0. d[i][0] must be i and d[0][j] must be j; zeros make every answer too small.

Comparing word1[i] with word2[j]. Cell (i, j) is about prefixes of length i and j, so the last letters are word1[i-1] and word2[j-1].

One-row version that overwrites the diagonal. With a single array, dp[j-1] is already the new row when you need its old value; save it in a diag variable first. Two rows avoid the bug.

Greedy alignment. Counting mismatches position by position gives 3 for abc → bca; the answer is 2.
