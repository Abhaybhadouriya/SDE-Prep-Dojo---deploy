The problem (in our words)

A spell checker compares a typed word word1 with a dictionary word word2. It may change word1 using three operations, each costing one step:

  • Insert one character anywhere.
  • Delete one character.
  • Replace one character with another.

Return the minimum number of operations needed to turn word1 into word2.

Signature: int minDistance(String word1, String word2).

Constraints

  • 0 <= word1.length, word2.length <= 500
  • word1 and word2 contain only lowercase English letters.

Practice it: LeetCode 72 - Edit Distance · GfG - Edit Distance

Constraints tell you: 500 × 500 = 250,000 cells, so an O(m·n) table is the target; recursion without memo is 3^500. Either string may be empty (length 0), which the base row and column handle. The answer is at most max(m, n) ≤ 500.
