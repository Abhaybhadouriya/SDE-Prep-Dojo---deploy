Dry run

Input word1 = "mart" (rows), word2 = "karma" (columns). Each step fills one row; green cells are matches that copy their diagonal.

  1. Base row and column: turning "" into b[0..j) takes j inserts; turning a[0..i) into "" takes i deletes.
  2. Row "m": m never matches k, a, r, a, so each cell is 1 + min(diagonal, up, left). Only (1,4) uses the m of "karm": it copies the diagonal 3.
  3. Row "a": a = a at column 2, so d[2][2] = d[1][1] = 1 (match is free). a = a again at column 5, so d[2][5] copies its diagonal d[1][4] = 3 (not 1 + min = 4). The rest take 1 + min of the three neighbours.
  4. Row "r": r = r at column 3, so d[3][3] = d[2][2] = 1. "mar" -> "kar" costs one replace.
  5. Row "t": t matches nothing. d[4][5] = 1 + min(d[3][4] = 2, d[3][5] = 3, d[4][4] = 2) = 3.
  6. Walk back from the corner: insert "a" (left), replace t -> m (diagonal), r = r and a = a (free diagonals), replace m -> k. mart -> kart -> karm -> karma: 3 edits.
  7. Each row only read the row above and the cell to its left, so two rows of n + 1 numbers (prev, cur) give O(n) space.
