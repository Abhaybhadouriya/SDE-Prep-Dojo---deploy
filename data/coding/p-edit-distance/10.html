Technique: a 2D DP over prefix pairs (i, j) of two sequences, where each cell looks at the diagonal, up and left neighbours and the last characters decide which ones apply.

Closest match: GfG Edit Distance

  • Same: minimum inserts, deletes and replaces to turn one string into the other.
  • Different: only the input format and the judge's limits.
  • So: the same two-row DP.

How to recognise it:

  • Two strings (or arrays) are compared and the best alignment between them is unknown.
  • Each step consumes the last element of one or both: the subproblem is a pair of prefixes.

Practice order:

  1. Warm-up: LC 1143 (LCS), then LC 583.
  2. This problem: recursion, the table, then two rows; print the edits from the table once.
  3. Then LC 712 (weights), LC 115 (counting), LC 44 (wildcards).
