Interview follow-ups

Return the sequence itself, not only its length.

Remember the start x of the best run along with its length; the answer is range(x, x + best). No extra pass is needed.

How to answer

Show that the walk already knows both ends of the run.

Likely follow-ups
  • Several runs tie: return the one with the smallest start? (Compare starts on ties.)
Values arrive one by one. Report the longest run after each.

Keep a map from the two end values of every run to its length (or union-find with sizes). A new x merges the run ending at x-1 and the run starting at x+1: new length = left + right + 1, written at the two new ends. O(1) per insert; keep a running maximum.

How to answer

Say "only the ends need to be correct"; inner values are never read again.

Likely follow-ups
  • Now values can also be deleted. (A balanced tree of intervals.)
Memory is tight: you cannot afford a hash set of 105 values.

Sort in place (heapsort, O(1) extra) and do the one-pass scan: O(n log n) time, O(1) space. If values are in a small known range, a bitset of that range is the best of both (1 bit per possible value).

How to answer

Name the trade-off directly: the O(n) version costs O(n) memory.

Likely follow-ups
  • Values in [0, 232): a 512 MB bitset - acceptable?
The numbers are spread across many machines.

Partition values by range (each machine owns a contiguous range), solve locally, and send each machine's run touching its lower and upper boundary to a coordinator that joins runs across neighbouring ranges. Hash partitioning would scatter runs and needs a merge step like the boundary map.

How to answer

Point out that only boundary runs need communication.

Likely follow-ups
  • How do you pick ranges for skewed data? (Sample quantiles.)
Prove the nested loop is O(n).

Charge each inner step "y in seen, y++" to the value y. Every y belongs to exactly one run, and the inner loop runs only from that run's start, so each value is charged at most once. Inner steps <= distinct values <= n; plus O(n) outer iterations.

How to answer

Use the word "amortised" and the charging argument; it is the same argument as for sliding windows.

Likely follow-ups
  • What breaks if you loop over nums with duplicates? (Charges repeat.)
