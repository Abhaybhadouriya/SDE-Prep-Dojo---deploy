The story

Explain like I'm 5

A pile of numbered tickets lies on the floor, unsorted, some duplicated. What is the longest row of tickets with numbers that follow each other, like 8, 9, 10, 11? A smart way: for each ticket, ask "is the ticket one lower on the floor?" If yes, this ticket is not the start of a row, so ignore it. If no, it is a start: count upward 9, 10, 11... until a number is missing. Each row is counted once, from its first ticket.

The hash set answers "is it on the floor?" in O(1); the "start only" rule is what keeps the counting linear.

From your world

It is like finding the longest contiguous run of received sequence numbers in an out-of-order packet trace: put the sequence numbers in a set, and measure a run only from a number whose predecessor never arrived (the start of a gap-free block). No sort of the trace is needed.
