Technique: hash-set membership plus "act only on a canonical element" (the start of a run), which turns a nested loop into amortised O(n).

Closest match: LC 2501 Longest Square Streak in an Array Medium

  • Same: the longest chain of values that all appear in the array, found with a set.
  • Different: the next value is x² instead of x+1, and a streak needs at least 2 values (else -1).
  • So: walk x, x², x⁴ ... from each value while present; chains are short (values <= 105, so at most 5 steps), so no start check is needed.

How to recognise it:

  • The question is about which values exist, not where they are; order in the array is irrelevant.
  • An O(n) bound on unsorted data: think hash set or counting, not sorting.

Practice order:

  1. Warm-up: the sorting version of this problem (handle duplicates).
  2. This problem: the set walk; test with many duplicates of a run start.
  3. Then: 2501 Longest Square Streak, and 298 Binary Tree Longest Consecutive Sequence (Premium).
