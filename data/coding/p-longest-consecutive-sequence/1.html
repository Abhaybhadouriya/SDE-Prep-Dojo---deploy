The problem (in our words)

You get an unsorted integer array nums (values may repeat). A consecutive sequence is a set of values x, x+1, x+2, ..., x+L-1 that all appear somewhere in nums, in any positions. Return the largest such L. Repeated values count once.

Your algorithm must run in O(n) time.

Signature: int longestConsecutive(int[] nums).

Constraints:

  • 0 <= nums.length <= 105
  • -109 <= nums[i] <= 109

Practice it: LeetCode 128 · GfG Longest Consecutive Subsequence · TUF article

Constraints tell you: the O(n) requirement rules out sorting (O(n log n)) as the final answer, though it is a fine first rung. Values up to 109 in magnitude rule out a boolean array indexed by value: you need hashing. The array can be empty: return 0.
