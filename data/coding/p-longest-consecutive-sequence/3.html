Recognise the pattern

When you see "unsorted array" + "O(n)" + a question about values (not positions) such as "consecutive", "x and x+1", "pairs that sum to k", think put the values in a hash set and ask membership questions. To avoid double work, only act on a canonical element (here: the smallest of each run).

ValuesRun starts (x-1 missing)Answer
{1, 2, 3}13
{1, 3, 5}1, 3, 51
{4, 2, 3, 10, 11}2, 103
{7, 7, 7}71

Each run has exactly one start, and walks begin only at starts, so the walks never overlap.
