Common mistakes

Reading s[i] when s is empty or already matched. Check i < |s| before s[i] == t[j]. In C++ s[0] on an empty string returns the terminator (no crash, but a habit that bites in Java with charAt).

Checking letter membership instead of order. Counting letters, or using t.indexOf(c) from the start each time, accepts "dgo" in "xdlobg". Search from the position after the previous match.

Mixing up subsequence and substring. t.contains(s) needs the letters to be adjacent; a subsequence allows gaps.

Follow-up: forgetting the +1. After matching at index p, the next search starts at p + 1, otherwise "aa" matches a single "a" twice.
