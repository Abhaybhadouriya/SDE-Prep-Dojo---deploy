The problem (in our words)

You are given two strings: a short code word s and a long transmission t. Return true if s can be read out of t by deleting some characters of t (possibly none) without changing the order of the characters that remain, that is, if s is a subsequence of t; otherwise return false. For example, "dog" is a subsequence of "xdlobg", while "dgo" is not.

Signature: boolean isSubsequence(String s, String t).

Constraints:

  • 0 <= s.length <= 100
  • 0 <= t.length <= 104
  • s and t contain only lowercase English letters.

Follow-up: suppose a huge number of strings s1, s2, ..., sk arrive (k ≥ 109) and each must be checked against the same t. How would you change the solution?

Practice it: LeetCode 392 · GfG Check for Subsequence

Constraints tell you: |t| ≤ 104 and |s| ≤ 100, so even an O(|s|·|t|) DP (106 cells) passes, but one linear scan is expected. Either string may be empty: the empty string is a subsequence of everything. Only 26 letters, so the follow-up index is 26 lists. The follow-up's k ≥ 109 says "do not rescan t per query": preprocess t once.
