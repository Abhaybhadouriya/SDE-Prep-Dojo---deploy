Recognise the pattern

Cue: two sequences + "in the same order, gaps allowed" + a yes/no answer -> two pointers moving in the same direction, the pattern pointer advancing only on a match. When the same long text is queried many times -> index the text (positions per symbol + binary search, or a next-occurrence table).

Try a few:

stAnswerNote
"ab""ba"falseLetters present, wrong order.
"aa""a"falseEach letter of t is used at most once.
"aa""baba"trueTwo separate a's, in order.
"ab""aab"trueTaking the first a or the second a both work; the first is never worse.
