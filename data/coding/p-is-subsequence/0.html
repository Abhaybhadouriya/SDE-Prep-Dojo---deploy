The story

Explain like I'm 5

You have a shopping list, "milk, eggs, bread", and you walk down one long aisle that you cannot walk back. Each time you pass the next item on your list, you grab it and look at the next item on the list. If you reach the end of the aisle with the list done, you won. Grabbing the first milk you see is always right: a later milk would only leave less aisle for the eggs.

That "grab the first one" rule is the whole proof. The rest is two indexes moving forward.

From your world

This is how a packet filter matches an ordered set of patterns in a byte stream without buffering, or how grep checks a fixed sequence of events in a log: one cursor in the stream, one cursor in the pattern, the pattern cursor only advances on a hit. The follow-up (many patterns, one big text) is the classic "index the text once" move, like building a per-key position list before running many queries.
