Practice problems (in this order)

Each link opens our write-up page with the full problem, hints and code. "Premium" marks problems that need a LeetCode subscription to submit.

Warm up: the rule and the walk

  • Search in a Binary Search Tree Easy - the downward walk, iteratively.
  • Insert into a Binary Search Tree Medium - hang it on the null link.
  • Range Sum of BST Easy - prune subtrees that are entirely out of range.
  • Lowest Common Ancestor of a BST Medium - the first node where the two keys split.
  • Convert Sorted Array to Binary Search Tree Easy - middle is the root.

Inorder: sorted for free

  • Validate Binary Search Tree Medium - do it both ways.
  • Minimum Absolute Difference in BST Easy - neighbours in inorder.
  • Kth Smallest Element in a BST Medium - then the subtree-size follow-up.
  • Binary Search Tree Iterator Medium - the left-spine stack.
  • Two Sum IV - Input is a BST Easy - try two iterators instead of a hash set.
  • Convert BST to Greater Tree Medium - reverse inorder with a running sum.
  • Recover Binary Search Tree Medium - the two dips; Morris for O(1).

Edit and navigate

  • Delete Node in a BST Medium - the three cases.
  • Trim a Binary Search Tree Medium - out-of-range node: return the trimmed side that can still hold keys.
  • Inorder Successor in BST Medium Premium - candidate on every left turn.
  • Inorder Successor in BST II Medium Premium - parent pointers, like rb_next().
  • Closest Binary Search Tree Value Easy Premium - one walk; mind the tie rule.
  • Closest Binary Search Tree Value II Hard Premium - two stacks, O(h + k).

Build and combine

  • Construct BST from Preorder Traversal Medium - an upper bound passed down, O(n).
  • Convert Sorted List to Binary Search Tree Medium - build in inorder.
  • Balance a Binary Search Tree Medium - inorder, then middle-as-root.
  • Verify Preorder Sequence in BST Medium Premium - monotonic stack with a lower bound.
  • Largest BST Subtree Medium Premium - postorder (isBST, min, max, size).
  • Maximum Sum BST in Binary Tree Hard - same postorder, sum instead of size.
  • Unique Binary Search Trees Medium - Catalan numbers; a DP that looks like a BST question.
