Recognise the pattern

Cue: "return an item with probability proportional to its weight" (or "according to a distribution", "like a loaded die") with many queries -> prefix sums of the weights + one uniform draw + lower-bound binary search. If the weights change between queries, swap the prefix array for a Fenwick tree.

The same three-step move (cumulate, draw, search) shows up whenever a discrete distribution must be sampled: weighted shuffle, random point in rectangles of different areas, sampling ads by bid.
