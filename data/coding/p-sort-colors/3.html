Recognise the pattern

When you see "group items into 2 or 3 classes, in place, one pass", think partition with pointers. Two classes: one write pointer (Move Zeroes, parity). Three classes: Dutch national flag with lo, mid, hi. If the problem also demands the original relative order inside each class (stable), in-place swapping is not enough; use counts or an output array.

Try the three rules on tiny inputs and watch mid:

InputFirst moveDoes mid move?
[0,1]0 swaps with itself, lo and mid moveyes
[1,0]1 stays; then 0 swaps with the 1 at loyes, both times
[2,0]2 swaps with the 0 at hino: the 0 now at mid is still unchecked
[2,2]2 swaps with the 2 at hino; hi passes mid next round and the loop ends
