Example 1, [1,2,0,0,2,1]. Cells show the colour (R/W/B); the bar above shows the four zones; the pointers are below.

  1. Start: lo = mid = 0, hi = 5. Everything is in the unknown zone [mid..hi].
  2. nums[0] = 1: already in the right zone, just mid++.
  3. nums[1] = 2: swap it with nums[5] and hi--. mid stays: the value that came from the right has not been checked yet.
  4. nums[1] = 1: already in the right zone, just mid++.
  5. nums[2] = 0: swap it with nums[0] (the first 1, or itself), then lo++ and mid++.
  6. nums[3] = 0: swap it with nums[1] (the first 1, or itself), then lo++ and mid++.
  7. nums[4] = 2: swap it with nums[4] and hi--. mid stays: the value that came from the right has not been checked yet. Now mid > hi: the unknown zone is empty, so the array is sorted: [0, 0, 1, 1, 2, 2].
