Quiz

For a = [1, 2, 1, 2, 3], atMost(2 distinct) = 12 and atMost(1 distinct) = 5. How many subarrays have exactly 2 distinct values?

  1. 12
  2. 17
  3. 5
  4. 7
exactly(2) = atMost(2) - atMost(1) = 12 - 5 = 7.

In the "count at least K" shape, after shrinking while the window is still valid, what do you add?

  1. right - left + 1
  2. n - right
  3. left
  4. right - left
Starts 0 .. left - 1 all give valid (bigger) windows ending at right, so add left.

In Minimum Window Substring, a character c enters the window. When do you decrement missing?

  1. When c is the first character of t
  2. When need[c] was greater than 0 before the decrement
  3. When need[c] becomes 0 or less
  4. Always
Only a character that was still owed pays a debt; a spare copy (need[c] already 0 or less) does not.

Which question should NOT be solved with atMost(K) - atMost(K - 1) on a window?

  1. Subarrays with sum exactly K where values may be negative
  2. Subarrays with exactly K distinct integers
  3. Subarrays with exactly K odd numbers
  4. Binary subarrays with sum S
With negatives, "sum at most K" is not monotone, so even the atMost helper is wrong. Use prefix sums with a hash map.

Max Consecutive Ones III with k flips is best restated as:

  1. Longest window with exactly k zeros
  2. Longest window with at most k zeros
  3. Number of windows with k zeros
  4. Shortest window with k ones
Flipping zeros is a budget; the window is valid while it holds at most k zeros.

Why must atMost(K) return 0 when K is negative?

  1. Because the answer is always n
  2. Otherwise the shrink loop never becomes valid and left runs past right
  3. It does not matter
  4. To save time
No window satisfies "at most -1", so the while loop would keep shrinking an empty window. The guard returns the correct count, 0.
