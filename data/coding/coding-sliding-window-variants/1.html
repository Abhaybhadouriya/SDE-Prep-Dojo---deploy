One skeleton, four shapes

Every variable window solution has the same bones: a for loop that moves right forward and adds a[right] to the window state, an inner while that moves left forward, and one line that uses the window. What changes from problem to problem is only two things: the condition on the while and the line that uses the window.

The whole page rests on one requirement: the condition must be monotone. In plain words: if a window is valid, every smaller window inside it is valid too (for "at most" conditions), or every bigger window around it is valid too (for "at least" and "covers" conditions). Monotone conditions are what let left move only forward. If you cannot say this sentence about your condition, the sliding window is the wrong tool.

Before you write code, say the monotone sentence out loud: "with only non-negative numbers, if a window's sum is at most S, every smaller window inside it is too." That one sentence shows you know why the two pointers are allowed.
