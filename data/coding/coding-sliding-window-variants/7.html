Fixed windows with frequency maps

When the length is fixed (k, or the length of a pattern), there is no shrink decision: each step, one item enters on the right and one leaves on the left. The work moves into the state. Two patterns cover nearly every interview question.

The matches counter (anagrams, permutations)

Find All Anagrams in a String (LC 438) and Permutation in String (LC 567) ask whether a window of length |p| has the same letter counts as p. Comparing two 26-entry arrays each step works (O(26 n)), and in an interview that is usually fine. The sharper version keeps matches = how many of the 26 letters currently have equal counts. When a letter's count changes, check it before and after: if it was equal, matches--; change it; if it is now equal, matches++. The window is an anagram exactly when matches == 26. Each step changes at most two letters, so the check is O(1).

Distinct inside a fixed window

Maximum Sum of Distinct Subarrays With Length K (LC 2461): keep a running sum and a count map. The window is "all distinct" when the map has exactly k keys. Delete keys whose count reaches zero, or the size check lies. Use 64-bit sums: k values up to 105 each overflow 32 bits fast.

Substring with Concatenation of All Words (LC 30) is the fixed-window idea one level up: the "items" are words of length w, so you run w separate windows, one for each starting offset 0..w-1, each stepping by w. Each pass is the distinct-count window with words as keys.

Fixed window, index rule: when right enters, the item leaving is a[right - k], and the first full window is ready when right == k - 1. Write those two lines first and test them on k = 1 and k = n.
