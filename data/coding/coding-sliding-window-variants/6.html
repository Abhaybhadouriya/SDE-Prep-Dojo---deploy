Shortest covering window

Minimum Window Substring (LC 76) is the most asked Hard in this family: the smallest substring of s that contains every character of t, duplicates included. The condition "covers t" is monotone upwards (a bigger window still covers), so we use the shortest shape: expand until the window covers, then shrink while it still covers, recording inside the loop.

The state is the part people get wrong. You need two things:

  • need[c]: how many more copies of c the window still owes. It starts as the counts of t. It goes down when c enters and up when c leaves. It may go negative: that means the window has spare copies.
  • missing: the total number of characters still owed, starting at len(t). A character entering lowers missing only if need[c] was positive before it entered. A character leaving raises missing only if need[c] becomes positive after it leaves.

The window is valid exactly when missing == 0, an O(1) check. Without missing you would compare two maps on every step, which is O(alphabet) per step. Click through s = "BXAYCAB", t = "ABC":

  1. need holds the counts of t: one A, one B, one C. missing = 3 characters still owed.
  2. right = 0, B enters. need[B] was 1 (positive), so this B pays a debt: missing = 2.
  3. X enters: need[X] was 0, so it is spare (need[X] = -1). A enters and pays a debt: missing = 1.
  4. Y is spare, C pays the last debt: missing = 0. The window [0, 4] = BXAYC covers t. Record length 5.
  5. Shrink: B leaves. need[B] goes back to 1, which is positive, so a debt is open again: missing = 1. The window is invalid; stop shrinking.
  6. right = 5, A enters. need[A] was 0, so this A is spare (need[A] = -1). missing stays 1.
  7. right = 6, B enters and pays the open debt: missing = 0. Window [1, 6] has length 6, not better than 5. Now shrink while valid.
  8. X leaves (it was spare, need[X] back to 0). A leaves (spare, need[A] back to 0). Still valid. Window [3, 6] = YCAB, length 4: new best.
  9. Y leaves (spare). Still valid. Window [4, 6] = CAB, length 3: new best.
  10. C leaves: need[C] = 1, missing = 1, invalid. right is at the end, so the loop ends. Answer: CAB.

The loop behind the steps. Invariant: missing counts the characters of t not yet covered; the window grows until missing is 0, then shrinks from the left while it stays 0, recording the shortest. Lifted unchanged from the tested templates below.

// SHORTEST covering window (LC 76): need[] may go negative (surplus); missing = chars still owed.
string minWindow(const string& s, const string& t) {
    int need[128] = {0};
    for (char c : t) need[(int)c]++;
    int missing = t.size(), left = 0, bestLen = INT_MAX, bestStart = 0;
    for (int right = 0; right < (int)s.size(); right++) {
        if (need[(int)s[right]]-- > 0) missing--;
        while (missing == 0) {                             // valid: record, then shrink
            if (right - left + 1 < bestLen) { bestLen = right - left + 1; bestStart = left; }
            if (++need[(int)s[left]] > 0) missing++;
            left++;
        }
    }
    return bestLen == INT_MAX ? "" : s.substr(bestStart, bestLen);
}
# ---- 5. SHORTEST covering window: minimum window substring ----
def min_window(s, t):
    """LC 76: smallest substring of s that contains every char of t (with counts)."""
    need = Counter(t)
    missing = len(t)
    left = 0
    best_len, best_start = float("inf"), 0
    for right, ch in enumerate(s):
        if need[ch] > 0:                          # this char was still needed
            missing -= 1
        need[ch] -= 1                             # may go negative = surplus
        while missing == 0:                       # valid: record, then shrink
            if right - left + 1 < best_len:
                best_len, best_start = right - left + 1, left
            out = s[left]
            need[out] += 1
            if need[out] > 0:                     # we just gave away a needed char
                missing += 1
            left += 1
    return "" if best_len == float("inf") else s[best_start:best_start + best_len]

Cost: each character enters once and leaves at most once, so O(|s| + |t|) time. Space is O(alphabet): a 128-entry array for ASCII. Record the start and the length, not the substring, so you do not copy strings on every step.

Close relatives

  • Minimum Size Subarray Sum (LC 209): the same shape with a sum instead of missing; only valid for positive numbers.
  • Replace the Substring for Balanced String (LC 1234): find the shortest window whose outside already has at most n/4 of each letter. Same shape, condition on the complement.
  • Shortest Subarray with Sum at Least K (LC 862): negative numbers break the window. The fix is prefix sums plus a monotonic deque of increasing prefix values. Know it as the "where the window stops working" example.
  • Minimum Window Subsequence (LC 727): "subsequence" instead of "all characters in any order". Not a counting window: walk forward to match t, then walk backward to tighten the start, or use DP.
