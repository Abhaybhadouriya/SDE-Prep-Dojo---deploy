  • Cue: fixed-width rows filled in order -> greedy i..j packing with a running length.
  • Insight: word j fits iff letters + len(w_j) + (j - i) <= maxWidth.
  • State: i, j, letters; gaps = j - i - 1; each, extra = divmod(maxWidth - letters, gaps).
  • Trap: last line (j == n) and one-word lines: left-justify + pad; extras go LEFT.
  • Cost: O(total characters) time, O(maxWidth) per line.
while i < n:
    j, L = i, 0
    while j < n and L + len(w[j]) + (j - i) <= W: L += len(w[j]); j += 1
    g = j - i - 1
    if j == n or g == 0: line = ' '.join(w[i:j]).ljust(W)
    else:
        q, r = divmod(W - L, g)
        line = ''.join(w[k] + ' ' * (q + (k - i < r)) for k in range(i, j - 1)) + w[j - 1]
    out.append(line); i = j
