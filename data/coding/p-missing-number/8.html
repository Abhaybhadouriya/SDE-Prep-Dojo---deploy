Common mistakes

XORing only indices 0..n-1. The range has n + 1 numbers but the array has n slots; index n must be added explicitly (start with acc = n, or XOR it in at the end).

Using the sum formula with n from the wrong place. n is nums.length, not max(nums): if n itself is missing, the max is n - 1 and the formula gives the wrong range.

Overflow in other languages. n*(n+1)/2 computed in int overflows for n above ~65,000. Use a 64-bit type, the running difference, or XOR.

Treating it as cyclic sort when not needed. Swapping values into place works (O(n), O(1)) but mutates the input and is easy to get wrong with the value n, which has no slot. Use it only if the interviewer wants the "index as hash" technique.
