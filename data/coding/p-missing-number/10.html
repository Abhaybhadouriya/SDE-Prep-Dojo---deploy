Technique: the expected contents are known (a range), so compare expected to actual with a cancelling operation, or use values as indices into the array itself.

Closest match: GfG Missing in Array

  • Same: one value of a known range is absent, no duplicates.
  • Different: the range is 1..n and the array has n - 1 elements.
  • So: XOR 1..n with the values (or n(n+1)/2 minus the sum); shift the indices by one.

How to recognise it:

  • "Numbers from 0..n / 1..n" plus "one missing / one repeated": the range is free information.
  • "Appears twice except one": XOR.
  • "Constant space, may modify the array": use the values as indices (sign bit or swaps).

Practice order:

  1. Warm-up: LC 136 Single Number.
  2. This problem: sum, then XOR, then binary search for the sorted variant.
  3. Then LC 645, LC 448 and LC 41 to practise the "index as hash" family.
