Recognise the pattern

When you see "values are exactly 0..n (or 1..n) with one missing / one duplicated", think the expected set is known for free, so compare it to what you have: sum difference, XOR cancellation, or use each value as an index.

When you see "every element appears twice except one", think XOR: x ^ x = 0 and x ^ 0 = x, in any order.

The key observation: pair every number of the full range 0..n with itself. The present numbers have both copies (one as an index, one as a value); the missing number has only its index copy. Anything that cancels pairs (subtraction, XOR) leaves exactly the missing number.

Taxonomy: Bits → XOR cancellation → single number family, also Arrays → index as hash → cyclic sort. Pattern lessons: Bit manipulation, Arrays & hashing.
