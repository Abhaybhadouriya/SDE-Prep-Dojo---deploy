Recognise the pattern

Cue: "take k items, only from the two ends" -> the result is a prefix plus a suffix; equivalently the untouched part is one contiguous window of n - k. Fixed-size sliding window.

When you see "remove from either end", think "what remains is a contiguous subarray": optimise that subarray instead (here: minimum sum of length n - k; in LC 1658: longest subarray with a given sum).

When you see a choice sequence where the order does not change the final set, think enumerating the final sets, not the sequences.

Taxonomy: Sliding window → fixed window sum / average. Pattern lessons: Sliding window, Sliding window variants, Prefix sum.
