  • Cue: longest/count palindromic SUBSTRING -> expand around 2n - 1 centres.
  • Insight: palindromes nest around one centre; the first mismatch ends that centre.
  • State: start, best; expand(lo, hi) returns hi - lo - 1.
  • Trap: even centres (c, c+1); start = c - (len - 1) / 2; cut the string once.
  • Cost: O(n²) time, O(1) space; DP O(n²)/O(n²); Manacher O(n).
def expand(lo, hi):
    while lo >= 0 and hi < n and s[lo] == s[hi]:
        lo -= 1; hi += 1
    return hi - lo - 1
for c in range(n):
    use(max(expand(c, c), expand(c, c + 1)), c)

How many centres do you expand from for a string of length n?

  1. n
  2. n - 1
  3. 2n - 1 (each letter and each gap)
  4. n²
Odd palindromes centre on a letter, even ones on a gap. Skipping the gaps misses "abba".

expand(lo, hi) stops at the first mismatch and returns hi - lo - 1. Why minus 1?

  1. off-by-one guard
  2. both lo and hi have moved one step past the palindrome
  3. to skip the centre
  4. for even centres only
The palindrome is lo+1..hi-1, whose length is (hi - 1) - (lo + 1) + 1 = hi - lo - 1.

What is the extra space of expand-around-centre?

  1. O(1)
  2. O(n)
  3. O(n²)
  4. O(log n)
It keeps only start and best length and cuts the substring once at the end. The DP table costs O(n²).
