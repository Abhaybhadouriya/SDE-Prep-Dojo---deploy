Common mistakes

Odd centres only. Misses every even-length palindrome: "xyyx" returns "x". Expand from (c, c) AND (c, c + 1).

Off-by-one in the start index. After the loop, lo and hi are one step outside the palindrome: length = hi - lo - 1, start = lo + 1. Using c - len / 2 is wrong for even lengths; c - (len - 1) / 2 is right for both.

Wrong fill order in the DP. Looping i from 0 upwards reads pal[i+1][j-1] before it is computed. Fill by length, or i from n-1 down.

"Reverse the string and take the longest common substring". Fails on "abacdfgdcaba": it shares "abacd" with its reverse, yet "abacd" is not a palindrome. It works only if you also check that the match sits at mirrored positions, and by then the centre method is simpler.

Building substrings inside the loop. s.substring(...) per centre turns O(n²) into O(n³) allocations in Java. Track start and length; cut once at the end.
