Common mistakes

Starting lo at 1 (or 0). The greedy check then meets a package heavier than the capacity; without a guard it puts it on a "day" that overflows, and the search can return an answer smaller than the heaviest package. Start lo at max(weights).

Mixing the two binary-search templates. With while lo < hi use hi = mid and lo = mid + 1. Writing hi = mid - 1 can skip the answer; lo = mid with a floor mid loops for ever.

Off-by-one in the day counter. Start used = 1 (the first day is open before any package) and increment when a package does not fit. Starting at 0 under-counts by one.

Sorting the weights. The order is fixed by the belt. Sorting changes the problem (and the answer).
