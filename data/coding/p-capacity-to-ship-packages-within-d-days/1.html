The problem (in our words)

Packages wait on a conveyor belt in a fixed order; weights[i] is the weight of the i-th package. A ship carries them over days days. Each day it loads packages in the given order (no skipping, no reordering), as long as the total loaded that day does not exceed its capacity. Return the smallest capacity that ships all packages within days days.

Signature: int shipWithinDays(int[] weights, int days).

  • 1 <= days <= weights.length <= 5 * 104
  • 1 <= weights[i] <= 500

Practice it: LeetCode 1011 · TUF article

Constraints tell you: n up to 5·104 and weights up to 500, so the capacity lies in [1, 2.5·107]. Trying every capacity is up to 2.5·107 × n steps: far too slow. log2(2.5·107) ≈ 25, so 25 greedy checks of O(n) each, about 1.25·106 steps. The sum fits in a 32-bit int. days <= n, so the answer is never below the heaviest package.
