60-second recall

  • Cue: evaluate + - * / without brackets -> sum of signed terms.
  • Rule: act when a number ENDS, using the operator BEFORE it (start with '+').
  • State: total (closed terms) + last (open term, sign included).
  • Trap: divide toward zero (not floor); apply the last number at the end of the string.
  • Cost: O(n) time, O(1) space; the stack version is O(n) space and extends to brackets.
total = last = num = 0; op = "+"
for i, c in enumerate(s):
    if c.isdigit(): num = num * 10 + int(c)
    if c in "+-*/" or i == len(s) - 1:
        if op in "+-": total += last; last = num if op == "+" else -num
        elif op == "*": last *= num
        else: last = int(last / num)        # toward zero
        op, num = c, 0
return total + last

Quick quiz

In "4+6*2", what are total and last right after the 6 is applied?

  1. total 10, last 0
  2. total 0, last 10
  3. total 4, last 6
  4. total 4, last 12
The 6 is preceded by '+', so 4 moves into total and last = 6. The '*' 2 later turns last into 12.

What does "5-7/2" return?

  1. 1
  2. 2
  3. -1
  4. 3
The term is (-7) / 2 = -3 toward zero; 5 + (-3) = 2.

Why can the stack be replaced by one variable here but not in Basic Calculator III?

  1. Without brackets only the top term can change; brackets need a saved level per '('
  2. Because multiplication is commutative
  3. Because the input is short
  4. It can be replaced in both
With brackets, an outer term is suspended while the inner expression is evaluated, so you need a stack (or recursion) of (total, last, op) levels.
