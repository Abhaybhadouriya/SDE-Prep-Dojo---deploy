Common mistakes

Applying the operator you just read instead of the one before the number. When you see '*' after 6 in "4+6*2", the 6 is still waiting for the 2. Always act on the previous operator when a number ends.

Forgetting the last number. The loop only applies a number when an operator arrives; the final number has none. Either check i == n - 1 (as in the code) or append a sentinel '+'.

Skipping spaces with continue before the end check. On "3+2 " the last character is a space; a continue jumps over the i == n - 1 test and the 2 is lost.

Floor division in Python. -3 // 2 == -2. Use int(a / b) or divide the absolute values and restore the sign.

Treating each character as a number. "12" is twelve, not 1 then 2. Accumulate num * 10 + digit.
