The problem (in our words)

A delivery robot stands on the top-left cell (0, 0) of a warehouse floor laid out as a grid with m rows and n columns. Its target is the bottom-right cell (m - 1, n - 1). In one move the robot goes exactly one cell down or one cell right; it never moves up or left and never leaves the grid. There are no obstacles.

Given the two integers m and n, return the number of distinct routes the robot can take from the start to the target. Two routes are different if their sequences of moves differ.

Signature: int uniquePaths(int m, int n). The tests guarantee the answer is at most 2 × 10^9.

Constraints

  • 1 <= m, n <= 100
  • The answer is ≤ 2 × 10^9 (so it fits in a signed 32-bit int).

Practice it: LeetCode 62 - Unique Paths · GfG - Count paths from top left to bottom right · TUF - Grid unique paths

Constraints tell you: m·n ≤ 10^4 cells, so an O(m·n) table is instant. The cap of 2 × 10^9 matters for the formula: intermediate products overflow 32 bits, so compute it in 64 bits and divide at every step. Every DP cell is ≤ the final answer, so the DP never overflows an int.
