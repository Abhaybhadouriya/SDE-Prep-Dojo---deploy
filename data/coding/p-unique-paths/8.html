Common mistakes

Overflow in the formula. Computing (m+n-2)! directly, or multiplying in 32-bit ints, overflows long before the answer does.

Dividing before multiplying. res = res / i * (x) loses the remainder; multiply first so every division is exact.

Initialising the edges to 0. Row 0 and column 0 must be 1; with 0 the whole table stays 0.

Using m and n as the number of moves. There are m-1 downs and n-1 rights, so the formula is C(m+n-2, m-1), not C(m+n, m).
