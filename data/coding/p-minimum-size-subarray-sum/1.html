The problem (in our words)

You are given an array nums of positive integers and a positive integer target. Return the smallest length of a contiguous, non-empty subarray whose sum is greater than or equal to target. If no subarray reaches the target, return 0.

Signature: int minSubArrayLen(int target, vector<int>& nums).

Constraints:

  • 1 <= target <= 109
  • 1 <= nums.length <= 105
  • 1 <= nums[i] <= 104

Follow-up (part of the original): after the O(n) solution, write one that runs in O(n log n).

Practice it: LeetCode 209 · GfG: smallest subarray with sum greater than x (strictly greater, otherwise the same)

Constraints tell you: n = 105 rules out O(n2) (1010 steps). Values are at least 1, which is the whole key: the window sum is strictly monotonic in its length. The total is at most 105 x 104 = 109, which still fits in a signed 32-bit int (2.1·109), but only just; in a variant with larger values use 64-bit.
