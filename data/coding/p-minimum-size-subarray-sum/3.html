Recognise the pattern

When you see "shortest (or longest) contiguous subarray" + a sum condition + all values positive, think variable sliding window. Shortest that reaches a bound: shrink while valid and record inside the loop. Longest that stays under a bound: shrink while invalid and record after the loop. Negative values break it: go to prefix sums with a monotonic deque (LC 862).
