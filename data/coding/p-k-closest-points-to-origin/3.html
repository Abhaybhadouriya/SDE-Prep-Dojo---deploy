Recognise the pattern

Cue: "k closest / k largest / k most frequent / k smallest" -> top-k. To keep the k smallest, use a max-heap of size k (the root is the one to evict). For all data in memory and only the set (not the order), quickselect is O(n) average. For one-off small inputs, sort and slice.

Try a fewHeap typeWhy
k smallest distancesmax-heap, size kEvict the largest of the kept ones.
k largest elementsmin-heap, size kEvict the smallest of the kept ones.
k-th smallest onlymax-heap, size k; answer = rootThe root is exactly the k-th.
