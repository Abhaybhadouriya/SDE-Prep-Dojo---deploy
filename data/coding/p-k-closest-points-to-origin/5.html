Dry run

Example 2 with the max-heap, k = 2.

  1. Compute x² + y² for every point. Squared distance keeps the order and stays an integer.
  2. (4, 0), d = 16. The heap has room: push it.
  3. (-2, -2), d = 8. Still room: push. The root is now the worse of the two, 16.
  4. (1, -3), d = 10. The heap is full; 10 beats the worst kept (16), so 16 is evicted and 10 goes in. The new worst is 10.
  5. (0, 5), d = 25. It is not better than the worst kept (10): ignore it without touching the heap.
  6. Done: the heap holds the 2 closest points. Order inside the answer does not matter.
