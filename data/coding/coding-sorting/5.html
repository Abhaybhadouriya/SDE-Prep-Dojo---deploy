Merge sort that counts pairs

A large family of Hard problems asks: how many pairs i < j satisfy some rule between a[i] and a[j]? Inversions (a[i] > a[j]), Reverse Pairs (a[i] > 2·a[j]), Count of Smaller Numbers After Self, Count of Range Sum (on prefix sums). The brute force is O(n2). Merge sort gives O(n log n) because of one fact:

The key claim: when you merge two sorted halves, every left item is still to the left of every right item in the original array. So pairs that cross the middle can be counted with two pointers over two sorted lists, and pairs inside one half were already counted by the recursion.

For plain inversions you can count while merging: when you take an item from the right half, every item still waiting in the left half is bigger, so add mid - i. For a rule like a[i] > 2·a[j] the merge order and the counting order differ, so count in a separate pass first, then merge. The pointer j never moves back, because the left half is sorted.

  1. Both halves came back sorted from recursion: L = [3, 5, 7], R = [1, 2, 4]. We count pairs with L[i] > 2 * R[j]. Pointer j starts at R[0].
  2. i at 3: move j while 3 > 2 * R[j]. 3 > 2 yes, 3 > 4 no. So j = 1: one right item pairs with 3. Count 1.
  3. i at 5: j does not go back. Every R item that paired with 3 also pairs with 5, because 5 ≥ 3. 5 > 4 yes, 5 > 8 no, so j = 2. Count + 2 = 3.
  4. i at 7: 7 > 8 no, j stays at 2. Count + 2 = 5. Each pointer moved at most 3 times: O(n) for this level.
  5. Only after counting do we merge as usual. Counting and merging are two separate passes over the same two sorted halves; both are linear, so the whole thing stays O(n log n).
// 4. Merge sort counting pairs i < j with a[i] > 2*a[j] (LC 493).
func sortCount(a, tmp []int, lo, hi int) int { // [lo, hi)
	if hi-lo <= 1 {
		return 0
	}
	mid := lo + (hi-lo)/2
	cnt := sortCount(a, tmp, lo, mid) + sortCount(a, tmp, mid, hi)
	for i, j := lo, mid; i < mid; i++ {
		for j < hi && int64(a[i]) > 2*int64(a[j]) {
			j++
		}
		cnt += j - mid
	}
	i, j, t := lo, mid, lo
	for i < mid || j < hi {
		if j >= hi || (i < mid && a[i] <= a[j]) {
			tmp[t] = a[i]
			i++
		} else {
			tmp[t] = a[j]
			j++
		}
		t++
	}
	copy(a[lo:hi], tmp[lo:hi])
	return cnt
}

func reversePairs(nums []int) int {
	a := append([]int(nil), nums...)
	return sortCount(a, make([]int, len(a)), 0, len(a))
}
// 4. Merge sort that counts pairs i < j with a[i] > 2*a[j] (LC 493).
long long sortCount(vector<int>& a, vector<int>& tmp, int lo, int hi) {   // [lo, hi)
    if (hi - lo <= 1) return 0;
    int mid = lo + (hi - lo) / 2;
    long long cnt = sortCount(a, tmp, lo, mid) + sortCount(a, tmp, mid, hi);
    int j = mid;                                            // both halves are sorted now
    for (int i = lo; i < mid; i++) {
        while (j < hi && (long long)a[i] > 2LL * a[j]) j++;
        cnt += j - mid;                                     // a[mid..j) all pair with a[i]
    }
    merge(a.begin() + lo, a.begin() + mid, a.begin() + mid, a.begin() + hi, tmp.begin() + lo);
    copy(tmp.begin() + lo, tmp.begin() + hi, a.begin() + lo);
    return cnt;
}
int reversePairs(vector<int> a) {
    vector<int> tmp(a.size());
    return (int)sortCount(a, tmp, 0, (int)a.size());
}
// 4. Merge sort counting pairs i < j with a[i] > 2*a[j] (LC 493).
static long sortCount(int[] a, int[] tmp, int lo, int hi) {   // [lo, hi)
    if (hi - lo <= 1) return 0;
    int mid = (lo + hi) >>> 1;
    long cnt = sortCount(a, tmp, lo, mid) + sortCount(a, tmp, mid, hi);
    for (int i = lo, j = mid; i < mid; i++) {
        while (j < hi && (long) a[i] > 2L * a[j]) j++;
        cnt += j - mid;
    }
    int i = lo, j = mid, t = lo;                                // standard merge
    while (i < mid || j < hi)
        tmp[t++] = (j >= hi || (i < mid && a[i] <= a[j])) ? a[i++] : a[j++];
    System.arraycopy(tmp, lo, a, lo, hi - lo);
    return cnt;
}
static int reversePairs(int[] nums) {
    int[] a = nums.clone();
    return (int) sortCount(a, new int[a.length], 0, a.length);
}
# 4. Merge sort counting pairs i < j with a[i] > 2*a[j] (LC 493).
def reverse_pairs(a):
    def solve(lo, hi):                # sorts a[lo:hi], returns the count
        if hi - lo <= 1:
            return 0
        mid = (lo + hi) // 2
        cnt = solve(lo, mid) + solve(mid, hi)
        j = mid
        for i in range(lo, mid):      # both halves sorted: j only moves right
            while j < hi and a[i] > 2 * a[j]:
                j += 1
            cnt += j - mid
        a[lo:hi] = sorted(a[lo:hi])   # a real merge is O(n); sorted() on two runs is O(n) in TimSort
        return cnt

    a = list(a)
    return solve(0, len(a))

Count of Smaller Numbers After Self is the same skeleton, but you sort indexes instead of values, so each count lands on the right original position: when a left item is placed during the merge, add the number of right items already placed before it. A Fenwick tree over compressed values is the other standard answer; know both and say which you prefer (merge sort needs no coordinate compression).

Overflow: 2 * a[j] overflows 32-bit ints when a[j] is near 231. LeetCode's Reverse Pairs tests exactly that. Use 64-bit (2LL * a[j] in C++, 2L in Java, int64 in Go).
