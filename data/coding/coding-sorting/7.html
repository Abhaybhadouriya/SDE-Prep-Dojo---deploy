How to recognise the pattern

Cues: "pairs / groups / duplicates" with no need for original positions: sort first. "Values in a small range" or "frequency at most n": count or bucket. "Count pairs i < j with a[i] (op) a[j]": merge sort counting (or a Fenwick tree). "k-th smallest / largest / closest": quickselect or a heap. "Order by a rule between two items": custom comparator. "Ties keep input order": stable sort or the index as last key.
