Partitioning and quickselect

Partitioning rearranges an array around a pivot value: smaller on the left, larger on the right. Quicksort partitions and recurses into both sides. Quickselect partitions and recurses into one side only, the side holding the index you want. Expected work is n + n/2 + n/4 + ... = O(n). That is how you get the k-th largest without sorting.

The smallest version of this is Sort Colors (the Dutch national flag): only three values 0, 1, 2, so the pivot is 1 and one pass finishes the job.

  1. Start: lo = 0, i = 0, hi = 5. Everything is unknown.
  2. a[0] = 2: swap it with a[hi] and shrink hi. Do not move i: the 0 that came back is still unchecked.
  3. a[0] = 0: swap with a[lo] (itself), then lo++ and i++.
  4. a[1] = 0: same again. Now lo = i = 2.
  5. a[2] = 2: swap with a[4] = 1, hi = 3.
  6. a[2] = 1: already in the middle band, just i++.
  7. a[3] = 1: i++. Now i > hi, the unknown band is empty: sorted in one pass, O(1) extra space.
// 5a. Dutch national flag (LC 75).
func sortColors(a []int) {
	lo, i, hi := 0, 0, len(a)-1
	for i <= hi {
		switch a[i] {
		case 0:
			a[lo], a[i] = a[i], a[lo]
			lo++
			i++
		case 2:
			a[i], a[hi] = a[hi], a[i]
			hi--
		default:
			i++
		}
	}
}

// 5b. Quickselect, random pivot, 3-way partition (LC 215).
func findKthLargest(nums []int, k int) int {
	a := append([]int(nil), nums...)
	target, l, r := len(a)-k, 0, len(a)-1
	for {
		pivot := a[l+rand.Intn(r-l+1)]
		lt, i, gt := l, l, r
		for i <= gt {
			if a[i] < pivot {
				a[lt], a[i] = a[i], a[lt]
				lt++
				i++
			} else if a[i] > pivot {
				a[i], a[gt] = a[gt], a[i]
				gt--
			} else {
				i++
			}
		}
		if target < lt {
			r = lt - 1
		} else if target > gt {
			l = gt + 1
		} else {
			return pivot
		}
	}
}
// 5a. Dutch national flag (LC 75): [0,lo) = 0s, [lo,i) = 1s, (hi,n) = 2s.
void sortColors(vector<int>& a) {
    int lo = 0, i = 0, hi = (int)a.size() - 1;
    while (i <= hi) {
        if (a[i] == 0) swap(a[lo++], a[i++]);
        else if (a[i] == 2) swap(a[i], a[hi--]);           // do not advance i: new a[i] is unseen
        else i++;
    }
}

// 5b. Quickselect with a random pivot and 3-way partition (LC 215).
int findKthLargest(vector<int> a, int k) {
    static mt19937 rng(12345);
    int target = (int)a.size() - k;                         // index in ascending order
    int l = 0, r = (int)a.size() - 1;
    while (true) {
        int pivot = a[l + rng() % (r - l + 1)];
        int lt = l, i = l, gt = r;                          // < pivot | == pivot | > pivot
        while (i <= gt) {
            if (a[i] < pivot) swap(a[lt++], a[i++]);
            else if (a[i] > pivot) swap(a[i], a[gt--]);
            else i++;
        }
        if (target < lt) r = lt - 1;
        else if (target > gt) l = gt + 1;
        else return pivot;                                  // target sits in the == block
    }
}

        else if (target > gt) l = gt + 1;
        else return pivot;

}

static void swap(int[] a, int i, int j) { int t = a[i]; a[i] = a[j]; a[j] = t; }

Why the pivot must be random

With "always take the first element" as the pivot, a sorted input splits into sizes 0 and n-1 every time: O(n2). A random pivot makes that astronomically unlikely, and the 3-way split handles the other killer, an array of all-equal values (2-way Lomuto partition is O(n2) on [7, 7, 7, ...]). LeetCode's Kth Largest Element has test cases built to punish both. If an interviewer asks for a guaranteed O(n), name median of medians and say it is rarely coded in interviews.
