Can you do it in a single traversal?

Yes: one DFS with two flags. Pass leftEdge to the left child always and to the right child only if there is no left child; mirror it for rightEdge. Print a left-edge inner node before recursing (preorder), a right-edge inner node after recursing (postorder, which reverses the right edge for free), and a leaf when you meet it.

How to answer

Say the flag propagation rule out loud and why postorder gives the bottom-up right edge.

Likely follow-ups
  • Which is easier to get right, and why might you still prefer the four-walk version?
What changes if the left edge should start at the root even when it has no left child (the older GfG definition)?

Only the start of the walk: with no left subtree, the left edge would continue down the right subtree. That is exactly why LC 545 defines the left edge as empty in that case, to avoid printing right-subtree nodes twice. Clarify the definition before coding; it is the point of the question.

How to answer

Show you noticed the ambiguity and ask which definition they want.

Likely follow-ups
  • Which nodes would then be printed twice with your current code?
Do it clockwise instead of anti-clockwise.

Root, then the right edge top-down, then the leaves right to left (DFS visiting right before left), then the left edge reversed. It is the mirror image of the same four parts.

How to answer

List the four parts in the new order; no new idea needed.

Likely follow-ups
  • How do you get leaves right to left without reversing a list?
The tree is 106 nodes deep. What breaks?

Recursion: a recursive leaf walk overflows the stack (C++ default stack is a few MB, Python's limit is 1000). The edge walks are loops already; make the leaf walk an explicit stack, or use Morris traversal for O(1) extra space.

How to answer

Point at the one recursive part and replace it.

Likely follow-ups
  • How does Morris traversal find leaves without a stack?
Return the boundary of an N-ary tree.

Left edge: follow the first child until a leaf. Right edge: follow the last child, reversed. Leaves: any DFS visiting children in order. Same ownership rule.

How to answer

Generalise "left" to "first child" and "right" to "last child".
