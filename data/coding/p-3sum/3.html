Recognise the pattern

When you see "find all k-tuples with a given sum" + "no duplicate tuples" + n in the thousands, think sort, fix k-2 elements with loops, and run a two-pointer pair search on the rest. The order of the output does not matter, which is your permission to sort.

Try a few to see why sorting is the key:

Sorted suffix (pair target 4)lo + hiMove
[-1, 0, 2, 3, 5, 7]-1 + 7 = 6Too big: 7 cannot work even with the smallest partner -> hi--
[-1, 0, 2, 3, 5]-1 + 5 = 4Hit: record, move both
[0, 2, 3]0 + 3 = 3Too small: 0 cannot work even with the largest partner -> lo++
