How to recognise it:

  • "Palindromic" + "substring" (contiguous) -> centres; "subsequence" -> LCS-style DP.
  • You need many "is s[i..j] a palindrome" answers -> build the table once.

Practice order:

  1. Warm-up: 680 Valid Palindrome II (two pointers).
  2. This problem: DP table first, then centre expansion with O(1) space.
  3. Then 5 Longest Palindromic Substring, 131/132 Palindrome Partitioning, 516 Subsequence.
