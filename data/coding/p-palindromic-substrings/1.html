The problem (in our words)

You are given a string s. Return how many of its substrings are palindromes. A palindrome reads the same forwards and backwards; a substring is a contiguous, non-empty block of characters. Substrings are counted by position: two substrings with the same letters but different start or end indices count separately (in "ppp", each of the three "p" counts).

Signature: int countSubstrings(String s).

  • 1 <= s.length <= 1000
  • s consists of lowercase English letters.

Practice it: LeetCode 647 · GfG Palindrome SubStrings Count · TUF article

Constraints tell you: n = 1000 means about 500,000 substrings. O(n³) (test each one) is ~1.7·10^8 character comparisons in the worst case - risky; O(n²) is 10^6 and easy. The answer is at most n(n+1)/2 = 500,500, so an int is enough.
