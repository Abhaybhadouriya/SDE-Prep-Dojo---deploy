Interview follow-ups

Return the longest palindromic substring instead of the count.

Same loop; after expanding from a centre, the last matching span is (lo + 1, hi - 1); keep the widest one. O(n²) time, O(1) space.

How to answer

Show that only the bookkeeping changes - a sign you understand the centre idea.

Likely follow-ups
  • Can you do it in O(n)? (Manacher.)
Count only distinct palindromic substrings.

Put each found substring (or its hash, or its (start, length) after deduplicating with a rolling hash) into a set: O(n²) substrings in the worst case, so O(n²) memory with hashes. The optimal tool is the palindromic tree (eertree), which has at most n + 2 nodes, one per distinct palindrome - mention it, rarely coded.

How to answer

Note that a string of length n has at most n distinct non-empty palindromic substrings.

Likely follow-ups
  • Why at most n? (Each new letter adds at most one new palindrome: the longest palindromic suffix.)
Write the DP version and give the fill order.

pal[i][j] = s[i] == s[j] && (j - i < 2 || pal[i+1][j-1]). Loop i from n-1 down to 0 and j from i to n-1, so the inner interval is ready. Count true cells. O(n²) time and space.

How to answer

Draw the table: each cell depends on its lower-left diagonal neighbour.

Likely follow-ups
  • Reduce the table to O(n) memory (keep one row; iterate j downwards).
Answer many queries "how many palindromic substrings lie inside s[l..r]?"

Precompute pal[i][j], then cnt[l][r] by inclusion-exclusion: cnt[l][r] = cnt[l+1][r] + cnt[l][r-1] - cnt[l+1][r-1] + pal[l][r]. O(n²) preprocessing, O(1) per query.

How to answer

Spot that the count over a range is a 2D prefix sum over the pal table.

Likely follow-ups
  • What if n = 10^5? (Manacher radii plus offline counting.)
Why is centre expansion O(n²) and not O(n³)?

Each successful expansion step does O(1) work and corresponds to exactly one palindromic substring; each centre also has one failing step. So the total work is O(number of palindromes + number of centres) = O(n²) at most, and O(n) on strings with few palindromes.

How to answer

Tie the cost to the output size: it is output-sensitive.

Likely follow-ups
  • Which input is the worst case? (All equal letters.)
