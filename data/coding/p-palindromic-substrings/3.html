Recognise the pattern

Cue: "palindromic substring(s)" - count them, find the longest, list them - -> expand around each of the 2n - 1 centres, or the interval DP pal[i][j] = s[i] == s[j] && pal[i+1][j-1]. "Subsequence" instead of "substring" is a different problem (LCS-style DP).

Look at how palindromes around one centre relate:

String, centrePalindromes foundStops because
"racecar", letter 3 (e)e, cec, aceca, racecarend of string
"noon", gap 1|2oo, noonend of string
"abab", letter 1 (b)b, abaleft end reached

The palindromes around a centre are nested, and the first mismatch kills every longer one with that centre. So one outward walk per centre counts them all.
