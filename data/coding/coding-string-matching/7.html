Number of distinct substrings

The problem, in our words. Given a lowercase string s (length 1 to 500), count how many different non-empty substrings it has. "aabbaba" has 21; "abcdefg" has 7 · 8 / 2 = 28 because all are different. Original: LeetCode 1698 (Premium; asked at Intuit, Uber and Bloomberg in the Premium lists); our write-up: Number of Distinct Substrings in a String. The follow-up is "can you do it in O(n) time?".

The ladder to present:

  1. Brute force, O(n3). Put every s[i:j] in a set of strings. Each substring costs O(n) to build and hash. Fine for n = 500 in C++, risky in Python.
  2. Trie of all suffixes, O(n2). Insert every suffix into a trie; each new node is one new distinct substring. Exact, but up to n2/2 nodes of memory.
  3. Rolling hash per length, O(n2) expected. For each length L, slide a hash across s and count distinct hash values; O(n) extra memory. This is the template below. Because the hashes act as identity, use two moduli (see the collision table).
  4. Mention, do not code: a suffix array with the LCP array gives n(n+1)/2 - sum(LCP) in O(n log n); a suffix automaton gives it in O(n). Saying the names and the formula is enough at SDE-3 level; interviewers do not expect either from memory.
// countDistinct: LC 1698, double rolling hash per length.
func countDistinct(s string) int {
	const M1, M2, B = 1_000_000_007, 1_000_000_009, 131
	n, total := len(s), 0
	for length := 1; length <= n; length++ {
		seen := map[int64]struct{}{}
		var h1, h2, p1, p2 int64 = 0, 0, 1, 1
		for i := 0; i < length; i++ {
			h1 = (h1*B + int64(s[i])) % M1
			h2 = (h2*B + int64(s[i])) % M2
			if i > 0 {
				p1, p2 = p1*B%M1, p2*B%M2
			}
		}
		for i := 0; ; i++ {
			seen[h1<<32|h2] = struct{}{}
			if i+length == n {
				break
			}
			h1 = ((h1-int64(s[i])*p1%M1+M1)*B + int64(s[i+length])) % M1
			h2 = ((h2-int64(s[i])*p2%M2+M2)*B + int64(s[i+length])) % M2
		}
		total += len(seen)
	}
	return total
}
// LC 1698: number of distinct non-empty substrings. Double rolling hash per length, O(n^2) expected.
int countDistinct(const string& s) {
    const long long M1 = 1000000007LL, M2 = 1000000009LL, B = 131;
    int n = s.size(), total = 0;
    for (int len = 1; len <= n; len++) {
        unordered_set<long long> seen;
        long long h1 = 0, h2 = 0, p1 = 1, p2 = 1;
        for (int i = 0; i < len; i++) {
            h1 = (h1 * B + (unsigned char)s[i]) % M1;
            h2 = (h2 * B + (unsigned char)s[i]) % M2;
            if (i) { p1 = p1 * B % M1; p2 = p2 * B % M2; }
        }
        for (int i = 0;; i++) {
            seen.insert((h1 << 32) | h2);            // both < 2^30, so the key is exact
            if (i + len == n) break;
            h1 = ((h1 - (unsigned char)s[i] * p1 % M1 + M1) * B + (unsigned char)s[i + len]) % M1;
            h2 = ((h2 - (unsigned char)s[i] * p2 % M2 + M2) * B + (unsigned char)s[i + len]) % M2;
        }
        total += seen.size();
    }
    return total;
}
// LC 1698: distinct non-empty substrings with a double rolling hash per length.
static int countDistinct(String s) {
    final long M1 = 1_000_000_007L, M2 = 1_000_000_009L, B = 131;
    int n = s.length(), total = 0;
    for (int len = 1; len <= n; len++) {
        HashSet<Long> seen = new HashSet<>();
        long h1 = 0, h2 = 0, p1 = 1, p2 = 1;
        for (int i = 0; i < len; i++) {
            h1 = (h1 * B + s.charAt(i)) % M1;
            h2 = (h2 * B + s.charAt(i)) % M2;
            if (i > 0) { p1 = p1 * B % M1; p2 = p2 * B % M2; }
        }
        for (int i = 0; ; i++) {
            seen.add((h1 << 32) | h2);
            if (i + len == n) break;
            h1 = ((h1 - s.charAt(i) * p1 % M1 + M1) * B + s.charAt(i + len)) % M1;
            h2 = ((h2 - s.charAt(i) * p2 % M2 + M2) * B + s.charAt(i + len)) % M2;
        }
        total += seen.size();
    }
    return total;
}
def count_distinct(s: str) -> int:
    """LC 1698: distinct non-empty substrings; one hash mod 2^61-1 per window (Python ints do not overflow)."""
    MOD, B = (1 << 61) - 1, 131
    n, total = len(s), 0
    for length in range(1, n + 1):
        h = 0
        for i in range(length):
            h = (h * B + ord(s[i])) % MOD
        pw = pow(B, length - 1, MOD)
        seen = {h}
        for i in range(n - length):
            h = ((h - ord(s[i]) * pw) * B + ord(s[i + length])) % MOD
            seen.add(h)
        total += len(seen)
    return total

A neat exact alternative with the prefix function, also O(n2): add characters one at a time; the new substrings that end at the new character are its suffixes that did not occur before. Reverse the current prefix, run the prefix function, and the largest pi value is the length of the longest suffix already seen, so the count grows by (i + 1) - max(pi). No hashing, no collisions.
