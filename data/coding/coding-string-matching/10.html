Practice ladder

In order. The links open our write-up: the task restated, references to the original and to editorials, and code.

Warm-up: borders and doubling

  • Find the Index of the First Occurrence in a String Easy - naive first, then the KMP template.
  • Rotate String Easy - search in s + s.
  • Repeated Substring Pattern Easy - n % (n - pi[n-1]) == 0.
  • Maximum Repeating Substring Easy - match counts on runs of the word.
  • String Matching in an Array Easy - pairwise contains; know the cost.

Core: the interview set

  • Repeated String Match Medium - q or q + 1 copies.
  • Repeated DNA Sequences Medium - rolling hash, or 2 bits per letter in a 20-bit integer.
  • Number of Distinct Substrings in a String Medium - double hash per length, or a suffix trie.
  • Longest Happy Prefix Hard - it is pi[n-1].
  • Shortest Palindrome Hard - pi of s + "#" + reverse(s).
  • Longest Duplicate Substring Hard - binary search on the length + rolling hash; handle collisions.

Stretch: SDE-3 and recent contest-style asks

  • Longest Repeating Substring Medium - the n <= 2000 version of 1044; DP or hashing.
  • Sum of Scores of Built Strings Hard - sum of the Z-array.
  • Minimum Time to Revert Word to Initial State II Hard - first multiple of k where z covers the rest.
  • Find Beautiful Indices in the Given Array II Hard - two KMP passes, then two pointers (PhonePe, Google in the Premium lists).
  • Count Prefix and Suffix Pairs II Hard - a trie keyed by (s[i], s[n-1-i]) pairs, or Z plus hashing.
