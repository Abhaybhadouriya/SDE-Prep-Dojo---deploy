Three interview problems the prefix function solves

Shortest palindrome (LC 214)

The problem, in our words. Given a lowercase string s (length 0 to 5·104), you may only add characters at the front. Return the shortest palindrome you can build. Example: "aacecaaa" gives "aaacecaaa"; "abcd" gives "dcbabcd". Original: LeetCode 214; our write-up: Shortest Palindrome.

Insight. Whatever you add in front must mirror the part of s that is not already a palindrome. So find the longest palindromic prefix P of s; the answer is reverse(rest) + s. A prefix of s is a palindrome exactly when it equals a suffix of reverse(s). So build t = s + "#" + reverse(s) and read pi[last]: the longest prefix of t that is also a suffix of t. The # stops the border from running past s. O(n) instead of O(n2) for "check every prefix".

Repeated string match (LC 686)

The problem, in our words. Given strings a and b (lowercase, lengths 1 to 104), return the fewest copies of a, glued end to end, that contain b as a substring, or -1 if no count works. Example: a = "xyzw", b = "zwxyzwxy": three copies "xyzwxyzwxyzw" contain b, two do not, so the answer is 3. Original: LeetCode 686; our write-up: Repeated String Match.

Insight. b has to start somewhere inside the first copy of a, at an offset from 0 to |a|-1. From there it needs |b| characters, so q = ceil(|b| / |a|) copies are enough when the offset is 0, and q + 1 copies cover any other offset. If b is not in q + 1 copies, it is in no number of copies. Search with KMP: O(|a| + |b|), or with the library find and say it is O(n · m) in the worst case.

Period and border questions

  • Longest happy prefix (LC 1392): the longest proper prefix that is also a suffix is literally s[0 : pi[n-1]].
  • Repeated substring pattern (LC 459): let p = n - pi[n-1] (the smallest period). s is a block repeated at least twice exactly when pi[n-1] > 0 and n % p == 0. The well-known one-liner, "s occurs in (s + s) without its first and last characters", is the same fact.
  • Rotate string (LC 796): goal is a rotation of s when the lengths match and goal occurs in s + s. KMP makes it O(n).
func reverse(s string) string {
	b := []byte(s)
	for i, j := 0, len(b)-1; i < j; i, j = i+1, j-1 {
		b[i], b[j] = b[j], b[i]
	}
	return string(b)
}

// shortestPalindrome: LC 214.
func shortestPalindrome(s string) string {
	rev := reverse(s)
	pi := prefixFunction(s + "#" + rev)
	k := pi[len(pi)-1]
	return rev[:len(s)-k] + s
}

// repeatedStringMatch: LC 686.
func repeatedStringMatch(a, b string) int {
	q := (len(b) + len(a) - 1) / len(a)
	t := strings.Repeat(a, q)
	if len(kmpSearch(t, b)) > 0 {
		return q
	}
	if len(kmpSearch(t+a, b)) > 0 {
		return q + 1
	}
	return -1
}
// LC 214: shortest palindrome made by adding characters in front of s.
string shortestPalindrome(const string& s) {
    string rev(s.rbegin(), s.rend());
    vector<int> pi = prefixFunction(s + "#" + rev);  // '#' never occurs in s
    int k = pi.back();                               // longest palindromic prefix of s
    return rev.substr(0, s.size() - k) + s;
}

// LC 686: fewest copies of a so that b is a substring, or -1.
int repeatedStringMatch(const string& a, const string& b) {
    int q = (b.size() + a.size() - 1) / a.size();    // ceil(|b| / |a|)
    string t;
    for (int i = 0; i < q; i++) t += a;
    if (!kmpSearch(t, b).empty()) return q;
    t += a;                                          // one more copy covers any offset
    if (!kmpSearch(t, b).empty()) return q + 1;
    return -1;
}
// LC 214
static String shortestPalindrome(String s) {
    String rev = new StringBuilder(s).reverse().toString();
    int[] pi = prefixFunction(s + "#" + rev);
    int k = pi[pi.length - 1];
    return rev.substring(0, s.length() - k) + s;
}

// LC 686
static int repeatedStringMatch(String a, String b) {
    int q = (b.length() + a.length() - 1) / a.length();
    StringBuilder t = new StringBuilder();
    for (int i = 0; i < q; i++) t.append(a);
    if (!kmpSearch(t.toString(), b).isEmpty()) return q;
    t.append(a);
    if (!kmpSearch(t.toString(), b).isEmpty()) return q + 1;
    return -1;
}

def repeated_string_match(a: str, b: str) -> int:
    """LC 686."""
    q = -(-len(b) // len(a))
    if kmp_search(a * q, b):
        return q
    if kmp_search(a * (q + 1), b):
        return q + 1
    return -1
