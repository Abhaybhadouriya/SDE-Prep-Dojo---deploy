Words you need: prefix, suffix, border, period

  • Prefix of s: s[0..k), the first k characters. Proper means shorter than s itself.
  • Suffix of s: the last k characters.
  • Border: a string that is both a proper prefix and a suffix. abacaba has the borders aba and a.
  • Period p: s[i] = s[i + p] for every valid i. A border of length k gives a period n - k. abcabcab (n = 8) has border abcab (5), so period 3.

The prefix function stores, for every prefix of the pattern, the length of its longest border: pi[i] = longest border of s[0..i]. Many books call the same array lps ("longest proper prefix which is also suffix") or the failure function. One fact makes everything fast: a border of a border is also a border. So when the longest border does not work, the next one to try is pi[k-1], then pi[pi[k-1]-1], and so on. There is no need to search.
