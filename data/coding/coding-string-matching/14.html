What is the prefix function of aabaa?

  1. [0, 0, 1, 1, 2]
  2. [0, 1, 0, 1, 2]
  3. [0, 1, 2, 0, 1]
  4. [1, 1, 0, 1, 2]
"aa" has border "a" (1), "aab" none (0), "aaba" has "a" (1), "aabaa" has "aa" (2). pi[0] is always 0.

After a mismatch with k characters matched (k > 0), KMP sets k to...

  1. 0
  2. pi[k]
  3. k - 1
  4. pi[k - 1]
The matched part is pat[0..k-1]; its longest border is pi[k-1]. pi[k] is about a longer prefix that has not matched.

Using the Z-function on pat + text without a separator, text position j is a match when...

  1. z[m + j] >= m
  2. z[j] >= m
  3. z[m + j] == m exactly
  4. z[j] == m
Position m + j of the concatenation is text position j. Without a separator the match may run on past m, so the test is "at least m".

s = "abcabcabc". What does n - pi[n-1] tell you?

  1. The number of matches: 3
  2. The smallest period: 3
  3. The longest border: 6
  4. Nothing useful
pi[8] = 6 (border "abcabc"), so the smallest period is 9 - 6 = 3, and 9 % 3 == 0 means the string is "abc" three times.

You hash 105 substrings into a set using one modulus near 109. Roughly how many colliding pairs should you expect?

  1. About 0.00001
  2. About 105
  3. About 0.05
  4. About 5
k2 / (2M) = 1010 / (2·109) = 5. That is why hashes used as identity need two moduli.

a = "abc", b = "cabcab". How many copies of a are needed?

  1. 2
  2. 3
  3. 4
  4. -1
q = ceil(6 / 3) = 2 gives "abcabc", which does not contain b. q + 1 = 3 gives "abcabcabc", which does (from index 2).

Which tool fits "find a pattern in a TCP byte stream that arrives in segments" best?

  1. Z-function on the concatenated stream
  2. A hash set of all substrings
  3. Sorting the segments
  4. KMP, carrying k between segments
KMP's whole state is one integer, so it handles boundaries without buffering; Z needs the full concatenation in memory.
