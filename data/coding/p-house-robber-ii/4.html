Approaches: brute → better → optimal

Hint 1

In any valid plan, can both kiosk 0 and kiosk n-1 be opened?

Hint 2

If kiosk n-1 is closed, what is left is a straight line. The same is true if kiosk 0 is closed.

1. Brute force - try every subset

Idea: enumerate all 2^n subsets, drop those with two adjacent kiosks (including 0 and n-1), and keep the best sum. In bit terms: reject mask & (mask >> 1) and masks with both bit 0 and bit n-1 set. Our test drivers use exactly this as the checker.

O(2^n · n)time
O(1)space

What is wasted: everything; the line version of this problem already has an O(n) DP.

2. Better - DP with a "was the first house taken?" flag

Idea: run the line DP with an extra state bit: best[i][f], where f says whether house 0 is in the plan. At the last house, if f = 1, it may not be taken.

  1. State: best[i][f] = best total for houses 0..i, with f = 1 if house 0 is taken.
  2. Transition: the House Robber step inside each f, except that at i = n-1 the "take" option exists only for f = 0.
  3. Base case: best[0][1] = nums[0], best[0][0] = 0.
  4. Answer: max over f of best[n-1][f].
O(n)time
O(1)space (four variables)

Why it is not the favourite: it is correct, but the extra flag doubles the variables and is easy to get wrong under pressure. The two-pass form reuses House Robber I unchanged.

3. Optimal - break the circle, run the line robber twice

if n == 1: return nums[0]
return max(line(nums[0:n-1]),        # house n-1 never taken
           line(nums[1:n]))          # house 0 never taken
  1. Any plan skips an end. Houses 0 and n-1 are neighbours, so a valid plan contains at most one of them.
  2. Skipping an end makes a line. Without house n-1, the circle's only extra edge (n-1, 0) is gone and houses 0..n-2 form a plain line. The same holds without house 0.
  3. Each line is House Robber I. Two rolling variables per pass; pass index bounds (lo, hi) instead of copying slices if memory matters.
  4. n = 1 is special. Both ranges would be empty, giving 0, but the single house has no neighbour and can be taken.
O(n)time (two passes)
O(1)space

Why it works: the set of valid circle plans is exactly the union of valid line plans on 0..n-2 and valid line plans on 1..n-1. Every circle plan lies in one of the two sets (it misses house n-1 or house 0), and every plan in either set is valid in the circle (it cannot contain both ends). The best over a union is the max of the two bests.

Proof (optional)

Let P be valid in the circle. If n-1 ∉ P, then P ⊆ {0..n-2} and P has no adjacent pair in the line 0..n-2, so sum(P) ≤ line(0, n-2). Otherwise 0 ∉ P (0 and n-1 are adjacent), so sum(P) ≤ line(1, n-1). Conversely, a valid plan on line 0..n-2 never holds n-1, so the wrap-around edge cannot be violated; the same for 1..n-1. Hence the optimum equals max(line(0, n-2), line(1, n-1)) for n ≥ 2.
