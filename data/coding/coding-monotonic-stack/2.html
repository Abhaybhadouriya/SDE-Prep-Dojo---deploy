Four flavours and one rule for which way the stack goes

There are four questions: next or previous, greater or smaller. You do not need four memorised templates. You need one rule:

Pop whatever the new element answers. Looking for "next greater"? The new element answers every smaller element on top, so pop while top < x. The stack is left decreasing. Looking for "next smaller"? Pop while top > x; the stack is left increasing.

The second choice is when you write the answer:

  • Pop time gives the next element. When x pops top, x is the first element after top that beats it.
  • Push time gives the previous element. After you have popped everything x beats, the element now on top is the nearest earlier element that x does not beat: for "previous smaller", it is the nearest earlier element smaller than x. Read it, then push x.

Look at the strictness column carefully. For "next greater" we pop on <, because an equal value is not greater and cannot be the answer. For "previous greater" we pop on <=, because after popping, the top must be strictly greater than x; an equal value left on top would be the wrong answer. Write down "strictly greater" or "greater or equal" from the problem statement before you pick the operator. Getting this one character wrong is the single most common monotonic stack bug.

You can also get "previous" by running "next" from right to left. Both are fine; pick the one you can explain.

The easy staples

  • Daily Temperatures (LC 739): next greater, but the answer is the distance i - top, which is why we store indexes.
  • Next Greater Element II (LC 503): a circular array. Walk i from 0 to 2n - 1 and use a[i % n], but push only during the first lap. The second lap lets elements near the end find answers near the start. The top-voted solution calls this "loop twice".
  • Next Greater Element I (LC 496): run next greater over nums2, store it in a hash map from value to answer, and look up each value of nums1.
  • Online Stock Span (LC 901): "previous strictly greater" in a streaming class. Each call pops the days with price at most today's price and adds their spans to today's span; store (price, span) pairs so you never need the old indexes.
  • Buildings With an Ocean View (LC 1762): a building can see the ocean if no building to its right is at least as tall. That is "next greater-or-equal does not exist". Meta asks this one often: it appeared in 7 Meta interview reports in our scan of LeetCode Discuss posts (January 2024 to November 2026). A right-to-left scan with a running max also works and uses O(1) space; offer both.
