The greedy stack: building the smallest answer

LC 402, Remove K Digits: given a number as a string and k, delete exactly k digits so the remaining number is as small as possible. Example: "1432219", k = 3 gives "1219".

The greedy rule: a number is smaller when its earlier digits are smaller. If a digit is followed by a smaller digit, deleting the bigger one makes the number smaller at that position, which beats anything we could do later. So scan left to right, keep the digits you have kept so far on a stack, and while the top is bigger than the new digit and you still have deletions, pop it.

  1. '1': the stack is empty. Keep it.
  2. '4': not smaller than the top '1'. Keep it.
  3. '3' is smaller than the top '4'. Keeping 4 in front of 3 is a waste: pop 4 (k = 2). Push 3.
  4. '2' is smaller than the top '3': pop 3 (k = 1). Push 2.
  5. '2' equals the top. An equal digit does not make the number smaller, so do not spend a deletion. Push.
  6. '1' is smaller than the top '2': pop 2 (k = 0). Push 1.
  7. '9': no deletions left, push. The kept digits are 1219. Two cleanup rules: if k is still positive, cut digits from the tail (the stack is non-decreasing, so the tail has the biggest digits); then strip leading zeros, and return "0" if nothing is left.

The loop behind the steps. Invariant: the kept digits are non-decreasing; while removals remain, a smaller digit pops every bigger digit before it, because a smaller digit earlier always gives a smaller number. Lifted unchanged from the tested templates below.

// LC 402: greedy stack keeps the kept digits non-decreasing.
string removeKdigits(const string& num, int k) {
    string st;
    for (char d : num) {
        while (k > 0 && !st.empty() && st.back() > d) { st.pop_back(); k--; }
        st.push_back(d);
    }
    st.resize(st.size() - min<size_t>(k, st.size()));       // leftover deletions cut the tail
    size_t nz = st.find_first_not_of('0');
    return nz == string::npos ? "0" : st.substr(nz);
}
# ---- 4. GREEDY STACK: keep the answer string itself monotone ----
def remove_k_digits(num, k):
    """LC 402: smallest number after deleting k digits."""
    stack = []
    for d in num:
        while k and stack and stack[-1] > d:      # a bigger digit before a smaller one: drop it
            stack.pop()
            k -= 1
        stack.append(d)
    if k:
        stack = stack[:-k]                        # still have deletions: cut the tail
    return "".join(stack).lstrip("0") or "0"

This is the same stack as before, but now the stack is the answer, not a waiting room. The pop condition carries an extra budget (k > 0), and the stack is kept non-decreasing.

The family

  • Remove Duplicate Letters (LC 316, same as LC 1081): the smallest string that contains each distinct letter exactly once, as a subsequence. Pop a bigger letter on top only if it appears again later (last[top] > i); skip letters already on the stack. Here the "budget" is "can I get this letter back later?"
  • Find the Most Competitive Subsequence (LC 1673): the smallest subsequence of length k. Pop while the top is bigger and enough elements remain to still reach length k: len(stack) - 1 + (n - i) >= k. This is LC 402 with "delete n - k".
  • Create Maximum Number (LC 321): the largest subsequence of length i from one array and k - i from the other, then merge. Each part is the greedy stack with the comparison flipped.

Interviewers often ask for the proof of the greedy step. Say: "Take the first position where the kept digits go down, digit d followed by a smaller e. Any answer that keeps d at that position is beaten by deleting d instead, because the number then has e at that position and the prefix before it is unchanged. So deleting d is never worse."
