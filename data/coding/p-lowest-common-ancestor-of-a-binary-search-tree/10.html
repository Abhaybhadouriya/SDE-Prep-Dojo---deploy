Technique: use a BST's ordering to discard one whole subtree at every step.

Closest match: LC 236 Lowest Common Ancestor of a Binary Tree Medium

  • Same: return the deepest node that has both p and q below it.
  • Different: no ordering, so you cannot know which side p is on without looking.
  • So: post-order DFS: a node whose left and right searches both return non-null is the LCA. O(n). See our write-up.
