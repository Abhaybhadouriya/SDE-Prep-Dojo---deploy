Dry run

Example 3: haystack "abababd", needle "ababd", lps = [0, 0, 1, 2, 0].

  1. Before scanning, build the lps table of the needle (figure above). Align the needle at 0.
  2. The first four characters match: j climbs to 4. The next needle char is d.
  3. Mismatch at i = 4. Brute force would restart at index 1 and read text[1..4] again.
  4. KMP falls back instead: the last 2 matched chars ("ab") are also the needle's first 2 chars, so the needle slides to start 2 with j = 2 already matched. i does not move back.
  5. Retry the same text char against needle[2]: it matches, j = 3.
  6. Next char matches too, j = 4.
  7. j reaches the needle length: the match ends at i = 6 and starts at 2. The text pointer moved forward 7 times in total: O(n + m).
