The problem (in our words)

You get two strings, haystack and needle. Return the smallest index i such that haystack contains needle starting at position i, or -1 if needle never appears in haystack.

Signature: int strStr(String haystack, String needle).

  • 1 <= haystack.length, needle.length <= 104
  • Both strings contain only lowercase English letters.

Practice it: LeetCode 28 · GfG Implement strstr

Constraints tell you: n·m ≤ 108 character comparisons in the worst case, which a tight C++/Java loop survives (and LeetCode accepts brute force). So the follow-up, not the judge, is why KMP matters: an interviewer asks "can you do it in linear time?". Needle is never empty here (the classic "empty needle returns 0" rule does not apply). The needle can be longer than the haystack: return -1 without reading past the end.
