Common mistakes

Unsigned loop bound in C++. i <= haystack.size() - needle.size() underflows to a huge number when the needle is longer. Cast to int first.

Building lps with k = 0 on a mismatch. The fallback inside the table build is also k = lps[k - 1] in a while loop; resetting to 0 gives wrong tables for needles like "aabaaab".

Moving i back after a fallback. In KMP the text index never decreases; the retry happens with the same i and a smaller j.

Off-by-one in the answer. When j == m after reading text[i], the match starts at i - m + 1, not i - m.

Calling the built-in and stopping there. indexOf is fine in production, but in an interview it answers nothing; say you would use it, then implement.
