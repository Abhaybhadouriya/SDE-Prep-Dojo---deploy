Interview follow-ups

What is the complexity of the brute force, and when is it actually bad?

O((n - m + 1)·m). It is near-linear on random text because mismatches come early; it is quadratic on inputs with long partial matches, e.g. "aaaa...a" with needle "aa...ab".

How to answer

Give the bound and the worst-case input; that motivates KMP.

Likely follow-ups
  • Can you make it linear? (KMP / Z / Rabin-Karp.)
Return all occurrences, including overlapping ones.

KMP: on j == m, record i - m + 1 and continue with j = lps[m - 1]. For "aa" in "aaaa" this gives 0, 1, 2. Still O(n + m).

How to answer

Show the one-line change after a full match.

Likely follow-ups
  • Non-overlapping occurrences only? (Reset j = 0 after a match.)
Explain Rabin-Karp and its failure mode.

Polynomial hash with base B and a large prime mod; slide by removing text[i-m]·B^(m-1), multiplying by B and adding the new char. Verify with a real compare on hash equality. Expected O(n + m); adversarial or unlucky collisions push it toward O(n·m). Two moduli make collisions negligible.

How to answer

Write the slide update, mention verification on equality.

Likely follow-ups
  • Many patterns of the same length? (Put their hashes in a set: one pass over the text.)
Search for 10,000 patterns at once in a stream.

Aho-Corasick: build a trie of all patterns, add failure links (the multi-pattern lps), then scan the stream once; output links report every pattern ending at each position. O(total pattern length + n + matches).

How to answer

Say "KMP's lps on a trie", sketch building failure links by BFS.

Likely follow-ups
  • Memory of the automaton with 26 children per node vs a map.
What does the standard library use?

Implementations vary: glibc's strstr uses the Two-Way algorithm (linear, O(1) space); Java's indexOf is a simple scan with a first-char search; CPython's find uses a Boyer-Moore-Horspool style hybrid and, since 3.10, Two-Way for long needles. Saying "it depends, and it is usually sublinear on average" is enough.

How to answer

Show awareness, do not bluff details.

Likely follow-ups
  • Why can Boyer-Moore skip characters? (It compares from the needle's end and jumps on a bad character.)
