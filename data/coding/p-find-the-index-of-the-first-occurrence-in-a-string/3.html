Recognise the pattern

Cue: "find a pattern in a text", "is s a rotation of t", "smallest repeating unit", "longest prefix that is also a suffix" -> prefix function (KMP lps) or Z-function. Rabin-Karp (rolling hash) is the alternative when you need many patterns of one length or substring equality checks.

"abcd"0 0 0 0No self-overlap: after a mismatch nothing survives.
"aaaa"0 1 2 3Shift by one keeps 3 matched chars.
"ababd"0 0 1 2 0"abab" ends with its own prefix "ab".
