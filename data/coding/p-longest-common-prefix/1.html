The problem (in our words)

Given an array of strings strs, return the longest string that is a prefix of every string in the array. If they share no prefix, return the empty string "".

Signature: String longestCommonPrefix(String[] strs).

  • 1 <= strs.length <= 200
  • 0 <= strs[i].length <= 200
  • strs[i] contains only lowercase English letters if it is non-empty.

Practice it: LeetCode 14 · GfG Longest Common Prefix of Strings · TUF article

Constraints tell you: at most 200 × 200 = 40,000 characters, so any approach up to O(S log n) is fine; the interview is about clean stopping conditions and stating the complexity honestly. Strings can be empty, and there is always at least one string.
