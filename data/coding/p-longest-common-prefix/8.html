Common mistakes

No length check on the other strings. w[i] != c alone reads past the end of a shorter string: an exception in Java/Python, undefined behaviour in C++ (std::string's operator[] at size() returns '\0', which happens to work, but one past that does not).

Building the answer with += in a loop. In Java that is O(m²) string copies. Return a substring of strs[0] once you know the length.

Using min(strs) as "the shortest string". In Python min on strings is lexicographic, not by length. (It still works for the sort trick, because there you want the lexicographic min and max.)

Saying O(n·m) without defining m. State it as O(S), the total characters, or n × length of the shortest string; interviewers ask.
