Recognise the pattern

When you see "common prefix of all", think scan position by position across all strings (vertical scan). If the question is asked many times or about pairs ("longest common prefix between any pair", autocomplete), think trie. If you may sort, only the smallest and the largest string matter.

Try a few tiny inputs:

InputAnswerNote
["ab"]"ab"One string is its own common prefix.
["ab", ""]""An empty string ends at column 0.
["abc","abd","ab"]"ab"A later string is the shortest: you must check every string's length, not only the first one's.
