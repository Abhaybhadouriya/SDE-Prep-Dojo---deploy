Common mistakes

Marking visited on dequeue. The same word can then be queued many times by different parents in one level; on dense lists that is a time-limit error. Remove it from the set when you enqueue it.

Off by one. The answer counts words, so a direct neighbour gives 2. Start the counter at 1 with beginWord in the queue.

Using a list for the dictionary. if cand in wordList on a list is O(N) per lookup, turning the BFS into O(N² · L · 26). Convert it to a hash set first.

DFS for the shortest path. DFS finds a ladder, not the shortest one, and exploring all ladders is exponential.

Bidirectional without the size swap. Alternating sides blindly can grow a huge frontier while the other is tiny; always expand the smaller set.
