Common mistakes

Skipping the verification pass. The vote only guarantees "every real answer is a survivor". On [1, 2, 3, 4] the survivor 4 is not an answer.

Testing "count is 0" before "matches the other slot". The same value lands in both slots and a real candidate disappears (see the hint above).

Same placeholder for both slots. With cand1 = cand2 = 0 and input [0, 0, 0], the verification counts 0 for both and reports [0, 0]. Use different placeholders, or verify with else if and dedupe.

Using >= n/3 or n/3 as a float. The task is strictly more than ⌊n/3⌋; use integer division.
