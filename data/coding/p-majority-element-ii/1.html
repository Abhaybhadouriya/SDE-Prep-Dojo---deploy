The problem (in our words)

A survey produced an integer array nums of size n. Return every value that appears more than ⌊n / 3⌋ times. The answer may be empty, may have one value or two values, and may be returned in any order.

  • Input: an integer array nums.
  • Output: a list of the qualifying values. Signature: List<Integer> majorityElement(int[] nums).
  • Unlike Majority Element I, no answer is guaranteed to exist.

Constraints

  • 1 <= nums.length <= 5 * 10^4
  • -10^9 <= nums[i] <= 10^9

Follow-up: solve it in linear time and O(1) extra space.

Practice it: LeetCode 229 - Majority Element II · GfG - Majority Element, more than n/3 · takeuforward

Constraints tell you: n ≤ 5 × 10^4 means a hash map or sorting easily passes, so the interviewer is really testing the O(1) space follow-up. Values span ±10^9, so no counting array indexed by value. "Any order" and "possibly empty" mean the verification pass is mandatory, not optional.
