Closest match: LC 279 Perfect Squares Medium

  • Same: fewest reusable items summing to exactly n; best[a] = 1 + min(best[a - item]).
  • Different: the "coins" are the squares 1, 4, 9, ... ≤ n, and 1 is always present, so there is always an answer.
  • So: the identical loop with items = squares, O(n√n); no -1 case.

How to recognise it:

  • A target sum, a set of item sizes, unlimited copies of each, and "fewest", "most" or "how many ways".
  • A greedy counter-example exists, or the problem says "return -1 if impossible".

Practice order:

  2. This problem: memo first, then the table; check both on random tests.
