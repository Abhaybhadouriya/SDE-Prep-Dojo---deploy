The problem (in our words)

You get an integer array coins of distinct coin values and an integer amount. You may use each coin value any number of times. Return the fewest coins whose values add up to exactly amount. If no combination makes that amount, return -1.

Signature: int coinChange(int[] coins, int amount).

Constraints

  • 1 <= coins.length <= 12
  • 1 <= coins[i] <= 231 - 1
  • 0 <= amount <= 104

Practice it: LeetCode 322 · GfG Coin Change (Minimum Coins) · TUF Minimum Coins

Constraints tell you: amount ≤ 104 and at most 12 coins: a table of 104 cells × 12 coins = 1.2·105 steps, trivial. Coins can be as large as 231 - 1, so never compute a - c or a + c before checking c <= a (overflow), and never use INT_MAX as "infinity" and then add 1 to it.
