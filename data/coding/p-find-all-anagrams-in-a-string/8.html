Common mistakes

Recording the wrong index. If your loop variable is the right edge r, the start is r - m + 1. Recording r returns end positions.

Comparing arrays with == in Java. int[] == int[] compares references; use Arrays.equals (C++ vector == and Python list == do compare contents).

Testing before the window is full. With a "for each right edge" loop, only test once r >= m - 1; a partly loaded window can never match but the index arithmetic goes negative.

Using a hash map and forgetting to delete zero keys. If you compare maps directly, a key with value 0 makes two equal multisets look different. Delete keys that reach 0, or use the array.

Rebuilding the window with substring calls. s.substring(i, i+m) per step is O(m) each, back to O(n · m).
