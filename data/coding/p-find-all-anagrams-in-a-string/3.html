Recognise the pattern

When you see "all start indices of anagrams / permutations of p in s", think a fixed window of length len(p) with a count array, and record a start whenever the counts match.

When you see "does the window's multiset equal a target multiset?" asked at every position, think a diff array plus a counter of zero entries, so each test is O(1).

It is LC 567 (Permutation in String) with one change: do not stop at the first match, collect all of them. The window size never changes, so there is no "shrink while" loop: each step is exactly one letter in and one letter out.

Pattern: Sliding window > fixed-size window > fixed window frequency match · Lessons: Fixed sliding window, Fixed window frequency match, Canonical keys for anagrams
