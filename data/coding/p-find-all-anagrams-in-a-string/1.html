The problem (in our words)

You are given a text s and a pattern p, both lowercase. Return the list of every index i such that the substring of s starting at i with length len(p) is an anagram of p (the same letters with the same counts, in any order). The indices may be returned in any order; if there are none, return an empty list.

Signature: List<Integer> findAnagrams(String s, String p).

Constraints

  • 1 <= s.length, p.length <= 3 · 10^4
  • s and p contain only lowercase English letters.
  • p may be longer than s (then the answer is empty).

Practice it: LeetCode 438 - Find All Anagrams in a String · GfG - Count Occurrences of Anagrams (return the count instead of the list)

Constraints tell you: with n and m up to 3 · 10^4, recounting every window is O(n · m) ≈ 9 · 10^8 in the worst case (m about n/2), too slow. A 26-letter alphabet means the window state is a 26-slot array; sliding it costs O(1) per step, so O(n) or O(26 · n) is the target. Answers can overlap ("aaaa" with "aa" gives 0, 1, 2), so you cannot jump past a match.
