Approaches: brute → better → optimal

Hint 1

What single object describes all anagrams of p at once?

Hint 2

Windows at i and i+1 share len(p) - 1 letters. What do you need to update?

1. Brute force - check every window from scratch

Idea: for each start i in 0 .. n - m, sort (or count) s[i .. i+m-1] and compare with sorted p.

O((n - m + 1) · m)time with counting (sorting adds log m)
O(26)space (O(m) for sorting)

What is wasted: each window is recounted although it shares all but one letter with the previous one.

2. Better - slide the counts, compare 26 slots

Idea: keep two 26-slot arrays, one for p and one for the window. Load the first window; then for each step add the entering letter, remove the leaving one, and compare the arrays. This is the most common accepted solution.

O(m + 26 · n)time
O(26)space

3. Optimal - diff array and a matched counter

diff = count(p) - count(window)            # all 0  <=>  window is an anagram
matched = number of letters with diff == 0  # so the test is matched == 26
update(c, d): if diff[c] == 0: matched -= 1; diff[c] += d; if diff[c] == 0: matched += 1
  1. Load the first window. diff[c] += 1 for each letter of p, diff[c] -= 1 for each letter of s[0 .. m-1]. Count the zeros: that is matched.
  2. Test, then slide. At start i, if matched == 26, record i. Then the letter s[i + m] enters (diff -1) and s[i] leaves (diff +1).
  3. Keep matched exact. An update can only move one entry onto 0 or off 0; checking before and after the change covers both.
  4. Stop after the last window, start n - m, which is tested before the loop exits.
O(n + m)time: m to load, O(1) per slide
O(26)extra space (the answer list aside)

Why it works: two strings of equal length are anagrams exactly when their letter counts agree, that is when all 26 entries of diff are 0. matched is defined as the number of zero entries; it is correct after the setup and every update preserves it, because a ±1 change can only cross 0 from one side. Every start 0 .. n - m is tested exactly once, so the output is exactly the set of anagram starts, in increasing order.

The most voted community post frames this as a general "substring search" template (a hash map plus a counter of satisfied letters, expand right, shrink left); for a fixed length the shrink step is always exactly one letter, which is what this version writes directly.
