Technique: a fixed window whose state is a frequency table, tested against a target table in O(1) with a matched counter.

Closest match: GfG Count Occurrences of Anagrams · CF 144C Anagram Search CF 1500

  • Same: every window of len(p) is tested for "same counts as p".
  • Different: GfG wants only the number of windows; CF 144C adds '?' wildcards in s.
  • So: count instead of collecting; for '?', skip it in the counts and accept a window when no letter exceeds p's count.
