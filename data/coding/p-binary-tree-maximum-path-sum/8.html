Common mistakes

Initialising best to 0. For [-3] the answer is -3, but a 0 start returns 0 (the empty path, which is not allowed). Start from root.val or INT_MIN.

Returning left + right + val to the parent. That is a fork with three branches at v once the parent is added. Return val + max(left, right); the two-sided value is only recorded.

Clamping the node itself. Writing max(node.val, 0) + l + r for the bend lets the path "skip" its top node, which joins two arms that are not connected. Only child arms may be dropped; the top node is always on the path.

Only checking paths through the root. Example 2: the best path 6 - 10 never touches the root. The comparison must happen at every node.

Python recursion limit. The default limit of 1000 crashes on a deep, skewed tree. Call sys.setrecursionlimit or write an iterative post-order.
