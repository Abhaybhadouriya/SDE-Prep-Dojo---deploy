The story

Explain like I'm 5

A family tree of towns is joined by roads; each town gives you coins (or takes a toll if its number is negative). You may drive any route that never visits a town twice, starting and ending anywhere, and you keep the net coins. Any such route climbs up to one "top" town and then goes down the other side. So ask every town: "if you were the top, what is the best you can do?" It needs the best road down its left side and the best road down its right side, and it skips a side that would lose money.

The difficulty is that each node must give two different answers: one for "the path stops bending here" (both sides) and one for "my parent wants to extend me" (one side only).

From your world

It is the same post-order aggregation as summing sizes up a directory tree or a cgroup hierarchy, except each node returns a value to its parent and updates a global statistic. Think of a per-subtree "best chain" metric that is reported upward, while the global maximum is kept in one shared counter.
