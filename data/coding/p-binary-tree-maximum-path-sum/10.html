How to recognise it:

  • "Path" between any two nodes (not only root-to-leaf) and a best value over all paths.
  • The answer at a node needs both subtrees, but the parent can only use one of them.

Practice order:

  1. Warm-up: 543 Diameter of Binary Tree (same template, no negatives).
  2. This problem: write the O(n²) version, then the one-pass DFS; compare on random trees.
  3. Then 687 Longest Univalue Path and 2538 (general tree, harder).
