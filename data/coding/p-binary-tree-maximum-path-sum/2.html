Input rootOutputWhy
[2,-1,3]52 + 3. Adding the -1 child would only lower it.
[-5,4,10,null,null,6,-3]16The path 6 - 10. Going through the root gives 4 + (-5) + 10 + 6 = 15, which is worse: the best path need not touch the root.
[-3]-3A path must contain at least one node, so an all-negative tree returns its largest value, not 0.
