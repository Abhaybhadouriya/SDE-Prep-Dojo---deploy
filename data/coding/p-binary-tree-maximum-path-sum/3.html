Recognise the pattern

When you see "best path anywhere in a tree" (sum, length, same values), think a bottom-up DFS where each node returns the best chain going down from it and records the best path that bends at it. Same template as Diameter of Binary Tree (count edges instead of sums) and Longest Univalue Path.

Try a few tiny trees to see when a side should be dropped:

TreeBest pathNote
[1,2,3]6Both arms positive: bend at the root.
[1,-2,3]4Left arm negative: clamp it to 0 (do not take it).
[-10,9,20]20The root costs more than the 9 gains: the answer is the single node 20.
[-2,-1]-1All negative: the best single node.
