Common mistakes

Forgetting to pop. Without path.pop(), the second branch sees "dj" + "k" and produces "djk". Every append inside the loop needs a matching pop.

Storing the buffer itself. In Java/Python, out.add(path) stores a reference to the shared buffer, so every entry ends up as the same (finally empty) value. Copy it: path.toString(), "".join(path).

Off-by-two in the key table. Indexing a table that starts at "abc" with digit - '0' maps 2 to "ghi". Either pad indices 0 and 1 with empty strings (as we do) or subtract '2'.

Claiming O(3n). Keys 7 and 9 have four letters, so the bound is O(4n · n); the n is the cost of copying each word.
