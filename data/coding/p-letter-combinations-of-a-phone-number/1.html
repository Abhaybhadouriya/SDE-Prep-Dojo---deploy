The problem (in our words)

You get a string digits made of the characters '2' to '9'. Each digit stands for the letters printed on that key of a classic phone pad:

23456789
abcdefghijklmnopqrstuvwxyz

Return every string you can form by choosing exactly one letter for each digit, in the order of the digits. The answer may be returned in any order. The key 1 has no letters and never appears.

Signature: List<String> letterCombinations(String digits).

Constraints:

  • 1 <= digits.length <= 4
  • digits[i] is a digit in the range ['2', '9'].

Older versions of the problem allowed an empty string, with the expected answer []. Our code handles it.

Practice it: LeetCode 17 · GfG Possible Words From Phone Digits

Constraints tell you: n <= 4 and at most 4 letters per key, so the output has at most 44 = 256 words. You must produce all of them, so any correct method is "fast"; the interview is about writing the enumeration cleanly, and about saying why exponential time is unavoidable here (it is the output size).
