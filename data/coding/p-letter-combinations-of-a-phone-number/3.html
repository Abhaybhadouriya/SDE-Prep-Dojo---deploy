Recognise the pattern

When you see "return all combinations / strings / ways" + a small input (n <= 10 or so), think backtracking. When every position has an independent list of options (no "used" set, no sum limit), it is a plain Cartesian product: one recursion level per position, one branch per option.

The count is a product of the key sizes, which is exactly the number of leaves of a tree with one level per digit.
