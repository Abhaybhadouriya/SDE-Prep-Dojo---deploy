Approaches: brute → better → optimal

Hint 1

If you knew the input always had exactly two digits, you would write two nested loops. What do you do when the number of loops is not fixed?

Hint 2

Write a function that handles "digit i onward", given the letters already chosen for digits 0..i-1.

1. Brute force - fixed nested loops

Idea: since n <= 4, write four nested loops and skip the levels that do not exist (or switch on n). It works, but it is not what the interviewer wants to see: the code does not generalise and is easy to get wrong.

O(4n · n)time
O(1)extra space

What is wasted: nothing in time, but a loop per digit hard-codes n. -> rung 2 removes that.

2. Better - iterative product (BFS by levels)

Idea: start with [""]. For each digit, replace every partial word w with w + each letter of that key. After the last digit, the list is the answer. This is the most-voted community answer (a FIFO queue) in another shape.

words = [""]
for d in digits:
    words = [w + c for w in words for c in KEYS[int(d)]]
O(4n · n)time
O(4n · n)space (all partial words of a level)

Trade-off: simple and correct; it builds every partial word as a new string. Equal in big-O to rung 3, and fine to present. Rung 3 is the backtracking template that transfers to harder problems.

3. Optimal - backtracking with one shared path

def build(i):
    if i == len(digits): out.append("".join(path)); return
    for c in KEYS[int(digits[i])]:
        path.append(c); build(i + 1); path.pop()
  1. State = (i, path). path holds one chosen letter for each digit before position i.
  2. Choose: for each letter of key digits[i], append it to path.
  3. Explore: recurse with i + 1.
  4. Un-choose: pop the letter, so the buffer is clean for the next branch.
  5. Base case: i == n means every digit has a letter: copy path into the output. That copy is the only place a string is built.
O(4n · n)time
O(n)extra space (stack + path)

Why it works: the recursion tree has one level per digit and one child per letter, so its leaves are in one-to-one correspondence with the words. A DFS visits each leaf once; the tree has at most 4n leaves and fewer than 2 · 4n nodes in total, so the work outside the leaf copies is O(4n), and the copies add O(n) each.

Proof (optional)

By induction on n - i: build(i) with a fixed prefix p of length i appends exactly the words p + s for every s in the product of keys(digits[i..n-1]), and returns with path == p. Base i = n: it appends p. Step: for each letter c, path becomes p + c, the call appends all p + c + s', and restores p + c; the pop restores p. The union over c is exactly the product. With i = 0 and p = "" that is the full answer, each word once.
