  • Cue: "all combinations", one independent choice per position, small n -> backtracking product.
  • Insight: one tree level per digit, one branch per letter; each leaf is one word.
  • State: i (next digit), path (letters so far), out (words); key table padded at 0 and 1.
  • Trap: pop after recursing; copy the path at the leaf; "" gives [] not [""].
  • Cost: O(4^n · n) time = output size; O(n) extra space.

No digits means no combinations. A naive backtrack adds the empty path as one leaf, giving [""].
