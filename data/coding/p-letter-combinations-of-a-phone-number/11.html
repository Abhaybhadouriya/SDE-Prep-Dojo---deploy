Interview follow-ups

Do it without recursion.

Use the iterative product (rung 2), or count in a mixed radix: keep an index array idx[0..n-1], emit the word, then increment the last index with carry, like an odometer whose wheels have 3 or 4 positions.

How to answer

The odometer version is O(n) extra space and emits words in lexicographic order.

Likely follow-ups
  • Make it a lazy iterator with hasNext() / next().
Only return combinations that are real words from a dictionary.

Walk a trie of the dictionary alongside the DFS: at depth i, only follow letters that are children of the current trie node. Dead prefixes are cut at once, so the work is bounded by the dictionary, not by 4n. For a single lookup the other way round, map every dictionary word to its digit string in a hash map.

How to answer

Say "prune with a trie": it is the same tree, with branches removed.

Likely follow-ups
  • T9 autocomplete: rank the matches by frequency (a heap per trie node).
Just return how many combinations there are.

Multiply the key sizes: 3 for most digits, 4 for 7 and 9. O(n) time and O(1) space; no enumeration. If digits 0 and 1 may appear (no letters), the count is 0 if they must produce a letter, or they are skipped if they map to themselves.

How to answer

Point out that counting is cheap and listing is the expensive part.

Likely follow-ups
  • Pressing a key k times picks its k-th letter (LC 2266): now it is a DP on runs.
The input can have 20 digits. What breaks?

The output: up to 420 ≈ 1012 words. Do not store them; stream them to a callback or a lazy iterator, or return the count, or the k-th word directly (mixed radix: divide k by the key sizes from the right).

How to answer

Separate the time (unavoidable if every word is needed) from the memory (avoidable).

Likely follow-ups
  • Return the k-th word in lexicographic order in O(n).
Why is the space O(n) when the output is 4n · n?

"Extra space" excludes the output, which every method must hold. Beyond it, the DFS keeps the recursion stack of depth n and one path buffer of length n.

How to answer

Always say which space you count; interviewers check that you know the difference.

Likely follow-ups
  • And the iterative version? (It holds a whole level of partial words.)
