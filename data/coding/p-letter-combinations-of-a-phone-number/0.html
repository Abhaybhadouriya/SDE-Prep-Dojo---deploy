The story

Explain like I'm 5

An old phone keypad prints letters on each number key: 2 is "abc", 3 is "def", up to 9 which is "wxyz". Someone texts you the digits they pressed, "35". Which words could they have meant? For the first key pick d, e or f; for the second pick j, k or l. Every way of picking one letter per key is a possible word: dj, dk, dl, ej and so on.

This is a "make one choice per position, list every full combination" problem: the smallest backtracking problem there is, and the template for Subsets, Permutations and Combination Sum.

From your world

It is a nested loop whose depth is only known at run time, like walking every path of a radix tree or enumerating every combination of option flags for a test matrix. Recursion (or an explicit stack) gives you the variable number of loops; the shared path buffer is your one scratch frame, pushed and popped like a stack.
