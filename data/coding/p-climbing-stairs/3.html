Recognise the pattern

When you see "count the ways" to reach a target with a few allowed moves, where order matters, think 1-D DP over the position: ways[i] = sum of ways[i - move] for each move. Two moves of sizes 1 and 2 -> Fibonacci. "Minimum cost" instead of "count" -> the same shape with min instead of +.

Try a fewWaysPattern
n = 11[1]
n = 22[1,1], [2]
n = 33= 2 + 1
n = 45= 3 + 2
n = 58= 5 + 3: each value is the sum of the two before
