Dry run

Example 3, n = 6. Green arrow = climbs whose last move is a 1-step; accent arrow = last move a 2-step.

  1. Base cases: ways[0] = 1 (the empty climb: you are already there) and ways[1] = 1 (one single step).
  2. i = 2: the last move came from step 1 (a 1-step) or from step 0 (a 2-step). ways[2] = 1 + 1 = 2.
  3. i = 3: from step 2 (2 ways) or from step 1 (1 way). ways[3] = 2 + 1 = 3.
  4. i = 4: ways[3] + ways[2] = 3 + 2 = 5. These are the five climbs of example 1.
  5. i = 5: ways[4] + ways[3] = 5 + 3 = 8.
  6. i = 6: ways[5] + ways[4] = 8 + 5 = 13. Answer for n = 6 is 13.
  7. Each cell read only the two cells before it, so two variables (prev1, prev2) replace the array: O(1) space.
