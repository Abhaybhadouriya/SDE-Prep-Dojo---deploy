  • Cue: count ordered ways to reach n with moves of 1 or 2 -> Fibonacci-style 1-D DP.
  • Insight: split by the LAST move: ways[n] = ways[n-1] + ways[n-2], no overlap.
  • State: prev2 = ways[i-2], prev1 = ways[i-1]; base ways[0] = ways[1] = 1.
  • Trap: base cases (n=2 gives 2); update order; recursion without memo times out.
  • Cost: O(n) time, O(1) space; recursion O(1.62^n); matrix power O(log n).
ways = [0] * (n + 1); ways[0] = 1
for i in range(1, n + 1):
    for m in moves:                 # allowed step sizes
        if i - m >= 0: ways[i] += ways[i - m]
return ways[n]                      # keep only the last max(moves) cells
