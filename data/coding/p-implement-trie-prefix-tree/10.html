How to recognise it:

  • The query is about how strings begin, and there are many strings or many queries.
  • You need the shortest or longest stored prefix of something, or the stored words below a prefix.

Practice order:

  1. This problem: write the node, insert and one shared walk.
  2. Then 211 (wildcard DFS) and 648 (stop at the first end flag).
  3. Then 212 Word Search II (trie + grid backtracking), the classic hard follow-up.
