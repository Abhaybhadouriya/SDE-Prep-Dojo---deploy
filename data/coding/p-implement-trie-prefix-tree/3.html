Recognise the pattern

Cue: many strings + queries about prefixes ("starts with", "autocomplete", "shortest root", "longest common prefix") + a small fixed alphabet -> trie. If the queries are only exact-match, a hash set is enough; the word "prefix" is what earns the trie.

Try a few calls on a set of words and watch what each structure has to do:

Query on {car, cat, cart}Hash setTrie
search("cat")✓ one hash lookup✓ walk 3 letters
startsWith("ca")✗ has to scan every word✓ walk 2 letters
startsWith("cx")✗ scans every word to say no✓ fails after 2 letters
