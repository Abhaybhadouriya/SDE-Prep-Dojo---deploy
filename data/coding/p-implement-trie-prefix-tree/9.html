  • Cue: many words + "starts with" / autocomplete / shortest root -> trie.
  • Insight: one node per distinct prefix; a query is a walk of its own length.
  • State: node = child[26] (or a map) + isEnd flag; root = empty prefix.
  • Trap: search needs isEnd, startsWith does not; read paths must not create nodes.
  • Cost: O(L) per call; space O(total letters × 26); hash set prefix scan O(N·L).
def walk(s):
    cur = root
    for ch in s:
        cur = cur.child.get(ch)
        if cur is None: return None
    return cur

  2. 0
  3. 1
  4. 2
c, a and r already exist; only the e below r is new.

The cost of startsWith(p) depends on...

  1. the length of p only
  2. the number of stored words
  3. the total stored letters
  4. the alphabet size times the number of words
The walk visits at most |p| + 1 nodes, whatever is stored.
