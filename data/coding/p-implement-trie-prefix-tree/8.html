Common mistakes

search returns true for a prefix. Returning "the walk finished" from search makes search("boa") true after inserting only "board". The end flag is the whole difference between the two queries.

Queries that create nodes. In C++, children[ch] on a std::unordered_map inserts an empty entry; in Python, setdefault in search does the same. The answers stay right but memory grows with every failed query. Use find / .get in the read path.

Marking the end on the wrong node. Setting isEnd on the node before the last letter, or on a freshly created child after the loop, is an off-by-one that only shows up for one-letter words.

Using a char as an index without the offset. child[ch] instead of child[ch - 'a'] indexes out of bounds (ASCII 97-122 in a 26-slot array).

Copying a C++ trie that owns raw pointers. A default copy shares the nodes and the second destructor frees them twice. Delete the copy constructor (as our code does) or use unique_ptr children.
