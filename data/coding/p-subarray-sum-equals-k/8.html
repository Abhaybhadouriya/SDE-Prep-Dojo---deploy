Common mistakes

Using a sliding window. It passes all-positive tests and fails as soon as a negative appears; say why it fails before the interviewer asks.

Forgetting seen[0] = 1. Every subarray that starts at index 0 is missed: [3], k = 3 returns 0.

Inserting before looking up. With k = 0 every prefix matches itself, so the answer is inflated by n.

Storing a set (or an index) instead of a count. Prefix values repeat (zeros, negatives); each earlier occurrence is a different start. [0,0,0] needs 6, a set gives 3.

Python's defaultdict lookup inserts keys. seen[run - k] on a defaultdict adds a 0 entry each miss; harmless for the answer but grows memory. Use .get(key, 0).
