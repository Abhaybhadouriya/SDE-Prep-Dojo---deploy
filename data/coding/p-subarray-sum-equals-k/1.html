The problem (in our words)

You are given an integer array nums (readings that can be positive, zero or negative) and an integer k. Return the number of subarrays whose elements add up to exactly k. A subarray is a contiguous, non-empty run of elements; two subarrays are different if they start or end at different indices, even when their values are the same.

Signature: int subarraySum(vector<int>& nums, int k).

Constraints:

  • 1 <= nums.length <= 2 * 104
  • -1000 <= nums[i] <= 1000
  • -107 <= k <= 107

Practice it: LeetCode 560 · TUF: count subarrays with given sum

Constraints tell you: n = 2·104 means O(n2) = 4·108 simple additions; it may pass in C++ but times out in most languages, and the interviewer wants O(n). Values down to -1000 mean the running sum is not monotonic, which kills two pointers. The largest possible |sum| is 2·104 x 1000 = 2·107, so a 32-bit int is safe.
