Recognise the pattern

When you see "count (or find) subarrays with sum = k" + values that can be negative, think prefix sum + hash map of earlier prefixes. All values positive and "longest/shortest with sum ≤ k" -> sliding window instead. "Divisible by k" -> the same map keyed by prefix mod k.
