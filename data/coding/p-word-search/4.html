Approaches: brute → better → optimal

Hint 1

Write a function "can word[k:] be spelled starting at cell (i, j)?" What must be true of board[i][j]? What do you call next?

Hint 2

To forbid reuse you need to know which cells are on the current path. Mark the cell before recursing and unmark it after. Do you need a separate visited array?

1. Brute force - enumerate paths with a copied visited set

Idea: from every cell, generate all simple paths of length L by DFS, passing a new copy of the visited set to each call, and compare the spelled string with the word only at the end.

O(m·n·4L·L)time
O(L²)space

What is wasted: paths whose first letters already differ from the word are extended anyway, and copying the visited set costs O(L) per call. -> rung 2.

2. Better - DFS that stops at the first wrong letter

Idea: compare board[i][j] with word[k] on entry and return false at once on a mismatch. Use one shared visited matrix: set it before the recursive calls and clear it after (backtrack).

O(m·n·3L)time
O(m·n + L)space

What is wasted: the extra m·n visited matrix (you can mark the board itself), and whole searches that could be refused before starting (the board lacks a letter, or the first letter is everywhere). -> rung 3.

3. Optimal - in-place marking + two prunings

def dfs(i, j, k):
    if out_of_board(i, j) or board[i][j] != word[k]: return False
    if k == len(word) - 1: return True
    board[i][j] = "#"                        # on the current path
    ok = any(dfs(i + di, j + dj, k + 1) for di, dj in DIRS)
    board[i][j] = word[k]                     # backtrack
    return ok
  1. Mark in place. Overwrite the cell with '#' (no letter equals it), so the mismatch test also rejects cells already on the path. Restore it before returning. O(L) extra space: just the recursion.
  2. Prune 1: letter counts. If the word needs three e's and the board has two, return false without searching. O(m·n + L).
  3. Prune 2: start from the rarer end. A path spelled forwards is the same path backwards. If the board has many copies of word[0] and few of the last letter, reverse the word: far fewer searches survive the first comparison. This kills the classic worst case "aaaaaaaaab" on a board full of a's.
  4. Short-circuit. Stop at the first true; || / or already does it.
O(m·n·3L)time, worst case
O(L)space

Why it works: DFS explores every simple path that matches a prefix of the word, and only those, because any path to the full word must pass through matching prefixes. The mark/unmark pair keeps the invariant "cells marked = cells on the current path", so reuse is impossible on the current path and allowed on later ones. The prunings never reject a word that exists: missing letters make a path impossible, and reversing only changes the direction a path is read.

Proof of the 3L bound (optional)

The first letter can try up to 4 neighbours. Every later step came from one neighbour, which is marked, so at most 3 fresh directions remain. A search from one start therefore visits at most 4 · 3L-2 leaves, and there are m·n starts: O(m·n·3L). The bound is tight only on adversarial boards (many equal letters); the prunings target exactly those.
