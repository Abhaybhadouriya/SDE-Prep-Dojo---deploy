Recognise the pattern

When you see grid + "path of adjacent cells" + "each cell at most once" + small limits, think DFS backtracking with a visited mark that is undone on return. If it were "is any path / reachable at all" (no letter order, no reuse rule per path), a plain BFS/DFS flood fill with a permanent visited set would do.

Try a few tiny boards:

BoardWordResultNote
a b"aba"falseNeeds to return to a: reuse is forbidden.
a b / b a"abab"trueA loop of four distinct cells.
a b / c d"ad"falseDiagonals do not count.
