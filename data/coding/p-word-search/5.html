Dry run

Board A B B / B C D, word "ABBD". Directions are tried in the order down, up, right, left. Blue = on the path (marked #), orange = being tested, dashed red = rejected, green = found.

  1. Prunings pass (the board has A, B, B, D; word[0] = A and word[3] = D are both rare). Start at (0,0): A matches word[0]. Mark it.
  2. Try down first: (1,0) = B matches word[1]. Mark it and look for word[2] = B around it.
  3. From (1,0): down and left are off the board, up is (0,0), marked #, so it fails the letter test; right is (1,1) = C, not B. Dead end: unmark (1,0) and return false.
  4. Back at (0,0), the next directions: up is off the board; right is (0,1) = B, which matches word[1]. Mark it.
  5. From (0,1): down (1,1) = C is not B; up is off the board; right (0,2) = B matches word[2]. Mark it.
  6. From (0,2): down (1,2) = D matches word[3], the last letter: return true.
  7. true travels back up the three calls; each call restores its cell, so the board is unchanged when exist returns.
