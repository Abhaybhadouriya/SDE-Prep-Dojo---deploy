60-second recall

  • Cue: a + or - on every number, count the ways to hit target.
  • Insight: P - N = target, P + N = total -> P = (total + target) / 2.
  • Guard: |target| > total or odd total + target -> 0.
  • DP: ways[0] = 1; for x: for s = P down to x: ways[s] += ways[s - x].
  • Trap: zeros double the count (handled by looping down to s = x = 0).
if abs(t) > total or (total + t) % 2: return 0
P = (total + t) // 2
ways = [1] + [0] * P
for x in nums:
    for s in range(P, x - 1, -1):
        ways[s] += ways[s - x]
return ways[P]

Quick quiz

nums = [1,1,1,1,1], target = 3. What is P?

  1. 3
  2. 1
  3. 2.5
  4. 4
(5 + 3) / 2 = 4: four '+' signs and one '-', so the answer is C(5,1) = 5.

What does a 0 in nums do to the row?

  1. Doubles every entry
  2. Nothing
  3. Adds 1 to ways[0]
  4. Clears the row
ways[s] += ways[s - 0] = ways[s]: every subset can include it or not.

total = 6, target = 3. The answer is...

  1. depends on nums
  2. 0, because 9 is odd
  3. 1
  4. 3
P = 4.5 is not an integer, so no sign pattern works.
