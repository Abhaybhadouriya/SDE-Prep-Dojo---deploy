Derive the subset-sum target on the whiteboard.

P - N = target, P + N = total. Add them: 2P = total + target, so P = (total + target) / 2, which must be a non-negative integer no larger than total. Every sign pattern is one subset (the '+' set), so the count of patterns equals the count of subsets with sum P.

How to answer

Two lines of algebra, then state the bijection explicitly; that is the proof.

Likely follow-ups
  • Why can you use N = (total - target) / 2 instead? Same bijection with the '-' set; smaller row if target > 0.
Print all the expressions, not just the count.

Output size can be exponential (2n for all zeros), so backtracking is unavoidable. Prune with the 2-D count table: only recurse into a branch whose count is non-zero, so no work is wasted on dead branches.

How to answer

Say the lower bound: you cannot beat the output size.

Likely follow-ups
  • Return only the k-th expression in lexicographic order: walk the count table.
Numbers can be negative.

A negative number with '+' is the same as its absolute value with '-', and the set of expressions maps one-to-one. So replace each number by its absolute value; the count does not change.

How to answer

Look for a symmetry before reaching for an offset table.

Likely follow-ups
  • Then the offset-memo version works without the reduction, too.
n is 40 and values are up to 109.

The sum table is impossible. Meet in the middle: enumerate the 220 signed sums of each half, put one half's sums in a hash map of counts, and for each sum a of the other half add count[target - a]. O(2n/2) time and memory.

How to answer

The DP is pseudo-polynomial (it depends on the sum, not n); big values break it.

Likely follow-ups
  • Same idea in LC 2035 and LC 1755.
The count can be huge; return it modulo 109 + 7.

Apply the modulus in the update: ways[s] = (ways[s] + ways[s - x]) % MOD. Additions only, so no modular inverse is needed. Keep the zero-doubling behaviour; it is still correct modulo MOD.

How to answer

Mention 64-bit intermediates in Java/C++ if you add before the modulus.
