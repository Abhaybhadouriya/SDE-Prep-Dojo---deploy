The problem (in our words)

You are given an integer array nums and an integer target. Build an expression by writing either '+' or '-' in front of every number of nums (keeping their order) and joining them. For example, [3, 5] can give "+3-5" = -2.

Return the number of different expressions whose value equals target. Two expressions are different if at least one number has a different sign (so equal values at different positions count separately).

Signature: int findTargetSumWays(int[] nums, int target).

Constraints:

  • 1 <= nums.length <= 20
  • 0 <= nums[i] <= 1000
  • 0 <= sum(nums[i]) <= 1000
  • -1000 <= target <= 1000

Practice it: LeetCode 494 · GfG Target Sum

Constraints tell you: n ≤ 20 means 220 ≈ 106 sign patterns, so even brute force passes; the test is whether you can do better. The total is at most 1,000, so a table indexed by sum has about 1,000 cells: n x total = 20,000 steps. The answer fits in a 32-bit int.
