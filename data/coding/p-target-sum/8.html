Common mistakes

Missing the |target| > total check. With target = -1000 and total = 10, (total + target) / 2 is negative and the row allocation or index crashes.

Loop upward. Upward reuses the same number many times (unbounded knapsack). With [1,1,1,1] and target 2 (P = 3) the right answer is 4, but the upward loop returns 20: the first 1 alone already "makes" 2 and 3.

Treating 0 specially or ignoring it. Each zero doubles the answer. The downward loop down to s = x = 0 handles it with no special case.

Memo key without the index. Keying only on the running sum merges different positions; the state is (i, s).

Negative indexes in the 2-D table. Running sums go from -total to +total; shift by +total or use a map.
