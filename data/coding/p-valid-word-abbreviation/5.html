Dry run

Example 2: word = "kernel", abbr = "k2n1l". Green rings = a letter match, the blue ring = a number being read, grey veil = letters skipped by a jump.

  1. Start: i = 0 in the word, j = 0 in the abbreviation.
  2. abbr[0] = 'k' is a letter: it must equal word[0] = 'k'. It does, so both pointers move.
  3. abbr[1] = '2' is a digit and not '0': read the whole number (2). It stands for 2 hidden letters.
  4. Jump i from 1 to 3: 'e' and 'r' are skipped without being looked at. j is past the number.
  5. abbr[2] = 'n' must equal word[3] = 'n'. Match: move both.
  6. abbr[3] = '1': one hidden letter. Jump i from 4 to 5.
  7. abbr[4] = 'l' must equal word[5] = 'l'. Match: move both.
  8. Both pointers are exactly at the end (i == 6 == n, j == 5 == m): return true.
