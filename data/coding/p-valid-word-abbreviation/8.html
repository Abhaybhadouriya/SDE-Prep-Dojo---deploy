Common mistakes

Checking only j == m at the end. "ab", "a" passes that check; the word must be used up too.

Indexing word[i] after an overshooting jump. Keep i < n in the loop condition so a jump past the end never reads out of bounds.

Accepting "0" or "01". Test the first digit of a number, not just any digit; the most common wrong answer on this problem.

Int overflow in C++/Java. i += 2147483647 wraps to a negative index. Break as soon as the number exceeds n, or parse into a 64-bit value.

Reading one digit at a time. "12" is twelve, not one then two. Parse the full run of digits before jumping.
