When you fail a re-solve

Failing a review is the system working: it found a weak spot before an interviewer did. What you do next depends on why you failed, and there are only four reasons.

  1. Stop at the time box. 25 minutes for a Medium, 35 for a Hard. Struggling past that teaches frustration, not the problem.
  2. Read the answer actively. Read your old code or the write-up on the problem page, then close it and write the solution from memory straight away. Do not move on until it is green.
  3. Classify the failure with the tree above and apply its fix.
  4. Grade Again (or Hard if you only ran over time). The card returns tomorrow.
  5. Solve a sibling. Each problem page lists similar problems; pick one from the same variant within two days. Passing a sibling proves you learned the idea, not the answer.

Leeches. A card that fails three times in a month is what Anki users call a leech. Do not keep drilling it. Rebuild it: reread the lesson section for its pattern, solve two easier problems from the same subgroup, then write a brand-new card in different words.

From your world

A failed re-solve is a regression caught in CI, not in production. You would not just re-run the pipeline until it turns green; you would find the root cause, add a test for it and fix the code. Line 5 of the card is that test.
