Then mark each one Solved on its page. They will start showing up in Revise tomorrow.

Patterns get the same treatment. The Pattern cards mode on Revise shows the revision card of each pattern lesson (cue, insight, state, trap, cost) and schedules it on the same 1-3-7-14-30-60-120 ladder, five new lessons at a time. Use it on days with no problems due: recognising the pattern is the step a timed round tests first.
