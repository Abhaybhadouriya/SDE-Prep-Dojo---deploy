Revision card

  • Cue: new item may cancel the latest survivor, and the cancel can cascade -> stack.
  • Insight: only (+ on the left, - on the right) collide; a - only reaches the top.
  • State: stack of survivors, shape (negatives)(positives); flag alive.
  • Trap: while not if; tie pops the top AND drops the newcomer; - then + is no collision.
  • Cost: O(n) time (each pushed/popped once), O(n) space; replay O(n²).
st = []
for x in items:
    while st and conflicts(st[-1], x) and x_wins(st[-1], x):
        st.pop()                       # x destroys the top, keep fighting
    if not (st and conflicts(st[-1], x)): st.append(x)
    elif tie(st[-1], x): st.pop()      # both gone
return st

Only + on the left and - on the right move towards each other.

Stack [5, 10], newcomer -10. Result?

  1. [5]
  2. [5, -10]
  3. []
  4. [5, 10]
Equal size: both explode. The 10 is popped AND the -10 is dropped, so 5 never meets it.

Why a while loop and not an if?

  1. style
  2. one big negative asteroid can destroy several positives in a row
  3. to handle ties
  4. it must be if
