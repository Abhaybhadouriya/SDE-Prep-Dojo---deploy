The problem (in our words)

You are given an integer array asteroids describing rocks in a row; the index is the rock's position in space from left to right. For each rock, the absolute value is its size and the sign is its direction: positive moves right, negative moves left. All rocks move at the same speed.

When two rocks meet, the smaller one explodes; if they are the same size, both explode. Two rocks moving in the same direction never meet. Return the state of the row after all collisions, as an array in left-to-right order.

Signature: int[] asteroidCollision(int[] asteroids).

  • 2 <= asteroids.length <= 104
  • -1000 <= asteroids[i] <= 1000
  • asteroids[i] != 0

Practice it: LeetCode 735 · TUF article

Constraints tell you: n up to 104, so even an O(n²) "replay until stable" passes, but the interviewer wants the O(n) stack. Sizes are small (≤ 1000) so there is no overflow concern; zero is excluded, so every rock has a direction.
