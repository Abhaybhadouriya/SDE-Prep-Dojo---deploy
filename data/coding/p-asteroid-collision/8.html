Common mistakes

Treating "- then +" as a collision. [-3, 5] fly apart. The pop condition must check top > 0 && incoming < 0, not just "different signs".

Stopping after one pop. Writing if instead of while handles [2,-5] but returns the wrong answer on [1,2,3,-4].

Pushing the newcomer after a tie. On equal sizes both explode; the incoming rock must not be pushed. A boolean alive flag (as in our code) makes the three outcomes explicit.

Reversing the stack at the end. The stack bottom is the leftmost survivor, so it is already in output order. (Only a Deque used with push/pop in Java needs reversing, because it pushes at the front.)
