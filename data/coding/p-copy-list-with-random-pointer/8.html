Common mistakes

Copying random pointers as they are. copy.random = old.random makes the copy point into the original list: a shallow copy. The judge checks for this.

Wiring random during unweaving. Once some originals have been unlinked from their copies, X.random.next may already be the next original, not the copy. Finish pass 2 completely first.

Not restoring the input. Returning the copies but leaving originals woven breaks the input list, and the judge rejects the answer because the original list was modified.

Hash map keyed by value. Values repeat; key by the node (reference / pointer). In Python use the node itself (hashed by identity) or id(node).
