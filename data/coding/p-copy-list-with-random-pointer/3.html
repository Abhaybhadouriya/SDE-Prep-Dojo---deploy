Recognise the pattern

When you see "clone / deep copy" a structure with extra pointers that can point anywhere (random, neighbours, parent), think you need old-node -> new-node. Use a hash map (works for any graph), or, for a list, interleave the copies so old.next is the map.

Why one pass is not enough:

MomentWhat we want to setDoes the target copy exist?
Creating copy of node 1 in example 1 (val 8)random -> copy of node 0✓ already made
Creating copy of node 2 (val 1)random -> copy of node 4✗ not made yet

So: first create all copies (and remember where they are), then wire the random pointers.
