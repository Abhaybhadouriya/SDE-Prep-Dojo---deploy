The story

Explain like I'm 5

Children stand in a line, each holding the shoulder of the next child. Each child also points at one "best friend" anywhere in the line, or at nobody. You must build a second line of new children that copies this exactly: same order, same best-friend pattern, but every new child must point at a new child, never at someone in the old line. The hard part is the pointing: when you create new child number 1, their best friend's copy may not exist yet.

Copying next alone is easy. The random pointer is what turns this into a "map old identity to new identity" problem, the same problem as cloning any graph.

From your world

This is fork() copying a process image: every pointer inside the copied memory must be relocated to the child's copy, not left pointing into the parent. Relocation needs a table old address -> new address. The weaving trick stores that table inside the structure itself, the way an in-place compacting GC writes a forwarding pointer into each old object.
