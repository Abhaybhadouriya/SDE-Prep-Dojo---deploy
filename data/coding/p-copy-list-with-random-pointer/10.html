Technique: clone a pointer structure by mapping each old node to its new node, then rewiring every pointer through that map.

Closest match: LC 133 Clone Graph Medium

  • Same: deep copy where pointers (neighbours) may point to nodes not yet copied; map old -> new.
  • Different: a node has many neighbours and there is no "next" order, so nodes are found by BFS/DFS.
  • So: the hash map rung is the answer; the weaving trick has no list to weave into.

How to recognise it:

  • "Deep copy", "clone", "no pointer of the copy may point into the original".
