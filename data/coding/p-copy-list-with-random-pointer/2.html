Input [val, random_index]OutputWhy
[[3,null],[8,0],[1,4],[6,2],[2,0]][[3,null],[8,0],[1,4],[6,2],[2,0]]The copy has the same shape; random pointers can go forwards (1 -> index 4) or backwards (8 -> index 0).
[[5,1],[9,1]][[5,1],[9,1]]Node 9 points at itself. Its copy must point at the copy of 9, i.e. at itself in the new list.
[[4,null],[4,0],[4,null]][[4,null],[4,0],[4,null]]Equal values: a map keyed by value would confuse the three nodes. Key by node.
[][]An empty list copies to an empty list (return null).
