Approaches: brute -> better -> optimal

Hint 1

What order are a key's writes stored in if you just append them?

Hint 2

"Largest time <= t" is one step left of "first time > t".

Hint 3

What should get return if the first time > t is at index 0?

1. Brute force - scan the history

Idea: map key -> list of (time, value); get walks the list from the end and returns the first entry with time <= t.

O(1) / O(n)set / get
O(n)space

What is wasted: the list is sorted by time, and the scan ignores that. With one hot key and 105 gets of an early time, that is 1010 steps. -> rung 2.

2. Better - a sorted map per key

Idea: key -> TreeMap<time, value> (Java) or std::map; get is floorEntry(t) or prev(upper_bound(t)). This is the most-voted C++ and Java solution style: three lines.

O(log n)set and get
O(n)space, ~3-5x overhead per node

What is wasted: a balanced tree pays for out-of-order inserts that the constraints promise never happen: an extra log n per set and a pointer-heavy node per entry. It is still a good answer, and the right one if the interviewer drops the "increasing" rule. -> rung 3.

3. Optimal - append-only arrays + binary search

def get(self, key, t):
    ts = self.times.get(key)
    if not ts: return ""
    i = bisect_right(ts, t)          # first index with time > t
    return self.vals[key][i - 1] if i else ""
  1. set: append (time, value) to the key's list. Times strictly increase, so the list stays sorted with no extra work.
  2. get: look up the list; if the key is missing, return "".
  3. Upper bound: find i = the first index whose time is > t (lo = mid + 1 when time <= t, else hi = mid).
  4. Step back: i - 1 is the latest time <= t. If i == 0, every write is after t: return "".
O(1) amortisedset
O(log nkey)get
O(n)space

Why it works: within one key the predicate "time > t" is false...false true...true along the sorted list, so its first true index is well defined and binary search finds it. Everything before it was written at or before t, and the entry right before it is the latest such write, which is exactly what get must return.
