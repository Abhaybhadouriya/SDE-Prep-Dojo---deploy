Recognise the pattern

Cue: "value as of time t", "latest version not after t", "the price at that moment" -> a floor lookup in a time-sorted list per key. If inserts arrive in order, the list is a plain array plus binary search; if not, use a sorted map (TreeMap.floorEntry, std::map::upper_bound).
