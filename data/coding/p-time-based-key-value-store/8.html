Common mistakes

Lower bound instead of upper bound. bisect_left(ts, t) - 1 skips the write at exactly time t and returns the one before it.

Index -1 in Python. When nothing is at or before t, vals[i - 1] with i = 0 returns the newest value instead of "". Check i == 0 first.

Creating keys on reads. m[key] in C++ (and defaultdict[key] in Python) inserts an empty list on every get of an unknown key; it is not wrong here, but it grows memory with junk on a read-heavy workload.

Copying the vector in C++. auto h = history[key]; copies the whole history on every get, turning O(log n) into O(n). Bind a const&.

Sorting inside get. Some solutions sort the list on each get "to be safe"; the constraints make it sorted already, and sorting costs O(n log n) per call.
