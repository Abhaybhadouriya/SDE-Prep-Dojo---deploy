The problem (in our words)

A satellite photo is stored as an m x n binary matrix grid: 1 is land and 0 is water. An island is a group of land cells joined horizontally or vertically (4 directions; diagonals do not connect). Everything outside the grid is water. The area of an island is the number of its cells. Return the largest island area, or 0 if there is no land at all.

  • Input: int[][] grid with values 0 or 1.
  • Output: an integer, the maximum area. Signature: int maxAreaOfIsland(int[][] grid).

Constraints

  • m == grid.length, n == grid[i].length
  • 1 <= m, n <= 50
  • grid[i][j] is either 0 or 1.

Practice it: LeetCode 695 - Max Area of Island · GfG - Largest region of 1s (8 directions)

Constraints tell you: at most 50 × 50 = 2,500 cells, so any linear scan is instant and recursion depth is at most 2,500 (safe in C++, Java and Go; Python needs a raised limit or an explicit stack). The real test is whether you visit each cell once and handle the boundary cleanly.
