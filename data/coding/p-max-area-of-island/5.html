The 4 × 5 grid from example 1. Blue = land not yet visited, highlighted = the island being filled now, shaded = already sunk.

  1. Start: scan cells left to right, top to bottom. Blue cells are land not yet visited; the answer so far is 0.
  2. Scan reaches land at (0, 0): flood-fill island A through up/down/left/right neighbours, sinking each cell (1 -> 0). It has 3 cells, so best = 3.
  3. Scan reaches land at (0, 4): flood-fill island B through up/down/left/right neighbours, sinking each cell (1 -> 0). It has 3 cells, so best = 3.
  4. Scan reaches land at (2, 2): flood-fill island C through up/down/left/right neighbours, sinking each cell (1 -> 0). It has 4 cells, so best = 4.
  5. The scan finishes with no land left: every cell was looked at a constant number of times. The answer is 4 (island C). Note (1, 3) and (2, 2) touch only diagonally, so islands B and C stay separate.
