Example 3: numLevels = 5, rules = [[1,0],[2,0],[3,1],[3,2],[4,3]], so edges 0->1, 0->2, 1->3, 2->3, 3->4.

  1. Count in-degrees. Only level 0 waits for nothing, so the queue starts as [0].
  2. Take 0. Its dependants 1 and 2 each lose one wait and reach 0: both join the queue.
  3. Take 1. Level 3 drops from 2 to 1; it still waits for level 2, so it does not join yet.
  4. Take 2. Level 3 drops to 0 and joins the queue. The diamond is resolved.
  5. Take 3. Level 4 drops to 0 and joins.
  6. Take 4. The queue is empty and taken = 5 = n, so there is no cycle: return true.
