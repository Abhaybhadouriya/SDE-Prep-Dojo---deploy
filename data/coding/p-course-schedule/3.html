Recognise the pattern

When you see "X must happen before Y" + "is there a valid order / can all be done", think directed graph -> topological sort; "impossible" means a directed cycle.

When you see "can all be done?" (207) or "give one valid order" (210), think the same Kahn loop: 207 checks the count of popped nodes, 210 returns the pop order.
