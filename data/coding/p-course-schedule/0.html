Explain like I'm 5

A training academy has n levels, numbered 0 to n-1. Some levels unlock only after others: "finish level 3 before level 5". You are given every such rule. Can a trainee finish all levels in some order? If two levels each wait for the other, nobody can ever start either of them, and the answer is no.

This is modprobe resolving module dependencies, make ordering targets, or systemd ordering units with After=. A dependency loop is exactly the "ordering cycle" systemd reports at boot. The in-degree counter per node behaves like a reference count: when it drops to zero, the unit is ready to run.
