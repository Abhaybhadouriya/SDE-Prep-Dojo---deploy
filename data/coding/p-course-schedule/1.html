The problem (in our words)

You get an integer numLevels and an array rules, where rules[i] = [a, b] means level b must be completed before level a. Return true if it is possible to complete every level, otherwise false.

Signature: boolean canFinish(int numLevels, int[][] rules)

  • Constraints:
  • 1 <= numLevels <= 2000
  • 0 <= rules.length <= 5000
  • rules[i].length == 2
  • 0 <= a, b < numLevels
  • All pairs rules[i] are distinct.

Practice it: LeetCode 207 - Course Schedule · GfG - Prerequisite Tasks · GfG article

Constraints tell you: V = 2000 and E = 5000 are small, but they still reward O(V + E). A 2000-long chain also means a recursive DFS goes 2000 frames deep, above Python's default limit of 1000.

Note: a == b is allowed by the constraints (a level that requires itself). That is a cycle of length one, so the answer is false.
