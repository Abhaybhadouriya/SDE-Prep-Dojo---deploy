Recognise the pattern

Cue: "longest substring / subarray such that some budget is not exceeded", and the budget only gets worse as the window grows -> variable sliding window. Here the budget is "letters that differ from the majority" <= k.

Close relatives: Max Consecutive Ones III (two letters, flip zeros) and Longest Substring with At Most K Distinct Characters (budget = number of distinct letters). Pattern pages: Sliding window · Sliding window variants · explorer node Sliding window > variable window.
