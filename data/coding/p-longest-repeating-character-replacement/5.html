Dry run

s = "BBCBCCB", k = 1. The blue ring is the window; a red box is the letter dropped when the window slides.

  1. right = 0 'B': count B = 1, maxFreq = 1. Window "B" needs 1 - 1 = 0 repaints <= k = 1. Keep it.
  2. right = 1 'B': B = 2, maxFreq = 2. "BB" needs 0 repaints. Window size 2.
  3. right = 2 'C': C = 1. "BBC" needs 3 - 2 = 1 repaint (the C). Still <= 1, the window grows to 3.
  4. right = 3 'B': B = 3, maxFreq = 3. "BBCB" needs 4 - 3 = 1 repaint. Size 4 = the best so far.
  5. right = 4 'C': "BBCBC" would need 5 - 3 = 2 > k. Do not shrink to fit: just slide. Drop s[0] = 'B' (B = 2), left = 1. The size stays 4.
  6. right = 5 'C': C = 3. Size would be 5, 5 - 3 = 2 > k, so slide again: drop s[1] = 'B', left = 2. Window "CBCC" (size 4).
  7. right = 6 'B': size would be 5, 5 - 3 = 2 > k, slide: drop s[2] = 'C', left = 3. The window "BCCB" really needs 2 repaints and maxFreq = 3 is stale - but its SIZE (4) is a length we already proved reachable. Answer = n - left = 7 - 3 = 4.
