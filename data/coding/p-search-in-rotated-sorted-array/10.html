How to recognise it:

  • "Rotated", "shifted", "circularly sorted", "ring buffer" and a log-time requirement.
  • The array is not sorted, but a cheap test at mid still tells you which side to keep.

Practice order:

  1. Warm-up: 704 Binary Search, then 153 Find Minimum in Rotated Sorted Array.
  2. This problem: write the one-pass version and test every rotation of a small array.
  3. Harder: 81 (duplicates), 154 (minimum with duplicates).
