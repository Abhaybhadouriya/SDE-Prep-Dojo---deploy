The problem (in our words)

You get the head of a singly linked list and an integer n. Delete the node that is n-th from the end of the list (n = 1 is the last node, n = length is the first node) and return the head of the resulting list. If the list had one node and you delete it, return null.

Signature: ListNode removeNthFromEnd(ListNode head, int n), where ListNode has an integer val and a next pointer.

Constraints

  • The list has sz nodes, 1 <= sz <= 30.
  • 0 <= Node.val <= 100
  • 1 <= n <= sz (n is always valid).

Follow-up asked by the original: can you do it in one pass over the list?

Practice it: LeetCode 19 - Remove Nth Node From End of List · GfG - Kth from End of Linked List (find, not delete) · TUF - Remove the Nth node from the end

Constraints tell you: 30 nodes means any approach passes; the interview is about the follow-up (one pass, O(1) space) and about not crashing when the node to delete is the head (n == sz). Since n <= sz is guaranteed, the leader never runs off the list while opening the gap; mention that you rely on it.
