  • Cue: k-th from the end of a singly linked list, one pass, O(1) space.
  • Insight: a fixed gap of n between two pointers turns "distance from end" into "distance from lead".
  • State: dummy, lead, trail; lead goes n ahead, then both move.
  • Trap: loop while lead.next (stop on the predecessor); dummy covers n == length; return dummy.next.
  • Cost: O(L) time, O(1) space; two-pass count is the same big-O.
dummy = Node(0, head); lead = trail = dummy
for _ in range(n): lead = lead.next
while lead.next:
    lead = lead.next; trail = trail.next
trail.next = trail.next.next
return dummy.next

With lead and trail starting on the dummy and a gap of n, which loop condition leaves trail on the predecessor?

  1. while lead
  2. while lead.next
  3. while trail.next
Stopping with lead on the last node puts trail n nodes behind it: one before the n-th from the end.

For [3,4], n = 2, where is trail when the slide loop ends?

  1. On the dummy
  2. On 3
  3. On 4
After the gap, lead is on 4 and lead.next is null, so trail never moves; D.next = 4 deletes the head.

What does the dummy node save you from?

  1. Counting the length
  2. Freeing the removed node
  3. A special case when the head is the node to delete
Every real node now has a predecessor, so n == length is handled by the same unlink.
