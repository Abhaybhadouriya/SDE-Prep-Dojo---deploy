Common mistakes

Returning k off by one. If k is the index of the last kept value (starting at 0), return k + 1; if k is the count (as in our code), return k. Mixing the two conventions fails every test.

Rebinding instead of modifying (Python). nums = sorted(set(nums)) creates a new list; the judge still sees the old one. Use nums[:] = ... if you go that way (it still uses O(n) memory).

Removing from the list while looping over it. nums.remove(x) or erase inside the loop shifts the remaining elements (O(n²)) and makes the loop index skip elements.

Starting k at 0 and comparing with nums[k-1]. On the first step that reads index -1: out of bounds in C++/Java, and in Python it silently reads the last element.
