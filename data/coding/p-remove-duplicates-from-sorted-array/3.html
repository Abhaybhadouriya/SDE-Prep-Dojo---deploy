Recognise the pattern

Cue: "in place" + "remove / keep some elements" + "return the new length" -> same-direction two pointers: a read pointer that visits everything and a write pointer that marks the end of the kept part. Sorted adds the key fact: duplicates are adjacent, so "is it new?" is one comparison with the last kept value.

Try a few and note what you compare with:

InputkNote
[1,1,1]1Every later value equals the last kept one.
[1,2,3]3Every value is new; the "copy" writes a value onto itself.
[1,2,1](not allowed)Unsorted: the second 1 is not adjacent to the first, and one comparison is no longer enough.
