The story

Explain like I'm 5

You have a row of stickers, already sorted by number, and some numbers repeat. You want one sticker of each number, packed to the left. Walk along the row with one finger; with your other hand, keep a "next free spot" on the left. Every time your finger finds a number different from the last one you kept, move that sticker to the free spot and shift the spot one place to the right.

You never need to look back further than the last kept sticker, because the row is sorted: all copies of a number sit together.

From your world

This is sort | uniq done in place: uniq also only compares each line with the previous kept line, which works because its input is sorted. The read/write pointer pair is the same pattern you use to compact an array of descriptors after dropping some entries, without allocating a second buffer.
