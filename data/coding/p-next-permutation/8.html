Common mistakes

Strict comparison in the pivot scan. while nums[i] > nums[i+1] stops on equal neighbours. On [3,3,3] it picks i = 1 as the pivot, and the successor scan then finds no bigger value and runs off the array.

Strict comparison in the successor scan. while nums[j] < nums[i] stops on a value equal to the pivot. On [1,5,1] it swaps 1 with 1 and returns [1,1,5], which is smaller than the input.

Sorting or reversing the wrong range. Reverse from i + 1, not from i, and not from j. When there is no pivot, reverse the whole array (start at 0 = i + 1 with i = -1).

Picking the largest value in the suffix. Swapping the pivot with the maximum of the suffix gives a bigger ordering, but not the next one (on [1,3,5,4,2] it gives 1,5,... instead of 1,4,...).
