Recognise the pattern

When you see "next / previous arrangement in dictionary order", "smallest number bigger than X with the same digits", "k-th next permutation", think pivot + successor + reverse (Narayana Pandita's 14th-century method, the one behind C++ std::next_permutation). The reverse works only because the suffix is known to be sorted (descending), which is the key fact to say.

Try the orderings of [1, 2, 3] and mark where the change happens:
