Common mistakes

Checking only the root. abs(depth(left) - depth(right)) <= 1 at the root alone passes the tree in the figure above and is wrong: the rule holds for every node.

Confusing "balanced" with "complete" or "min depth vs max depth". Comparing the shallowest leaf with the deepest leaf (difference <= 1) is a different, stricter property. The sparsest balanced tree of height 5 (left side height 4, right side height 3, built the same way recursively) passes the per-node rule but has leaves at depth 3 and at depth 5.

Losing the -1. Computing 1 + max(lh, rh) before checking for -1 turns a failure (-1) into a height (0 or more) and the error disappears higher up.

Calling depth() inside the bottom-up function. Mixing both versions keeps the O(n2) cost; the height must come from the recursive call's return value.

Python recursion limit. A skewed 5000-node tree raises RecursionError with the default limit of 1000; set sys.setrecursionlimit or use the iterative version.
