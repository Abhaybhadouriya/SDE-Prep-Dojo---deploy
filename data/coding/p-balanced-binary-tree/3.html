Recognise the pattern

Cue: a property that must hold "for every node" and depends on a number computed from the subtrees (height, size, sum) -> bottom-up DFS: each call returns that number to its parent, and the check happens on the way up. If the answer is a yes/no, smuggle the "no" inside the number (a sentinel like -1) so one function does both jobs.
