  • Cue: sorted disjoint ranges + add one -> three phases, no sort.
  • Insight: left zone = prefix (end < lo), right zone = suffix (start > hi).
  • State: index i, running block lo, hi, output list.
  • Trap: always emit the block; strict end < lo, inclusive start <= hi.
  • Cost: O(n) time, O(n) output; append+sort+merge O(n log n).
out, i = [], 0
while i < n and a[i].end < lo: out.append(a[i]); i += 1    # left
while i < n and a[i].start <= hi:                          # overlap
    lo = min(lo, a[i].start); hi = max(hi, a[i].end); i += 1
out.append((lo, hi))
out.extend(a[i:])                                            # right

The input is sorted and non-overlapping. Which three phases does one pass have?

  1. Sort, merge, split
  2. Copy intervals ending before the new one, merge every overlap into it, copy the rest
  3. Binary search, insert, re-sort
Only the middle phase changes anything; it widens the new interval to min start and max end.

Intervals [a, b] and [c, d] overlap (touching counts) when?

  1. a < c
  2. c <= b and a <= d
  3. b == d
They share at least one point; e.g. [1,3] and [3,5] merge into [1,5].

Time of the one-pass solution?

  1. O(n log n)
  2. O(n)
  3. O(log n)
No sort is needed because the input is already sorted.
