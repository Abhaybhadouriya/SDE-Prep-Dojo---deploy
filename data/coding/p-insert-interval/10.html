Technique: on a sorted, disjoint list, the ranges that touch a query range form one contiguous run; find it (scan or binary search) and replace it.

Closest match: LC 56 Merge Intervals Medium

  • Same: output the merged, sorted, non-overlapping list; touching counts.
  • Different: the input is unsorted and anything can overlap anything.
  • So: sort first (O(n log n)), then sweep with one open block instead of three fixed phases.

How to recognise it:

  • The statement promises the list is sorted and non-overlapping: that promise is the whole trick.
  • One change to the set of ranges (add, remove, query): find the touched run, replace it.

Practice order:

  1. Warm-up: 228 Summary Ranges.
  2. 56 Merge Intervals, then this problem (notice the sort disappears).
  3. Then 986 Interval List Intersections and 1272 Remove Interval.
  4. Harder: 352 Data Stream as Disjoint Intervals, 715 Range Module.
