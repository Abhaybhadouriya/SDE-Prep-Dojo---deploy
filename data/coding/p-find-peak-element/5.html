Binary search on [1,3,6,4,2,5,9,12,10,7,8,0] (n = 12). Blue = still in range, orange = the pair mid / mid + 1 being compared, grey = thrown away.

  1. Start with the whole array: lo = 0, hi = 11. A peak certainly exists (the maximum, 12, is one).
  2. mid = 5. nums[5] = 5 < nums[6] = 9: uphill, so a peak lies to the right. lo = 6. Note we drop the peak at index 2; that is fine, one peak is enough.
  3. Range [6, 11], mid = 8. nums[8] = 10 > nums[9] = 7: downhill, so mid or something to its left is a peak. hi = 8.
  4. Range [6, 8], mid = 7. nums[7] = 12 > nums[8] = 10: downhill again. hi = 7.
  5. Range [6, 7], mid = 6. nums[6] = 9 < nums[7] = 12: uphill. lo = 7.
  6. lo == hi == 7: return 7. nums[7] = 12 beats 9 and 10. Four comparisons instead of up to eleven.
