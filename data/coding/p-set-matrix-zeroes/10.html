How to recognise it:

  • "In place" + an update rule that must use the original values.
  • "Constant extra space" on a structure you may overwrite: look for spare cells or spare bits.

Practice order:

  1. Warm-up: GfG Boolean Matrix with two arrays.
  2. This problem: arrays version, then the row 0 / column 0 markers.
  3. Then LC 289 (two states per cell) and LC 41 (array as its own hash table).
