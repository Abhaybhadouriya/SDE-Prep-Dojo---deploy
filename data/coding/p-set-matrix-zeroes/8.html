Common mistakes

Zeroing as you scan. Written zeros are later read as original zeros and spread across the whole grid. Always separate "find" from "apply".

Using a sentinel like -1 or Integer.MIN_VALUE for "will become 0". Values cover the whole int range, so a real cell can hold the sentinel. (It also costs O(m·n·(m+n)) time.)

Letting [0][0] mean both row 0 and column 0. A zero only in column 0 then wipes row 0 too. One extra boolean fixes it.

Applying top-down. Rewriting row 0 first destroys the column marks before the other rows read them. Go bottom-up, or handle row 0 and column 0 after all other cells with two extra flags.

Starting the marking loop at j = 0. Then a zero at (i, 0) writes [0][0] = 0 and row 0 is wrongly zeroed. The inner loops start at 1.
