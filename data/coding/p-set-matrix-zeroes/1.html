The problem (in our words)

A warehouse floor plan is an m x n integer grid matrix. A value of 0 means "damaged tile". Safety rules say that if a tile is damaged, every tile in its row and every tile in its column must be marked 0 as well.

Change matrix in place so that, for every cell that held 0 in the original grid, its entire row and entire column become 0. Only zeros from the original input spread; zeros you write do not spread further. Return nothing.

Signature: void setZeroes(int[][] matrix).

Constraints

  • m == matrix.length, n == matrix[0].length
  • 1 <= m, n <= 200
  • -231 <= matrix[i][j] <= 231 - 1

Follow-up (part of the original): an O(m·n)-space copy is a poor answer; O(m + n) extra space is better; can you do it in O(1) extra space?

Practice it: LeetCode 73 - Set Matrix Zeroes · GfG - Set Matrix Zeros · TUF - Set Matrix Zero

Constraints tell you: 200 × 200 = 40,000 cells, so any O(m·n) pass is instant and O(m·n·(m+n)) (8 million) would also pass; the question is purely about extra space. Values cover the full int range, so you cannot use a "special value" such as -1 as a marker: any int could be real data.
