Recognise the pattern

When you see "modify a grid in place" + "the change depends on the original values", think two phases: record decisions first, apply them second.

When you see "O(1) extra space" with a grid or array you are allowed to overwrite, think storing the bookkeeping inside the input itself (a row/column of the grid, a sign bit, spare bits of each value).

Try the obvious one-pass idea on [[1,0],[1,1]]: zero row 0 and column 1 when you meet the 0, and you get [[0,0],[1,0]]; correct here. On [[0,1],[1,1]], a one-pass version that zeroes eagerly turns (0,1) into 0, then later "finds" it and zeroes column 1 as well: [[0,0],[0,0]] instead of [[0,0],[0,1]]. Written zeros must never be read as original zeros.

Taxonomy: Matrix → in-place tricks → marker state. Pattern lesson: Matrix problems.
