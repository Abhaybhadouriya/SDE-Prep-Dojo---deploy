Approaches: brute -> better -> optimal

Hint 1

What do you really need to know at the end? Only "does row i contain a zero" and "does column j contain a zero".

Hint 2

Those m + n booleans need somewhere to live. Is there a row and a column of the matrix whose own fate you can compute separately?

1. Brute force - copy the grid

Idea: make a copy. For every zero in the copy, write zeros across its row and column in the original. Reading from the copy means written zeros never spread.

O(m·n·(m+n))time (each zero writes a row and a column)
O(m·n)extra space

What is wasted: a full copy, when the only facts that matter are one bit per row and one bit per column; and the same row is rewritten once per zero in it.

2. Better - two boolean arrays

rowZ, colZ = [False] * m, [False] * n
for i, j where matrix[i][j] == 0: rowZ[i] = colZ[j] = True
for i, j: if rowZ[i] or colZ[j]: matrix[i][j] = 0
O(m·n)time
O(m + n)extra space

What is wasted: the m + n booleans. Row 0 and column 0 of the matrix are exactly m + n cells, and if row 0 or column 0 ends up zeroed, their old values do not matter anyway.

3. Optimal - markers in row 0 and column 0

for i in range(m):                       # pass 1, top-down
    if M[i][0] == 0: col0 = True
    for j in range(1, n):
        if M[i][j] == 0: M[i][0] = M[0][j] = 0
for i in range(m - 1, -1, -1):           # pass 2, bottom-up
    for j in range(n - 1, 0, -1):
        if M[i][0] == 0 or M[0][j] == 0: M[i][j] = 0
    if col0: M[i][0] = 0
  1. Row 0 becomes colZ, column 0 becomes rowZ. A zero at (i, j) writes 0 into its row head [i][0] and its column head [0][j]. Overwriting them is safe: a head is only overwritten with 0 when its row/column must become 0 anyway.
  2. The corner is shared, so add one boolean. [0][0] is both "row 0's head" and "column 0's head". Let it mean row 0; a separate col0Zero says whether column 0 had a zero. It is set from matrix[i][0] before the inner loop, which starts at j = 1 so the marks never touch column 0's own flag.
  3. Apply bottom-up, right-to-left. Row 0 holds the column marks, so it must be rewritten last; going from the last row up guarantees that. Column 0 holds the row marks, so within a row the loop stops at j = 1 and column 0 is handled by col0Zero at the end of the row.
  1. Start. Zeros sit at (0,2) and (1,0). Rows 0 and 1 and columns 0 and 2 must end up all zero.
  2. Pass 1, row 0. First check column 0: matrix[0][0] = 5, so col0Zero stays false. Then scan j = 1..3: the 0 at (0,2) marks its row head [0][0] = 0 and its column head [0][2] (already 0).
  3. Row 1. matrix[1][0] = 0 is a zero in column 0: set col0Zero = true. Columns 1..3 of row 1 hold no zero.
  4. Row 2: no zeros. Pass 1 is over. Row heads (column 0): 0, 0, 9 -> rows 0 and 1. Column heads (row 0, j ≥ 1): 3, 0, 8 -> column 2.
  5. Pass 2 starts at the bottom row. Row 2: head 9 is not 0; column head [0][2] = 0, so (2,2) = 0. col0Zero is true, so (2,0) = 0 too. Row 2 = [0, 4, 0, 3].
  6. Row 1: its head [1][0] is 0, so columns 1..3 become 0, and col0Zero zeroes (1,0). Row 1 = [0, 0, 0, 0].
  7. Row 0 last: its head [0][0] = 0, so the whole row becomes 0. Row 0 held the column marks, so it had to wait until every other row had read them.
  8. Result [[0,0,0,0],[0,0,0,0],[0,4,0,3]]. Two passes over the grid, O(m·n) time, one boolean of extra space.
O(m·n)time, two passes
O(1)extra space (one boolean)

Why it works: after pass 1, [i][0] == 0 exactly when row i had an original zero (for i ≥ 1), [0][j] == 0 exactly when column j had one (for j ≥ 1), [0][0] == 0 exactly when row 0 had one, and col0Zero covers column 0. A head can only turn to 0 because of an original zero in its line, so no false marks appear. Pass 2 reads each mark before anything overwrites it: rows i ≥ 1 are done before row 0, and column 0 of a row is written after that row's other cells.

Proof (optional)

Pass 1 writes only zeros, only into row 0 and column 0, and only for lines that contain an original zero, so it never creates a wrong mark; every original zero marks both of its lines, so it never misses one (a zero in column 0 is caught by col0Zero, and a zero in row 0 at j ≥ 1 marks [0][0]). In pass 2, cell (i, j) with j ≥ 1 reads [i][0] and [0][j]. [i][0] is only written at the end of row i's turn, after the read. [0][j] is only written during row 0's turn, which comes last, and row 0 reads its own marks before writing them, going right to left, while [0][0] is read for every j ≥ 1 and written only after them.
