Recognise the pattern

When you see a grid + "connected / regions / groups / islands / provinces", think each cell is a node, the 4 neighbours are edges, and you are counting or measuring connected components with BFS/DFS. If cells are added over time, think union-find. If you need the shortest distance, it is BFS only.
