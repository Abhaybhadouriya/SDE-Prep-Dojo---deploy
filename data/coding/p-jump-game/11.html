Return the minimum number of jumps (LC 45).

Keep curEnd (the farthest index reachable with the current number of jumps) and farthest. Scan i from 0 to n - 2, updating farthest; when i == curEnd, count a jump and set curEnd = farthest. It is BFS where each layer is an interval. O(n), O(1).

How to answer

Say "BFS by layers, but each layer is a contiguous range, so no queue".

Likely follow-ups
  • Return the actual path: record, for each layer, the index that produced farthest.
Write the DP first, then optimise it.

Bottom-up from the right: good[n-1] = true, good[i] = any good[j] for j in i+1..i+nums[i]: O(n²). Observe that only the leftmost good index matters, which gives the right-to-left "goal" greedy in O(n), O(1).

How to answer

This shows the DP → greedy derivation interviewers like: name the redundant information you drop.

Likely follow-ups
  • Count the number of distinct ways to reach the end (a DP with a prefix-sum window, mod 1e9+7).
Jumps can go left or right by exactly nums[i] (LC 1306).

The prefix property breaks, so treat indices as graph nodes with up to two edges each and run BFS or DFS from the start with a visited array. O(n) time and space.

How to answer

Say why the greedy no longer applies: reachability is no longer monotone.

Likely follow-ups
  • Teleports between equal values (LC 1345): clear the value bucket after the first visit.
Each jump costs money (cost[i] to land on i). Find the cheapest way to the end.

Now it is a shortest path with a window: dp[i] = cost[i] + min(dp[j]) over j with j + nums[j] ≥ i. With a fixed window size k (LC 1696 Jump Game VI) use a monotonic deque for O(n); with per-index ranges use a segment tree or Dijkstra.

How to answer

Spot that costs turn reachability into optimisation, and name the window-min structure.

Likely follow-ups
  • Why does a deque give O(n)? Each index is pushed and popped once.
Which index is the farthest you can reach if the end is not reachable?

It is exactly the final value of reach when the scan stops (cap it at n - 1). The greedy already computes it; return it instead of the boolean.

How to answer

A quick win: show the invariant gives this for free.

Likely follow-ups
  • Which single zero, if changed to 1, makes the end reachable?
