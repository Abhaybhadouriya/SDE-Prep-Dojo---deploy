Recognise the pattern

When you see "can you reach the end" with "jump up to k" moves, think greedy farthest reach. "Up to" is the key word: if you can reach x, you can reach everything before x, so the reachable set is a prefix and one number describes it.

Move ruleReachable setTool
Jump 1..nums[i] forward (this problem)always a prefix [0, reach]greedy, O(n)
Jump exactly nums[i], left or right (LC 1306)any set, not a prefixBFS / DFS, O(n)
Fewest jumps to the end (LC 45)prefix, in layersgreedy BFS by levels, O(n)
