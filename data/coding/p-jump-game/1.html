The problem (in our words)

A row of n stepping stones is numbered 0 to n - 1, and you start on stone 0. Stone i carries the number nums[i]: from it you may jump forward by any distance from 1 up to nums[i] (a 0 means you cannot jump from that stone). Return true if you can reach the last stone, and false otherwise.

  • Input: an integer array nums.
  • Output: a boolean. Signature: boolean canJump(int[] nums).
  • Standing on the last stone at the start (n = 1) counts as reaching it.

Constraints

  • 1 <= nums.length <= 10^4
  • 0 <= nums[i] <= 10^5

Practice it: LeetCode 55 - Jump Game · GfG - Reaching End with Jumps · takeuforward

Constraints tell you: n ≤ 10^4 lets an O(n²) DP pass, but jump lengths up to 10^5 make the DP's inner loop long; the interviewer wants the O(n) greedy. i + nums[i] is at most about 1.1 × 10^5: no overflow.
