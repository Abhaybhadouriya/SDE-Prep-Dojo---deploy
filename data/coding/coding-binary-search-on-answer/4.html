Maximise the minimum: aggressive cows and friends

The classic is Aggressive Cows (SPOJ AGGRCOW, also on TUF), told our way: a barn has n stalls at distinct positions x[i] on a line, and you must put c cows into stalls (one per stall) so that the smallest distance between any two cows is as large as possible. Return that largest possible minimum distance. Constraints: 2 <= c <= n <= 10^5, 0 <= x[i] <= 10^9. Example: stalls [1, 2, 4, 8, 9], c = 3 gives 3. The LeetCode twin is 1552, Magnetic Force Between Two Balls.

Answer: a gap g. Check canPlace(g): sort the stalls, put a cow in the first stall, then in every stall at least g past the last cow; succeed if you placed c cows. Monotone the other way: if gap g is achievable, any smaller gap is too. So the row is T..T F..F and we want the last T.

  1. Gaps can be 1..8 (8 = last stall - first stall). canPlace(g) is T..T F..F, so find the first g where it FAILS and subtract 1. Range [lo, hi) = [1, 9).
  2. [1, 9): try gap 5. Greedy puts a cow in the first stall, then in each stall at least 5 past the last cow: 2 placed. Not enough: gap 5 fails, hi = mid = 5.
  3. [1, 5): try gap 3. Greedy puts a cow in the first stall, then in each stall at least 3 past the last cow: 3 placed. Enough, so gap 3 works: the first failure is to the right, lo = 4.
  4. [4, 5): try gap 4. Greedy puts a cow in the first stall, then in each stall at least 4 past the last cow: 2 placed. Not enough: gap 4 fails, hi = mid = 4.
  5. First failing gap = 4, so the largest gap that works is 3: cows at [1, 4, 8].

Why greedy placement is exact: putting each cow as far left as allowed leaves the most room for the rest (an exchange argument, like the shipping one). Sorting costs O(n log n); the search adds O(n log(range)).

Other "maximise the minimum" problems: 2226, Maximum Candies Allocated to K Children (largest pile size x so that the piles can be cut into at least k pieces of size x: count sum(c / x)), and 2141, Maximum Running Time of N Computers (time t works if sum(min(battery, t)) >= n * t).
