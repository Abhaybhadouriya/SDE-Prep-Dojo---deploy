Revision card

  • Cue: Minimise the maximum / maximise the minimum, "at least k days", huge answer range, easy feasibility check.
  • Insight: If "is X enough?" is monotone in X, binary search X itself instead of building the answer.
  • State: lo, hi over the answer range plus a greedy check(X) that is exact.
  • Trap: Wrong direction (first true vs last true); sums of large inputs overflow 32 bits; float ceil.
  • Cost: O(n log range) time, O(1) extra space.

More to remember

  • Search the answer space when "is X enough?" is easy and monotone.
  • Four steps: answer and range, check, one-sentence monotonicity, first-true or last-true.
  • Minimise the max = first true; maximise the min = last true = first false minus one.
  • Contiguous groups under a cap: greedy fill is an exact check (ship, split array, books, painters).
  • k-th smallest: search the value with "count <= x is at least k".
  • Median of two arrays: binary search the cut in the shorter array.
  • 64-bit sums, integer ceil, early exit, and lo + (hi - lo) / 2.
