Real-valued answers and other variants

  • Answers that are real numbers, like 774, Minimize Max Distance to Gas Station (add k stations, minimise the largest gap; a gap g needs ceil(d / g) - 1 new stations per segment). Do not loop on lo < hi with floats. Run a fixed 60-100 iterations, or loop while hi - lo > 1e-6, updating lo = mid / hi = mid with no +1.
  • Search on the answer plus a graph check: 778, Swim in Rising Water and 1631, Path With Minimum Effort: "is there a path using only edges with cost <= x?" is a BFS check. Dijkstra or union-find also work; the binary search version is often the easiest to get right.
  • Search on a length: "longest subarray / substring with property P" when P is monotone in length (if length L works, L - 1 does). Check with a sliding window or rolling hash per length (longest duplicate substring).
