Common mistakes

Summing even indices vs odd indices. Picks need not alternate; [4,1,1,4] gives 5 instead of 8.

Updating in the wrong order. prev1 = max(prev1, prev2 + x); prev2 = prev1 sets prev2 to the new value. Use a temporary or a tuple assignment.

Special-casing n = 1 and n = 2 and getting one wrong. Starting both variables at 0 removes all base-case code.

Defining the state as "best plan that opens locker i". Then the answer is max over the last two cells and the transition needs max(best[i-2], best[i-3]); it works but is easy to get wrong. "Best using 0..i" is simpler.
