The problem (in our words)

A night guard audits a row of storage lockers in a station. Locker i holds nums[i] rupees. Neighbouring lockers share one tamper sensor, so opening two adjacent lockers on the same night raises the alarm. Opening lockers that are not next to each other is safe.

Given the integer array nums, return the largest total amount that can be collected in one night without ever opening two adjacent lockers. Opening no locker at all is allowed (total 0).

Signature: int rob(int[] nums).

Constraints

  • 1 <= nums.length <= 100
  • 0 <= nums[i] <= 400

Practice it: LeetCode 198 - House Robber · GfG - Stickler Thief · TUF - Maximum sum of non-adjacent elements

Constraints tell you: n ≤ 100 is tiny, so even O(n²) passes; the interviewer wants the O(n) DP and then the O(1)-space version. Values are ≥ 0 and the total is at most 50 × 400 = 20,000, so a 32-bit int never overflows, and skipping is never worse than "taking a negative".
