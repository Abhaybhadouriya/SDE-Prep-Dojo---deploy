Recognise the pattern

When you see "choose items in a line" + "no two neighbours" (or any rule that only looks one or two steps back) + "maximise the sum", think 1D DP with a pick/skip choice per index.

When you see that the answer at i depends only on i-1 and i-2, think two rolling variables.

Try a few greedy ideas first; they all break:

InputGreedy ideaGreedy givesBest
[4,1,1,4]even indices or odd indices58✗
[5,6,5]take the largest first610✗
[2,9,3]take the largest first99✓ (by luck)

A choice made at one index changes what is allowed at the next one, and you cannot know locally which choice is right. That is the signal for DP: try both choices, but remember the results so you never solve the same prefix twice.

Pattern: DP → 1D DP → pick or skip · Lessons: Dynamic programming, DP state design
