Interview follow-ups

The lockers are in a circle (first and last are neighbours).

The first and last cannot both be opened, so at least one of them is closed. Solve the line problem on nums[0..n-2] and on nums[1..n-1] and return the larger (and nums[0] when n = 1). Still O(n) time, O(1) space.

How to answer

Break the circle by fixing one end as closed; reuse the linear function.

Likely follow-ups
  • Why is n = 1 special? (Both ranges would be empty.)
Also return which lockers to open.

Keep the full best array. Walk back from i = n-1: if best[i] == best[i-1], locker i was skipped, go to i-1; otherwise it was opened, record i and go to i-2. O(n) extra space is needed for the walk-back.

How to answer

Say that the O(1) version loses the choices, so you keep the table (or a bit per index).

Likely follow-ups
  • Can you store less than the whole table? (One bit per index: "taken or not".)
Opened lockers must be at least k apart.

Taking locker i now blocks i-1 .. i-k+1, so best[i] = max(best[i-1], best[i-k] + nums[i]). Keep the last k values in a ring buffer: O(n) time, O(k) space.

How to answer

Show that only the "how far back" index changes in the transition.

Likely follow-ups
  • What if each locker has its own cooldown? (Then sort/jump like weighted interval scheduling with binary search.)
Values can be negative. Does the code change?

No, as long as opening nothing is allowed: the skip option already avoids any negative locker, and the base 0 is the empty plan. If at least one locker must be opened, the DP result is still right whenever some value is positive; when every value is ≤ 0, the answer is simply max(nums).

How to answer

Ask whether the empty choice is legal; that decides the base case.

Likely follow-ups
  • Compare with Kadane's empty vs non-empty subarray rule.
Open exactly m lockers (or at most m) with the maximum total.

Add the count to the state: best[i][j] = best using lockers 0..i with j opened. Transition max(best[i-1][j], best[i-2][j-1] + nums[i]). O(n·m) time, O(m) space with rolling rows.

How to answer

Name the extra dimension and keep the same pick/skip transition.

Likely follow-ups
  • Minimise the largest single locker you open while opening at least m (LC 2560): binary search on the answer plus a greedy check.
