Common mistakes

Putting the copy in the map after the neighbour loop. The recursion comes back to the node before it is registered and clones it again, forever. Register on the line right after new Node.

Copying the neighbour list by reference. clone.neighbors = node.neighbors (or list(node.neighbors)) points the copy at original nodes; the judge reports "node with value 1 was not copied but a reference to the original one".

Using a visited set of booleans only. You need the copy itself when you see a visited node, so store original -> copy.

BFS: creating the copy when dequeuing. A node can be enqueued twice and copied twice. Create and map it when it is first discovered.

A member-variable map that is never cleared. If the same Solution object is reused for a second graph, old entries leak in. Create the map per call (as in the Java version) or clear it.
