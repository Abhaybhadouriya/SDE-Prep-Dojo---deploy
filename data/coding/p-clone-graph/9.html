Revision card

  • Cue: deep copy of nodes with pointers, cycles or shared targets possible.
  • Insight: map original -> copy is both "visited" and "where is its twin".
  • State: map copy_of; create + register a node BEFORE visiting its neighbours (BFS: on discovery).
  • Trap: late map entry = infinite loop; copied list = shared originals; null input.
  • Cost: O(V + E) time, O(V) space.
def copy(u):
    if u in seen: return seen[u]
    seen[u] = twin(u)            # register before recursing
    link seen[u] to copy(v) for each neighbour v
    return seen[u]

What does the map store?

  1. original node -> true/false
  2. original node -> its copy
  3. value -> list of neighbours
You need the copy to link to it when you meet a visited node, so a flag is not enough.

When must the copy enter the map?

  1. Right after it is created, before its neighbours
  2. After all its neighbours are cloned
  3. At the end of the traversal
Neighbours can lead back to this node; the entry must already be there to stop the cycle.

The graph is a chain of 10^6 nodes. What do you change?

  1. Nothing
  2. Key the map by value
  3. Use iterative BFS (or an explicit stack) to avoid stack overflow
Recursive DFS depth equals the chain length; an explicit queue or stack keeps memory on the heap.
