Dry run

Graph [[2,3],[1,3,4],[1,2],[2]], starting at node 1, neighbours in list order. Blue copies exist; the ring is the node being processed.

  1. dfs(1): 1 is not in the map. Create 1' and store 1 -> 1' in the map BEFORE looking at neighbours.
  2. First neighbour of 1 is 2: not in the map, so recurse. Create 2' and store 2 -> 2'.
  3. First neighbour of 2 is 1: already in the map, so dfs returns 1' at once (no recursion) and 2' gets 1' in its list. This lookup is what stops the cycle 1-2-1-2...
  4. Next neighbour of 2 is 3: new. Create 3' and store 3 -> 3'.
  5. Both neighbours of 3 (1 and 2) are in the map: 3' gets [1', 2']. dfs(3) returns 3', which 2' appends.
  6. Last neighbour of 2 is 4: create 4', its only neighbour 2 is mapped, 4' = [2']. Back in 2: 2' = [1', 3', 4']; dfs(2) returns 2', which 1' appends.
  7. Last neighbour of 1 is 3: mapped, so 1' = [2', 3']. Return 1'. Every node was created once and every list entry added once: O(V + E).
