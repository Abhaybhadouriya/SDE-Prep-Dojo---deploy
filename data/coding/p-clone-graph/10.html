How to recognise it:

  • "Deep copy", "clone", "duplicate" a structure made of nodes and references.
  • The structure can reach the same node by two routes (cycles, sharing, random pointers).

Practice order:

  1. Number of Islands (traversal with visited).
  2. This problem: DFS, then BFS.
  3. Copy List with Random Pointer (map, then O(1)-space interleave).
  4. Clone Binary Tree with Random Pointer (Premium).
