The story

Explain like I'm 5

You have a set of friends, each holding strings tied to other friends. You must build an identical set out of new toys: same friends, same strings, but no string may touch an old toy. You walk from friend to friend; the first time you meet someone, you make their toy twin and write "Asha -> toy Asha" in a notebook. Next time a string leads you back to Asha, you look in the notebook instead of making a second toy.

From your world

This is a deep copy of a pointer structure with cycles, the same job as copying a kernel object graph (or serialising one) where you keep an "old address -> new address" table so shared and cyclic references are rebuilt exactly once. It is copy.deepcopy's memo dictionary, written by hand.
