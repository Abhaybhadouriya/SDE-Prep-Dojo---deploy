Recognise the pattern

When you see "deep copy" + "nodes that point to other nodes" + possible cycles or shared targets, think traversal + a hash map original -> copy that doubles as the visited set.

When you see the copy needing pointers to nodes you have not reached yet, think "create on first sight, fill in later": the map hands out the copy even while it is still being built.

Why not just copy recursively like a tree? A tree has exactly one path to each node, so a plain recursive copy works. Here node 1 lists 2 and node 2 lists 1: a plain copy recurses 1 -> 2 -> 1 -> 2 forever. You need a memory of "already copied", and since you need the copy itself (to link to it), the memory must store the copy, not just a flag.

Taxonomy: Graphs → Traversal → Clone / reach. Pattern lessons: Graphs and Graph BFS. Same trick on a list: Copy List with Random Pointer.
