The problem (in our words)

A shelf scanner writes one reading per slot into an integer array nums; a reading of 0 means "empty slot". Rearrange the array in place so that every zero ends up at the end, while all the non-zero readings keep their original relative order. Do not allocate a copy of the array.

Signature: void moveZeroes(int[] nums). Nothing is returned; the judge reads nums after your function finishes.

  • 1 <= nums.length <= 104
  • -231 <= nums[i] <= 231 - 1

Follow-up: can you keep the total number of operations (writes) as small as possible?

Practice it: LeetCode 283 · GfG Move All Zeroes to End · TUF article

Constraints tell you: n <= 104, so even O(n2) would pass, but the interviewer wants O(n) and O(1) extra space ("in place"). Values span the full 32-bit range, including negatives: never use a value like -1 as a marker, and only compare with 0.
