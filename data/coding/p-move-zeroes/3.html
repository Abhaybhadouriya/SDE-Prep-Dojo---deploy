Recognise the pattern

Cue: "in place" + "keep the relative order" + "move / remove the elements that match X" -> same-direction two pointers: a reader r visits every element, a writer w marks the end of the kept part. It is the same loop as Remove Element and Remove Duplicates from Sorted Array.

RequirementToolWhy
Keep order, in placeReader + writer moving the same wayThe writer never overtakes the reader, so nothing unread is overwritten.
Order does not matterOpposite-end pointers (swap with the back)Fewer writes, but it scrambles the order: wrong here.
