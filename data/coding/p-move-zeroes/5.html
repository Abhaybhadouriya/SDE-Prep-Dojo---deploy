Dry run

Example 1, [0,5,0,2,8], with the one-pass swap. Blue cells are the compacted non-zeros [0, w), grey cells are the zero block [w, r).

  1. Start: w = 0 (next slot for a non-zero), r = 0 (next value to read). Nothing is placed yet.
  2. nums[0] = 0: skip it. The zero stays behind w and becomes part of the zero block [w..r].
  3. nums[1] = 5: swap it with nums[0] (the first zero of the block). The zero rolls right, w moves to 1.
  4. nums[2] = 0: skip it. The zero stays behind w and becomes part of the zero block [w..r].
  5. nums[3] = 2: swap it with nums[1] (the first zero of the block). The zero rolls right, w moves to 2.
  6. nums[4] = 8: swap it with nums[2] (the first zero of the block). The zero rolls right, w moves to 3. r has read everything: the array is [5, 2, 8, 0, 0], 3 swaps, order kept.
