Dry run

List 10 -> 20 -> 30 -> 40 -> 50, k = 2, expected 40 -> 50 -> 10 -> 20 -> 30.

  1. Input 10 -> 20 -> 30 -> 40 -> 50, k = 2. Rotating right by 2 moves the last two nodes to the front.
  2. Walk once to the tail, counting nodes: len = 5. Keep the tail pointer; we will need it to close the ring.
  3. k %= len keeps k = 2 (k = 7 or 12 would give the same list). The new tail is node len - k = 3, i.e. value 30: walk len - k - 1 = 2 steps from head.
  4. Point the old tail (50) at the old head (10). The list is now a ring, so any node can become the head.
  5. Remember newHead = 30.next = 40, then cut: 30.next = null. Result 40 -> 50 -> 10 -> 20 -> 30. Total work: one full walk plus one partial walk, O(n), O(1) memory.
