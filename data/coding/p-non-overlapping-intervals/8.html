Common mistakes

Sorting by start and keeping the first of each overlap. On [[1,10],[2,3],[4,5]] it keeps [1,10] and removes 2. If you sort by start, on an overlap keep the one with the smaller end.

Treating touching as overlap. Writing start > lastEnd removes [5,8] from [[3,5],[5,8]], answering 1 instead of 0.

Starting lastEnd at 0. Starts can be negative (down to -5 × 10^4), so [[-3,-1]] would be "removed". Use minus infinity, INT_MIN, or start with the first interval kept.

Comparator overflow. (a, b) -> a[1] - b[1] is safe here (values within ±5 × 10^4), but it overflows for full int ranges. Prefer Integer.compare, as in our code.

Counting merged groups. "How many overlap groups" (Merge Intervals) is a different question: [[1,3],[2,5],[4,6]] is one merged block, but you need to remove only one interval, not two.
