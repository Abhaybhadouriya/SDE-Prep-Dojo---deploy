Recognise the pattern

Cue: "remove the fewest intervals so none overlap" = "keep the most pairwise non-overlapping intervals" → interval scheduling: sort by end, greedy. Any time the question is about a maximum set of compatible intervals, the earliest finishing time wins.

Try a few rules on [[1,10], [2,3], [4,5]] (best answer: remove 1, the long one):

Greedy ruleKeepsRemovesCorrect?
Earliest start first[1,10]2✗ the long one blocks both short ones
Shortest first[2,3], [4,5]1✓ here, but fails on [[1,5],[4,7],[6,10]] (keeps [4,7] only)
Earliest end first[2,3], [4,5]1✓ always (proof below)
