Approaches: brute -> better -> optimal

Hint 1

How many rounds are there, if each round takes at most one letter from each word?

1. Brute force - concatenate with += in a loop

Idea: loop over the shorter length, doing res = res + word1[i] + word2[i], then add the leftover slice of the longer word.

O((n + m)²)time (immutable strings)
O(n + m)space

What is wasted: in Java every + on a string copies the whole result built so far, so the total work grows quadratically (CPython sometimes avoids the copy for +=, but that is an implementation detail, not a guarantee). At 200 letters you cannot see it, but an interviewer will ask. Also, the "leftover" step is a second code path that is easy to get wrong. -> rung 2.

2. Better - two pointers and a builder

Idea: pointers i into word1 and j into word2; while both have letters, append word1[i++] then word2[j++]; after the loop, append whatever is left of each (only one can be non-empty). Append into a StringBuilder / strings.Builder / list.

O(n + m)time
O(1)extra (output aside)

What is wasted: nothing in time, but two loops for one rule. Since i and j are always equal while both words have letters, one index is enough. -> rung 3.

3. Optimal - one index, two existence checks

out = []
for i in range(max(len(a), len(b))):
    if i < len(a): out.append(a[i])
    if i < len(b): out.append(b[i])
return "".join(out)
  1. Round i takes at most two letters. word1[i] first, then word2[i]; there are max(n, m) rounds.
  2. A finished word stops contributing. The i < n / i < m checks make the tail-append happen inside the same loop.
  3. Size is known. Reserve n + m once (C++ reserve, Java new StringBuilder(n + m), Go Grow) so there is no reallocation.
O(n + m)time
O(1)extra (output aside)

Why it works: letter word1[i] must land right after word2[i-1] (or first, for i = 0) whenever word2 is long enough, and right after word1[i-1] otherwise; round i appends exactly those letters in that order. By induction, after round i the output is the correct merge of word1[0..i] and word2[0..i]. After max(n, m) rounds both words are used up.
