Common mistakes

Looping to min(n, m) and forgetting the tail. "hi", "there" returns "htih". Either loop to max(n, m) with checks, or append both leftover slices after the loop.

Starting with word2. The order inside a round is fixed: word1 first. "ab", "pq" must give "apbq", not "paqb".

Indexing past the end. Looping to max(n, m) without the i < n check throws in Java (StringIndexOutOfBoundsException) and is undefined behaviour in C++ (operator[] past size()).

Quadratic string building. res += c in a Java loop copies the string each time; use a StringBuilder. In Python, collect into a list and "".join once.
