The problem (in our words)

Two radio operators each send a word, word1 and word2. Build one message by taking letters in alternating order, starting with word1: first letter of word1, first letter of word2, second letter of word1, second letter of word2, and so on. When one word runs out of letters, append the remaining letters of the other word, in order, at the end. Return the merged string.

Signature: String mergeAlternately(String word1, String word2).

Constraints:

  • 1 <= word1.length, word2.length <= 100
  • word1 and word2 consist of lowercase English letters.

Practice it: LeetCode 1768 · GfG Merge two strings

Constraints tell you: at most 200 output characters, so any linear method is instant; the point of the question is clean handling of unequal lengths. Both words have at least one letter, so there is no empty-input case on the judge (handle it anyway: the loop does it for free). The output has exactly n + m letters, so its size is known up front.
