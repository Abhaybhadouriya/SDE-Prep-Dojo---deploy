  • Cue: take from two sequences in turns; leftovers of the longer go at the end.
  • Insight: loop i to max(n, m); append a[i] if i < n, then b[i] if i < m.
  • State: one index i, one output buffer pre-sized to n + m.
  • Trap: min(n, m) loop drops the tail; word1 goes first; no string += in a loop.
  • Cost: O(n + m) time, O(1) extra besides the output; k strings -> round-robin queue.
out = []
for i in range(max(len(a), len(b))):
    if i < len(a): out.append(a[i])   # first source first
    if i < len(b): out.append(b[i])   # an exhausted source is skipped
return "".join(out)
