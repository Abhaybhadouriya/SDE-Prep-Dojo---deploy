DFS and BFS: the two ways to walk

Every graph algorithm on this page is a walk with some bookkeeping. There are only two walks.

  • Depth-first search (DFS) follows one path as deep as it can, then backs up. It uses a stack: either the call stack (recursion) or an explicit one. Good for: "visit everything reachable", counting components, flood fill, cycle detection, topological order, path existence.
  • Breadth-first search (BFS) visits all vertices at distance 1, then distance 2, and so on. It uses a FIFO queue. Good for: fewest steps in an unweighted graph, "minimum moves", "nearest X", anything that spreads in waves (rotting oranges, fire, infection).

Both visit each vertex once and look at each edge once (twice for undirected), so both run in O(V + E) time with O(V) extra space for the seen marks and the stack or queue. On a grid that is O(R x C).

The one rule that prevents most bugs: mark a vertex as seen when you push it, not when you pop it. If you mark on pop, the same vertex gets pushed many times from different neighbours; BFS distances stay correct but the queue can blow up to O(E) entries and a grid solution times out.

Watch BFS find shortest paths

Below, BFS starts at vertex 0. Orange vertices have just been discovered and sit in the queue; teal ones are already discovered. The label next to each vertex is its distance, fixed forever the moment it is discovered.

  1. Start: set dist[0] = 0, mark 0 as seen and push it. Nothing else is known yet.
  2. Pop 0. Its neighbours 1 and 2 are new: give them distance 1, mark them, push them. Layer 1 is complete.
  3. Pop 1: neighbour 3 is new (distance 2). Pop 2: 3 is already marked so it is skipped; 4 is new (distance 2).
  4. Pop 3: 5 is new (distance 3). Pop 4: 5 is already marked. Marking on push is what stops 5 entering the queue twice.
  5. Pop 5: 6 is new (distance 4). Every vertex now has its final distance.
  6. The queue is empty. If we had stored parent[v] when discovering v, walking parents back from 6 gives a shortest path.

Why is the first discovery the shortest? BFS pulls vertices out of the queue in non-decreasing order of distance (all of layer k before any of layer k+1). A vertex is first reached from some vertex of the earliest possible layer, so its distance cannot be improved later. This argument needs every edge to cost the same; with weights it breaks, and you need Dijkstra (below).

Template 1: BFS on a grid (single or multi-source)

This one function solves Shortest Path in Binary Matrix, Rotting Oranges, 01 Matrix, Walls and Gates and As Far From Land as Possible. The only change between them is what counts as a wall and which cells you seed as sources. Seeding many sources at distance 0 is called multi-source BFS: it computes "distance to the nearest source" for every cell in one pass, instead of one BFS per source.

Every version on this page, Go included, was compiled and run (Go 1.27, C++14, Java 21, Python 3.11) and passes its checks.

// bfsGrid: grid '#' = wall. Steps from the nearest source, -1 = unreachable.
func bfsGrid(grid []string, sources [][2]int) [][]int {
    R, C := len(grid), len(grid[0])
    dist := make([][]int, R)
    for i := range dist {
        dist[i] = make([]int, C)
        for j := range dist[i] {
            dist[i][j] = -1
        }
    }
    q := [][2]int{}
    for _, s := range sources {
        dist[s[0]][s[1]] = 0
        q = append(q, s)
    }
    dirs := [4][2]int{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}
    for head := 0; head < len(q); head++ { // slice + head index = queue
        r, c := q[head][0], q[head][1]
        for _, d := range dirs {
            nr, nc := r+d[0], c+d[1]
            if nr < 0 || nr >= R || nc < 0 || nc >= C {
                continue
            }
            if grid[nr][nc] == '#' || dist[nr][nc] != -1 {
                continue
            }
            dist[nr][nc] = dist[r][c] + 1 // mark when you PUSH, not when you pop
            q = append(q, [2]int{nr, nc})
        }
    }
    return dist
}

// grid: '#' = wall. Returns steps from the nearest source, -1 = unreachable.
vector<vector<int>> bfsGrid(const vector<string>& grid, const vector<pair<int,int>>& sources) {
    int R = grid.size(), C = grid[0].size();
    vector<vector<int>> dist(R, vector<int>(C, -1));
    queue<pair<int,int>> q;
    for (const auto& s : sources) { dist[s.first][s.second] = 0; q.push(s); }
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    while (!q.empty()) {
        int r = q.front().first, c = q.front().second; q.pop();
        for (int k = 0; k < 4; k++) {
            int nr = r + dr[k], nc = c + dc[k];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            if (grid[nr][nc] == '#' || dist[nr][nc] != -1) continue;
            dist[nr][nc] = dist[r][c] + 1;      // mark when you PUSH, not when you pop
            q.push({nr, nc});
        }
    }
    return dist;
}

static int[][] bfsGrid(String[] grid, int[][] sources) {
    int R = grid.length, C = grid[0].length();
    int[][] dist = new int[R][C];
    for (int[] row : dist) Arrays.fill(row, -1);
    ArrayDeque<int[]> q = new ArrayDeque<>();
    for (int[] s : sources) { dist[s[0]][s[1]] = 0; q.add(s); }
    int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    while (!q.isEmpty()) {
        int[] cur = q.poll();
        for (int[] d : dirs) {
            int nr = cur[0] + d[0], nc = cur[1] + d[1];
            if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
            if (grid[nr].charAt(nc) == '#' || dist[nr][nc] != -1) continue;
            dist[nr][nc] = dist[cur[0]][cur[1]] + 1;   // mark when you PUSH
            q.add(new int[]{nr, nc});
        }
    }
    return dist;
}
from collections import deque

def bfs_grid(grid, sources):
    """grid: list of strings, '#' = wall. Returns steps from the nearest source, -1 = unreachable."""
    R, C = len(grid), len(grid[0])
    dist = [[-1] * C for _ in range(R)]
    q = deque()
    for r, c in sources:                      # one source or many (multi-source BFS)
        dist[r][c] = 0
        q.append((r, c))
    while q:
        r, c = q.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C and grid[nr][nc] != '#' and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1     # mark when you PUSH, not when you pop
                q.append((nr, nc))
    return dist
