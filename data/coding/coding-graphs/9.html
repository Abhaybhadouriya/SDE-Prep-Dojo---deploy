Minimum spanning tree (overview)

A spanning tree connects all V vertices with exactly V-1 edges and no cycle. The minimum spanning tree (MST) is the one with the smallest total weight: the cheapest way to wire every city. Interviews ask for it rarely and only in its plain form (Min Cost to Connect All Points, Connecting Cities With Minimum Cost), so knowing one algorithm well is enough:

  • Kruskal: sort edges by weight; walk them cheapest first; keep an edge if union-find says its ends are in different groups. Stop at V-1 edges. O(E log E). Best when you are given an edge list.
  • Prim: grow one tree from a start vertex; repeatedly add the cheapest edge leaving the tree (min-heap, like Dijkstra but keyed on the edge weight, not the path sum). O(E log V); on a complete graph of points, the O(V2) array version without a heap is the fastest.

Do not confuse MST with shortest paths: the MST minimises the total wiring, not the distance between any particular pair.
