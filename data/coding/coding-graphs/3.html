Grid DFS and connected components

A connected component is a maximal group of vertices that can all reach each other. "How many islands", "how many provinces", "how many friend circles", "how many separate networks": all of these are "count the components". The recipe:

  1. Loop over every vertex. For a grid, every cell.
  2. Skip it if it is not part of the graph (water) or already seen.
  3. Otherwise you found a new component. Add one to the count and flood it: DFS or BFS from it, marking everything reachable.

Each vertex is flooded once overall, so the whole count is still O(V + E). The flood can also compute something per component: its size (Max Area of Island), its shape (Number of Distinct Islands: record the path of moves), or whether it touches the border (Surrounded Regions and Number of Enclaves: flood from the border first, then everything not flooded is enclosed).

// countIslands: grid of '1' (land) / '0' (water). Iterative DFS with an explicit stack.
func countIslands(grid []string) int {
    R, C := len(grid), len(grid[0])
    seen := make([][]bool, R)
    for i := range seen {
        seen[i] = make([]bool, C)
    }
    dirs := [4][2]int{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}
    islands := 0
    for i := 0; i < R; i++ {
        for j := 0; j < C; j++ {
            if grid[i][j] != '1' || seen[i][j] {
                continue
            }
            islands++ // new component: flood it
            seen[i][j] = true
            stack := [][2]int{{i, j}}
            for len(stack) > 0 {
                cur := stack[len(stack)-1]
                stack = stack[:len(stack)-1]
                for _, d := range dirs {
                    nr, nc := cur[0]+d[0], cur[1]+d[1]
                    if nr < 0 || nr >= R || nc < 0 || nc >= C {
                        continue
                    }
                    if grid[nr][nc] != '1' || seen[nr][nc] {
                        continue
                    }
                    seen[nr][nc] = true
                    stack = append(stack, [2]int{nr, nc})
                }
            }
        }
    }
    return islands
}
// grid of '1' (land) / '0' (water). Iterative DFS: no stack overflow on a 1000x1000 grid.
int countIslands(const vector<string>& grid) {
    int R = grid.size(), C = grid[0].size(), islands = 0;
    vector<vector<char>> seen(R, vector<char>(C, 0));
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    for (int i = 0; i < R; i++)
        for (int j = 0; j < C; j++) {
            if (grid[i][j] != '1' || seen[i][j]) continue;
            islands++;                              // new component: flood it
            seen[i][j] = 1;
            vector<pair<int,int>> st(1, {i, j});
            while (!st.empty()) {
                int r = st.back().first, c = st.back().second; st.pop_back();
                for (int k = 0; k < 4; k++) {
                    int nr = r + dr[k], nc = c + dc[k];
                    if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
                    if (grid[nr][nc] != '1' || seen[nr][nc]) continue;
                    seen[nr][nc] = 1;
                    st.push_back({nr, nc});
                }
            }
        }
    return islands;
}
static int countIslands(String[] grid) {
    int R = grid.length, C = grid[0].length(), islands = 0;
    boolean[][] seen = new boolean[R][C];
    int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
    for (int i = 0; i < R; i++)
        for (int j = 0; j < C; j++) {
            if (grid[i].charAt(j) != '1' || seen[i][j]) continue;
            islands++;                                  // new component: flood it
            seen[i][j] = true;
            ArrayDeque<int[]> st = new ArrayDeque<>();
            st.push(new int[]{i, j});
            while (!st.isEmpty()) {
                int[] cur = st.pop();
                for (int[] d : dirs) {
                    int nr = cur[0] + d[0], nc = cur[1] + d[1];
                    if (nr < 0 || nr >= R || nc < 0 || nc >= C) continue;
                    if (grid[nr].charAt(nc) != '1' || seen[nr][nc]) continue;
                    seen[nr][nc] = true;
                    st.push(new int[]{nr, nc});
                }
            }
        }
    return islands;
}
def count_islands(grid):
    """grid: list of strings of '1' (land) / '0' (water). Iterative DFS: no recursion limit."""
    R, C = len(grid), len(grid[0])
    seen = [[False] * C for _ in range(R)]
    islands = 0
    for i in range(R):
        for j in range(C):
            if grid[i][j] != '1' or seen[i][j]:
                continue
            islands += 1                          # new component found: flood it
            seen[i][j] = True
            stack = [(i, j)]
            while stack:
                r, c = stack.pop()
                for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                    if 0 <= nr < R and 0 <= nc < C and grid[nr][nc] == '1' and not seen[nr][nc]:
                        seen[nr][nc] = True
                        stack.append((nr, nc))
    return islands

Recursive or iterative? Recursive DFS is shorter and fine for most LeetCode inputs, but a 1000 x 1000 grid that is all land recurses a million deep. Python's default limit is 1000 frames and C++ can overflow an 8 MB stack. The explicit stack above has neither problem. Say this out loud in the interview: it shows you think about the real machine.

From your world

Recursion depth is stack usage, the same reason kernel code avoids recursion on its 8 or 16 KB thread stacks. An explicit stack on the heap is what you would write in a driver.

Two tricks: you may mark seen by overwriting the grid (set land to '0'), but ask first. For "reverse" questions like Pacific Atlantic Water Flow, run the search from the targets inward (from each ocean's border cells uphill) instead of from every cell outward; that turns O((RC)2) into O(RC).
