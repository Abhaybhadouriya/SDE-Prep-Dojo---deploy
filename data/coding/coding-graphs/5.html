Cycle detection and the bipartite check

"Is there a cycle?" has two different answers depending on whether edges have direction. Mixing them up is a classic interview mistake.

Undirected graphs

During DFS or BFS, if you reach an already-seen vertex that is not the vertex you just came from, you found a cycle. You must pass the parent along, because in an undirected graph every edge u-v looks like a cycle u → v → u otherwise. Even simpler: process edges with union-find; if both ends of an edge already have the same root, that edge closes a cycle (this is Redundant Connection, and Graph Valid Tree is "exactly n-1 edges and no cycle").

Directed graphs: three colours

In a directed graph, seeing an old vertex is not enough (two paths can merge without forming a loop). You need to know whether that vertex is still on the current DFS path. Give every vertex one of three colours: WHITE (never visited), GRAY (on the current path, its DFS has not finished), BLACK (finished, everything below it explored). An edge into a GRAY vertex is a back edge, and a back edge means a cycle.

def has_cycle_directed(n, adj):
    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * n

    def dfs(u):
        color[u] = GRAY                           # on the current path
        for v in adj[u]:
            if color[v] == GRAY:
                return True                       # back edge: cycle
            if color[v] == WHITE and dfs(v):
                return True
        color[u] = BLACK                          # finished, safe
        return False

    return any(color[u] == WHITE and dfs(u) for u in range(n))

The vertices that end BLACK without ever touching a cycle are exactly the answer to Find Eventual Safe States. Kahn's algorithm in the next section detects directed cycles too, without recursion, and is usually the one to write in an interview.

Bipartite check

A graph is bipartite if you can split the vertices into two teams so every edge joins different teams. Colour the start vertex 0, colour each new neighbour the opposite colour, and fail if an edge joins two vertices of the same colour. Run it from every uncoloured vertex because the graph may be disconnected. Problems: Is Graph Bipartite, Possible Bipartition ("split people who dislike each other into two groups").

def is_bipartite(n, adj):
    side = [-1] * n
    for s in range(n):
        if side[s] != -1:
            continue
        side[s] = 0
        q = deque([s])
        while q:
            u = q.popleft()
            for v in adj[u]:
                if side[v] == -1:
                    side[v] = 1 - side[u]
                    q.append(v)
                elif side[v] == side[u]:
                    return False                  # odd cycle
    return True
