How to recognise which tool

The question says...Think
grid of 0/1 or characters, "islands", "regions", "connected"grid DFS/BFS flood fill; count components
"minimum number of steps / moves / transformations", every move costs the sameBFS (multi-source if there are many starts)
"prerequisites", "order", "dependencies", "build order", "alien alphabet"topological sort (Kahn); cycle = impossible
"is it possible to finish / is there a deadlock?" on a directed graphdirected cycle detection (Kahn count or three colours)
"split into two groups so no conflicting pair is together"bipartite check (2-colouring)
"merge accounts / groups that share X", edges arrive over time, "redundant edge"union-find
weighted edges, "minimum cost / time / effort" from one sourceDijkstra; with a stop limit, Bellman-Ford or BFS over (node, stops)
"connect all points with minimum total cost"MST (Kruskal with union-find, or Prim)
"copy the graph", "clone"DFS/BFS with a map old node → new node

Read the constraints. V and E up to 105 means O(V + E) or O(E log V) only. A grid up to 1000 x 1000 = 106 cells means one linear pass, iterative DFS or BFS. n up to 15-20 with "visit all nodes" means BFS or DP over a bitmask of visited nodes (Shortest Path Visiting All Nodes).
