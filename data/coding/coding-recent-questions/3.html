What the list is made of

Problems carry LeetCode topic tags. Grouping the tags into eight pattern families shows what each company leans on. One problem can count in two columns (Number of Islands is both "graph" and "matrix"), so rows do not add up to 100%.

Each family has a primer page: Graphs, Trees, Dynamic programming, Sliding window and Two pointers, Stacks and queues, Heaps, Design problems and Binary search. Across all reports, the most common raw tags are array (994), string (468), hash table (449), DFS (359), BFS (310) and DP (291).
