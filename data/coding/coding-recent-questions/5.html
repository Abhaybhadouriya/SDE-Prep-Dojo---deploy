  • SDE-1 / new grad: classic problems with a clear pattern: Number of Islands, Rotting Oranges, Merge Intervals. The bar is a correct, clean solution with the complexity stated, and testing without prompting.
  • SDE-2: the same problems with a twist, and two problems per round at Meta. The bar adds speed and handling the follow-up ("now the input is a stream").
  • SDE-3: more design-shaped problems (Max Stack, All O`one Data Structure, LRU) where you choose the data structures yourself, plus Hards like Reverse Nodes in k-Group. The bar adds trade-offs, production concerns (thread safety, memory) and leading the discussion.
