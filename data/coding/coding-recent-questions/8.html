Two templates that cover the top of the list

Two pieces of code carry a large share of the top 30: the LRU cache (hash map plus doubly linked list, also the base of LFU, Max Stack and All O`one) and multi-source BFS by levels (Rotting Oranges, and with small changes Number of Islands, 01 Matrix, Walls and Gates, Course Schedule's Kahn loop). Step through both, then keep the code.

LRU cache, step by step

Capacity 2. The list keeps keys in use order, most recent next to HEAD. The map finds any node in O(1), so moving a node to the front or removing the last one is O(1) too. Every node stores its key, because when we evict tail.prev we must also delete it from the map.

  1. put(1, 10): insert key 1 at the front. List after: 1:10.
  2. put(2, 20): insert key 2 at the front. List after: 2:20 → 1:10.
  3. get(1): returns 10; key 1 moved to the front. List after: 1:10 → 2:20.
  4. put(3, 30): full: evict tail.prev = key 2, then insert 3 at the front. List after: 3:30 → 1:10.
  5. get(2): returns -1 (miss); nothing moves. List after: 3:30 → 1:10.
  6. put(1, 11): key 1 exists: update value, move to front, no eviction. List after: 1:11 → 3:30.

From your world

This is struct list_head with a sentinel: head.next is the first entry, an empty list points at itself, and unlinking needs no special case for the first or last node. get is list_move(&n->lru, &cache->head); eviction is list_last_entry() then list_del(). The kernel's page reclaim works on the same idea at scale, with active and inactive LRU lists (and MGLRU's generations) instead of one list.

Multi-source BFS, step by step

Rotting Oranges: every minute, each rotten orange rots its fresh neighbours. Put all rotten oranges in the queue at minute 0, then process the queue one level at a time; the level number is the minute. Mark a cell rotten when you push it, so no cell enters the queue twice.

  1. Scan the grid once: every rotten orange goes into the queue at minute 0 (here only (0,0)), and we count 6 fresh oranges.
  2. Minute 1: pop the whole previous level and rot each fresh neighbour, marking it as it is pushed: (1,0), (0,1). Fresh left: 4.
  3. Minute 2: pop the whole previous level and rot each fresh neighbour, marking it as it is pushed: (1,1), (0,2). Fresh left: 2.
  4. Minute 3: pop the whole previous level and rot each fresh neighbour, marking it as it is pushed: (2,1). Fresh left: 1.
  5. Minute 4: pop the whole previous level and rot each fresh neighbour, marking it as it is pushed: (2,2). Fresh left: 0. The loop stops because nothing fresh is left; return the minute count.

From your world

BFS levels are hop counts. A route update flooding out from several routers at once, or a TTL that drops by one per hop, is the same picture: level k is "everything reachable in exactly k hops from any source". Starting with all sources in the queue gives the distance to the nearest source without running one BFS per source.

The code

The same two functions in four languages, each with its tests in coding-code/coding-recent-questions/. Write the LRU by hand in the interview: Python's OrderedDict.move_to_end and Java's LinkedHashMap with access order solve it in five lines, so ask first; most interviewers want the list.

What is in each file (same names in every language; Go and Java use camelCase):

  • Node - doubly linked list node used by the LRU cache.
  • LRUCache - LC 146: hash map of keys to nodes of a doubly linked list, most recent at the front.
  • oranges_rotting - LC 994: multi-source BFS, minutes until no fresh orange is left, or -1.

// Recently asked questions: LRU cache (LC 146) and multi-source BFS (LC 994).
package main

import "fmt"

type node struct {
	key, val   int
	prev, next *node
}

type LRUCache struct {
	cap        int
	m          map[int]*node
	head, tail *node // sentinels: head.next is the most recent
}

func Constructor(capacity int) LRUCache {
	h, t := &node{}, &node{}
	h.next, t.prev = t, h
	return LRUCache{cap: capacity, m: make(map[int]*node), head: h, tail: t}
}

func (c *LRUCache) unlink(n *node) { n.prev.next, n.next.prev = n.next, n.prev }

func (c *LRUCache) pushFront(n *node) {
	n.prev, n.next = c.head, c.head.next
	c.head.next.prev = n
	c.head.next = n
}

func (c *LRUCache) Get(key int) int {
	n, ok := c.m[key]
	if !ok {
		return -1
	}
	c.unlink(n) // a read is a use
	c.pushFront(n)
	return n.val
}

func (c *LRUCache) Put(key, value int) {
	if n, ok := c.m[key]; ok {
		n.val = value
		c.unlink(n)
		c.pushFront(n)
		return
	}
	if len(c.m) == c.cap { // evict before inserting
		lru := c.tail.prev
		c.unlink(lru)
		delete(c.m, lru.key)
	}
	n := &node{key: key, val: value}
	c.m[key] = n
	c.pushFront(n)
}

// orangesRotting: 0 empty, 1 fresh, 2 rotten. Minutes until no fresh orange is left, or -1.
func orangesRotting(grid [][]int) int {
	rows, cols, fresh := len(grid), len(grid[0]), 0
	q := [][2]int{}
	for r := 0; r < rows; r++ {
		for c := 0; c < cols; c++ {
			if grid[r][c] == 2 {
				q = append(q, [2]int{r, c}) // all sources at minute 0
			} else if grid[r][c] == 1 {
				fresh++
			}
		}
	}
	dirs := [4][2]int{{1, 0}, {-1, 0}, {0, 1}, {0, -1}}
	minutes := 0
	for len(q) > 0 && fresh > 0 {
		next := [][2]int{} // one level = one minute
		for _, cur := range q {
			for _, d := range dirs {
				nr, nc := cur[0]+d[0], cur[1]+d[1]
				if nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] == 1 {
					grid[nr][nc] = 2 // mark when pushed
					fresh--
					next = append(next, [2]int{nr, nc})
				}
			}
		}
		q = next
		minutes++
	}
	if fresh > 0 {
		return -1
	}
	return minutes
}
// Recently asked questions: LRU cache (LC 146) and multi-source BFS (LC 994). C++14.
#include <cstdio>
#include <queue>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;

class LRUCache {
    struct Node { int key, val; Node *prev, *next; };
    int cap;
    unordered_map<int, Node*> m;   // key -> node
    Node head{0, 0, nullptr, nullptr}, tail{0, 0, nullptr, nullptr};  // sentinels
    void unlink(Node* n) { n->prev->next = n->next; n->next->prev = n->prev; }
    void pushFront(Node* n) {
        n->prev = &head; n->next = head.next;
        head.next->prev = n; head.next = n;
    }
public:
    explicit LRUCache(int capacity) : cap(capacity) { head.next = &tail; tail.prev = &head; }
    ~LRUCache() { for (auto& kv : m) delete kv.second; }
    int get(int key) {
        auto it = m.find(key);
        if (it == m.end()) return -1;
        unlink(it->second); pushFront(it->second);   // a read is a use
        return it->second->val;
    }
    void put(int key, int value) {
        auto it = m.find(key);
        if (it != m.end()) {
            it->second->val = value;
            unlink(it->second); pushFront(it->second);
            return;
        }
        if ((int)m.size() == cap) {                  // evict before inserting
            Node* lru = tail.prev;
            unlink(lru); m.erase(lru->key); delete lru;
        }
        Node* n = new Node{key, value, nullptr, nullptr};
        m[key] = n; pushFront(n);
    }
};

// 0 empty, 1 fresh, 2 rotten. Minutes until no fresh orange is left, or -1.
int orangesRotting(vector<vector<int>> grid) {
    int rows = grid.size(), cols = grid[0].size(), fresh = 0;
    queue<pair<int, int>> q;
    for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++) {
            if (grid[r][c] == 2) q.push({r, c});      // all sources at minute 0
            else if (grid[r][c] == 1) fresh++;
        }
    const int dr[] = {1, -1, 0, 0}, dc[] = {0, 0, 1, -1};
    int minutes = 0;
    while (!q.empty() && fresh > 0) {
        for (int k = q.size(); k > 0; k--) {          // one level = one minute
            auto cur = q.front(); q.pop();
            for (int d = 0; d < 4; d++) {
                int nr = cur.first + dr[d], nc = cur.second + dc[d];
                if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] == 1) {
                    grid[nr][nc] = 2;                   // mark when pushed
                    fresh--;
                    q.push({nr, nc});
                }
            }
        }
        minutes++;
    }
    return fresh == 0 ? minutes : -1;
}

import java.util.ArrayDeque;
import java.util.HashMap;
import java.util.Map;

public class Templates {
    static class LRUCache {
        private static final class Node {
            int key, val; Node prev, next;
            Node(int k, int v) { key = k; val = v; }
        }
        private final int cap;
        private final Map<Integer, Node> map = new HashMap<>();
        private final Node head = new Node(0, 0), tail = new Node(0, 0);  // sentinels

        LRUCache(int capacity) { cap = capacity; head.next = tail; tail.prev = head; }

        private void unlink(Node n) { n.prev.next = n.next; n.next.prev = n.prev; }
        private void pushFront(Node n) {
            n.prev = head; n.next = head.next;
            head.next.prev = n; head.next = n;
        }

        int get(int key) {
            Node n = map.get(key);
            if (n == null) return -1;
            unlink(n); pushFront(n);                 // a read is a use
            return n.val;
        }

        void put(int key, int value) {
            Node n = map.get(key);
            if (n != null) { n.val = value; unlink(n); pushFront(n); return; }
            if (map.size() == cap) {                 // evict before inserting
                Node lru = tail.prev;
                unlink(lru); map.remove(lru.key);
            }
            n = new Node(key, value);
            map.put(key, n); pushFront(n);
        }
    }

    // 0 empty, 1 fresh, 2 rotten. Minutes until no fresh orange is left, or -1.
    static int orangesRotting(int[][] grid) {
        int rows = grid.length, cols = grid[0].length, fresh = 0;
        ArrayDeque<int[]> q = new ArrayDeque<>();
        for (int r = 0; r < rows; r++)
            for (int c = 0; c < cols; c++) {
                if (grid[r][c] == 2) q.add(new int[]{r, c});   // all sources at minute 0
                else if (grid[r][c] == 1) fresh++;
            }
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};
        int minutes = 0;
        while (!q.isEmpty() && fresh > 0) {
            for (int k = q.size(); k > 0; k--) {               // one level = one minute
                int[] cur = q.poll();
                for (int[] d : dirs) {
                    int nr = cur[0] + d[0], nc = cur[1] + d[1];
                    if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && grid[nr][nc] == 1) {
                        grid[nr][nc] = 2;                        // mark when pushed
                        fresh--;
                        q.add(new int[]{nr, nc});
                    }
                }
            }
            minutes++;
        }
        return fresh == 0 ? minutes : -1;
    }
}
# Recently asked questions: the two most reusable templates.
# 1) LRU cache (LeetCode 146): hash map + doubly linked list with sentinels.
# 2) Multi-source BFS by levels (LeetCode 994 Rotting Oranges shape).
from collections import deque


class Node:
    __slots__ = ("key", "val", "prev", "next")

    def __init__(self, key=0, val=0):
        self.key, self.val = key, val
        self.prev = self.next = None


class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.map = {}                          # key -> Node
        self.head, self.tail = Node(), Node()  # sentinels: head.next = most recent
        self.head.next, self.tail.prev = self.tail, self.head

    def _unlink(self, n):
        n.prev.next, n.next.prev = n.next, n.prev

    def _push_front(self, n):
        n.prev, n.next = self.head, self.head.next
        self.head.next.prev = n
        self.head.next = n

    def get(self, key):
        n = self.map.get(key)
        if n is None:
            return -1
        self._unlink(n)                        # a read is a use: move to front
        self._push_front(n)
        return n.val

    def put(self, key, value):
        n = self.map.get(key)
        if n is not None:                      # update counts as a use too
            n.val = value
            self._unlink(n)
            self._push_front(n)
            return
        if len(self.map) == self.cap:          # evict BEFORE inserting
            lru = self.tail.prev
            self._unlink(lru)
            del self.map[lru.key]              # why the node stores its key
        n = Node(key, value)
        self.map[key] = n
        self._push_front(n)


def oranges_rotting(grid):
    """0 empty, 1 fresh, 2 rotten. Minutes until no fresh orange is left, or -1."""
    rows, cols = len(grid), len(grid[0])
    q, fresh = deque(), 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                q.append((r, c))               # every source starts at minute 0
            elif grid[r][c] == 1:
                fresh += 1
    minutes = 0
    while q and fresh:                         # stop when nothing is left to rot
        for _ in range(len(q)):                # one level = one minute
            r, c = q.popleft()
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2           # mark when pushed, not when popped
                    fresh -= 1
                    q.append((nr, nc))
        minutes += 1
    return minutes if fresh == 0 else -1

Complexity: LRU get and put are O(1) average time, O(capacity) space. The BFS is O(rows x cols) time and space: every cell is pushed at most once.
