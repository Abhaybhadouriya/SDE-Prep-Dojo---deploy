Common mistakes

Merging by name. Same name does not mean same person. Only emails connect accounts.

Merging only direct overlaps. A single pass that merges account i into the first account it overlaps misses chains formed later. Union-find (or a graph traversal) handles the transitive part.

Building a clique per account. Connecting every pair of emails in an account is O(L²) edges; a star from the first email (or union with the first owner) is enough.

Forgetting to sort or to dedupe. Output emails must be sorted and unique. Collecting from the email -> owner map gives each email once.

Using == on strings in Java. A string-keyed union-find with parent.get(s) == s compares references; it works by accident on LeetCode for some inputs. Compare with equals, or union indices as we do.
