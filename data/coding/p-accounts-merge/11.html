Union-find or DFS: which would you code and why?

Both are O(N log N) with the sort. Union-find unions while reading and needs only a parent array over accounts; DFS needs the full adjacency list first and recursion (or a stack). I code union-find and mention DFS as the equivalent alternative.

How to answer

What is the complexity, exactly?

With N total emails and A accounts: the scan does N map operations and up to N unions, O(N·α(A)). Grouping is O(N). Sorting all groups is O(N log N) in the worst case (one big group). Memory O(N) for the map and groups plus O(A) for parents.

How to answer

State what N is first; most errors come from mixing up accounts and emails.
