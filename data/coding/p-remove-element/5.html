Example 2, nums = [4,0,7,7,2,4,7,1], val = 7, with the reader/writer copy. Blue cells are the kept part [0, w); grey cells were already read and may be overwritten.

  1. Start: w = 0 (next slot for a kept value), r = 0 (next value to read), val = 7.
  2. nums[0] = 4 is kept and r = w, so the copy writes it onto itself; w moves to 1.
  3. nums[1] = 0 is kept and r = w, so the copy writes it onto itself; w moves to 2.
  4. nums[2] = 7 = val: skip it. Nothing is written; w stays 2, so slot 2 will be overwritten later.
  5. nums[3] = 7 = val: skip it. Nothing is written; w stays 2, so slot 2 will be overwritten later.
  6. nums[4] = 2 is kept: copy it to slot 2 (over a stale value), w moves to 3.
  7. nums[5] = 4 is kept: copy it to slot 3 (over a stale value), w moves to 4.
  8. nums[6] = 7 = val: skip it. Nothing is written; w stays 4, so slot 4 will be overwritten later.
  9. nums[7] = 1 is kept: copy it to slot 4 (over a stale value), w moves to 5. Done: return k = 5; the first 5 slots hold [4, 0, 2, 4, 1], in input order. Slots 5..7 are junk the judge ignores.
