60-second recall

  • Cue: remove in place, return the new length, tail ignored -> reader r + writer w.
  • Insight: [0,w) = kept values in order; w <= r, so copying never loses an unread value.
  • State: w (next write slot, also the answer), r (next read).
  • Trap: swap-with-last must re-check slot i; return kept count, mutate the given array.
  • Cost: O(n), O(1); copy = #kept writes, overwrite-with-last = #hits writes.
w = 0
for x in a:
    if keep(x):
        a[w] = x; w += 1
return w            # a[:w] = kept values, in order
