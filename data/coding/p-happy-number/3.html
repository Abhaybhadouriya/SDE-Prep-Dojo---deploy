Cue: "apply f repeatedly; does it reach X or loop forever?" -> the values form a functional graph (every node has exactly one outgoing edge), so the path is a "rho": a tail into one cycle. Detect the cycle with a seen-set or with fast/slow pointers.

Linked List Cycle is the same algorithm with node.next; Find the Duplicate Number uses nums[i] as next. Here, next is digitSquareSum(x). Whenever "next" is a pure function of the current value, you can run Floyd on it without building any list.
