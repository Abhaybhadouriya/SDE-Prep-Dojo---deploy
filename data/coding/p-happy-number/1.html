The problem (in our words)

Decide whether a positive integer n is happy. Starting from n, repeatedly replace the current number with the sum of the squares of its decimal digits. If this process eventually reaches 1 (where it stays, because 1² = 1), n is happy. Otherwise the process loops forever through a cycle that does not contain 1, and n is not happy.

Return true if n is happy and false otherwise.

Signature: boolean isHappy(int n).

  • 1 <= n <= 231 - 1

Practice it: LeetCode 202 · GfG Digit Square Sequence

Constraints tell you: n has at most 10 digits, so the first step already drops it to at most 10 · 81 = 810. From then on everything stays at or below 3 · 81 = 243 (see the proof below). The work is tiny; what is graded is the termination argument and the space.
