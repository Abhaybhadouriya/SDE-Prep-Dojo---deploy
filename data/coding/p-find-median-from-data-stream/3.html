Recognise the pattern

When you see "numbers arrive over time" + "report the middle / k-th / percentile after each one", think two heaps split at the boundary. If you only ever need the k largest, one heap of size k is enough; if items also leave (a sliding window), add lazy deletion or use a balanced tree.

Try a few tiny streams and look at where the median lives:

Stream so farSmall halfLarge halfMedian
5{5}{}5 = max(small)
5, 1{1}{5}(1 + 5) / 2
5, 1, 3{1, 3}{5}3 = max(small)
5, 1, 3, 9{1, 3}{5, 9}(3 + 5) / 2

Only max(small) and min(large) ever appear in the answer. A structure that gives a max or a min fast is a heap.
