Common mistakes

Balancing sizes but not order. Pushing num into whichever heap is smaller breaks "low <= high". Add 5 (low = {5}), add 1 (high = {1}), add 9 (low = {9, 5}): the code reports 9, but the sorted list is [1, 5, 9] and the median is 5. Always route the new value through one heap first.

Integer division for the even case. (a + b) / 2 with ints drops the .5. Cast first: (a + (double) b) / 2.0.

Python heaps are min-heaps only. Store negated values for the max-heap and negate again when you read -low[0]. Forgetting one sign flip gives the wrong half.

Java's PriorityQueue comparator. (a, b) -> b - a overflows for large opposite-sign ints; use Collections.reverseOrder() or Integer.compare(b, a).
