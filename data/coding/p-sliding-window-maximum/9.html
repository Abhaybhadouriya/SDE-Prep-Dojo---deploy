  • Cue: fixed window + max/min per window (or dp over the last k cells).
  • Insight: a value beaten by a newer one is dead; kept values decrease, front = max.
  • State: deque of indices, values strictly decreasing front to back.
  • Trap: store indices; expire when dq[0] <= i - k; output from i = k - 1.
  • Cost: O(n) amortised, O(k) space; heap O(n log n); brute O(n·k).
for i, x in enumerate(a):
    if dq and dq[0] <= i - k: dq.popleft()     # expired
    while dq and a[dq[-1]] <= x: dq.pop()       # dominated
    dq.append(i)
    if i >= k - 1: emit(a[dq[0]])

Why can index j be dropped when a later index i has nums[i] ≥ nums[j]?

  1. Because j is smaller
  2. Because the deque has a size limit of k
  3. j leaves the window before i and is never larger, so it can never be a window max again
Every future window that contains j also contains i.

What is the total number of deque pops over the whole run?

  1. At most n
  2. At most n·k
  3. Exactly k
Each index is pushed once, so it can be popped at most once, from the front or the back.

For the minimum instead of the maximum, what changes?

  1. Pop from the front instead of the back
  2. Keep values increasing: pop the back while nums[back] ≥ x
  3. Nothing
Flip the comparison; the expiry rule is unchanged.
