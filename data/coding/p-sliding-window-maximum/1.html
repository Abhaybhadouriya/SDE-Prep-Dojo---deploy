The problem (in our words)

A network probe writes one latency reading per second into the array nums. A dashboard shows the peak latency over the last k seconds. Picture a window of exactly k consecutive readings that starts at the left end and moves right by one position at a time until it reaches the right end.

Return an array with the maximum of each window position, in order from left to right. There are n - k + 1 windows.

Signature: int[] maxSlidingWindow(int[] nums, int k).

Constraints

  • 1 <= nums.length <= 10^5
  • -10^4 <= nums[i] <= 10^4
  • 1 <= k <= nums.length

Practice it: LeetCode 239 - Sliding Window Maximum · GfG - K Sized Subarray Maximum · TUF - Sliding window maximum

Constraints tell you: n and k can both be 10^5, so the O(n·k) scan is up to 10^10 steps. You need O(n log n) (a heap) or O(n) (the deque). Values may be negative, so never start a running max at 0.
