Common mistakes

One window for "exactly k". It finds one start per end; duplicates just after left make several starts good. Always ask: is the condition monotonic in the window? "Exactly" is not; "at most" is.

Updating distinct at the wrong moment. Increase it only when freq goes 0 → 1, decrease only when it goes 1 → 0. Changing it on every add or remove breaks the count.

Using if for the shrink. One removal may not lower distinct (the dropped value appears again later in the window); loop until distinct ≤ k.

Reusing the count array between the two calls. Each atMost call needs a fresh, zeroed array.

Count array of size n. nums[i] can equal n; index n needs size n + 1. With a hash map instead, remove keys at 0 if you use the map size as distinct.
