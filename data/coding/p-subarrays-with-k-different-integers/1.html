The problem (in our words)

You are given an integer array nums and an integer k. Call a contiguous, non-empty subarray good if it contains exactly k different values (for instance [4,2,4,7] has three: 2, 4 and 7). Return the number of good subarrays. Subarrays at different positions count separately.

Signature: int subarraysWithKDistinct(vector<int>& nums, int k).

Constraints:

  • 1 <= nums.length <= 2 * 104
  • 1 <= nums[i], k <= nums.length

Practice it: LeetCode 992 · TUF: subarrays with k different integers

Constraints tell you: n = 2·104 puts O(n2) at 2·108 set operations: too slow, and the Hard label means O(n) is expected. Values lie in 1..n, so a plain int array of size n + 1 replaces the hash map (faster, no hashing). The answer is at most n(n+1)/2 ≈ 2·108, so int32 is enough.
