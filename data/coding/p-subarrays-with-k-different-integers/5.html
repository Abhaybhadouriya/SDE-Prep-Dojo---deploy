Example 1, nums = [3,1,3,1,2], k = 2. Top row: the "at most 2 distinct" window (green) with its counts. Bottom row: the "at most 1 distinct" window (blue). The purple band on the top row is the starts between the two left edges, the good subarrays ending here.

  1. Exactly 2 distinct = (at most 2) - (at most 1). Each window keeps a count per value; it shrinks only when it holds one value too many. For an end r it adds r - left + 1 subarrays.
  2. right = 0 (value 3): the ≤ 2 window is [0..0] (+1), the ≤ 1 window is [0..0] (+1). Nothing has exactly 2 distinct yet.
  3. right = 1 (value 1): the ≤ 2 window is [0..1] (+2), the ≤ 1 window is [1..1] (+1). Starts in between have exactly 2 distinct: [3,1].
  4. right = 2 (value 3): the ≤ 2 window is [0..2] (+3), the ≤ 1 window is [2..2] (+1). Starts in between have exactly 2 distinct: [3,1,3], [1,3].
  5. right = 3 (value 1): the ≤ 2 window is [0..3] (+4), the ≤ 1 window is [3..3] (+1). Starts in between have exactly 2 distinct: [3,1,3,1], [1,3,1], [3,1].
  6. right = 4 (value 2): the ≤ 2 window is [3..4] (+2), the ≤ 1 window is [4..4] (+1). Starts in between have exactly 2 distinct: [1,2]. Answer = 12 - 5 = 7.
