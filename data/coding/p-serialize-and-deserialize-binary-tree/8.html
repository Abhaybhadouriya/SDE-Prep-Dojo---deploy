Common mistakes

No null markers. A plain traversal cannot tell a left child from a right child (see the picture above).

No separator, or reading one character per value. "-10" and "1000" are several characters; "12" could be 1 then 2. Always split on a delimiter.

String concatenation in a loop. s += token in Java creates a new string each time: O(n2). Use StringBuilder / a list and join.

Using a static or member variable as the read cursor without resetting it: the second deserialize call starts in the middle. Keep the index local, or pass an iterator / queue.

Java ArrayDeque with null. It throws on add(null); use a LinkedList or a list with a head index for the serialize queue.
