The problem (in our words)

Design a class Codec with two methods:

  • String serialize(TreeNode root) - turns a binary tree into a string.
  • TreeNode deserialize(String data) - turns that string back into the same tree (same shape, same values).

The format is up to you; there is no restriction on how it works. The only requirement is that deserialize(serialize(root)) gives a tree identical to root. (LeetCode shows trees as level-order lists like [7,2,9,null,null,6,10]; you may, but need not, use that format.) The class must not keep state between calls: whatever it needs must be inside the string.

Constraints

  • The number of nodes is in the range [0, 104].
  • -1000 <= Node.val <= 1000

Practice it: LeetCode 297 · GfG Serialize and Deserialize a Binary Tree · TUF Serialize and Deserialize a Binary Tree

Constraints tell you: values can be negative and repeat, so a separator is needed (a value can have a minus sign and up to 4 digits) and tricks that rely on unique values (preorder + inorder) do not apply. 104 nodes can form a chain 104 deep: recursion is fine in C++/Java/Go, but it exceeds Python's default limit of 1000, which is one reason our code uses an iterative BFS.
