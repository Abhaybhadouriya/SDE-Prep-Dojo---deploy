The story

Explain like I'm 5

You built a tree out of toy blocks and have to describe it over the phone so a friend can build the exact same one. Saying only the numbers in some order is not enough: "1 then 2" could mean 2 hangs on the left or on the right. So you also say "nothing here" for every empty spot. Then your friend, following the same order, always knows where the next block goes.

Hard in the label, but the core is one idea: null markers make a single traversal unambiguous. The rest is careful string handling.

From your world

This is marshalling a pointer structure into a wire format, like encoding a device tree blob or a netlink nested attribute: pointers mean nothing on the other side, so you send the shape explicitly. A TLV with "absent" entries is exactly the "#" marker. And as with any wire format, the reader must consume tokens in exactly the order the writer produced them.
