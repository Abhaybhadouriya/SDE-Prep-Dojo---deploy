The problem (in our words)

You are given a string s holding a line of text. A word is a maximal run of non-space characters. Words are separated by at least one space, and the line may also start or end with spaces.

Return a string with the words in reverse order, joined by exactly one space. The result must have no leading or trailing spaces and no repeated spaces, even if the input had them. Characters inside a word keep their order and case.

  • Input: a string s.
  • Output: a string. Signature: String reverseWords(String s).

Constraints

  • 1 <= s.length <= 10^4
  • s contains English letters (upper-case and lower-case), digits, and spaces ' '.
  • There is at least one word in s.

Follow-up: if strings are mutable in your language, can you do it in place with O(1) extra space?

Practice it: LeetCode 151 - Reverse Words in a String (the original) · GfG - Reverse Words · takeuforward

Constraints tell you: n ≤ 10^4, so any O(n) solution is instant and even O(n^2) string concatenation would likely pass; the interview is about clean handling of spaces and about the in-place follow-up. "At least one word" means the answer is never empty, so you never have to special-case an all-space input. The characters are ASCII, so byte-wise reversal is safe (with UTF-8 multi-byte text it would not be).
