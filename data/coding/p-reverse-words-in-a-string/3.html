Recognise the pattern

Cue: "reverse the order of blocks but keep each block intact" → reverse the whole, then reverse each block. "Remove extra spaces in place" → read / write two pointers (the write pointer trails the read pointer).

Why reversing twice works: if the line is A B C (A, B, C words), reversing it gives rev(C) rev(B) rev(A). The blocks are in the target order; each is spelled backwards, and rev(rev(X)) = X.
