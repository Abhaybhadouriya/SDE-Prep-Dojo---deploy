Common mistakes

Splitting on a single space. "a  b".split(" ") gives ["a", "", "b"]; joining the reversed list gives a double space. Use whitespace-run splitting or filter empty pieces.

Forgetting to trim. Leading or trailing spaces in the output fail the judge even when the word order is right.

Writing the separator before the first word. Write the space only when w > 0, i.e. before every word except the first.

Forgetting the final cut. In place, the buffer still holds leftover characters after w (dry run step 5); return only the first w characters.

Claiming O(1) space in Java or Python. Strings are immutable there; converting to a char array is O(n). Say "O(1) extra beyond the one working buffer".

String concatenation in a loop. ans = word + " " + ans copies the answer every time: O(n^2) in the worst case. Use a builder or a list and join.
