Approaches: brute → better → optimal

Hint 1

First solve it with your language's split: what does it do with repeated spaces?

Hint 2

Without split: walk from the right end, and each time you find a word, append it to the answer.

Hint 3

For O(1) space: what does reversing the whole string do to the word order? To each word?

1. Library - split, reverse, join

Idea: split on runs of whitespace (which drops the empty pieces), reverse the list, join with one space.

return " ".join(reversed(s.split()))   # Python split() with no argument drops empties
O(n)time
O(n)space (list of words)

Careful: s.split(" ") in Python and s.split(" ") in Java keep empty strings for double spaces; in Java use s.trim().split("\\s+"). Say the one-liner, then expect "now without the library".

2. Better - scan from the right with two pointers

Idea: let i start at the end. Skip spaces; set j = i; move i left while it is on letters; now s[i+1..j] is a word, append it (with a space if the answer is non-empty). Repeat until i < 0.

out, i = [], len(s) - 1
while i >= 0:
    while i >= 0 and s[i] == " ": i -= 1
    if i < 0: break
    j = i
    while i >= 0 and s[i] != " ": i -= 1
    out.append(s[i + 1:j + 1])
return " ".join(out)
O(n)time
O(n)space (the output)

Why it is better: no library, one pass, and it shows you control the spaces yourself. It still builds a second buffer, which the follow-up asks you to avoid.

3. Optimal - reverse all, then reverse each word while compacting

  1. Reverse the whole buffer. Word order is now final; each word is backwards.
  2. Read pointer r, write pointer w = 0. r skips any run of spaces.
  3. At the start of a word: if w > 0, write one space (the separator). Remember start = w.
  4. Copy the word: while s[r] is not a space, s[w++] = s[r++]. Then reverse s[start..w-1] to fix its letters.
  5. Cut: when r reaches the end, the answer is the first w characters (resize(w)).
O(n)time (each char moved and reversed a constant number of times)
O(1)extra space in C++ / C; O(n) in Java, Python, Go (immutable strings need one buffer)

Why w never passes r: w only grows when r also grows (copying a char), except for the single separator space, and that space is written only after r has skipped at least one space (or at the very start, where w = 0 and no space is written). So w ≤ r always holds, and an in-place copy is safe.

Variant - compact first, then reverse

Some top solutions do it in three separate passes: (1) remove extra spaces with the read/write pointers, (2) reverse the whole compacted string, (3) reverse each word. Same O(n) and O(1); easier to test each pass on its own, slightly more code.
