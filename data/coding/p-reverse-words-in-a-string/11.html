Interview follow-ups

Do it in place with O(1) extra space.

That is approach 3: reverse the whole buffer, then for each word copy it left to the write pointer and reverse it, writing one separator before every word except the first; cut to w. In C++ std::string is mutable, so it is truly O(1) extra. In Java or Python state that the one char array copy is unavoidable.

How to answer

Explain the invariant w ≤ r before you write code; it is the reason in-place copying is safe.

Likely follow-ups
  • Can you do it with no full reverse? Yes: compact first, then reverse each word, then reverse all; the order of passes does not matter.
The text is UTF-8 with multi-byte characters.

Byte-wise reversal breaks multi-byte sequences: a 3-byte character would come out with its bytes in the wrong order. Reversing the whole buffer and then each word twice actually restores every byte's order inside a word, so the double reversal is safe for the words themselves, but any single reversal (LC 557 style) is not. Safer: work on code points (or grapheme clusters for emoji and combining marks), or use the right-to-left scan that copies words as byte slices without reversing them.

How to answer

Show you know the difference between bytes, code points and grapheme clusters.

Likely follow-ups
  • Which separators count as whitespace in Unicode? Tabs, no-break spaces and more: define the set up front.
The input is a stream too large for memory: output the words in reverse order.

You must buffer, because the first output word is the last input word. Options: push word offsets onto a stack and re-read the words from the file at the end (seekable input), or write words to chunk files and emit the chunks in reverse order, each reversed in memory. Memory then depends on the chunk size, not the input size.

How to answer

State the lower bound (you cannot emit anything before you see the end), then the external-memory plan.

Likely follow-ups
  • How would you do it with tac-like tools? Reverse by lines, then by words in each line.
Keep the original spacing (do not collapse spaces), just reverse the words.

Then skip the compaction: reverse the whole buffer and reverse each maximal non-space run in place. The gaps come out mirrored (the leading gap becomes the trailing gap), which is the natural meaning of "reverse with spacing kept". Ask which one the interviewer wants.

How to answer

Clarify the requirement with a tiny example before changing code.

Likely follow-ups
  • Reverse only the words, keep the gaps where they were? Collect the words, then refill the slots in reverse order.
Write unit tests for your function.

One word; one word with spaces on both sides; several single-space words; multiple spaces between words; leading and trailing spaces; one-letter words; mixed case and digits; the maximum length (10^4) with alternating letter and space. Compare against the split/join one-liner as an oracle on random inputs.

How to answer

Group tests by class (spaces at ends, inside, none) and name the oracle you trust.

Likely follow-ups
  • How do you generate random tests? Random words of letters joined by 1-3 spaces, with optional padding.
