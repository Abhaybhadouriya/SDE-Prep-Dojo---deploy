The problem (in our words)

You get an array nums where every entry is 0 or 1, and an integer k. You may change at most k of the zeros into ones. Return the length of the longest block of consecutive ones that the array can contain after those changes.

Signature: int longestOnes(int[] nums, int k).

Constraints

  • 1 <= nums.length <= 10^5
  • nums[i] is either 0 or 1
  • 0 <= k <= nums.length

Practice it: LeetCode 1004 · GfG Max Consecutive 1's with K Flips · TUF article

Constraints tell you: n up to 10^5 rules out the O(n²) "try every start" loop (10^10 steps in the worst case); you need O(n) or O(n log n). k can be 0 (no flips) or as large as n (flip everything).
