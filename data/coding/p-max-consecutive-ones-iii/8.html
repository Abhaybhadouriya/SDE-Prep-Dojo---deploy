Common mistakes

Moving left once with if but still keeping best = max(...). With if, the window can stay invalid (it only slides), so measuring it inside the loop counts an illegal window. Either use while + best, or if + return n - left, never a mix.

Decrementing zeros for every element that leaves. Only a leaving 0 reduces the count; a leaving 1 does not.

Recording the length before shrinking. Update best after the while loop, when the window is valid again.

Greedy "flip the zeros between the longest runs". Picking zeros next to the current longest run fails: on [1,1,1,0,0,1,1,0,1,1], k = 1 extending the run 1,1,1 gives 4, but flipping index 7 gives 5. The window does the choosing for you.
