Common mistakes

Setting end = current.end instead of the max. [[1,10],[2,3]] would shrink to [1,3].

Using < for the overlap test. The problem counts touching intervals as overlapping; [1,4],[4,6] must give [1,6].

Forgetting to push the last block (in the "keep start/end variables" style). The loop ends with an open block that was never added. Appending first and stretching out[-1] avoids this.

Aliasing the input in Java/Go. Adding the input array itself to the output and then stretching it changes the caller's data. Copy the pair (the code above does).

Comparing only with the previous input interval instead of the open block: [1,10],[2,3],[4,5] then compares [4,5] with [2,3] and wrongly opens a new block.
