Recognise the pattern

When you see "intervals / ranges / bookings" + "overlap, union, merge, free time", think sort by start, then sweep with one open block. If the question asks "how many at once", switch to a sweep of +1/-1 events or a min-heap of end times.

Pair (sorted)Merge?Rule
[1,3], [2,5]yes -> [1,5]2 <= 3
[1,4], [4,6]yes -> [1,6]4 <= 4, touching counts
[1,2], [3,4]no3 > 2; integer gap of one is still a gap
[1,10], [2,3]yes -> [1,10]end = max(10, 3)
