Recognise the pattern

Cue: "rearrange so that equal items are not adjacent / at least k apart" -> count frequencies, the most frequent item decides feasibility, and a greedy always serves the item with the most remaining copies (heap) or places it first on a fixed stride.

This is the "pick the maximum repeatedly" scheduling family: Task Scheduler, Longest Happy String and Distant Barcodes use the same counting argument.
