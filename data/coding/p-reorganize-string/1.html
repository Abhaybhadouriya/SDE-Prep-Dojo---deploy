The problem (in our words)

You are given a string s. Reorder its characters so that no two adjacent characters are equal. Return any such arrangement. If no arrangement exists, return the empty string "".

Signature: String reorganizeString(String s).

  • 1 <= s.length <= 500
  • s consists of lowercase English letters.

Practice it: LeetCode 767 · GfG Rearrange characters

Constraints tell you: only 26 distinct letters, so anything per-letter is O(1); n is tiny, so even a sort is fine, but the expected answer is linear. Any valid output is accepted, so you do not have to match a particular string.
