60-second recall

  • Cue: no two equal neighbours -> count; the top letter decides.
  • Bound: possible iff maxCount <= (n + 1) / 2 (the number of even slots).
  • O(n): top letter on 0,2,4,...; others continue on evens, then wrap to 1,3,5,...
  • Trap: the top letter MUST go first; the rest can go in any order.
  • Heap version: pop the two largest per round; extends to "k apart" with a cooldown queue.
if top_cnt > (n + 1) // 2: return ""
pos = 0
for ch in [top] + others:
    for _ in range(cnt[ch]):
        if pos >= n: pos = 1
        out[pos] = ch; pos += 2

(n + 1) / 2 = 5: the letter takes slots 0, 2, 4, 6, 8.

Why must the most frequent letter be placed first in the even-slot fill?

  1. It makes the output sorted
  2. It is faster
  3. It is the only letter that could touch itself at the even-to-odd wrap
  4. The heap requires it
Any other letter that wraps has fewer copies than the slots before it, so its odd and even copies cannot meet; the top letter could.

In the heap version, why pop two letters per round?

  1. So the same letter is never appended twice in a row
  2. To halve the number of rounds
  3. Because the heap stores pairs
  4. To keep the output sorted
Popping one and pushing it back could return the same letter immediately.
