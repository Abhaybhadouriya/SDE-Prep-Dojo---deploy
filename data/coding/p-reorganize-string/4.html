Approaches: brute -> better -> optimal

Hint 1

When is it impossible? Think about the letter that appears most often and how many positions can hold it without two touching.

Hint 2

Positions 0, 2, 4, ... never touch each other. How many of them are there in a string of length n?

1. Brute force - try permutations

Idea: generate permutations (backtracking, skipping duplicate letters) and return the first with no equal neighbours. Correct but O(n!) in the worst case; useful only to explain what "valid" means.

O(n!)time
O(n)space

2. Better - max-heap, two letters per round

Idea: push (count, letter) for each letter into a max-heap. Each round pop the two most frequent letters, append both, decrement, and push back the ones with copies left. If only one letter remains with count 1, append it; with count > 1, return "".

heap = [(-c, ch) for ch, c in Counter(s).items()]; heapify(heap)
out = []
while len(heap) >= 2:
    c1, a = heappop(heap); c2, b = heappop(heap)
    out += [a, b]                       # a != b, and a differs from the previous b
    if c1 + 1: heappush(heap, (c1 + 1, a))
    if c2 + 1: heappush(heap, (c2 + 1, b))
if heap:
    c, ch = heap[0]
    if c < -1: return ""
    out.append(ch)
return "".join(out)
O(n log k)time, k <= 26
O(k)heap

Why it works: taking the two largest each round keeps the counts as balanced as possible, so the top count never exceeds the rest by more than one; a round never repeats a letter, and the next round's first letter differs from the previous round's second letter as long as the gap condition holds. This version generalises directly to "k apart" (pop k letters, park them in a cooldown queue).

3. Optimal - even-slot fill, O(n)

Idea: count letters. If the top count exceeds (n + 1) / 2, return "". Otherwise write the top letter on slots 0, 2, 4, ...; then write every other letter, one copy at a time, on the next even slot, and when the even slots run out, continue on 1, 3, 5, ...

O(n)time
O(1)extra (26 counters, plus the output)

Why it works (feasibility): in any valid string, copies of one letter need a different letter between each pair, so a letter with count m needs at least 2m - 1 positions: m <= (n + 1) / 2. The even slots number exactly ceil(n / 2) = (n + 1) / 2, so the condition is also sufficient.

Why no two equal letters touch: slots of the same parity are 2 apart, so a letter can only clash with itself where it crosses from the even slots to the odd ones. The top letter never crosses (it fits in the evens). Any other letter c that crosses takes the last few even slots (at least one) and the first few odd slots. For its odd slot 2j+1 to touch its even slot 2i, it would need j >= i - 1, which means c has at least as many odd copies as the even slots before its first even copy, which is at least the top count. Then count(c) >= 1 + count(top) > count(top), a contradiction.
