Recognise the pattern

Cue: "same characters, any order", "rearrangement", "permutation of" -> compare frequency counts, not positions. Small fixed alphabet -> counter array; open alphabet -> hash map.

This is the base case of the whole anagram family: Group Anagrams turns the count into a key, Find All Anagrams slides the count along a window. Pattern pages: Arrays & hashing · Strings · explorer node Arrays > hashing.
