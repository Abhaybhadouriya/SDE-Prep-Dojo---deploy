The problem (in our words)

A word-game app shuffles the tiles of a word s and a player lays down the word t. Decide whether the player used exactly the same tiles: report true when t is a rearrangement (an anagram) of s, and false in every other case. A rearrangement keeps every letter and its count, only the order may change, so "listen" and "silent" match but "aab" and "abb" do not.

Signature: boolean isAnagram(String s, String t).

Constraints

  • 1 <= s.length, t.length <= 5 · 104
  • s and t contain only lowercase English letters.

Follow-up (from the original): what if the inputs can contain Unicode characters? How would you adapt the solution?

Practice it: LeetCode 242 · GfG Anagram · TUF Check if two strings are anagrams

Constraints tell you: n up to 5·104, so even O(n log n) sorting is instant; the interviewer wants O(n). "Only lowercase letters" is the hint that a fixed array of 26 beats a hash map. The lengths can differ, so check that first.
