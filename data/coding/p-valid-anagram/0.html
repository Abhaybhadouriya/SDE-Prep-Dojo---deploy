The story

Explain like I'm 5

You have two bags of Scrabble tiles. Are they the same bag, just shaken differently? Pour the first bag onto a board with one square per letter, then take tiles off the board for each tile in the second bag. If the board is empty at the end, and no square ever had to go below zero by the end, the bags matched.

The order of the letters is noise; only how many of each matters. As soon as you see that, sorting and hashing both work, and a plain counter array is the cheapest.

From your world

It is a checksum that ignores order, like comparing two packet captures by a histogram of byte values instead of byte by byte. A 26-slot int array on the stack is the C engineer's hash map: index = c - 'a', no allocation, no collisions.
