Dry run

s = "apple", t = "papel". Each step handles one position of both strings; green counters are balanced, amber ones are not (yet).

  1. Same length (5 and 5), so keep going. All counters start at 0. Only the letters that appear are drawn; the real array has 26 slots.
  2. i = 0: s[0] = 'a' adds 1 to a, t[0] = 'p' takes 1 from p. Positive = s has more of it so far, negative = t has more.
  3. i = 1: s[1] = 'p' brings p back to 0, t[1] = 'a' brings a back to 0. The order of letters does not matter, only the balance.
  4. i = 2: s[2] = 'p' and t[2] = 'p' cancel inside the same step: p goes +1 then -1.
  5. i = 3: s[3] = 'l' gives l = +1, t[3] = 'e' gives e = -1. Two letters are out of balance right now, which is fine mid-way.
  6. i = 4: s[4] = 'e' and t[4] = 'l' cancel both. Final scan: every counter is 0, so the answer is true.
