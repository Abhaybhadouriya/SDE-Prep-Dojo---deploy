Common mistakes

Comparing sets instead of counts. set(s) == set(t) says "aab" and "abb" are anagrams. Counts matter.

Skipping the length check when walking both strings with one index: you read out of bounds, or you miss the extra letters of the longer string.

Indexing with the raw char. count[s[i]] on a 26-slot array overflows; subtract 'a'. In C/C++, a char above 127 can be negative - another reason the Unicode version needs a map.

Two maps compared field by field by hand. Works, but it is more code and easy to get one direction wrong (checking only keys of the first map).
