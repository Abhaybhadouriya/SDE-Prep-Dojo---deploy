Recognise the pattern

Cue: "sorted" + "in place" + "return the new length, the rest does not matter" -> same-direction read/write pointers. "At most m copies" adds one twist: the keep test compares with the kept value m slots back, nums[k-m].

Try a few and note what the test compares:

InputkNote
[5,5]2Fewer than two kept when each arrives: always keep.
[5,5,5]2The third 5 sees nums[k-2] = 5: two copies already in.
[1,5,5,5]3The second 5 sees nums[k-2] = 1: only one 5 kept, so keep.
[1,1,2,2]4Every value appears twice; nothing is dropped.
