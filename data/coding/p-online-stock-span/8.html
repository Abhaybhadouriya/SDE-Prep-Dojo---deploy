Common mistakes

Using < instead of <=. The span includes equal prices, so equal tops must be popped. "5, 5" must return 1, 2.

Pushing only the price, then returning 1 + number of pops. Popped entries stand for several days. Without the stored span, "40, 30, 35, 50" gives 3 instead of 4.

Storing indexes without a global day counter. The index version (span = today - index of the top after popping, or today + 1 if empty) works, but you need to keep the day number as a field; forgetting the empty-stack case gives an off-by-one.

Calling it O(n) per call. A single call can pop many entries, but the total over all calls is O(n): say "amortised O(1)" and give the push-once / pop-once argument.

Using java.util.Stack without thinking. It is synchronised and legacy; ArrayDeque is the idiomatic choice (and faster).
