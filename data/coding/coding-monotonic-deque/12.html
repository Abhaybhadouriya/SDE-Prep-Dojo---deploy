Revision card

  • Cue: Sliding window maximum / minimum, "max - min ≤ limit", best of the last k dp values.
  • Insight: An older, worse element can never be the answer again: delete it now, and the survivors stay sorted.
  • State: deque of indexes: pop dominated from the back, push, pop expired (index ≤ right - k) from the front, read the front.
  • Trap: Storing values instead of indexes, so expiry cannot be checked; forgetting the front pop.
  • Cost: Each index pushed and popped once: O(n) total, O(k) space.

More to remember

  • Older and smaller (for max) means dominated: delete it now. Survivors are monotonic.
  • Store indexes. Pop dominated from the back, push, pop expired from the front, read the front.
  • Each index is pushed once and popped once: O(n) total, O(1) amortised.
  • Two deques give window max and min at the same time (max - min <= limit).
  • Negatives in "sum >= K": prefix sums plus a deque of increasing P (front rule: use then retire; back rule: later and lower wins).
  • "Best of the last k dp states" is a sliding window max over dp.
