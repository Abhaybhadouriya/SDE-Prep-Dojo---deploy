Revision card

  • Cue: group words equal up to a cyclic shift of the alphabet → canonical key + map.
  • Insight: key = word shifted so that it starts with 'a': (c - w[0] + 26) % 26.
  • State: map key → list of words (plus first-seen order if needed).
  • Trap: negative % in C++/Java; difference keys need separators; length matters.
  • Cost: O(N·L) time and space; brute force O(N²·L).
groups = defaultdict(list)
for w in words:
    key = tuple((ord(c) - ord(w[0])) % 26 for c in w)
    groups[key].append(w)
return list(groups.values())

Quick quiz

Key of "yb" (shift to start at 'a')?

  1. "ab"
  2. "ac"
  3. "ad"
  4. "az"
y is 24, b is 1: (1 - 24 + 26) % 26 = 3, the letter d. So the key is "ad".

Are "ab" and "abc" ever in the same group?

  1. No, shifts keep the length
  2. Yes, after 26 shifts
  3. Only if the words wrap at z
  4. Yes, they share a prefix
A shift changes letters, never the length; the keys have different lengths too.
