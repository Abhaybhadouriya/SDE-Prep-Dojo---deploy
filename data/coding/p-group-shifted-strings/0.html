The story

Explain like I'm 5

Think of a secret-decoder wheel with the alphabet around the edge. Turning the wheel one notch changes every letter of a word to the next letter, and z goes back round to a. "dog" turned one notch is "eph". Two words belong to the same family if some number of turns makes one into the other. To sort words into families, turn each word until its first letter is 'a' and read the result: everyone in a family reads the same thing.

From your world

It is like comparing two packet traces captured with different clock offsets. To tell if they are the same sequence, you subtract each trace's first timestamp so both start at 0, then compare. Here the "offset" is the first letter, and the subtraction is modulo 26 because the alphabet wraps like a sequence-number space.
