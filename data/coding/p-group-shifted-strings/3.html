Recognise the pattern

When you see "group items that are equal up to a shift / rotation / relabelling", think canonical key + hash map: pick one representative of each class (here the member that starts with 'a') and group by it.

A key is valid only if key(x) == key(y) exactly when x and y are in the same shifting sequence.
