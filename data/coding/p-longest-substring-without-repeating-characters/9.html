  • Cue: longest contiguous piece + "no repeats" → variable sliding window.
  • Insight: repeat inside window → left = lastSeen[c] + 1; left only moves forward.
  • State: left, right, last[256] (index, -1 = never), best.
  • Trap: check last[c] >= left (or max) - "abba" must give 2, not 3.
  • Cost: O(n) time, O(Σ) space; brute O(n·Σ), naive O(n³).
left = best = 0
for right, x in enumerate(a):
    add(x)
    while window_invalid():
        remove(a[left]); left += 1
    best = max(best, right - left + 1)

Quick quiz

Processing "abba", right = 3 reads 'a' (last seen at 0) while left = 2. What happens to left?

  1. left = 1
  2. left stays 2
  3. left = 3
  4. left = 0
The old 'a' is left of the window, so it is not a repeat inside it. Moving left to 1 would bring the second 'b' back in.

Where must best be updated?

  1. Only when a repeat is found
  2. Only at the end
  3. On every step, after fixing left
  4. Before reading s[right]
The longest window may end at the last character, with no repeat after it.

Why is the set-shrink version still O(n)?

  1. Sets are O(1)
  2. Each char is added once and removed at most once
  3. The alphabet is small
  4. It is not; it is O(n²)
