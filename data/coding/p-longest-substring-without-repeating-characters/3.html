Recognise the pattern

When you see "longest / shortest contiguous piece" + a condition that breaks when you add an element and is repaired by removing from the front ("no repeats", "at most k distinct", "sum <= budget"), think variable sliding window, the "longest valid window" variant.

Try a few: if a window s[l..r] has no repeats, every window inside it also has none. That monotonic property is what lets the left edge only move forward.
