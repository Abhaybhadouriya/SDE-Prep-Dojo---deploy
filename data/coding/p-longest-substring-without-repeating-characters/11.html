Why is the set version O(n) when it has a while loop inside a for loop?

Each character is inserted once (when right reaches it) and erased at most once (when left passes it). Both pointers only move forward, so the loop bodies run at most 2n times in total.

How to answer

Use the phrase "amortised: each element enters and leaves the window once".
