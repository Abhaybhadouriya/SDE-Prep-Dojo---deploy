The problem (in our words)

A packet sniffer prints a capture as one string s of tag characters. Find the length of the longest contiguous piece of s (a substring, not a subsequence) in which no character appears twice.

  • Input: a string s.
  • Output: one integer, the length of the longest substring of s with all characters distinct. Signature: int lengthOfLongestSubstring(string s).

Constraints

  • 0 <= s.length <= 10^5 (the empty string is allowed, and its answer is 0).
  • s consists of English letters, digits, symbols and spaces (all ASCII).

Practice it: LeetCode 3 - Longest Substring Without Repeating Characters · GfG - Longest Distinct Characters in String · takeuforward

Constraints tell you: n up to 10^5 rules out O(n²) substrings with an O(n) check (O(n³)), and O(n²) itself is about 10^10 steps, clearly too slow. Aim for O(n). The ASCII alphabet means a 128 or 256-entry array can replace the hash map.
