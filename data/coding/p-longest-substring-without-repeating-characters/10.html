Technique: longest valid window where validity is "monotone" (a bad window stays bad when it grows), so the left edge only moves forward.

Closest match: LC 340 Longest Substring with At Most K Distinct Characters Premium

  • Same: longest substring, window state is per-character, left only moves forward.
  • Different: up to k distinct characters are allowed, and repeats are fine.
  • So: keep counts and a distinct counter instead of last indexes; shrink while distinct > k (you cannot jump).

How to recognise it:

  • "Longest/shortest substring or subarray" with a condition on its contents.
  • Adding an element can only break the condition; removing from the front can only repair it.

Practice order:

  1. Warm-up: the GfG twin, from memory.
  2. This problem: set version, then the last-index jump.
