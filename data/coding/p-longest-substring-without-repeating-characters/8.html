Common mistakes

Moving left backwards. left = last[c] + 1 without the >= left check (or a max) breaks on "abba": at the last a, left goes from 2 back to 1 and the answer becomes 3.

Updating best only when a repeat happens. If the longest window is at the end of the string ("tmmzuxt"), it is never recorded. Update best on every step.

Using a 26-entry array. The input includes digits, symbols and spaces. last[c - 'a'] goes out of bounds for ' '.

Length off by one. The window s[left..right] has right - left + 1 characters, not right - left.

Answering with a subsequence. Counting distinct characters (len(set(s))) is a different problem.
