Recognise the pattern

Cue: "shortest / minimum number of steps" + a grid or graph + every step costs the same -> BFS by levels. Weights that differ -> Dijkstra (LC 1631). Weights only 0 or 1 -> 0-1 BFS with a deque. Many sources at once -> multi-source BFS (LC 994, 542).
