How to recognise it:

  • "Minimum steps / moves / time" and each move costs the same -> BFS by levels.
  • Extra per-cell state (keys, removals, direction) -> BFS over (cell, state).
  • Different costs per move -> Dijkstra; costs 0 or 1 -> deque BFS.

Practice order:

  1. 200 Number of Islands (grid traversal).
  2. This problem, then 1926 Nearest Exit (change the goal test).
  3. 994 Rotting Oranges and 542 01 Matrix (multi-source).
  4. 1293 Obstacles Elimination (BFS with state), then 1631 (Dijkstra).
