  • Cue: fewest steps on a grid, every step costs 1 -> BFS by levels.
  • Insight: BFS pops cells in distance order, so the first pop of the goal is the answer.
  • State: queue of cells, grid reused as the visited set, a level counter starting at 1.
  • Trap: 8 directions; mark on push; check both corners; length = cells, not moves.
  • Cost: O(n²) time and space. Follow-up: A* with the Chebyshev heuristic.
if grid[0][0] or grid[-1][-1]: return -1
q, grid[0][0], length = deque([(0, 0)]), 1, 1
while q:
    for _ in range(len(q)):
        r, c = q.popleft()
        if r == c == n - 1: return length
        for each free 8-neighbour: mark it, push it
    length += 1
return -1

All moves cost 1. Which search returns the shortest path the first time it reaches the goal?

  1. DFS
  2. BFS
  3. Either, if you mark visited cells
BFS pops cells in order of distance; DFS reaches the goal first along some path, not the shortest.

When should a cell be marked visited?

  1. When it is pushed
  2. When it is popped
  3. Never: the grid stops repeats
Marking on push stops the same cell being queued by several neighbours of one level.
