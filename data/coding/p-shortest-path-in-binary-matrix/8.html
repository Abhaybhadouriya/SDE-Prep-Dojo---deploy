Common mistakes

Only 4 directions. Copying the Number of Islands neighbour list misses diagonals and gives longer or missing paths: example 1 returns 3 instead of 2, and example 2 returns -1 instead of 4.

Marking visited on pop. The same cell gets queued by several neighbours of one level. The answer stays right, but the queue can grow up to 8 times larger and slower; on bigger grids it times out.

Off by one on the length. The answer counts cells, not moves. Start the count at 1 for the start cell.

Forgetting the blocked start or goal. Without the check, a blocked (0,0) gets pushed and searched as if it were free.

Using DFS and taking the first hit. DFS finds a path first, not the shortest one.
