Interview follow-ups

Return the path itself, not just its length.

Store a parent for each cell when you push it (parent[nr][nc] = (r, c)). When the goal is popped, follow parents back to (0,0) and reverse. Same O(n²) time, plus O(n²) for the parent array.

How to answer

Point out the grid can no longer be the only visited marker if you also need parents; use the parent array as the visited set.

Likely follow-ups
  • All shortest paths? Keep a list of parents per cell (BFS DAG) and enumerate.
Do not modify the input grid.

Use a separate visited boolean array (or a bitset of n² bits: 10,000 bits = 1.25 KB). Or store distances in an int array initialised to -1, which doubles as visited.

How to answer

Say why mutating is a trade-off: it saves memory but callers may reuse the grid.

Likely follow-ups
  • Can you restore the grid afterwards? Yes, every cell you set to 1 was a 0 that you pushed.
Can you visit fewer cells? The grid is huge and mostly open.

Two options. Bidirectional BFS: grow levels from both corners and stop when they meet; in open grids it explores far less. A*: a min-heap keyed by g + h, where g = cells so far and h = max(|n-1-r|, |n-1-c|) (Chebyshev distance). That heuristic never overestimates with diagonal moves, so the result stays optimal.

How to answer

Name the heuristic and why it is admissible; mention the heap costs a log factor in the worst case.

Likely follow-ups
  • Why not Manhattan distance? With diagonal moves it can overestimate, so A* may return a non-shortest path.
Now diagonal moves cost √2 (or 2) and straight moves cost 1.

Costs differ, so BFS levels no longer equal distance. Use Dijkstra with a min-heap of (dist, r, c): O(n² log n). If the costs are small integers, a bucket queue (Dial's algorithm) avoids the log.

How to answer

Explain exactly which BFS property breaks: the FIFO order is no longer distance order.

Likely follow-ups
  • Costs only 0 or 1? 0-1 BFS: push front for 0, back for 1.
You may remove up to k blocked cells.

Make the state (r, c, removalsLeft) and BFS over it, O(n² · k). Keep, per cell, the most removals left you have seen when you arrived; a later arrival with fewer left is never better. That is LC 1293.

How to answer

Show the general move: when the plain BFS loses information, add it to the state.

Likely follow-ups
  • If k >= the Manhattan distance minus 1, the answer is that distance at once (shortcut).
