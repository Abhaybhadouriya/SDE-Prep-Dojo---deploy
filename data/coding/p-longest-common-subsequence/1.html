The problem (in our words)

You are given two strings text1 and text2. Return the length of their longest common subsequence; return 0 if they have no common subsequence.

A subsequence of a string is what remains after deleting zero or more characters without changing the order of the rest (for example, "rdn" is a subsequence of "garden", "dnr" is not). A common subsequence is a subsequence of both strings.

Signature: int longestCommonSubsequence(String text1, String text2).

Constraints

  • 1 <= text1.length, text2.length <= 1000
  • text1 and text2 consist of only lowercase English characters.

Practice it: LeetCode 1143 · GfG Longest Common Subsequence · TUF Longest Common Subsequence

Constraints tell you: 1000 × 1000 = 106 cells, so O(m·n) is the intended bound; the 2m subsets of one string are far too many. A full int table is 4 MB, fine, but the follow-up "use less memory" is common.
