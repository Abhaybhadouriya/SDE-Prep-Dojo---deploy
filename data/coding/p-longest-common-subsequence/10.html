Technique: a table over two prefixes where each cell looks at the diagonal, up and left neighbours.

Closest match: LC 583 Delete Operation for Two Strings Medium

  • Same: the letters you keep form a common subsequence; keep as many as possible.
  • Different: it asks for the number of deletions, not the kept length.
  • So: answer = m + n - 2 · LCS(a, b). Same table, one formula at the end.

How to recognise it:

  • Two strings or arrays and the word "subsequence", "delete characters", "transform", "align".
  • Lengths up to about 103 each (an m·n table fits).

Extra practice (competitive programming, optional - not interview questions): CodeChef VISA01 Longest Common Subsequence (Same table with stdin input).

Practice order:

  1. 392 Is Subsequence, then this problem (table, then one row).
  2. 583 Delete Operation and 1035 Uncrossed Lines (pure reductions).
  3. 72 Edit Distance, then 1092 Shortest Common Supersequence (reconstruction).
