a = "acbd" (rows), b = "abcd" (columns). The glowing row is being filled; green cells are letter matches that take diagonal + 1.

  1. Row 0 and column 0 are the empty prefix: an empty string shares nothing, so they are all 0. dp[i][j] = LCS of the first i letters of a and the first j letters of b.
  2. Row 'a': at column 'a' the letters match, so dp = diagonal + 1 = 1 (green). Every cell to the right copies the best of up/left, so the row stays 1.
  3. Row 'c': no match at 'a' or 'b' (copy max of up and left = 1). At column 'c' they match: diagonal dp[1][2] = 1, so 2. Then 'd' copies 2 from the left.
  4. Row 'b': the match at column 'b' uses diagonal dp[2][1] = 1, giving 2. Columns 'c' and 'd' copy 2. Note 'ab' and 'ac' both have length 2: the table keeps only the length.
  5. Row 'd': the match at column 'd' uses diagonal dp[3][3] = 2, giving 3 in the corner. That is the answer: LCS('acbd', 'abcd') = 3.
  6. Recover one LCS by walking back from the corner: on a match go diagonal and take the letter; otherwise step to the larger of up/left. Taken letters, read backwards: a, c, d -> "acd".
