  • Cue: two sequences, keep order, longest shared -> dp over two prefixes.
  • Insight: last letters equal -> diag + 1; else max(drop a's last, drop b's last).
  • State: dp[i][j] for prefixes of length i, j; row 0 / column 0 = 0.
  • Trap: substring vs subsequence; old diagonal in the 1D version.
  • Cost: O(m·n) time; O(min(m, n)) space with one row + diag.
row = [0] * (n + 1)
for ca in a:
    diag = 0
    for j in range(1, n + 1):
        up = row[j]
        row[j] = diag + 1 if ca == b[j-1] else max(up, row[j-1])
        diag = up
return row[n]

Quick quiz

a[i-1] == b[j-1]. Which cell gives dp[i][j]?

  1. max(dp[i-1][j], dp[i][j-1])
  2. dp[i-1][j-1] + 1
  3. dp[i-1][j] + 1
  4. dp[i][j-1] + 1
Matching last characters can both be used, so the answer is the diagonal plus one.

In the one-row version, why keep a separate diag variable?

  1. to save time
  2. to handle empty strings
  3. Python needs it
  4. row[j-1] is already overwritten with the current row's value
When cell j is computed, row[j-1] holds the new row; the old diagonal must be saved before it is overwritten.

Sizes are 1000 x 1000. What is the time cost?

  1. O(n + m)
  2. O(n log m)
  3. O(n * m) = 10^6 cell updates
  4. O(2^n)
Every (i, j) pair is filled once with O(1) work.
