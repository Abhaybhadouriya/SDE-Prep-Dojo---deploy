The problem (in our words)

A rectangular island is split into an m x n grid of cells. You get the integer matrix heights, where heights[r][c] is the height of cell (r, c). The Pacific ocean touches the island's top and left edges; the Atlantic touches its bottom and right edges. Rain on a cell can move to a neighbour directly up, down, left or right when that neighbour's height is less than or equal to the current cell's height. Any cell next to an ocean can pour into that ocean.

Return a list of coordinates [r, c] of every cell from which rain can reach both the Pacific and the Atlantic. Any order is accepted.

Signature: List<List<Integer>> pacificAtlantic(int[][] heights).

  • m == heights.length, n == heights[r].length
  • 1 <= m, n <= 200
  • 0 <= heights[r][c] <= 105

Practice it: LeetCode 417 - Pacific Atlantic Water Flow.

Constraints tell you: up to 200 x 200 = 40,000 cells. A search from every cell is up to 40,000 x 40,000 = 1.6 billion steps: too slow. O(m·n) is the target, which means each cell is visited a constant number of times. Heights fit in an int; there is no arithmetic on them, only comparisons. "Less than or equal" means a flat plateau lets water through.
