How to recognise it:

  • "Which cells can reach X" where X is a fixed set (border, exits, all zeros): seed the search with X.
  • The move rule is directional (downhill, one-way): flip it when you flip the search direction.

Practice order:

  1. Warm-up: 733 Flood Fill, then 200 Number of Islands.
  2. 130 Surrounded Regions and 1020 Number of Enclaves (one border flood).
  3. This problem (two floods), then 994 Rotting Oranges and 542 01 Matrix (layers), then 407 Trapping Rain Water II.
