Technique: "contribution of each element as the minimum (or maximum) of a range", with the range ends found by nearest-smaller lookups on a monotonic stack.

Closest match: LC 85 Maximal Rectangle Hard

  • Same: the largest all-ones rectangle in a 0/1 matrix is this problem run once per row.
  • Different: the histogram for row r is "consecutive ones ending at row r" per column.
  • So: update h[c] = cell ? h[c] + 1 : 0 row by row and call this function: O(rows × cols).

How to recognise it:

  • A value is limited by the minimum over a contiguous range, and the range should be as long as possible.
  • "For each element, the first smaller/greater one on the left and right."

Extra practice (competitive programming, optional - not interview questions): CodeChef PREP22 Largest Rectangle in Histogram (Same task with stdin/stdout input).
