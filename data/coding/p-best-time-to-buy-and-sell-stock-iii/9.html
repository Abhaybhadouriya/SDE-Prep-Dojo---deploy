60-second recall

  • Cue: stock prices, at most 2 trades, one share at a time.
  • States: buy1, sell1, buy2, sell2 = best balance after each step.
  • Step: each state = max(stay, previous state ± p).
  • Init: buys = -prices[0], sells = 0; answer sell2.
  • Alt: left[i] + right[i] split; k trades: buy[j], sell[j] arrays.
b1 = b2 = -prices[0]; s1 = s2 = 0
for p in prices:
    b1 = max(b1, -p);      s1 = max(s1, b1 + p)
    b2 = max(b2, s1 - p);  s2 = max(s2, b2 + p)
return s2

What does buy2 mean after day d?

  1. The price of the second buy
  2. The best balance over days 0..d if you have completed one trade and now hold the second share
  3. The profit of the second trade
Every state is a best balance, starting from 0 cash.

Why is it fine that sell1 uses the buy1 updated on the same day?

  1. Buying and selling on the same day adds 0 profit, so it never creates a gain
  2. Prices never repeat
  3. It is a bug that the tests miss
A same-day round trip is a no-op in value.
