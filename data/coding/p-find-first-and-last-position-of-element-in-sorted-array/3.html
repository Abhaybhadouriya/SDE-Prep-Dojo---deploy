Recognise the pattern

Cue: sorted input + "first / last / how many / where would it go" + O(log n) -> boundary binary search on a monotone yes/no test. "Find any occurrence" is classic binary search; "first or last occurrence" is lower / upper bound.

The key picture: on a sorted array, the test nums[i] >= target is false for a prefix and true for the rest. So is nums[i] > target. Binary search finds where the falses end.
