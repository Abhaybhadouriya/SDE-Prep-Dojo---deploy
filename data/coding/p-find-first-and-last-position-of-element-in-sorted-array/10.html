How to recognise it:

  • "Sorted", "first/last occurrence", "number of times x appears", "insert position", O(log n).
  • Any question that can be rephrased as "smallest i such that test(i) is true", with a monotone test.

Practice order:

  1. Warm-up: 704 Binary Search, then 35 Search Insert Position (one lower bound), then 278 First Bad Version.
  2. This problem: write boundary(strict) once and test it on all-equal and empty arrays.
  3. Then 2055 Plates Between Candles and 658 Find K Closest Elements; then binary search on the answer (1011).
