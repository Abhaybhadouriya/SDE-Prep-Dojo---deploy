The story

Explain like I'm 5

A librarian keeps a shelf of books sorted by year: 1981, 1983, 1983, 1983, 1985, ... You ask "where do the 1983 books start and end?" She does not read the shelf from the left. She opens the middle, sees 1985, and knows every 1983 is to the left. Twice she plays this halving game: once to find the first book that is "1983 or later", once to find the first book that is "later than 1983". The 1983 books are exactly the books in between.

The whole trick is to stop searching for the target and search for a boundary: the first position where a yes/no question flips from no to yes. Every boundary search uses the same loop, so you write it once and call it twice.

From your world

This is lower_bound / upper_bound from the C++ STL, and the same search the kernel does in sorted tables such as the exception table or a sorted array of timer deadlines: find the first entry at or after a key, then the first entry after it. equal_range returns both at once.
