Interview follow-ups

Why not start the search from each O inside the board?

Inside-out needs one flood per region plus a "touched border" flag, and you must finish the whole flood even after the flag is set. Outside-in has one source set and one rule: reachable means safe. Both are O(m·n); outside-in is shorter and harder to get wrong.

How to answer

Say "reverse the question" explicitly; interviewers listen for it.

Likely follow-ups
  • What if diagonal moves also connect cells? (Use 8 neighbours; nothing else changes.)
Solve it without a queue or recursion.

Union-find over r*n + c plus one virtual node EDGE = m*n. Union each border O with EDGE and each O with its right and down O neighbours. Then flip every O whose root is not find(EDGE). O(m·n·α) time, O(m·n) memory.

How to answer

Name the virtual-node trick; it turns "connected to the boundary" into "same set as one node".

Likely follow-ups
  • Cells flip from X to O over time and you must answer after each change: the union-find version handles additions online.
You may not use a third character in the board.

Keep a separate safe boolean grid (or a bitset of 40,000 bits = 5 KB). The BFS marks safe, and the final pass flips every O that is not safe. Same complexity.

How to answer

Offer the bitset to show you think about memory.

Likely follow-ups
  • Can you reuse the low bit of the char instead? (Possible, but it hurts readability; say so.)
Return the number of captured regions and the size of the largest one.

After the border BFS, the remaining O cells are exactly the captured ones. Run a normal island count over them (one flood per region) and track each flood's size. Still O(m·n).

How to answer

Compose two known tools: border flood, then component counting.

Likely follow-ups
  • This is exactly LC 1254 (count) and LC 1020 (cells).
The board is huge and split across machines by row bands.

Each machine labels its local O components and records which labels touch the global border and which touch the band's top or bottom row. A coordinator unions labels across band edges (union-find on labels) and marks every set containing a border-touching label as safe. Each machine then flips its unsafe labels. Communication is O(n) per band edge.

How to answer

Local work, then a small global merge of boundary information.

Likely follow-ups
  • Same scheme counts islands on a distributed grid.
