Approaches: brute -> better -> optimal

Hint 1

For a given O, what single fact decides whether it gets captured?

Hint 2

It survives exactly when a path of O cells joins it to the border. Where should a search for such paths start?

1. Brute force - one search per O cell

Idea: for every O, run a fresh BFS over O cells and check whether it hits the border. If not, mark the cell for capture (do not flip during the scan, or later searches see a changed board).

O((m·n)²)time worst case
O(m·n)space

What is wasted: every cell of a big region repeats the same search. -> rung 2.

2. Better - one search per region (inside-out)

Idea: scan for an unvisited O, flood its whole region while recording its cells and whether any cell lies on the border. After the flood, if no cell touched the border, flip all recorded cells.

O(m·n)time
O(m·n)visited grid + region list

What is not ideal: correct and linear, but it needs a visited grid and a list per region, and the "touched border" flag is easy to get wrong if you stop the flood early (you must still visit the rest of the region, or the next scan step restarts inside it). -> rung 3 removes the bookkeeping.

3. Optimal - flood from the border (outside-in)

Reverse the question: instead of "is this region closed?", ask "what can the border reach?".

  1. Seed: walk the four edges; every border O becomes '#' (safe) and goes into one queue.
  2. Spread: BFS from all seeds together; an O neighbour of a safe cell is safe too: tag it '#' when you push it.
  3. Flip: one pass: remaining O -> X (captured), '#' -> O (restored).
for every border cell (r, c): keep(r, c)       # 'O' -> '#', push
while q: r, c = q.popleft(); keep each of its 4 neighbours
for every cell: 'O' -> 'X', '#' -> 'O'
O(m·n)time
O(m·n)queue worst case, no visited grid

Why it works: an O survives if and only if a path of O cells joins it to a border O. A BFS seeded with all border O cells reaches exactly the cells that have such a path (BFS finds every cell connected to a source). So after the BFS, "tagged" means "survives" and "still O" means "surrounded". Each cell is tagged at most once, so the BFS is O(m·n), and the final pass is O(m·n).

4. Alternative - union-find with a virtual "border" node

Idea: make one extra node EDGE. Union every border O with EDGE and every O with its right and down O neighbours. Finally, flip each O whose root differs from find(EDGE).

O(m·n·α)time
O(m·n)parent array

When it is useful: no recursion or queue at all, and the virtual-node trick is a reusable idea (it reappears in "regions connected to a boundary" and percolation problems). In an interview the border BFS is shorter.
