Common mistakes

Flipping during the search. If you turn cells into X while still deciding, a later search walks a different board. Decide first (tag), flip in a separate pass.

Only checking the four neighbours of an O for the border. "Not next to the edge" is not "surrounded": (2,3) in example 2 is inner but escapes through (3,3). Reachability is transitive.

Forgetting to restore '#'. The final pass has two jobs: O -> X and # -> O. Writing ch = (ch == '#') ? 'O' : 'X' does both and also leaves X as X.

Recursive DFS on a 200 x 200 board. It passes in C++ most of the time, but Python needs sys.setrecursionlimit and can still crash the interpreter's C stack. Say the risk, then use BFS.

Indexing board[0] before checking the size in languages where an empty board is possible (older versions of this problem allowed it). Today m, n >= 1, but a one-line guard costs nothing.
