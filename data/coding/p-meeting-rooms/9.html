  • Cue: list of [start, end] + "can one person attend all?" (any overlap).
  • Insight: sorted by start, the first overlap is always between neighbours.
  • State: the sorted list; compare cur.start with prev.end.
  • Trap: strict < (touching is fine); empty list returns true.
  • Cost: O(n log n) time for the sort, O(1) extra; brute O(n^2).
iv.sort(key=lambda x: x[0])
for i in range(1, len(iv)):
    if iv[i][0] < iv[i - 1][1]:
        return False      # or: merge / count rooms
return True

After sorting by start time, what proves a clash?

  1. Any meeting longer than an hour
  2. intervals[i].start < intervals[i-1].end
  3. Two equal end times
In sorted order only neighbours need comparing: if the next one starts before the previous ends, one person cannot attend both.

Do [5,10] and [10,15] clash?

  1. Yes
  2. No, one ends exactly when the next starts
  3. Only if they are in different rooms
End times are exclusive here, so use a strict <.

Time and space?

  1. O(n log n) for the sort, O(1) extra (or the sort's own space)
  2. O(n), O(n)
  3. O(n^2), O(1)
The scan is O(n); the sort dominates.
