The story

Explain like I'm 5

A consultant gets a list of booked calls for one day, in no particular order. She has one headset and can be on one call at a time. Can she take all of them? On paper you would sort the calls by start time and read down the list: the only question at each line is "does this call start before the previous one ended?". You never need to compare a call with one far up the list.

From your world

This is the check you do on a sorted list of memory regions (or IP ranges) before you program them into an MMU or a routing table: sort by base address and verify that each base is at or past the previous region's end. One overlapping neighbour pair is the whole failure condition.
