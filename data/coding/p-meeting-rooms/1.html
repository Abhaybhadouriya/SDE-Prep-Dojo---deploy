The problem (in our words)

You get an array of meeting time ranges intervals, where intervals[i] = [start_i, end_i]. Decide whether one person could attend all of them, which means no two meetings overlap. A meeting that ends at time t and another that starts at time t do not overlap (the end time is exclusive).

Return true if every meeting can be attended, otherwise false.

Signature: boolean canAttendMeetings(int[][] intervals)

  • Constraints:
  • 0 <= intervals.length <= 10^4
  • intervals[i].length == 2
  • 0 <= start_i < end_i <= 10^6

Practice it: LeetCode 252 - Meeting Rooms Premium · GfG - Meeting Rooms (attend all meetings, free)

Constraints tell you: n up to 10^4 makes even the O(n^2) pair check pass in most judges, but the interviewer wants O(n log n). An empty array is allowed and must return true. Times up to 10^6 also allow a counting approach over time if needed.
