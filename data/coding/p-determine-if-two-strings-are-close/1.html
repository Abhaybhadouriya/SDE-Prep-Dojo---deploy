The problem (in our words)

A puzzle game shows two words made of lower-case letters. You may change a word with two moves, as often as you like and on either word:

  • Move 1 (swap): exchange the positions of any two characters, for example pqrst → ptrsq.
  • Move 2 (relabel): choose two letters that both already occur in the word and turn every copy of the first into the second and every copy of the second into the first, for example xxyzyy → yyxzxx (all x become y and all y become x).

The words are called close if one can be turned into the other. Given word1 and word2, return true if they are close and false otherwise.

  • Input: two strings word1, word2.
  • Output: a boolean. Signature: boolean closeStrings(String word1, String word2).

Constraints

  • 1 <= word1.length, word2.length <= 10^5 (the lengths may differ)
  • word1 and word2 contain only lower-case English letters.

Practice it: LeetCode 1657 - Determine if Two Strings Are Close

Constraints tell you: n = 10^5 rules out any search over reachable strings; one linear pass is the target. Only 26 letters means every per-letter table is constant size, so sorting it costs O(26 log 26), a constant.
