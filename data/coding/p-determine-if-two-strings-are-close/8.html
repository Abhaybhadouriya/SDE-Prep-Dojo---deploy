Common mistakes

Checking only the sorted counts. "uuv" and "wwv" pass that test but are not close. The letter-set check is half of the answer.

Checking only the letter set. "aabbcc" and "aaabbc" use the same letters, but no relabel turns counts {2,2,2} into {3,2,1}.

Comparing per-letter counts (an anagram test). That answers a stricter question and returns false for "kkkllm" and "lmmkkk".

Reusing the one-array +1/-1 trick from Valid Anagram. Adding for word1 and subtracting for word2 tests per-letter equality, which is the anagram question again. Here the two count arrays must be kept apart so each can be sorted.

Sorting the words instead of the counts. Sorting characters costs O(n log n) and still leaves you with an anagram check, not a closeness check.
