Interview follow-ups

Reverse the leftover group too.

Drop the probe's early exit: reverse up to k nodes, stopping at null. With the iterative code, count the actual group length and use after = null when the list ends. This is the GfG version.

How to answer

Show which one line encodes the "leave the tail" rule (the probe) and change only that.

Likely follow-ups
  • Reverse alternate groups only (reverse k, skip k).
Count the groups from the end instead (the leftover is at the front).

Compute the length n first, skip n % k nodes, then run the same loop from there. Or reverse the whole list, apply the algorithm, and reverse back - three O(n) passes, still O(1) space.

How to answer

Prefer the length-first version: one extra pass, no double reversal to reason about.

Likely follow-ups
  • Can you do it in one pass? (Not without knowing n or using extra space.)
Why a dummy node? Can you do without it?

Without it, the first group must be special-cased: its new head becomes the list's new head, and there is no previous tail to stitch. The dummy gives every group a node before it. In C you can use a pointer-to-pointer (ListNode **link = &head) instead of a dummy node.

How to answer

Mention the pointer-to-pointer idiom; kernel-style C reviewers like it.

Likely follow-ups
  • Rewrite the stitch with **link.
It is a doubly linked list. What extra work is there?

Inside a group, swap prev and next on each node. At the seams, also fix after.prev = first and kth.prev = prevTail. Four seam pointers instead of two; still O(n) / O(1).

How to answer

List the seam pointers explicitly; that is where bugs hide.

Likely follow-ups
  • Circular list: where does the probe stop?
Give the recursive version and its space cost.

Count k nodes; if short, return head. Recurse on node k+1 to get the solved rest, then head-insert the k nodes of this group in front of it one by one (rung 2). The stack holds one frame per group: O(n/k), up to 5000 frames for k = 1.

How to answer

Give it as a clean alternative, then say why the iterative one meets the follow-up.

Likely follow-ups
  • Is it tail-recursive? (No: work happens after the call returns.)
