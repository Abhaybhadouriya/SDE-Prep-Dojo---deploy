The problem (in our words)

You are given the root of a binary tree. Give the root column 0; a left child is one column to the left of its parent (col - 1) and a right child one column to the right (col + 1).

Return the node values column by column, from the leftmost column to the rightmost. Inside one column, list values from top to bottom. If two nodes are in the same row and the same column, list them from left to right (the order a level-order scan meets them).

Signature: List<List<Integer>> verticalOrder(TreeNode root). The tree is given in level-order form, e.g. [6,2,9,null,null,7,11]; an empty tree returns [].

  • The number of nodes is in the range [0, 100].
  • -100 <= Node.val <= 100

Practice it: LeetCode 314 (Premium) · GfG Vertical Tree Traversal (free, same tie rule)

Constraints tell you: at most 100 nodes, so speed is not the issue; the interviewer wants the correct order and the reason BFS gives it. Columns range over [-99, 99]; an empty tree is allowed (0 nodes), so handle null.
