Common mistakes

Using recursive DFS and a column map. The order inside a column breaks as soon as a deep left-subtree node drifts into a column with a shallower node from the right subtree.

Sorting values inside a column. That is LC 987's rule. Here example 2 must give [10, 8, 7], not [10, 7, 8].

Forgetting the empty tree. 314 allows 0 nodes; pushing null into the queue crashes on node.val.

Indexing an array by column without an offset. Columns go negative. Use a hash map plus min/max, or offset by n.

Pushing null children with a column. Harmless in some languages but wastes queue space and needs an extra check on pop; push only real children.
