Recognise the pattern

Cue: "group tree nodes by a horizontal position, top to bottom, ties left to right" -> BFS carrying the position, bucket by position. BFS order is row order with left-to-right inside each row, which is exactly the tie rule. If the tie rule were "by value" (LC 987), you would need a sort.

The same skeleton answers top view (keep the first value per column), bottom view (keep the last), and the column-width questions.
