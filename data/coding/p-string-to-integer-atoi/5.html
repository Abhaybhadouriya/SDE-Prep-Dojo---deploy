Dry run

s = " -0072 units". Greyed cells are consumed; the ring is the character being read.

  1. Phase 1: s[0] is a space. Skip it (i++). Only the space character counts; a tab or a letter would end this phase.
  2. s[1] is also a space: skip.
  3. Phase 2: s[2] = '-', so sign = -1, i++. At most one sign is read; a second + or - would be a non-digit and end the number.
  4. Phase 3: digit 0. Overflow check: is 0 > (2147483647 - 0) / 10? No. value = 0·10 + 0 = 0. Leading zeros cost nothing.
  5. Digit 0 again: value stays 0.
  6. Digit 7: check 0 > (2147483647 - 7) / 10? No. value = 7.
  7. Digit 2: check 7 > 214748364? No. value = 72.
  8. s[7] is a space, not a digit: stop reading. Everything after it ("units") is ignored, even the digits it might contain.
  9. Return sign · value = -72. One pass, O(n) time, three integers of state.
