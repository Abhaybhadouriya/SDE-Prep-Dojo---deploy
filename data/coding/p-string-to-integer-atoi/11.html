Interview follow-ups

Write the overflow check without using a wider type.

if (value > (INT_MAX - d) / 10) before folding, or the two-part form value > INT_MAX / 10 || (value == INT_MAX / 10 && d > 7). Both are exact for a non-negative magnitude.

How to answer

Show the algebra in one line and test it on 2147483647 (no clamp) and 2147483648 (clamp).

Likely follow-ups
  • What changes for 64-bit (int64) output? (Only the constant.)
Write it as an explicit state machine (DFA).

States start, signed, in_number, end; a transition table indexed by character class (space, sign, digit, other). The parse loop becomes state = table[state][cls(c)], and the digit action runs in in_number. It is longer here, but it scales to Valid Number, where hand-written ifs get messy.

How to answer

Draw the four states first, then the table; mention that the table makes the rules easy to audit.

Likely follow-ups
  • Add support for hex 0x1F. (A new state after a leading 0, digit values from a lookup.)
Return an error for invalid input instead of 0, like strtol.

Return the position where parsing stopped (like endptr) and a status: ok, no digits, out of range. The caller can then reject trailing garbage ("12abc") that atoi silently accepts.

How to answer

Point out the API difference: atoi cannot tell "0" from "abc"; that is why strtol and kstrtoint exist.

Likely follow-ups
  • Reject leading zeros? Allow underscores as digit separators?
Do it recursively.

Strip the prefix iteratively, then parse(i, value) returns value at the first non-digit and otherwise recurses with value · 10 + d (with the same check). TUF's write-up uses this form. Depth is the digit count, at most 200.

How to answer

Make it tail-recursive and say that the loop is what the compiler would turn it into.

Likely follow-ups
  • Stack depth for a 106-character input? (Too deep in Python and Java; use the loop.)
Parse a number in any base 2-36, with the same clamping.

Map characters to digit values (0-9, a-z/A-Z -> 10-35), reject digits ≥ base, and use value > (INT_MAX - d) / base. Everything else is unchanged.

How to answer

Show that the pre-check generalises by replacing 10 with the base.

Likely follow-ups
  • Auto-detect the base from 0x / 0 / 0b prefixes, as strtol(s, NULL, 0) does.
