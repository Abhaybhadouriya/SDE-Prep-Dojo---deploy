Common mistakes

Using trim() / isspace. Only ' ' is skipped. It does not matter for LeetCode's character set, but say it; real atoi also skips tabs and newlines, so be explicit about which spec you follow.

Overflowing first, checking after. value = value * 10 + d; if (value > INT_MAX) in a 32-bit int is undefined behaviour in C++ and silently wraps in Java, so the test never fires.

Parsing into a long and clamping at the end. 200 digits overflow 64 bits too. Clamp inside the loop.

Accumulating a negative value with the sign applied. Possible, but then the check and the rounding of negative division differ by language. Keep a non-negative magnitude and a separate sign.

Python str.isdigit(). It accepts Unicode digits like '²', and int('²') fails. Compare with '0' <= c <= '9'.
