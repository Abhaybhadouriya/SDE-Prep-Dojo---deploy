Counting windows and "exactly K"

"How many subarrays have product less than k?" For each right, after shrinking, every window that ends at right and starts anywhere in [left, right] is valid (smaller windows inside a valid one are valid). That is right - left + 1 windows. Add it up and you have counted all of them in O(n).

"Exactly K distinct" is not monotone: a window with exactly 3 distinct values can become a window with 2 when you shrink it, which is not valid either, but growing it can also make it valid again. The template breaks. The fix is a subtraction:

exactly(K) = atMost(K) - atMost(K - 1), and "at most" is monotone, so each part is one ordinary pass. The same trick solves "binary subarrays with sum S" (atMost(S) - atMost(S - 1)) and "count nice subarrays with k odd numbers".

Sliding windows need the condition to be monotone. "Subarray sum equals k" with negative numbers is not: adding a negative number shrinks the sum, so you cannot know which way to move. Use prefix sums and a hash map of seen prefix sums instead (O(n) time, O(n) space).
