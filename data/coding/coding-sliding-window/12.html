Remember this

Revision card

  • Cue: Contiguous subarray or substring, longest / shortest / count with a condition, fixed size k.
  • Insight: Both edges only move forward, so a window over all n positions costs O(n).
  • State: left, right and an O(1) state (sum, counts, distinct, missing); a deque for window max.
  • Trap: A condition that is not monotone (negatives in sums); recording at the wrong moment for "shortest".
  • Cost: O(n) time; O(alphabet) or O(k) space.

More to remember

  • A window is [left, right]; both edges only move forward, so the work is O(n).
  • Fixed window: add a[right], remove a[right - k].
  • Variable window: expand, shrink while invalid, record. "Shortest": shrink while valid, record inside.
  • The condition must be monotone. If not, try atMost(K) - atMost(K - 1), prefix sums, or heaps.
  • Count windows ending at right: right - left + 1.
  • Window max/min: a deque of indexes with monotone values.
  • State is O(1) to update: sum, counts, distinct, missing, max frequency.
