In a fixed window of size k, which element leaves when right is added?

  1. a[left + k]
  2. a[right - k + 1]
  3. a[right - k]
  4. a[right - 1]
The new window is [right - k + 1, right], so the index just before it, right - k, leaves.

"Longest substring with at most k distinct characters". Where do you record the answer?

  1. Inside the shrink loop

Which problem breaks the sliding window template?

  1. Fruit into baskets
  2. Count subarrays with sum exactly k, numbers may be negative
  3. Minimum size subarray with sum at least S (positive numbers)
  4. Max consecutive ones with k flips
With negatives, growing the window can lower the sum, so validity is not monotone. Use prefix sums.

After shrinking, the window [left, right] is valid and validity is monotone. How many valid windows end at right?

  1. n - right
  2. right - left
  3. right - left + 1
  4. 1
Every start from left to right gives a valid window, because a smaller window inside a valid one is valid.

The monotonic deque for window maximum stores...

  1. indexes whose values are decreasing from front to back
  2. all indexes of the window
  3. the k largest values
  4. values in increasing order
Front = current max; smaller older values at the back are popped when a bigger value arrives.

Count subarrays with exactly 3 distinct values:

  1. atMost(3) + atMost(2)
  2. atMost(3) - atMost(2)
  3. Sort, then two pointers
  4. One window, shrink while distinct > 3
"Exactly" is not monotone; "at most" is, and the difference counts exactly 3.
