Variable windows: expand, shrink, record

Here the length is the answer. "Longest substring with no repeated letter." "Shortest subarray with sum at least S." "Longest run of 1s if you may flip at most k zeros." One template solves all of them:

left = 0
for right in range(n):
    add(a[right])                 # 1. expand
    while window_is_invalid():    # 2. shrink until valid
        remove(a[left]); left += 1
    best = max(best, right - left + 1)   # 3. record (longest)

The one rule that makes this correct: validity must be monotone. If a window is invalid, every bigger window that contains it is also invalid; if it is valid, every smaller window inside it is valid. "At most k distinct letters" has that property: removing letters can only lower the distinct count. Because of it, once right is fixed, the best left is the smallest one that makes the window valid, and that left never needs to move back when right grows.

Watch it on "abaccc" with "at most 2 distinct letters":

  1. Expand: right = 0 takes 'a'. 1 distinct, still within k = 2, so the window [0..0] is valid. Length 1, new best = 1.
  2. Expand: right = 1 takes 'b'. 2 distinct, still within k = 2, so the window [0..1] is valid. Length 2, new best = 2.
  3. Expand: right = 2 takes 'a'. 2 distinct, still within k = 2, so the window [0..2] is valid. Length 3, new best = 3.
  4. Expand: right = 3 takes 'c'. Now 3 distinct letters, more than k = 2. The window is invalid, so we may not record it.
  5. Shrink: move left forward, removing 'a' then 'b', until only 2 distinct letters remain. left = 2. Valid again; length 2, best stays 3.
  6. Expand: right = 4 takes 'c'. 2 distinct, still within k = 2, so the window [2..4] is valid. Length 3, best stays 3.
  7. Expand: right = 5 takes 'c'. 2 distinct, still within k = 2, so the window [2..5] is valid. Length 4, new best = 4.
  8. right reached the end: answer 4, the window "accc". left moved 2 times and right 6 times in total, so the work is O(n) even with the inner while loop.
