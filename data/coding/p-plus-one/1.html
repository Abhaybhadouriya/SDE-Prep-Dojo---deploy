The problem (in our words)

A non-negative integer is stored as an array digits: digits[0] is the most significant digit and the last element is the least significant one. There are no leading zeros (except the number 0 itself, which is [0]). Add one to the number and return the result in the same digit-array format.

Signature: int[] plusOne(int[] digits).

  • 1 <= digits.length <= 100
  • 0 <= digits[i] <= 9
  • digits has no leading 0.

Practice it: LeetCode 66 · GfG Adding One to Array

Constraints tell you: up to 100 digits, so the number can be far beyond 64 bits (264 has only 20 digits). Converting to an integer and back fails in C++, Java and Go; you must do the arithmetic on the digits. The size is tiny, so any O(n) idea is fine; the interview is about the carry and the all-nines case.
