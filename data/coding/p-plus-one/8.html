Common mistakes

Converting to long. Passes the small examples, fails on 20+ digits. Interviewers often pick this problem to see if you notice.

Forgetting the all-nines case. The loop ends with [0,0,0] and you return it. Always ask "what if the carry is still 1 after index 0?"

Copying the array into a new one of size n+1 every time. Only all-nines needs a new array, and its contents are known (1 then zeros), so there is nothing to copy.

Looping from the front. The least significant digit is the last element. Starting at index 0 adds 1 to the wrong place.
