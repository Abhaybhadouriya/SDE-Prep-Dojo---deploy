Patience sorting on [4, 10, 4, 3, 8, 9]. What is tails at the end?

  1. [4, 8, 9, 10]
  2. [3, 4, 8, 9]
  3. [3, 8, 9]
  4. [4, 10]
4 → [4]; 10 → [4, 10]; 4 replaces 4; 3 replaces 4 → [3, 10]; 8 replaces 10 → [3, 8]; 9 appends → [3, 8, 9]. LIS = 3.

You need the longest non-decreasing subsequence. Which search do you use on tails?

  1. Either; they give the same length
  2. Linear scan from the end
  3. lower_bound (first >= x)
  4. upper_bound (first > x)
Equal values must extend the run, so x has to go after any equal tail: first slot strictly greater than x.

In edit distance, which neighbour of dp[i][j] means "insert b[j-1]"?

  1. dp[i-1][j-1]
  2. dp[i-1][j]
  3. dp[i][j-1]
  4. dp[i+1][j]
After inserting b[j-1] at the end of a, that character is done and a is unchanged: what remains is a[0..i) to b[0..j-1).

Fewest deletions (from either string) to make "sea" and "eat" equal?

  1. 2
  2. 3
  3. 1
  4. 4
LCS = "ea" (2). Deletions = 3 + 3 - 2 · 2 = 2: drop s from the first, t from the second.

Longest common substring of two arrays. What does a mismatch at (i, j) set?

  1. max(dp[i-1][j], dp[i][j-1])
  2. dp[i-1][j-1]
  3. 0
  4. 1
dp[i][j] is the common run ending at both positions; a mismatch breaks it. The answer is the max over all cells.

Regex: s = "", p = "a*b*". What is dp[0][0], and which row of the table decides it?

  1. true; the i = n row (empty rest of s)
  2. true; column 0
  3. false; row 0
  4. false; the pattern is longer than s
With n = 0, row i = n is the only row. a* and b* each take the skip branch (j+2), reaching dp[0][4] = true.

Distinct subsequences with one 1-D array: why must j go from m down to 1?

  1. To save memory
  2. Because t is read right to left
  3. So the answer comes out in dp[0]
  4. So dp[j-1] still holds the previous row's value when dp[j] is updated
A forward loop would use the current character twice in one row, like unbounded knapsack instead of 0/1.
