Counting: distinct subsequences

Problem (restated from LeetCode 115, Distinct Subsequences). Given strings s and t, count the ways to pick characters of s, in order, that spell t. Two ways differ if they use a different set of positions. Example: s = "banana", t = "ban" gives 3. Limits: both strings have 1 to 1000 English letters, and the tests are built so the answer fits in a 32-bit signed integer.

dp[i][j] = number of ways to spell t[0..j) using s[0..i). Base: dp[i][0] = 1 (one way to spell the empty string: pick nothing) and dp[0][j] = 0 for j > 0. For each character of s you can always skip it (dp[i-1][j], up), and if s[i-1] == t[j-1] you may also use it (dp[i-1][j-1], diagonal). The two choices give different position sets, so you add them. Counting problems add; optimisation problems take max or min. The grid is the same.

With one row, the new value of dp[j] needs the old dp[j-1]. Loop j backwards so dp[j-1] has not been overwritten yet; this is the same reason 0/1 knapsack loops capacity backwards.

// Distinct subsequences: ways to pick t out of s. j runs BACKWARDS so
// dp[j-1] is still the previous row's value.
func numDistinct(s, t string) int64 {
	m := len(t)
	dp := make([]int64, m+1)
	dp[0] = 1
	for i := 0; i < len(s); i++ {
		for j := m; j >= 1; j-- {
			if t[j-1] == s[i] {
				dp[j] += dp[j-1]
			}
		}
	}
	return dp[m]
}
// Distinct subsequences: ways to pick t out of s. 1-D, j runs BACKWARDS so
// dp[j-1] is still the previous row's value.
long long numDistinct(const string& s, const string& t) {
    int m = t.size();
    vector<long long> dp(m + 1, 0);
    dp[0] = 1;                                   // empty t: one way
    for (char c : s)
        for (int j = m; j >= 1; j--)
            if (t[j - 1] == c) dp[j] += dp[j - 1];
    return dp[m];
}
// Distinct subsequences: ways to pick t out of s. j runs BACKWARDS so
// dp[j-1] is still the previous row's value.
static long numDistinct(String s, String t) {
    int m = t.length();
    long[] dp = new long[m + 1];
    dp[0] = 1;
    for (char c : s.toCharArray())
        for (int j = m; j >= 1; j--)
            if (t.charAt(j - 1) == c) dp[j] += dp[j - 1];
    return dp[m];
}
def num_distinct(s: str, t: str) -> int:
    """Ways to pick t out of s. j runs BACKWARDS so dp[j-1] is still last row's."""
    m = len(t)
    dp = [1] + [0] * m
    for c in s:
        for j in range(m, 0, -1):
            if t[j - 1] == c:
                dp[j] += dp[j - 1]
    return dp[m]

Overflow. The final answer fits in 32 bits, but middle values may not. Many accepted C++ and Java solutions use long long / long (or unsigned) for the table. Python does not care. Say this in the interview even if the tests pass with int.
