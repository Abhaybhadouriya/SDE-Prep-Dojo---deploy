Patience sorting: LIS in O(n log n)

The faster method keeps a different array. tails[L-1] = the smallest possible last value of any increasing subsequence of length L seen so far. Why the smallest? A run that ends lower is never worse: anything that could extend a run ending at 9 could also extend a run ending at 4. So for each length we only need to remember the best (lowest) ending.

Fact: tails is always sorted in increasing order. (If a length-3 run ended at 5, its first two items form a length-2 run that ends below 5, so tails[1] < 5.) Because it is sorted, each new value x needs one binary search:

  1. Find the first slot with tails[k] >= x (C++ lower_bound, Python bisect_left, Go sort.SearchInts).
  2. Append x if no such slot exists: x extends the longest run, so the answer grows by one.
  3. Replace tails[k] with x otherwise: there is now a length-(k+1) run that ends lower.

Click through it on the same array:

  1. 8: tails is empty, append. tails = [8]: the best length-1 run ends at 8.
  2. 6: the first tail >= 6 is 8 in slot 0; replace it. tails = [6]. Same length, but a length-1 run can now end lower, which leaves more room to grow.
  3. 1: the first tail >= 1 is 6 in slot 0; replace it. tails = [1]. Same length, but a length-1 run can now end lower, which leaves more room to grow.
  4. 4: bigger than every tail, so append. tails = [1, 4], length 2 is now possible.
  5. 2: the first tail >= 2 is 4 in slot 1; replace it. tails = [1, 2]. Same length, but a length-2 run can now end lower, which leaves more room to grow.
  6. 5: bigger than every tail, so append. tails = [1, 2, 5], length 3 is now possible.
  7. 90: bigger than every tail, so append. tails = [1, 2, 5, 90], length 4 is now possible.
  8. 12: the first tail >= 12 is 90 in slot 3; replace it. tails = [1, 2, 5, 12]. Same length, but a length-4 run can now end lower, which leaves more room to grow. Done: the answer is len(tails) = 4. tails here happens to be a real subsequence, but in general it is not (try [3, 4, 1]: tails = [1, 4]).

The name comes from the card game: you deal cards onto piles, each card on the leftmost pile whose top is bigger or equal, and the number of piles at the end is the LIS length. tails holds the pile tops.

Template: LIS, both ways

// O(n^2) LIS: dp[i] = longest strictly increasing subsequence that ENDS at i.
func lisQuadratic(a []int) int {
	dp := make([]int, len(a))
	best := 0
	for i := range a {
		dp[i] = 1
		for j := 0; j < i; j++ {
			if a[j] < a[i] && dp[j]+1 > dp[i] {
				dp[i] = dp[j] + 1
			}
		}
		if dp[i] > best {
			best = dp[i]
		}
	}
	return best
}

// O(n log n) patience sorting: tails[L-1] = smallest tail of any increasing
// subsequence of length L. tails stays sorted, so binary search it.
func lisFast(a []int) int {
	tails := []int{}
	for _, x := range a {
		k := sort.SearchInts(tails, x) // first index with tails[k] >= x (strict LIS)
		if k == len(tails) {
			tails = append(tails, x)
		} else {
			tails[k] = x
		}
	}
	return len(tails)
}
// O(n^2) LIS: dp[i] = longest strictly increasing subsequence that ENDS at i.
int lisQuadratic(const vector<int>& a) {
    int n = a.size(), best = 0;
    vector<int> dp(n, 1);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
        best = max(best, dp[i]);
    }
    return best;
}

// O(n log n) patience sorting: tails[L-1] = smallest possible tail of an
// increasing subsequence of length L. tails stays sorted, so binary search.
int lisFast(const vector<int>& a) {
    vector<int> tails;
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x); // strict: lower_bound
        if (it == tails.end()) tails.push_back(x);            // x extends the longest pile
        else *it = x;                                         // x is a better (smaller) tail
    }
    return tails.size();
}
// O(n^2) LIS: dp[i] = longest strictly increasing subsequence that ENDS at i.
static int lisQuadratic(int[] a) {
    int n = a.length, best = 0;
    int[] dp = new int[n];
    for (int i = 0; i < n; i++) {
        dp[i] = 1;
        for (int j = 0; j < i; j++)
            if (a[j] < a[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
        best = Math.max(best, dp[i]);
    }
    return best;
}

// O(n log n) patience sorting: tails[L-1] = smallest tail of any increasing
// subsequence of length L. tails is sorted, so we binary search it.
static int lisFast(int[] a) {
    int[] tails = new int[a.length];
    int len = 0;
    for (int x : a) {
        int lo = 0, hi = len;                 // first index with tails[idx] >= x
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (tails[mid] < x) lo = mid + 1; else hi = mid;
        }
        tails[lo] = x;                        // replace, or append when lo == len
        if (lo == len) len++;
    }
    return len;
}
def lis_quadratic(a: List[int]) -> int:
    """dp[i] = longest strictly increasing subsequence that ENDS at i. O(n^2)."""
    dp = [1] * len(a)
    for i in range(len(a)):
        for j in range(i):
            if a[j] < a[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp, default=0)


def lis_fast(a: List[int]) -> int:
    """Patience sorting, O(n log n): tails[L-1] = smallest tail of any
    increasing subsequence of length L. tails stays sorted."""
    tails: List[int] = []
    for x in a:
        k = bisect_left(tails, x)  # strict increase -> bisect_left
        if k == len(tails):
            tails.append(x)        # x extends the longest pile
        else:
            tails[k] = x           # x is a smaller tail for length k+1
    return len(tails)

Strict or not? For a strictly increasing run use lower_bound / bisect_left, which replaces an equal value instead of extending past it. For a non-decreasing run (equal values allowed) use upper_bound / bisect_right. This one word is what the interviewer checks with an input like [2, 2, 2].

Rebuilding the actual subsequence in O(n log n) needs two more arrays: tailIdx[k] (the index of the value stored in tails[k]) and prev[i] (the index stored in tailIdx[k-1] at the moment i was placed in slot k). Follow prev back from tailIdx[last]. Do not print tails: it is a list of the best endings for each length, and in general it is not a real subsequence.
