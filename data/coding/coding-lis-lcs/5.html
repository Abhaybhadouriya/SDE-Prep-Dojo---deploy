Two strings, one grid: LCS

Every two-string problem on this page uses the same state: dp[i][j] = the answer for the first i characters of a and the first j characters of b. The table is (n+1) x (m+1). The extra row and column are the empty prefix, and they hold the base cases, so the loops never read index -1. When filling cell (i, j) you look at the last characters a[i-1] and b[j-1] and decide what to do with them. There are only three moves.

Problem (restated from LeetCode 1143, Longest Common Subsequence). Given two strings text1 and text2 of lowercase letters, return the length of their longest common subsequence: the longest string that is a subsequence of both. Return 0 if they share no letter. Example: "crate" and "trace" give 3 (for example "rae"). Limits: each string has 1 to 1000 characters.

If the last letters match, using both is always safe: dp[i][j] = dp[i-1][j-1] + 1. (Any common subsequence that does not end with this pair can be changed to end with it without getting shorter.) If they differ, at least one of the two letters is not in the answer, so drop one: max(dp[i-1][j], dp[i][j-1]).

// dp[i][j] = answer for prefixes a[:i] and b[:j]; row/column 0 = empty prefix.
func lcs(a, b string) int {
	n, m := len(a), len(b)
	dp := make([][]int, n+1)
	for i := range dp {
		dp[i] = make([]int, m+1)
	}
	for i := 1; i <= n; i++ {
		for j := 1; j <= m; j++ {
			if a[i-1] == b[j-1] {
				dp[i][j] = dp[i-1][j-1] + 1 // use both
			} else {
				dp[i][j] = max(dp[i-1][j], dp[i][j-1]) // drop one
			}
		}
	}
	return dp[n][m]
}
// dp[i][j] = answer for the prefixes a[0..i) and b[0..j). Row 0 and column 0
// are the empty-prefix base cases, so the loops never index -1.
int lcs(const string& a, const string& b) {
    int n = a.size(), m = b.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            dp[i][j] = a[i - 1] == b[j - 1] ? dp[i - 1][j - 1] + 1            // use both
                                            : max(dp[i - 1][j], dp[i][j - 1]); // drop one
    return dp[n][m];
}
// dp[i][j] = answer for prefixes a[0..i) and b[0..j); row/column 0 = empty prefix.
static int lcs(String a, String b) {
    int n = a.length(), m = b.length();
    int[][] dp = new int[n + 1][m + 1];
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? dp[i - 1][j - 1] + 1                       // use both
                    : Math.max(dp[i - 1][j], dp[i][j - 1]);      // drop one
    return dp[n][m];
}
def lcs(a: str, b: str) -> int:
    """dp[i][j] = answer for prefixes a[:i] and b[:j]; row/column 0 = empty prefix."""
    n, m = len(a), len(b)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1           # use both
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])  # drop one
    return dp[n][m]

Many questions are LCS in disguise. Once you see it, the answer is one line on top of the table:

  • Delete Operation for Two Strings (583): fewest deletes to make them equal = n + m - 2 · LCS.
  • Minimum ASCII Delete Sum (712): the same table, but you keep the most ASCII weight instead of the most letters.
  • Shortest Common Supersequence (1092): length n + m - LCS; to print it, walk the traceback and emit common letters once and the others as you pass them.
  • Uncrossed Lines (1035): LCS on integer arrays.
  • Minimum insertions to make a string a palindrome: n - LCS(s, reverse(s)), covered on the palindrome DP page.

Substring is different. Maximum Length of Repeated Subarray (718) asks for a contiguous match. Then dp[i][j] = length of the common run that ends at both i and j: dp[i-1][j-1] + 1 on a match, and 0 otherwise (the run breaks). The answer is the max over all cells, not the corner.
