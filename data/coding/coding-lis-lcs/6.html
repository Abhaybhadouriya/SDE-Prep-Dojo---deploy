Edit distance: three arrows with a cost

Problem (restated from LeetCode 72, Edit Distance). Given word1 and word2, return the fewest operations that turn word1 into word2. One operation is: insert a character, delete a character, or replace a character. Example: "trace" to "rat" takes 3 (delete t, replace c with t, delete e). Limits: each word has 0 to 500 lowercase letters.

dp[i][j] = fewest edits to turn a[0..i) into b[0..j). Base cases: dp[i][0] = i (delete everything) and dp[0][j] = j (insert everything). For the rest, look at the last characters. If they match, keep both for free: dp[i-1][j-1]. Otherwise pay 1 for the cheapest of:

  • replace a[i-1] with b[j-1]: then both are done, dp[i-1][j-1] + 1 (diagonal);
  • delete a[i-1]: dp[i-1][j] + 1 (up);
  • insert b[j-1] at the end of a: dp[i][j-1] + 1 (left).
  1. Base cases first. Row 0: turning "" into "", "r", "ra", "rat" costs 0, 1, 2, 3 inserts. Column 0: turning "t", "tr", ... into "" costs 1, 2, ... deletes. These are why the table has an extra row and column.
  2. Row 1 (t): 1, 2, 2. t = t at column 3, so that cell copies its diagonal for free: dp[1][3] = dp[0][2] = 2. Every other cell is 1 + the smallest of diagonal, up and left.
  3. Row 2 (r): 1, 2, 3. r = r at column 1, so that cell copies its diagonal for free: dp[2][1] = dp[1][0] = 1. Every other cell is 1 + the smallest of diagonal, up and left.
  4. Row 3 (a): 2, 1, 2. a = a at column 2, so that cell copies its diagonal for free: dp[3][2] = dp[2][1] = 1. Every other cell is 1 + the smallest of diagonal, up and left.
  5. Row 4 (c): 3, 2, 2. c matches no letter of "rat", so every cell is 1 + the smallest of diagonal, up and left.
  6. Row 5 (e): 4, 3, 3. e matches no letter of "rat", so every cell is 1 + the smallest of diagonal, up and left.
  7. Trace back from the corner to read the edits: delete t, keep r, keep a, delete c, replace e with t. Total 3 edits. Each row only ever read the row above it, so two rows of memory are enough.

Row i only reads row i-1 and the cell to its left, so two rows are enough: O(nm) time, O(min(n, m)) memory if you put the shorter string on the columns. If you also need the list of edits, keep the full table and trace back as in the last step.

// Edit distance with two rolling rows: O(n*m) time, O(m) memory.
func minDistance(a, b string) int {
	n, m := len(a), len(b)
	prev, cur := make([]int, m+1), make([]int, m+1)
	for j := 0; j <= m; j++ {
		prev[j] = j // "" -> b[:j]: j inserts
	}
	for i := 1; i <= n; i++ {
		cur[0] = i // a[:i] -> "": i deletes
		for j := 1; j <= m; j++ {
			if a[i-1] == b[j-1] {
				cur[j] = prev[j-1]
			} else {
				cur[j] = 1 + min(prev[j-1], prev[j], cur[j-1]) // replace, delete, insert
			}
		}
		prev, cur = cur, prev
	}
	return prev[m]
}
// Edit distance with two rolling rows: O(n*m) time, O(m) memory.
int minDistance(const string& a, const string& b) {
    int n = a.size(), m = b.size();
    vector<int> prev(m + 1), cur(m + 1);
    for (int j = 0; j <= m; j++) prev[j] = j;          // "" -> b[0..j): j inserts
    for (int i = 1; i <= n; i++) {
        cur[0] = i;                                    // a[0..i) -> "": i deletes
        for (int j = 1; j <= m; j++) {
            if (a[i - 1] == b[j - 1]) cur[j] = prev[j - 1];          // free match
            else cur[j] = 1 + min({prev[j - 1],                      // replace
                                   prev[j],                          // delete a[i-1]
                                   cur[j - 1]});                     // insert b[j-1]
        }
        swap(prev, cur);
    }
    return prev[m];
}

static int minDistance(String a, String b) {
    int n = a.length(), m = b.length();
    int[] prev = new int[m + 1], cur = new int[m + 1];
    for (int j = 0; j <= m; j++) prev[j] = j;                 // "" -> b[0..j): j inserts
    for (int i = 1; i <= n; i++) {
        cur[0] = i;                                           // a[0..i) -> "": i deletes
        for (int j = 1; j <= m; j++) {
            if (a.charAt(i - 1) == b.charAt(j - 1)) cur[j] = prev[j - 1];
            else cur[j] = 1 + Math.min(prev[j - 1],           // replace
                              Math.min(prev[j],               // delete a[i-1]
                                       cur[j - 1]));          // insert b[j-1]
        }
        int[] t = prev; prev = cur; cur = t;
    }
    return prev[m];
}
def min_distance(a: str, b: str) -> int:
    """Edit distance with two rolling rows: O(n*m) time, O(m) memory."""
    m = len(b)
    prev = list(range(m + 1))            # "" -> b[:j]: j inserts
    for i in range(1, len(a) + 1):
        cur = [i] + [0] * m              # a[:i] -> "": i deletes
        for j in range(1, m + 1):
            if a[i - 1] == b[j - 1]:
                cur[j] = prev[j - 1]     # free match
            else:
                cur[j] = 1 + min(prev[j - 1],  # replace
                                 prev[j],      # delete a[i-1]
                                 cur[j - 1])   # insert b[j-1]
        prev = cur
    return prev[m]

From your world

The rolling-row trick is double buffering: you keep a "front" and a "back" row and swap pointers, like two DMA buffers that a driver flips between so one is filled while the other is read. Swapping the vectors is O(1); copying a row each time is a needless O(m).
