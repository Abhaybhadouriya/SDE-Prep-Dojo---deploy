The story: stairs and two diaries

Explain like I'm 5

A row of children stands in a line, each a different height. You may pick some of them, keeping their order, so that each child you pick is taller than the one before. You want to pick as many as you can. That is a staircase hidden in the line.

Now two friends each kept a diary of what they ate this week, in order. You want the longest list of meals that appear in both diaries in the same order. You cannot change the order, but you can skip meals in either diary.

The first puzzle is the longest increasing subsequence (LIS). The second is the longest common subsequence (LCS). A subsequence keeps the order but may skip items: from abcde you can take ace, but not eca. A substring (or subarray) may not skip anything. Mixing these two words up is the most common reason a DP answer goes wrong, so check which one the question means before you write anything.

Both puzzles have the DP feel: try every choice would be exponential (2n subsets), but the answer for a long input is built from answers for shorter pieces. For LIS the piece is "the best staircase that ends at child i". For two strings the piece is "the answer for the first i letters of one and the first j letters of the other". The rest of this page is just careful work on those two ideas. If DP itself is new, read the DP primer first.

From your world

You have used two-string DP already: diff and git diff compute a shortest edit script between two files, which is LCS on lines (Myers' algorithm is a faster way to walk the same grid). Edit distance is what a fuzzy command matcher uses when your shell says "did you mean ...". Patience sorting is also the name of a diff variant (git diff --patience), which uses exactly the LIS trick on this page to line up unique lines.
