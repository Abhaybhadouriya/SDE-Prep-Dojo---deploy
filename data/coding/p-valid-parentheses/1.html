The problem (in our words)

A config linter receives a string s made only of the six bracket characters ( ) [ ] { }. Decide whether the brackets are balanced:

  • every opening bracket is closed by a closing bracket of the same type;
  • brackets are closed in the correct order (the last one opened is the first one closed);
  • every closing bracket has a matching opening bracket before it.
  • Input: a string s.
  • Output: true if s is balanced, else false. Signature: bool isValid(string s).

Constraints

  • 1 <= s.length <= 10^4
  • s consists only of the characters '(', ')', '[', ']', '{', '}'.

Practice it: LeetCode 20 - Valid Parentheses · GfG - Parenthesis Checker · takeuforward

Constraints tell you: n ≤ 10^4 would even allow O(n²), but the one-pass stack is the expected answer. Only six characters exist, so you do not need to handle letters or spaces.
