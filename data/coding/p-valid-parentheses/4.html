Approaches: brute → better → optimal

Hint 1

When you see a closing bracket, which opening bracket must it match?

1. Brute force - delete adjacent pairs until nothing changes

Idea: a balanced string always contains an adjacent pair (), [] or {}. Delete such pairs repeatedly; the string is valid if it becomes empty.

O(n²)time (n/2 passes, each O(n))
O(n)space (string copies)

What is wasted: every pass re-reads the outer brackets that are still waiting. We only ever need the innermost open bracket: that is the top of a stack.

2. Optimal - stack of owed closers

for ch in s:                                   # core: 4 lines
    if ch in closer: stack.append(closer[ch])  # opener: push what we owe
    elif not stack or stack.pop() != ch: return False
return not stack
  1. The stack holds the unmatched openers, newest on top. We store the closer each one needs, so the check is a single equality.
  2. A closer must equal the top. If the stack is empty, nothing is open ("]"); if the top differs, the order is wrong ("[(])"). Either way: false at once.
  3. At the end the stack must be empty. Leftovers are openers that were never closed ("((").
O(n)time, one pass
O(n)space (all openers in the worst case)

Why it works: in a balanced string the bracket that closes next is always the most recently opened one that is still open. A stack is exactly "the most recent one still open". Each closer either matches that one (and both disappear, leaving a smaller balanced problem) or proves the string invalid.

Proof (optional)

Invariant: after reading a prefix p with no failure, the stack (bottom to top) lists the closers of the unmatched openers of p in opening order, and p with those openers removed is balanced. Reading an opener extends both. Reading a closer c: in any balanced completion, c must close the last unmatched opener, i.e. the top. So a mismatch or an empty stack means no completion exists (false), and a match keeps the invariant. At the end, s is balanced exactly when no opener is unmatched, i.e. the stack is empty.

Space trick worth mentioning: if the string has an odd length it can never be balanced, so if len(s) % 2: return False is a valid early exit (not needed for correctness).
