Common mistakes

Popping an empty stack. stack.pop() on "]" throws in Python and Java, and is undefined behaviour with std::stack::top() in C++. Test empty first.

Returning true at the end without checking the stack. "((" never fails a comparison, but it is not balanced.

Counting instead of stacking. Three counters (one per type) accept "[(])". Counts lose the order.

Using java.util.Stack in Java. It works, but it is synchronised and legacy; ArrayDeque is the idiomatic choice, and interviewers notice.
