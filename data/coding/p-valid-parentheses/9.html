Revision card

  • Cue: nested open/close pairs of several types → stack (one type: a counter).
  • Insight: last opened must close first; push the closer you owe, compare on close.
  • State: stack of expected closers.
  • Trap: empty stack on a closer, and a non-empty stack at the end, both mean false.
  • Cost: O(n) time, O(n) space; pair-deletion brute force O(n²).
stack = []
for x in items:
    if opens(x): stack.append(expected_close(x))
    elif not stack or stack.pop() != x: return False
return not stack
