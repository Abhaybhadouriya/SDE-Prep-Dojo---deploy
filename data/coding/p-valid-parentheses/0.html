The story

Explain like I'm 5

You put on a coat, then a scarf, then a hat. To take them off without a mess you remove the hat first, then the scarf, then the coat: the last thing on is the first thing off. A bracket string is a list of "put on" and "take off" actions. It is tidy only if every "take off" removes the thing you put on most recently, and at the end you are wearing nothing.

From your world

This is a call stack, or nested lock acquisition with strict LIFO release. Every push is a function entry, every closer is a return that must match the frame on top. A mismatch is a corrupted stack; leftovers at the end are frames that never returned.
