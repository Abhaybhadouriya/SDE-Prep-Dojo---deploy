Which pair of optimisations gives the O(α(n)) amortised bound?

  1. Path compression together with union by rank or size
  2. Path compression alone
  3. Storing every set as a sorted list
  4. Union by rank alone
Each one alone gives O(log n). Tarjan's nearly constant bound needs both.

In Redundant Connection, union(u, v) returns false for edge [u, v]. What does that mean?

  1. u and v are already connected, so this edge closes a cycle
  2. u and v are out of range
  3. The graph is disconnected
  4. The ranks of u and v are equal
A failed union means both ends already share a root; adding the edge creates a cycle, so it is redundant.

A new land cell in Number of Islands II touches the same existing island from two sides. How does the count change?

  1. +1, then -2
  2. +1 for the new cell, -1 for the first union, 0 for the second
  3. -1
  4. it stays the same only if the cell was already land
The second union finds both roots equal and returns false, so it does not decrement. Net change: 0, which is correct.

Why do you read size[find(x)] rather than size[x]?

  1. find also updates the sizes
  2. size[] is sorted
  3. sizes are only kept up to date at roots
  4. size[x] is always 1
Union adds the child root's size into the parent root's size; non-root entries go stale immediately.

Two records in Accounts Merge have the same name but no common email. What should happen?

  1. Drop the second record
  2. Merge them only if they have the same number of emails
  3. Keep them separate
  4. Merge them, names identify people
The problem says different people can share a name; only shared emails link records.

Which problem is NOT a good fit for union-find?

  1. Counting friend circles
  2. Kruskal's minimum spanning tree
  3. Smallest String With Swaps
  4. Course Schedule (can all courses be finished?)
Course Schedule needs directed cycle detection. DSU ignores edge direction, so use topological sort instead.
