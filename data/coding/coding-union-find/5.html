Accounts Merge: union by a shared key

The problem (restated). You receive a list of user records. Each record is a list of strings: the first is a person's name, the rest are email addresses. Two records belong to the same person if they share at least one email, and this is transitive. Two different people can have the same name. Merge the records and return one record per person: the name followed by that person's emails in sorted order. Records may be returned in any order. Limits: up to 1000 records, each with 1 to 9 emails of at most 30 characters. References: LeetCode 721, TUF: Disjoint Set Union.

The pattern here is merging by key. The vertices are the records; there is no edge list. Instead, keep a map owner[email] = first record index that had it. When a later record mentions the same email, union it with the owner. Transitivity comes for free: record 0 and record 2 never share an email directly, but both are unioned with record 1.

// 3. Accounts merge: union accounts that share an email, then group emails by root.
func accountsMerge(accounts [][]string) [][]string {
	d := NewDSU(len(accounts))
	owner := map[string]int{} // email -> first account that had it
	for i, acc := range accounts {
		for _, email := range acc[1:] {
			if j, ok := owner[email]; ok {
				d.Union(i, j)
			} else {
				owner[email] = i
			}
		}
	}
	groups := map[int][]string{}
	for email, i := range owner {
		r := d.Find(i)
		groups[r] = append(groups[r], email)
	}
	out := [][]string{}
	for r, emails := range groups {
		sort.Strings(emails)
		out = append(out, append([]string{accounts[r][0]}, emails...))
	}
	return out
}
// 3. Accounts merge: union accounts that share an email, then group emails by root.
vector<vector<string>> accountsMerge(const vector<vector<string>>& accounts) {
    DSU dsu(accounts.size());
    unordered_map<string, int> owner;                // email -> first account that had it
    for (int i = 0; i < (int)accounts.size(); i++)
        for (size_t j = 1; j < accounts[i].size(); j++) {
            auto it = owner.find(accounts[i][j]);
            if (it == owner.end()) owner[accounts[i][j]] = i;
            else dsu.unite(i, it->second);
        }
    unordered_map<int, vector<string>> groups;
    for (const auto& p : owner) groups[dsu.find(p.second)].push_back(p.first);
    vector<vector<string>> out;
    for (auto& g : groups) {
        sort(g.second.begin(), g.second.end());
        vector<string> row(1, accounts[g.first][0]);
        row.insert(row.end(), g.second.begin(), g.second.end());
        out.push_back(row);
    }
    return out;
}
// 3. Accounts merge: union accounts that share an email, then group emails by root.
static List<List<String>> accountsMerge(List<List<String>> accounts) {
    DSU dsu = new DSU(accounts.size());
    Map<String, Integer> owner = new HashMap<>(); // email -> first account that had it
    for (int i = 0; i < accounts.size(); i++)
        for (String email : accounts.get(i).subList(1, accounts.get(i).size())) {
            Integer j = owner.putIfAbsent(email, i);
            if (j != null) dsu.union(i, j);
        }
    Map<Integer, List<String>> groups = new HashMap<>();
    for (Map.Entry<String, Integer> e : owner.entrySet())
        groups.computeIfAbsent(dsu.find(e.getValue()), k -> new ArrayList<>()).add(e.getKey());
    List<List<String>> out = new ArrayList<>();
    for (Map.Entry<Integer, List<String>> g : groups.entrySet()) {
        Collections.sort(g.getValue());
        List<String> row = new ArrayList<>();
        row.add(accounts.get(g.getKey()).get(0));
        row.addAll(g.getValue());
        out.add(row);
    }
    return out;
}
# 3. Accounts merge: union accounts that share an email, then group emails by root.
def accounts_merge(accounts):
    dsu = DSU(len(accounts))
    owner = {}                         # email -> first account index that had it
    for i, acc in enumerate(accounts):
        for email in acc[1:]:
            if email in owner:
                dsu.union(i, owner[email])
            else:
                owner[email] = i
    groups = defaultdict(list)
    for email, i in owner.items():
        groups[dsu.find(i)].append(email)
    return [[accounts[r][0]] + sorted(emails) for r, emails in groups.items()]

Complexity. With E emails in total: O(E α(n)) for the unions plus O(E log E) to sort the emails inside the groups. The sorting dominates. A DFS over an email graph also works; DSU is shorter and avoids building adjacency lists of strings.

The same "union through a key" trick solves Most Stones Removed (union each stone's row with its column; answer = stones - components) and Smallest String With Swaps (union swappable indices, then sort the letters inside each group).
