Union-find or BFS / DFS?

Many connectivity problems can be solved either way. The deciding question is when the edges arrive.

SituationBest toolWhy
Static graph, count components onceeitherBFS / DFS is O(V + E); DSU is O(E α(V)). Pick whichever you write faster without bugs.
Edges arrive one by one; answer after eachDSUEach new edge is one union; re-running BFS each time is O(V + E) per edge.
"Does this edge close a cycle?" (undirected)DSUThe union fails exactly when both ends are already connected.
Items are linked through a shared key (email, row, column)DSUUnion each item with the first owner of the key; no explicit graph needed.
Need the actual path, or the shortest distanceBFSDSU forgets how things got connected.
Directed edges, ordering, directed cyclesDFS / topological sortDSU treats every edge as undirected.
Edges are deletedneither directlyDSU cannot split. Classic trick: process the timeline in reverse so deletions become additions.
