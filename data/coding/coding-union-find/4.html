Redundant Connection: the edge that closes the cycle

The problem (restated). A network started as a tree of n machines labelled 1 to n. Then one extra cable was added between two machines that were not directly connected. You receive all n cables as a list edges[i] = [a, b]. Return one cable whose removal leaves a tree on all n machines; if several cables qualify, return the one that appears last in the list. Limits: 3 ≤ n ≤ 1000, no repeated cables, the graph is connected. References: LeetCode 684, editorial.

Solution. Process cables in order and union their ends. The first cable whose two ends already share a root closes the only cycle. Why is that also the last qualifying cable in the input? Any cable on the cycle can be removed, and the cycle becomes closed only when its last cable (in input order) is processed; before that, the other cycle cables merged sets normally.

  1. Start: five vertices, each its own set (parent[v] = v). Edges arrive in input order; dashed lines are edges not processed yet.
  2. Edge 1-2: find(1) = 1 and find(2) = 2 differ, so union them. Ranks are equal, so 2 goes under 1 and rank[1] becomes 1.
  3. Edge 2-3: find(2) = 1 and find(3) = 3 differ. 3 (rank 0) goes under 1 (rank 1).
  4. Edge 3-4: find(3) = 1 and find(4) = 4 differ. 4 goes under 1. Vertices 1 to 4 are now one set, connected by a tree.
  5. Edge 1-4: find(1) = 1 and find(4) = 1. Both ends are already connected, so this edge closes a cycle: it is the answer [1, 4]. Edge 1-5 is never needed.
// 2. Redundant connection: the first edge that joins two already-connected vertices.
func findRedundantConnection(edges [][]int) []int {
	d := NewDSU(len(edges) + 1) // vertices are 1..n, n edges
	for _, e := range edges {
		if !d.Union(e[0], e[1]) {
			return e
		}
	}
	return nil
}
// 2. Redundant connection: the first edge that joins two already-connected vertices.
vector<int> findRedundantConnection(const vector<vector<int>>& edges) {
    DSU dsu(edges.size() + 1);                       // vertices are 1..n, n edges
    for (const auto& e : edges)
        if (!dsu.unite(e[0], e[1])) return e;
    return {};
}
// 2. Redundant connection: the first edge that joins two already-connected vertices.
static int[] findRedundantConnection(int[][] edges) {
    DSU dsu = new DSU(edges.length + 1);          // vertices are 1..n, n edges
    for (int[] e : edges)
        if (!dsu.union(e[0], e[1])) return e;
    return new int[0];
}
# 2. Redundant connection: the first edge that joins two already-connected vertices.
def find_redundant_connection(edges):
    dsu = DSU(len(edges) + 1)          # vertices are 1..n and there are n edges
    for u, v in edges:
        if not dsu.union(u, v):
            return [u, v]
    return []

Two cousins use the same "union fails" signal. Graph Valid Tree: n vertices form a tree iff there are exactly n - 1 edges and no union fails. Number of Operations to Make Network Connected: every failed union is a spare cable; you need (components - 1) of them, so the answer is count - 1 if edges ≥ n - 1, else -1. The directed version, Redundant Connection II, adds the "a vertex has two parents" case and is a well-known Hard.
