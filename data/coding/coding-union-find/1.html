A forest in an array

Each set is stored as a tree whose edges point upward, from child to parent. The root is the set's representative and is its own parent. The whole forest fits in one integer array, parent[]:

The naive operations are three lines each:

parent = list(range(n))          # everyone starts alone

def find(x):
    while parent[x] != x:        # climb to the root
        x = parent[x]
    return x

def union(a, b):
    parent[find(a)] = find(b)    # hang one root under the other

This is correct but can be slow. If unions happen to build a long chain (union(1, 0), union(2, 1), union(3, 2)...), the tree becomes a linked list and every find costs O(n). Two small changes fix this, and both are expected in an interview.
