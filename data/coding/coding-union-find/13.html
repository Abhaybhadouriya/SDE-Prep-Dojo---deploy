Revision card

  • Cue: Groups that merge over time, "connected?", redundant edge, accounts merge, islands added online.
  • Insight: Each group is a tree; two elements are together exactly when their roots match.
  • State: parent[] with path compression + rank or size; components = n - successful unions.
  • Trap: Linking non-roots; comparing parent[] instead of find(); reading size at a non-root.
  • Cost: O(α(n)) amortised per operation, O(n) space.

More to remember

  • DSU answers "same group?" while groups merge. It cannot split, list members fast, or give paths.
  • Path compression + union by rank or size = O(α(n)) amortised. One alone = O(log n).
  • Always link roots; always compare find results; read sizes at roots only.
  • union returning false = this edge closes a cycle. Components = n - successful unions.
  • Merge by key: map each key to its first owner and union later owners with it.
  • Online additions (Number of Islands II): +1 per new cell, -1 per successful union.
  • Large Island: precompute sizes, then sum distinct neighbouring roots.
