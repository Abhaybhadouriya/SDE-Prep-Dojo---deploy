Common mistakes

  • Comparing parent[a] == parent[b] instead of find(a) == find(b). Parents are not roots until compressed.
  • Setting parent[a] = b instead of linking the roots, parent[find(a)] = find(b). The first silently splits a's old tree.
  • Reading size[x] at a non-root. Sizes are only maintained at roots: use size[find(x)].
  • Off-by-one on 1-indexed vertices (Redundant Connection): allocate n + 1 slots.
  • Double counting the same neighbouring island in Making a Large Island. Collect distinct roots first.
  • Re-adding a repeated position in Number of Islands II, which inflates the count.
  • Merging accounts by name. Names are not unique; only shared emails link records.
  • Recursive find on a long chain in Python before any compression: hits the recursion limit. Use the iterative version.
  • Using DSU for directed problems. It ignores direction; use topological sort or DFS.
