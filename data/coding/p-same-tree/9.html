  • Base: both null -> true; one null -> false; values differ -> false.
  • Step: same(p.left, q.left) AND same(p.right, q.right); short-circuit.
  • Trap: null checks before .val; traversal lists need null markers.
  • Cost: O(n) time, O(h) stack; BFS over pairs if depth is a worry.
