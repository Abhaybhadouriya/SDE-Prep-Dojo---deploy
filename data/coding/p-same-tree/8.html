Common mistakes

Reading .val before the null checks. Crashes on [5] vs []. Handle "both null" and "one null" first.

Comparing traversals without null markers. In-order or pre-order lists alone do not fix the shape; [4,7] and [4,null,7] have the same pre-order 4,7.

Comparing node references. p == q on two non-null nodes from different trees is always false. Compare values, then recurse.

Using if not p.val in Python. A node with value 0 looks "empty". Test p is None.
