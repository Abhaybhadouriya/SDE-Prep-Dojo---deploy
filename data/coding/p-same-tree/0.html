The story

Explain like I'm 5

Two kids built family trees out of cards on two tables and want to know if they built exactly the same thing. They stand at the top cards, check that the names match, then both step to their left card and check, then both step to the right. If one kid has a card where the other has an empty spot, or the names differ, the trees are different and they can stop right there.

Two trees are the same only if they have the same shape and the same values in the same places. Having the same values, or even the same in-order listing, is not enough.

From your world

It is a structural diff of two nested configs (two parsed JSON or device-tree blobs): recurse into matching keys, report the first mismatch. A Merkle tree speeds this up for huge trees by comparing hashes of subtrees first, which is exactly the "hash every subtree" follow-up below.
