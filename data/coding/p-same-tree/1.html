The problem (in our words)

You get the roots p and q of two binary trees. Return true if the two trees are identical: they have the same structure and every pair of nodes in the same position holds the same value. Otherwise return false.

Signature: boolean isSameTree(TreeNode p, TreeNode q). Trees are given in LeetCode level order, for example [4,7,null,2]; either tree may be empty ([]).

Constraints

  • The number of nodes in each tree is in [0, 100].
  • -104 <= Node.val <= 104.

Practice it: LeetCode 100 · GfG Identical Trees · TUF Check if two trees are identical

Constraints tell you: at most 100 nodes, so anything works; the interviewer is checking that you handle the null cases cleanly and know the time and space in terms of n and h. Either tree can be empty, so the null checks must come before any .val.
