Recognise the pattern

When you see "count subarrays with exactly k of something" and the "at most k" version is monotonic (a bigger window never has less of it), think exactly(k) = atMost(k) - atMost(k - 1), each a counting window that adds right - left + 1. If values can be negative, the window fails: use the prefix-sum count map instead.
