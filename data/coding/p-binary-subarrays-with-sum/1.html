The problem (in our words)

You are given an array nums in which every element is 0 or 1, and an integer goal. Return the number of non-empty contiguous subarrays whose elements add up to exactly goal. Subarrays at different positions count separately even if their values match.

Signature: int numSubarraysWithSum(vector<int>& nums, int goal).

Constraints:

  • 1 <= nums.length <= 3 * 104
  • nums[i] is either 0 or 1
  • 0 <= goal <= nums.length

Practice it: LeetCode 930 · TUF: binary subarrays with sum

Constraints tell you: n = 3·104 makes O(n2) about 4.5·108 pair checks: too slow outside C++, and not what the interviewer wants. goal can be 0, which is the case that breaks naive windows (many all-zero subarrays). The answer is at most n(n+1)/2 ≈ 4.5·108, so it fits in int32.
