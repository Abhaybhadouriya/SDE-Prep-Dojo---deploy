Common mistakes

Dropping digits. Using isalpha (letters only) makes "0P" look like "p", a palindrome. The rule is letters and digits.

Moving both pointers on a skip. When s[l] is punctuation, only l moves; moving r too skips a real character on the right.

Inner skip loops without a bound. while (!isalnum(s[l])) l++; runs off the end of ".,;". Keep l < r in every inner loop, or use the single-loop form shown here.

Using \w in a regex filter. \w keeps the underscore, so "a_b"-style inputs go wrong. Use [^A-Za-z0-9].

Calling isalnum(char) on a signed char in C++. Bytes above 127 are negative and the call is undefined behaviour; cast to unsigned char.
