Revision card

  • Cue: "same forwards and backwards", ignore some chars → two pointers from both ends.
  • Insight: skip non-alphanumerics one side at a time; compare lower-cased pairs.
  • State: l = 0, r = n - 1; loop while l < r.
  • Trap: digits count ("0P" is false); move only the skipping pointer; keep l < r.
  • Cost: O(n) time, O(1) space; clean copy + reverse is O(n) space.
l, r = 0, len(s) - 1
while l < r:
    if skip(s[l]): l += 1
    elif skip(s[r]): r -= 1
    elif norm(s[l]) != norm(s[r]): return False
    else: l += 1; r -= 1
return True
