The problem (in our words)

A sign-maker wants to know whether a slogan s reads the same in both directions. First turn every upper-case letter into lower case and throw away every character that is not a letter or a digit. If what remains reads the same forwards and backwards, the slogan is a palindrome. Return true if it is, false otherwise.

  • Input: a string s.
  • Output: a boolean. Signature: boolean isPalindrome(String s).
  • Letters and digits both count ("alphanumeric"); an empty result after filtering counts as a palindrome.

Constraints

  • 1 <= s.length <= 2 * 10^5
  • s consists only of printable ASCII characters.

Practice it: LeetCode 125 - Valid Palindrome · GfG - Palindrome String · takeuforward

Constraints tell you: 2 × 10^5 characters means a single O(n) pass. Printable ASCII means the standard isalnum / tolower are enough, and a byte is a character (no Unicode handling). The string is never empty, but it can be all punctuation.
