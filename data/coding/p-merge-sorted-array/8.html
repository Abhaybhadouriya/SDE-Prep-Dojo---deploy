Common mistakes

Looping while i >= 0 && j >= 0 and forgetting the leftovers. If nums1 runs out first (e.g. [7, 8, 9] with [1, 2, 3]), the values 1, 2, 3 are never copied. Either loop on j >= 0 only, as above, or add a tail loop for nums2. (Leftover nums1 values never need copying.)

Merging from the front in place. Writing the smaller value at index 0, 1, ... overwrites nums1 values that are not read yet.

Treating the placeholder zeros as data. With m = 0, nums1 = [0, 0] has no real values. Use m, never nums1.length, for the read head.

Returning a new array. The judge reads nums1. In Python, nums1 = sorted(...) rebinds the local name and leaves the caller's list unchanged; use nums1[:] = ... if you go that way.
