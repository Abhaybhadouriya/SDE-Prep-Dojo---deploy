Common mistakes

Adding at null instead of at the leaf. Returning prefix when node == null counts every leaf twice (once per null child) and counts one-child nodes as numbers: [1,0] gives 1 + 10 + 10 = 21.

Building the number backwards. cur = digit * 10^depth + prefix reads the path leaf-first; the root is the most significant digit.

A shared global cur without undo. If cur is a field, you must divide it back after visiting children; passing it as a parameter avoids the bug entirely.

Treating a one-child node as a leaf. The leaf test is "both children null", not "one of them is null".
