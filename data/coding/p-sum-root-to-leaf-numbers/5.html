Example 2, [3,8,0,6,2]. The thick edges are the current root-to-node path.

  1. Start at the root with prefix 0. cur = 0 * 10 + 3 = 3. The root has children, so it ends no number yet: pass 3 down to both children.
  2. Go left to 8 with prefix 3. Multiplying by 10 shifts the digits already on the path one place left, then the new digit fills the ones place: 38.
  3. 6 with prefix 38: cur = 386. 6 has no children: it is a leaf, so 386 is one finished number. total = 386.
  4. Back at 8 (its prefix 38 is still on its own stack frame, nothing to undo). Its right child 2: cur = 382, a leaf. total = 386 + 382 = 768.
  5. Back at the root, go right to 0 with prefix 3: cur = 30. A 0 digit still shifts the place value. 0 is a leaf: total = 768 + 30 = 798.
