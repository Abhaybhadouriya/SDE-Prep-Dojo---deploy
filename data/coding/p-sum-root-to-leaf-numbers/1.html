The problem (in our words)

You are given the root of a binary tree in which every node holds a single digit from 0 to 9. Every path from the root down to a leaf spells a number: reading the digits from the root to the leaf gives its decimal digits, most significant first (path 4 -> 9 -> 5 is the number 495). A leaf is a node with no children.

Return the sum of the numbers of all root-to-leaf paths. The answer is guaranteed to fit in a 32-bit integer.

Signature: int sumNumbers(TreeNode root). The tree is given in level-order form, e.g. [3,8,0,6,2].

  • The number of nodes is in the range [1, 1000].
  • 0 <= Node.val <= 9
  • The depth of the tree does not exceed 10.

Practice it: LeetCode 129 · GfG Root to Leaf Paths Sum

Constraints tell you: depth at most 10 means each number has at most 10 digits and recursion depth is tiny; the 32-bit guarantee means plain int is enough (still, mention that a deeper tree would need 64 bits or a modulus). 1000 nodes: any O(n) walk.
