Recognise the pattern

Cue: "every root-to-leaf path" + "a value that depends on the whole path" -> top-down DFS that passes the path's running state as an argument and does the real work at the leaves. Here the state is one integer; in Path Sum it is the remaining target; in Path Sum II it is the path list.
