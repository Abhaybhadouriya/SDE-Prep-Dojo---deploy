Common mistakes

Off-by-one rows. Returning numRows + 1 rows, or treating row numbers as 1-based in the formula. Row i has i + 1 entries.

Python aliasing. [[1] * k] * n or appending the same list object to the result and then mutating it: every row changes together. Create a new list per row.

Integer division too early in the multiplicative formula: prev * ((i - j + 1) / j) truncates. Multiply first, then divide.

Reading tri[i-1] for i = 0 (index -1 is the last row in Python, an exception elsewhere). Guard the inner loop with j in 1..i-1.
