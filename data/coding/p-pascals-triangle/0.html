The story

Explain like I'm 5

Stack bricks in a pyramid. The bricks on the edges get the number 1. Every other brick gets the sum of the two bricks it rests on. Build the pyramid one layer at a time from the top.

The problem itself is a warm-up for 2D arrays and a first taste of DP (each row depends only on the previous one). The interview value is in the follow-ups: one row in O(k) space, a single C(n, r) without overflow, and C(n, r) mod p - all of which reuse the same table or its formula.

From your world

Row i counts the ways to choose j set bits out of i: C(i, j) is the number of i-bit masks with popcount j. The 2i total of a row is the number of i-bit masks.
