Recognise the pattern

Cue: "each value is the sum of the values above it" or "C(n, r) for many n, r" -> build rows with the recurrence; "C(n, r) for one pair" -> the multiplicative formula; "C(n, r) mod p, many queries" -> factorials and inverse factorials.

The recurrence C(i, j) = C(i-1, j-1) + C(i-1, j) is the same one behind counting grid paths (Unique Paths) and many "choose or skip" DPs.
