60-second recall

  • Cue: row-by-row values that depend on the row above -> build each row from the previous one.
  • Rule: ends are 1; inner = up-left + up.
  • Math: entry (i, j) = C(i, j); row i sums to 2i.
  • One row: C(i, j) = C(i, j-1)·(i-j+1)/j, multiply first, 64-bit.
  • One row in place: update j from right to left: row[j] += row[j-1].
  • Cost: O(n²) = output size; int is enough up to 30 rows.
for i in range(n):
    row = [1] * (i + 1)
    for j in range(1, i): row[j] = tri[-1][j-1] + tri[-1][j]
    tri.append(row)
