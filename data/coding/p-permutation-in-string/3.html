Recognise the pattern

When you see "permutation / anagram / rearrangement of p inside s", think a fixed window of length len(p) and a letter-count array, not generating permutations.

When you see "is the window equal to a target multiset?", think one diff array (target minus window) plus a counter of zero entries, so equality is a single integer compare.

Two facts make this a fixed window. First, order does not matter, so a substring is fully described by its 26 counts. Second, any match has length exactly len(s1), so only n2 - n1 + 1 windows exist, and neighbouring windows differ by one letter in and one letter out.

Pattern: Sliding window > fixed-size window > fixed window frequency match · Lessons: Fixed sliding window, Fixed window frequency match, Counting with arrays
