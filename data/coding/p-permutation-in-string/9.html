  • Cue: "permutation / anagram of s1 inside s2": order is irrelevant, length is fixed.
  • Insight: fixed window of len(s1); a window matches iff all 26 counts agree.
  • State: diff[c] = count_s1 - count_window; matched = number of zero entries.
  • Trap: s1 longer than s2; check the first and the last window; counts, not sets.
  • Cost: O(n1 + n2) time, O(26) space (O(26 · n2) with a plain array compare).
for i, ch in enumerate(s2):
    add(ch)                          # enters on the right
    if i >= m: remove(s2[i - m])     # leaves on the left
    if i >= m - 1 and matched == 26: return True

When does an update change matched?

  1. Whenever the letter is in s1
  2. When diff[c] was 0 before, or is 0 after the change
  3. Only when the window is full
matched counts zero entries; a +1 or -1 can only move an entry onto or off 0.

The same letter enters and leaves in one slide. What happens?

  1. Nothing changes overall
  2. matched drops by 2
  3. It needs a special case
The -1 and +1 cancel; matched may dip and recover inside the two updates.

How many windows does s2 have?

  1. n2
  2. n2 - n1
  3. n2 - n1 + 1
Starts 0 .. n2 - n1 inclusive.
