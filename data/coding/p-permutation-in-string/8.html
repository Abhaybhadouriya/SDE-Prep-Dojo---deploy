Common mistakes

Checking letters with a set. "Every letter of s1 is in the window" ignores multiplicity. Use counts.

Using a variable window. Growing and shrinking like Minimum Window Substring works but is harder to get right. The length is fixed at n1; a fixed window is simpler.

Updating matched with the wrong condition. matched changes only when an entry moves onto 0 or off 0. Incrementing it whenever a "needed" letter enters double counts letters that are already satisfied.

Off-by-one on the last window. There are n2 - n1 + 1 windows. Either check after every slide including the last, or loop the start from 0 to n2 - n1 inclusive.

Comparing with the wrong string's length. The window length is len(s1); the loop bound is len(s2). Swapping them is a common slip under pressure.
