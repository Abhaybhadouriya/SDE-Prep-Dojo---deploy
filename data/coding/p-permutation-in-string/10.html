Technique: a fixed window whose state is a frequency table, compared with a target table in O(1) via a matched counter.

Closest match: CF 144C Anagram Search CF 1500

  • Same: slide a window of len(p) over s and test "is it an anagram of p?".
  • Different: s may contain '?' that can become any letter, and you count the good windows.
  • So: ignore '?' in the counts; a window is good when no letter count exceeds p's (the '?' fill the rest).

How to recognise it:

  • "Permutation", "anagram", "rearrangement", "same letters" + "substring / contiguous".
  • The match has a known length (len of the pattern), so the window size is fixed.

Practice order:

  1. Warm-up: LC 242 (one count compare), LC 643 (fixed window sum).
  2. This problem: sliding counts with a 26-slot compare, then the matched counter.
  3. Then LC 438 (all starts), CF 144C (wildcards) and LC 30 (words).
