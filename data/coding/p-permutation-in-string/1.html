The problem (in our words)

You are given two lowercase strings, a short s1 (a "pattern") and a longer s2 (a "text"). Return true if some contiguous piece (substring) of s2 is a rearrangement (permutation) of s1, and false otherwise.

A rearrangement uses every letter of s1 exactly as many times as it appears in s1, in any order. So the piece of s2 must have length len(s1) and the same count of every letter.

Signature: boolean checkInclusion(String s1, String s2).

Constraints

  • 1 <= s1.length, s2.length <= 10^4
  • s1 and s2 contain only lowercase English letters.
  • s1 may be longer than s2 (then the answer is false).

Practice it: LeetCode 567 - Permutation in String · GfG - Count Occurrences of Anagrams (count the windows instead of asking if one exists)

Constraints tell you: lengths up to 10^4 make O(n1 · n2) about 10^8 letter operations, too slow in Python and borderline elsewhere. The alphabet is 26 letters, so the "state" of a window is a 26-slot array, and comparing two such arrays is constant work. That points to a fixed window with counts, O(26 · n2) or O(n2).
