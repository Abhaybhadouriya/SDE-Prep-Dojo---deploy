The problem (in our words)

You get the heads of two singly linked lists, list1 and list2. Each list is sorted in non-decreasing order (equal values may repeat). Build one sorted list by splicing together the existing nodes of the two lists, and return its head. Either list may be empty; if both are, return null.

Signature: ListNode mergeTwoLists(ListNode list1, ListNode list2), where ListNode has an integer val and a next pointer.

Constraints

  • Each list has between 0 and 50 nodes.
  • -100 <= Node.val <= 100
  • Both list1 and list2 are sorted in non-decreasing order.

Practice it: LeetCode 21 - Merge Two Sorted Lists · GfG - Merge two sorted linked lists · TUF - Merge two sorted linked lists

Constraints tell you: at most 100 nodes in total, so any approach passes; the interview is about clean pointer handling. "Splice the existing nodes" means the expected answer moves next pointers and does not allocate (O(1) extra space). Empty lists are allowed, so null inputs must work.
