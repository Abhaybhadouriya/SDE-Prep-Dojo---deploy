Common mistakes

Forgetting the leftover. Ending with while a and b and returning drops the tail of the longer list. One line fixes it: tail.next = a or b.

Looping over the leftover node by node. It works but is wasted code; the rest is already a sorted chain.

Not moving tail. Writing tail.next = a without tail = tail.next overwrites the same link every step, and the answer has one node.

Returning dummy instead of dummy.next. The answer then starts with a 0 that was never in the input.

C++: allocating the dummy with new and leaking it. Use a stack ListNode dummy; and return dummy.next.
