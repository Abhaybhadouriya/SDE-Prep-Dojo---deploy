In the Dojo mock format, by which minute should problem 1 be coded and tested?

  1. 12
  2. 18
  3. 22
  4. 32
Minute 22 is the second checkpoint: P1 closed and tested. Minute 12 is "coding started", minute 32 is "P2 half-coded".

It is minute 12 and you still have no idea better than brute force for problem 1. What does the format say to do?

  1. Keep thinking until the optimal idea comes
  2. Code the brute force now and mention the better idea as the next step
  3. Skip to problem 2
A working baseline is always worth something, and coding it often reveals the bottleneck that leads to the better idea.

An SDE-2 mock scores communication 3, problem solving 3, code 3, testing 2, with both problems solved. What is the verdict under the page's bar?

  1. No hire: testing is below 3
  2. Hire: all signals are at least 2
  3. Lean no hire: the total is 11, one short of 12
Floor (2) and solved count (2) are met; only the total misses. One miss = lean no hire. The fix is the testing routine.

For an SDE-2 candidate, why does the picker require problem 2 to come from a different pattern group than problem 1?

  1. So one mock tests two patterns and recognition, not one pattern twice
  2. Different groups are always harder
  3. The company list has no two problems in one group
Recognising which pattern applies is a large part of the round. Two problems from one group test it only once.

Which problems belong in the "seen" set that the picker skips?

  1. Only problems you solved without help
  2. Every problem you have ever attempted
  3. Anything you solved or read a solution for in the last 14 days
Recent problems test recall. Older ones are fair game: if you cannot re-solve them cold, that is useful information too.

You fail a mock because you did not recognise a graph problem. Which debrief bin and fix fit best?

  1. Execution: practise the dry-run table
  2. Process: obey the checkpoints
  3. Technique: re-type the BFS template
  4. Recognition: rewrite the card's Trigger line and add more problems of that pattern
Not seeing the pattern is a recognition gap. The Trigger line records the words in the statement that should have pointed to it.

What is the best use of D-2, two days before the interview?

  1. Nothing at all
  2. Reading revision cards without timed re-solving
  3. Learning one new topic you skipped
  4. A last full mock on Hard problems
Reading cards is a light recognition drill that protects confidence. The last full mock is D-3; new topics are out after that.
