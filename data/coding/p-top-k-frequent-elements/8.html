Common mistakes

n buckets instead of n + 1. A value that fills the whole array has count n; bucket[n] is out of range if you allocate only n lists.

Max-heap of everything, then "pop k". Correct, but it stores all u items and is O(u log u) if you push one by one. Say "min-heap capped at k" or use heapify.

Indexing buckets by value instead of by count. The array index must be the count; values can be negative and would crash an array index.

Taking a whole bucket and returning more than k values. Stop as soon as the result has k items (the guarantee makes the cut point safe), or slice the result.
