The problem (in our words)

You get a string s. Return true if s can be made a palindrome by deleting at most one character (deleting none is allowed), and false otherwise. A palindrome reads the same forwards and backwards.

Signature: boolean validPalindrome(String s).

  • 1 <= s.length <= 10^5
  • s consists of lowercase English letters.

Practice it: LeetCode 680 · warm-up first: Valid Palindrome (LC 125)

Constraints tell you: n up to 100,000, so trying every deletion and re-checking (O(n²) = 1010) is too slow; O(n) is the target. Only lowercase letters: unlike LC 125 there is no case folding and no skipping of punctuation.
