Dry run

Example 2, "racecxar". Green = matched pair, red = mismatch, the grey veil = the character we are trying to delete.

  1. Outer pointers: s[0] = 'r', s[7] = 'r'. Equal, so this pair can stay. Move both inward.
  2. 'a' = 'a'. Still no deletion spent. Every matched pair is a pair we will never need to re-check.
  3. First mismatch: 'c' vs 'x'. The outer part already matches, so the one deletion MUST be s[2] or s[5]; nothing else can fix this pair. Try both.
  4. Option 1: delete the left char. Check s[3..5] = "ecx" as a plain palindrome: 'e' vs 'x' fails at once. No second deletion is allowed.
  5. Option 2: delete the right char. s[2..4] = "cec": 'c' = 'c', then the pointers meet at 'e'. A palindrome, so return true. Total work: one pass plus at most two short checks, O(n).
