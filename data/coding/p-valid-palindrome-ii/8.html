Common mistakes

Trying only one side. Skipping just lo (or just hi) passes most tests and fails "cuucu"-style inputs. Always try both.

Choosing the side by peeking one character. "If s[lo+1] == s[hi] skip left, else skip right" is wrong when both peeks match but only one branch works further in. Check both branches fully.

Allowing a second deletion inside the branch. Calling the main function recursively in the branches allows unlimited deletions and turns it into exponential time. The branch check must be strict.

Building substrings in a loop. s.substring + reverse per candidate is O(n) memory each time; in the brute force it makes O(n²) memory traffic.

Copying LC 125's filtering. This problem has only lowercase letters; adding isalnum skips or lower-casing is harmless but signals you did not read the constraints.
