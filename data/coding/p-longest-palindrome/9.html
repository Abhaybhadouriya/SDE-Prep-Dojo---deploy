  • Cue: palindrome + "built from / rearrange the letters" -> only count parities matter.
  • Insight: palindrome = mirrored pairs + at most one centre letter.
  • State: int count[128]; length = sum of c / 2 * 2.
  • Trap: +1 only if length < n, and only once; case-sensitive letters.
  • Cost: O(n) time, O(1) space; formula n - odd + (odd > 0).
count = Counter(s)
odd = sum(c & 1 for c in count.values())
return len(s) - odd + (1 if odd else 0)

Quick quiz

A letter appears 7 times. How many of its copies can always be used (not counting the middle)?

  1. 7
  2. 6
  3. 0
  4. 1
7 / 2 * 2 = 6: three mirrored pairs. The seventh copy is a leftover that may become the middle.

Counts are a:3, b:5, c:1. What is the answer?

  1. 9
  2. 6
  3. 7
  4. 8
Pairs give 2 + 4 + 0 = 6. Three letters have odd counts, but only one can be the middle: 6 + 1 = 7 (= 9 - 3 + 1).

Why can the answer never be 0?

  1. s has at least one letter, and one letter alone is a palindrome
  2. because of case sensitivity
  3. every string has a pair
  4. it can be 0
The constraints say length >= 1, and any single letter reads the same both ways.
