Common mistakes

Dropping odd counts entirely. Adding only the even counts gives 0 + 1 = 1 for "aaabbbc" (every count there is odd) instead of 5. An odd count c still gives c - 1 letters.

Adding the middle once per odd letter. Only one letter can sit in the centre; add +1 at most once.

Always adding 1. "aaaa" has no leftover, so the answer is 4, not 5. Add 1 only when the pairs did not use every letter.

Indexing a 26-slot array with c - 'a' on uppercase input gives a negative index ('A' - 'a' = -32). Use 128 slots indexed by the character, or 52 slots with separate offsets.

Solving the wrong problem. Expanding around centres finds the longest palindromic substring; here the letters may be reordered.
