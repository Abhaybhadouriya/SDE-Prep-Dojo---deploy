Approaches: brute -> better -> optimal

Hint 1

In a palindrome, how many times can a letter appear if it is not the middle letter?

Hint 2

A letter that appears 5 times: how many of those 5 can you always use?

1. Brute force - try every subset of tiles

Idea: for every subset of positions, check whether those letters can be arranged into a palindrome (at most one letter with an odd count) and keep the largest size. Correct by definition, and our test files use it as the reference on short strings.

O(2n · n)time
O(1)counts per subset

What is wasted: the check only looks at counts, so subsets with the same counts are tested again and again. Deciding letter by letter is enough.

2. Better - sort, then measure runs

Idea: sort the string so equal letters sit together, measure each run length c, add c / 2 * 2, and remember whether any run was odd.

O(n log n)time
O(n)sorted copy

What is wasted: sorting just to count. With 52 possible letters, a counter table gives the same runs in one pass.

3. Optimal - count, take all pairs, add one middle

count = Counter(s)
length = sum(c // 2 * 2 for c in count.values())
if length < len(s):
    length += 1          # some letter was left over: it takes the middle
return length
  1. Count. One pass fills a 128-slot table (ASCII), so 'A' and 'a' land in different slots.
  2. Pairs. Each letter contributes its largest even part: 4 -> 4, 5 -> 4, 1 -> 0.
  3. Middle. If the pairs used fewer than n letters, at least one letter had an odd count; one of its spares becomes the centre (+1).
O(n)time (one pass + 128 slots)
O(1)128 ints

Why it works (upper bound + construction): in any palindrome, the letters left of the centre mirror the letters right of it, so every letter appears an even number of times except possibly the single centre letter. Hence a letter with count c contributes at most c if even, c - 1 if odd, and at most one letter can add the extra 1. Our sum reaches exactly that bound, and it is achievable: write one letter of each pair on the left half, its mirror on the right half, and one leftover in the middle.

One-pass variants (from the editorial and the top-voted answers): keep a set of letters seen an odd number of times; on each letter, remove it if present (a pair is complete, +2) or add it. At the end, answer = pairs·2 + (set non-empty). The same idea with arithmetic: n - odd + (odd > 0), where odd = number of odd counts. The parity mask in the story is this set packed into 64 bits.
