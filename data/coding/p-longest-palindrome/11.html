Interview follow-ups

Return one longest palindrome, not just its length.

Build the left half: for each letter, append c / 2 copies. Pick any letter with an odd count as the middle (or none). The answer is left + middle + reverse(left). O(n) time, O(n) output. Iterating letters in sorted order makes the result the lexicographically smallest of the longest ones.

How to answer

Reuse the counts; the construction is the proof that the bound is reachable.

Likely follow-ups
  • Largest instead of smallest: iterate from 'z' down (LC 2384 adds the leading-zero rule).
Can you do it in one pass with no second loop over the table?

Yes. Keep odd = number of letters with an odd count so far: on each letter, after incrementing its count, do odd += 1 if the new count is odd, else odd -= 1. At the end, return n - odd + (odd > 0). Or keep a 64-bit mask and XOR one bit per letter; odd = popcount(mask).

How to answer

Point out that only the parity of each count matters, so one bit per letter is enough.

Likely follow-ups
  • Which form handles a stream of letters with O(1) per update? (All of them; the mask is the smallest.)
Many queries: the longest palindrome you can build from the letters of s[l..r].

Precompute prefix parity masks: P[i+1] = P[i] ^ bit(s[i]). The parity mask of s[l..r] is P[r+1] ^ P[l], so odd = popcount(P[r+1] ^ P[l]) and the answer is len - odd + (odd > 0). O(n) preprocessing, O(1) per query.

How to answer

Parities are XOR-able, so prefix XOR works the way prefix sums do.

Likely follow-ups
  • With up to k letter changes allowed per query: that is LC 1177 (fix odd / 2 letters).
The input can hold any Unicode characters.

Use a hash map from code point to count, or a hash set of "currently odd" characters (add on first sight, remove on the second). The formula is unchanged. Normalise first if "é" may be stored as one or two code points.

How to answer

The algorithm only needs parities; the container changes, nothing else.

Likely follow-ups
  • Case-insensitive: fold case before counting (then "Aa" gives 2).
Minimum number of letters to remove so that all remaining letters form a palindrome.

It is n - answer = max(0, odd - 1): every odd-count letter except one must lose one copy. If you may change letters instead of removing them, each change fixes two odd letters, so odd / 2 changes.

How to answer

Express the loss in terms of odd, then adjust for the operation type.

Likely follow-ups
  • Then output the smallest such palindrome (CF 600C).
