The story

Explain like I'm 5

You are lining up toy blocks so the row looks the same from both ends. Every block on the left needs a twin of the same colour on the right. So you sort the blocks by colour and take them two at a time. Lonely blocks with no twin cannot be used, except one: a single lonely block can stand in the very middle, because the middle is its own mirror.

The task says "built from those letters", so we may reorder them freely. That is the key reading: this is not Longest Palindromic Substring. Positions do not matter; only how many of each letter we have.

From your world

The parity of each count is all that decides the loss. Keep a 64-bit mask with one bit per letter and XOR the bit on every occurrence (like toggling a register flag): at the end, popcount(mask) is the number of letters with an odd count, and the answer is n - odd + (odd > 0). 52 letters fit in one uint64_t.
