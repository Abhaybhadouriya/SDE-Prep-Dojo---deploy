The problem (in our words)

A log collector receives k feeds. Each feed is a singly linked list of records, and the values (timestamps) in every feed are in ascending (non-decreasing) order. You are given the feeds as an array lists of list heads; a head may be null when a feed is empty.

Join all the nodes into one singly linked list whose values are in ascending order, and return its head. Return null (an empty list) when there are no nodes at all.

Signature: ListNode mergeKLists(ListNode[] lists), where ListNode has an integer val and a next pointer.

Constraints

  • k == lists.length and 0 <= k <= 10^4
  • 0 <= lists[i].length <= 500
  • -10^4 <= lists[i][j] <= 10^4
  • Every lists[i] is sorted in ascending order.
  • The total number of nodes over all lists is at most 10^4.

Practice it: LeetCode 23 - Merge k Sorted Lists · GfG - Merge K sorted linked lists · TUF - flatten / merge sorted lists

Constraints tell you: call the total node count N (≤ 10^4). N and k can both be 10^4, so an O(N·k) merge is up to 10^8 steps (too slow in a real round), while O(N log k) is about 1.4·10^5. k can also be far larger than N (thousands of empty feeds), so empty heads must be skipped, not assumed away.
