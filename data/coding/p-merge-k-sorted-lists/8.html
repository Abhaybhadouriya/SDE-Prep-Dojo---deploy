Common mistakes

Pushing null heads. Java's PriorityQueue throws on null, and C++ dereferences a null pointer inside the comparator. Filter empty lists first.

Python tuples that compare nodes. heappush(h, (node.val, node)) raises TypeError when two values tie, because Python then compares the nodes. Put a unique tie-breaker (list index or a counter) in the middle.

Using the default C++ heap. priority_queue is a max-heap. The comparator must return a->val > b->val to get the smallest on top.

Calling the sequential merge O(N log k). Merging into one growing result is O(N·k); only balanced pairing gives log k rounds.

Forgetting to cut the tail. When you splice nodes, the last node already has next = null only because it was the end of its list. If you copy values into new nodes instead, remember to terminate the list.
