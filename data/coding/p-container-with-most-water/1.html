The problem (in our words)

You get an integer array height of length n. Picture n vertical posts on a number line: post i stands at x = i and runs from (i, 0) up to (i, height[i]). Choose two posts; together with the x-axis they form a tank. The tank holds min(height[i], height[j]) * (j - i) units of water. Return the largest amount any pair of posts can hold. The tank cannot be tilted.

Signature: int maxArea(int[] height) (LeetCode style; read the array, return one integer).

  • n == height.length
  • 2 <= n <= 105
  • 0 <= height[i] <= 104

Practice it: LeetCode 11 · GfG Container With Most Water

Constraints tell you: n up to 105 means the O(n²) pair loop (5·109 pairs) times out; you need O(n) or O(n log n). The largest area is 104 × (105 - 1) ≈ 109, which still fits in a 32-bit signed int (limit 2.1·109).
