The problem (in our words)

You get an integer array nums of length n and an integer k. Look at every contiguous subarray of length exactly k and return the largest average among them. Any answer within 10-5 of the true value is accepted.

Signature: double findMaxAverage(int[] nums, int k).

Constraints

  • n == nums.length
  • 1 <= k <= n <= 10^5
  • -10^4 <= nums[i] <= 10^4

Practice it: LeetCode 643 - Maximum Average Subarray I · GfG - Maximum Average Subarray

Constraints tell you: n up to 105 and k up to n: recomputing each window is O(n·k), up to about 2.5 * 109 steps when k = n/2. One pass is the target. A window sum is at most 105 * 104 = 109 in absolute value, which just fits in a 32-bit int; 64-bit is the safe habit. Values can be negative, so the answer can be negative.
