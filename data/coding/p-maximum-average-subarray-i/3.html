Recognise the pattern

Cue: "subarray / substring of length exactly k" + a sum, average, count or max -> fixed-size sliding window: add the entering element, remove the leaving one.

When you see "every window of size k", think "what changes when the window moves by one?" If the summary can be updated in O(1) (sum, count of something, frequency map), it is a fixed window.

When you see "maximum average, length at least k", think binary search on the average plus prefix sums (LC 644).

Taxonomy: Sliding window → fixed window sum / average. Pattern lessons: Sliding window, Prefix sum.
