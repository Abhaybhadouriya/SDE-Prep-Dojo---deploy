60-second recall

  • Cue: evaluate a string with + - and nested brackets, no eval -> stack of (total, sign).
  • Insight: brackets only flip signs; park the outer total and the sign before "(".
  • State: total, num, sign; stack of (total, sign) per open bracket.
  • Trap: add the last number at the end; reset num after ")"; unary minus needs no special case.
  • Cost: O(n) time, O(depth) space; Calculator II/III add a term stack or recursion.
for c in s:
    if c.isdigit(): num = num * 10 + int(c)
    elif c in "+-": total += sign * num; num = 0; sign = 1 if c == "+" else -1
    elif c == "(": stack.append((total, sign)); total, sign = 0, 1
    elif c == ")":
        total += sign * num; num = 0
        t, g = stack.pop(); total = t + g * total; sign = 1
return total + sign * num

s = "1 - (2 - 3)". What is pushed on the stack when '(' is read?

  1. (1, -1)
  2. (1, 1)
  3. (-1, 1)
  4. (0, -1)
After "1 -" the total is 1 and the sign is -1. '(' parks (total, sign) = (1, -1) and restarts with total 0, sign +1. At ')' the inner -1 becomes 1 + (-1)(-1) = 2.

Why does the code end with return total + sign * num and not return total?

  1. The last number is still in num: no operator follows it to add it
  2. It handles unary minus
  3. It empties the stack
  4. It is only for empty strings
Numbers are added when the next operator or ')' arrives. The final number has neither, so it is added after the loop.

Input "-(2 + 3)". What extra handling does the leading unary minus need here?

  1. None: total starts at 0, so it reads as 0 - (2 + 3)
  2. Push a 0 token first
  3. A separate unary flag
  4. Reject the input
'-' just sets sign = -1 with total 0, and '(' parks (0, -1). The result is 0 + (-1)(5) = -5.
