The problem (in our words)

You are given a string s holding a valid arithmetic expression. Evaluate it and return the integer result. You must not use any built-in function that evaluates strings as expressions (such as eval()).

The expression contains non-negative integers, the binary operators + and -, parentheses ( ), and spaces. In addition, - may be used as a unary minus ("-1" and "-(2 + 3)" are valid), but + is never unary ("+1" and "+(2 + 3)" do not appear). Two operators never appear next to each other.

Signature: int calculate(String s).

  • 1 <= s.length <= 3 · 105
  • s consists of digits, '+', '-', '(', ')' and ' '.
  • s is a valid expression.
  • '+' is not used as a unary operation; '-' can be.
  • There are no two consecutive operators in the input.
  • Every number and every running calculation fits in a signed 32-bit integer.

Practice it: LeetCode 224 - Basic Calculator

Constraints tell you: 3·105 characters means one linear pass; nesting can be about 105 deep ("((((...1...))))"), which can overflow a recursive parser in Python and is risky in Java, so an explicit stack is safer. Values fit in int32, but intermediate sign * num before the final answer is safest in 64-bit (our C++/Java code uses long).
