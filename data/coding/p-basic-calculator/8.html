Common mistakes

Forgetting the last number. Numbers are added when an operator or ) ends them, so "1 + 2" returns 1 unless you add sign * num after the loop.

Not resetting num after ). The bracket's value goes into total; if num still holds the inner last number, the next operator adds it again.

Pushing the sign but not the total (or the other way round). Both are needed: 7-(...) must remember 7 and the minus.

Special-casing unary minus. No special case is needed: with num = 0, a leading - adds 0 and sets the sign. Code that looks back at the previous non-space character is a common source of bugs with spaces.

Reading one digit per number. "12+3" is 15, not 1+2+3. Accumulate num = num * 10 + d.

Using eval or a regex shortcut. Forbidden by the statement, and the point of the round is the parser.
