The story

Explain like I'm 5

A pile of boxes sits in a warehouse, each with a weight written on it. You only ever add or remove the top box. The manager keeps asking "what is the lightest box in the pile right now?" Lifting every box to check is slow. The trick: when you put a box on the pile, also write on it a sticky note saying "the lightest box from me down is X". The answer is then always on the top box's note, and when you take a box off, the box below still has its own correct note.

The work is not the stack itself (any array is a stack). The work is keeping one extra answer correct while the stack shrinks, because a minimum, unlike a sum, cannot be "un-added" when its element leaves.

From your world

It is the same as saving state on a call stack: each kernel stack frame (or each spin_lock_irqsave) stores the old flags next to the new work, so the matching restore needs no computation. Here each frame saves "the min before me" so pop restores it for free.
