The problem (in our words)

Build a class MinStack for a stack of 32-bit integers that answers "what is the smallest value currently stored?" in constant time. It must support:

  • MinStack() - create an empty stack.
  • void push(int val) - put val on top.
  • void pop() - remove the top element.
  • int top() - return the top element without removing it.
  • int getMin() - return the minimum element in the stack.

Each of the four operations must run in O(1) time. The judge calls them as two arrays, the method names and their arguments, and expects one output per call (null for the constructor, push and pop).

Constraints

  • -231 <= val <= 231 - 1
  • pop, top and getMin are only called when the stack is not empty.
  • At most 3 * 104 calls in total to push, pop, top and getMin.

Practice it: LeetCode 155 · GfG Get Min from Stack

Constraints tell you: 3·104 calls is tiny, so even an O(n) getMin would pass the judge; the O(1) rule is the real test. Values span the full 32-bit range, so any trick that stores differences (val - min) can overflow 32 bits: it needs a 64-bit type.
