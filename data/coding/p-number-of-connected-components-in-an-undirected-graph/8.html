Common mistakes

Adding the edge in one direction only (DFS version). With [[1,0]] and a flood starting at 0, a one-way list never reaches 1 and the answer is 2 instead of 1.

Comparing nodes instead of roots. if parent[a] != parent[b] is wrong once trees have depth; always compare find(a) and find(b).

Decrementing on every edge. n - e is only right for a forest. A cycle edge merges nothing; decrement only when the roots differ.

Counting distinct parent[] values at the end. Without a final find on every node, parent entries may point at non-roots. Count roots (find(i) == i), or better, keep the running count.

Building the graph from the edges only. Nodes with no edges never appear in an edge list but still count.
