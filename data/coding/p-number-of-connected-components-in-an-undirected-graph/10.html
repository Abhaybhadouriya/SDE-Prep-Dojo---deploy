Closest match: GfG Connected Components in an Undirected Graph Medium

  • Same: n nodes and an edge list, count the components.
  • Different: GfG asks for the components themselves (sorted lists) and allows zero edges.
  • So: use DFS/BFS and collect the visited nodes per start, or group nodes by find(i).

How to recognise it:

  • "Groups", "networks", "provinces", "friend circles", "clusters" from pairwise links.
  • The links are undirected (for directed graphs, components are SCCs: a different algorithm).

Practice order:

  1. Number of Provinces (DFS on a matrix), then this problem with union-find.
  2. Graph Valid Tree and Redundant Connection (the cycle-edge test).
  3. Number of Operations to Make Network Connected, then Accounts Merge.
