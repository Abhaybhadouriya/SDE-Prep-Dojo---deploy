60-second recall

  • Cue: count groups from an undirected edge list.
  • Insight: start with n; every edge between two different roots removes one component.
  • Tool: union-find (path halving + union by size), or DFS/BFS from each unvisited node.
  • Trap: isolated nodes count; cycle edges do not decrement; compare roots, not parents.
  • Cost: O((n + e) α(n)) time, O(n) space; DFS O(n + e) with an adjacency list.
parent = list(range(n)); count = n
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]; x = parent[x]
    return x
for a, b in edges:
    ra, rb = find(a), find(b)
    if ra != rb: parent[rb] = ra; count -= 1
return count

Quick quiz

n = 5 and 4 edges, two of which close cycles. How many components?

  1. 1
  2. 3
  3. 5
  4. 2
Only 2 edges merge: 5 - 2 = 3.

What does it mean when find(a) == find(b) for a new edge?

  1. The edge is invalid
  2. a and b are the same node
  3. The edge closes a cycle
  4. The graph is disconnected
They were already connected, so the edge adds a second path between them: a cycle.

When is a graph with n nodes a tree?

  1. Exactly n - 1 edges and every one merges (one component, no cycle)
  2. Any n - 1 edges
  3. No isolated node
  4. Edges sorted
That is Graph Valid Tree: n - 1 successful unions mean one component and no cycle.
