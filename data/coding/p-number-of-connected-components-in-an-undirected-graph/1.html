The problem (in our words)

A graph has n nodes labelled 0 to n - 1. You are given the integer n and an array edges where edges[i] = [ai, bi] means there is an undirected edge between nodes ai and bi. Return the number of connected components in the graph: maximal groups of nodes in which every node can reach every other through edges. A node with no edges is a component by itself.

Signature: int countComponents(int n, int[][] edges).

Constraints:

  • 1 <= n <= 2000
  • 1 <= edges.length <= 5000
  • edges[i].length == 2
  • 0 <= ai <= bi < n and ai != bi (no self-loops)
  • No edge is listed twice.

Practice it: LeetCode 323 (Premium) · GfG Connected Components (free, same task) · TUF article

Constraints tell you: n + e is at most 7,000, so any O(n + e) traversal is instant, and even an O(n * e) approach would pass. The test is not speed but correctness: isolated nodes, cycles, and edges that arrive in any order.
