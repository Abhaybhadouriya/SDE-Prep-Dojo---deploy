One row is enough, if you walk it backwards

Row i reads only row i-1. So keep one array best[c] and overwrite it item by item. The catch is the order of the capacity loop. When we compute best[c] for the current item we must read best[c-w] as it was before this item. If we walk c upwards, best[c-w] has already been updated with this item, so we would be adding the item to a bag that may already contain it. Walk c downwards and every smaller cell is still the old row.

The most-asked 0/1 problem is the boolean version. Partition Equal Subset Sum: given a list of positive integers (at most 200 of them, each at most 100), decide whether it can be split into two groups with equal sums. If the total is odd, no. Otherwise ask "is there a subset with sum total/2?". The state can[s] = "some subset of the items seen so far sums to exactly s", with can[0] = true. Step through it:

  1. Start: only sum 0 is reachable (take nothing). We need sum 5, half of the total 10.
  2. Item 3, capacity loop from 5 down to 3: can[3] becomes true because can[0] was true.
  3. Item 1, from 5 down to 1: can[4] (3 + 1) and can[1] turn on. Going down means can[2] read can[1] before it changed, so this single 1 is not used twice.
  4. Item 5: can[5] turns on from can[0]. We could stop here: the answer is already true.
  5. The second 1 fills can[2] (1 + 1). Final answer can[5] = T: {5} and {3, 1, 1} both sum to 5.
// 0/1 knapsack, one row: capacity loop runs DOWN so each item is used at most once.
func knap01(w, v []int, capacity int) int {
	best := make([]int, capacity+1)
	for i := range w {
		for c := capacity; c >= w[i]; c-- {
			best[c] = max(best[c], best[c-w[i]]+v[i])
		}
	}
	return best[capacity]
}

// 0/1 boolean: can the array be split into two halves with equal sums? (subset sum = total/2)
func canPartition(nums []int) bool {
	total := 0
	for _, x := range nums {
		total += x
	}
	if total%2 != 0 {
		return false
	}
	half := total / 2
	can := make([]bool, half+1)
	can[0] = true // empty subset
	for _, x := range nums {
		for s := half; s >= x; s-- {
			can[s] = can[s] || can[s-x]
		}
	}
	return can[half]
}

# 0/1 knapsack, one row: capacity loop runs DOWN so each item is used at most once.
def knap01(weights, values, cap):
    best = [0] * (cap + 1)
    for w, v in zip(weights, values):
        for c in range(cap, w - 1, -1):
            best[c] = max(best[c], best[c - w] + v)
    return best[cap]

# 0/1 boolean: can the array be split into two halves with equal sums? (subset sum = total/2)
def can_partition(nums):
    total = sum(nums)
    if total % 2:
        return False
    half = total // 2
    can = [True] + [False] * half                         # can[s] = some subset sums to s
    for x in nums:
        for s in range(half, x - 1, -1):
            can[s] = can[s] or can[s - x]
    return can[half]

The bitset version

For boolean subset sum the whole array is a bitmap: bit s is set when sum s is reachable. Adding item x to every reachable sum is a left shift by x, and "or keep the old sums" is an OR. So one item costs one shift-or over S/64 machine words instead of S separate cell updates. In C++ that is bits |= bits << x on a std::bitset; in Python an arbitrary-size int does the same thing.

// Same question with a bitset: bit s set = sum s reachable. Shift-or adds one item to every sum.
func canPartitionBits(nums []int) bool {
	total := 0
	for _, x := range nums {
		total += x
	}
	if total%2 != 0 {
		return false
	}
	bits := big.NewInt(1)
	for _, x := range nums {
		bits.Or(bits, new(big.Int).Lsh(bits, uint(x)))
	}
	return bits.Bit(total/2) == 1
}
// Same question with a bitset: bit s set = sum s reachable. Shift-or adds one item to every sum.
bool canPartitionBits(const vector<int>& nums) {
    int total = accumulate(nums.begin(), nums.end(), 0);
    if (total % 2) return false;
    bitset<20001> bits;                                                    // LC 416: sum <= 200 * 100
    bits[0] = 1;
    for (int x : nums) bits |= bits << x;
    return bits[total / 2];
}
# Same question with a bitset: bit s set = sum s reachable. Shift-or adds one item to every sum.
def can_partition_bits(nums):
    total = sum(nums)
    if total % 2:
        return False
    bits = 1
    for x in nums:
        bits |= bits << x
    return (bits >> (total // 2)) & 1 == 1
