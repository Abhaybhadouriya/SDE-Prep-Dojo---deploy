Revision card

  • Cue: Pick items under a capacity, "subset sum", "partition equal", coin change ways or fewest coins.
  • Insight: Each item is a take-or-skip decision against a remaining capacity.
  • State: best[c] over capacity; 0/1 loops c downwards, unbounded loops c upwards.
  • Trap: Loop order swaps combinations and orderings; sentinel overflow for "fewest"; ways[0] = 1.
  • Cost: O(n W) pseudo-polynomial: right when W is small.

More to remember

  • 0/1: best[i][c] = max(best[i-1][c], best[i-1][c-w] + v). Unbounded: the take term reads row i, not i-1.
  • One row: 0/1 loops capacity down, unbounded loops capacity up.
  • Counting: coins outside = combinations, amounts outside = orderings.
  • Bases: count ways[0] = 1; fewest f[0] = 0 with a safe sentinel; feasible can[0] = true.
  • Reductions: equal partition = subset sum total/2; target sum = subset sum (total + target)/2; min difference = largest reachable sum ≤ total/2.
  • O(n x W) is pseudo-polynomial: right when the capacity is small.
  • Keep the 2D table if you may need to list the chosen items.
