Unbounded knapsack: coins you can reuse

When every item has unlimited copies, the "take" choice reads the current row: after taking one coin you may take the same coin again. In one array that is exactly the upward loop that was a bug for 0/1. The 2D form is best[i][c] = max(best[i-1][c], best[i][c-w] + v); note the second term stays on row i.

Coin Change restated: given coin denominations (up to 12 of them) and an amount up to 104, return the fewest coins that add up to the amount, or -1 if it cannot be made. Coins can be reused.

  • State: fewest[a] = fewest coins that sum to exactly a.
  • Transition: the last coin is some c ≤ a, so fewest[a] = min(fewest[a - c] + 1).
  • Base and "impossible": fewest[0] = 0; every other cell starts at a sentinel larger than any real answer (amount + 1 works, because the answer never exceeds amount when a 1-coin exists, and is -1 otherwise). Using INT_MAX instead overflows on + 1.
  • Why not greedy: with coins {1, 3, 4} and amount 6, "largest first" gives 4 + 1 + 1 (three coins); 3 + 3 is two.

Perfect Squares (fewest perfect squares summing to n, n ≤ 104) is the same template where the coins are 1, 4, 9, 16 ... up to n. Rod cutting is the max-value version: lengths are weights, prices are values, pieces can repeat. Minimum Cost For Tickets looks similar but is a 1D DP over days, because a pass covers a time window rather than a fixed weight.

// Unbounded, minimum: fewest coins for amount (-1 if impossible). Capacity loop runs UP: reuse allowed.
func coinChange(coins []int, amount int) int {
	inf := amount + 1
	fewest := make([]int, amount+1)
	for a := 1; a <= amount; a++ {
		fewest[a] = inf
	}
	for _, c := range coins {
		for a := c; a <= amount; a++ {
			fewest[a] = min(fewest[a], fewest[a-c]+1)
		}
	}
	if fewest[amount] >= inf {
		return -1
	}
	return fewest[amount]
}

// Unbounded, minimum, items generated on the fly: fewest perfect squares summing to n.
func numSquares(n int) int {
	fewest := make([]int, n+1)
	for a := 1; a <= n; a++ {
		fewest[a] = n // n ones always work
	}
	for k := 1; k*k <= n; k++ {
		for a := k * k; a <= n; a++ {
			fewest[a] = min(fewest[a], fewest[a-k*k]+1)
		}
	}
	return fewest[n]
}
// Unbounded, minimum: fewest coins for amount (-1 if impossible). Capacity loop runs UP: reuse allowed.
int coinChange(const vector<int>& coins, int amount) {
    const int INF = amount + 1;
    vector<int> fewest(amount + 1, INF);
    fewest[0] = 0;
    for (int c : coins)
        for (int a = c; a <= amount; a++)
            fewest[a] = min(fewest[a], fewest[a - c] + 1);
    return fewest[amount] < INF ? fewest[amount] : -1;
}

# Unbounded, minimum: fewest coins for amount (-1 if impossible). Capacity loop runs UP: reuse allowed.
def coin_change(coins, amount):
    INF = amount + 1
    fewest = [0] + [INF] * amount
    for c in coins:
        for a in range(c, amount + 1):
            fewest[a] = min(fewest[a], fewest[a - c] + 1)
    return fewest[amount] if fewest[amount] < INF else -1

# Unbounded, minimum, items generated on the fly: fewest perfect squares summing to n.
def num_squares(n):
    fewest = [0] + [n] * n                                # n ones always work
    sq = 1
    while sq * sq <= n:
        s = sq * sq
        for a in range(s, n + 1):
            fewest[a] = min(fewest[a], fewest[a - s] + 1)
        sq += 1
    return fewest[n]
