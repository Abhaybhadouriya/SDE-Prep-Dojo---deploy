Recognise the pattern

Cue: "sorted array, then rotated" + "O(log n)" → binary search on a predicate, not on a target value. The predicate is "is nums[i] <= nums[last]?": it is false on the left (high) run and true on the right (low) run, and the minimum is the first true.
