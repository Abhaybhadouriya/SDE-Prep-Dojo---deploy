  • Cue: BST + k-th smallest / sorted order → in-order traversal.
  • Insight: left subtree < node < right subtree, so in-order is sorted (follow-up: store subtree sizes for an O(h) rank query).
  • State: a stack of pending ancestors, cur, and k counting down.
  • Trap: 1-based k; stop early; counter by reference.
  • Cost: O(h + k) time (not O(k)), O(h) space.
st, cur = [], root
while cur or st:
    while cur: st.append(cur); cur = cur.left
    cur = st.pop(); k -= 1
    if k == 0: return cur.val
    cur = cur.right
