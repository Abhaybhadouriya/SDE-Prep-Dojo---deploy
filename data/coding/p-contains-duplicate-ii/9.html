Revision card

  • Cue: equal values within distance k → fixed window of the last k values.
  • Insight: index i can only pair with i-k .. i-1; keep those values in a set.
  • State: hash set of the last k values (or map value → latest index).
  • Trap: evict nums[i-k] after inserting, not before checking; distance k is allowed.
  • Cost: O(n) time, O(min(n, k)) space; brute O(n·k).
window = set()
for i, x in enumerate(nums):
    if x in window: return True
    window.add(x)
    if i >= k: window.remove(nums[i - k])
return False

Quick quiz

In the last-seen map, which earlier index of a value should you keep?

  1. the first one
  2. all of them
  3. the most recent one
  4. the median one
For the current and every later index, the most recent copy is the nearest one; older copies can only be farther.

What does the window code return for [3, 3] with k = 0?

  1. true
  2. false
  3. it crashes
  4. depends on hashing
At i = 0, 3 is added and immediately evicted (i >= k). At i = 1 the set is empty, so no hit: distinct indices can never be 0 apart.

What is the memory bound of the window set?

  1. O(min(n, k))
  2. O(n)
  3. O(k^2)
  4. O(1)
At most k + 1 values live in the set at once, and never more than n.
