Common mistakes

Off-by-one in the eviction. Removing nums[i-k] before the check at index i makes the window k - 1 wide and misses pairs at distance exactly k. Either check first and evict nums[i-k] after inserting (our code), or evict nums[i-k-1] before the check when i > k (the classic Java version).

Keeping the first index in the map. Writing last[x] = i only when x is new keeps the oldest copy; then [1, 0, 1, 1] with k = 1 compares index 3 with index 0 and wrongly says false.

Using abs(i - j) < k. The limit is inclusive.

Allocating a window of size k up front. k can be 10^5 while n is 3; size the structure by what you insert, not by k.
