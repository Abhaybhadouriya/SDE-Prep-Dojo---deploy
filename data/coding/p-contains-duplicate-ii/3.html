Recognise the pattern

When you see "two equal elements within distance k" or "a repeat in any window of size k", think fixed-size sliding window + hash set (or a last-seen index map). The window holds exactly the elements the current one may pair with.

It sits between two families: the hash lookup of Two Sum / Contains Duplicate ("have I seen this value before?") and the fixed window of the sliding-window problems ("only the last k items count"). Contains Duplicate III adds a third condition (values close, not equal) and needs an ordered set or buckets.
