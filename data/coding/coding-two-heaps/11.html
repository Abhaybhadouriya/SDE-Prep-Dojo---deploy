After adding 4, 1, 9, 6, 2 with the two-heap MedianFinder, what do lo and hi hold?

  1. lo = {2, 4}, hi = {1, 6, 9}
  2. lo = {4, 6, 9}, hi = {1, 2}
  3. lo = {1, 2, 4}, hi = {6, 9}
  4. lo = {1, 2}, hi = {4, 6, 9}
lo keeps the smaller half and the extra item when the count is odd: {1, 2, 4} with top 4, the median. hi = {6, 9}.

Why does lazy deletion keep the total time at O(n log n)?

  1. Stale items are never popped
  2. The heaps never hold more than k items
  3. Hash maps make heap pops O(1)
  4. Each value is pushed once and popped at most once, each in O(log n)
Heaps can hold stale items (up to O(n) of them), but every item enters once and leaves once, so the total is O(n log n).

IPO with k = 3, w = 1, profits [3, 1, 5], capital [1, 0, 5]. What is the final capital?

  1. 4
  2. 5
  3. 9
  4. 10
w = 1 unlocks +3 and +1; take +3, w = 4. Nothing new until 5, so take +1, w = 5. Now +5 is unlocked: w = 10.

In smallest range, which list do you advance after checking the window?

  1. The longest list
  2. The one holding the current minimum
  3. Each list in turn
  4. The one holding the current maximum
Only raising the minimum can narrow the window; moving any other head can only raise the maximum.

For k smallest pairs, why do we seed only column 0 and push only (i, j + 1)?

  1. Column 0 always holds the answer
  2. It sorts the output
  3. Each cell then has exactly one way into the heap, so no visited set is needed and the heap stays small
  4. Pushing (i + 1, j) would be wrong
Pushing both neighbours also works but needs a visited set to avoid duplicates. Rows as lists gives each cell a single predecessor.

Every value of a stream lies in [0, 100]. What is the best median structure?

  1. A sorted array with binary insert
  2. Two heaps
  3. An array of 101 counters, walked to the middle
  4. A balanced BST
