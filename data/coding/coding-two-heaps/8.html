Common mistakes

  • Checking the median rule only on size. Equal sizes are not enough: if 9 sits in lo and 4 in hi, the tops lie. The "push to lo, move lo's top to hi" step is what keeps order; do not skip it to save a log n.
  • Overflow and integer division in the average. (a + b) / 2 overflows near 231 and truncates 4.5 to 4 in C++ and Java. Cast to double first and divide by 2.0.
  • Lazy deletion: reading a top without pruning. Prune both heaps after every rebalance, not only after the removal, because a rebalance can expose a stale value.
  • Lazy deletion: counting sizes with len(heap). The heaps contain stale items; balance must count valid ones (bal, or explicit valid-size counters).
  • IPO: popping an empty heap. If nothing is affordable, break.
  • Merge k lists in Python with (val, node) tuples. Equal values make Python compare ListNodes and crash. Add an index: (val, i, node).
  • K pairs: seeding every row and column. Pushing both (i + 1, j) and (i, j + 1) needs a visited set and is easy to get wrong. Seed column 0 and only move right.
  • Smallest range: continuing after a list ends. Once a list has no next item, the window can no longer cover it. Stop.
