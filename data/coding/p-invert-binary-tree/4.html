Approaches: brute -> better -> optimal

Hint 1

What is the mirror of an empty tree? Of a single leaf?

Hint 2

If someone hands you the mirrored left subtree and the mirrored right subtree, what is left to do at the root?

Hint 3

Does the order in which you swap nodes matter, or could a queue do it too?

1. Build a new mirrored copy

Idea: mirror(node) = new Node(node.val, left = mirror(node.right), right = mirror(node.left)), returning null for null. It never touches the input.

O(n)time
O(n)extra space (new nodes) + O(h) stack

What is wasted: n new nodes. The problem lets us modify the input, and each node can be fixed where it is. -> rung 2. (The copy is the right answer if the caller still needs the original.)

2. Recursive DFS, in place (the expected answer)

  1. Base case: null mirrors to null.
  2. Recurse: mirror the right subtree and the left subtree.
  3. Swap: attach the mirrored right as the new left and the mirrored left as the new right. Return the node.
O(n)time
O(h)stack, h = height (log n balanced, n skewed)

Why it works: by induction on height. A null tree is its own mirror. For a node, assume the calls return correct mirrors of the two subtrees. The mirror of the whole tree has the same root, with the mirror of the old right subtree on the left and the mirror of the old left subtree on the right, which is exactly what we attach. Each node is visited once and does O(1) work.

Pre-order also works: swap the children first, then recurse into both. Both orders are correct because the swap at a node only touches that node's two pointers; it never depends on whether descendants are already swapped. What breaks is in-order "recurse left, swap, recurse left again" written carelessly, see Mistakes.

3. Iterative BFS or explicit stack (no recursion)

Idea: push the root; pop a node, swap its children, push the non-null children. A queue gives level order, a stack gives pre-order; both visit every node once.

q = deque([root] if root else [])
while q:
    node = q.popleft()
    node.left, node.right = node.right, node.left
    if node.left: q.append(node.left)
    if node.right: q.append(node.right)
return root
O(n)time
O(w)space, w = max width (queue) or O(h) (stack)

When to prefer it: when the tree can be very deep (a skewed tree with 105+ nodes overflows a default call stack, especially in Python with its 1000-frame limit). With n <= 100 here, recursion is fine.
