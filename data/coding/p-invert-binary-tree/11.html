Interview follow-ups

Do it without recursion.

BFS with a queue (or DFS with a stack): pop a node, swap its children, push the non-null children. O(n) time, O(width) or O(height) memory, no risk of call-stack overflow.

How to answer

Point out that order does not matter because each swap is local; that is why a plain queue is enough.

Likely follow-ups
  • O(1) extra space? Morris-style threading can visit nodes without a stack, but it temporarily rewires right pointers, which conflicts with swapping: hard to get right; say so.
Return a mirrored copy and keep the original unchanged.

mirror(n) = n ? new Node(n.val, mirror(n.right), mirror(n.left)) : null. O(n) time and O(n) new nodes.

How to answer

Ask whether mutating the input is allowed before coding; it changes the space answer.

Likely follow-ups
  • Who frees the copy in C/C++? Ownership and a matching destroy function.
How do you test it?

Three cheap properties: inverting twice returns the original shape; the in-order sequence of the result is the reverse of the input's; and the level order of each level is reversed. Plus the null, single-node and one-child cases.

How to answer

Property tests beat hand-written expected trees for structural transforms.

Likely follow-ups
  • Generate random trees and compare against the copy-based version.
Is the tree symmetric (LC 101)? Can you use your inversion to answer?

Yes, but wastefully: copy, invert the copy and compare with Same Tree, O(n) time and O(n) space. Better: one recursion isMirror(a, b) that compares a.val == b.val and recurses on (a.left, b.right) and (a.right, b.left), O(n) time, O(h) space, no copy.

How to answer

Give the reuse idea first, then improve it: interviewers like seeing the link.

Likely follow-ups
  • Iterative version with a queue of pairs.
The tree is an n-ary tree (children in a list). How does inversion change?

Reverse each node's child list and recurse into every child: O(n) total because each node appears in exactly one child list.

How to answer

Generalise "swap two" to "reverse k"; complexity is unchanged.

Likely follow-ups
  • Left-child right-sibling representation: what does mirroring mean there?
