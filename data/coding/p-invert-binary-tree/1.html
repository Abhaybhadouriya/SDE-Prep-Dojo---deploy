The problem (in our words)

You are given the root of a binary tree. Invert it: for every node, exchange its left and right subtrees, so the result is the mirror image of the input. Return the root of the inverted tree (inverting in place and returning the same root object is fine).

Trees are written in level order with null for missing children, as on LeetCode: [5,3,8,1,4,7,9] is root 5 with children 3 and 8, whose children are 1, 4 and 7, 9.

Signature: TreeNode invertTree(TreeNode root).

  • The number of nodes is in the range [0, 100].
  • -100 <= Node.val <= 100

Practice it: LeetCode 226 · GfG Mirror Tree

Constraints tell you: at most 100 nodes, so recursion depth is at most 100 and any O(n) traversal is instant. The tree can be empty (0 nodes): the function must accept null. The values do not matter at all; only the shape changes.
