LCA in a BST and with parent pointers

Problem (restated from LeetCode 235, Lowest Common Ancestor of a Binary Search Tree). Same question, but the tree is a binary search tree: every value in a node's left subtree is smaller than the node and every value in its right subtree is larger. You get the root and two different nodes p and q that are both in it; return their LCA. In the BST below, LCA(10, 14) = 12, LCA(8, 14) = 8 and LCA(8, 30) = 20. Limits: 2 to 105 nodes, distinct values in [-109, 109], p != q, both exist.

The general code above still works, but it ignores the best hint in the question. In a BST, the values tell you which side p and q are on. Let lo = min(p, q) and hi = max(p, q). At a node: if hi < node, both are on the left; if lo > node, both are on the right; otherwise they are on different sides (or one of them is this node), and this node is the answer.

Problem (restated from LeetCode 1650, Lowest Common Ancestor of a Binary Tree III, Premium). Every node now also has a parent pointer (null for the root). You are not given the root, only the two nodes p and q. Return their LCA. Limits: 2 to 105 nodes, distinct values in [-109, 109], p != q, and both are in the same tree.

Each node's parent chain is a linked list that ends at the root. Two such lists merge at the LCA and share everything after it. So this is intersection of two linked lists, and there are three answers, in the order you should offer them:

  1. Hash set: put all of p's ancestors (p included) in a set, then walk up from q until you hit one. O(h) time and O(h) space.
  2. Equalise depths: measure both depths, move the deeper node up by the difference, then move both up together until they are the same node. O(h) time, O(1) space, two passes.
  3. Switch at the top: walk both pointers up; when one passes the root, restart it from the other start node. Each walks depth(p) + depth(q) + 1 moves and they meet at the LCA. O(1) space and no depth bookkeeping.

Template: LCA in a BST, and with parent pointers

// LCA in a BST: walk down until p and q are no longer on the same side. O(h), O(1) space.
func lcaBST(root, p, q *TreeNode) *TreeNode {
	lo, hi := p.Val, q.Val
	if lo > hi {
		lo, hi = hi, lo
	}
	for n := root; n != nil; {
		if hi < n.Val {
			n = n.Left // both smaller
		} else if lo > n.Val {
			n = n.Right // both bigger
		} else {
			return n // split (or n is p or q)
		}
	}
	return nil
}

// LCA with parent pointers, no root: each pointer walks up and, at the top, restarts from the
// OTHER node. Both travel depth(p) + depth(q) steps and meet at the LCA.
func lcaParent(p, q *TreeNode) *TreeNode {
	a, b := p, q
	for a != b {
		if a.Parent != nil {
			a = a.Parent
		} else {
			a = q
		}
		if b.Parent != nil {
			b = b.Parent
		} else {
			b = p
		}
	}
	return a
}
// LCA in a BST: walk down until p and q are no longer on the same side. O(h), O(1) space.
TreeNode* lcaBST(TreeNode* root, TreeNode* p, TreeNode* q) {
    int lo = min(p->val, q->val), hi = max(p->val, q->val);
    for (TreeNode* n = root; n; ) {
        if (hi < n->val) n = n->left;            // both smaller
        else if (lo > n->val) n = n->right;      // both bigger
        else return n;                           // split (or n is p or q)
    }
    return nullptr;
}

// LCA with parent pointers, no root: each pointer walks up and, at the top, restarts from the
// OTHER node. Both travel depth(p) + depth(q) steps and meet at the LCA.
TreeNode* lcaParent(TreeNode* p, TreeNode* q) {
    TreeNode *a = p, *b = q;
    while (a != b) {
        a = a->parent ? a->parent : q;
        b = b->parent ? b->parent : p;
    }
    return a;
}
// LCA in a BST: walk down until p and q are no longer on the same side. O(h), O(1) space.
static TreeNode lcaBST(TreeNode root, TreeNode p, TreeNode q) {
    int lo = Math.min(p.val, q.val), hi = Math.max(p.val, q.val);
    TreeNode n = root;
    while (n != null) {
        if (hi < n.val) n = n.left;          // both smaller
        else if (lo > n.val) n = n.right;    // both bigger
        else return n;                       // split (or n is p or q)
    }
    return null;
}

// LCA with parent pointers, no root: each pointer walks up and, at the top, restarts from the
// OTHER node. Both travel depth(p) + depth(q) steps and meet at the LCA.
static TreeNode lcaParent(TreeNode p, TreeNode q) {
    TreeNode a = p, b = q;
    while (a != b) {
        a = a.parent != null ? a.parent : q;
        b = b.parent != null ? b.parent : p;
    }
    return a;
}
def lca_bst(root, p, q):
    """LCA in a BST: walk down until p and q are no longer on the same side. O(h), O(1) space."""
    lo, hi = min(p.val, q.val), max(p.val, q.val)
    node = root
    while node:
        if hi < node.val:
            node = node.left             # both smaller: go left
        elif lo > node.val:
            node = node.right            # both bigger: go right
        else:
            return node                  # split (or node is p or q)
    return None

def lca_parent(p, q):
    """LCA with parent pointers, no root given: two pointers walk up; when one reaches the top
    it restarts from the OTHER node. Both travel depth(p) + depth(q) and meet at the LCA."""
    a, b = p, q
    while a is not b:
        a = a.parent if a.parent else q
        b = b.parent if b.parent else p
    return a

Our checks use one node type with a parent field for every variant. On LeetCode 1650 the type is called Node; the code is the same. The "switch" loop in these templates moves to the other start node when parent is null instead of first stepping onto null; both versions meet at the LCA.

BST cost: O(h) time and O(1) space; h is about log n for a balanced tree and n for a sorted-insert chain. Parent-pointer cost: O(h) time, O(1) space.
