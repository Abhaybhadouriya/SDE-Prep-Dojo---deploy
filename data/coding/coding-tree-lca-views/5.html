All nodes at distance K: turn the tree into a graph

Problem (restated from LeetCode 863, All Nodes Distance K in Binary Tree). You get the root of a binary tree, a node target in it and an integer k. Return the values of all nodes that are exactly k edges away from target, in any order. In our main tree, with target 4 and k = 2, the answer is [6, 9, 15]: two of them below 4 and one reached by going up through 10. Limits: 1 to 500 nodes, distinct values in [0, 500], target is in the tree, 0 <= k <= 1000.

Going down k levels is easy. The hard part is "up then down": 15 is two edges from 4, through 4's parent. Trees do not have up-pointers, so add them: one DFS records parent[child] = node. Now every node has at most three neighbours and this is plain graph BFS from the target, with a seen-set so you never walk back. Stop after k rings; the current ring is the answer.

  1. A tree only points down, but distance goes up too: 4's neighbour 10 is its parent. One DFS fills a map child -> parent. Now each node has up to three neighbours (left, right, parent) and the tree is an undirected graph.
  2. Start BFS at the target. Ring 0 is just {4}. Mark it seen, so nobody walks back into it.
  3. Ring 1: the unseen neighbours of 4 are 2 and 7 (children) and 10 (parent). All are distance 1. Mark them seen.
  4. Ring 2: 2 has no unseen neighbour, 7 gives 6 and 9, 10 gives 15 (its parent is null and 4 is seen). After k = 2 rings, the frontier is the answer: [6, 9, 15] in any order. O(n) time and space.

// Add parent links (tree -> undirected graph), then BFS k rings out from target.
func distanceK(root, target *TreeNode, k int) []int {
	par := map[*TreeNode]*TreeNode{root: nil}
	st := []*TreeNode{root}
	for len(st) > 0 {
		n := st[len(st)-1]
		st = st[:len(st)-1]
		for _, c := range []*TreeNode{n.Left, n.Right} {
			if c != nil {
				par[c] = n
				st = append(st, c)
			}
		}
	}
	seen := map[*TreeNode]bool{target: true}
	ring := []*TreeNode{target}
	for d := 0; d < k && len(ring) > 0; d++ {
		var nxt []*TreeNode
		for _, n := range ring {
			for _, nb := range []*TreeNode{n.Left, n.Right, par[n]} {
				if nb != nil && !seen[nb] {
					seen[nb] = true
					nxt = append(nxt, nb)
				}
			}
		}
		ring = nxt
	}
	out := []int{}
	for _, n := range ring {
		out = append(out, n.Val)
	}
	return out
}
// Add parent links (tree -> undirected graph), then BFS k rings out from target.
vector<int> distanceK(TreeNode* root, TreeNode* target, int k) {
    unordered_map<TreeNode*, TreeNode*> par{{root, nullptr}};
    vector<TreeNode*> st{root};
    while (!st.empty()) {
        TreeNode* n = st.back(); st.pop_back();
        for (TreeNode* c : {n->left, n->right}) if (c) { par[c] = n; st.push_back(c); }
    }
    unordered_set<TreeNode*> seen{target};
    vector<TreeNode*> ring{target};
    for (int d = 0; d < k && !ring.empty(); d++) {
        vector<TreeNode*> nxt;
        for (TreeNode* n : ring)
            for (TreeNode* nb : {n->left, n->right, par[n]})
                if (nb && seen.insert(nb).second) nxt.push_back(nb);
        ring.swap(nxt);
    }
    vector<int> out;
    for (TreeNode* n : ring) out.push_back(n->val);
    return out;
}
// Add parent links (tree -> undirected graph), then BFS k rings out from target.
static List<Integer> distanceK(TreeNode root, TreeNode target, int k) {
    Map<TreeNode, TreeNode> par = new HashMap<>();
    ArrayDeque<TreeNode> st = new ArrayDeque<>();
    st.push(root);
    while (!st.isEmpty()) {
        TreeNode n = st.pop();
        if (n.left != null) { par.put(n.left, n); st.push(n.left); }
        if (n.right != null) { par.put(n.right, n); st.push(n.right); }
    }
    Set<TreeNode> seen = new HashSet<>();
    seen.add(target);
    List<TreeNode> ring = new ArrayList<>(List.of(target));
    for (int d = 0; d < k && !ring.isEmpty(); d++) {
        List<TreeNode> nxt = new ArrayList<>();
        for (TreeNode n : ring)
            for (TreeNode nb : new TreeNode[]{n.left, n.right, par.get(n)})
                if (nb != null && seen.add(nb)) nxt.add(nb);
        ring = nxt;
    }
    List<Integer> out = new ArrayList<>();
    for (TreeNode n : ring) out.add(n.val);
    return out;
}
def distance_k(root, target, k):
    """Turn the tree into an undirected graph (add parent links), then BFS k rings out from target."""
    parent = {root: None}
    st = [root]
    while st:                              # iterative DFS: record each node's parent
        node = st.pop()
        for ch in (node.left, node.right):
            if ch:
                parent[ch] = node
                st.append(ch)
    seen = {target}
    ring = [target]
    for _ in range(k):
        nxt = []
        for node in ring:
            for nb in (node.left, node.right, parent[node]):
                if nb and nb not in seen:
                    seen.add(nb)
                    nxt.append(nb)
        ring = nxt
    return [n.val for n in ring]

The same "parent map + BFS from a start node" solves LeetCode 2385, Amount of Time for Binary Tree to Be Infected: an infection starts at the node with value start and each minute spreads to every neighbour (children and parent); return how many minutes until every node is infected (1 to 105 nodes, distinct values in [1, 105]). The answer is the number of BFS rings minus one, which is the largest distance from start.

No extra map? There is a one-pass recursive version: dfs(node) returns the distance from node down to the target, or -1 if the target is not below. When a child reports distance d, the current node is at distance d + 1, and you collect the nodes at depth k - d - 2 in the other child's subtree. It saves the map but is harder to get right live.
