Revision card

  • Cue: Lowest common ancestor, left/right/top/vertical views, nodes at distance K, serialize/deserialize.
  • Insight: Each call reports what it found below; views are coordinates (depth, column).
  • State: post-order returning null/p/q/LCA; BFS with (node, col); parent map for distance K.
  • Trap: Early return when nodes may be missing; preorder without null markers cannot be rebuilt.
  • Cost: O(n) time, O(h) or O(n) space.

More to remember

  • LCA: each call returns null, p, q or the LCA; both children non-null means "split here".
  • Missing nodes: no early return; count what you found.
  • BST: walk with lo/hi, O(h), O(1). Parent pointers: linked-list intersection.
  • Views are coordinates: row = depth, col = left -1 / right +1. Levels for left/right, columns for top/bottom/vertical.
  • Distance K: add parent links, BFS from the target with a seen set.
  • Serialize: preorder + a marker per empty child (2n + 1 tokens). BST: no markers needed.
  • Build: preorder (or postorder from the end) gives roots, inorder splits; map + moving index for O(n).
