  1. 9

Only q is below 7, so 7 is a messenger: it returns 9. The node that sees both sides non-null is 4.

BST [20, 8, 30, 4, 12, 25, 35, null, null, 10, 14]. What is LCA(4, 14)?

  1. 20
  2. 12
  3. 4
  4. 8
At 20, both are smaller: go left. At 8, 4 <= 8 <= 14: split. The answer is 8.

Distance K from the target: why is a seen set needed after adding parent links?

  1. It is not needed
  2. To handle duplicate values
  3. Child-to-parent plus parent-to-child creates two-way edges, so BFS would walk back

The tree is now an undirected graph. Without "seen" each node re-adds its parent or child and distances come out wrong.
