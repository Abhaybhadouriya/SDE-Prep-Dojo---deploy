Explain like I'm 5

You are building staircases out of numbered blocks that arrive one by one, and every staircase must go strictly up. For each staircase height you only care about one thing: the lowest possible top block, because a low top is easiest to build on later. When a new block arrives, put it on the tallest staircase whose top is smaller than it; if it beats every top, you just made a taller staircase. Otherwise it becomes a better (lower) top for an existing height.

From your world

The tails array is a sorted lookup table kept in a fixed-size, contiguous buffer, updated by binary search and overwrite, never by insertion. That is the same discipline as an ordered array of timer deadlines or a sorted prefix table where an update replaces an entry in place: O(log n) to find the slot, O(1) to write it.
