Common mistakes

Returning dp[n-1] in the O(n²) DP. dp[i] is the LIS ending at i; the best one can end anywhere. On [3, 4, 1], dp = [1, 2, 1]: dp[n-1] is 1, but the answer is 2.

Using upper_bound for a strict LIS. bisect_right on [4, 4, 4] appends every 4 and returns 3.

Printing tails as "the LIS". After [3, 12, 4, 9, 7, 15, 2, 20], tails = [2, 4, 7, 15, 20], which is not a subsequence (2 comes after 15). To rebuild a real LIS, store the slot index of each element and a parent pointer.

Initialising dp to 0. Every element alone is a subsequence of length 1; with 0 the answer for a decreasing array becomes 0.
