The problem (in our words)

You get the head of a singly linked list of digits. Return true if the values read the same from front to back and from back to front, and false otherwise.

Signature: boolean isPalindrome(ListNode head), where ListNode has int val and ListNode next.

  • The list has between 1 and 105 nodes.
  • 0 <= Node.val <= 9
  • Follow-up: can you do it in O(n) time and O(1) extra space?

Practice it: LeetCode 234 · GfG Check if Linked List is Palindrome · TUF article

Constraints tell you: 105 nodes, so anything O(n) or O(n log n) passes; the real question is the follow-up's O(1) space. A recursive solution looks O(1) but uses 105 stack frames: that is O(n) space and can overflow. The list is never empty, so head is not null. Values are single digits, so "build a number" ideas overflow fast; compare nodes instead.
