The input may contain duplicates. Return each distinct subset once.

Sort first, then in the loop skip nums[i] == nums[i-1] when i > start: at one level of the tree, equal values would start identical branches. The same value can still be chosen at deeper levels. This is LeetCode 90.

How to answer

Explain "i > start" with [1,2,2]: the second 2 is skipped only as a sibling, not as a child.

Likely follow-ups
  • Can the bitmask method handle duplicates? (Only with a set of sorted tuples: extra memory.)
Return only the subsets of size k.

Record when len(cur) == k and return; prune when there are not enough elements left (n - i < k - len(cur)). Time O(k·C(n, k)). This is LeetCode 77.

How to answer

Mention the "not enough left" break: it is the pruning interviewers look for.

Likely follow-ups
  • Next k-subset without recursion? (Gosper's hack on a bitmask.)
n is 30. What breaks, and how do you change the API?

230 ≈ 109 subsets cannot be stored. Return an iterator or take a callback that receives each subset; memory drops to O(n). With a bitmask the iterator state is one 32-bit counter. For n > 63 the plain mask no longer fits a word, but the recursive version still works.

How to answer

Separate generation from consumption: "stream, do not collect".

Likely follow-ups
  • Resume after a crash? (Persist the mask; it fully describes the position.)
Count the subsets whose sum equals a target T.

Do not enumerate when values are small: a 0/1 knapsack count dp[s] += dp[s - x] runs in O(n·T). With n ≤ 40 and large values, split into two halves, enumerate 220 sums per half, sort one and binary-search (meet in the middle).

How to answer

Ask about the value range first: it decides between DP and enumeration.

Likely follow-ups
  • Negative values? (Shift the DP index by the sum of negatives.)
Return the subsets in lexicographic order.

Sort the input. The start-index recursion then emits subsets in lexicographic order of their sorted contents ([], [4], [4,7], [4,7,9], [4,9], [7], ...), which the bitmask order does not.

How to answer

Show the first five outputs of each method side by side.

Likely follow-ups
  • Order by size first? (Loop k = 0..n and run the size-k version.)
