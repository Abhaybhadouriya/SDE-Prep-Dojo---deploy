Common mistakes

Appending cur instead of a copy. In Java, Python and Go every stored entry then points at the same list, which is empty at the end: the output is 2n empty lists. Copy (new ArrayList<>(cur), cur[:], append([]int(nil), cur...)).

Recursing with start + 1 instead of i + 1. The child must start after the element just chosen; start + 1 lets earlier elements join again and creates duplicates like [7,4].

Recording only at the leaves. If you record when start == n with the "for loop" template, you get only the subsets that contain the last element. Leaves-only recording belongs to the pick/skip template (two recursive calls per element).

Java: cur.remove(x) with an Integer value. remove(Object) deletes by value and remove(int) by index; pass the index cur.size() - 1.
