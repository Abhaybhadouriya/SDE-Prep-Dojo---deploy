Technique: combine structures that point into each other, so each operation uses whichever one makes it O(1).

Closest match: LC 381 Insert Delete GetRandom O(1) - Duplicates allowed Hard

  • Same: dense array for random picks, swap-with-last delete.
  • Different: a value may appear many times, and getRandom is weighted by count.
  • So: map each value to a set of indexes; on remove, take any index of v, move the last element there, and update the moved element's index set (remove its old last index, add i).
