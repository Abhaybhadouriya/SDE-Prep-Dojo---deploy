The story

Explain like I'm 5

A raffle has numbered seats in a row, all filled with no gaps, and a notebook saying which person sits in which seat. To draw a winner, roll a die over the seat numbers: everybody has the same chance because there are no empty seats. When someone leaves, do not make everybody behind them shuffle forward. Just ask the person in the very last seat to move into the empty one, fix that one line in the notebook, and remove the last seat.

The interview point is the swap with last: it keeps the array dense (needed for a fair random pick) while making delete O(1). The rest is bookkeeping, and the bookkeeping order matters when the element removed is itself the last one.

From your world

The kernel does the same thing in many places: a dense array of active entries plus a reverse index (for example, a free-slot table where removal moves the tail entry into the freed slot and patches its back-pointer). It keeps iteration and random selection over active entries cache-friendly, with O(1) removal.
