Common mistakes

Deleting the key before updating the moved value. When val is the last element, del pos[val] followed by pos[last] = i re-creates the key and the next insert(val) wrongly returns false. Update first, delete last (or special-case i == size - 1).

Java list.remove(Integer) vs list.remove(int). remove(val) with an int argument removes by index; with an Integer it searches by value in O(n). Always remove by the last index: vals.remove(vals.size() - 1).

Erasing from the middle of the array. vals.erase(begin + i) or list.remove(i) shifts the tail: O(n). The point is to never do that.

Creating a new random generator per call. In Java or C++, seeding a new generator in each getRandom is slow and, with time-based seeds, can return the same value repeatedly. Keep one generator as a field.
