The problem (in our words)

A courier network has n depots numbered 0 to n - 1. Each entry flights[i] = [from_i, to_i, price_i] is a one-way shipment link: it carries a parcel from depot from_i to depot to_i for price_i. The parcel starts at depot src, must reach depot dst, and the contract allows a stop budget k (the integers src, dst and k.

Return the cheapest total price to send a parcel from src to dst using a route with at most k stops (intermediate depots, so at most k + 1 links). If no such route exists, return -1.

  • Input: n, the edge list flights, and integers src, dst, k.
  • Output: one integer, the minimum price, or -1. Signature: int findCheapestPrice(int n, int[][] flights, int src, int dst, int k).

Constraints

  • 2 <= n <= 100
  • 0 <= flights.length <= n * (n - 1) / 2
  • flights[i].length == 3
  • 0 <= from_i, to_i < n and from_i != to_i
  • 1 <= price_i <= 10^4
  • There are no multiple flights between the same pair of cities (in the same direction).
  • 0 <= src, dst, k < n and src != dst
