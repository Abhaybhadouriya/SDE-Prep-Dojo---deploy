Recognise the pattern

Cue: "cheapest / shortest path" + "at most k edges / stops / hops" → Bellman-Ford limited to k + 1 rounds (or BFS by levels, or Dijkstra on the state (node, edges used)). Any extra budget on the path (stops, fuel, time) turns the node into a pair.

Why plain Dijkstra is not enough: it keeps one number per node, the cheapest cost. With a hop limit, a node reached cheaply but with many hops can be useless, while a more expensive route with fewer hops is the one that can still reach dst. One number cannot remember both.
