Dry run

The network from Example 1: [[0,1,50],[1,2,50],[2,4,50],[0,3,200],[3,4,60]], src 0, dst 4. The bottom row is the cost array after each round; highlighted cells changed in that round.

  1. Round 0: cost = [0, inf, inf, inf, inf]. With zero flights only depot 0 is reachable.
  2. Start of round 1: copy cost into nxt. Every flight in this round reads the old cost and writes nxt, so a round can add at most one flight to any route.
  3. Round 1 (at most 1 flight): 0 → 1 gives 50 and 0 → 3 gives 200. The flight 1 → 2 is tried too, but it reads the old cost[1], which is still infinite, so it does nothing.
  4. Round 2 (at most 2 flights): 1 → 2 gives 100 and 3 → 4 gives 260. For k = 1 we stop after k + 1 = 2 rounds: the answer is 260.
  5. Round 3 (at most 3 flights): 2 → 4 now reads cost[2] = 100, so depot 4 improves to 150. For k = 2 the answer is 150.
  6. Why the copy matters: if round 1 writes into the same array, 0 → 1 sets cost[1] = 50, then 1 → 2 immediately reads it (100), then 2 → 4 reads that (150). One round used three flights, so k = 0 would wrongly return 150 instead of -1.
