Common mistakes

Relaxing in place. Without the per-round copy, one round can chain several flights (dry run step 5), so the hop limit is silently ignored. Plain Bellman-Ford does not care; this problem does.

Running k rounds instead of k + 1. k counts stops, not flights. k = 0 still allows one direct flight.

Plain Dijkstra with a visited set or one dist per node. It discards the "more expensive but fewer flights" route that is the only valid one (pattern table above). Store the flight count in the state, and prune by fewest flights.

Overflow from infinity. With INF = INT_MAX, cost[u] + price overflows. Check cost[u] != INF first, or use 1e9 as infinity (still far above 10^6).

Unpruned DFS or BFS. Exploring every route without "only push if cheaper than best[v] at this level" is exponential and times out.
