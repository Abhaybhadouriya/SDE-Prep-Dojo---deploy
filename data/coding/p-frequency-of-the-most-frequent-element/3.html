Recognise the pattern

When you see "at most k increments (or a budget)" + "maximise how many elements become equal", think sort, then a sliding window whose cost is max × size - sum.

When you see "longest group that satisfies a budget", where shrinking a group can only make it cheaper, think variable window: expand right, shrink left while over budget, record after the shrink.

Two facts turn this into a window. The target is always an existing value: raising elements to a value that is not in the list costs more than raising them to the largest list value below it, for the same count. The elements to raise are the ones just below the target in sorted order: swapping any chosen element for a closer one only saves operations. So every candidate answer is a contiguous block of the sorted array ending at its target.

Pattern: Sliding window → variable window → longest valid · Lessons: Sliding window, Sliding window variants
