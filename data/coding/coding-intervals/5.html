Template 4 and 5: can-attend and greedy by end

Can attend all (Meeting Rooms): sort by start; if any meeting starts before the previous one ends, one person cannot attend all. O(n log n).

Maximum set of non-overlapping intervals is the classic activity selection problem. Non-overlapping Intervals asks for the fewest intervals to remove so that the rest do not overlap; that is n - (most you can keep). The greedy: sort by end, keep an interval if it starts at or after the end of the last kept one.

Why earliest end is safe (the exchange argument, two sentences you can say in an interview). Take any optimal answer and look at its first interval. The interval with the earliest end ends no later, so swap it in: the rest still fits, and the count is the same. Repeat for the next choice, and the greedy answer is as large as the optimal one.

func canAttend(iv [][]int) bool {
	sort.Slice(iv, func(i, j int) bool { return iv[i][0] < iv[j][0] })
	for k := 1; k < len(iv); k++ {
		if iv[k][0] < iv[k-1][1] {
			return false
		}
	}
	return true
}

func eraseOverlap(iv [][]int) int {
	sort.Slice(iv, func(i, j int) bool { return iv[i][1] < iv[j][1] }) // by END
	kept, end := 0, math.MinInt64
	for _, x := range iv {
		if x[0] >= end {
			kept++
			end = x[1]
		}
	}
	return len(iv) - kept
}

def can_attend(iv):
    """Meeting rooms I: sort by start, any start < previous end is a clash (end is exclusive)."""
    iv = sorted(iv)
    return all(iv[k][0] >= iv[k - 1][1] for k in range(1, len(iv)))

def erase_overlap(iv):
    """Non-overlapping intervals: greedy by END keeps the most; answer = removed count."""
    iv = sorted(iv, key=lambda x: x[1])
    kept, end = 0, float("-inf")
    for s, e in iv:
        if s >= end:                         # [1,2],[2,3] do not overlap in this problem
            kept += 1
            end = e
    return len(iv) - kept
