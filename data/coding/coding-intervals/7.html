Template 7: difference arrays and the sweep line

Sometimes you do not need the intervals at all, only the count at every point. Then write each interval as two events, +v at its start and -v just after its end, and a prefix sum gives the count everywhere. If coordinates are small (stops 0..1000, days 1..n), the events live in an array: a difference array. If they are large or sparse, sort the events instead (or keep them in an ordered map): a sweep line.

Car Pooling: a car with a capacity drives east; trips are [people, from, to], and people leave at to. Can it take every trip?

func carPooling(trips [][]int, capacity int) bool {
	var diff [1002]int
	for _, t := range trips {
		diff[t[1]] += t[0]
		diff[t[2]] -= t[0]
	}
	load := 0
	for _, d := range diff {
		load += d
		if load > capacity {
			return false
		}
	}
	return true
}

def car_pooling(trips, capacity):
    """Difference array over stops: +p at from, -p at to (passengers leave at 'to')."""
    diff = [0] * 1002
    for p, a, b in trips:
        diff[a] += p
        diff[b] -= p
    load = 0
    for d in diff:
        load += d
        if load > capacity:
            return False
    return True
  • Corporate Flight Bookings and Range Addition: the same array with closed ranges, so the -v goes at end + 1.
  • My Calendar II: no triple booking. Keep +1/-1 in an ordered map (TreeMap, C++ map) and sweep it on each booking; O(n) per booking is fine for the limits.
  • The Skyline Problem (Hard): a sweep over building edges with a max-heap of live heights (lazy deletion); the output is every x where the max height changes.
  • Minimum Interval to Include Each Query (Hard): sort intervals by start and the queries too; sweep the queries, push intervals that have started into a min-heap by length, pop the ones that have already ended.

From your world

A difference array is how you would count concurrent TCP connections from a log of open and close times: +1 on SYN, -1 on FIN, and the running sum is the number of live connections. Peak concurrency is the maximum of that sum, which is exactly the Meeting Rooms II answer. It is also a refcount: each event moves the count, and you only care when it crosses a limit.
