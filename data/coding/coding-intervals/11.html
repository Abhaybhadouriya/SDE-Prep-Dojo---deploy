Remember this

Revision card

  • Cue: Meetings, bookings, ranges, "merge", "overlap", "minimum rooms / arrows".
  • Insight: Sorting makes overlap local: each interval only has to check the last kept one.
  • State: sort by start (merge) or by end (keep most / fewest removals); a min-heap of ends or +1/-1 events (rooms).
  • Trap: Closed vs half-open ends; on equal times process the end (-1) before the start (+1).
  • Cost: O(n log n) sort, then O(n).

More to remember

  • Overlap test: a.start <= b.end and b.start <= a.end (closed). Decide closed or half-open from the examples.
  • Merge: sort by start, stretch the last block with max. Insert: left, absorb, right, O(n).
  • Intersect two sorted lists: overlap = [max starts, min ends]; advance the one that ends first.
  • Keep the most / remove the fewest / fewest arrows: sort by end.
  • Rooms needed = maximum overlap: min-heap of ends, or +1/-1 sweep with ends first on ties.
  • Count at every point after many range updates: difference array (small range) or sorted events (large range).
