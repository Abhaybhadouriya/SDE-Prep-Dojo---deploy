The problem (in our words)

You are given a string path, an absolute Unix-style path (it starts with '/'). Return its simplified canonical path. The input follows these rules:

  • A single period '.' means the current directory.
  • A double period '..' means the parent directory (one level up).
  • Several consecutive slashes such as '//' or '///' count as a single slash.
  • Any other sequence of periods, such as '...' or '....', is a valid directory or file name.

The canonical path must:

  • start with a single slash '/';
  • separate directories with exactly one slash;
  • not end with a slash, unless it is the root "/";
  • contain no '.' or '..' components (only the real directories on the way from the root to the target).

Signature: String simplifyPath(String path).

  • 1 <= path.length <= 3000
  • path consists of English letters, digits, period '.', slash '/' or '_'.
  • path is a valid absolute Unix path.
