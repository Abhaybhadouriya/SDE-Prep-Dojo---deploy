Common mistakes

Pushing ".." when the stack is empty. Writing if part == ".." and dirs: pop() else: push(part) pushes ".." at the root. The empty-stack ".." must fall into "ignore", not into "push".

Checking characters instead of components. part.startsWith(".") or part[0] == '.' treats .git and ... as special. Compare the whole token.

Returning "" for the root. "/".join([]) is empty; prefix the "/" outside the join, or special-case the empty stack.

Reversing a Java Deque the wrong way. With push/pop the newest name is at the front; build the answer by iterating from the back (descendingIterator) or use addLast/pollLast as our code does.
