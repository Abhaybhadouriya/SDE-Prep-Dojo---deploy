  • Cue: components where ".." cancels the latest directory -> stack.
  • Insight: "" and "." skip; ".." pops if non-empty; anything else is a name and is pushed.
  • State: stack of names; output "/" + join(stack, "/"), empty stack -> "/".
  • Trap: do not push ".." at root; "..." and ".git" are names; compare whole tokens.
  • Cost: O(n) time and space; in C, use the output buffer as the stack.

What happens to the token '...'?

  1. It goes up two directories
  2. It is an ordinary directory name and is pushed
  3. It is skipped
Only '.' and '..' are special; any other token is a name.

What does '..' do at the root (empty stack)?

  1. Error
  2. Nothing: you cannot go above /
  3. Pushes '..'
Pop only if the stack is non-empty.

Why split on '/' and ignore empty tokens?

  1. Several slashes in a row count as one, and they produce empty tokens
  2. It is faster
  3. To drop the root
'//a///b' must become '/a/b'.
