Recognise the pattern

When you see "find which of MANY words / patterns occur" in a grid or a text, think trie over the words, then one search over the input that walks the trie in step.

When you see "path on a grid, each cell once, 4 directions", think backtracking DFS that marks the cell on the way in and restores it on the way out.

Word Search I answers "is this one word on the board?". Running it 3 * 104 times repeats the same work: every word starting with "ca" re-walks the same "c → a" paths. A trie merges those common prefixes, so a board path is walked once, no matter how many words share it.

Taxonomy: Backtracking → board search (variant: word search), also Tries → applied. Pattern lessons: Backtracking · Tries.
