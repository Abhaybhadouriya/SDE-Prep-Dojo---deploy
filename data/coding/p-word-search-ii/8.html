Common mistakes

Stopping when a word is found. A return after reporting "car" loses "care". Report, then keep exploring.

Forgetting to restore the cell. If board[r][c] = ch is skipped on some return path, later starts see a '#' and miss words. Put the restore right after the neighbour loop, with no early return in between.

Pruning before restoring, or pruning a node that still holds a word. Delete the child only when it has no children and its word was already reported.

Duplicates in the answer. Without clearing node.word (or a set), a word traceable from two places is returned twice.

Building the path string at every step. path + ch on each call costs O(L) per step. Store the word on the end node instead.
