Recognise the pattern

Cue: "report nodes grouped by a coordinate, with a specific order inside each group" -> tag every node with its coordinates during any traversal, then sort by a composite key. If the order inside a group were only "top to bottom, left to right", a BFS with a column map would do (LC 314); the extra "same cell -> by value" rule is what makes a sort the clean answer.
