Common mistakes

Sorting each column only by value. Example 3 then returns [[1],[0,5]]. The rule is row first, value only as a tie-break inside one cell. (The top-voted community post exists purely to clarify this sentence of the statement.)

Using LC 314's BFS order for ties. In 314, same-cell nodes are listed left to right; in 987 they are listed by value. Example 2: BFS gives [10, 8, 7]; the answer is [10, 7, 8].

Plain DFS without row tracking. DFS visits a deep left node before a shallow right node of the same column; without the row in the key, column order is wrong.

Storing values in a set per cell. Duplicate values in the same cell must both appear.
