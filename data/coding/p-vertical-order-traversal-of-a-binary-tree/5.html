Example 2, [10,4,12,1,8,7,15]. A pre-order DFS records one triple per node; then one sort and one grouping pass.

  1. Start at the root with (row 0, col 0). Record the triple (col, row, val) = (0, 0, 10).
  2. Go left: row + 1, col - 1. Node 4 is at (1, -1): record (-1, 1, 4).
  3. Left again: node 1 at (2, -2). Record (-2, 2, 1).
  4. Back at 4, go right: col goes back up to 0. Node 8 at (2, 0): record (0, 2, 8).
  5. Back at the root, go right: node 12 at (1, 1). Record (1, 1, 12).
  6. 12's left child 7: (2, 0) - the same cell as 8, although it lives in the other subtree. Record (0, 2, 7).
  7. Last node 15 at (2, 2). Seven triples, in DFS order (any traversal order works, the sort fixes it).
  8. One sort by (col, row, val). Column 0 now reads (0,0,10), (0,2,7), (0,2,8): row decides 10 first; inside the shared cell the value puts 7 before 8.
  9. Walk the sorted list and start a new inner list whenever col changes. Answer [[1],[4],[10,7,8],[12],[15]].
