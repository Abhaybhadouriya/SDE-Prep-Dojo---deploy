Move 1: the dummy head

Many list operations have one ugly case: the node you change is the head itself. Removing the head, inserting before the head, or building a brand-new list all need "if this is the first node, update head, else update prev.next". A dummy head (also called a sentinel) removes that branch: you create one extra node in front, so every real node, including the first, now has a node before it.

Use a dummy whenever the head may change: removing elements, removing the n-th from the end, partitioning, merging, adding two numbers digit by digit, reversing a sub-range, or reversing in k-groups. When you build an output list, pair the dummy with a tail pointer: append with tail.next = node; tail = node, and the list grows in O(1) per node.

In C++ declare the dummy on the stack (ListNode dummy(0, head);) so it can never leak. In Java, Python and Go a small heap node is fine.
