What a node is, and what it costs

An array keeps its items side by side in one block of memory, so item i is at base + i * size. A linked list scatters its nodes wherever the allocator put them; the only way to reach node 5 is to follow four next pointers.

OperationArraySingly linked list
Read item iO(1)O(i): walk from the head
Insert or delete after a node you holdO(n): shift the restO(1): rewire one or two pointers
Delete a node you hold (no pointer to the one before)n/aO(n) to find the one before; doubly linked: O(1)
Find the middle, or the k-th from the endO(1)O(n), in one pass with two pointers
Cache behaviourgreat (sequential)poor (pointer chasing)

The interview ListNode is always the same tiny struct: val and next. You get the head; you return a head. "In place" means you may rewire next pointers but should not allocate a new node per old node (except in deep-copy problems, where the copies are the answer).

Draw before you code. For any rewiring, draw three or four boxes, write the pointer names over them, and perform each line of your loop on the drawing. Most bugs show up on the drawing in under a minute. Interviewers read this as a strength, not as slowness.
