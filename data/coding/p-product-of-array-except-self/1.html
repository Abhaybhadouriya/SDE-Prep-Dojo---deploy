The problem (in our words)

You get an integer array nums of length n. Build and return an array answer of the same length where answer[i] is the product of every element of nums except nums[i]. Your algorithm must run in O(n) time and must not use the division operation. Every product of a prefix or a suffix of nums, and every answer[i], fits in a 32-bit signed integer.

Signature: int[] productExceptSelf(int[] nums) (LeetCode style).

  • 2 <= nums.length <= 105
  • -30 <= nums[i] <= 30
  • Each answer[i] fits in a 32-bit integer.
  • Follow-up: use O(1) extra space; the output array does not count.

Practice it: LeetCode 238 · GfG Product Array Puzzle

Constraints tell you: n up to 105 rules out the O(n²) double loop; the "no division" rule rules out the total-product trick; the 32-bit guarantee covers prefix and suffix products, which is exactly what the two-pass method stores, so plain int is safe.
