The first example. Left: the matrix (green = '1'). Right: the side table filled row by row. Highlighted = the cell being explained, blue = its three neighbours.

  1. side[r][c] = side length of the largest all-1 square whose bottom-right corner is (r, c). A 0 cell gets 0. In the top row (and left column) a 1 has no room to grow, so it is 1.
  2. Row 1. Cell (1,2) looks at its three neighbours up, left and up-left (blue): all are 1, so a 2x2 square ends here. Cell (1,0) is 1 with no neighbours inside the grid: 1. Cell (1,4): up is 0, so only 1.
  3. Row 2. Cell (2,3): up = 2, left = 2, up-left = 2, so side = 3: a 3x3 block of 1s (outlined in both grids, rows 0-2, columns 1-3). The min is the weakest of the three directions: one short neighbour caps the square.
  4. Row 3. Cell (3,3): up = 3 but left = 1, so the min caps it at 2. The best side seen is 3, and the function returns the area 3 * 3 = 9, not 3.
