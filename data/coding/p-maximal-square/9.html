  • Cue: biggest all-1 square -> side[r][c] = square ending at (r, c) as bottom-right.
  • Rule: '1' -> 1 + min(up, left, up-left); '0' -> 0.
  • Proof: a k-square contains (k-1)-squares at all three; three t-squares + the cell cover a (t+1)-square.
  • Space: one row of n+1, save the old value as diag before each write, reset diag per row.
  • Return: best² (area). Count all squares instead: sum of side values (LC 1277).
for r, c with matrix[r][c] == "1":
    side[r][c] = 1 + min(side[r-1][c], side[r][c-1], side[r-1][c-1])
best = max(best, side[r][c]);  return best * best
