Common mistakes

Undoing after success. If the recursion returns true and you still reset the cell, the board ends up with dots. Return immediately on success; undo only when the child failed.

Forgetting return false after the digit loop. Then a blank with no legal digit is silently left as '.' and the next level carries on as if it were filled.

Wrong box index. It is (r / 3) * 3 + c / 3 with integer division. r / 3 + c / 3 maps different boxes to the same index.

Using a bit shift by the character. 1 << board[r][c] shifts by 49-57 (ASCII). Convert first: board[r][c] - '0'.

Claiming the complexity is O(981). Give it in terms of blanks, O(9m), and say that pruning makes the real tree tiny; the board size is a constant.
