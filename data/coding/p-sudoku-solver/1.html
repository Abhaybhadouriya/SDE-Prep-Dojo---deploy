The problem (in our words)

A 9x9 Sudoku board arrives with some cells blank. Fill every blank in place so that the finished board obeys the three rules:

  1. Every row holds 1-9 with no repeats.
  2. Every column holds 1-9 with no repeats.
  3. Each of the nine 3-by-3 blocks (rows and columns split 0-2, 3-5, 6-8) holds 1-9 with no repeats.

Empty cells are marked with the character '.'. The function returns nothing; the board itself must hold the solution afterwards.

Signature: void solveSudoku(char[][] board).

  • board.length == 9 and board[i].length == 9
  • board[i][j] is a digit '1'-'9' or '.'
  • The input board is guaranteed to have exactly one solution.

Practice it: LeetCode 37 · GfG Solve the Sudoku

Constraints tell you: the board size is fixed, so "complexity" is about the number of blanks m and how hard you prune. Unique solution means you may stop at the first full board. Because the board must be modified in place, the recursion must not undo the final, successful placement.
