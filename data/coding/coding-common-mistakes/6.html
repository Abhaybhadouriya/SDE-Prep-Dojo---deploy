6. Wrong complexity claims

Symptom: "this is O(n) because there is one loop", while the loop body does something linear. Interviewers check this on purpose.

The opposite mistake is just as common: calling a sliding window O(n2) because it has a nested while. Count total work instead: each index enters the window once and leaves it once, so the inner loop runs at most n times in total. That is amortised O(n). Do not forget the space of the recursion stack, the output, and the sort (Python's sort uses O(n) extra memory).
