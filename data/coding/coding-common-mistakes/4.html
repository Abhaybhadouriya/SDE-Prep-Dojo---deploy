4. Mutating the input

Symptom: you mark visited cells by writing '0' into the caller's grid, or sort the input array, and the interviewer asks "what if the caller needs the grid afterwards?" or "what if two threads call this?". Sorting also destroys the original indices that Two Sum asks for.

Fix: ask. "May I modify the input?" is a good question, not a weak one. If yes, say it out loud as a trade-off ("O(1) extra space, but destructive"). If no, keep your own seen array, copy first, or restore the cells before returning. In C++, take const vector<int>& so the compiler holds you to it. To sort and still return indices, sort pairs of (value, index).

Hidden mutations: Python list.sort() versus sorted(); Java Arrays.sort(a) on the parameter; Go append to a slice that has spare capacity writes into the caller's backing array; a default argument def f(x, memo={}) in Python is shared between calls.
