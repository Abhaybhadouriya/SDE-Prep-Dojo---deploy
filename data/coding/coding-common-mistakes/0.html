The story: the pilot's checklist

Explain like I'm 5

Pilots know how to fly. Still, before every take-off they read a checklist out loud: fuel, flaps, doors. Planes rarely crash because the pilot cannot fly. They crash because of a small thing nobody checked.

Coding rounds are the same. Most rejected candidates knew the pattern. They lost the round on a small thing: they started typing before they understood the question, an index went one too far, a number got too big, or they sat in silence for ten minutes. This page is the checklist.

From your world

You already run this checklist in code review. Size calculations go through check_mul_overflow() or kmalloc_array() because n * size can wrap. Kernel stacks are 16 KB on x86-64, so nobody writes unbounded recursion. A function that takes const struct foo * promises not to change its input. The interview versions of these bugs are the same bugs; only the language and the clock are different.
