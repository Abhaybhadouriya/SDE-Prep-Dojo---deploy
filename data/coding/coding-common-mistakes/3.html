3. Integer overflow

Symptom: code is correct on the examples and fails on the hidden test with values near 109. In C and C++ signed overflow is undefined behaviour; in Java and Go it silently wraps; Python has big integers, so the bug only appears when the problem itself says "return 0 if the result does not fit in 32 bits".

Where it hidesExampleFix
Midpoint(lo + hi) / 2 with values or indices up to 231lo + (hi - lo) / 2
Sums of many valuesSum of 105 values up to 109 = 1014; 4Sum target sums64-bit accumulator (long, long long, int64)
ProductsArea w * h, a[i] * a[j], factorials, hash rollingCast before multiplying: (long long)w * h; mod after each step
Building a numberReverse an integer, parse a string to intCheck before the step: r > (MAX - d) / 10
abs and negation-INT_MIN and abs(INT_MIN) overflowWork in negatives, or in 64 bits
Comparatorsreturn a - b; in a Java comparatorInteger.compare(a, b)
