Recognise the pattern

Cue: "circular route" + "running resource must stay >= 0" + "find the start" -> work with net[i] = gas[i] - cost[i] and a running sum that you reset on failure.

Cue 2: "does any start exist?" on a loop -> look at the total. A cycle cannot create resources, so total < 0 means no.

Try a few tiny loops (net values only) and watch what the total says:
