The problem (in our words)

There are n charging pads on a circular route, numbered 0 to n - 1. Pad i gives gas[i] units of charge, and flying from pad i to pad (i + 1) mod n uses cost[i] units. The battery has no upper limit and starts empty at the pad you pick.

Return the index of the starting pad from which you can travel around the full loop once, clockwise, ending back at the start. If no such pad exists, return -1. If a solution exists, it is guaranteed to be unique.

Signature: int canCompleteCircuit(int[] gas, int[] cost) - returns one integer.

  • Constraints:
  • n == gas.length == cost.length
  • 1 <= n <= 10^5
  • 0 <= gas[i], cost[i] <= 10^4
  • The input is built so that the answer, if it exists, is unique.

Practice it: LeetCode 134 - Gas Station · GfG - Gas Station (circular tour)

Constraints tell you: n up to 10^5 rules out trying every start with a full lap (O(n^2) = 10^10 steps). Aim for O(n). The total of all gas - cost is at most 10^5 * 10^4 = 10^9 in absolute value, so a 32-bit int is enough (just).
