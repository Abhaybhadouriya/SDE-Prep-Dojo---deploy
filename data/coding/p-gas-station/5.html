Dry run

Example 1: net = [-1, -1, 2, -3, 5].

  1. i = 0: tank = -1 < 0. Pad 0 cannot even reach pad 1, so start = 1 and the tank resets to 0. total = -1.
  2. i = 1: tank = -1 < 0 again. Pad 1 is dead; start = 2. total = -2.
  3. i = 2: tank = 2. Pad 2 is a live candidate. total = 0.
  4. i = 3: tank = 2 - 3 = -1. Starting at 2 fails at pad 3, and pad 3 alone fails too (it arrives with 0, not 2). Both are dead; start = 4.
  5. i = 4: tank = 5. End of the array. total = 2.
  6. total = 2 >= 0, so the surviving candidate pad 4 is the answer. No second lap is needed.
