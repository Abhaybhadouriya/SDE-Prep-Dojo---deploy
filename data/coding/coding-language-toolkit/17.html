Revision card

  • Cue: you reach for a container mid-problem (map, heap, deque, ordered set) or a number may pass 231.
  • Insight: each language has one default per job; know its name, its missing-key rule and its heap direction cold.
  • State: C++ unordered_map / priority_queue (max) / deque / map; Python dict / heapq (min) / deque / bisect; Java HashMap / PriorityQueue (min) / ArrayDeque / TreeMap; Go map / container/heap / slice / sorted slice.
  • Trap: C++ m[k] inserts; list.pop(0) is O(n); a - b comparators overflow; int products overflow before you widen.
  • Cost: hash O(1) average, heap and ordered map O(log n), sort O(n log n); string + in a loop O(n2) outside CPython.

More to remember

  • Pick one language for all rounds. C++ is the smallest jump from C; Python is the least code.
  • Heaps: C++ max by default; Java, Python min; Go is your Less.
  • Missing keys: C++ [] inserts, Java returns null, Python raises, Go returns zero.
  • Strings are immutable in Java, Python and Go: build with a builder or join.
  • Queues: deque, never pop(0) on a list.
  • Comparators: strict (<, never <=), and Integer.compare, never a - b.
  • Ordered map: C++ map, Java TreeMap, Python bisect / SortedList, Go sorted slice.
  • Widen to 64 bits before multiplying; % and / on negatives differ between Python and the rest.
