Stacks, queues and deques

A stack (last in, first out) powers bracket matching, monotonic stacks and iterative DFS. A queue (first in, first out) powers BFS. A deque (double-ended queue) does both and powers sliding-window maximum and 0-1 BFS.

st := []int{1, 2}
top := st[len(st)-1]
st = st[:len(st)-1] // pop
q := []int{1, 2, 3}
q = append(q, 4)
front := q[0]
q = q[1:] // pop front: O(1), but the array is not freed until q is copied
q = append([]int{0}, q...) // push front: O(n); use a ring buffer if hot
vector<int> st = {1, 2};             // vector as a stack
int top = st.back(); st.pop_back();  // pop_back() returns void
deque<int> q = {1, 2, 3};
q.push_back(4);
int front = q.front(); q.pop_front();
q.push_front(0);
queue<int> bfs; bfs.push(7);         // adapter: push / front / pop
Deque<Integer> st = new ArrayDeque<>();  // use as stack; not legacy Stack
st.push(1); st.push(2);
int top = st.pop();                      // 2
Deque<Integer> q = new ArrayDeque<>(List.of(1, 2, 3));
q.offerLast(4);
int front = q.pollFirst();               // 1
q.offerFirst(0);
Queue<Integer> bfs = new ArrayDeque<>(); // offer / poll / peek
bfs.offer(7);
stack = []
stack.append(1); stack.append(2)
top = stack.pop()                  # 2: list end is O(1)
q = deque([1, 2, 3])
q.append(4)                        # push back
front = q.popleft()                # 1: O(1); list.pop(0) would be O(n)
q.appendleft(0)                    # push front

Two traps: Python list.pop(0) and Java ArrayList.remove(0) shift every element (O(n)), so use a deque for queues. Java's old Stack class is synchronized and legacy; ArrayDeque is the recommended replacement (it rejects null elements). In C++ pop() and pop_back() return void, so read top() or back() first.

The most common deque algorithm in interviews is the monotonic deque for sliding-window maximum: keep indices whose values decrease from front to back, so the front is always the current maximum. Step through it:

  1. i = 0, value 1: nothing smaller at the back, push 0. Window not full yet, no output.
  2. i = 1, value 3: pop index 0 (1) from the back because 3 is at least as big, then push 1. Window not full yet, no output.
  3. i = 2, value -1: nothing smaller at the back, push 2. Window [0..2] max = front = 3.
  4. i = 3, value -3: nothing smaller at the back, push 3. Window [1..3] max = front = 3.
  5. i = 4, value 5: pop index 3 (-3), index 2 (-1), index 1 (3) from the back because 5 is at least as big, then push 4. Window [2..4] max = front = 5.
  6. i = 5, value 3: nothing smaller at the back, push 5. Window [3..5] max = front = 5.
  7. i = 6, value 6: pop index 5 (3), index 4 (5) from the back because 6 is at least as big, then push 6. Window [4..6] max = front = 6.
  8. i = 7, value 7: pop index 6 (6) from the back because 7 is at least as big, then push 7. Window [5..7] max = front = 7. Every index was pushed once and popped at most once: O(n) total.
