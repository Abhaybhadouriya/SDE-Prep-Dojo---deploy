Practice problems

Solve each in your chosen language using the container named; the point is fluency with the API.

  • Two Sum LC 1 Easy - hash map from value to index.
  • Valid Anagram LC 242 Easy - a 26-entry count array instead of a map.
  • Group Anagrams LC 49 Medium - map from a sorted-string key to a list.
  • Valid Parentheses LC 20 Easy - stack plus a small map of pairs.
  • Implement Queue using Stacks LC 232 Easy - two stacks, amortised O(1).
  • Sliding Window Maximum LC 239 Hard - the monotonic deque from the stepper.
  • Kth Largest Element in an Array LC 215 Medium - size-k min-heap in each language.
  • Top K Frequent Words LC 692 Medium - map counts plus a two-key comparator.
  • Merge k Sorted Lists LC 23 Hard - heap of nodes with a custom comparator.
  • Largest Number LC 179 Medium - comparator a + b vs b + a.
  • Merge Intervals LC 56 Medium - sort pairs by start.
  • Time Based Key-Value Store LC 981 Medium - floor lookup: TreeMap / map / bisect.
  • Reverse Integer LC 7 Medium - 32-bit overflow checks without a 64-bit type.
  • LRU Cache LC 146 Medium - hash map plus doubly linked list (Java LinkedHashMap, Python OrderedDict).
