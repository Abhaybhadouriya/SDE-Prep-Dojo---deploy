Quiz

Which of these is a max-heap by default?

  1. Java PriorityQueue
  2. C++ priority_queue
  3. Python heapq
  4. All of them
C++ is max by default; Java and Python are min-heaps.

In C++, what does if (cnt[x] > 0) do when x is not in the unordered_map?

  1. Throws an exception
  2. Returns false without changing the map
  3. Is undefined behaviour
  4. Inserts x with value 0, then evaluates false
operator[] inserts a default value. Use count or find to avoid it.

What is -7 // 2 in Python?

  1. -4
  2. -3
  3. -3.5
  4. 3
Python's floor division rounds toward negative infinity. C, C++, Java and Go truncate toward zero and give -3.

The best Python container for a BFS queue is:

  1. list with pop(0)
  2. heapq
  3. collections.deque with popleft()
  4. set
popleft is O(1); list.pop(0) shifts every element and is O(n).

Why is Integer a = 1000, b = 1000; a == b false in Java?

  1. Integer overflow
  2. == compares object references, and only -128 to 127 are cached
  3. Autoboxing is disabled by default
  4. It is a compile error
Use equals or unbox to int before comparing.

Which language's standard library has no ordered map?

  1. C++
  2. Java
  3. Go
  4. None: all four have one
Go has only hash maps; Python's standard library has only bisect (SortedList is a third-party package).

The monotonic deque for sliding-window maximum runs in O(n) because:

  1. each index is pushed once and popped at most once
  2. the deque never holds more than 2 elements
  3. the window size k is a constant
  4. it sorts the window each step
Aggregate counting: at most n pushes and n pops in total, whatever k is.
