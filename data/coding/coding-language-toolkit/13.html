How to recognise which container you need

  • "Have I seen this before?" / counting / grouping → hash set or hash map.
  • Values in a small fixed range (26 letters, digits) → a plain array of counts, faster and simpler than a map.
  • "Top k", "k closest", "k-th largest" → heap of size k (O(n log k)).
  • "Repeatedly take the smallest / earliest" → min-heap (merge k lists, meeting rooms, Dijkstra).
  • Matching brackets, "next greater element", undo → stack.
  • Level by level, shortest path in an unweighted graph → queue.
  • Max or min of a moving window → monotonic deque.
  • "Largest value ≤ x", bookings, timestamps → ordered map, or binary search on a sorted array if the data is static.
  • Ordering by a rule that compares pairs ("largest number") → custom comparator.
