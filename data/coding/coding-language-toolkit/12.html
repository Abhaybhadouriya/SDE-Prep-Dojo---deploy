When to just write it in C++

If your main language is Go or Python, a few problem types are noticeably easier in C++ (or Java), and it is worth asking whether switching for one round is allowed:

  • An ordered multiset is the natural structure: sliding-window median, "k-th smallest in a moving window", interval booking with floor and ceiling queries. C++ multiset or Java TreeMap does it in a few lines; Go needs a hand-written tree or a two-heap workaround.
  • Heavy use of heaps with custom order in Go: container/heap needs five methods per type. In C++ it is one line.
  • Tight time limits on an online assessment with n up to 10⁶ and nested work: Python's interpreter overhead can time out a solution that is correct and asymptotically fine.
  • Bit manipulation and fixed-width arithmetic: C++ and Go have real unsigned 32 and 64-bit types; Python's unbounded ints need masking with & 0xFFFFFFFF.

The flip side: switching languages mid-loop costs more than it saves if you are not fluent. Decide before the interview, not during it.
