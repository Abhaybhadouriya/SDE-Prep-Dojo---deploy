Ordered maps and sets

A balanced search tree keeps keys sorted with O(log n) insert, delete and search, and answers "largest key ≤ x" (floor) and "smallest key ≥ x" (ceiling). You need it for calendar booking, time-based key-value stores, sliding-window median and "closest value" questions.

keys := []int{10, 20, 30}        // no TreeMap in the standard library:
i := sort.SearchInts(keys, 26)   // keep a sorted slice; first index with keys[i] >= 26
floor := keys[i-1]               // 20 (check i > 0)
keys = append(keys, 0)           // insert 25 at i: O(n) shift
copy(keys[i+1:], keys[i:])
keys[i] = 25
map<int, string> m = {{10, "a"}, {20, "b"}, {30, "c"}};   // red-black tree, O(log n)
auto it = m.upper_bound(26);           // first key > 26  -> 30
int floorKey = prev(it)->first;        // largest key <= 26 -> 20 (check it != begin())
auto ce = m.lower_bound(20);           // first key >= 20 -> 20 (ceiling)
set<int> s = {5, 1, 9};
int smallest = *s.begin(), largest = *s.rbegin();
multiset<int> ms = {3, 3, 4};
ms.erase(ms.find(3));                  // erase ONE copy; ms.erase(3) erases all
TreeMap<Integer, String> m = new TreeMap<>(Map.of(10, "a", 20, "b", 30, "c"));
Integer fl = m.floorKey(26);           // 20: largest key <= 26 (null if none)
Integer ce = m.ceilingKey(26);         // 30: smallest key >= 26
Integer hi = m.higherKey(30);          // null: always null-check
TreeSet<Integer> s = new TreeSet<>(List.of(5, 1, 9));
int smallest = s.first(), largest = s.last();
keys = [10, 20, 30]                # keep a sorted list
bisect.insort(keys, 25)            # O(n) insert (shifts), O(log n) search
i = bisect.bisect_right(keys, 26)  # first index with value > 26
floor = keys[i - 1] if i else None  # 25: largest <= 26
# LeetCode's Python also ships sortedcontainers:
# from sortedcontainers import SortedList  (O(log n) add / remove / index)

This is the biggest language gap. C++ (map, set, multiset with lower_bound / upper_bound) and Java (TreeMap, TreeSet with floorKey, ceilingKey, headMap) are complete. Python's standard library has only bisect over a sorted list (O(log n) search, O(n) insert), though LeetCode's Python environment includes sortedcontainers.SortedList; ask before using it elsewhere. Go has neither, so use a sorted slice with sort.Search or switch strategy (a heap with lazy deletion often replaces a multiset).
