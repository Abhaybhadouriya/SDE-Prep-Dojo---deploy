Which language should you interview in?

Most large companies let you choose any mainstream language for coding rounds; confirm with your recruiter. Pick one and use it for every round. The usual trade-off:

C++JavaPythonGo
Distance from Csmallest: same syntax, pointers, memory modelsimilar syntax, garbage collected, no pointersdifferent syntax, dynamic typesC-like, garbage collected, simple
Lines to writemediummostfewestmedium to many
Built-in containerseverything, incl. ordered map, multiseteverything, incl. TreeMap, TreeSetdict, set, deque, heapq; no sorted map built inslice, map; heap via an interface; no deque, no sorted map
Integer overflowsigned overflow is undefined behaviourwraps silentlynever (unbounded ints)wraps silently
Classic trapmap[k] inserts, comparator must be strict== on boxed Integer, a - b comparator// floors negatives, recursion limit 1,000random map order, heap boilerplate

Advice for a C engineer. If you have not used a high-level language much, C++ is the shortest jump: write the C you know and reach for vector, unordered_map, priority_queue and sort when needed. If you already read Python comfortably, Python lets you write the least code in 45 minutes, and less code means fewer bugs. Use Go or Java if that is what the target team writes and you are fluent; both are fine, they just need more typing. Writing pure C is usually allowed but you would spend ten minutes building a hash map; use C++ as "C with a standard library" instead.
