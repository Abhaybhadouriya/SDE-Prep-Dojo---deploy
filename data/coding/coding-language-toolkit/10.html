Recursion depth and other runtime limits

Python's default recursion limit is 1,000 frames; a recursive DFS over a 10⁴-node path fails with RecursionError. sys.setrecursionlimit raises the limit but not the real C stack, so for deep inputs write the DFS iteratively with an explicit stack. Java threads have a fixed stack (often around 512 KB to 1 MB) and throw StackOverflowError on very deep recursion. C++ uses the process stack (commonly 8 MB on Linux). Go goroutine stacks start small and grow on demand, up to a large limit (1 GB on 64-bit by default), so deep recursion rarely fails in Go. In interviews, mention the depth whenever you recurse on input-sized structures: "recursion depth is O(n); for a skewed tree I'd switch to an explicit stack".
