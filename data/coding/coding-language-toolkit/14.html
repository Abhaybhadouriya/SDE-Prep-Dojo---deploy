Common mistakes

  • Using the wrong heap direction (forgetting C++ is max, Java and Python are min).
  • C++ if (m[key]) inserting keys while iterating over m.
  • Java a - b comparators, == on Integer or String, and int[] as a map key.
  • Python list.pop(0) as a queue, s += ch in a loop, and -7 // 2 giving -4 when C semantics were intended.
  • Go: relying on map iteration order, or forgetting that append may share the backing array (copy before storing a slice in a result).
  • Multiplying two ints before widening to 64 bits.
  • Recursing 10⁵ deep in Python or Java without mentioning the stack.
  • C++ multiset.erase(value) removing every copy when you wanted one (use erase(find(value))).
