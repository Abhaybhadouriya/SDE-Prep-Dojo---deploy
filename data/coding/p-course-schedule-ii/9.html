  • Cue: "b before a" rules + "find an order / is it possible" → topological sort.
  • Insight: take any course with in-degree 0; output shorter than n means a cycle.
  • State: adjacency b → a, indeg[], queue of ready courses, order[].
  • Trap: edge direction ([a, b] is b → a); check len(order) == n; deque not list.
  • Cost: O(V + E) time and space; rescanning brute force O(V · (V + E)).
indeg = count_incoming(graph)
q = deque(v for v in nodes if indeg[v] == 0)
order = []
while q:
    v = q.popleft(); order.append(v)
    for w in graph[v]:
        indeg[w] -= 1
        if indeg[w] == 0: q.append(w)
return order if len(order) == len(nodes) else []
