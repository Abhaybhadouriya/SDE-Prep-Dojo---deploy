The story

Explain like I'm 5

Getting dressed: socks before shoes, shirt before jacket. Write each "before" rule as an arrow. Any item with no arrow pointing at it can be put on now. Put it on, rub out its arrows, and look again. If at some point nothing is free but clothes are left, two rules point at each other ("shoes before socks, socks before shoes") and you can never finish.

From your world

This is how a build system or a kernel module loader orders work. make builds a target once all its dependencies are built; modprobe loads a module after the modules it depends on. systemd's After= and Requires= are edges, and an ordering cycle is reported (and broken) at boot.
