Interview follow-ups

Return the smallest order lexicographically.

Replace the FIFO queue with a min-heap: always take the smallest ready course. O((V + E) log V). A plain queue gives a valid order but not the smallest.

How to answer

Point out that Kahn lets you choose any ready node, so the choice rule decides which valid order you get.

Likely follow-ups
  • Is the order unique? Only if the queue never holds 2+ nodes at once (LC 444).
Each course takes one semester and you can take any number at once. Minimum semesters?

Run Kahn level by level: all courses in the queue now form one semester; count the levels. With course durations, compute finish[a] = max(finish[b]) + time[a] in topo order: the longest path (critical path) in a DAG, LC 2050.

How to answer

Name it "longest path in a DAG via topological order".

Likely follow-ups
  • At most k courses per semester? That becomes NP-hard in general (LC 1494 uses bitmask DP for n ≤ 15).
If there is a cycle, report the courses on it.

Use DFS with three colours and a parent array. When you meet a grey node g from u, walk parents from u back to g: that is the cycle. Kahn alone only tells you which nodes are stuck (on or behind a cycle), not the cycle itself.

How to answer

Explain why the leftover set of Kahn is a superset of the cycle.

Likely follow-ups
  • Fewest edges to delete to break all cycles? Minimum feedback arc set: NP-hard; say so.
Prerequisites arrive one at a time; detect the first one that creates a cycle.

Before adding b → a, check whether a can already reach b (BFS/DFS, O(V + E) per insert). Re-running the full sort each time is the same cost. Incremental topological-order algorithms exist (Pearce-Kelly) but are rarely expected.

How to answer

Give the simple per-insert reachability check, then mention that a maintained order only needs local repair.

Likely follow-ups
  • Package manager install order with version pins?
Kahn or DFS: which would you pick, and why?

Kahn: iterative (no recursion limit with 2000 nodes in Python's default 1000-frame limit), the cycle test is one length check, and levels come for free. DFS: natural when you also need the cycle path or are already doing a DFS.

How to answer

Mention the Python recursion limit concretely: a chain of 2000 courses overflows it unless you raise it.

Likely follow-ups
  • Write the DFS version iteratively.
The dependency graph is huge and spread across services (a build farm).

Run Kahn as an event system: each task keeps a counter of unfinished dependencies; when a task finishes, it decrements its dependants' counters and enqueues those that reach 0 on a work queue. Workers pull from the queue in parallel. This is how CI pipelines and Bazel schedule work.

How to answer

Map indeg to a counter per task and the queue to a distributed work queue; mention idempotent decrements on retries.

Likely follow-ups
  • A worker dies mid-task? Lease and retry; decrements must happen once.
