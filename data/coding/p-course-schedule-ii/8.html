Common mistakes

Reversing the edge. [a, b] means b before a, so the edge is b → a and indeg[a]++. Flipping it produces the reverse order, which fails every non-trivial test.

Forgetting the length check. Returning the order without comparing its length to n returns a partial list for cyclic inputs instead of [].

Two-colour DFS. A plain visited array cannot tell "on the current path" (a cycle) from "finished earlier" (fine). You need three states (white / grey / black).

Using queue.pop(0) in Python. It is O(n) per call, so the loop becomes O(V²). Use collections.deque.

Starting only from course 0. Graphs can be disconnected; seed the queue with every course whose in-degree is 0.
