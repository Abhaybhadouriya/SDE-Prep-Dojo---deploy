Base and Roman conversion

To write n in base b, take n % b as the last digit, set n //= b, repeat, and reverse at the end. Reading is the reverse: value = value * b + digit. Two interview twists:

  • Excel columns (A = 1 ... Z = 26, AA = 27) have no zero digit. Subtract 1 before every % 26: n -= 1; digit = n % 26; n //= 26. Going the other way is ordinary: col = col * 26 + (c - 'A' + 1).
  • Roman numerals: to write them, go greedy over the 13 values M, CM, D, CD, C, XC, L, XL, X, IX, V, IV, I. To read them, subtract a symbol when the next symbol is larger (the I in IV), otherwise add it.
