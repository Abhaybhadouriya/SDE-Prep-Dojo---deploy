Points, lines and rectangles

Interview geometry avoids floating point. Keep everything as integers: squared distances, cross products and reduced fractions.

QuestionInteger-only answer
Which point is closer?Compare x*x + y*y. A square root never changes the order (K Closest Points).
Are A, B, C on one line?cross(A, B, C) == 0. This avoids dividing by zero for vertical lines (Check If It Is a Straight Line).
Same slope for hashing?Reduce (dy, dx) by their gcd and fix the sign (Max Points on a Line).
Do two rectangles overlap?max(x1, x3) < min(x2, x4) and the same for y (Rectangle Overlap). The overlap area is the product of those two gaps when both are positive.
Axis-aligned squares from a point stream?Count points in a hash map. For a query point, every stored point on the same row fixes the side length, and you look up the other two corners (Detect Squares).
