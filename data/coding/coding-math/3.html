GCD, LCM and Euclid

The greatest common divisor of a and b equals the gcd of b and a % b, because any number that divides both a and b also divides the remainder. Repeat until the remainder is 0. Each two steps at least halve the numbers, so it takes O(log min(a, b)) steps.

def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

lcm = a // gcd(a, b) * b      # divide first so the middle value stays small

Where gcd appears in interviews: GCD of Strings (if s + t == t + s, the answer is the prefix of length gcd(len s, len t)); reducing fractions and slopes to a canonical form for hashing (Max Points on a Line); rotating an array in place by cycles (there are gcd(n, k) cycles); and "can you measure exactly z litres with jugs x and y" (yes if z is a multiple of gcd(x, y) and z ≤ x + y).
