Big numbers as strings

When numbers are longer than 64 bits, the input is a string and you do school arithmetic by hand. Every one of these problems is the same loop: walk from the right, keep a carry, and stop when both inputs and the carry are used up.

i, j, carry, out = len(a) - 1, len(b) - 1, 0, []
while i >= 0 or j >= 0 or carry:
    s = carry + (int(a[i]) if i >= 0 else 0) + (int(b[j]) if j >= 0 else 0)
    out.append(str(s % 10)); carry = s // 10          # base 2 for Add Binary
    i -= 1; j -= 1
return "".join(reversed(out))

Fraction to Recurring Decimal is long division: the integer part is num / den, then repeatedly multiply the remainder by 10. Once a remainder repeats, the digits repeat from where that remainder first appeared, so keep a map from remainder to position. Use 64-bit values: -2147483648 / -1 overflows a 32-bit int.
