Fast power (binary exponentiation)

x13 = x8 · x4 · x1, because 13 is 1101 in binary. So walk the bits of the exponent from the bottom. Keep squaring the base (x, x2, x4, x8, ...) and multiply it into the result whenever the current bit is 1.

  1. 13 in binary is 1101, so 313 = 38 · 34 · 31. Start with r = 1, b = 3.
  2. Bit 0 is 1, so multiply it in: r = 3. Square the base: b = 32 = 9.
  3. Bit 1 is 0: 32 is not part of the answer. Do not touch r. Square: b = 34 = 81.
  4. Bit 2 is 1: r = 3 · 81 = 243 (that is 35). Square: b = 38 = 6561.
  5. Bit 3 is 1: r = 243 · 6561 = 1,594,323 = 313. The exponent has no more bits.
  6. 4 rounds instead of 12 multiplications. For e = 1018 that is about 60 rounds instead of 1018. With % m after every multiply, the numbers never grow.
def mod_pow(b, e, m):
    r = 1
    b %= m
    while e:
        if e & 1: r = r * b % m     # this power of two is part of e
        b = b * b % m              # next power: b^2, b^4, b^8 ...
        e >>= 1
    return r
  • Pow(x, n) with a double x: the same loop without % m. For n < 0, use 1/x and -n, held in a 64-bit variable, because -INT_MIN overflows.
  • Modular inverse: for a prime p, a-1 = ap-2 mod p (Fermat's little theorem). This makes nCr mod p and "divide by 2 mod p" possible.
  • Count Good Numbers: the answer is 5even positions · 4odd positions, with n up to 1015, so fast power is required.
  • The same loop raises a matrix to a power, which gives Fibonacci or any linear recurrence in O(log n).
