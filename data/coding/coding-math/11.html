How to recognise a maths problem

Cues. "Return modulo 109+7" -> reduce on every step; a division means a modular inverse. An exponent or n up to 1012-1018 -> fast power, or a formula, never a loop. "Without converting to integer" / inputs longer than 20 digits -> string arithmetic from the right. "32-bit signed", "clamp" -> check overflow before each step. "Number of ways" with a grid or choices and no obstacles -> nCr. "Points", "slope", "same line" -> cross product or a gcd-reduced key. "Random with weights" -> prefix sums + binary search. "Unknown length", "stream", "one pass" + random -> reservoir.
