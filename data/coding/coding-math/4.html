Primes and the sieve

To test one number, trial division up to its square root is enough: if n = a · b with a ≤ b, then a ≤ sqrt(n). To find all primes below n, use the sieve of Eratosthenes: every composite number is crossed out by its smallest prime factor.

  1. Write down 2..30 and assume every number is prime. 1 is not prime.
  2. 2 is prime. Cross out its multiples, starting at 2 x 2 = 4.
  3. 3 is the next number not crossed out, so it is prime. Start at 3 x 3 = 9: smaller multiples like 6 already have a smaller prime factor and are crossed out.
  4. 5 is prime. Start at 25. Every multiple of 5 below 25 (10, 15, 20) was crossed by 2 or 3.
  5. The next prime is 7, and 7 x 7 = 49 > 30, so the outer loop stops at p2 > n. The 10 boxes left are the primes below 31.
is_p = [True] * n; is_p[0] = is_p[1] = False
for p in range(2, int(n ** 0.5) + 1):
    if is_p[p]:
        for m in range(p * p, n, p): is_p[m] = False

The cost is O(n log log n), which is almost linear. Related ideas: store the smallest prime factor instead of a boolean and you can factorise any x ≤ n in O(log x). Factorial trailing zeroes counts factors of 5 (n/5 + n/25 + ...). Bulb Switcher is "which numbers have an odd number of divisors": only perfect squares.
