Explain like I'm 5

A vending machine takes only 2, 3 and 5 rupee coins and you must pay exactly 8. You have as many coins of each kind as you like. Which bags of coins work? {2,2,2,2}, {2,3,3} and {3,5}. The bag {3,3,2} is the same bag as {2,3,3}: the order you drop the coins in does not matter. The trick to never count a bag twice: always drop coins from smallest to largest, and once you move on to a bigger coin, never go back to a smaller one.

From your world

It is a depth-first walk of a search tree with an explicit stack, like walking a directory tree or a page-table hierarchy: push a choice, descend, pop it on the way back. The "start index" is a cursor that only moves forward, which is what turns permutations (ordered) into combinations (unordered), the same way a sorted-key iterator never revisits a smaller key.
