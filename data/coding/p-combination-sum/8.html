Common mistakes

Looping from 0 in every call. You generate [2,3,3], [3,2,3], [3,3,2]: permutations instead of combinations. The loop must start at start.

Recursing with i + 1. That forbids reuse and solves a different problem (each value at most once); [2,2,2,2] disappears.

Storing pick itself. In Java/Python/Go the stored reference keeps changing and ends up empty; store a copy (new ArrayList<>(pick), pick[:], append([]int(nil), pick...)).

Using break without sorting. In [5,2], target 4: 5 > 4 breaks before 2 is tried, losing [2,2].

Go slices sharing a backing array. append(out, pick) stores a slice header that later appends overwrite. Copy first. (Same bug in C if you store a pointer to a reused buffer.)
