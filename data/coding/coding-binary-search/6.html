Searching a 2D matrix

Two different problems hide behind "search a sorted matrix". Read the statement carefully.

Rows continue each other: one flat array

If every row is sorted and each row starts after the previous row ends, the matrix read row by row is one sorted array of length rows * cols. Search indexes 0 to rows * cols - 1 and convert: row = mid / cols, col = mid % cols. O(log(rows * cols)).

Rows and columns sorted separately: the staircase

If rows are sorted and columns are sorted but rows overlap, the flat trick fails. Start at the top-right corner. If the value is too big, the whole column below is bigger still: move left. If it is too small, the whole row to the left is smaller: move down. Every step removes a row or a column, so O(rows + cols). (Bottom-left works too; top-left and bottom-right do not, because both moves go the same direction.)
