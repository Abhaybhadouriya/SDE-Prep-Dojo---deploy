Remember this

Revision card

  • Cue: Sorted or rotated input, "first / last position", O(log n) required, a monotone yes/no over an index.
  • Insight: Every search is "find the first index where a monotone predicate turns true".
  • State: lo, hi and a written invariant: closed [lo, hi] for exact match, half-open [lo, hi) for bounds.
  • Trap: mid overflow (use lo + (hi - lo) / 2); a branch that does not shrink the range loops forever.
  • Cost: O(log n) time, O(1) space.

More to remember

  • State the invariant first; the updates and the return value follow from it.
  • Closed [lo, hi] + while lo <= hi for exact match; half-open [lo, hi) + while lo < hi + hi = mid for bounds.
  • Everything is "first true" of a monotone predicate.
  • mid = lo + (hi - lo) / 2; every branch must shrink the range.
  • Rotated: one half is always sorted. Min: compare with a[hi].
  • Peak: walk uphill. Matrix: flat index or staircase, depending on the statement.
  • "Value at time t": upper_bound(times, t) - 1.
