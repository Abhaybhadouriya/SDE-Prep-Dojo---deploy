Quiz

In the half-open lower-bound template, a[mid] >= x. What is the update?

  1. lo = mid
  2. hi = mid
  3. hi = mid - 1
  4. return mid
mid might be the first value >= x, so it must stay in [lo, hi).

lower_bound([1, 3, 3, 5], 3) and upper_bound([1, 3, 3, 5], 3) are...

  1. 2 and 3
  2. 1 and 2
  3. 1 and 3
  4. 0 and 3
First value >= 3 is at index 1; first value > 3 is 5 at index 3.

To find the minimum of a rotated array with distinct values, compare a[mid] with...

  1. a[lo]
  2. a[mid - 1]
  3. a[hi]
  4. the target
a[mid] > a[hi] means the drop is right of mid; otherwise mid..hi is sorted. a[lo] fails on an unrotated array.

Which loop can run forever?

  1. while lo < hi with lo = mid + 1 / hi = mid
  2. while lo <= hi with lo = mid + 1 / hi = mid - 1
  3. Both of them
  4. while lo < hi with lo = mid / hi = mid - 1 and mid rounded down
On [lo, lo + 1], mid rounded down equals lo, so lo = mid changes nothing.

Rows and columns are sorted, but row 2 starts before row 1 ends. Best approach?

  1. Staircase from the top-right corner
  2. Staircase from the top-left corner
  3. Flat index binary search
  4. Sort the matrix first
The flat trick needs rows that continue each other. From the top-right, each step drops a row or a column.

Records for one key have times [1, 4, 10]. get(key, 7) returns the value at time...

  1. 4
  2. 10
  3. none
  4. 1
upper_bound([1, 4, 10], 7) = 2; minus one = index 1 = time 4.
