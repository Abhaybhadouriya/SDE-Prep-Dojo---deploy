Common mistakes

  • Mixing templates. while lo <= hi with hi = mid loops forever when lo == hi and the predicate is true.
  • Rounding mid the wrong way. lo = mid with mid rounded down stalls on a two-element range. Round up or restructure as "first true".
  • Overflow. (lo + hi) / 2 with large ints, or mid * mid in 32 bits.
  • Returning the wrong pointer. With the half-open template the answer is lo (== hi); check whether it equals n ("none") before you read a[lo].
  • Rotated search with < instead of <=. Use a[lo] <= a[mid]: when lo == mid the left "half" is one element and it is sorted.
  • Assuming Java's Arrays.binarySearch finds the first copy. With duplicates it returns any matching index.
  • Using the flat-matrix trick on a staircase matrix (or the other way round). Check whether each row starts after the previous row ends.
