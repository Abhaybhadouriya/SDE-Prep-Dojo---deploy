DFS with three colours: finish last, place first

The second algorithm comes from depth-first search. Run DFS and record each vertex at the moment it finishes (after all its outgoing edges are explored). A vertex finishes only after everything reachable from it has finished, so in the finish list every vertex appears after all its successors. Reverse that list and every edge points forward.

To detect cycles, a single visited flag is not enough in a directed graph. You need three states:

  • WHITE: never seen.
  • GRAY: entered but not finished; it is on the current recursion path.
  • BLACK: finished; it and everything below it are fully explored and placed.

An edge to a GRAY vertex goes back into the path you are standing on: that is a back edge, and a back edge exists if and only if the graph has a cycle. An edge to a BLACK vertex is harmless; you simply reached an already-finished subgraph by a second route.

  1. dfs(0): paint 0 GRAY. GRAY means "on the current recursion path, not finished yet".
  2. Follow 0 → 1: vertex 1 is WHITE, so recurse and paint it GRAY.
  3. Follow 1 → 3: 3 is WHITE, paint it GRAY. It has no outgoing edges, so it finishes at once: paint it BLACK and append it to the finish list.
  4. Back in 1: no more edges. 1 finishes: BLACK, appended after 3.
  5. Back in 0, follow 0 → 2. From 2, the edge 2 → 3 reaches a BLACK vertex: 3 is already finished, so this is not a cycle. 2 finishes.
  6. 0 finishes last. Reverse the finish list: 0, 2, 1, 3 is a valid order, because every vertex finishes after everything it points to.
  7. Replay with one extra edge 3 → 0. Exploring from 3 meets 0 while 0 is still GRAY: an edge back into the current path closes a loop. That is the only kind of edge that proves a cycle.

Template: DFS topological sort

// 2. DFS three colours: 0 = WHITE (unseen), 1 = GRAY (on path), 2 = BLACK (finished).
func topoDfs(n int, edges [][2]int) []int {
	adj := make([][]int, n)
	for _, e := range edges {
		adj[e[0]] = append(adj[e[0]], e[1])
	}
	color := make([]int, n)
	post := []int{}
	var dfs func(u int) bool
	dfs = func(u int) bool {
		color[u] = 1
		for _, v := range adj[u] {
			if color[v] == 1 { // back edge -> cycle
				return false
			}
			if color[v] == 0 && !dfs(v) {
				return false
			}
		}
		color[u] = 2
		post = append(post, u) // finished after its successors
		return true
	}
	for s := 0; s < n; s++ {
		if color[s] == 0 && !dfs(s) {
			return nil
		}
	}
	for i, j := 0, len(post)-1; i < j; i, j = i+1, j-1 { // reverse finish order
		post[i], post[j] = post[j], post[i]
	}
	return post
}
// 2. DFS three colours: 0 = WHITE (unseen), 1 = GRAY (on path), 2 = BLACK (finished).
bool dfsColour(int u, const vector<vector<int>>& adj, vector<int>& color, vector<int>& post) {
    color[u] = 1;
    for (int v : adj[u]) {
        if (color[v] == 1) return false;                         // back edge -> cycle
        if (color[v] == 0 && !dfsColour(v, adj, color, post)) return false;
    }
    color[u] = 2;
    post.push_back(u);                                           // finished after its successors
    return true;
}
vector<int> topoDfs(int n, const vector<pair<int,int>>& edges) {
    vector<vector<int>> adj(n);
    for (const auto& e : edges) adj[e.first].push_back(e.second);
    vector<int> color(n, 0), post;
    for (int s = 0; s < n; s++)
        if (color[s] == 0 && !dfsColour(s, adj, color, post)) return {};
    reverse(post.begin(), post.end());                           // reverse finish order
    return post;
}

static int[] topoDfs(int n, int[][] edges) {
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    for (int[] e : edges) adj.get(e[0]).add(e[1]);
    int[] color = new int[n];
    List<Integer> post = new ArrayList<>();
    for (int s = 0; s < n; s++)
        if (color[s] == 0 && !dfsColour(s, adj, color, post)) return new int[0];
    int[] order = new int[n];
    for (int i = 0; i < n; i++) order[i] = post.get(n - 1 - i);  // reverse finish order
    return order;
}
# 2. DFS three colours: WHITE = unseen, GRAY = on the current path, BLACK = finished.
def topo_dfs(n, edges):
    """Returns a topological order, or [] if a back edge (cycle) is found."""
    adj = [[] for _ in range(n)]
    for u, v in edges:
        adj[u].append(v)
    WHITE, GRAY, BLACK = 0, 1, 2
    color = [WHITE] * n
    post = []                      # vertices in the order they finish

    def dfs(u):
        color[u] = GRAY
        for v in adj[u]:
            if color[v] == GRAY:   # back edge: v is still on the path -> cycle
                return False
            if color[v] == WHITE and not dfs(v):
                return False
        color[u] = BLACK
        post.append(u)             # u finishes after everything it points to
        return True

    for s in range(n):
        if color[s] == WHITE and not dfs(s):
            return []
    return post[::-1]              # reverse finish order = topological order

Recursion depth. A chain of 105 courses means a recursion 105 deep. Python's default limit is 1000, and a C++ or Java thread stack can overflow too. In an interview, say this out loud and either prefer Kahn's (no recursion at all) or convert the DFS to an explicit stack that stores (vertex, next-edge-index).
