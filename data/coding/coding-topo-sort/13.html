Course Schedule gives pairs [a, b] meaning "take b before a". Which edge do you add?

  1. it does not matter for the order
  2. b → a
  3. both directions
  4. a → b
The edge goes from what comes first to what comes later: b → a. Reversing it keeps cycle detection correct but reverses the order.

Kahn's algorithm finishes with 8 of 10 vertices output. What can you conclude?

  1. The graph contains a directed cycle
  2. The graph is disconnected
  3. Two vertices were isolated
  4. The 8-vertex order is valid and the other 2 can go anywhere
Leftover vertices never reached in-degree 0, which only happens when they wait on a cycle. Isolated and disconnected vertices start at in-degree 0 and are output normally.

During a three-colour DFS you follow an edge u → v and v is BLACK. What does that mean?

  1. v must be re-explored
  2. A cycle through u and v
  3. Nothing special: v was finished via another route
  4. The graph is not a DAG
Only an edge to a GRAY vertex (still on the current path) is a back edge. BLACK vertices are already placed after everything they reach.

Alien words: "abc", "ab". What should the function return?

  1. "abc"
  2. any permutation of a, b, c
  3. "cba"
  4. "" because the list is invalid
A word can never sort after its own proper prefix in any alphabet, so no order is consistent with this list.

How do you get the lexicographically smallest topological order?

  1. Sort the vertices first, then run DFS
  2. Reverse the DFS order
  3. Run Kahn's with a min-heap as the ready set
  4. Run Kahn's with a stack
At each step the smallest ready vertex is chosen, which is exactly what a min-heap gives. Cost O(V log V + E).

Tasks have durations and unlimited parallelism. The minimum total time equals:

  1. the sum of all durations
  2. the heaviest path in the DAG (the critical path)
  3. the number of Kahn levels
  4. the largest single duration
Each task can start as soon as its prerequisites finish, so the finish time is the longest weighted chain. Kahn levels count rounds only when every task takes the same time.
