Variants that test whether you really understand it

Once the basic template is fluent, interviewers change one requirement. Each row below is a small edit to Kahn's algorithm or the DFS, not a new algorithm.

TwistEditProblem
Is the order unique?Unique iff the ready queue never holds two vertices at once (any two ready vertices could swap). Equivalent: consecutive vertices of the order are joined by an edge.Sequence Reconstruction
Smallest order (lexicographic)Replace the queue with a min-heap: O(V log V + E).common follow-up on Course Schedule II
Which vertices can never reach a cycle?Reverse every edge and run Kahn from the terminal vertices, or three-colour DFS and keep the vertices that finish BLACK without meeting GRAY.Find Eventual Safe States
Items with string names and "supplies"Map names to ids; supplies start with in-degree 0; output only recipes that reach 0.Find All Possible Recipes
Reachability queries "is u a prerequisite of v?"Propagate ancestor sets (bitsets for n ≤ 100) in topological order, then each query is O(1).Course Schedule IV
Best value along any pathDP in topological order with dp[v][colour]; a cycle means answer -1.Largest Color Value
Two independent orderingsTopo-sort the row constraints and the column constraints separately, then place each number at (its row rank, its column rank).Build a Matrix With Conditions
Orders inside groups and between groupsTwo-level topological sort: one over groups, one over items in each group.Sort Items by Groups
Undirected tree, find the centreKahn-style leaf peeling on degrees (not in-degrees): strip all leaves round by round; the last 1 or 2 vertices are the answer.Minimum Height Trees
Grid with "strictly increasing" movesThe moves form a DAG implicitly (values strictly increase, so no cycle). Memoised DFS or Kahn on out-degrees.Longest Increasing Path in a Matrix
At most k courses per semesterNot a greedy topological sort: picking which ready courses to take is NP-hard in general, so the intended solution is bitmask DP over subsets (n ≤ 15).Parallel Courses II

The last row is a trap worth knowing: interviewers sometimes ask it to see whether you will claim "just take the k courses with the longest remaining chain". That greedy fails on some inputs; say so, and reach for the small-n bitmask DP.

For union-based alternatives to cycle detection in undirected graphs (where three colours are overkill), see Union-find. For the BFS and DFS basics this page builds on, see Graphs: topological sort.
