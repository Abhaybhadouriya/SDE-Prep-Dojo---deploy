Kahn's algorithm: peel off what is ready

Kahn's algorithm is the morning-dressing method, written down. The in-degree of a vertex is the number of edges coming into it: how many things it still waits on.

  1. Count in-degrees for every vertex from the edge list.
  2. Queue every vertex with in-degree 0. They have no prerequisites and can go first.
  3. Pop a vertex, append it to the answer, and "delete" its outgoing edges by decrementing the in-degree of each neighbour. Any neighbour that drops to 0 is now ready: push it.
  4. When the queue is empty, if you output all V vertices the order is valid. If you output fewer, the leftovers are stuck on a cycle.

Click through it on a six-vertex DAG. Orange vertices are in the queue, teal ones are already output, and the table on the right is the in-degree array.

  1. Count in-degrees: how many prerequisites each vertex still waits on. 0 and 1 wait on nothing, so both go in the queue.
  2. Pop 0 and output it. Its only edge is 0 → 2, so 2 now waits on one thing instead of two.
  3. Pop 1. Edge 1 → 2 drops 2 to 0 and edge 1 → 3 drops 3 to 0: both are ready and join the queue.
  4. Pop 2. Edge 2 → 4 drops 4 from 2 to 1. Vertex 4 still waits on 3, so it stays out of the queue.
  5. Pop 3. Edge 3 → 4 drops 4 to 0: its last prerequisite is done, so it joins the queue.
  6. Pop 4. Edge 4 → 5 drops 5 to 0 and it joins the queue.
  7. Pop 5. The queue is empty and we output 6 of 6 vertices, so there is no cycle. Had a cycle existed, its vertices would never reach in-degree 0 and the count would come up short.

Why it is correct: a vertex enters the queue only when all its predecessors have been output, so every edge points forward in the result. Why the count detects cycles: no vertex on a cycle can reach in-degree 0 before another vertex on the same cycle is output, which never happens, so the whole cycle (and everything downstream of it) is left behind.

// 1. Kahn's algorithm (BFS on in-degrees). edges[i] = {u, v}: "u must come before v".
func topoKahn(n int, edges [][2]int) []int {
	adj := make([][]int, n)
	indeg := make([]int, n)
	for _, e := range edges {
		adj[e[0]] = append(adj[e[0]], e[1])
		indeg[e[1]]++
	}
	q := []int{}
	for i := 0; i < n; i++ {
		if indeg[i] == 0 { // no prerequisites
			q = append(q, i)
		}
	}
	order := []int{}
	for head := 0; head < len(q); head++ { // slice + head index = FIFO queue
		u := q[head]
		order = append(order, u)
		for _, v := range adj[u] {
			indeg[v]--
			if indeg[v] == 0 { // v's last prerequisite just finished
				q = append(q, v)
			}
		}
	}
	if len(order) != n {
		return nil // leftovers are stuck on a cycle
	}
	return order
}
// 1. Kahn's algorithm (BFS on in-degrees). edges: {u, v} = "u must come before v".
vector<int> topoKahn(int n, const vector<pair<int,int>>& edges) {
    vector<vector<int>> adj(n);
    vector<int> indeg(n, 0);
    for (const auto& e : edges) { adj[e.first].push_back(e.second); indeg[e.second]++; }
    queue<int> q;
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.push(i);   // no prerequisites
    vector<int> order;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : adj[u])
            if (--indeg[v] == 0) q.push(v);     // v's last prerequisite just finished
    }
    if ((int)order.size() != n) order.clear();  // leftovers are stuck on a cycle
    return order;
}

static int[] topoKahn(int n, int[][] edges) {
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    int[] indeg = new int[n];
    for (int[] e : edges) { adj.get(e[0]).add(e[1]); indeg[e[1]]++; }
    ArrayDeque<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.add(i);   // no prerequisites
    int[] order = new int[n];
    int k = 0;
    while (!q.isEmpty()) {
        int u = q.poll();
        order[k++] = u;
        for (int v : adj.get(u))
            if (--indeg[v] == 0) q.add(v);   // v's last prerequisite just finished
    }
    return k == n ? order : new int[0];      // leftovers are stuck on a cycle
}
# 1. Kahn's algorithm (BFS on in-degrees). edges: (u, v) = "u must come before v".
def topo_kahn(n, edges):
    """Returns a topological order of 0..n-1, or [] if the graph has a cycle."""
    adj = [[] for _ in range(n)]
    indeg = [0] * n
    for u, v in edges:
        adj[u].append(v)
        indeg[v] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)   # everything with no prerequisite
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in adj[u]:
            indeg[v] -= 1          # u is done: v waits on one fewer thing
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []   # leftovers are stuck on a cycle

Queue or stack? Kahn's works with any container for the ready set: a FIFO queue, a stack, even a plain list. The output differs but is always valid. Swap in a min-heap and you get the lexicographically smallest order; keep it as a FIFO and process it level by level and you get "rounds" (semesters, build waves).
