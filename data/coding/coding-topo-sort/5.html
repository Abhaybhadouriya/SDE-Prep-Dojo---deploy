Alien Dictionary: deriving the graph yourself

The problem (restated). An unknown language uses lowercase English letters in some unknown order. You receive a list of words from its dictionary, sorted by that language's rules. Return a string containing every letter that appears in the words, in an order consistent with the list. If no order is consistent, return "". If several are, return any. Limits: up to 100 words, each up to 100 lowercase letters. References: LeetCode 269 (Premium), GfG: Alien Dictionary, TUF G-26.

This is the topological sort question interviewers love, because the graph is hidden. The step that matters is building the edges:

  1. Every letter in any word is a vertex, even if it never gets an edge (it can go anywhere in the answer).
  2. Compare only adjacent words. Sorting is transitive, so word 1 vs word 3 adds nothing that 1 vs 2 and 2 vs 3 do not already imply.
  3. In each pair, find the first position where the letters differ. That pair of letters gives exactly one edge, a → b. Everything after the first difference tells you nothing, exactly like comparing "cat" and "dog" in English tells you only c < d.
  4. If there is no difference and the first word is longer (like "abc" then "ab"), the list is invalid: a word can never sort after its own prefix. Return "" immediately.
  5. Run Kahn. If fewer letters come out than exist, the edges contain a cycle (the list contradicts itself): return "".
// 3. Alien dictionary: derive "a before b" from adjacent sorted words, then Kahn.
func alienOrder(words []string) string {
	adj := map[byte]map[byte]bool{}
	indeg := map[byte]int{}
	letters := []byte{} // first-appearance order keeps the output deterministic
	for _, w := range words {
		for i := 0; i < len(w); i++ {
			if _, ok := adj[w[i]]; !ok {
				adj[w[i]] = map[byte]bool{}
				indeg[w[i]] = 0
				letters = append(letters, w[i])
			}
		}
	}
	for i := 0; i+1 < len(words); i++ {
		a, b := words[i], words[i+1]
		k := 0
		for k < len(a) && k < len(b) && a[k] == b[k] {
			k++
		}
		if k < len(a) && k < len(b) { // first difference only
			if !adj[a[k]][b[k]] {
				adj[a[k]][b[k]] = true
				indeg[b[k]]++
			}
		} else if len(a) > len(b) {
			return "" // "abc" before "ab": invalid
		}
	}
	q := []byte{}
	for _, c := range letters {
		if indeg[c] == 0 {
			q = append(q, c)
		}
	}
	out := []byte{}
	for head := 0; head < len(q); head++ {
		c := q[head]
		out = append(out, c)
		for d := range adj[c] {
			indeg[d]--
			if indeg[d] == 0 {
				q = append(q, d)
			}
		}
	}
	if len(out) != len(letters) {
		return ""
	}
	return string(out)
}
// 3. Alien dictionary: derive "a before b" from adjacent sorted words, then Kahn.
string alienOrder(const vector<string>& words) {
    map<char, set<char>> adj;
    map<char, int> indeg;
    for (const auto& w : words) for (char c : w) { adj[c]; indeg[c]; }
    for (size_t i = 0; i + 1 < words.size(); i++) {
        const string& a = words[i]; const string& b = words[i + 1];
        size_t k = 0;
        while (k < a.size() && k < b.size() && a[k] == b[k]) k++;
        if (k < a.size() && k < b.size()) {                      // first difference only
            if (adj[a[k]].insert(b[k]).second) indeg[b[k]]++;
        } else if (a.size() > b.size()) {
            return "";                                           // "abc" before "ab": invalid
        }
    }
    queue<char> q;
    for (const auto& p : indeg) if (p.second == 0) q.push(p.first);
    string out;
    while (!q.empty()) {
        char c = q.front(); q.pop();
        out += c;
        for (char d : adj[c]) if (--indeg[d] == 0) q.push(d);
    }
    return out.size() == adj.size() ? out : "";
}
// 3. Alien dictionary: derive "a before b" from adjacent sorted words, then Kahn.
static String alienOrder(String[] words) {
    Map<Character, Set<Character>> adj = new LinkedHashMap<>();
    Map<Character, Integer> indeg = new HashMap<>();
    for (String w : words) for (char c : w.toCharArray()) { adj.putIfAbsent(c, new HashSet<>()); indeg.putIfAbsent(c, 0); }
    for (int i = 0; i + 1 < words.length; i++) {
        String a = words[i], b = words[i + 1];
        int k = 0;
        while (k < a.length() && k < b.length() && a.charAt(k) == b.charAt(k)) k++;
        if (k < a.length() && k < b.length()) {                 // first difference only
            if (adj.get(a.charAt(k)).add(b.charAt(k))) indeg.merge(b.charAt(k), 1, Integer::sum);
        } else if (a.length() > b.length()) {
            return "";                                          // "abc" before "ab": invalid
        }
    }
    ArrayDeque<Character> q = new ArrayDeque<>();
    for (char c : adj.keySet()) if (indeg.get(c) == 0) q.add(c);
    StringBuilder out = new StringBuilder();
    while (!q.isEmpty()) {
        char c = q.poll();
        out.append(c);
        for (char d : adj.get(c)) if (indeg.merge(d, -1, Integer::sum) == 0) q.add(d);
    }
    return out.length() == adj.size() ? out.toString() : "";
}
# 3. Alien dictionary: derive "a before b" edges from adjacent sorted words, then Kahn.
def alien_order(words):
    """Returns one valid letter order, or "" if the word list is inconsistent."""
    adj = {ch: set() for w in words for ch in w}
    indeg = {ch: 0 for ch in adj}
    for w1, w2 in zip(words, words[1:]):
        for a, b in zip(w1, w2):
            if a != b:                       # first difference is the only information
                if b not in adj[a]:
                    adj[a].add(b)
                    indeg[b] += 1
                break
        else:
            if len(w1) > len(w2):            # "abc" before "ab" can never be sorted
                return ""
    q = deque(ch for ch in adj if indeg[ch] == 0)
    out = []
    while q:
        a = q.popleft()
        out.append(a)
        for b in adj[a]:
            indeg[b] -= 1
            if indeg[b] == 0:
                q.append(b)
    return "".join(out) if len(out) == len(adj) else ""

Complexity. Building edges reads every character at most once across all adjacent comparisons: O(C) where C is the total length of all words. The graph has at most 26 vertices and at most one new edge per adjacent pair (at most 26 x 25 distinct ones), so the sort is O(1) in the alphabet size. Total O(C) time, O(1) extra space for the alphabet-sized graph.

Duplicate edges. If "a before b" is derived twice and you increment in-degree twice but only store the edge once (or store it twice and decrement once), the in-degrees go wrong and valid inputs come out as "cycle". Use a set for each letter's neighbours and increment in-degree only when the edge is new, as the templates do.
