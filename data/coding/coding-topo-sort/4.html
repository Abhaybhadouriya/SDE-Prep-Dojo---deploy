Course Schedule I and II

The problem (restated). A university offers n modules numbered 0 to n - 1. You get a list of pairs [a, b], each meaning "module b must be completed before module a". Part I asks: return true if a student can complete every module, else false. Part II asks: return any order in which all modules can be completed, or an empty list if none exists. Limits: 1 ≤ n ≤ 2000; Part I has at most 5000 pairs, Part II up to n(n - 1); all pairs are distinct. References: LeetCode 207, LeetCode 210.

Solution. Build the edge b → a for each pair (careful with the direction) and run the Kahn template. Part I returns len(order) == n; Part II returns the order itself. That is the entire answer; what earns the "strong hire" is how you talk about it:

  • Name the reduction: "this is cycle detection in a directed graph; an order exists iff there is no cycle".
  • State the direction of the edge and why.
  • Give O(V + E) time and space, and mention that isolated modules (no pairs at all) are in-degree 0 and come out naturally.
  • Offer the DFS alternative in one sentence and why you did not pick it (recursion depth).
# Course Schedule II, using topo_kahn from the template above
def find_order(n, prerequisites):
    return topo_kahn(n, [(b, a) for a, b in prerequisites])   # [a, b] means b before a

Common follow-up: "Now tell me which modules form the cycle." With Kahn, the leftovers include the cycle plus everything stuck behind it. To print the exact cycle, run the three-colour DFS, keep a parent array, and when you meet a GRAY vertex v from u, walk parent from u back to v.
