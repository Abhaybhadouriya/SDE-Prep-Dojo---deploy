Common mistakes

  • Edge direction reversed. [a, b] in Course Schedule means b → a. Reversed edges give a reversed order. Say the direction out loud before coding.
  • Using a visited flag for directed cycle detection. It reports false cycles on diamonds. Use GRAY / BLACK, or Kahn's count.
  • Forgetting isolated vertices. A vertex with no edges must still appear in the order. Initialise the in-degree array for all n vertices (and, in Alien Dictionary, every letter of every word).
  • Counting duplicate edges in in-degree but not in the adjacency (or the other way round). In-degree and the adjacency list must describe the same multiset of edges.
  • Missing the prefix rule in Alien Dictionary ("abc" before "ab" is invalid), or comparing beyond the first differing letter.
  • Returning a partial order when there is a cycle. Kahn's leftovers mean "impossible": return empty, -1 or false as the problem asks.
  • Deep recursion on 105 vertices in Python or on a small thread stack. Prefer Kahn's, or make the DFS iterative.
  • Assuming greedy works with a capacity limit (k per semester). It does not in general; see Parallel Courses II.
