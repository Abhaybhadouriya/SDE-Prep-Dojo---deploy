Revision card

  • Cue: Prerequisites, build order, "can all tasks finish", alien dictionary, longest path in a DAG.
  • Insight: An order exists exactly when the directed graph has no cycle.
  • State: in-degree[] and a queue of in-degree 0 (Kahn), or three colours with a reversed finish order (DFS).
  • Trap: Wrong edge direction; fewer than V vertices output means a cycle; alien dictionary prefix rule.
  • Cost: O(V + E) time and space.

More to remember

  • An order exists iff the directed graph has no cycle. "Can we finish?" = "is it a DAG?".
  • Kahn's: queue in-degree 0, pop, decrement, push new zeros; fewer than V output means a cycle.
  • DFS: reverse the finish order; an edge to a GRAY vertex is a cycle; BLACK is harmless.
  • Levels = rounds; min-heap = smallest order; queue size 1 always = unique order.
  • Any DP on a DAG runs in topological order (critical path, longest path, counting paths).
  • Alien Dictionary: adjacent pairs only, first difference only, prefix rule, every letter is a vertex.
  • Always state the edge direction before coding.
