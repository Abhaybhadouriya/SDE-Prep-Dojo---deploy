Revision card

  • Cue: "replace consistently, no two map to one" → bijection: two maps.
  • Insight: forward map = function, reverse map = injective; both together = isomorphic.
  • State: sToT[256], tToS[256] (or first-occurrence patterns as a canonical key).
  • Trap: one-way map accepts "ab"/"cc"; tables sized 26 break on ASCII.
  • Cost: O(n) time, O(1) space; all pairs O(n²).
fwd, rev = {}, {}
for a, b in zip(xs, ys):
    if fwd.setdefault(a, b) != b or rev.setdefault(b, a) != a:
        return False
return True
