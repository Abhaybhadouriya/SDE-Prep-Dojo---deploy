The story

Explain like I'm 5

You and a friend invent a secret code: every letter of your message is swapped for a code letter. The rules are simple. The same letter must always become the same code letter, and two different letters may never share one code letter, or your friend could not decode the message. Given a message and a supposed coded version, check if one consistent code like that exists.

From your world

It is a NAT table that must be one-to-one. Each inside address maps to one outside address, and no outside address may be handed to two inside hosts, or return traffic cannot be translated back. You keep both directions of the table for exactly that reason, and this solution does the same: a forward table and a reverse table, checked on every packet (character).
