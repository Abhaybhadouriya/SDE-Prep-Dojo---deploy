Recognise the pattern

When you see "replace characters consistently" or "same structure / same pattern", think bijection check with two maps, or equivalently a canonical key: the pattern of first occurrences.

A one-way map only proves "s determines t". Isomorphism also needs "t determines s", so check both directions (or run the one-way check twice, s vs t and t vs s).
