Interview follow-ups

Can you do it with a single map?

Yes: keep s → t and a set of characters of t already used. When a is new, b must not be in the used set; when a is known, its image must be b. Or run the one-way check twice: f(s, t) and f(t, s).

How to answer

Name the two properties (function, injective) and show which structure enforces each.

Likely follow-ups
  • Which is faster? The same O(n); arrays beat hash maps on constants.
Given many strings, group the ones that are isomorphic to each other.

Isomorphism is an equivalence relation, so give each string its first-occurrence pattern as a canonical key ("tool" → 0,1,1,3) and group with a hash map, like Group Anagrams. O(total length).

How to answer

Switch from the pairwise check to the canonical-key view; pairwise checks would cost O(N²).

Likely follow-ups
  • Key encoding? Join the numbers with a separator, or map index k to a character.
The strings are Unicode, not ASCII.

Use hash maps keyed by code point instead of 256-slot arrays, and iterate code points (Java codePoints(), Go range over the string), not UTF-16 units or bytes. Space becomes O(distinct characters).

How to answer

Mention that byte-wise iteration breaks multi-byte characters into pieces.

Likely follow-ups
  • Lengths in characters differ even when byte lengths match? Compare code-point counts first.
You may apply the replacement to s only one character class at a time, in place, using one spare symbol. Can s still be turned into t?

That is LC 1153 (String Transforms Into Another String, Premium). A forward map must still be a function, but it need not be injective; the catch is cycles (a → b, b → a), which need a spare unused character. So: the forward map is consistent, and either s == t or t uses fewer than 26 distinct letters.

How to answer

Contrast with this problem: here the reverse table is needed; there the reverse condition is replaced by "a free letter exists".

Likely follow-ups
  • Minimum number of conversions? Count mapped edges plus one per cycle.
Return the mapping itself, or the first index where it breaks.

The forward table at the end is the mapping. For the first failing index, return i at the point where the loop returns false. Nothing else changes.

How to answer

Show that the one-pass version gives this for free, unlike the pattern-comparison version.

Likely follow-ups
  • Minimum characters to change in t to make it isomorphic? Becomes an assignment (matching) problem.
