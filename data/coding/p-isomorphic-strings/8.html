Common mistakes

Checking only one direction. A single map s → t accepts "ab" / "cc". Either keep the reverse map or run the check twice with the arguments swapped.

Sizing the table for 26 letters. The input is any ASCII; "p.p" indexes the table with '.' and a 26-slot array overflows (or a c - 'a' index goes negative).

Indexing with a signed char in C/C++. A byte ≥ 128 becomes a negative index. Convert to unsigned char first.

Using 0 as "unset" while storing raw indices. In the last-seen variant, index 0 is a real position; store i + 1 (or start the tables at -1).

Comparing letter counts or sets. "aba" and "aab" have identical counts (two of one letter, one of another), but their patterns are 0 1 0 and 0 0 2: not isomorphic. Positions matter.
