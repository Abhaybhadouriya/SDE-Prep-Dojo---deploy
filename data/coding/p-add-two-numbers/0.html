The story

Explain like I'm 5

Two odometers have been read out digit by digit, starting with the rightmost wheel. To add the readings, you do what you learned in school: add the two ones digits, write down the last digit and carry the 1 if the sum is 10 or more, then move to the tens. Because the digits arrive ones-first, you never need to know how long the numbers are.

From your world

Multi-precision integers work the same way: the kernel's MPI code (lib/crypto/mpi) stores a big number as an array of machine words, least significant word first, and adds two of them word by word with a carry, which is what the CPU's add-with-carry instruction (ADC on x86) does in hardware. Here each "word" is one decimal digit in a list node.
