The problem (in our words)

Two non-negative integers are given as non-empty singly linked lists, one decimal digit per node, with the digits stored in reverse order (the head holds the ones digit). Return their sum as a linked list in the same reverse-digit format.

Neither number has leading zeros, except the number 0 itself (a single node with 0).

Signature: ListNode addTwoNumbers(ListNode l1, ListNode l2), where ListNode has an integer val and a next pointer.

Constraints

  • Each list has between 1 and 100 nodes.
  • 0 <= Node.val <= 9
  • The numbers have no leading zeros, except the number 0 itself.

Practice it: LeetCode 2 - Add Two Numbers · TUF - Add two numbers (reverse order) · GfG - Add Number Linked Lists (forward-order variant)

Constraints tell you: up to 100 digits means the numbers can be about 10^100, far beyond 64-bit (about 1.8·10^19). Converting to long fails; you must add digit by digit. The lists may have different lengths, and the result can be one digit longer than the longer input.
