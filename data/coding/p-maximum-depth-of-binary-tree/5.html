Example 1: [7, 3, 9, null, null, 4, 8, null, null, null, 2], recursive version. Blue = the call being worked on, green = finished, with its returned depth beside it.

  1. Call on the root 7. Before it can answer, it asks its left child.
  2. Node 3 has two empty children (0 and 0), so it returns 1.
  3. Back at 7, ask the right child 9, which first asks its left child 4: a leaf, returns 1.
  4. 9 now asks 8. Its left child is empty (0); its right child 2 is a leaf and returns 1.
  5. 8 returns 1 + max(0, 1) = 2.
  6. 9 returns 1 + max(1, 2) = 3.
  7. 7 returns 1 + max(1, 3) = 4. That is the answer.
