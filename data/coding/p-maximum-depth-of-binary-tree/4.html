Approaches: brute -> better -> optimal

Hint 1

If someone told you the depth of the left subtree and of the right subtree, what is the depth of the whole tree?

1. Brute force - measure every root-to-leaf path

Idea: walk down from the root carrying the current depth; at every leaf, update the best. This is a top-down DFS, and it is already O(n), so the "ladder" here is about style and stack safety rather than speed.

def walk(node, d):
    if node is None: return
    if not node.left and not node.right:
        best[0] = max(best[0], d)
    walk(node.left, d + 1); walk(node.right, d + 1)
O(n)time
O(h)stack

What is wasted: nothing in time, but it needs a shared variable. Returning the answer from each call is cleaner and generalises to diameter, balance and path-sum problems. -> rung 2.

2. Optimal (recursive) - bottom-up post-order DFS

def max_depth(node):
    if node is None:
        return 0
    return 1 + max(max_depth(node.left), max_depth(node.right))
  1. Base case. An empty subtree contributes 0 levels.
  2. Combine. A node's depth is itself (1) plus the deeper child's depth.
  3. Post-order. Both children are answered before the parent, so each node is computed once from finished results.
O(n)time
O(h)stack, h = height (log n balanced, n skewed)

Why it works: induction on the tree size. Empty tree: 0 is correct. Otherwise any root-to-leaf path is the root plus a root-to-leaf path in one subtree, so the longest one has length 1 + max(depth(L), depth(R)), and by induction the recursive calls return those depths correctly.

3. Optimal (iterative) - BFS, count the levels

q, levels = deque([root]), 0
while q:
    levels += 1
    for _ in range(len(q)):          # exactly one level
        node = q.popleft()
        if node.left: q.append(node.left)
        if node.right: q.append(node.right)

Idea: process the tree level by level; the number of levels is the depth. No recursion, so a 10^4-node chain is safe in any language. The queue holds at most one level (up to n/2 nodes for a full tree), so the space is O(width).

O(n)time
O(w)queue, w = max level width
Proof (optional) - the BFS count

BFS removes all nodes at depth d before any node at depth d + 1 enters the processing loop, because a node at depth d + 1 is added only by its parent at depth d. So iteration k of the outer loop processes exactly the nodes at depth k, and the loop runs once per non-empty level, which is the maximum depth.
