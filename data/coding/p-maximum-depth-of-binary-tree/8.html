Common mistakes

  • Returning 1 for a null node (or starting the count at 1 for the empty tree). Every depth comes out one too high, and [] returns 1.
  • Counting edges instead of nodes. This problem counts nodes; some textbooks define height in edges (leaf = 0). Ask, then be consistent.
  • Using min logic from Minimum Depth by habit (or the other way round). For minimum depth, a node with one child must not take the empty side's 0.
  • BFS without the level-size loop. Incrementing the counter once per popped node counts nodes, not levels.
  • Python recursion on a deep chain. The default limit (1,000) raises RecursionError on a skewed 10^4 tree; use BFS or sys.setrecursionlimit.
