  • Cue: a whole-tree number built from the subtrees' numbers (height, size, sum).
  • Insight: depth(node) = 1 + max(depth(left), depth(right)); depth(null) = 0.
  • State: nothing shared; each call returns its subtree's depth (BFS: queue + level count).
  • Trap: null returns 0, not 1; count levels, not popped nodes; deep chain in Python.
  • Cost: O(n) time; O(h) stack (DFS) or O(width) queue (BFS).
def solve(node):
    if node is None:
        return BASE              # 0 for height, size, sum
    l, r = solve(node.left), solve(node.right)
    return combine(node, l, r)   # 1 + max(l, r) here

depth(node) for a non-null node is?

  1. depth(left) + depth(right)
  2. 1 + max(depth(left), depth(right))
  3. max(depth(left), depth(right))
The deepest path goes through the taller child, plus the node itself.

What is depth(null)?

  1. 0
  2. 1
  3. -1
An empty tree has depth 0, so a leaf gets 1 + max(0, 0) = 1.

A BFS version returns what?

  1. The number of nodes
  2. The number of levels it processes
