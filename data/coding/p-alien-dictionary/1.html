The problem (in our words)

A new language uses the lowercase English letters, but in an order you do not know. You get a list of strings words that is claimed to be sorted in lexicographic order of that language (compare letter by letter; at the first different letter the smaller letter decides; if one word runs out first, the shorter word is smaller).

  • Return a string with every distinct letter that appears in words, exactly once each, ordered by the new language's rules.
  • If no order of the letters can make words sorted (the claim is false), return the empty string "".
  • If several orders work, return any one of them.

Signature: string alienOrder(vector<string>& words).

Constraints:

  • 1 <= words.length <= 100
  • 1 <= words[i].length <= 100
  • words[i] contains only lowercase English letters.

Practice it: LeetCode 269 Premium · GfG Alien Dictionary (free; you also get the alphabet size k) · TUF article

Constraints tell you: at most 100 x 100 = 104 characters and only 26 letters, so the graph has at most 26 nodes and 99 useful edges. Any linear pass over the words plus a 26 x 26 adjacency matrix is fine; the hard part is getting the rules right, not speed.
