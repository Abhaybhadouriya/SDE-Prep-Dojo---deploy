Dry run

Example 1, ["wx","wz","xw","zw","zy"]. Steps 1-4 read the adjacent pairs (grey = equal prefix, blue/green = the first difference), steps 5-9 run Kahn's queue (amber = in the queue, blue = output).

  1. Pair 0/1: "wx" vs "wz". The first letters match; the first DIFFERENT letters are x and z, so x comes before z. Edge x -> z.
  2. Pair 1/2: "wz" vs "xw". They differ at once: w before x. Edge w -> x. Letters after the first difference tell us nothing.
  3. Pair 2/3: "xw" vs "zw": x before z again. The edge already exists, so in-degree is NOT increased twice (that is why we dedupe).
  4. Pair 3/4: "zw" vs "zy": w before y. Edge w -> y. All rules are known: in-degree w 0, x 1, y 1, z 1.
  5. Kahn starts: every letter with in-degree 0 goes into the queue. Only w has no rule before it: queue [w].
  6. Pop w and output it. Remove its edges: x and y drop to in-degree 0, so both join the queue: [x, y]. Output: w.
  7. Pop x, output wx. Its edge to z goes: z reaches 0 and joins the queue: [y, z].
  8. Pop y, output wxy. y has no outgoing rules. Queue: [z].
  9. Pop z, output wxyz. The queue is empty and 4 letters were output = 4 distinct letters, so there is no cycle. Answer: "wxyz" ("wyxz" or "wxzy" would also be accepted).
