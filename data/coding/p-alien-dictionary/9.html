  • Cue: sorted list in an unknown order -> derive letter rules -> topological sort.
  • Insight: only ADJACENT words, only their FIRST different letter, give a rule.
  • State: letters seen, edge[26][26], indeg[26], queue of in-degree-0 letters.
  • Trap: longer word before its prefix -> ""; dedupe edges; keep rule-free letters.
  • Cost: O(total chars + 26²) time, O(26²) space; cycle = output shorter than letters.
indeg = {v: 0 for v in nodes}; [indeg[v] += 1 for each edge u -> v]
q = deque(v for v in nodes if indeg[v] == 0); out = []
while q:
    u = q.popleft(); out.append(u)
    for v in adj[u]:
        indeg[v] -= 1
        if indeg[v] == 0: q.append(v)
return out if len(out) == len(nodes) else CYCLE

Quick quiz

What rule does the pair "bca" before "bad" give?

  1. c before a, and a before d
  2. b before b
  3. c before a only
  4. none
They first differ at index 1 (c vs a). Everything after the first difference is unconstrained.

words = ["mn", "m"]. What is the answer?

  1. "" (impossible)
  2. "mn"
  3. "nm"
  4. any order of m, n
"m" is a prefix of "mn" and must come first; the list is not sorted under any alphabet.

Kahn's loop ends having output 3 letters, but 5 distinct letters appear. What does that mean?

  1. Two letters had no rules
  2. The queue was seeded wrongly
  3. The answer is the 3 letters
  4. The remaining letters are on (or behind) a cycle: return ""
Letters with no rules have in-degree 0 and are output at once. Only a cycle keeps in-degrees above zero forever.
