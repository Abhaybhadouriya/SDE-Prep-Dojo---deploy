Common mistakes

Missing the prefix rule. ["abc","ab"] creates no edge, so the graph looks fine and you return "abc". You must return "" the moment a longer word precedes its own prefix.

Comparing past the first difference. "ba" vs "ac" only says b<a. Adding a<c as well invents a rule and can create a fake cycle.

Counting duplicate edges twice in the in-degree. If the neighbour set ignores the second x -> z but indeg[z] still goes up twice, z ends at in-degree 1 after x is output, never enters the queue, and a valid input is reported as a cycle. Use a set or a boolean matrix and increase the count only when the edge is new.

Dropping letters with no rules. Building the node set from edges only loses letters like the free ones in ["cab"]. Collect letters from every word first.

Forgetting the cycle check. Kahn's loop ends quietly on a cycle; compare the output length with the number of distinct letters.
