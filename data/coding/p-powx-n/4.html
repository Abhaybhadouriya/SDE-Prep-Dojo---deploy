Approaches: brute → better → optimal

Hint 1

If you knew xn/2, how would you get xn with one or two multiplications?

Hint 2

For negative n, what is xn in terms of 1/x?

Hint 3

What is -n when n = -2147483648 in a 32-bit int?

1. Brute force - multiply n times

Idea: result = 1; repeat |n| times: result *= x; take 1/result if n < 0.

O(|n|)time
O(1)space

What is wasted: x8 is computed as eight separate products, although x4 · x4 gives it in one. With |n| ≈ 2·109 this times out. -> rung 2.

2. Better - recursive halving

Idea: xn = (xn/2)² when n is even, and x · (xn/2)² when n is odd. Compute the half once and reuse it.

def pw(x, n):              # n >= 0
    if n == 0: return 1.0
    half = pw(x, n // 2)   # compute ONCE, do not call pw twice
    return half * half if n % 2 == 0 else half * half * x
O(log |n|)time
O(log |n|)stack

What is wasted: about 31 stack frames. Not a real problem, but the iterative version is just as short and uses O(1) space, and interviewers often ask for it. -> rung 3.

3. Optimal - iterative square and multiply

e = abs(n); x = 1 / x if n < 0 else x
while e:
    if e & 1: result *= x
    x *= x; e >>= 1
  1. Handle the sign once. x-k = (1/x)k, so flip x and work with a non-negative exponent. In C++/Java, copy n into a long first.
  2. Keep the invariant result · basee = xn. It is true at the start (1 · xn) and each step preserves it.
  3. Odd e: move one factor into result. result · base · basee-1 is the same value.
  4. Then halve e and square base. basee = (base²)e/2 for even e.
  5. Stop at e = 0. The invariant says result = xn.
O(log |n|)time
O(1)space

Why it works: the loop reads the exponent bit by bit from the lowest. At the k-th turn, base holds x2k, exactly the factor that bit k stands for. Multiplying it in only when bit k is 1 builds xsum of chosen 2k = xn.

Proof (optional)

Invariant P: result · basee = x0n0 (x0, n0 after the sign flip). Initially result = 1, base = x0, e = n0: true. If e is odd, result' = result · base and e - 1 is even, so result' · basee-1 = result · basee. Then base' = base², e' = ⌊e/2⌋ and base'e' = base2⌊e/2⌋, which equals the remaining basee (e even at that point). e halves every turn, so the loop ends after ⌊log₂ e⌋ + 1 turns, with e = 0 and result = x0n0.
