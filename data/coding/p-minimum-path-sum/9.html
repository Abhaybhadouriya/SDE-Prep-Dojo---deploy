Revision card

  • Cue: grid, corner to corner, only right/down moves, min cost -> 2-D grid DP.
  • Insight: last move came from above or left: best = cell + min(above, left).
  • State: one array best[c]; before overwrite it is "above", best[c-1] is "left".
  • Trap: top row / left column have one neighbour; include both end cells.
  • Cost: O(m·n) time, O(n) space (O(1) if the grid may be overwritten).
best = [INF] * cols; best[0] = 0          # virtual "above" of row 0
for r in range(rows):
    for c in range(cols):
        left = best[c-1] if c else INF
        best[c] = grid[r][c] + min(best[c], left)   # count -> +, max -> max
return best[-1]
