Recognise the pattern

Cue: a grid, a start corner and an end corner, and moves that only go right/down (never back) -> 2-D DP over cells. "Count the routes" -> add the two neighbours (Unique Paths). "Cheapest / most valuable route" -> take min / max of the two neighbours and add the cell. Moves in all four directions -> no DP order exists; use BFS / Dijkstra instead.
