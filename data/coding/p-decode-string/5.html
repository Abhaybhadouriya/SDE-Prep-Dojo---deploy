Dry run

The stack version on "2[x3[y]]", one character per step.

  1. Digit: k = 0·10 + 2 = 2. Nothing else happens; a count is only used when its [ arrives.
  2. [ opens a frame: push (outer text so far = "", count = 2), then reset cur = "", k = 0. The frame remembers what to glue in front and how many copies to make.
  3. Letter: append to cur, which always belongs to the innermost open bracket. cur = "x".
  4. Digit: k = 3.
  5. [: push ("x", 3). The "x" is safe on the stack while we decode the inner group.
  6. Letter: cur = "y".
  7. ] closes the inner group: pop ("x", 3), cur = "x" + "y"·3 = "xyyy". The inner result became part of its parent's text.
  8. ]: pop ("", 2), cur = "" + "xyyy"·2. The stack is empty and the input is done: return "xyyyxyyy".
