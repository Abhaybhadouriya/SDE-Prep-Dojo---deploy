Common mistakes

Reading only one digit. k = int(c) turns "10[d]" into "0[d]" after "1". Accumulate k = k*10 + digit.

Not resetting k after [. The next count would start from the old one: "2[a3[b]]" reads the inner count as 23.

Forgetting the outer text. Pushing only the count and on ] doing cur = cur * k drops the "x" in "2[x3[y]]". The frame must hold the text before the bracket.

Quadratic string building. s += c in a loop is O(n²) in Java (String) and can be in Python; use StringBuilder / a list and join.
