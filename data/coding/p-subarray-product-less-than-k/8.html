Common mistakes

Forgetting k <= 1. With k = 1 and a guard-free loop, left runs past right (the empty window still has product 1), and you read out of bounds or count negative lengths. Either return 0 early or add left <= right to the loop.

Using > instead of >= in the shrink test. The product must be strictly less than k; a window with product exactly k is invalid.

Adding 1 per valid window instead of the window length. That counts only the longest subarray per end, not all of them.

Float division in Python (/=). It turns prod into a float; products of large values then lose precision. Use //=.

Applying this to arrays with zeros or negatives. The window relies on "longer means larger product". A 0 or a negative value breaks that; see the follow-ups.
