Technique: count subarrays whose aggregate stays under a limit by adding, for each right end, the size of the longest valid window ending there.

Closest match: LC 2302 Count Subarrays With Score Less Than K Hard

  • Same: positive values, count subarrays whose aggregate is strictly below k, window grows right and shrinks left.
  • Different: the aggregate is (sum of the subarray) × (its length), and k goes up to 10^15.
  • So: keep a running sum, test sum * (right - left + 1) >= k, use 64-bit math. The counting line is identical.

How to recognise it:

  • "Number of contiguous subarrays" + a limit on a sum or product + all values positive.
  • If values can be zero or negative, switch to prefix sums with a hash map (sums) or a different argument (products).

Extra practice (competitive programming, optional - not interview questions): Codeforces 279B Books (rating 1400: the same positive-values window, maximise the length of a window with sum <= t).

Practice order:

  1. Warm-up: 209 (shortest window with sum >= target).
  2. This problem: write the window and say the counting argument out loud.
  3. Then 2302 (same count, new aggregate) and 2962 (count "at least" windows by adding left).
