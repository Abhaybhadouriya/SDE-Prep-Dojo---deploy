Dry run

The 4 x 4 example. Red cells are the ones swapped in that step; green marks the diagonal (it never moves during the transpose). The faded grid on the right is the target.

  1. Start. The dashed line is the main diagonal (r == c). The target on the right is where every value must end up: old[r][c] goes to new[c][n-1-r].
  2. Transpose, r = 0: swap (0,1) <-> (1,0), (0,2) <-> (2,0), (0,3) <-> (3,0). Only cells above the diagonal start a swap, so each pair is swapped once. Row 0 was 3, 8, 1, 6; it now holds the old column 0.
  3. Transpose, r = 1: swap (1,2) <-> (2,1), (1,3) <-> (3,1). Only cells above the diagonal start a swap, so each pair is swapped once.
  4. Transpose, r = 2: swap (2,3) <-> (3,2). Only cells above the diagonal start a swap, so each pair is swapped once.
  5. Transpose done: row r now holds old column r (top to bottom). Compare with the target: each row has the right values, but in reverse order.
  6. Reverse row 0 with two pointers: 3, 2, 7, 11 becomes 11, 7, 2, 3.
  7. Reverse row 1 with two pointers: 8, 0, 5, 13 becomes 13, 5, 0, 8.
  8. Reverse row 2 with two pointers: 1, 9, 12, 14 becomes 14, 12, 9, 1.
  9. Reverse row 3. Every row now matches the target: [11,7,2,3] [13,5,0,8] [14,12,9,1] [15,10,4,6]. Done in place, O(1) extra memory.
