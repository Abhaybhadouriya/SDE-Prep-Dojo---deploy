Common mistakes

Transposing with c from 0. Each pair is swapped twice and the matrix comes back unchanged. Start the inner loop at r + 1.

Reversing the wrong thing. Transpose + reverse the row order gives an anticlockwise turn. Check one corner: the top-left value must end top-right.

Python: matrix = [list(r) for r in zip(*matrix[::-1])]. It rebinds the local name and builds a new grid, so the caller's matrix is unchanged. Use matrix[:] = ... if you go that way, and say it is not O(1) space.

Four-way swap in the wrong direction. Moving top -> right -> bottom -> left with one temp needs the assignments written backwards (top <- left first). Writing them forwards overwrites values you still need.
