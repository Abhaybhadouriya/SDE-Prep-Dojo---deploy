The problem (in our words)

A thumbnail service stores each image as an n x n grid of integers matrix. Turn the image 90 degrees clockwise.

The turn must be done in place: change matrix itself and do not allocate another n x n grid to build the result. The function returns nothing.

Signature: void rotate(int[][] matrix).

Constraints

  • n == matrix.length == matrix[i].length
  • 1 <= n <= 20
  • -1000 <= matrix[i][j] <= 1000

Practice it: LeetCode 48 - Rotate Image · GfG - Rotate a matrix by 90° clockwise without extra space · TUF - Rotate matrix 90° clockwise

Constraints tell you: n ≤ 20 means at most 400 cells, so speed is never the issue; the whole question is the in-place rule and getting the index mapping right. The matrix is square, which is what makes in place possible (a non-square turn changes the shape).
