Approaches: brute -> better -> optimal

Hint 1

Where does the top row end up after the turn? Write the new position of (r, c).

Hint 2

Can you get (r, c) -> (c, n-1-r) as two steps that each only swap pairs?

1. Brute force - copy into a new grid (breaks the rule)

Idea: out[c][n-1-r] = matrix[r][c] for every cell, then copy out back.

O(n²)time
O(n²)extra space

Why mention it: it is the reference the other methods are checked against (our test drivers do exactly that), and it pins down the mapping. But it allocates the second grid the problem forbids.

2. In place - rotate four cells at a time, layer by layer

Idea: the four cells (r, c), (c, n-1-r), (n-1-r, n-1-c), (n-1-c, r) form a cycle under the turn. For each ring (layer) from the outside in, and each offset along its top edge, move the four values round with one temporary.

for r in range(n // 2):
    for c in range(r, n - 1 - r):
        tmp = m[r][c]                         # top
        m[r][c] = m[n - 1 - c][r]             # top    <- left
        m[n - 1 - c][r] = m[n - 1 - r][n - 1 - c]   # left   <- bottom
        m[n - 1 - r][n - 1 - c] = m[c][n - 1 - r]   # bottom <- right
        m[c][n - 1 - r] = tmp                 # right  <- top
O(n²)time, each cell written once
O(1)extra space

Trade-off: optimal, but four index expressions must all be right, and the inner range (r .. n-2-r) is easy to get off by one. Fine if you are confident; otherwise rung 3.

3. Optimal (and easiest to get right) - transpose, then reverse rows

  1. Transpose: for every r and every c > r, swap m[r][c] and m[c][r]. Now (r, c) holds what was at (c, r).
  2. Reverse each row: two pointers per row, or the language's in-place reverse.
  3. Check on a corner: the top-left value goes to (0, 0) after the transpose, then to (0, n-1) after the reverse: top-right. Correct for clockwise.
O(n²)time (about 2 swaps per cell)
O(1)extra space

Why it works: the transpose maps (r, c) -> (c, r); reversing row c maps column r to column n-1-r. Together: (r, c) -> (c, n-1-r), which is exactly the clockwise mapping. Each step is a permutation made of disjoint swaps (pairs across the diagonal; pairs mirrored in a row), so it needs only one temporary at a time. The c > r bound makes each diagonal pair swap once; swapping all pairs would swap every pair twice and leave the matrix unchanged.
