Rotate anticlockwise, or by 180°.

Anticlockwise: transpose, then reverse the order of the rows (or reverse each row first, then transpose). 180°: reverse the row order and reverse each row (no transpose). Each is O(n²) time, O(1) space.

How to answer

Write the mapping, then pick the two reflections; check one corner.

Likely follow-ups
  • Rotate by k × 90°: do k mod 4 turns, or pick the matching mapping.
Do it with each cell written exactly once.

Use the four-way cycles (rung 2): for each layer r in 0..n/2-1 and offset c in r..n-2-r, rotate the four cells with one temporary. n² writes in total versus about 2n² for transpose + reverse, which matters for slow memory (flash, a framebuffer over a bus).

How to answer

Name the four positions of one cycle and the loop ranges; dry-run a 2 x 2.

Likely follow-ups
  • Which version is more cache-friendly? (Transpose touches columns; the row reverses are sequential.)
The matrix is m x n (not square). Rotate it.

The result is n x m, so it cannot overwrite the input in its 2D shape; allocate out[c][m-1-r] = in[r][c]. If it is stored as one flat array of m·n values, an in-place rotation is possible by following permutation cycles (like in-place transposition), but it is a research-level detail; say that the simple answer allocates.

How to answer

Point out that "in place" depends on the square shape.

Likely follow-ups
  • Rotating the Box (LC 1861) is the rectangular version with a twist.
The image is huge and rotated very often. What would you do?

Often you do not move data at all: keep a rotation count and map reads through the formula (a view). When you must materialise it, rotate in cache-sized square blocks (tile the transpose) so both the read and write sides stay in cache; GPUs and image libraries do exactly this.

How to answer

Separate "logical rotation" (index mapping) from "physical rotation" (copying), then talk about locality.

Likely follow-ups
  • Why is a naive transpose slow for big n? (Column-wise writes miss the cache on every element.)
Check if one matrix is a rotation of another.

Compare the target with the four mappings directly: identity, (c, n-1-r), (n-1-r, n-1-c), (n-1-c, r). One O(n²) pass that keeps four boolean flags, no rotation needed (LC 1886).

How to answer

Reuse the mappings instead of rotating four times.
