Dry run

Example 1. Bars are the meetings in start order; the blue one is the meeting being placed and the dashed line its start time. Below: the two sorted arrays with the pointers s (current start) and e (earliest end not yet used).

  1. Starts [0,3,4,6,9,13], ends [5,8,9,12,14,16], sorted on their own. rooms = 0, e = 0 points at the earliest end.
  2. Start 0 < end 5: no meeting has finished, so a new room. rooms = 1.
  3. Start 3 < end 5: still nothing finished. New room, rooms = 2.
  4. Start 4 < end 5: three meetings overlap at time 4. rooms = 3.
  5. Start 6 >= end 5: the meeting that ends at 5 is over; reuse its room. e = 1, rooms stays 3.
  6. Start 9 >= end 8: reuse a room again (half-open: ending at 8 frees the room before 9). e = 2.
  7. Start 13 >= end 9: reuse. e = 3. All starts are done: the answer is 3 rooms.
