Common mistakes

Using <= for the overlap test. A meeting ending at 8 and one starting at 8 do not clash here. The heap test is busy[0] <= s (free), the sweep test is s < ends[e] (busy). GfG's Minimum Platforms uses inclusive times, so there the signs flip.

Popping every finished room from the heap. Using while busy[0] <= s: pop is fine for the count only if you track the maximum size; returning len(busy) at the end would then be wrong. Pop at most one per meeting, or keep a running max.

Sorting the heap version by end time. Meetings must be processed in start order; sorting by end assigns a later-starting meeting before an earlier one and over-counts.

Merging intervals first. Merging [0,8] and [3,5] into one block hides the fact that they need two rooms. Merge (LC 56) and rooms (this problem) are different questions.
