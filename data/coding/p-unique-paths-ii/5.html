Dry run

The first example: a 3 x 4 grid with one rock at row 1, column 2. Green = final counts, highlighted = the row being written, red = rock. The orange strip is the single array the code actually keeps.

  1. Row 0: the start gets 1, and every free cell in the top row can only be entered from the left, so each copies its left neighbour: 1 1 1 1. In the code this whole grid is one array ways of length 4 that is overwritten row by row.
  2. Row 1: ways[c] += ways[c - 1] means old value (from above) + new left value. c=0: 1 (only from above). c=1: 1 + 1 = 2. c=2 is a rock, set to 0: no path may pass through it. c=3: 1 (above) + 0 (the rock on its left) = 1.
  3. Row 2: c=0: 1. c=1: 2 + 1 = 3. c=2: 0 (above is the rock) + 3 = 3. c=3: 1 + 3 = 4. Each cell only ever needed the cell above it (still in the array) and the cell to its left (just updated).
  4. The bottom-right value is the answer: 4 paths. Check by hand: of the C(5,2) = 10 obstacle-free paths, the 6 that pass through (1,2) are gone; 10 - 6 = 4.
