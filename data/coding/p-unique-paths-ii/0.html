The story

Explain like I'm 5

A delivery robot in a warehouse can only roll east or south. Some floor tiles hold crates. How many different routes reach the loading dock in the far corner? Stand on any tile and ask: "how did I get here?" Either from the tile above or from the tile on the left. So the number of routes to this tile is the routes to the one above plus the routes to the one on the left. A crate tile has zero routes.

This is the obstacle version of Unique Paths. Without rocks there is a closed form (a binomial coefficient); with rocks you need the DP, and the interviewer watches how you handle the first row, the first column and a blocked start.

From your world

Think of counting forwarding paths in a directed acyclic mesh where links only go "down" or "right": the path count into a router is the sum of the counts into its upstream neighbours, and a failed router contributes nothing. Processing nodes in topological order (here: row by row) is what makes one pass enough.
