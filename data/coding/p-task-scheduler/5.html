Dry run

Example 2, [P,P,P,Q,Q,Q,R] with n = 3, building the frame. Dashed cells are the frame; idle cells are red.

  1. Count: P = 3, Q = 3, R = 1. The top count is 3, so the schedule has 3 rows. Each row is n + 1 = 4 slots wide: one task plus the 3-slot cooldown.
  2. Put the most frequent task, P, at slot 0 of every row. Two copies of P are now exactly 4 slots apart, the minimum the cooldown allows.
  3. Q ties with P (3 copies), so it also needs a cell in the last row. Put it at slot 1 of every row. width = 2 labels reach the last row.
  4. R has 1 copy: drop it into any free cell of an earlier row (row 1, slot 2). Fewer copies than rows means it never needs the last row.
  5. Free cells left in rows 1-2 become idle slots. The last row stops after the width = 2 cells (nothing has to wait after it).
  6. Total = (top - 1) x (n + 1) + width = 2 x 4 + 2 = 10 = 7 tasks + 3 idles. Since 10 > 7 tasks, the frame is the answer.
