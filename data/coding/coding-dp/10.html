Revision card

  • Cue: "Number of ways", "min / max cost", "can you reach", and a brute force that repeats subproblems.
  • Insight: Solve each subproblem once: optimal substructure plus overlapping subproblems.
  • State: One exact state sentence, a transition from the last decision, base cases and a fill order.
  • Trap: A vague state sentence; filling in an order that reads unfilled cells; the answer is not always the last cell.
  • Cost: States x work per transition; often O(n) or O(n m), rolled down to O(1) or one row.

More to remember

  • DP = optimal substructure + overlapping subproblems. Solve each subproblem once.
  • The recipe: state (one exact sentence), transition (the last decision), base cases, fill order and where the answer is.
  • Cost = number of states x work per transition.
  • Path to the final answer: recursion → memo → table → rolling variables.
  • 1D: climbing stairs (sum), house robber (take or skip), decode ways (count valid last pieces).
  • Grid: from up and left; one row is enough unless you need the diagonal.
  • Spot the family (knapsack, LIS, two strings, interval, state machine, tree, bitmask) and the state shape follows.
