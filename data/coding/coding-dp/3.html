1D DP: house robber and decode ways

House robber: take or skip

The problem: a row of houses holds amounts of cash; robbing two adjacent houses sets off an alarm; return the most you can take. A greedy "take the biggest" fails: in [2, 7, 9, 3, 1] the best is 2 + 9 + 1 = 12, not 7 + 3 = 10.

  • State: best[i] = most money from houses 0..i.
  • Transition (last decision = house i): skip it, getting best[i-1]; or rob it, so house i-1 must be skipped, getting best[i-2] + nums[i]. best[i] = max(best[i-1], best[i-2] + nums[i]).
  • Base: best[-1] = best[-2] = 0 (no houses, no money), which the two variables handle.
  • Answer: best[n-1]. O(n) time, O(1) space.
  1. The state is "best money from houses 0..i"; the transition looks at the last house: skip it or rob it.
  2. best[0]: with one house, rob it. Missing entries before index 0 count as 0.
  3. best[1]: robbing house 1 alone (7) beats keeping house 0 (2). Orange cells are the two inputs being read.
  4. best[2]: robbing house 2 adds 9 to best[0] = 2, giving 11, which beats 7.
  5. best[3]: robbing house 3 gives best[1] + 3 = 10, less than skipping it (11).
  6. best[4]: best[2] + 1 = 12 beats 11. Only the last two cells were ever read, so two variables suffice.
  7. To list the houses, walk back through the full table and see which side of each max won. This needs the table, not just two variables.
func rob(nums []int) int {
    take, skip := 0, 0 // best with / without robbing the last house
    for _, x := range nums {
        take, skip = skip+x, max(take, skip)
    }
    return max(take, skip)
}
int rob(const vector<int>& nums) {
    int take = 0, skip = 0;                          // best with / without robbing the last house
    for (int x : nums) { int t = skip + x; skip = max(take, skip); take = t; }
    return max(take, skip);
}
static int rob(int[] nums) {
    int take = 0, skip = 0;
    for (int x : nums) { int t = skip + x; skip = Math.max(take, skip); take = t; }
    return Math.max(take, skip);
}
def rob(nums):
    take, skip = 0, 0                             # best ending with / without robbing the last house
    for x in nums:
        take, skip = skip + x, max(take, skip)
    return max(take, skip)

The two-variable version above names them take (best if the last house is robbed) and skip (best if it is not): a tiny state machine, which is the same idea the stock-trading DPs use with "holding" and "not holding". House Robber II (houses in a circle) runs this twice: once on houses 0..n-2, once on 1..n-1, because the first and last cannot both be robbed. Delete and Earn becomes house robber after you sum points by value and lay the values out in a line.

Decode ways: counting with validity rules

The problem: letters A-Z are encoded as "1".."26"; given a digit string, count the ways to decode it. "226" decodes as 2-2-6 (BBF), 22-6 (VF) or 2-26 (BZ): 3 ways.

  • State: dp[i] = number of ways to decode the first i characters (so dp[0] = 1: the empty prefix has one decoding, the empty one).
  • Transition (last decision = how the last letter was formed): the last character alone, if it is 1-9: add dp[i-1]. The last two characters together, if they form 10-26: add dp[i-2].
  • Answer: dp[n]. O(n) time, O(1) space with two variables.
func numDecodings(s string) int {
    if len(s) == 0 {
        return 0
    }
    prev2, prev1 := 1, 1 // dp[i-2], dp[i-1]; dp[0] = 1
    for i := 1; i <= len(s); i++ {
        cur := 0
        if s[i-1] != '0' {
            cur += prev1 // last char alone: 1..9
        }
        if i >= 2 && (s[i-2] == '1' || (s[i-2] == '2' && s[i-1] <= '6')) {
            cur += prev2 // last two chars: 10..26
        }
        prev2, prev1 = prev1, cur
    }
    return prev1
}
int numDecodings(const string& s) {
    if (s.empty()) return 0;
    int prev2 = 1, prev1 = 1;                        // dp[i-2], dp[i-1]; dp[0] = 1
    for (size_t i = 1; i <= s.size(); i++) {
        int cur = 0;
        if (s[i - 1] != '0') cur += prev1;           // last char alone: 1..9
        if (i >= 2 && (s[i - 2] == '1' || (s[i - 2] == '2' && s[i - 1] <= '6')))
            cur += prev2;                            // last two chars: 10..26
        prev2 = prev1; prev1 = cur;
    }
    return prev1;
}
static int numDecodings(String s) {
    if (s.isEmpty()) return 0;
    int prev2 = 1, prev1 = 1;
    for (int i = 1; i <= s.length(); i++) {
        int cur = 0;
        if (s.charAt(i - 1) != '0') cur += prev1;
        if (i >= 2) {
            char a = s.charAt(i - 2), b = s.charAt(i - 1);
            if (a == '1' || (a == '2' && b <= '6')) cur += prev2;
        }
        prev2 = prev1; prev1 = cur;
    }
    return prev1;
}
def num_decodings(s):
    prev2, prev1 = 1, 1                           # dp[i-2], dp[i-1]; dp[0] = 1 (empty prefix)
    for i in range(1, len(s) + 1):
        cur = 0
        if s[i - 1] != '0':
            cur += prev1                          # last char alone: 1..9
        if i >= 2 and (s[i - 2] == '1' or (s[i - 2] == '2' and s[i - 1] <= '6')):
            cur += prev2                          # last two chars: 10..26
        prev2, prev1 = prev1, cur
    return prev1 if s else 0

The traps are all about zero: "0" alone is not a letter, so "06" has 0 decodings and "10" has exactly 1. A zero that is not preceded by 1 or 2 ("30", "100") makes the whole count 0, and the code handles it automatically because neither branch adds anything. Test these strings before you say "done".
