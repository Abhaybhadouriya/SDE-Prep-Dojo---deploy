The map of DP families

Almost every interview DP belongs to one of a dozen families. Each family has a typical state shape, and each has a clue in the problem statement. Learn the families, and a new DP problem becomes "which family, and what is the state?".

From your world

The state-machine family is literally a protocol state machine with costs: the TCP connection states, or a NIC driver's link states, with "what is the best total if I am in state S after event i?" stored per state. You already think in states and transitions; DP just adds a number to each state.
