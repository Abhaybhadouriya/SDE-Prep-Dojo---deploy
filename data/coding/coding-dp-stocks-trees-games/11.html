Revision card

  • Cue: Buy/sell with rules, "rob houses on a tree", cameras, two players picking optimally.
  • Insight: A small tag on the step (holding, resting, trades used) or a tuple per tree node captures the whole past.
  • State: hold / free / cooldown states per day; post-order DFS returning a tuple; dp = mover's score minus the other's.
  • Trap: Holding must start at minus infinity; calling a child twice in tree DP; ignoring the tie rule in games.
  • Cost: O(n) or O(n k) for stocks; O(n) for tree DP; O(n^2) for interval games.

More to remember

  • State = step + a small tag (holding, resting, j trades used). Draw the boxes and arrows; each box is a max over incoming arrows.
  • Stocks: I = buy with 0 cash, II = buy with cash, fee = subtract on sell, cooldown = third state, k = chain of 2k states (guard k >= n/2).
  • "Holding" starts at minus infinity; the answer is a "no share" state.
  • Tree DP: post-order DFS returns a tuple per node; never call a child twice.
  • Cameras: NOT_COVERED / HAS_CAMERA / COVERED, null = COVERED, fix the root.
  • Games: store (mover - other); value = take - dp(rest). Ties: check the problem's rule.
  • Weighted intervals: sort by end, dp over prefixes, upper bound for the last compatible job.
