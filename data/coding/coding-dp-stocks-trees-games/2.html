Cooldown: draw the machine first, then code it

Stock with cooldown (LeetCode 309), told our way: daily prices for n days; you may trade any number of times, holding at most one share, but the day after you sell you must sit out (no buying). Return the maximum profit. Constraints: 1 <= n <= 5000, prices between 0 and 1000. Example: prices [2, 5, 1, 4, 6] give 5. Without the cooldown the answer would be 8 (2 to 5, then 1 to 6), but selling on day 1 forbids buying at 1 on day 2.

Two states are no longer enough, because "own nothing" now splits into "sold today" (cannot buy tomorrow) and "resting" (free to buy). Draw the machine:

Read the formulas straight off the arrows: every arrow into a box is one term of that box's max. All three right-hand sides must use yesterday's values, so compute them together (a tuple assignment, or temporaries in C).

Watch the notebook fill for [2, 5, 1, 4, 6]:

  1. Day 0, price 2: the only useful move is to buy, so hold = -2. Nothing can be sold yet.
  2. Day 1, price 5: selling the share bought at 2 gives sold = 3. Hold stays -2 (buying at 5 would be worse).
  3. Day 2, price 1: the cooldown bites. Buying today uses rest (0), not sold (3), so hold only improves to -1. The 3 moves into rest, ready for tomorrow.
  4. Day 3, price 4: buying now would cost 3 - 4 = -1, no better than -1 already held. Selling gives 3.
  5. Day 4, price 6: selling the share bought at 1 gives sold = 5.
  6. The answer is the best "no share" state on the last day: 5.

Transaction fee (LeetCode 714): unlimited trades, no cooldown, but each completed buy-sell pair costs a fixed fee. That is Stock II with the fee subtracted on the sell arrow: cash = max(cash, hold + price - fee). Two states again.

// maxProfitCooldown: unlimited trades, one day of rest after each sale (LC 309).
func maxProfitCooldown(prices []int) int {
	hold, sold, rest := math.MinInt32, 0, 0 // the three states at the end of a day
	for _, p := range prices {
		// right-hand side uses yesterday's values
		hold, sold, rest = max(hold, rest-p), hold+p, max(rest, sold)
	}
	return max(sold, rest)
}

// maxProfitFee: unlimited trades, pay fee per completed transaction (LC 714).
func maxProfitFee(prices []int, fee int) int {
	cash, hold := 0, math.MinInt32
	for _, p := range prices {
		cash = max(cash, hold+p-fee) // sell today and pay the fee
		hold = max(hold, cash-p)     // buy today
	}
	return cash
}
// Unlimited trades, one day of rest after each sale (LC 309).
int maxProfitCooldown(const vector<int>& prices) {
    int hold = INT_MIN / 2, sold = 0, rest = 0;      // the three states at the end of a day
    for (int p : prices) {
        int prevSold = sold;
        sold = hold + p;                             // sell today (must have held)
        hold = max(hold, rest - p);                  // keep holding, or buy after a rest day
        rest = max(rest, prevSold);                  // do nothing (yesterday's sale cools down)
    }
    return max(sold, rest);
}

        cash = max(cash, hold + p - fee);            // sell today and pay the fee
        hold = max(hold, cash - p);                  // buy today
    }
    return cash;
}
