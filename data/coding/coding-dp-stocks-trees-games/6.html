Weighted job scheduling: sort, DP, binary search

Maximum Profit in Job Scheduling (LeetCode 1235), told our way: you get n jobs, job i runs from start[i] to end[i] and pays profit[i]. Pick a set of jobs whose time ranges do not overlap (a job that ends at time X may be followed by one that starts at X) and maximise the total pay. Constraints: 1 <= n <= 5 * 10^4, times between 1 and 109, profits between 1 and 104.

Times up to 109 rule out a DP over time. Sort the jobs by end time and let dp[i] = best pay using only the first i jobs. For job i there are two choices: skip it (dp[i-1]) or take it and add the best schedule of jobs that end by its start. Because ends are sorted, "the jobs that end by its start" are a prefix, found with one binary search.

Cost: O(n log n) for the sort plus n binary searches. The binary search must find the last job with end <= start (upper bound on start), not "end < start"; mixing those up is the most common bug here.

// jobScheduling (LC 1235): sort by end, dp over prefixes + binary search.
func jobScheduling(start, end, profit []int) int {
	n := len(start)
	idx := make([]int, n)
	for i := range idx {
		idx[i] = i
	}
	sort.Slice(idx, func(a, b int) bool { return end[idx[a]] < end[idx[b]] })
	dp := make([]int, n+1) // dp[i] = best using the first i jobs (by end)
	for i := 1; i <= n; i++ {
		job := idx[i-1]
		// number of jobs among the first i-1 that end at or before this job starts
		k := sort.Search(i-1, func(m int) bool { return end[idx[m]] > start[job] })
		dp[i] = max(dp[i-1], dp[k]+profit[job]) // skip it, or take it after job k
	}
	return dp[n]
}
// Maximum Profit in Job Scheduling (LC 1235): sort by end, dp over prefixes + binary search.
int jobScheduling(const vector<int>& start, const vector<int>& end, const vector<int>& profit) {
    int n = start.size();
    vector<int> idx(n);
    iota(idx.begin(), idx.end(), 0);
    sort(idx.begin(), idx.end(), [&](int a, int b) { return end[a] < end[b]; });
    vector<int> ends(n);
    for (int i = 0; i < n; i++) ends[i] = end[idx[i]];
    vector<int> dp(n + 1, 0);                        // dp[i] = best using the first i jobs (by end)
    for (int i = 1; i <= n; i++) {
        int job = idx[i - 1];
        // number of jobs that end at or before this job starts
        int k = upper_bound(ends.begin(), ends.begin() + (i - 1), start[job]) - ends.begin();
        dp[i] = max(dp[i - 1], dp[k] + profit[job]); // skip it, or take it after job k
    }
    return dp[n];
}
// Maximum Profit in Job Scheduling (LC 1235): sort by end, dp over prefixes + binary search.
static int jobScheduling(int[] start, int[] end, int[] profit) {
    int n = start.length;
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) idx[i] = i;
    Arrays.sort(idx, (a, b) -> Integer.compare(end[a], end[b]));
    int[] dp = new int[n + 1];                       // dp[i] = best using the first i jobs (by end)
    for (int i = 1; i <= n; i++) {
        int job = idx[i - 1];
        int lo = 0, hi = i - 1;                      // count jobs among the first i-1 ending <= start
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (end[idx[mid]] <= start[job]) lo = mid + 1; else hi = mid;
        }
        dp[i] = Math.max(dp[i - 1], dp[lo] + profit[job]);  // skip it, or take it after job lo
    }
    return dp[n];
}
def job_scheduling(start: List[int], end: List[int], profit: List[int]) -> int:
    """LC 1235: sort by end, dp over prefixes + binary search."""
    jobs = sorted(zip(end, start, profit))
    ends = [e for e, _, _ in jobs]
    dp = [0] * (len(jobs) + 1)  # dp[i] = best using the first i jobs (by end)
    for i, (e, s, p) in enumerate(jobs, 1):
        k = bisect_right(ends, s, 0, i - 1)  # jobs that end at or before s
        dp[i] = max(dp[i - 1], dp[k] + p)  # skip it, or take it after job k
    return dp[-1]

From your world

This is the offline version of a reservation table: think of booking non-overlapping DMA windows or TDMA slots where each slot request has a value. Sorting by end time is the same trick as an earliest-deadline-first queue; the binary search is bsearch() over a sorted array of end times, using an "upper bound" comparator.
