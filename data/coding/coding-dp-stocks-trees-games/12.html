Quiz

In the cooldown machine, which value does today's "buy" arrow read?

  1. Yesterday's hold
  2. Yesterday's rest
  3. Yesterday's sold
  4. Today's sold
After a sale you must rest one day, so you can only buy from the rest state.

Stock IV with k = 109 and n = 1000. What should your code do?

  1. Return 0
  2. Run the O(n k) DP
  3. Return the sum of all positive day-to-day rises
  4. Allocate arrays of size k
At most n/2 transactions can be useful, so k does not bind and the problem becomes Stock II.

House Robber III: a node with value 7 has children returning (take, skip) = (3, 5) and (4, 1). What does it return?

  1. (13, 9)
  2. (7, 9)
  3. (13, 8)
  4. (14, 9)
take = 7 + 5 + 1 = 13; skip = max(3, 5) + max(4, 1) = 9.

Binary Tree Cameras: what does a null child return?

  1. NOT_COVERED
  2. COVERED
  3. It is skipped and returns nothing
  4. HAS_CAMERA
A null needs no coverage and gives none, so COVERED; that makes leaves NOT_COVERED, pushing cameras to their parents.

Predict the Winner: cards [5, 1]. What is diff[0][1]?

  1. -4
  2. 5
  3. 6
  4. 4
Take 5 and leave 1: 5 - 1 = 4.

Job scheduling: four jobs sorted by end time have ends [3, 5, 5, 8], and the last one starts at 5. How many of the first three can come before it?

  1. 4
  2. 1
  3. 2
  4. 3
Upper bound of 5: ends 3, 5, 5 are <= 5, because a job may start exactly when another ends.

Which problem is NOT naturally a state-machine DP?

  1. Maximum alternating subsequence sum
  2. Longest increasing subsequence
  3. Stock with transaction fee
  4. Paint House
LIS depends on the value of the last pick, not a small set of tags; it is a 1D DP over "ends at i" (or patience sorting).
