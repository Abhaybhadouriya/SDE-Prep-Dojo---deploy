Resources

  • NeetCode roadmap - Arrays & Hashing course - the standard first block of problems, with short videos per problem.
  • Tech Interview Handbook - Hash table doc - a compact cheat sheet of hash-table techniques and corner cases.
  • Tech Interview Handbook - Array doc - array corner cases to say out loud (empty, one element, duplicates).
  • Sean Prashad - LeetCode patterns repo - problems grouped by pattern; good for extra practice after this page.
  • Boyer and Moore - MJRTY, a fast majority vote algorithm paper - the authors' own page with an animated example.
  • Maximum subarray problem doc - Kadane's algorithm, its history and variants (empty subarray allowed or not).
  • Two Sum - community solutions blog - sort by Most Votes for the one-pass map write-ups in many languages.
  • First Missing Positive - community solutions blog - Most Votes posts compare the swap and the negative-marking versions.
  • Go maps in action doc - zero values, the comma-ok idiom and why iteration order is random.
  • Java HashMap API doc - load factor, resizing and iteration-order guarantees (none).
  • C++ unordered_map doc - reserve, find vs operator[], complexity guarantees.
  • Linux jhash.h repo - the hash the kernel uses for many of its tables, for the "From your world" bridge.
