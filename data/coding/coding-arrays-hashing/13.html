Revision card

  • Cue: "Have I seen this before?", counts, groups, pairs to a target, O(n) asked on unsorted input.
  • Insight: A brute force re-scans; a hash map remembers what you already scanned, so one pass is enough.
  • State: map value to index (two-sum), int cnt[26] or a map of counts, map canonical key to list (grouping).
  • Trap: Store x before asking for target - x (finds x + x = target wrongly); sorted-string keys cost O(k log k).
  • Cost: O(n) expected time, O(n) space; sorting instead costs O(n log n) and saves the map.

More to remember

  • Brute force re-scans; hashing remembers. One pass plus O(1) lookups = O(n) expected.
  • Two-sum: ask for target - x first, then store x.
  • Counting: small alphabet = int cnt[26]; anything else = a map.
  • Grouping: compute a canonical key, then map[key].append(item).
  • Consecutive runs: start a walk only where x - 1 is missing.
  • Kadane: cur = max(x, cur + x), start at nums[0].
  • Values in 1..n plus O(1) space: the array is the hash table.
  • Majority with O(1) space: vote, then re-count if no majority is promised.
