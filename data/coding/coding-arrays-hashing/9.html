How to recognise it

Read the problem, then match the words in it against these cues. Say the cue out loud in the interview ("I need a fast 'have I seen x' check, so a hash set"): it shows the interviewer your reasoning before you write code.

When it is NOT this pattern. If the array is sorted and you need pairs, two pointers give O(1) space (next page). If the question is about a contiguous window with a limit ("at most k distinct", "length at least"), it is a sliding window, which often uses a count map inside it.
