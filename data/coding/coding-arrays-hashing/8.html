Pattern 7: Boyer-Moore majority vote

"Find the element that appears more than n/2 times" has a hash map answer (count everything, O(n) space). The interview follow-up is "O(1) space". Boyer-Moore voting keeps one candidate and one counter. A matching element votes +1, a different one votes -1, and when the counter hits 0 the next element becomes the new candidate.

Why it works, in one sentence: each -1 cancels one copy of the candidate against one different element; the majority has more copies than all other elements together, so it cannot be cancelled out completely and is the candidate left standing. Practice it: LeetCode 169 - Majority Element (takeuforward); the restated version and edge cases are in our Majority Element write-up.

func majorityElement(nums []int) int {
	cand, votes := 0, 0
	for _, x := range nums {
		if votes == 0 {
			cand = x // the prefix so far cancelled out
		}
		if x == cand {
			votes++
		} else {
			votes--
		}
	}
	return cand // re-count if a majority is not guaranteed
}
int majorityElement(const vector<int>& nums) {
    int cand = 0, votes = 0;
    for (int x : nums) {
        if (votes == 0) cand = x;               // the prefix so far cancelled out
        votes += (x == cand) ? 1 : -1;
    }
    return cand;                                // re-count if a majority is not guaranteed
}
static int majorityElement(int[] nums) {
    int cand = 0, votes = 0;
    for (int x : nums) {
        if (votes == 0) cand = x;              // the prefix so far cancelled out
        votes += (x == cand) ? 1 : -1;
    }
    return cand;                               // re-count if a majority is not guaranteed
}
def majority_element(nums):
    cand, votes = None, 0
    for x in nums:
        if votes == 0:
            cand = x                   # previous prefix cancelled out fully
        votes += 1 if x == cand else -1
    return cand                        # valid only if a majority is guaranteed (else re-count)

Only when a majority is promised. On [1, 2, 3] the vote ends with candidate 3, which is not a majority. If the problem does not guarantee a majority, do a second pass to count the candidate. The n/3 version (Majority Element II) keeps two candidates and two counters and always needs the second counting pass.
