Common mistakes

Switching on p.next == null instead of p == null. Skipping the null step means disjoint lists never make both pointers null at the same time, and the loop never ends.

Comparing values. p.val == q.val returns the first equal value, which is often not the shared node.

Re-linking the lists to find the join. Joining A's tail to B's head and running cycle detection works (it is LC 142), but you must undo it: the problem requires the original structure.

Python: == instead of is when a ListNode class defines __eq__; identity is what you want.
