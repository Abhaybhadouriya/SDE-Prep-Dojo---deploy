Revision card

  • Cue: two singly lists may share a tail; find the first shared node, O(1) memory.
  • Insight: a + c + b = b + c + a: walk A then B, and B then A.
  • State: p, q; at null jump to the other head.
  • Trap: switch on p == null (keep the null step), compare identity not values.
  • Cost: O(m + n) time, O(1) space; no join ends with both null.
p, q = headA, headB
while p is not q:
    p = headB if p is None else p.next
    q = headA if q is None else q.next
return p

Why do the two pointers meet at the join?

  1. They move at different speeds
  2. Each walks own part + shared part + the other own part, the same total
  3. The lists have equal length
a + c + b = b + c + a.

What happens when the lists do not intersect?

  1. Both become null at the same move and null is returned
  2. The loop runs forever
  3. It returns the last node of A
With c = 0 both cover a + b nodes plus one null step.

Which comparison is correct?

  1. p.val == q.val
  2. p.next == q.next
  3. p == q (same node)
The shared node is the same object; values can repeat anywhere.
