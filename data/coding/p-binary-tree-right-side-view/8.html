Common mistakes

Following right children only. Returns the right spine and misses deeper levels that exist only on the left ([1,2,3,4] gives [1,3] instead of [1,3,4]).

Reading q.size() inside the inner loop. The queue grows while you push children, so the level boundary is lost. Snapshot the width before the loop.

DFS left-first with "first at depth". That gives the LEFT view. For the right view, recurse right first (or go left-first and overwrite view[depth] every time).

Returning null for an empty tree. The expected output is an empty list.
