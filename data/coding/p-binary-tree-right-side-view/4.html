Approaches: brute → better → optimal

Hint 1

Which node is visible on level d? Can you list the nodes of level d in left-to-right order?

Hint 2

If you visit right children before left children, the first node you reach at a new depth is the visible one.

1. Brute force - collect all levels, then take the last of each

Idea: do a normal level-order traversal that returns a list of lists (LC 102), then map each level to its last element.

O(n)time
O(n)space

What is wasted: it stores every node of every level, although we need one value per level. It is still a fine answer for n ≤ 100; the next rungs only cut the memory. -> rung 2.

2. Optimal (iterative) - BFS, keep the last node of each level

while q:
    width = len(q)                      # exactly one level is in the queue
    for i in range(width):
        node = q.popleft()
        if i == width - 1: view.append(node.val)
        push(node.left); push(node.right)
  1. Snapshot the width. At the top of the outer loop the queue holds exactly one level, so len(q) is that level's size.
  2. Pop exactly width nodes. Children pushed during the loop belong to the next level and wait behind.
  3. The last pop is the visible node because children are pushed left before right, so each level comes out left to right.
O(n)time
O(w)space, w = widest level

3. Optimal (recursive) - DFS right-first, first node at each new depth

def dfs(node, depth):
    if not node: return
    if depth == len(view): view.append(node.val)   # first time we reach this depth
    dfs(node.right, depth + 1); dfs(node.left, depth + 1)
  1. len(view) = the number of depths already seen. If depth == len(view), this is the first node met at this depth.
  2. Right before left means the first node met at a depth is the rightmost one there.
O(n)time
O(h)space, h = height (recursion)

Why it works: in a preorder walk that visits right subtrees first, every node to the right of x on x's level is visited before x (it lies in a subtree that branches off to the right at some common ancestor, and that subtree is finished first). So the first node visited at each depth has nothing to its right.
