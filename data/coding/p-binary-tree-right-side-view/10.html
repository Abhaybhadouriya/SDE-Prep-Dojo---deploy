Technique: level-order traversal with a per-level action (first, last, max, sum, link), or DFS that carries the depth.

Closest match: GfG Right View of Binary Tree GfG (and its twin, Left View)

  • Same: one node per level, seen from a side.
  • Different: the left view takes the FIRST node of each level.
  • So: BFS: test i == 0; DFS: recurse left before right.

How to recognise it:

  • "Per level", "row by row", "seen from the left/right/top", "deepest".
  • The answer has one entry per depth of the tree.

Practice order:

  1. Warm-up: 102 Level Order Traversal (the width-snapshot loop).
  2. This problem: BFS first, then the right-first DFS.
  3. Then 513 Bottom Left Value, 103 Zigzag, and 987 Vertical Order for the harder grouping.
