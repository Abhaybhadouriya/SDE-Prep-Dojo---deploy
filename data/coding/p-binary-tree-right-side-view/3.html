Recognise the pattern

When you see "one value per level" / "top to bottom" / "seen from a side", think level-order BFS with a width snapshot, or DFS that carries the depth. Right view = last of level; left view = first of level; largest per row, average per row and zigzag are the same loop with a different per-level action.

Try a few shapes and check "just follow right children":
