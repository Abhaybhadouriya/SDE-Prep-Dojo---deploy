Recognise the pattern

Cue: a sequence where you repeatedly remove / merge / cut an element, the cost depends on its current neighbours, and n is a few hundred -> interval DP on dp[l][r], enumerating the split point k. If "the first choice" makes the sides depend on each other, enumerate the last choice instead.

Why "first" fails: in [2,4,3], bursting 4 first makes 2 and 3 neighbours, so the left part's score now depends on the right part. The subproblems are not independent, and you would need to remember which balloons are left: 2n states. With "k is last in (l, r)", every balloon in (l, k) is burst while k is still standing, so its world is bounded by l and k, and the same for (k, r).
