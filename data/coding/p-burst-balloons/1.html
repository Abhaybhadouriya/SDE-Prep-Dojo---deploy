The problem (in our words)

You get an array nums of n balloons; balloon i shows the number nums[i]. You must burst all of them, one at a time, in any order. Bursting balloon i earns nums[left] * nums[i] * nums[right] coins, where left and right are its current nearest unburst neighbours. If a neighbour does not exist (off either end), treat it as a balloon showing 1. Return the maximum total coins you can collect.

Signature: int maxCoins(int[] nums).

Constraints

  • n == nums.length, 1 <= n <= 300
  • 0 <= nums[i] <= 100

Practice it: LeetCode 312 · GfG Burst Balloons

Constraints tell you: n ≤ 300 means O(n3) = 2.7·107 basic steps, fine; O(n!) or O(2n) is impossible. The largest total is below 300 · 1003 = 3·108, so 32-bit ints are enough.
