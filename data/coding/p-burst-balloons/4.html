Approaches: brute -> better -> optimal

Hint 1

Add a balloon with value 1 at each end. Now every real balloon always has two neighbours.

Hint 2

Fix two balloons l and r that are NOT burst. Among the balloons strictly between them, which one's coins can you compute without knowing the order of the others?

Hint 3

The last one burst between l and r: at that moment its neighbours are l and r, so it earns v[l]·v[k]·v[r].

1. Brute force - try every order

Idea: recursively pick any remaining balloon to burst next, add its coins, recurse on the remaining list, keep the maximum.

O(n!)time
O(n)depth

What is wasted: the score of the remaining balloons depends only on which ones remain, not on the order the others were burst. Memoising on the set of remaining balloons gives O(2n · n): still far too slow for n = 300.

2. Better - memoised recursion on (l, r), last balloon

Idea: pad to v = [1] + nums + [1]. f(l, r) = best coins for bursting everything strictly between l and r. Try every k in (l, r) as the last: f(l, r) = max f(l, k) + f(k, r) + v[l]·v[k]·v[r], with f(l, l + 1) = 0.

@cache
def f(l, r):
    return max((f(l, k) + f(k, r) + v[l] * v[k] * v[r] for k in range(l + 1, r)), default=0)
return f(0, len(v) - 1)
O(n3)time: n2 states × n choices
O(n2)memo

What is wasted: nothing asymptotically, but 45 000 memo entries plus Python call overhead is slow; bottom-up is the same table filled by interval length.

3. Optimal - bottom-up by interval length

  • State: best[l][r], 0 <= l < r <= n + 1, over the padded array: most coins from bursting all balloons strictly between l and r while l and r stand.
  • Transition: best[l][r] = max over l < k < r of best[l][k] + best[k][r] + v[l]·v[k]·v[r].
  • Base case: best[l][l + 1] = 0 (nothing inside).
  • Order: by increasing gap r - l, since every transition reads strictly shorter intervals.
  • Answer: best[0][n + 1].
O(n3)time (~4.5·106 inner steps for n = 300)
O(n2)space

Why it works: take any order of bursting the balloons in (l, r) and let k be the one burst last. Every balloon in (l, k) bursts while k is alive, so its neighbours always lie in [l, k]: that part is a valid order for the subproblem (l, k), and likewise (k, r). k itself earns exactly v[l]·v[k]·v[r]. So every order's total is at most best[l][k] + best[k][r] + v[l]·v[k]·v[r] for its k, and conversely any pair of optimal sub-orders plus k last is a real order. Hence the max over k is exact. The padding 1s are never burst, matching the "missing neighbour counts as 1" rule.
