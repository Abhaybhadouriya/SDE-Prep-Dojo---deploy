The problem (in our words)

A tree was lost, but two walks of it were logged as integer arrays of equal length. preorder lists the nodes in root, left subtree, right subtree order; inorder lists the same nodes in left subtree, root, right subtree order. Rebuild that binary tree from the two logs and return its root.

Signature: TreeNode buildTree(int[] preorder, int[] inorder). The judge prints the result in level order with null for missing children.

Constraints:

  • 1 <= preorder.length <= 3000
  • inorder.length == preorder.length
  • -3000 <= preorder[i], inorder[i] <= 3000
  • All values in preorder are distinct, and the values of inorder are the same set.
  • The inputs are guaranteed to be valid traversals of one binary tree.

Practice it: LeetCode 105 · GfG practice · TUF article

Constraints tell you: n = 3000, so even O(n2) = 9 x 106 passes, but interviewers expect O(n). A chain-shaped tree is 3000 levels deep: recursion is fine in C++/Java/Go, but Python needs a higher recursion limit (or the iterative version). Distinct values is what makes the answer unique and the hash map possible.
