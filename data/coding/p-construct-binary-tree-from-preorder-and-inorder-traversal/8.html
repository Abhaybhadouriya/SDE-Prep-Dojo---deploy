Common mistakes

Building the right subtree first with a shared cursor. The cursor walks preorder, which lists the left subtree before the right one. Swap the calls and the right side steals left-side values. (With postorder + inorder it is the reverse: walk from the end and build right first.)

Off-by-one in preorder ranges. If you pass preorder ranges instead of a cursor, the left part is [preLo + 1, preLo + (mid - inLo)]; using mid instead of mid - inLo is the classic bug. The cursor version avoids it.

Slicing arrays in Python / Java. preorder[1:k+1] copies; on a chain that is O(n2) time and memory. Pass indices.

Linear search for the root. Correct but O(n2) on skewed trees. The map is one line.

Assuming it works with duplicate values. preorder [1,1], inorder [1,1] fits both "root with left child" and "root with right child". Say that distinctness is required.
