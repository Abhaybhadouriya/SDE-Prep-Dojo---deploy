Recognise the pattern

Cue: "rebuild a tree from two traversals" -> one traversal gives the root (preorder: first; postorder: last), inorder splits the rest into left and right sizes. Recurse on index ranges with a value -> inorder index map. Without inorder (preorder + postorder) the tree is not unique unless it is full.
