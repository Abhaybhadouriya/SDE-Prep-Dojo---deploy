Now build it from inorder and postorder.

Same map and build(lo, hi); the cursor starts at the last postorder index and decreases, and you build the right subtree before the left, because postorder read backwards is root, right, left.

How to answer

Say "mirror the order" before writing anything; it shows you understand why the order mattered.

Likely follow-ups
  • Preorder + postorder? Not unique; LC 889 accepts any tree.
Can you do it without the O(n) hash map?

Yes: the "stop value" recursion (or its iterative stack form) walks preorder and inorder with two cursors, and a subtree ends when inorder reaches the value of the ancestor it hangs under. O(n) time, O(h) extra space.

How to answer

Explain the invariant: inorder's cursor reaching the parent means the left subtree is complete.

Likely follow-ups
  • Iterative version to avoid stack overflow on a 106-deep chain.
What if values can repeat?

The answer may no longer be unique, and the map cannot store several positions. If the task promises a valid answer and accepts any, keep per-value position lists and pick a split whose left size is consistent with the preorder segment (check that both sides contain the same multiset), which costs more than O(n). In an interview, state the ambiguity first.

How to answer

Give the two-node counterexample, then ask what output is acceptable.

Likely follow-ups
  • Attach unique ids to nodes instead of values.
What is the space complexity, exactly?

The output tree is n nodes (not counted as extra). Extra: the map O(n) and recursion depth O(h), which is O(log n) for a balanced tree and O(n) for a chain.

How to answer

Separate output, auxiliary structure and stack.

Likely follow-ups
  • Can the stack overflow? On a 3000-deep chain in Python, yes, without raising the limit.
Check whether two given arrays are valid traversals of one tree.

Run the same builder with guards: the value at the cursor must exist in the map and its inorder index must lie inside [lo..hi]; at the end the cursor must equal n. Any failure means the arrays are inconsistent. Still O(n).

How to answer

Validation is the builder plus range checks; no second algorithm needed.

Likely follow-ups
  • Return the tree's height without building it: track depth in the same recursion.
