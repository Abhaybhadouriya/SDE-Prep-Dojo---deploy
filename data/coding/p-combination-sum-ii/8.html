Common mistakes

Skipping with i > 0 instead of i > start. That forbids using a value twice anywhere, so [1,1,2] is lost. The skip must apply only among siblings in the same slot.

Forgetting to sort. The skip only compares neighbours; unsorted equal values are not adjacent, and the break is wrong too.

Recursing with i instead of i + 1. That is Combination Sum I: a card gets reused.

continue instead of break when a[i] > left. Still correct, but it keeps scanning values that cannot fit; on 100 cards it wastes work at every node.

Appending pick itself. In Java / Python the list is mutated later; append a copy (new ArrayList<>(pick), pick[:]).

Dedup with a set of sorted tuples. Accepted for small inputs, but it hides the exponential repeated work, and interviewers ask you to remove it.
