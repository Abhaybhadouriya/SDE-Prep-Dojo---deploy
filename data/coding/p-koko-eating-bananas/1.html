The problem (in our words)

A print shop has n jobs; job i has piles[i] pages. The shop closes in h hours. You pick one whole-number speed k (pages per hour). Each hour the printer chooses one job and prints k pages of it; if that job has fewer than k pages left, it prints them all and does nothing else in that hour (it never moves on to a second job within the same hour). Return the minimum integer k such that all jobs are finished within h hours.

  • Input: an integer array piles and an integer h.
  • Output: one integer, the smallest valid speed. Signature: int minEatingSpeed(int[] piles, int h).
  • A job with p pages takes exactly ceil(p / k) hours at speed k.

Constraints

  • 1 <= piles.length <= 10^4
  • piles.length <= h <= 10^9 (so an answer always exists)
  • 1 <= piles[i] <= 10^9

Practice it: LeetCode 875 - Koko Eating Bananas (the original: a monkey and banana piles) · GfG - Koko Eating Bananas · takeuforward

Constraints tell you: speeds range over 1..10^9, so trying each one is hopeless; log2(10^9) is about 30 guesses, and each guess costs O(n) = 10^4, so about 3 × 10^5 operations. The total hours at speed 1 can reach 10^4 × 10^9 = 10^13, which overflows a 32-bit int: sum in 64 bits.
